# 第四部

1—2 1810年罗斯托夫家的乡村生活。尼古拉回家休假，试图整顿家业

3—7 准备打猎；机灵的猎人丹尼洛。尼古拉同远房大叔和伊拉金一起猎狼、狐狸和灰兔；打猎丰收。到大叔家过夜；大叔弹吉他，娜塔莎跳俄罗斯舞

8—11 婚事。娜塔莎的悲伤。尼古拉和宋尼雅。竖琴和歌唱晚会；乘三驾马车化装出游；宋尼雅在谷仓旁算命

12—13 归家；在镜子前算命。尼古拉决定娶宋尼雅，因此同母亲发生冲突

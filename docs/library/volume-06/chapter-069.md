# 小俄罗斯传说《四十年》的结尾[15]

在8月12日到13日的夜晚，他（杀人犯）第一次同儿子谈话后在自己屋里独自躺下睡觉，对他的惩罚也就开始了。

“没有上帝，没有灵魂，没有惩罚！多么好，多么太平！我徒然折磨自己太多太久了。正如亚历山大所说的，为了生存我们老是互相争斗，互相残杀。为生存而争斗，这就是规律！没有别的规律。上帝让我成为胜利者。这是上帝恩赐的！这个愚蠢的习惯想法一直存在着。其实不是上帝恩赐，而是我自己努力成为胜利者；我觉得很快活。人人都在争斗；谁争斗，谁就能胜利。我作了争斗，我取得了胜利。我本可以好好生活，只是回忆往事使我痛苦；如今我将过得更好，十分好。我明白他们羡慕我（他记起了苦行僧的话）。他们羡慕我，人人都希望这样。既然希望，你就得争斗。自己争斗，不要等待人家恩赐。就说亚历山大吧……”

他想起，几天前亚历山大对他说，每年给他两万卢布太少。亚历山大要求增加一万，当他拒绝时，儿子很不高兴。

“假如他盘算在我死后取得全部财产……”

特罗斐姆·谢苗诺维奇恍然大悟，儿子一定在盼着他快点死掉。

“要争斗，成为胜利者，我争斗，杀死了商人；我要他死，我就要了他的命。可是他，我的儿子亚历山大，他要谁死呢？”

他停了停，魂飞魄散地从床上坐起来。

“要谁死？要我死！是的，我挡了他的路。不论我给他多少，他还是要我死。我一死，他就是当家人了。”

特罗斐姆开始回忆儿子的看法和言语，他处处看出儿子盼着他死。儿子不能不这样盼望。

“他是个受过教育、不迷信的人。如果他这样盼望，他就会把我杀死。假如他不自杀。可是他有毒药！”

他忽然想起儿子同他谈到过古代的毒药，这种毒药杀人之后不会留下痕迹。

“他要是有这种毒药，怎能保证他不给我吃呢？他一定会给我吃的！”

“他已经说过我荒废事业，他说可以做得更多些。是的，只要一杯茶就行了！可以收买仆人、厨子，他们都是可以收买的。”

他想起他那个喜欢打扮的侍仆。

“只要给这个人一千卢布就成了，还有厨子也是这样。”

特罗斐姆想到这事很激动。为了使自己镇静，他想喝一杯糖水，那杯糖水就放在他床边的小几上。他拿起玻璃杯，杯底有一样白色的东西。“谁知道这是什么东西……不，你骗不了我！”他说着，把水倒掉；然后走到洗脸盆旁，在那里喝了水。“对了，人跟人都在争斗。但争斗的时候可不能粗心大意，得留点儿神。妻子吃喝什么，我也吃喝什么……她也是这样。她知道七分之一将归她所有。她那些穷亲戚早就向她提过要求了。是的，战争，这就是战争！我一定要设法不让他们从我的死亡中得到好处。我要写一份遗嘱，剥夺他们的一切权利，使我的死对他们没有好处。对了，我明天就写，并向他们宣布。”

他想睡觉，可是思潮起伏，他安静不下来。他决定写遗嘱。他穿上睡袍和软鞋，走到桌旁，动手写遗嘱。遗嘱里写明把全部财产捐赠给慈善机构。写好遗嘱，他想躺下睡觉，但这时他想到了听差，想到了管院子的仆人。他想象自己是听差，并对自己说：“如果我是个穷听差，每月领十五卢布工钱，而隔开五个房间却睡着一个口袋里放着许多钱的富人，那会怎么样？我像现在一样明确地知道，没有上帝，没有神的裁判。我会怎么办？我会像对付商人那样对付他。”特罗斐姆又感到了恐惧；他又站起来，关上房门，可是门闩不牢。于是他用安乐椅把门堵住，在门把手上系一条手巾，在安乐椅上再放一把安乐椅，使它一动就会发出响声。直到这时他才熄灭蜡烛，接着酣睡了很久，以致妻子不放心，走来推门。安乐椅倒下来，发出响声，特罗斐姆脸色发白，心惊胆战地跳起来。

“谁？什么事？救命啊！”他甚至叫起来，好半天清醒不过来。在惊醒的时候，他觉得仿佛有人来谋杀他。一直到他完全清醒过来，他才说他是出于谨慎才把门堵住的。他竭力掩饰自己的恐惧；但不论他怎样掩饰，从那天起家人和仆人还是发现他身上发生了巨大的变化。以前，当他想到自己的罪行时，他有时快乐，有时愤怒，有时和蔼可亲，有时垂头丧气。以前他不喜欢一些人，却喜欢另一些人，尤其喜欢几个孙儿。现在他总是只身独处，总是沉默寡言，小心翼翼，对任何人都疑神疑鬼，对任何人、甚至对孩子都十分冷淡。从那时起，写遗嘱成为他的主要活动。他好久都没能写成一份满意的遗嘱。所有为此事跑来帮他的官吏都不能使他感到满足。他写过又重写，不断改变主意。他对食物也特别挑剔。有时，他放下他所喜爱的美味佳肴，尝都不尝一下，常常不吃饭，在家人吃到一半时才来。他拿过儿子、女儿或妻子吃过的盘子吃起来。他专为自己买了酒，锁在自己房间的柜子里。他开始很少处理事务；当他处理财务时，总是对家人隐瞒利润，不让人知道他收到多少钱财。金钱以前曾给他带来莫大的快乐，如今只使他烦恼。他竭力把钱保存好，觉得无法信任像他自己这样不信神的人。他觉得，如果大家都像他和他儿子那样知道没有上帝，也没有神的裁判，那么，任何力量都不能保护他。人家会杀死他，毒死他，用诡计或者暴力夺取他的财产。唯一解救的办法是，不要告诉人家他知道没有上帝，也没有神的裁判，相反，要使他们相信，上帝是有的，神的裁判也是有的。因此，在8月12日后特罗斐姆身上发生了最后一次变化：他变得特别虔诚，这是他这辈子从未有过的。他不错过一次礼拜，参加所有的斋戒，包括星期三和星期五的斋戒，不放弃一次机会向家人、朋友和仆人宣传，上帝和教规都是存在的，谁不遵守，谁就将灭亡，并将在来世受到残酷的惩罚。他甚至教诲儿子，装作忘记以前同儿子说过的话，并在这方面作过忏悔。

从8月12日起，他相信他没有什么事可害怕的，也没有什么人能使他害怕，相信上帝是没有的，如今再没有什么事会妨碍他随心所欲地生活了。从那时起，他的乐趣不仅完全消失，而且变成了痛苦。被杀害、毒死、受骗，在自己家里和家人之间发生最可怕的罪行，他也始终不能摆脱这种恐惧。他怀疑人人都在搞最可怕的阴谋。他胆战心惊，憎恨一切人，憎恨妻子、儿子、女儿和所有的人。就连他原来所钟爱的几个小孙儿，如今都被他看作一群小野兽。他认为，他们也憎恨他，就像他憎恨别人那样。为了摆脱恐惧，他不断做两件事：第一是采取种种防人的措施；第二是教诲人们，上帝是存在的，神的裁判是存在的。他认为只有更使人家相信他自己不相信的事，他自己才能得救。他的心情不断恶化，这不仅不能使他高兴，而且使他恐惧。家人都是他的敌人。就连吃喝睡觉这些普通的乐趣他都没有。他处处怀疑人家在策划恶毒的阴谋对付他。

不幸的特罗斐姆就这样又过了十多年。他的怪癖大家都看到，但他的痛苦却谁也没有看到。他的痛苦是深重的。他的痛苦主要是他的生活被恐惧所破坏（他这样感觉），心中充满恐惧，却怎么也无法克服，无法摆脱，而且他所担心的事情也越来越逼近了。

特罗斐姆就这样受了十二年的煎熬。有一天，他做礼拜回来，在自己房间里吃了早饭，喝了点他锁在柜子里的酒，躺下睡觉，就此再也没有醒来。特罗斐姆的死是突然的，平静的。

特罗斐姆的豪华棺材被运到亚历山大·聂夫斯基修道院墓地。棺材后面跟着一大群熟人，他们是来参加大富翁金矿主死后的丰盛午餐和晚餐的。一位当时以善于辞令著称的彼得堡传教士致了临葬悼词，竭力颂扬死者的高尚品德、虔诚信仰和幸福生活。除了上帝，谁也不知道特罗斐姆的罪行，也不知道自从他心中失去上帝那分钟起他受到了什么样的惩罚。

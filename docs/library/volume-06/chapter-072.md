# 克鲁采奏鸣曲

只是我告诉你们，凡看见妇女就动淫念的，这人心里已经与她犯奸淫了。（《马太福音》第五章第二十八节）

门徒对耶稣说，人和妻子既是这样，倒不如不娶。耶稣说，这话不是人都能领受的。唯独赐给谁，谁才能领受。

因为有生来是阉人，也有被人阉的，并有为天国的缘故自阉的；这话谁能领受，就可以领受。（《马太福音》第十九章第十、十一、十二节）

# 16

第二天，骑兵连出发了。两个军官没有看到房东，也没有向他们辞行。彼此也没有说话。他们打算在下一个宿营地决斗。不过，舒尔兹骑兵大尉是个好人，又是名出色的骑手，在团里很受人爱戴，原来准备担任伯爵的副手，但他巧妙地处理了这件事，不仅取消了决斗，而且团里也没有人知道这件事。再有，土尔宾和波洛佐夫两人虽不像以前那么要好，但仍旧你我相称，一起吃饭，一起打牌。

1856年4月11日

# 二

父亲在屋子里咕噜咕噜地打鼾。米嘉一清早起来，给干活的枣红马带上笼头，骑到顿河边上去饮水和洗澡。干枯的白垩在马蹄下飒飒发响，飞溅开来。他骑到陡岸下的水边，卸去马嚼子，自己脱掉衣服，因为早晨的寒气而打着寒噤，同时听到，隆隆的炮声在老远的水上扩散开来，轻轻地沿着顿河的河面滚动。米嘉一头钻进清晨的寒冷彻骨的水里，笑了笑想：“现在菲多尔该已经到了布尔什维克的地方……在红卫军里干着了……”

他的思想一转到家，转到父亲身上，快乐的情绪就像风中的火星一样，一下子熄灭了。他躬着背骑着马回家去，眼睛也变得暗淡无光了。

快到家的时候，心里想：“我得赶快逃到那边去……到布尔什维克的地方去……真理在他们那边，菲多尔说过的……我要找他去。不然，父亲今天会剥掉我的皮……把我收拾得鼻孔流血的……”

他在台阶旁取下笼头，慢吞吞地走进屋子里。父亲在正房里哑着嗓子问：

“为什么不带小公马去洗澡？”

米嘉对茫然地站在火炉旁的母亲瞧了一眼，感到全身的血，都涌到心脏里了。

“马房里没有小公马！……”

“那么它在哪里？”

“我不知道。”

“那么菲多尔在哪里？”

“我没看见。”

父亲穿上靴子，一步拖一步地走着。他穿过厨房，走进贮藏室，两只睡得浮肿的眼睛闪闪地发着光。

“鞍子在哪里？……”他在门口大声问。

米嘉挨近母亲，像小时候那样抓住她的手。父亲走进厨房里，两手卷着一条皮带。

“你把钥匙给了谁啦？”

母亲用身体挡住米嘉。

“你别动他，阿尼西姆·彼特罗维奇。看基督分上，别打他！……你不疼儿子吗？”

“滚开，混蛋！……听到没有？……”他推开母亲，把米嘉掀倒地上，熟练而狠心地用脚踢了好一阵，直到米嘉的喉咙里停止低沉的呻吟。

# 九

吃早饭的时候，米哈依尔得意洋洋地撚弄着搽过油的淡黄色小胡子。

“妈妈，现在把我提升为骑兵中尉了，因为我把布尔什维主义连根拔掉了。我是不好惹的，稍微有点什么就枪毙！”

母亲叹了一口气：

“米哈依尔，你说，爸爸他们怎么了？……也许会回来吧……”

“妈妈，我是个军官，又是静静的顿河的忠实儿子，可不能考虑什么亲属关系。不论父亲，不论亲兄弟，一律送交法办……”

“好儿子！……我的米哈依尔！……叫我怎么办呢？……你们都是我的奶喂大的，我都一样疼！……”

“不能有丝毫同情心！……”他严厉地扫了一眼伊格拿特的儿子：“把这个小畜生从桌子边拉走，不然我会扭断他的脖子的，共产小杂种！……你瞧，他看人的样子，活像一头小狼……将来长大了，也是个布尔什维克，像他父亲一样，小坏蛋！……”

# 十

第二天早晨，菲多尔的母亲没吃早饭，就想走了。

“或者再待一天吧？”菲多尔勉强问。

他不知怎的感到一种无法克制的羞耻，为了自己，为了老板，为了母亲，也为了这无聊的生活。因此，母亲能不能再呆一天，他是无所谓的，虽然昨天碰到她的时候，还感到非常高兴。

在经历了这一切以后，最好带着自己的思想、愤怒和对这世界的痛恨，独自呆在一个地方——在这个世界里找不到一个人保护，找不到一个人可以商量，也找不到一个人会向你说一句温暖的同情话。

母亲也忙着想走。她看见儿子，心里很难受，而更难受的是，坐在桌子旁边要看见老板和老板娘像狗一样贪婪的充满敌意的眼睛。她每吃一口东西，他们都盯住她看。

“不，儿子，还是让我走吧……咱们总能见面的。”

“嗯，走吧。”菲多尔没有表情地说。

他们分手了。菲多尔忽然想到，母亲路上没有吃的东西。

“等一下，妈妈，我去问问老板娘，也许她会给咱们一斗粮食的。老板不付钱，我就拿粮食当工钱吧……你可以拿去卖掉……”

老板娘听了菲多尔的请求，拿起钥匙，一句话不说，走到谷仓跟前。她开了锁，问：

“口袋有吗？”

“有的。”

菲多尔张开口袋，眼睛望着一旁，望着粮囤的棕色围墙。围墙上结满蛛网，像花边一样精致。老板娘用不足的量器，吝啬地量着带杂粒的小麦。

门“吱嘎”一声响了。老板挺着大肚子走进来，冲到老婆跟前：

“回到屋子里去！”接着急忙向菲多尔奔去。

菲多尔小心翼翼地垂下口袋，身子靠在粮囤的墙上，等待着。

“你这是干什么呀？”扎哈尔歪着脸，声音嘶哑地嚷起来，“领粮食吗？……”

“是的。”

“煽动工人！制造纠纷！老板为了你几乎在家里挨巴掌，可你还要……还要拿我的粮食……啊？”

菲多尔一声不响。老板变了脸色，一步一步走到他的跟前，忽然用孩子一样尖锐的声音，结结巴巴地嚷道：

“从我的家里滚出去！……滚，畜生！……”

菲多尔左手提起口袋，向门口迈了一步，可是老板像公鸡一样向他扑过来，夺下他手里的口袋，抡开手臂，狠狠地给了他一记耳光。

菲多尔的眼前金星乱舞。一股怒火使他失去理智，两手也沉得好像灌满了铅……菲多尔身子摇晃了一下，一手抓住老板肥胖的喉咙，一手握紧拳头，使劲往那向后仰的头上敲了一记。

一转眼，扎哈尔已经被菲多尔压在底下，身体像一条大蝮蛇似的拼命扭动，想咬菲多尔的面孔。菲多尔把自己的嘴唇咬得出血，用力打着老板又短又粗的脖子和他那格格发响的牙齿。扎哈尔使用娘儿们的各种手段：抓，咬，撕菲多尔的头发，可是过了一会儿，他被彻底打垮了，喘着气，流着眼泪，嘴唇上满是鼻涕，躺在地上，可怜地喊着喔唷，打着呃逆<sup class="footnote-ref" id="note-ref-7-1"><a href="#note-7" aria-label="查看本页注释 7">[7]</a></sup>，肚子一起一伏地抖动。

菲多尔站起来，擦去抓破的脸上的血，等着第二次进攻，可是老板很快地翻了个身，哼哼着，像龙虾一样向门口爬去。

“为了一切！为了一切！为了一切！”菲多尔激动地想。他整了整衣服，提起口袋，一只手刚握住门把手，就听见声嘶力竭的叫声：

“救——命——呀！……杀——死——人——了！……好人呐，救——命——呀！……”

一阵难以克制的狂笑，哽住了菲多尔的喉咙。他靠在门框上，哈哈大笑，——在他父亲死后，这还是第一次。他笑够了，走到院子里。扎哈尔站在院子中央，脚尖向外撇着。他不听周围工人们惊慌的问话，张大嘴巴嚷道：

“救——命——呀！……”

# 十九

“……我们亲爱的菲多尔同志！你大概不知道法院的判决吧？扎哈尔被判七年徒刑，褫夺公民权三年，其他两人米哈依尔和赫烈诺夫村的投机商库兹卡，各处徒刑五年。还要告诉你一件事，赫烈诺夫村的共青团支部已经组织起来了。你那几个雇农同志——十五个人，还有六个穷孩子，都已经入团了。区委调了我的工作。大家都热烈希望你早日恢复健康，回到这儿来。叶戈尔在达尼洛夫村组织了一个十一人的支部。孩子们都干活去了。再要告诉你一件事：前几天我看见潘吉烈老大爷，他准备到医院里去望你，还要带吃的东西给你。赶快把身体养好回来，还有很多工作得做，可是时间跑得像脱缰的马一样快。

“团支部向你致共青团的敬礼，代表全体同志执笔的——雷勃尼柯夫。”

1926年

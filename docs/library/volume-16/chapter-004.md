# 二

又过了一天，两天，一星期，他们始终没有离开本乡一步。天一亮，直心肠的公鸡用惊奇的“喔—喔—喔”声把他们叫醒，仿佛在问：孩子们，你们还在这儿吗？

安德烈的父亲常常好玩地瞧着儿子。他什么都明白，但什么也不愿干涉。青年人会挑选他们的道路的，他们不爱接受旁人的劝告。何况他也不知道该怎样劝告儿子才好。“你留在家里吧！将来可以继承我那座房子。把屋顶修一修，漆一漆，它就会跟新的完全一样。”——难道他应该说这样的话吗？事实上，他能答应给儿子的只有一座小小的房子，而生活却愿意把整个世界交给他的儿子。

不过，儿子将挑选什么，到底是值得注意的。

“真倒霉，生得不乖巧！”安德烈父亲想到儿子，不胜感慨，“不灵活，唉，不灵活！”

可惜得很：儿子长得太文静拘谨，沉默寡言，甚至有些胆怯。他缺乏现代青年人那种活泼、豪放和勇敢的风度；他看见人怕难为情，碰到姑娘就脸红。他走不远的！

“说不定一辈子会跟着维克多跑吧，”父亲带着苦笑想，“维克多胆子真大！”

不过孩子们始终在寻找他们的路……他们在镇上走来走去，就像徘徊在车站的站台上一样，闷得受不了。他们已经不是本地人，已经成了过路的旅客；只等第三次铃声一响，他们就要走了。他们已经跟应该告别的一切告了别，已经从心上抛去必须抛去的一切宝贵和亲爱的东西。列车不断地在他们身旁闪过，车上的灯火在引诱他们，可是他们所期待的那列车，却始终没有来。

现在维克多很想当电影演员。他不知在什么地方听人说过，莫斯科有这样一所学校：不需要考试，不需要入学证，只要你有一张漂亮的脸，就可以当演员。他是一个漂亮的小伙子，这一层，他心里有数。他的身体非常强壮，动作矫捷灵活，眼睛里燃烧着黑色的火焰，嘴巴长得像强盗，勇敢而英俊。他有一个习惯，喜欢闭紧嘴巴，咬住下唇，仿佛马上就要吹口哨似的。男孩子们开玩笑，说他是吉卜赛人，姑娘们隔着篱笆望他，心里说不出是惊是喜。他当演员，不成问题。

但是安德烈怎么办呢？他走起路来摇摇摆摆，慢条斯理，头发乱得好像稻草，其中有一绺一直拖到额上，这副样子，叫他做什么好呢？难道叫他去做小丑不成？

“好吧，到了那边再说吧！”维克多心里作着决定。不论什么事，当他渴望做到时，他不爱考虑障碍。障碍使他生气，他就干脆逃避它们。他总是碰到一粒火星就会发火，但冷得也同样快。他的气质只宜当铁匠，不配做镟工。

“莫斯科，老兄，首都……电影院……是吗？”他激动地说着梦话，“也许，我们有才能？也许，这就是路？”

安德烈听着一声不响。他从来不跟维克多争论。事实上，他也不会争论。他总是很有耐心地听完好朋友那种慷慨激昂的狂想，一句话也不说，简直像表示同意似的，然而，过一会儿却低低地咕噜着，好像在赔不是：

“不，我不愿意。”

就这样，一下子把人家的幻想连根砍倒了。

维克多火了。

“活见鬼，安德烈，那么你到底想干什么呢？”他叫着，差一点哭出来。

而安德烈呢，还是照样沉默着，只是微微低下头，噘着嘴，听完朋友的责骂，然后又固执地低声重复说：

“不，我不愿意。”

河水送来了九月的寒意，隔河的矮树林黄起来了，涌现了大批的黄叶，秋天突然像老处女脸上的皱纹，一夜间就出现了；被这两个孩子摒弃的那些专科学校，都已经开了学；普晓河上的垂柳，关心他们的离家，泪已经流尽，它们的叶子开始发黄了。

有一天，这两个孩子没有到普晓河畔去。他们对河水已经不感兴趣，河水在他们身边匆匆地流过，好像它也有一个重大的目标在前方，但这跟岸上两个没事做的孩子有什么相干呢！

他们到郊外去，到大路那边去。那边，在企比略基镇口，耸立着一座灰色的古老坟山，坟山上长满银色的苦艾。孩子们爬到坟山顶上，就躺在草丛里。

迷迷糊糊地躺在坟山顶上是多么惬意啊！地面又清凉，又安静，临别的九月太阳把干燥的青草晒得暖暖的。苦艾在风中摇摆，形成一片青灰色的波浪，弄得他们更加昏昏欲睡。据说，草原的老鹰从前很爱飞到这儿来，飞到这座坟山上来；现在可连鸵隼也看不到一只了。乱草丛中，可以发现的，只有马的残骸：山下那条路不久以前还是过往客商常走的大道。

这条路现在仍旧弯弯曲曲，仿佛一串连环圈。它也像普晓河一样，伸展到不知名的远方，路上的车辆好像河里的小船，路上的行人仿佛在水里游泳，而那扬起的尘埃就像河里泛起的浪花。

安德烈不愿看到大路，他就翻了个身，仰天躺着，眼睛开始朝天空眺望。

然而，天上也有徜徉不定的白云在匆匆飞翔；天空也在瞬息万变地运动。于是安德烈就又翻了个身，把脸埋在泥土里。这样要好过些。

艾蒿发出一种苦味和平静的死气，这种气味只有在墓园和教堂里安葬和焚香的时候才闻得到。“为什么艾蒿总是发散着坟墓的气味呢？”安德烈胡思乱想着。“或者应该说，坟墓发散着艾蒿的气味？”他拿艾蒿的花瓣在手里搓搓，然后闻闻双手。“也许，哪儿都不用去吧？”他忽然想。“留在故乡。进父亲的那家制粉厂就行了。据说，再过一年，企比略基也要开始建设了。那时还要造一座发电站。或者，就留下来吧？”接着他一边沉思默想，一边把艾蒿的气味重新闻一闻。

维克多眼睛只望着大路。这天早晨，维克多变得出奇地沉默，他一句话也不跟朋友交谈，只是躺着，瞧着大路。路上的一切，在他看来，都是美好的：不论尘土也好，大车的轧轧声也好，汽油、羊群和马粪的气味也好。维克多觉得即使在这儿坟山顶上，也闻得到这些气味。但艾蒿的苦味，他可没有发觉。

一株株细长的杨树，盖着厚厚的尘土，活像一个个风尘仆仆的行人，在沿着大路跑去，并且消失在地平线之后。其中前面的几株好像一直通到波尔塔瓦。“到了波尔塔瓦就有火车可以坐，要到哪儿，就可以到哪儿：莫斯科、高加索或者太平洋，都去得。”维克多想。好吧，要是作不成演员，那么当飞行员也行，再不然去当装卸工人，或者干脆像高尔基那样赤着脚东西流浪，做一只自由自在的小鸟。

有一次，他连这样的建议也向安德烈提过。而安德烈呢，仍旧照老规矩，一声不响地听完他的话，然后光是没头没脑地问：“那么关系怎么办呢？”——“什么关系？”——维克多弄不懂了。“团的关系。我们的组织关系转到哪儿去呢？”

不，这样一辈子也不用想冲出企比略基了！这里的一切都在拉你的后腿：母亲、安德烈、共青团、路上每块熟悉的石头。这样是永远也冲不出去的了！必须干脆一些——现在马上就从坟山上跑下去，不要回头张望，不要跟谁告别，也不要犹豫不决，只要跟着杨树开步走去——不问上哪儿去，也不问为了什么，只要走，只要不再在坟山上的艾蒿间躺下去就好了。

他突然眼睛不看安德烈，低低地、像是自言自语地说：

“或者，分开吧？”

“什么？”安德烈反问。他没有听懂，惶恐地微微一笑。他以为维克多对他说了好一阵话，而他却被艾蒿催眠了，在打瞌睡，没有听到。

“我说，或者我们两人还是分开吧？”维克多重复了一遍。

他说这话时，故意不看朋友的脸。他等了一会儿。他想安德烈一定会马上跳起来，向他扑过去，并且叫道：你不要把我丢下吧，老兄，你要上哪儿去，就上哪儿去，只是要跟我一起去……

可是安德烈却一句话也不说……

于是维克多重新又说起话来，他实在是再也沉默不下去了。他烦恼地说，已经九月了，秋天了，有许多青年早已走了，他们全是些平平常常的孩子，不调皮，也不像安德烈那样左不是右不是，可是我们两人，老坐在企比略基，等着黄金的马车和天上掉下来的幸福，过失就在安德烈一个人身上，他是横也不对，竖也不对，要是没有他，维克多早就在莫斯科进了电影学校了。就算为了好朋友的缘故，他也不该放弃他的理想吧？

维克多越说越兴奋，越说越激昂，在火头上尽把负气话往朋友的身上倒，虽然他明明知道这些话是不公平的，是听了叫人生气的，说这些话是不客气的，不应该的，是可耻的，然而他已经克制不住了。蒙着尘土的杨树沿着大路一直往下跑，跑到波尔塔瓦；风吹树木，把它们绿色的背包吹得摇来摆去。

但是安德烈还是沉默着……

他躺着，脸埋在草丛里，一动也不动。他简直弄不明白，这一切是怎样发生的。他们本是好朋友，有过共同的幻想，作过天真的宣誓。他们时常在一起仰望头上的那些星星，他们对银河，就像对通到普晓河的那条大路一样熟悉。现在怎么样呢？现在要怎么样呢？维克多是对的。他勇敢，灵活，机敏。他即使只身独往，也不会出事的。安德烈对他帮得了什么忙呢？安德烈只是一个累赘罢了。

那么，友谊呢？友谊也就这么到了十字路口了。安德烈忽然想放声痛哭一场。

这场争吵会怎样结束，真是天知道！孩子的友谊是非常脆弱，没有牢固的基础的，说不定到了明天早晨，他们就会讲和，就会互相让步，并且终究会找到一条两人都合适的道路。但也可能从此分道扬镳，各人走各人的路。这样一来，他们的命运自然各自独立，两不相干了。过了好多年之后，如果他们有机会重逢的话，他们一定会觉得奇怪，从前两人怎么会梦想走同一条路的，但也可能会感到惋惜，他们当初没有找到一条两全其美的路。那天早晨，在坟山上，维克多话说到一半，突然独自跑掉了，留下安德烈一个人躺在艾蒿里。那天早晨之后，什么事情都有发生的可能，不过，那天晚上，他们两人突然都被叫到共青团的区委会里去了。

他们俩虽是各自去的，但在那里却不期而然地碰到了。

区委里挤满了共青团员，但没有一个人知道，叫他们来有什么事。

“也许是打仗吧？”不知哪一个猜测说，大家全笑了。虽然打仗也不是没有可能的。在那个时候，大家都有一种战争的预感。

最后区委书记巴辛柯来了，他仍旧像平常那样头发蓬松，脸上露出忧虑的神色。这个身穿绣有青色矢车菊衬衫的蓝眼睛青年，总是像在作战一样紧张。他老说着一个简单的句子：“同志们！要照章缴团费了。”他说这句话时的那副神气，简直就像叫人上火线一般。他充满责任心，一点没有幽默感。

巴辛柯用铅笔敲着玻璃水瓶，不等大家坐好、静下来，就嚷道：

“同志们！顿巴斯的计划完不成啦！”他透了一口气。

这是完全出乎意料之外的。大家全摸不着头脑。

不知哪一个女孩子的声音，天真地问：“孩子们，顿巴斯在哪儿呀？”大家都对她发出了嘘声。巴辛柯再次激动地用力喊道：“顿巴斯的计划完不成啦，同志们！”于是就像有一个蓬头散发、黑烟冲天、并且不知什么缘故遍体鳞伤的、名叫顿巴斯的陌生怪物，跑到了安德烈的跟前，站在他的身旁。许多汽笛在它的上空号叫，惊心动魄，参差不齐，好像秋天里的一群寒鸦……黑烟、汽笛声、灰色的雨——这就是安德烈所能想象的关于顿巴斯的一切。他简直连猜也猜不透，这跟他安德烈有什么关系。

然而维克多却兴致勃勃地仔细听着。“突破！”<sup class="footnote-ref" id="note-ref-7-1"><a href="#note-7" aria-label="查看本页注释 7">[7]</a></sup>——他爱好这一类字眼。看来巴辛柯马上要下命令了：“孩子们，前进！冲呀！拼死命呀！”于是他们就向前冲去。冲去！维克多还不知道，巴辛柯要他们去立怎样的功劳：他也像安德烈一样，对于那个陌生的顿巴斯，只能作些模糊的想象，而对于“顿巴斯突破了”这句话，更加摸不着头脑。“突破”当时在企比略基还是一个新名词。然而，无法形容的兴奋之感，已经占有和震动了维克多，就跟一年之前巴辛柯同样激动地对他们叫“同志们，中东铁路发生了冲突”时一模一样。维克多也像我们大家一样，属于充满幻想的一代。

此刻巴辛柯在谈着五年计划。他的声音一会儿高，一会儿低——他不会镇静沉着地说话。他具有一个真正共青团员的可爱品质：诚心诚意地关怀一切。对于他说来，世界上没有一个国家是遥远的，也没有一件事情是别人的。一切都是自己的，血肉相关的：不论是西伯利亚的粮食采购，还是乌兹别克的棉花收获，或是意大利共产党员的被处死刑，都一样。鲁尔<sup class="footnote-ref" id="note-ref-8-1"><a href="#note-8" aria-label="查看本页注释 8">[8]</a></sup>矿工罢工的被破坏，使他感到难过，就像他身受一样。

他说起话来颠三倒四，但从不间断。他的措辞也许并不恰当，然而他却能用自己的热情来修饰词句，这样一来，就产生了奇迹：拙劣的措辞变得优美动听，死板的词句也显得生动活泼了。

巴辛柯喉咙说干了，匆匆地拿起玻璃杯，咕嘟一声吞了一大口水……好像杯子里盛的是沸腾的开水，接着，连嘴唇都来不及抹一抹，又马上说下去了。

“真能说话！一停也不停！”安德烈怀着钦佩的心情想，同时叹了一口气，“我就没有这样的能力。如果要我发言，我会害怕的……我会逃走的。”接着他又像早晨那样，突然想起：什么地方也不用去了，还是留在这儿吧，留在团里跟巴辛柯学学吧。但愿将来自己也作个像巴辛柯那样的人。

巴辛柯突然中止了他大声的演讲，用平常谈话的音调说：

“现在我来把区委的决定，向你们大家读一读。”说着两手就在身上的许多口袋里乱摸：他根本没有公事皮包。

维克多用不耐烦的眼光盯着他看：他到底就要宣布什么，要他们去立些什么功劳，不过，无论什么功劳，维克多都是准备去立的。巴辛柯找了好久，还是找不到那张需要的纸头，他从口袋里掏出来的，都是别的东西，突然他掏出一张包巧克力糖的锡纸来——他喜欢吃甜食——这可把他弄得非常不好意思，大家偏偏又笑了起来。但是维克多一笑也不笑，他觉得一点也不可笑，此刻他满怀慷慨激昂和自我牺牲的心情，他对巴辛柯所抱的最低期望，是去赴营火晚会的命令。

突然他听到说：

“莫斯科和列宁格勒两市的同志们发起，要委派三万人到顿巴斯<sup class="footnote-ref" id="note-ref-9-1"><a href="#note-9" aria-label="查看本页注释 9">[9]</a></sup>矿区去参加经常工作。企比略基的共青团区委会支持这个建议，决定派遣下列十名列宁共产主义青年团企比略基镇组织里的最优秀团员：维克多、米特罗芳、安德烈……”

安德烈一听到自己的名字，吃了一惊：他一向以为区委会根本不知道有他这么一个团员，也不会把他记起来的。但是现在竟突然把他的名字列在十个最优秀的团员之中了。他的脸涨得通红。

“居然记起来了！”

不过，这种又惊又喜的感觉立刻就消失了。他明白，所谓十个人的名单，是怎么一回事。“这是说，要我们去当矿工吧？去当矿工？”他一面想，一面手足无措地向周围张望。他自己也没有想到，他是在找维克多。

他们分开坐着，因为早晨才吵过嘴，不过他们的目光马上碰在一处了。两人都感到，他们的命运就要——也许——从此决定了。安德烈的脸色显得惊惶失措，维克多的脸色显得委屈难当。

是的，实在是委屈难当。连他的嘴唇都在抖动，就像小孩子生气时那样。仿佛巴辛柯骗了他，并且在恶狠狠地嘲笑他。无论把维克多动员到哪儿去都行——天空、海洋、水底、北极，到处都一样。但是到矿井里去吗？干脆去当矿工吗？一分钟之前，他还准备不惜生命，去立任何功劳——而且此刻仍旧有着这样的准备。但是在矿井里谈得到什么功劳呢？干脆去当矿工！他几乎要从座位上跳起来。几乎要含着眼泪喊出来：“我不去！你们没有权力的！”

巴辛柯立刻注意到了维克多的脸色，使他感到惊奇，甚至生气。他期待人家回答他那火焰般的演说的，原不是这样的眼睛。

他冷冰冰地说：

“不过，谁要是不愿意，可以不去……这是要各人自愿的。”

# 四

“不过，要是谁不愿意，可以拒绝！”巴辛柯板着脸说，眼睛盯着孩子们。

安德烈和维克多都沉默着。

当然，也可以拒绝。可以站起来，直截了当地说：“不。我不干！”或者耍个花招，“我真愿意去，可是妈妈有病……年纪大了……一个人。”

拒绝是可以的，但是，如果在十七岁的年纪上就胆小，害怕，对共青团的第一次号召就加以拒绝，那以后将怎样生活呢？

跟我同年纪的孩子们，你们想来都体验过这种自豪的感觉：“我是被党所动员的！”不是被招募，不是被雇佣，而是被动员！

我们勇往直前地投入千人的队伍，两万五千人的队伍，投入舰队、乡村、森林。我们被派去管理粮食、木柴，做运输工作。有人一生的经历就是充满各种不同的动员，而这也就是我们祖国的历史，祖国主要干线的地理。我们会很快地收拾行李。我们过得惯任何气候。到处我们都是主人。

安德烈悄悄地抬起头来，低低地说：

“不，我们同意！”

说了出来，他自己也感到奇怪，怎么会这样说呢，不过他了解，说别种话是办不到的。

瘦长条子的巴辛柯，眉飞色舞地拍了一下手，接着把双手高举到头上，第一个鼓起掌来。

但是安德烈却心慌意乱、手足无措地站着，他自己还不明白，为什么大家全向他鼓掌，他还没有感到，这就是他生命里伟大的第一分钟；将来他会常常想起它，并且会用不同的方式想起它。

然后是演说。情绪突然激动的维克多，热情洋溢地高声说，如果祖国需要矿工，那么，好吧，他就自愿去……除了安德烈之外，所有被动员的人全说了话；巴辛柯又一次发言，之后，全体到会的人都情绪热烈地涌到了街上，一家家地护送英雄们归家去。

他们互相拥抱着，嘴里唱着歌，五人一排地走着，笔直地走在街道的中央，正像在1919年那样。他们把当天的英雄送到各自的大门口时，他们好一阵热热闹闹地互相告别，异口同声地高呼口号，发放“火箭”——要知道他们昨天还个个都是少年先锋队呢；其中有一个女孩子——就是问“那么顿巴斯在哪儿呢，孩子们？”的那一个——甚至当着众人的面，情不自禁地吻了吻安德烈，这弄得他很狼狈，大家都哈哈大笑。在他们的生活里，这一分钟是伟大的，它会被人记在心里，成为一个值得纪念的日子。“这是我们欢送我们的共青团员到矿井去的日子。”后来，欢送这一类事就习以为常了。祖国要求企比略基的孩子们投入伟大的生活：去学习，去参军，去到新的建筑工地。整个组织欢送他们，正像当时欢送维克多和安德烈一样。

只剩安德烈一个人留在自家的篱笆门口了，他没有马上走进屋里去。他还在庭园里，站在静静的柳树下，听着紫罗兰的夜曲。“去当矿工，这就是啦！”而心境忽然变得轻松平静了。选择好了。到了那边再说吧！

他一走进屋子，就对父亲说：

“后天我们要走了。”沉默了一会儿，又补充说：“到煤矿去。”

父亲惊奇地瞧了他一眼。

“上哪儿去？！这是怎么一回事，是你那个维克多出的主意吧？”他怒气冲冲地问。

“不。是共青团动员去的。”

“噢——噢！”父亲站了起来，在屋子里踱来踱去。

“也许，去回绝还不迟吧？”他犹豫不决地问，“试去商量一下吧？”

“不。不行。”

他们两人又沉默了一会儿。

“那么这不是长期的吧，孩子？”父亲终于又问，“一个月，或者，三个月？”

“那可不知道……”

父亲回到了工作台旁，继续他中断了的工作——给女儿做布娃娃，他是什么都会的。

“我还以为你要去念书呢。”他道歉似的笑着说，“趁现在我还有力量，还有可能……好吧，没关系！”接着他又低头做布娃娃，开始画眼睛。

而维克多呢，他一回到家马上就告诉母亲说，他要去当矿工了。

“啊呀，糟糕！”母亲拍了一下手。

可是维克多立时严厉而暴躁地制止了她。

“动员，妈妈。”

她在这几个字里听到熟悉的调子，沉默了。是的，维克多的父亲也总是用一两个简单的字眼来回答她那女人家的叹息和眼泪：革命。或者：动员。革命委员会的命令。

她克制了叹息。跟革命委员会争论是不行的。于是，她不让维克多看到自己无声的眼泪，马上动手替他整理行装。

第二天一整天，是在忙乱、激动、准备行李和烘制路上吃的圆面包中过去的。安德烈和维克多那天只在共青团的区委里见了一面。

可是晚上他们竟出乎意外地在庭园里相遇了。他们没有经过商量，就默默无言地一起朝普晓河走去。他们忘记了昨天的口角，谁也没有再提到它。这算得上什么口角呢！现在他们要长久地走在一块儿，也许一辈子不再分离。

他们走到普晓河畔，默默地对河水看了好一阵。他们不仅在跟普晓河告别，他们还在跟童年告别。他们的童年是美好的、丰富的、自由自在的。谢谢你，普晓河，谢谢你们，故乡的田野，故乡的城市！现在孩子们要开始劳动生活了。不过，他们开始这样的生活，已经算是晚的了。安德烈的父亲只有十岁就去挣自己的第一块面包了。

“据说，矿井里很可怕！”安德烈悄悄地说，“不要说人，连马的眼睛都会瞎的。”

“胡说八道！”

“不。它们的确是那样生活在矿井里：瞎着眼睛。”

河水洋洋地流着，冲击着一只橡木小船。

“我一到矿井，马上就要当一个突击队员，”维克多吹着牛，“让他们瞧瞧我们的本领！”他顽皮地伸展着整个灵活的身体。

“人家还说，矿井里煤气很多。划一根火柴，就会发生爆炸。”安德烈又说。

“你已经在担心了吗？”维克多轻蔑地冷笑一声。

“我？”安德烈平心静气地反问，“我——不。”

天色已经完全黑了。该回家了。维克多折了一条柳枝，抛在水里。

“漂吧！”

他俩好一阵屏住了呼吸，瞧那条树枝怎样顺着黑色的河水漂流；不，不会沉没的！——瞧它现在完全消逝在黑暗中了。

“不过像这样的河，那边是不会有的！”安德烈叹了一口气说，突然感到有一样东西堵住了喉咙。

“嗳，女人腔！”维克多怒气冲冲地吐了一口唾沫，骂了出来，马上走开了。

第二天大清早，被动员的团员们出发了。他们有乐队欢送。载着箱子的大车，走在前头。孩子们自己决定步行到车站。总共七公里路，全镇的团员都来给他们送行。

乐队一直走到那座坟山的地方，临别时又奏了一首快乐的进行曲。孩子们最后一次回头望望故乡，他们看到：好些屋顶，还有阳光照耀下屋顶上金黄色的南瓜。

这样，故乡瓦屋顶上的金黄色南瓜，将一辈子留在记忆里……

长干的白杨在大道两旁送孩子们远行。一转眼间它们已经在火车车厢的窗外奔驰了……白杨遍地，这就是乌克兰！

企比略基的孩子们在波尔塔瓦搭上了专车。车上已经有基辅人、彻尔尼戈夫人、日托米尔人、波尔塔瓦人；每站都有一批新的人上来：出现了苏梅的团员，然后又是哈尔科夫的团员；仿佛所有的共青团员都要往煤矿区去，而且都已经出发了。安德烈已经知道，他跟维克多是三万人中的两个。

“三万人！”维克多眉飞色舞地说，“这是一支大军！”

孩子们很快地互相结识。一路上有说有笑，一起歌唱，非常快乐。他们朝车窗外面望望，惊奇地发现这里的草原竟跟他们企比略基的草原一样，这里的田野也跟那里的田野相同——已经收割过了，金黄色的干草，东一堆，西一堆，而且，房子也同样是白的和蓝的，有着描花的百叶窗，还有那井上的辘轳和一排排的白杨。

甚至当那列快乐的专车，最后开入顿尼茨的地面时，景色仍旧一点也没有改变。同样有苦艾杂生的草原，有白杨，有土房子……

“不，这不是顿巴斯！”维克多绝望地叫道，“这不会是顿巴斯的。”

但是列车员证实说：是顿巴斯。红里曼，亚马，阿吉莫夫斯克。

直到傍晚，过了尼基托夫卡之后，玻璃窗上才撩人地映出了一片红光。孩子们都冲到窗口去看。不，这既不是火烧，也不是落日的斜照。

顿巴斯就这样头一次向孩子们显示了它整个的美和力：隆隆的响声和熊熊的火焰，缭绕在灭火塔上空的像乌云一样的浓烟，熔矿炉的深红色反光，矿渣堆上神秘地时隐时现的火光，黏土山上的青色篝火；煤烟的苦味和焦炭的刺鼻气味；煤气、硫磺、铁和在矸子山上冒烟的硫铁矿的难闻的气味；以及它那困难沉重、断断续续的呼吸，仿佛所有的鼓风机、压缩机和蒸汽站，都无法把足够的空气送入它那巨人般的铁肺里去，于是它喘息着，并且发出尖锐的声音……

顿巴斯在夜间给孩子们的印象就是这样——烟囱林立，威武伟大，蓬头散发，神秘莫测……

“我们将在这儿工作……生活。”孩子们又惊又喜地想。大家全都望着，望着车窗外的顿巴斯在怎样摇摇摆摆地、舒舒徐徐地飘过……

# 五

但是他们并不是很快就当上了矿工的。开头他们是客人。欢迎他们的有乐队和演说。当地的共青团领导者们，在他们周围奔走忙碌。他们唯恐新来的人们不喜欢这个地方。

其中有一个人极像巴辛柯，他动辄向人道歉：一会儿为了烟多，一会儿为了灰大，一会儿又为了树木太少……

“当然，没有习惯以前，会感到一些困难的。”他说。

“那么您习惯了没有呢？”维克多问他。

“我？”他笑了一笑，“我是生在这儿的。”

“那么这里怎样，好吗？”

“我觉得很好！”接着，好像在检查自己说的是不是真话，他回头向四周望望：他的眼睛发出了温暖的光芒，变得更加蓝了。“瞧那边就是我们的房子，”他用手指着，“有一棵槐树的地方。”

孩子们住在公共宿舍里。

“床头柜暂时还没有，”宿舍管理员解释说，“但是已经开单子去订了。还有盆花也去要过了，有了花要雅致些。”

安德烈选定了两个床铺——一个给自己，一个给维克多，并且挂上了照片。照片一共三张：一张是安德烈一家的“合家欢”，其中母亲抱着还在吃奶的娜塔莎；一张是少年先锋队在普晓河畔的露营；一张是安德烈念完企比略基七年制学校的毕业照。别的照片就没有了；事实上，这三张照片也已经足够说明安德烈的全部历史了。

然后他把那条绣有大红公鸡的手巾——母亲做给他出门用的——挂在照片上头的墙上，他觉得现在已经布置好了。维克多却没有带来任何照片。

整个晚上不断有人到宿舍里来，有认识的，也有不认识的。他们问孩子们已经安顿好了没有，还需要些什么东西。来了一个身材高大、体格魁伟的人，光着头，说起话来声音很低，很像首长的派头。

“矿长！”宿舍管理员低低地告诉孩子们，同时迎着来客跑去。不久，房子的每个角落，就都听见那位首长的低音了。

“床头柜，床头柜有什么要紧！你给我看烘干器吧。烘干器有吗？”

“烘干器作什么用呀？”安德烈低低地问一个面貌象巴辛柯的团员。

“烘干器吗？烘工作服、包脚布……”

“下雨天用吗？”

矿长和宿舍管理员听了，都笑起来。

“小朋友，矿井里永远在下雨啊！”宿舍管理员说。

“为什么说永远？”面貌象巴辛柯的那个团员着急了，“也有干燥的工作面的……总而言之，”他向那个宿舍管理员抛了一个愤怒的眼色，“奥尼辛叔叔，您最好还是别宣传下去了。这样只会使人家不安的……”

“什么，他们是小姐还是怎的！”矿长大声叫了起来，“要给他们洒些香水吗？我们应该马上把实际情形讲给他们听。你们是共青团员吗？”他对孩子们大声问道。

“共青团员。”一阵参差不齐的声音回答。

“你们为什么到这儿来，知道吗？”

“我们懂！”只有维克多一个人回答。

“好，那才对！”矿长声若洪钟地哈哈大笑。他是一个两颊红润的爱笑的人。

听到这些开玩笑的话，安德烈的心怦怦地跳了起来：这样说来，实在是苦得很的！

而维克多却喜欢矿长的话。

“那么我们什么时候爬到矿井里去呢？”他顽皮地嚷道，“为什么老带我们东走西玩，像是游览一样？真无聊呀！”

“老弟，矿井里不是爬下去的，”矿长回答说，“只有上娘儿们睡的火炕，才用得着爬。到矿井里去，朋友，是坐电梯下去的。”

“好，那么我们什么时候去呢？”维克多还喋喋不休地说。

“快了。瞧吧，胆子好大！”矿长笑了，突然将维克多一把拉到跟前，抱住了他，“嗨，如果你们个个都这样大胆，那么，老弟，事情就行了，行了！不成问题了！”

所有的客人都跟他一起离开宿舍。只有团员们留下来。大家都分散到自己的床铺上去了。安德烈从箱子里拿出一支小笛子，开始忧郁地吹着。

他心里很乱，很沉重。他自己也不知道是什么缘故。坏的事物他们还没有看到过。对他们的招待也很热烈殷勤。说不定，矿井也并不怎么可怕吧？不过心里总有些难过。笛子呜呜咽咽地奏着一支曲子：《哥萨克在土耳其人的奴役下哭泣》；安德烈根本没有想到自己在吹些什么。他想着家，想着矿井，想到他们来到那么远的地方，连信也不能马上收到。“矿井里永远在下雨啊！”他突然记起了这句话来。

维克多坐下来，亲热地抱住了朋友。

“你什么事伤心啊，哥萨克？”他快乐地问。

“唉，难过，维克多，心里难——过……”安德烈低低地坦白说，“烦恼。”

“真的吗？”维克多奇怪了，“为什么呀？”

“我怕……”

“喔唷，你真女人腔！”维克多笑了起来。“我怕——怕！”他学着安德烈的样子说，“你怎么，掉在树林子里了？落在狼群里了？我倒觉得这里很好，很开心。这里的人也都很好。”

淡黄头发的柯别略克人勃拉特青柯，手里拿着一束青草走进来。他刚才走到草原上，拔了一把青草回来，说：

“这里的草原很好，跟我们家乡的一样。只是面积小一点。周围都是矿井。而且草原还有烟的气味……”

他把青草撒在地板上，于是宿舍里马上就闻到了故乡的气味——百里香、薄荷和苦艾。

但因此却越发撩起了大家的乡愁……

“还是让我们来唱歌吧，朋友们！”有人提议说。说着那人自己先唱了起来。大家就接上去唱。于是歌声就在矿山的上空荡漾起来，就像荡漾在普晓河上，伏斯克拉河上，第聂伯河上一般……

在一片歌声中，进来了管宿舍的奥尼辛叔叔。他站在门旁，侧着耳朵听着。

“你们唱得真好！”最后他说，“你们是哪里人，库尔斯克吗？”

“不！”几个声音回答他，“各地方的人都有。”

“噢——噢！我还以为你们是库尔斯克人呢。以前凡是库尔斯克人和奥廖尔人都到顿巴斯来。”

“那么您，叔叔，下过矿井吗？”安德烈怯生生地问。

“谁——我吗？”宿舍管理员向他转过身去，“嘿，问这个！提这样的问题！我在矿井里有三十年了，我……”他气得话都说不出来了。

“那么为什么他们把您留在这儿呢？”

“不错，我也要问：为什么？全都是那个布金柯的主意。我们矿委的主席，不安分的家伙。他自己的计划搞不成功，却要我奥尼辛叔叔负责。第二年他跑来对我说：叔叔，我们必须提拔你，否则对你这样一个老矿工是说不过去的，但是……我说，我文化低，你能把我提到哪儿去呢？于是他就想出主意来了……”

“在井里怎样，要好些吗？”有人问。

“当然好些。太平些。在这儿，譬如说，一会儿屋顶漏了，一会儿又是那些该死的床头柜，一会儿把我奥尼辛叔叔叫到首长那儿，一会儿叫到检察长那儿，这儿，那儿……在井里要太平得多了。我是一个支架工！”他说这话时的神气非常骄傲，仿佛支架工等于将军，“不，孩子们，你们还是唱你们的歌吧！”

共青团员们又唱起来。奥尼辛叔叔在凳子上坐下来，倾听着。当一支歌唱完的时候，他什么话也不说，也不要求再唱一个，只干咳了几声，擦擦眼泪，又用双手托着白发苍苍的头，准备听下去。于是歌声倾泻出来，这些唱不完的如泣如诉的乌克兰民歌使人回肠荡气。这些歌曲具有神奇的力量，就连最感伤的几首，也不会使人难过，而会安慰人，仿佛歌声能带走他所有的烦恼，并且把它吹散在大地之上……

“是的，你们唱得真好！”奥尼辛叔叔最后说。他叹了一口气，擦擦眼泪，站了起来。“可是你们当不成矿工的，当不成的！”

这话实在太意外，弄得大家都哈哈大笑。

“为什么呢，奥尼辛叔叔？”维克多边笑边问。

“当不成的。不成！”老头儿摆了摆手。

“为什么？！”

“你们不是这样的料。就是如此！”

“什么？什么？”

“你们呀，我知道，都是娇生惯养的。妈妈的心肝！你们做不满三班就会开小差的……我知道你们！”

“我们不会的，不会的！”传出了几个气愤的声音。

“你们会的！”老头儿瞧不起人似的挥了挥手，“这种人我们看到过的！说什么计划没有完成，计划没有完成……但是为什么计划会没有完成呢？就是因为有了这种矿工，就是这个缘故。我们，”他突然拍拍自己的胸膛，“我们就是在1921年也没有不完成计划。我们吃野菜，但是没有不完成计划。我们照样工作，开出煤来。可是现在呢，我的天哪，顿巴斯弄得怎样了？哼，现在可变成进进出出的过道了！你们配当什么矿工？你们只要到矿井里去兜一圈，就会一溜烟跑了！”

他说得那么激昂，那么肯定，弄得大家都哑口无言，找不出话来回答。

只有那个从哈尔科夫来的叫斯维特里的长手臂家伙，本来一向皱着眉头不说话，这时走到宿舍管理员跟前，低低地、但却严厉地问道：

“老头儿，你干嘛要浇冷水，弄得大家心不定呢？”

“我不是浇冷水，”宿舍管理员对他挥挥手，“我心里难过。”

“你心里难过，更不应该浇冷水！”他威严地朝老头儿望了一眼，接着回头对大家说，“喂，朋友们！老头儿说我们会逃跑的。你们怎么说呢？”

“将来瞧吧！”有人叫道。

“这里有着各种不同的人，”奥尼辛叔叔说，“有自愿跑来的，也有被应征来的。被清算了的富农如今都涌到顿巴斯赚大钱来了……”

“他把我们比作被清算了的富农，”斯维特里沉着地继续说，“好吧，你们怎么说呢？”

“或者，应该打他耳光？”有人在远处说，“说不定他自己就是富农的走狗。”

“哼，老头儿，你要明白，我们是共青团员，”怒气冲冲的马里青柯窜了出来，“共青团员！”

“共青团员也有……”

“但你凭什么这样看待我们？”维克多忽然尖声地叫起来，几乎要捏紧拳头冲到宿舍管理员的跟前，“你是什么人？不，你说——你是什么人？”

现在大家都哇啦哇啦地闹开了，都从床铺上跳下来，向老头儿走拢去。但是斯维特里用一个威风凛凛的手势阻止了大家。孩子们马上觉得他是一个领导人物；后来他们知道他本是一个区委书记，是自愿到顿巴斯来的。当时他好像说过这样的话：“要进行鼓动，必须以身作则。”

他的年纪最大，身材也最高。他有着一双长长的手臂，宽大的前额，两条紧蹙的长眉毛和一对尖锐的凶眼睛，在这一分钟里，他的样子很可怕，虽然比大家都要镇静些。

“原来你就是这样迎接我们的！”他低低地对老头儿说，“哼，你只知道一个床头柜……”

“你就想一想吧，”宿舍管理员手足无措地嘟哝着，他也感觉到这个家伙的魄力，“我们当干部的看到这种一批来一批去的情形，非常气愤。被服刚给他们准备好，他们就带着走了！就拿你们种田的活儿来说吧——如果各种过路的，不论牛呀，马呀，羊呀，都任意在你的田里或者菜园里来来去去，你说好不好呢？……”

“也许，真的，”斯维特里突然转身对孩子们问，“也许，真的有人在打算跑吧？有吗？”他严厉地对大家望了望，在他那逼人的目光下大家都畏缩起来。

“说吧，谁？”他继续问，“有就走出来，老实说……还不晚……嗳？你吗？”他突然对着勃拉特青柯指了指，吓得勃拉特青柯倒退了一步。

“你不要胡说，不要胡说呀！”他恳求道。

“或者是你？”他指了指安德烈，“那么，是谁？你？你？你？”他的手指好像在刺透每一个人。“没有那样的人吗？如果有，我要砍去他的脑袋！……”他压低声音，狠狠地说，接着回头对宿舍管理员说：“瞧，老头儿，我们之中没有人会逃走的。”

“但愿如此！”奥尼辛叔叔摇摇头。

安德烈这夜老是睡不着。他老在自己那张狭窄的床铺上翻来覆去。今天这一天真把他吓坏了：所有这些谈话、暗示、调侃；以及这里的人全都担心他们会跑掉这一点；还有奥尼辛叔叔；还有附近那个可怕的——这一层现在他已经真正明白了——矿井的喘息；而尤其可怕的是斯维特里那只刺人的手指。

安德烈并不打算逃跑。他自己也知道，逃跑是可耻的，是不应该的。在那一分钟之前，他连逃跑的念头都不曾有过。此刻他也不会跑到任何地方去；因为在企比略基的会上，他曾经亲口说过：“不，我们同意！”

不过，既然斯维特里那么用手指威吓人，奥尼辛叔叔那么怀疑人，也决不会没有道理的。这样说来，矿井里真是很可怕吗？现在怎么办呢？

“我将做好应该做的一切，”安德烈对自己起着誓，“我将听大家的话。我要永远忍受，决不逃跑。但愿我有足够的勇气……”

同时他满怀希望地想到了维克多。只要维克多能帮忙，能支持他就好了！维克多是一个勇敢大胆、不顾死活的英雄！维克多是一个了不起的家伙！他有双倍的勇气！

“维克多！维克多！”他用耳语叫道。

可是维克多早就已经舒舒服服地睡着了。要是他梦见矿井的话，那么，矿井也一定是快乐的，玫瑰色的，阳光灿烂的。维克多甚至还在梦里微笑呢，他把眼睛眯得细细的，仿佛太阳光在顽皮地抚摸他的脸一般……

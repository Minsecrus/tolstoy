# 七

“原来矿井是打这儿开始的！”安德烈想。他在黑暗中爬着，什么也没看到，什么也不懂，整个身体弯曲得像一条软虫，一会儿膝头碰在突出的支柱上，一会儿脑袋撞在低垂的顶板上。而在他的前面和后面，别的几个孩子也都同样东碰西撞，气喘吁吁。安德烈不由得想：一条软虫经过它自己所开辟的、人类不容易发现的“行道”，爬进橡树的木质部，这情形大概就跟他们现在爬到岩层里去一样吧。但当时软虫有没有想到，它是在征服一棵树，它是自然的主宰？

“不会的，软虫什么也不想的！但人可不是虫。人什么都能！”“但我们却像蚯蚓一样爬着。”“算了吧！这是因为这儿还没有真正机械化。不过斯维特里会想办法的！”“但是怎样的机器可以爬到这儿来呢？这儿连人都觉得局促呢！”“各种机器全可以发明的。”“但是谁来发明呢？恐怕已经有人试过了。”“说不定就是我，就是我来发明！”他突然兴奋地自言自语说，并且因为自己有这样的念头而吃惊。

他甚至停下来，呆了一秒钟。嗳，如果发明这种机器的正是他安德烈，那该是多么光荣，多么好哇！只要他一发明，人家就会响应，就会仿造，而且斯维特里也会帮忙的……这个念头鼓舞了他；连爬路也变得轻松些了；仿佛孔隙也放大了，顶板也提高了，变得空旷了。

但接着马上有一条顽固的软虫在他脑子里作起祟来。

“你怎么发明得出呢？你又不是工程师！”那条虫怀疑地吱吱叫着。“有什么关系！工程师将来我也可以做的。”人反驳它。“但要做工程师必须学习许多东西，你怎么成！”虫戏谑他。“我会！我会！我会学习的！”

我会！——现在他疯狂地在黑暗中爬着。不，他不会从这儿逃跑的！他会留下来。他会懂得矿井里的一切。他是吓不倒的，不！

而将来他要去学习……他是一个人，不是一条虫。

这又是安德烈一生里伟大的一分钟，而他自己仍旧不觉得。他只是想：“今天我就要把心里所有的话，对维克多讲一讲。维克多的头脑可要比我的强。我们一块儿来订一个生活和学习的计划。”1930年时代的小伙子已经懂得没有计划是不行的。

而维克多却爬在前头很远的地方。他甚至不是在爬着，而是在浮着，好像一个经验丰富的游泳健将在一条还不熟悉的河流里游泳一样。他对什么都发生兴趣；顶板越低越妙；情势越危险越有趣。“要是到企比略基去讲给人家听，煤是怎样打这儿开出来的，他们准会大吃一惊！”他兴奋地想。对了，明天他就要亲自去采煤，他就要给大家颜色瞧！手镐一挥，就是一条大街，转一个弯，就是一条小路。他是一个身体强壮、手脚灵活的小伙子；此刻他也爬得比大家都好，而他在井里所感到的疲劳也比大家都少。他会显出颜色来的！

使他感到奇怪的只是，就在这儿，在采煤场子里，也没有人。

“这是怎么一回事，我们已经爬到采煤场子了吗？”他大声问。

“不，”组长在旁边的什么地方回答，“这是‘放煤眼’。现在就要到场子了。这儿来！”

维克多很快地爬到他的跟前，于是他们两人就摇起矿灯来，召集孩子们。最后全都喘吁吁地聚拢来了。

“这儿来！”组长马上发了口令，又爬到旁边的什么地方去了。不久从那儿传来了他那威风凛凛的老人的声音：“这就是采煤场子！”

他等着，直等到大家都爬到他跟前。

“都来了吗？”他庄严地问，“好，你们瞧吧，这就是我们的田地，我们矿工的自由天地……”他把矿灯举得高高的。维克多学他的样，接着大家也都照样做了。

于是孩子们就看到了煤。

矿灯的光散开来，在煤上颤动，在闪闪发亮的煤的表面上颤动，好像在水面上一样；而且整个煤层就像一条河流，一条闪闪发亮的黑色的河，在灯光下快乐地慢慢流动，然后突然急转直下，流到看看也很可怕的下面的什么地方去了。

“煤层很厚实，很好……”组长热情地说，接着抓了一把碎煤，兴致勃勃地用手指捏着，好像农民爱抚自己的泥土一般，“很肥的煤层。这叫‘码层’。就是说从底到顶有一码<sup class="footnote-ref" id="note-ref-28-1"><a href="#note-28" aria-label="查看本页注释 28">[28]</a></sup>厚……”

“人们也就在这一码之间工作！”安德烈想，同时朝下瞧了一眼。他看到了一排支持顶板的整整齐齐的圆柱子，每条柱子都是一码高！再下去一切都消失在黑暗中，灯光是射不到那儿的。右面的什么地方，有一把手镐在固执和调匀地啄着，砍着煤炭。“好像啄木鸟！”安德烈心里想。

瞧，这就是所谓采煤场子，所谓矿工的自由天地；一条长长的裂缝，那里采煤工在自己的台阶里弯着身子采煤，一排支持顶板的没有尽头的木柱，一条慢慢地向下流的煤河；而从下到上总共只有一码高。

“那么，从此以后我们也要在这儿工作了！”安德烈想，“不要紧，这儿也可以工作的。”现在，当遥远的梦想之光虽然还若隐若现，但却很有诱惑性地在他面前闪亮时，他已经觉得什么也不可怕了！

“好吧，孩子们！”组长说，“此刻我们要爬场子了。这儿的机械化是这样的：用屁股着地坐，用两脚向前爬。要勇敢地爬！不要怕！不要掉下去！两手抓住木柱，两脚踏牢下面的木头……懂吗？现在我要在每个台阶上把你们留下两个人。你们坐一会儿，瞧瞧矿工怎样工作，习惯习惯……等一会，回去时，我会把你们都召集拢来的……你们明白吗？”随后，他摇摇矿灯说：“好吧，老天保佑！走吧！”

他们就跟着往下滑，好像小时候不用雪橇，干脆用身体从冰山上滑下去一般……这实在可以说很有趣，但也有些惊心动魄：他们很快地往下冲，只用两手摸着木柱。维克多的鞋踏在不知谁的脖子上，那个人气愤地叫道：“喂，当心点，小鬼！”但接着又哈哈大笑，因为他自己也踏在另外一个同志的身上了。

“现在靠右，靠右边！”组长的声音从下面传上来。

孩子们就靠右边，朝有灯光的地方走去，他们来到了工作面。

挂在板皮上的矿灯，没精打采地照着工作面。在这儿工作的是一个年纪很轻的瘦长小伙子，头发鬈曲，颜色又像淡黄又像棕黄，因为在暗淡的灯光下看不清楚。他挖着煤，两脚像猴子一样灵活地牢牢踏在木柱上：看上去又像杂技团里的一个演员高悬在秋千架上。他的白背心满是煤屑和汗水。他工作的姿势很漂亮，这连那些新来的孩子们也看得出来；他那身体几乎像姑娘一般苗条柔软，一举一动灵活敏捷，如生龙活虎——肌肉一起一伏地跳动！

“足球健将！”组长看到了这样漂亮的工作姿势，笑眯眯地说，“米佳，了不起！老天帮助你！”

“谢谢，阿芳纳西叔叔！”米佳回答，并不停止工作，“我没有上帝也行。但是没有空车可怎么也不成……”

“什么，没有空车吗？”

“现在才来……但我可等了一早晨了，有什么办法！”

“是——呀……成问题！”组长同情地叹了一口气，“不过，米佳，我可给你把客人们带来了。也是你们的弟兄，共青团员……”

米佳好奇地瞧瞧孩子们，停止了工作。

“嗳，同志们，你们好！”他像一个好客的主人似的说，“欢迎！你们觉得这儿怎样？”

“我留两个人给你，”组长说，“你指点指点他们。喂，谁愿意？”

勃拉特青柯自愿留下，他已经筋疲力尽了，显出一副可怜相。马里青柯跟他一起留了下来。

“米佳，你等我们爬过去之后再挖，”组长请求道，“我到了下面再叫你。好，走吧。”

于是孩子们重又向下爬去，爬到下面一个台阶里去。

安德烈和维克多留在第三个台阶里——差不多在场子的尽头（从下到上算起）。在这里工作的是一个刚上年纪的采煤工，他的脸松软得像一个女人，脸上稀稀落落地长着几根髭须。他坐的姿势很呆笨，不灵活，不像一般矿工的坐法，他分开两脚，喘吁吁地用手镐削着顶上的煤块。起初他对孩子们完全不理不睬。

直到组长走时请求他——也像请求米佳那样——在他们爬过时不要挖，他才打着呵欠，把手镐放在一边，出人意料地用很尖的、简直和他那样肥胖的男人不相称的鼻音问道：

“孩子们，你们是打哪儿来的？啊？”

“我们是共青团员哪，”维克多得意洋洋地回答。他已经有成千个问题要问采煤工了，他真想马上让他也来挖一两下。

“那么你们为什么不安安静静地坐在家里呢？”采煤工懒洋洋地问。“什么，家里不好，还是怎的？”

“不，为什么？”维克多摸不着头脑地反问。

“那么你们的庄稼好吗？牛有没有？”

“我们不是乡下人。我们是城里来的。”

“真的吗？”他用没有神气的目光对他们瞧了又瞧，“但是干吗要从城里来呢？”

“我们是共青团员……”

“噢——噢！”他用鼻音说，“有这种情形的。”他又打了一个呵欠。接着他伸了个懒腰，哼了一声，就仰天躺下了。

维克多马上失去向他提问题的兴趣。孩子们无聊地看着采煤工：他也像所有的矿工一样穿着工作服，只是头上戴着一顶很旧的圆形厚羔皮帽——这种帽子是鞑靼人戴的。

“喂，斯维利多夫，行了！”组长在下面叫道。

但斯维利多夫却一动也不动。他仍旧躺着，眼睛一眨也不眨，呆呆地望着顶板——好像草原上的牧人，躺在阳光里望天空。突然他低声地笑了起来。孩子们惊奇地朝他望望：他那张臃肿的女人式的脸颤动得好像一块冻肉，而且立刻就要溶解似的……

“世界上真会有这种怪物，”他冷笑着说，“上这儿来挣大钱。嗳，怪物，真是怪物！”他简直笑得哽住了。

“原来他眼睛望着顶板在想这些个！”安德烈想，冷笑了一声。

“瞧，这就是大钱……”斯维利多夫用一只手指戳戳煤层，尖声地叫道，“它是大的，可你来拿拿它看，嗨，怪物！”他突然停止了笑，拿起手镐。“你们是什么人？”他问，“共青团员吗？好极了！”他严厉地用手镐威胁他们，接着朝煤层挖去。

孩子们开始默默地注视他工作。斯维利多夫挖起煤来不像米佳；他工作的姿势既不灵活，也不美观；他哼呼哼呼地喘着气，非常吃力地挖着，不时在手里吐一口唾沫，同时斜眼瞟着孩子们。然而，在他的地方，煤不像在米佳的地方那样大块大块地落下来，而是零零碎碎地滑下来，像液体那样地流着。

突然他停住了，倾听什么声音。

“嘘！”他用耳语说，“听到没有？”他脸上现出一副惊慌的神气。“听到没有？”他一面问，一面用一种奇怪的眼光斜瞅着孩子们。

“没——有……”孩子们犹豫不决地拖长声音回答。

“你们用耳朵听吧！格勒勒地响着是吗？”

他们侧着耳朵细听：真的，周围有一种低低的干裂的声音。

“这是场子在开玩笑……”斯维利多夫说，重又从旁边斜瞅着孩子们。“喔唷，倒霉，孩子们！倒霉！”

“什么？”维克多用耳语问，“会塌下来吗？”

“完全可能。”他重又侧着耳朵听。“这儿在裂开来！”他用手镐戳戳孩子们头上的顶板。那儿立刻有些东西掉下来。

“已经在掉下来了！”斯维利多夫说，“孩子们，我们必须抢救场子！”

“怎么抢救呢？”维克多喃喃地说。

“你是什么人？”斯维利多夫严厉地问，“共青团员吗？很好！”他重又倾听着，然后说：“孩子们，现在我跑去找支架工去，你们来撑住顶板。”

“怎么撑法？”

“这样！”斯维利多夫扑倒在地上，两手托牢木柱，用脊背撑着顶板，“这样会吗？”

“我们来试试……”安德烈没有把握地说。

“那么你们不害怕吗？”

“我们什么也不怕！”维克多夸口说。他突然觉得很有趣。“叔叔，您去吧，”他忙碌起来了，“您用不着替我们担心，这些事我们应付得了的！”于是他就断然地用脊背撑住了顶板。

“瞧吧，真是好汉，英雄！真是好汉！……”他看到他们两人已经趴在地上，撑住悬岩。“我马上就……马上就去。不，真了不起！这件事一定会登报的！”于是他匆匆忙忙地往下爬去了。

留下了安德烈和维克多两个人。他们沉默了一会儿。他们把脊背朝那又冷又滑的悬岩贴得更紧一些。然后维克多喃喃地说：

“听到吗？”

“听到……”安德烈也用耳语回答。

他们觉得破裂的程度更加厉害了。现在，当他们屏住呼吸，在肃静中侧耳倾听时，他们听到各种最轻微的沙沙声和矿井的叹息。场子已经不是在独奏，而是在合唱了。

奇怪得很，这两个孩子竟一点不觉得恐怖。现在，当他们跟真正的危险面面相对时，他们什么也不怕。他们一动不动地保持着笨拙和难看的姿势，甚至于没有想到自己。斯维利多夫赶得上吗？场子抢救得了吗？

如果说维克多的脑子里还模模糊糊地想到他们行为的英勇壮烈——“整个矿井都会知道……说不定报纸上还会登载……要是压死了，那么一定会用乐队来给他们送葬，就像给英雄们送葬那样……”那么安德烈就完全没有想到这一类事。他伏在地上，几天来头一次感到自己是一个人：他不害怕，他很镇定，他作着矿井所需要的事，他感到满足。

只是脊背已经在作痛，两脚也麻了……

“他怎么去了这么久！”维克多说。他不耐烦地、粗心地挪动了一下脊背，马上就有一块干泥从顶上落下来。

“小心点，你！”安德烈低声喝道，维克多又一动不动了。

时间过得像没有底，使人觉得难受。斯维利多夫没有把他们忘记吗？会不会他自己得了救，把场子忘记了呢……

突然他们听得下面有嘈杂的声音。他们侧着耳朵细听：有人在爬着。已经听得见人声了；在黑暗的什么地方亮着一点灯光……又是一点……越来越近了……

斯维利多夫第一个在工作面上出现了。他用自己那盏矿灯的光照亮了孩子们，欢天喜地地叫了起来：

“撑住了！”

人们从各处爬了拢来……

“撑住了！”斯维利多夫又叫了起来，接着克制了好久的大笑突然像号哭一样从他的胸中迸发出来。“撑住了！嗳，无常鬼，嗳，矿工——屁股撑住了顶板！”

回答他的是一阵疯狂的哄笑。这许多强壮的喉咙里发出来的哄笑，弄得整个场子像是震动和摇晃起来了；而我们这两个孩子那么小心翼翼地保护着的顶板，好像也要塌下来了……孩子们不由得向后退缩，躲避这一阵像倾盆大雨一样猛烈的笑声。他们已经猜到，他们是被愚弄了。

然而哈哈笑着的人们却越来越近了，人人都想亲眼瞧瞧场子里的英雄，这两个英雄……哈—哈—哈！——用屁股撑住了顶板。像狼眼一样黄澄澄的矿灯，四面八方朝这两个孩子围拢来，好像有一群狼在向他们袭击。脸看不出来——只见张开着哈哈大笑的口，仿佛狼的嘴巴……他们害怕起来了……

突然不知谁的响亮有力的声音，盖住了笑声和喧闹：

“喂，停止！我对你们说，停止！”他气愤愤地叫道，“你们这些混蛋，没良心！你们在笑谁，你们是狗养的吗？！”

“你这算什么，列斯尼亚克叔叔！”斯维利多夫笑得身子还在哆嗦，尖声地叫道，“这是给新人行个洗礼，神圣的洗礼，神圣的洗礼池……”

“噢，原来是你，斯维利多夫，是你干的好事吗？”列斯尼亚克叔叔就向他进攻，“你自己来了有多久？瞧，富农的坏种，真是天知道打哪儿弄来你们这批宝货，你当心我吧！”

“你这是怎么了，列斯尼亚克叔叔，怎么了，老天保佑你！”斯维利多夫开始恐惧地嘟哝起来了。

“这儿给你吃面包，你……你给我闭嘴！你给我爬进洞里去，免得大家听到你的声音。你做得好事！……嗨，当心点！”他拿矿灯威吓他。“你们也真好！”他对所有的人说。“你们开心。洛古诺夫，连你也在这儿吗？啊—呀—呀，还算是一个明事理的人呢……”

“你等一等，等一等，这算得上什么！……”发出了几个人尴尬的声音。“这只是开开玩笑，好玩得很……”

“开开玩笑？！”列斯尼亚克模仿着说，“你瞧瞧他们，瞧瞧这两个新人……你们对他们开什么玩笑？”他突然爬到孩子们跟前；他们看到一个留有胡须的、样子很凶的矿工：他沉重地在他们旁边蹲了下来，接着用矿灯照照他们。“还是小孩子呢！”他用和他的面貌不相称的温柔语气说，“是共青团员吗？”

孩子们默默地点点头作为回答。

“嗳，不要紧，不要紧，孩子们！”他和蔼可亲地说，接着朝大家掉过头来，“瞧你们侮辱了谁！共青团员！啊？说得过去吗？”

大家都尴尬地一声不响。

“瞧！”列斯尼亚克威严地说，“今后谁也不许碰他们一碰，谁也不许！要不然哪！”他气得胡须都翘了起来，“是的，你们认得我的！”他冷笑一声，重又回头对孩子们说：“要是再有人敢欺侮你们，你们来告诉我。我们这儿不用名片，你们只要记住，我叫列斯尼亚克。这儿人人都知道。普通的姓，矿工的姓……”他笑了起来。“现在，来吧，我带你们到平巷里去……你们在这儿没有什么事了！喂，大家让一让！”

大家赶紧给他让出一条路来，他就沿着场子灵活地往下爬去，这种灵活的程度，对于像他那样又高又胖的人说来，是惊人的；两个孩子跟在他的后面。

他把两人留在平巷里。

“我还有半工活要干，”他解释说，“你们在这凉快的地方坐一坐。我去告诉组长……”他拍拍维克多的肩膀，不好意思地补充说：“你们不要生我们这些人的气，人——不错，都是很好的。这件事完全该怪斯维利多夫一个人。他认识不够……在掌子里觉得寂寞，孤独……”

他走了，他们却连“谢谢”也没有对他说一声。自从斯维利多夫回来之后，他们还没有说过一句话。矿工们的哈哈笑声，还在他们的耳朵里回荡……

他们此刻无心安坐在“凉快的地方”，他们不约而同地、一声不响地沿着平巷随意走去，踏着积水……他们默默地走了好一阵，各人想着自己的心事，不过两人所想的，却是同一件事。

“现在大家都要嘲笑我们了！”最后维克多痛苦地喃喃说，“现在他们要长久地嘲笑我们了。”

安德烈只好去安慰他。

“谁也不会嘲笑的，维克多，你这算什么话！列斯尼亚克叔叔不会答应他们的，你瞧着吧！”他抱住朋友的肩膀，开始热情地嘟哝着：“这个斯维利多夫呀，他是一个富农，你自己也听到的。我们还要给他颜色瞧呢，哼！”

他们背后的远处，早就有一种轰隆隆的声音在不断地响起来，这响声越来越近，越来越近，但他们却没有听到。直到一个粗野的、尖锐刺耳的声音已经很近了，他们才掉过头去，同时看到有一批“货”朝他们送来。马的嘶声和赶车工的呼喝声已经听到了。

那时他们在轨道间东奔西窜，不知道该怎么办，该上哪儿去藏身……突然他们沿着平巷跑去，尽所有的力量跑去。

“快些，维克多，快些！”安德烈催促着。但是他们已经被一阵像鞭子的唿哨声一样尖锐的赶车工的口哨声赶上了，直到那时他们才想到，只要跳出轨道，把身体紧贴在木柱上就行了。他们就这么做了，接着那批“货”隆隆地在他们的身边运过。留着额发的赶车工，看到两个吓得脸无人色的孩子蜷缩在墙边，禁不住哈哈大笑。

他的笑声在矿井的圆顶下响了好一阵，最后静止了……于是孩子们听到身边又有一阵笑声——轻微的、清脆的、兴致勃勃的，但因此也就更加使人生气。

他们掉过头去——笑着的是一个姑娘。他们马上就看到了她。她是不能不被人家看见的：她周身都在发光。她身上有七八盏矿灯：有些挂在腰带上，有些提在手里，有一盏悬在背上。

姑娘在取笑这两个孩子：她看到他们刚才逃命时的那副样子……

“嗳，活像兔子，斜眼兔子！”她快乐地叫道。孩子们沉着脸向她走去。

“你笑什么？”维克多老大不高兴地问。

但姑娘只是笑得更加厉害些。她身上的矿灯振动得像响铃一般……

“是不是要给你吃一记耳光，你才会停止呢？”安德烈说，接着两个朋友都抓住了她的手臂。

她既不挣扎，也不求救或尖声叫喊。她只是用两只好奇的眼睛望着孩子们：难道他们真的敢打不成？那么，又将怎样呢？

维克多把她轻轻一推。

“犯不着跟她搞，傻瓜！下次当心点！”

她笑了起来。

“兔子，斜眼兔子！”她唱道。但是他们俩已经走远了。奇怪得很，虽然他们俩并没有出过一口气，也不曾真正打那个丫头——因为所有嘲笑他们的人而打她一个，但是他们却觉得轻松些了。这一天会过去的，会被忘记的；他们还要长久地生活下去的！好吧，就让人们笑去吧，他们至少在斯维利多夫走开的时候，并没因为只有他俩留在场子里而感到害怕！

现在他们知道了：在矿井里也像在日常生活中那样，也有困难，也有欢乐，也有好人，也有坏人……

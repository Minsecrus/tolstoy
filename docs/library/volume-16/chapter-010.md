# 八

那天夜里勃拉特青柯从矿里逃走了。这是直到第二天早晨大家都醒来之后才知道的。勃拉特青柯的床铺没有皱纹，枕头上放着共青团团证。没有信，也没有条子——只有枕头上的团证。但这样，事情也已经明明白白了。

共青团员聚集在他床铺的周围。他们一声不响地站着，仿佛这张床上躺着一个死人。

“这是头一个！”安德烈心慌意乱地想。

斯维特里从枕头上拿起团证，慢慢地大声念着：“勃拉特青柯·葛利哥里·安东诺维奇。”

“我们会记住的！”他严厉地说。“勃拉特青柯·葛利哥里·安东诺维奇，”突然他用力地把团证扔在床上，“你混蛋，勃拉特青柯·葛利哥里·安东诺维奇！”

“他怀念好空气。”马里青柯不好意思地说，这几天他跟勃拉特青柯很要好；他们的床铺就在一并排。“他老是抱怨这儿的空气。他是在新鲜空气里长大的，他生在草原上。可是这儿矿井里……”

“什么，难道我们本来是住在山洞里的吗？”斯维特里恶狠狠地打断了他的话。“老实说，我们也喜欢新鲜空气。但是我们不跑。不，看来，这张团证他弄到很容易，因此抛弃也很容易。全是胡说！好，没关系，”他恶声地说，“现在他不论到什么地方都呼吸不到新鲜空气了！对于他，现在到处都是有毒的空气。犹大<sup class="footnote-ref" id="note-ref-29-1"><a href="#note-29" aria-label="查看本页注释 29">[29]</a></sup>！”

“必须报告他的组织。”从哈尔科夫来的小伙子格列勃提议说。

“必须在报纸上发表，就该这么办！”维克多叫道，“让大家都知道！”

孩子们喧嚷起来：

“必须一方面登报，一方面报告团中央。”

“写信给他的母亲说：婶婶，瞧你的儿子是一个怎样的坏蛋，好吗？”

“这又关做母亲的什么事？”

“叫她教育得好些！不要养出坏蛋来！”

“他胆小，说不定还会回来的。”传出了不知谁的没有信心的声音。

“回来。你等着吧！”维克多哈哈地笑了起来，“这种人是不会回来的！”

斯维特里一声不响。他依照习惯还在倾听“群众的声音”——声音很激昂，很真诚！——同时心里作着考虑。他无法了解勃拉特青柯的行为：通常人们是不会抛弃团证的。他也无法了解他怎么会从矿上逃跑：通常人们是不会从岗位上逃跑的。而且逃到哪儿去呢？难道一个人逃得开自己，逃得开自己的良心吗？

但他不禁想到，此刻他自己本可以不在这儿，而在哈尔科夫。在哈尔科夫很开心。他正巧是在开团的全体大会之前走的。据说要他做市委第二书记……许多人知道他自动要求到煤矿区去，都感到很惊奇。

不过，谁也没有留他，谁也不敢留他：他是响应动员而走的。这是一件神圣的事。

难道这只是一窝蜂，只是一时感情冲动吗？大会确实很热烈……他自己的情绪当然也很高。此刻他在勃拉特青柯的床铺边检查自己。

他突然记起了哈尔科夫的所有委员们来。有些是从工厂到市委里来的，有些直接从学校里出来的；这些从学校里出来的，他总是叫他们“中学生”。中学生们不知怎的成熟得极快，他们一下子就变得又严肃，又老练。他想象他们也在这儿，在公共宿舍里，在矿井上——他笑了起来。不，他做得对，做得正确。不能老是鼓动人家，派遣人家。必须自己先去体验一下生活，以后……但是以后他将怎样，他连自己也不知道。其实考虑这一层也还早呢！

他发现人们静下来了，眼睛望着他：他们在等待他的决定。他们没有经过开会投票的手续，就选他当他们的领导人了。他不免生气。为什么要给他这样的一个负担呢？他不是到这儿来当委员的，他是到掌子里来工作的。啊，你们还是放了我吧！这里原来也有委员的。

但他自己知道，他一定要有一份责任，一定要过问一切。他不能不过问，他生成就是这样的性格！不过，事实上，他到了这儿，难道是预备躲起来的吗？他是来战斗的。他必须弄明白，为什么他们这儿的计划不能实现，为什么人们会从这儿逃走……

他说：“可以报告中央，也可以在报上发表！”他停了一停，然后用自己犀利的眼睛对大家扫视一过，补充说：“但主要的是要每个人记住。牢牢地记住！好，现在谁是下一个？”他早已发现安德烈一声不响，就直指着他的脸说：“现在该轮到你了吧，安德烈？”

“我不跑……”安德烈老大不高兴地回答。

“谁知道你！”斯维特里冷笑了一声，但接着突然变得很和气了。“嗳，朋友们！”他温柔地说，“归根结底，我们大家必须相亲相爱……”

情绪激动的矿委书记斯特鲁日尼科夫走了进来。他已经知道了所发生的事。

“朋友们，你们怎么会不看好他？”他在门槛上就嚷道。

“知人知面不知心！”马里青柯惶恐地喃喃说。

“这么说来，你们并没有真正共青团员的友谊！”书记说，“你们互相不了解……”

“我们连一个正式的组织也还没有……”斯维特里回答说。

“真的！”维克多叫道，“我们在过无党籍的生活。”

“组织，矿井里是有的，”书记生气地说，“你们何必要保持特殊呢？你们必须快快跟我们的人并起来。我们对你们的希望很大。”他望望斯维特里。

“我们得赶快工作！”维克多大声说，“干吗老带我们参观这个，参观那个？人会闷得跑的……”

“对啊！”斯维特里也支持他，“我们的时间也浪费得够了……”

“今天会有人来给你们分配工作的，”斯特鲁日尼科夫答应说，“明天就可以下井了！”

“我只要当采煤工！”维克多急躁地嚷道，“别的都不干。”

大家都围着书记你一句我一句地讲了起来，把勃拉特青柯的事也给忘了。他的团证依旧孤零零地留在枕头上。

斯特鲁日尼科夫走的时候才把它带了去……

维克多要求当采煤工，因为他听说这是矿井里最光荣的工作。他的要求受到了尊敬，他是一个强壮魁梧的小伙子。安德烈不愿落在朋友的后头，也要求当采煤工。矿里的负责同志答应明天送他们下井，去跟老手学习。

“你们稍微学一学手镐的用法，那边就会有计划给你们的。”

“要学很多时间吗？”安德烈问。

“学程本来是很长的，但是现在费时太长可不行。计划不能实现！”人家回答他说，“采煤工不够。不，你们不能学很久。”

“我们也用不到学很久。”维克多笑着说。

第二天他们就去上班。维克多当米佳的学生，他就是他们第一次下井时看到的那个鬈发的家伙。在光亮的地方，他的头发的确是棕黄色的。

“喂，米佳，给你一个学生！”采煤区长把维克多介绍给米佳说，接着笑了一笑。“你瞧，也是像你那样的一个演员。你们好好干吧！”采煤区长自认为是一个心理学家。

安德烈被带给一个刚上年纪的、沉默寡言的采煤工，他的名字叫安基波夫。

“这是你的学生，安基波夫！”采煤区长说。

“嗳，好吧……没关系……可以……”安基波夫心平气和地、慢吞吞地说。

“那么，你就教教他，怎样拿手镐，怎样整理镐齿，怎样挖煤……”

“行……当然……可以……好吧！……”于是安基波夫就一声不响地走出交接班室，安德烈跟在他的后面。

他们就这么一声不响地走到了工作面。

安基波夫按照习惯熟练地开始在工作面里布置起来，准备工作：挂起矿灯，放好装有镐齿的袋子，检查一下木柱的位置。

然后他坐下来，瞧瞧学生，搔搔后脑勺。应该拿这个对象怎么办呢，他可不知道。

“那么……嗳……”他犹豫不决地说，“这是煤……这是手镐……这是镐齿……”

“我明白。”安德烈喃喃地说。

“是——呀……当然……把戏不难……好吧！……你还有什么不知道？……啊？”他用询问的眼光对他望了望。

“我不知道……”安德烈尴尬地回答。

“是——呀……就是这样的……我得工作了……你瞧，真成问题！……”

“您工作吧！我瞧瞧。”

“对啊！”安基波夫高兴了，“那么你瞧吧！我呀……说话不行……不很行……我就用手镐……做给你瞧吧……”

于是他就开始挖煤，安德烈瞧着。

吃午饭时他碰到了维克多。维克多有些不开心。

“这算什么！”他气呼呼地说，“叫我去拜一个小孩子当师傅。他只是装腔作势，卖弄本领，毫无意思。”

原来他和米佳早已吵过嘴了。两个都是躁性子。“演员”开口就吹牛，维克多马上不客气地批评他。

“就这么吵了整整一班！”维克多闷闷不乐地结束自己的话，“嗳，那么你那一个怎样？”

“我的——不错！”安德烈叹了一口气。后来想到安基波夫怎样工作，就又补充说：“是的，我们很好！”

他真的很快就爱上了自己的师傅。安基波夫是个好人，虽然不爱说话。他向安德烈解释，他实在一点也不会，但工作做得很好，很卖力。

安德烈瞧着他，已经学会了很多东西，首先是工作面的秩序。

“这就是家……我的家……我是住在这儿的……”安基波夫用他那种特殊的腔调，期期地解释。“那边，”他指指地面上，“那边是房子……那边我睡觉……光是睡觉！”

他连自己轻易不肯告人的秘密也告诉了安德烈——怎样磨快镐齿。在这种场合，他简直兴奋极了，可见他不但熟悉工作，而且爱好工作。

安德烈瞧着他，学会了搭支架的方法。现在他常常为安基波夫搭支架，他搭的支架，安基波夫检查过两次，以后就不再检查了。

但是应该怎样挖煤呢——这一点，他没有本领给安德烈解释。

“挖……你瞧……就是这样挖……这样……”

然而煤却不听安德烈的话。他竭尽所有的力气挖，嘴里嗨荷嗨荷地哼着，用手镐全力刨煤，好像用斧头劈树一样，可是毫无结果：只敲下一些碎煤，像不乐意似的慢慢滚下来。

安德烈仔细看着师傅，他想识破师傅的窍门究竟在哪儿，但是识不破。安基波夫不慌不忙地挖着，看来只用一半力气，但是煤却在手镐下像一条快乐平静的溪水不断地流着，有时突然还有一大块煤落下来，隆隆地向下滚去。

有一次，安德烈觉得他的事情成功了。他兴致勃勃，精神奋发——煤滚下来了！他得意忘形地挖着，挖得满身是汗，突然他听到耳边有一个尖锐而粗暴的声音：

“停！”

他抬头一看。列斯尼亚克叔叔站在他的面前。

“停！”他厌恶地命令说，“何必白白地敲钝镐头！”安德烈手足无措地放下了手镐。

“现在你来这儿瞧！”列斯尼亚克用命令的语气说，同时把自己的矿灯拿近煤层（矿工们称为“面壁”）。“有吗？你瞧这儿是什么？”

“煤……”安德烈没有把握地喃喃说。

“煤！”老师傅冷笑了一声，“但是煤里有什么呢？来，你仔细瞧瞧！”

安德烈睁大了眼睛瞧：他看到煤层里有一条一条的细小的纹理、筋脉和裂痕，好像一个聪明而健康的老人的额纹一样。

“有吗？看到什么啦？”

“看到些纹理……裂痕……”

“现在你瞧这些裂痕的走势是怎样的。怎么样？看到吗？”

安德烈看到，所有的裂痕都朝一个方向；它们仿佛汇合在一起，形成一道细微而依稀可辨的溪流。

“这是流线，”列斯尼亚克解释道，“科学家叫它劈裂性。你应该循着劈裂性用手镐啄。不然瞎敲一阵有什么用！你用心拿手镐挖，煤就会听话地滚下来。你为什么没有把这一层解释给他听呢？”他责备安基波夫说。

“那个吗……当然……我好像说过……是吗？我又不是……教授！”安基波夫摆了摆手。

“在这件事上咱们是教授，不会有别人。”老师傅骄傲地说，接着朝安德烈回过头去。“你就这么工作吧，孩子！我会再来看你的。”

“当然……”安基波夫等列斯尼亚克走了，不好意思地喃喃说，“他是一个聪明人……党员……不像我们……而且是教授！……这还用说……这是……”

安德烈现在试着循劈裂性砍。开头不成功——流线老是要逃走，看不出来。他像追蜥蜴一样追它，想用手镐挟住它的尾巴；它偏要躲躲闪闪，耍滑头，不肯就范。后来他慢慢地学会看住它，不失掉它，挖起来就容易得多了。他很高兴。维克多可听到他在那么勇敢地挖煤吗？

维克多也在这儿，在场子里，高两个台阶的地方。但是他们只有在下工之后才碰得到。

维克多的情形可糟了。根据他的要求给他换了一个师傅——一个严肃而精明的矿工。但是维克多跟他也搞不好。他不耐烦听解释，甚至动辄生气，而他自己拿起手镐来干，又毫无结果。

“你循着劈裂性试试看！”安德烈劝他说，“循着劈裂性要容易些！”

然而问题并不在于劈裂性，而在于维克多的性格。他的性格就是那样的！只有他所爱好的事情，他才能做得很好；而他所爱好的，只是他很容易应付的工作。

在学校里是这样，小时候也是这样。他学会游泳不知怎的是无心的，自然而然的，好像他本来就是在河里出生的一样，他游得非常出色，别的孩子们都不及他。他天天在河上过日子，举行集体比赛和个别比赛；他总是胜过所有的孩子，感到幸福和骄傲。可是滑雪，他一下子学不会。他两次当众出丑，就马上把滑雪板抛弃了。

他习惯和爱好处处带头，如果不带头，那么就索性不干。

要是煤一下子能听他的话，要是头几天维克多就成为最优秀的新手而名闻全矿，他就会爱好矿井，也会爱好采煤工的工作。这样，矿井里也就不会有比他更卖力、更热心的人了。他会移山倒海！

但是煤不肯听话，于是矿井就马上使维克多觉得讨厌。现在他到掌子里去，就像去上“老虎凳”一样：师傅又要怒气冲冲地申斥他，组长又要冷言冷语地嘲笑他，那个新当选的采煤区共青团小组长斯维特里又要斜着眼睛瞧他；听说斯维特里在掌子里工作得很好。

维克多本来应该马上提出要求，把他解除采煤工的工作，调去当赶车工；他天生就有一副配作赶车工的大胆性格；整个矿井里不会有一个比他更不顾死活的赶车工。可是他自己没有想到，也没有人给他作过这样的劝告。而且事实上也很可耻：要知道当采煤工原是他自己要求的呀。

这样，他就垂头丧气地在掌子里做苦工。

他消沉了，发起愁来。晚上他一声不响地在床上翻来覆去。原来的那个大胆豪放的维克多，现在可影踪全无了。他的样子现在是又冷酷，又可怜。

“唉，安德烈，我们真倒霉！”他向朋友诉苦，“没想到！我们本来应该到新的建筑工地去，到马格尼特草原上去！那边我们可以干得多出色啊！”

“其实到处都一样，开头总是困难的……”安德烈怯生生地反驳。

“难道我害怕困难不成？你怎么，连我都不了解吗？老兄，我并不害怕劳动。不过那边的劳动漂亮，而这儿呀！”他轻蔑地摆了摆手。他完全忘记十天之前他还说过不同的话。他忘记得很快。

“我父亲说过，一切劳动都是漂亮的。”安德烈喃喃地说。

“但是他到过矿井吗，你的父亲？”维克多反驳道。“你瞧！但是咱们到过。咱们尝过这个滋味。今天我的那一个教我怎样‘钻狗洞’。‘钻狗洞’，”他痛苦地噘噘嘴，“字眼多难听！好像我们都是狗……我们也就得在这儿过一辈子——在狗洞里……”

安德烈不知道该怎样帮助朋友。他自己也很难过，不过他已经看到了前面的一线光明。现在只要抓住劈裂性就行了！他感激地记起了列斯尼亚克叔叔来。

“你最好去向列斯尼亚克叔叔请教。”他用试探的态度继续说。

“我为什么要去向他请教！”维克多耸耸肩膀，“我又不是病人，他也不是医生……”

“他是教授！老兄，他什么都懂，而且又是党员。让我们上他家里去吧。去作客。”

“去作客！”维克多冷笑了一声，“他请过你吗？”

“请过的。他亲自请的。”

“什么时候？”

“今天。他已经是第二次请我们了……”

维克多怀疑地望着朋友，是不是说谎？不过邀请使他很得意。如果采煤好手列斯尼亚克叔叔亲自叫他去作客，那就说明他还不是煤矿里最蹩脚的人物。

但是他却漫不经心地回答，仿佛不很情愿似的：

“好吧！放假天去一次也行……”

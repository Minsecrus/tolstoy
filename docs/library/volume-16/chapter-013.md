# 十一

一天早晨，玻璃窗上发出一种古怪的琅琅琅声——不，是嗡嗡嗡声——把维克多吵醒了。他一醒，就跳起来，侧耳细听。玻璃嗡嗡嗡地响着，好像有成千只振翅的蜜蜂在撞窗子，要飞进房子里来……

“噢——噢！”维克多烦恼地想，“汽笛已经响了！”他忽然觉得今天怎么也无法勉强自己起床和下井去了。他实在不愿意！

他把头放回枕头上——枕头是舒服的，可爱的——但没有闭上眼睛。他的床对面仍旧挂着那张标语：“矿工，拿煤来！”维克多一不小心转过头去，这几个字总是马上就射入他的眼睛。此刻，他很讨厌这几个字，尤其是后面的三个：拿煤来！

“我可不愿意！”维克多说，接着把被头拉到耳朵之上，吱吱咯咯地朝左边翻过身去。

玻璃窗继续振动着，而且琅琅琅地响着。只有一个迷迷糊糊、似醒未醒的人，才会觉得它们像蜜蜂的嗡嗡声。事实上，它们只是被几只汽笛的不平常的共鸣所震动，不过以前声音从来没有像今天早晨那么和谐一致。通常汽笛总是单独鸣响的，每只相隔有五分、十分，甚至十五分钟。然而，今天它们却突然一下子同声怒吼起来，仿佛有意要吵醒维克多。

他把头埋在枕头里。我不要！我不要起来！

但是，安德烈已经向他俯下身去了。

“嗳，起来，维克多，起来！起来，老弟！时候到了！”他一边叫，一边小心地但却固执地推着好朋友，他以为维克多还在睡觉呢，“起来！你听——汽笛……”

维克多不得不撑起身来。

“它们今天发什么疯呀？”他不高兴地咕噜着，还没有决定怎么办——假装生病呢，还是干脆大胆地说：我不愿再去了！“嘿，他妈的，这么吵闹！”他缩紧了身体，仍旧不起来。

“我想这只是大家在节日之前根据无线电对准了钟，所以汽笛都一下子同时响起来！”安德烈解释道。“你起来吧，维克多，起来吧！”他用恳求的语气补充说，“嗳，你这算什么呀！嗳，不可以的呀！”

“不错，不错，明天是节日，十一月七号，”维克多想了起来，“我怎么会没有想到这点呢？那么，只好起来。毫无办法。”

他不乐意地推开被头，开始穿衣服。安德烈催他：

“快点，维克多，快点！”

维克多萎靡不振地服从着。他已经没有自己的意志了，服服帖帖地跟着安德烈到盥洗室、烘衣室、食堂……

大家像平日一样，成群结队地跟着斯维特里走出食堂，又成群结队地下井去。开头几天，维克多很喜欢观察和亲自参加这个清早上工去的庄严行列。在这样的大清早，乡村的街道上，除了矿工，没有其他的人，就像战场上除了军人之外没有一个闲人一样。到处都是矿工。他们从四面八方集中到矿井里去。他们三五成群，沿着无数小路，穿过草原，有的从山上下来，经过山峡，有的单身独行，有的成群结队，有的匆匆疾行，有的甚至大步奔跑；不过全都很严肃，庄重，保持着一种清晨的特殊沉默，没有嘈杂的人声，只有偶然传出问安的简单语，好像哨兵在大雾中互相呼应一样……越近村子，矿工的队伍越密；在早晨的淡红色烟雾中，维克多觉得手镐就是作战用的斧钺，矿灯就是没有燃旺的火把……在这批黑色人群穿过草原的运动中，洋溢着一种威严勇武的精神，也许，这是由于大家都朝一个方向行动，仿佛他们被一种共同的默契、一个统一的意志和一致的目的联结在一起。这里好像军队，没有无意来到的人，也没有局外人；只有陌生人，这里的人们虽然形形色色，但都是矿工……再过一小时，这支友好的大军全部将在地下采煤了。

不过，此刻这支大军却神气活现地充塞了乡村的街道。一批批新的武装队伍，在每个十字路口加入这支大军；一群群新的武装着的人们，从所有的胡同里、院子里和庭园里出来，注入这道沉默无言的人流，他们都掮着同样的武器——斧头或者手镐，穿着同样的军服——矿工的黑色“天鹅绒”……

起初维克多所感到的唯一痛苦，就是他和他的同志们看上去还不像真正的矿工。不论什么人，只要一看到他们崭新干净的工作服，一看到他们那种畏畏缩缩的胆怯相，就会发觉这一点……

现在可没有什么事情使人觉得痛苦了。谁也说不出新来的团员跟原来的矿工有什么差别了。共青团员们在矿山上已经像在家里一样了。他们昂首阔步地走在街上。他们的工作服早就不新了，也早就不干净了，它们走了样，强烈地发出煤炭和矿井的气味，好像一个老兵的军用大衣发出火药和壕沟的气味一样……在这条总的沉默寡言的人流中，这批青年人能唯一突出的，就是他们尖锐的嗓子。

他们在街上走着，一边走，一边快乐地聊天。

“今天我要打败米佳！”谢辽查夸口说，“我要超过他，要是我吹牛，你们可以唾我的面……”

“是的，要是能够用什么纪录来迎接节日，那再好也没有了！”斯维特里回答说。

“朋友们，坑木在妨碍我的工作！”奥萨奇说，“我们的坑木真是见鬼。斯维特里，你最好注意一下这个问题！”

“坑木实在不合规格，”安德烈插嘴说，同时叹了一口气，“为了挑选合适的坑木，浪费很多时间……”

维克多没有参加谈话。他不愿参加，也无法参加。他能对朋友们说些什么呢？他们只谈矿井，老是谈矿井。他们已经过惯矿井生活了。矿井已经成为他们生活中的主要东西了。矿工的劳动在他们已经是一种快乐的工作，而在维克多却是一种讨厌的义务。鬼知道他怎么会搞得这么糟？或者，还是换一个矿井，到新的地方去当一名赶车工吧？无论如何，赶马要比刨煤有趣些。不过，最好还是进骑兵学校。而且要到边疆去。到一个很远很远的地方去，到远东去。到野森林里去。去搜捕特务分子。

他胡思乱想，在脑海里建造空中楼阁，但没有一个人去打扰他。虽然他也在人流中走着，朋友们却像已经把他这个人忘记了。连安德烈也不去理他，只顾兴致勃勃地跟斯维特里谈话。最后，当维克多一个人留在自己的台阶上时，他也并没有比早晨在人群中、在地面上时更孤独。

他甚至喜欢这种孤独，这在他年轻的生命中还是破题儿第一遭。

他不愿工作。不错，他装好镐齿，双手转了转手镐，但马上又把它抛在一边了。他即使刨得两手出血，还是刨不满定额。至于说比定额一半稍微多一些，或者稍微少一些——那又有什么差别呢！

不错，最好是进骑兵学校！……或者航行到很远很远的地方去。片舟孤帆，乘风破浪，游遍大海汪洋，不知什么叫忧愁烦恼。他躺下来，把双手枕在头下，开始凝视顶板。顶板好像一面没有光泽的镜子，又像电影院里的银幕，上面看得到你所幻想的一切。自然，远方航行——这只是一个荒唐的、孩子气的梦想，是一辈子不会实现的。何况现在也没有人再乘帆船航海了。不过，到野森林里去——这是有可能的。唔，就算不到边防军队去，也可以到新的建筑工地去。现在，野森林里已经开始了许多建设……据说；在野森林里，也像在矿井里一样，望不见天，那是因为树木稠密的缘故。然而，野森林里可没有这里这样黑暗。那边一片苍翠……还有针叶树的气味……杉松……这也是一种松树，不过比普通的松树大一点……

他不知不觉地睡着了。但是，他梦见的却不是野森林，也不是边疆，而是一个极不平常的陌生的热带地方；那里的天很高，而且蓝得像蓝色的普晓河。维克多老是逍遥自在地在这个蓝色的天空中翻筋斗，载沉载浮，他舞动双手，好像两只翅膀……世界上没有比这种腾云驾雾更开心的事了。

组长把他推醒了。

“哪，您来欣赏一下吧！”他失望地叫道，“瞧我们有着怎样的突击队员哪！伏罗日卓夫同志，随便您怎么办吧，我可实在对付不了他们啦！……”

“是——呀……”那个叫伏罗日卓夫的人闷闷不乐地说，“好人都用成绩来迎接节日。可是我们有些什么成绩呀！……”他把自己的那盏矿灯，一直提到维克多的鼻子前，把他的脸照得清清楚楚的。“你是谁？谁？叫什么名字？”他严厉地问。

但是，维克多目瞪口呆，没有话可以回答。他自己还不明白，他闯了什么祸。这里出了什么事？这两个人怎么会出现在他的台阶上？他们是谁？

“他叫维克多！”组长气愤地代维克多回答，“共青团员。”

“共青团员？”伏罗日卓夫不信任地反问，“坏透了。工作时间睡觉……是的……这件事，老弟，在军队里是要枪毙的。”他放下矿灯，简短地命令道：“来，干活吧！以后再跟你讲话。”

维克多连忙拿起手镐。伏罗日卓夫默默地瞧了一会儿，瞧他非常笨拙地但却猛烈地砍着煤，然后，一句话不说，就离开了掌子。直到他走的时候，维克多才记起来，伏罗日卓夫就是那个新任的矿党委书记。发现维克多在台阶上睡觉的原来是他……不过，现在只好听它去了——事情已经糟得不能再糟了。

快下班的时候，安德烈照例爬了下来。他在上面一个台阶上工作。

“嗳，干得怎样，维克多？”他性急地问，“刨满定额了吗？”

维克多什么也不回答。

“真的没有刨满吗？”安德烈大吃一惊，“老兄，你这是怎么搞的？”他用同情的眼光瞧瞧好朋友。“要知道明天是什么日子。我可刨满了！”他的脸上浮起了一个羞怯的幸福的微笑。他很想原原本本地讲一讲自己的成功。但是他明白此刻维克多听了会不高兴的。

“嗯，不要紧！”他这么说，希望宽宽朋友的心，“只是你不要泄气！下一次刨满它。你要知道，这是完全办得到的事……只要你存心……”

然而，好朋友的同情只惹得维克多发火。他既不需要宽容，也不需要安慰！他烦恼地叫起来：

“我本来也绝对能够刨满定额的。你要明白！只是我有病，有病！听到吗？我五脏六腑都有病！”他一边叫，一边几乎流出眼泪来，“都有病！我在这儿稍稍躺了一会儿……你懂吗？可是伏罗日卓夫却以为我在睡觉……”

“那么你为什么……你为什么早晨不说呢，维克多？”安德烈焦急地叫道，他一把抓起矿灯，赶紧提到好朋友的身旁。“也许，你根本不该下矿的吧？现在你很不舒服吗？很不舒服？”他像刚才伏罗日卓夫所做的那样，把矿灯直举到维克多的脸旁：维克多的脸涨得通红。

“我什么病也没有，”维克多声音嘶哑地说，“我只是在掌子里睡着了。睡得像狗蛋。”他拿起工具，眼睛不望安德烈，很快爬出了场子。安德烈完全被弄糊涂了，跟着他爬去。在这分钟里他只懂得一点：朋友的情形很糟，非常糟，但他不知道应该怎样帮助他。

在井底车场里，他们遇到斯维特里。斯维特里已经知道维克多在掌子里闯的祸了。

“又是你捣的鬼，维克多！”他老大不高兴地对维克多说，“你是故意的吗？不，你告诉我，你为什么要这样做？做给谁看？”

“不，他有病，有病……”安德烈连忙插嘴说，“斯维特里，你瞧瞧他的脸色——他真的有病。”

“有病？”斯维特里不相信地问，同时仔细朝维克多瞧瞧，“不大像……唔，好吧！我们以后再说。现在……去领工钱吧。也许，领了钱，病就会好了。”

“我们领不到多少钱。”安德烈不好意思地说。

“做多少工作，拿多少钱。”

不过，显而易见，两个朋友的工作成绩都很坏，因为连出纳员也感到很惊奇，嘲笑地摇摇头。

“青年人，你们是怕损害自己的健康吗？”他一面说，一面把钱递给维克多，“唔——唔！健康当然重于一切。”

维克多一只手揉着钞票，什么也不回答。

不久之前，他还多么得意洋洋地对头几笔工资作过幻想啊！他曾经打定主意要给企比略基的母亲寄一大笔钱去。“嗯，妈妈，您要知道您的儿子已经能够自立了。妈妈，现在您可别再伤心了！”可是，照目前的情形看来，妈妈要拿到不走正路的儿子的礼物，还得等待好久呢。他跟安德烈两人挣的钱，连吃饭都不够。他们怎么挨得到下次发工钱的日子呢？向有钱的同志们借吗？“有钱的”，“没钱的”——这些旧的界线变得多怪啊！谢辽查是有钱人，因为他活干得好；维克多是穷人，因为他在掌子里睡觉。而且谁也不应该可怜像维克多那样的穷人；他也不能以这样的贫穷自豪。这是一种不光荣的贫穷。这是一种可耻的贫穷。现在他也因为这种贫穷而感到羞耻。

晚上，俱乐部里开工人大会。维克多必须去参加，这一点是铁面无情的斯维特里所坚持的。这位团组长甚至亲自坐在维克多的旁边，仿佛怕他逃走。事实上，维克多是无路可逃的。难道他可以钻到地底下去吗？他明白，斯维特里带他去开会，决不会没有缘故。这样看来，这次大会已经特地为他维克多准备好些东西了。但到底是什么呢？不会是什么好事情的，因为维克多没有做过任何值得嘉奖的事。那么，就准是件很倒霉、很可耻的事了。而且，如果斯维特里认为维克多会吃不消，会逃走的话，那显然是极难受的。但究竟是什么呢？还有，什么时候开始呢？怎样开始呢？

这是任何一分钟都可能开始的。自从那位亲眼看到维克多在掌子里睡觉的矿党委书记伏罗日卓夫登上讲坛的那分钟起，维克多就失去了平静。维克多听着书记的报告。浑身嗦嗦发抖；他呆呆地等着，再过一秒钟就会从伏罗日卓夫的嘴里飞出生死攸关的话来，使维克多可怜的名字从此染上污点，永远无法洗刷干净。但是，伏罗日卓夫却没有提到维克多。

后来，人们向最优秀的采煤小组——列斯尼亚克小组致敬，并且授给它一面红旗。维克多看到列斯尼亚克老头怎样小心翼翼地、一本正经地从书记手里接过旗子，然后郑重其事地、满面春风地张开双手，举着旗子穿过会场。于是维克多就机械地向老头儿和旗子拍手，因为大家都在拍手，整个会场都在拍手。

接着，人们向最优秀的突击工作者致敬。于是，面红耳赤的奥萨奇、幸福得手足无措的谢辽查和打扮得十分清洁漂亮的红头发米佳，夹在别的人们之中，走到了台上。维克多又机械地跟着大家拍手，并且望着谢辽查怎样䀹动灰白睫毛，米佳怎样若无其事地像演员一样左手压紧胸口，向大家点头致敬。此刻，米佳、谢辽查和奥萨奇站在光辉灿烂的荣耀的顶峰，维克多却在万丈深渊里挣扎；他们之间的距离是那么大，以致维克多简直不敢羡慕这几位同志。他们是高不可攀的。维克多只能向他们拍手。他拍着手，一面拍，一面想：“嗳，什么时候轮到我呢？我将怎样呢？怎样呢？”

最后，掌声静止下来，伏罗日卓夫换了一种完全不同的声音说：

“唔，现在我们要奖赏一番那些工作成绩最坏的人了！”他从桌上拿起一张名单来。

会场马上改观了。刚才这个会还是那么美好，那么亲切，那么可爱；人们还是那么快乐，那么真诚地向英雄们鼓掌，发出心底的欢笑……可是此刻会场肃静了，愁眉不展了；维克多明白，这就要轮到他了。他匆忙地舔舔嘴唇。他的喉咙哽塞了。

伏罗日卓夫念出了第一个名字。这个名字维克多不知道，但会场里的人们是熟悉的。

马上传出了许多声音：

“叫他到台上去！到台上去！”

“出名的旷工者！”

“到台上去！”

“让他站在大家面前！”

“让人民看看他的眼睛！”

奇怪得很，旷工者真的朝台上走去了。他踉踉跄跄地沿着过道走去，回避大家的眼光，头发蓬松，脸红耳赤，立刻现出一副渺小可怜的样子，在全场的嘘声中，在轻薄的掌声和喧嚷声中走着。但到底走了上去！如果是伏罗日卓夫命令他登台的话，如果是首长要求他那么办的话，他一定会提出抗议，决不会服从的。但是，违反自己工人同志们的意思，违反他们的判决，他可没有胆量。他走到台上，只是惶恐地向他们伸出双手，好像在说：嗳，可怜可怜吧，弟兄们，不要过分责备我吧！

在他之后，被伏罗日卓夫提名的人都一个个走上台去：废品制造家、“飞行家”、懒汉、旷工者。“破坏计划的冠军队”——会场里已经有人那么称呼他们了。大会用自己的方式，用工人阶级的方式，来惩罚这一批人：不是罚款，不是处分，而是用劳动者惩罚懒汉的最可怕的方式：蔑视。

终于轮到了维克多。

“我不去！”他听到自己的名字，哑着声音说，同时用恳求的眼光瞧瞧斯维特里。

“要去的。”斯维特里伤心地回答。于是，维克多就弯着腰，从座位上站起来。

“不要紧，不要紧！”斯维特里用友好的声调低低地对他说，“去。不要紧。应该去。”

维克多走了出去。斯维特里用眼光送他。他只看到维克多的背影。但是这样也已经够了。斯维特里明白，他一辈子也不会忘记这个背影的。“我对他一无帮助！”突然他第一次痛苦地责备自己，“我只是怪他，骂他，责备他。我没有诚心诚意地跟他谈过一次话。我没有找到打开他心门的钥匙。事实上，我甚至不了解他是一个怎样的人。现在他走上台去了……而我却坐着——若无其事地袖手旁观着。谁也不会因此来处分我这个团组长。可是他一个人走着……大家都望着他……嗳，维克多，你抬起头来吧！抬起头来吧！”当维克多走上台之后，他已经成为斯维特里最亲近的一个人了——他一定要为他奋斗。

不过，维克多并不知道这一层。他没有看到斯维特里，也没有看到安德烈，总之他没有看到会场里任何一个个别的人。他只看到：许多双眼睛盯着他，他怕瞧这些眼睛。一个人作了对不起群众的事情，他就不敢正视群众的眼睛。维克多低下了头。可是，在第一排上，有一个戴布琼尼帽的老太婆坐在他的正对面，他没有办法不看到她。她用严厉凶恶的眼光盯住维克多，好像要一眼把他看穿似的。“干吗她这样瞧我？我做了什么对不起她的事了？”维克多感到害怕了。而老太婆始终望着他。她身上的一切——从骨瘦如柴的指头，到布琼尼帽的尖顶——都是尖锐的，不妥协的。她不认得维克多。不过，她用同样的目光瞧着“冠军队”里的每一个人。在她看来，他们都是同一路货——造成马丽雅矿耻辱的罪人。这些不知羞耻、没有良心的外路人，他们干吗到矿上来呀？他们不珍惜我们的东西。他们不曾在这儿流过血，出过汗，掉过眼泪。他们为了捞大钱上这儿来，我们为了马丽雅矿不惜牺牲生命。他们在掌子里睡觉，这批没良心的家伙，而我们的人却长眠在矿井旁的烈士墓里。我的尼基福就是其中的一个。

因此，老太婆带着火辣辣的憎恨望着维克多。

伏罗日卓夫念出了名单里最后一个名字：

“斯维利多夫！”他宣布说，“你们知道这个人吗？”

“知道，知道！”传出了几个人的声音，“不择手段唯利是图的家伙！”

“叫他上台！”

“何必叫这个家伙上台呢？”不知谁用伤风嘶哑的声音，怀疑地反对，“他反正不会害臊的。他死不要脸。”

“无论如何要他上台，上台！”

维克多看到斯维利多夫朝他走上台来，大吃一惊，因为不久之前在场子里戏弄他和安德烈的就是那个家伙。他仍旧戴着脱皮的圆形羔皮帽，穿着灰领的衣服和棉裤，脖子上绕着一条花花绿绿的毛围巾，脚上穿着毡靴，外加一双套鞋——好像斯维利多夫觉得这个地方很冷，他必须用毡和棉花把整个身体裹起来。他走上台去，真的没有一点难为情的样子，甚至显得很开心，很自在，一路上向熟人使眼色，走到台上时，对维克多像对老朋友似的眨眨眼睛，并且顽皮地用肘撞撞维克多的腰。这是维克多那天晚上所受的最后一次、也是最厉害的一次屈辱。因为这表示他已经堕落到了这样的地步：他跟斯维利多夫处在同一个队伍里，站在同一面旗子下……

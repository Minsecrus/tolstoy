# 十三

天色黑了。

雨停了。11月的头几阵寒气已经轻悄悄地在草地和湖泊上铺下了一层薄冰；在矿山黄昏的寂静中，听得到寒风下的冰块在冷得叮叮发响，好像有许多小铁锤在上面轻轻敲击。

维克多分不清道路，穿过村子跑着，飒飒地踏碎冰片，弄得泥浆和黑色的雨水四面飞溅；他竭尽全力跑着，仿佛后面有人和鬼在追他。

其实，在弯曲狭隘的死胡同和街巷里，并没有一个人，也没有什么东西在窥伺他；没有熟识的人——在村子里他认识的人很少，也没有什么可回忆的——他差不多完全没有什么回忆。他是一个外乡人，在这里还很陌生；他来了不久，心还没有在矿井里生根，可是竟要——走了，逃了。

去你的吧！——矿井冷笑着送他——去你的吧！我们没有你也过得下去的！没有你，发电站照样会正常工作，井架上的滑车照样会转动，钢缆照样会上下升降；还有，一批批的“货”照样会在平巷里吱吱咯咯、轰轰隆隆地飞驰，煤车会轻快地在铁轨接合处敲响，沿着木板的栈桥奔跑；青灰色的矸子山——矿工劳动的金字塔，会越堆越高。你只采了很少的煤，小伙子，你只是徒然在掌子里占一个位子而已。我们没有你也可以过得很不错的。你算得了什么？！

不过维克多已经无法自制了。

他快步穿过村子，一溜烟跑到公路上，才舒了一口气。嗳，瞧吧，现在离开车站只有三公里了——只有三公里。明天他就会在很远的地方了。

他四面望望。他的周围，公路上，并不像他开头所想象的那样荒无人迹。这里，那里，他的前面，他的后头，都有人在雾中跋涉，也像他一样手里提着箱子，或者背上背着袋子；风送来了他们沙哑的说话声和他们走路的脚步声。维克多猜到了——这是“飞行家”。他觉得很不高兴。“说不定会有人把我也当作‘飞行家’呢。”接着又伤心地想：“但是我到底是什么人呢？忍耐一些吧！”

在村子里，还没有人会想到他是个开小差的。就是小箱子也不能算作物证，因为人家会以为他是到澡堂子里去洗澡的……

然而，在这里，在车站附近的公路上，一切都是显而易见的！现在已经不能使维克多跟这批黑暗的人分开了。这儿的人全是一丘之貉，全是流氓，流浪汉，他们没有祖宗和家庭，没有羞耻和良心，没有爱和真理……他们的一切都是假的：护照、名字、灵魂……

而现在他就夹在他们之中。他是他们的同路人。他是属于他们的，属于他们那个落后的、无亲无故的流浪部落的，而且不仅限于在这条到车站去的短路上，而是长久地，也许要整整一辈子。尽管在他上装袋里，整整齐齐地放着他那张真实不假的共青团团证——这张团证是他从矿井逃走时由于胆怯（是的，不错，是由于胆怯）没有扔在枕头上——但那又有什么用呢？他是不敢再拿出来给人看的了。是的，他已经没有权利享用这张团证了！“共青团员决不会逃跑的！”现在他不得不隐瞒他原来是个共青团员了。不得不隐瞒他是从矿井里逃出来的。他得隐瞒自己的一切；得在纯洁无瑕的人们之间，过保守秘密的虚伪生活。难道人可以过这样的生活吗？！

后面又传来一阵脚步声，有人重重地喘着气，要追上维克多。维克多缩进了头，翻上了大衣领子。

一个身穿没有领章的旧军用大衣、头戴军用皮帽的人，追上了他。维克多偷偷地瞧了他一眼——一个他完全不认识的人。他松了一口气，抬起头来，现在可以走得安心些了……他们俩并排走着；彼此斜眼瞅着。穿军用大衣的人，手里也拿着一只箱子——恐怕也是个“飞行家”吧。自己人。

“自己人？”维克多心里很生气，“不，我不是他们那种人！”“那么又是怎样一种人呢？”

穿军用大衣的人突然发出一声尖锐刺耳的声音，好像沼地上苍鹭的长鸣。维克多惊惶地回过头去：他这是怎么了？在哭吗？他定睛细看：不，在笑！多么奇怪、恶毒的笑……

“您干吗呀？”他不由得问。

那个人仍复用古怪刺耳的笑声笑了起来。

“小鬼怕见阎王……”他说，“那么您是为了什么呢？”

“我，是什么人吗？”维克多惊惶失措了。

“全都是！”那个人指指道路。那边，在烟雾中踯躅着几个模糊不清的影子，不是人，是幻影。“我真想把他们一把抓起来，拿他们的头塞进小井里，叫他们都去见鬼！难道跟这种人一起可以建设社会主义吗？！”

维克多没有表示什么。

“蝗虫……”穿军用大衣的人说，“的的确确是蝗虫……真不知道是打哪儿弄来的一批宝货？从来不曾见过……您也该害羞！”他出其不意地朝维克多转过身去，“您大概是共青团员吧？”

“是——的……不过……”

“可耻！”那个矿工生气地说，“他们那批人不用提了！富农。田老鼠。他们天生是这样的坏种。但是您应该害羞！”

“但我……不是矿工！”维克多喊道，几乎要羞耻和失望得哭出来。“您怎么知道的？我是……偶然……我是从朋友那儿……作客来的……”他看到，这人并没有相信他，在含着怀疑的神气斜眼瞅他。难道从此以后所有的人永远要用这样的目光瞧他吗？“我……是来作客的……我自己在城里工作……”他连忙结结巴巴地说，“真的哪！……您要看看文件吗？老实话！”

“为什么还要说什么老实话呢？”他马上对自己生起气来，“彻头彻尾变成畜生了！”

但是，他却很希望人家相信他，哪怕就只有这个穿旧军用大衣、戴军用皮帽的古怪的陌生人！

“哦——哦！”那人终究拖长声音说，“嗯，那么请原谅……”他微微一笑，解释道：“看着这种光景真心痛。我真想把这批无业游民统统塞进小井里去！……无业游民——我最恨那种人。您是从马丽雅矿来的吗？”

“是——的……是……从马丽雅矿来的。”

“我在马丽雅矿没有见过您。”

“我不是说我是来作客的吗……没有多久……”维克多高兴地喋喋说，“那边我有个朋友……安德烈……我自己住在城里……难道我会答应自己……逃跑吗？”他一边说，一边像孩子一样脸涨得通红；他感到脸上热辣辣的，他很生自己的气。

“嗯！”那个矿工若无其事地说，“我还以为在什么地方看到过你呢……说不定！”

公路上出现了灯光。车站已经不远了。

穿军用大衣的人斜眼瞧了一下同行者——维克多现在不再缩头缩脑、躲躲闪闪了，他竭力装出堂而皇之的样子，大胆地看着人家的眼睛——接着又说：

“是的，说不定！……现在我记起来了：我在大会上看到过你。”

“什么？……”维克多吓得站住了。

穿军用大衣的人走到他的身边，拉拉他的衣襟，对准他的脸，低低地说：

“现在你想逃吗，混蛋？！”

“那么你……那么你呢？”维克多火起来了，“你自己也带着箱子……你也……”

“我是去参军，去集合！……”矿工一面说，一面厌恶地推开了维克多。

维克多只好逃开这个穿军用大衣的人。

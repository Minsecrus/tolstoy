# 十四

他上气不接下气地跑进车站，一直朝卖票房的窗口冲去。但愿火车快一点！……但愿快点离开这儿。可是卖票房的窗子还未开，问讯处里的人告诉他说，南行的火车还得等一个钟头，北行的火车要到夜里才有。“如果不脱班的话！”问讯处的姑娘冷冷地加了一句。

他离开了窗口。他毅然决定到北方去。不到南方去，不去过舒服的生活，也不到企比略基母亲那儿去，而到北方去，到最遥远的北方去，到火车开得到的最远最远的地方去。那边，在西伯利亚辽阔的荒野上，他将用事实证明自己正确的决定和诚意的悔改。

不过，北行的火车要到夜里才有，如果不脱班的话。而在这里车站上，每分钟他都可能被人看到，被人认出来。他又得碰到那个穿旧军用大衣的矿工。此刻车站上人们投射在他和他箱子上的每道目光，就像吐在他脸上的唾沫。

“南行的火车还得一个钟头。”他记了起来。

或者，就到南方去吧？到高加索去吧？到海滨去吧？刹那间他感到自己又幸福又自由。他要去哪儿，就可以去哪儿。他好像一只羽毛初丰的小鸟，头一次自由自在地鼓动翅膀，头一次明白天生它这对翅膀是飞翔用的。此刻他站在一个草原小站的月台上，整个世界就展开在他的面前。只要我高兴——明天温暖可爱的大海，就会在我的脚下汹涌起伏。只要我高兴——明天高山峻岭就会在我的面前突兀出现。

不过，无论如何他一定要到北方去，他只要到北方去。这样就永远没有一个人可以打他的耳光，说他是为了贪图舒服的生活而从矿井里逃走的。

他要到北方去，哪怕火车脱班一天一夜！

然而，挤在车站大厦或众目睽睽的月台上，是不妥当的。

他走到广场上。这是一个顿巴斯的11月黄昏，天空低低地紧接着地面，已经分不出哪里是天，哪里是地了，只有一片白蒙蒙的潮湿雾气；在这片雾气里，火车的汽笛声和喧闹的人声在互相呼应；声音荡漾在烟雾里，灯火凝定不动；草原上还闻得出枯草和昨天下过雨的气味——最后的秋天的气味。

天还不冷，但很凉快，笼罩着晚秋初寒的大地渴望下雪，就像夏天等下雨一样。

在那样的黄昏，地面上最甜蜜的气味，就是住宅和住宅烟囱里冒出来的淡烟。在那样的黄昏，有家的矿工爱好坐在家里，跟几个朋友一起喝烧酒。做主妇的就不时跑到地窖里去拿黄瓜和咸菜；黄瓜还没有进盐，要是吃得这么快的话，那么，盐就来不及透进去的。

在那样的黄昏，地面上人人准会想到煤；煤——就是温暖，甚至于只要一想到它，心头就会觉得暖和。大家都要储藏一些过冬用的煤，因此，在那样的黄昏，所有的电话、无线电话和电报机都在忙着煤的事。

在那样的黄昏，想到自己是个矿工很快乐。刨满了定额，来到地面上，到火热的澡堂子洗个热水澡，然后心安理得地望望人们的眼睛，穿过村子回家去，这真是惬意啊！在那样的黄昏，一定要有个自己的家，自己的一家人，和一颗平静纯洁的心……

但是维克多没有家。此刻他在车站旁边的那个广场里，坐在自己的箱子上。连鸟儿也早已结束秋天的旅行，而他却还只开始他的远行。什么在等着他呢？他将怎样呢？此刻他好像一个流浪汉……

天冷起来了。如果他不得已卖掉上装和短外衣，他又怎能到达目的地呢？他忽然觉得肚子饿了。此刻要是喝一杯热茶，该多么好啊。他记得这里离开广场不远有个小食堂。那个食堂很容易找，因为此刻正巧有闹声和歌声从那里传出来。他拿起箱子，开步走去。

食堂附近有一小群快乐的人。维克多想从旁边走过去，可是情不自禁地想侧耳听一下，就站住了。

人群中间，一个脸色冷得发青、身上穿着破衣服、脚上穿着矿工鞋的瘪三，用响板打出粗俗的音调，同时，一面跳舞，一面唱着快板小调；人群听得哈哈大笑，并且合着他唱。

可是，传到维克多耳朵里的却只有一些片断：

破大衣，没口袋，

旧靴子，没后跟……

打响板的人那么唱着。

再下去，一阵低沉、粗俗的唱词，沉没在人群的哄笑和快乐的尖叫声中，接着，一片合唱声好像油漆一样，又把它盖住了：

嗳呀，咚吧，咚吧，咚咚吧！……

嗳呀，咚吧，咚吧，咚咚吧！……

好吧，这倒是挺好玩的！火车即使不脱班，也不会马上就到，而茶尽可以晚一点去喝。维克多就钻到人丛里去。

那边掘着一个个的洞，

那边有矿工在做工……

打响板的人使劲唱着，人群合着重唱词：

嗳呀，咚吧，咚吧，咚咚吧！……

嗳呀，咚吧，咚吧，咚咚吧！……

人群又按着拍子鼓掌，差不多把响板枯燥的嗒嗒声盖住了。打响板的人不停地跳舞，试图穿着矿工草鞋跳踢踏舞，仿佛想在冻僵的地面上踹出火花来，他身上的破衣服一抖一抖地跳动，他那冷得发青的嘴唇和两颊也在颤动。

别了，矿井顿巴斯，

我们绝不再到此！

“嗳，加油呀！”维克多旁边的一个瘪三兴致勃发地尖声喊了出来，得意忘形地合着重唱词：

嗳呀，咚吧，咚吧，咚咚吧！……

嗳呀，咚吧，咚吧，咚咚吧！……

打响板的人，一面受着人们的鼓舞，一面因为跳得暖和些了，就“加油”唱下去：

我们矿工——做多久自己知道，

我们狂饮——要多少有多少。

明早天一亮，

飞离顿巴斯。

这算什么话呀？维克多落在什么地方了呀？干吗他要钻到这个龌龊的人群中去呢？流氓、瘪三、无赖、走江湖的，一切被矿井排挤出自己纯洁队伍之外的浮沫——他在这批人中间又有什么事做呢？……他决定马上走开，并且移动了一下身体，可是打响板的人已经发现他，觉得他与众不同，还很整齐清洁，还留有共青团员的标记——这个标记不会很快消灭——就向他眨眨眼睛，走上去，站在他的面前，扯动自己全身的破衣服。

“敬请指教！”他用难听的鼻音对维克多嚷道，“青年人，我要为您唱一曲！……”

接着他用迅雷不及掩耳的手势打起了一阵响板：

山梨花开又花落呀，

共青团员逃出顿巴斯呀……

“啊——啊——啊！”人群兴高采烈地咆哮起来。

现在大家都看着维克多。有人轻薄地拍拍他的肩膀。有人喊道：“喂，小鸟儿，头抬得高一些！”于是又响起了一阵快乐的、伤风嘶哑的笑声。

维克多冲出人群，可是几十双手抓住了他的短外衣和箱子……“嗳，小伙子，你上哪儿去呀？我们还要跟你一起跳舞呢！……”

“放手！”维克多忘其所以，气急败坏地一面喊，一面冲出去。他们放了他，因为他的反抗实在可怕。他推开面前的人们，拔脚就跑，自己也不知道上哪儿去……

他的后面，还长久地传来喊声、笑声，以及轻薄的低沉的合唱：

嗳呀，咚吧，咚吧，咚咚吧！……

嗳呀，咚吧，咚吧，咚咚吧！……

他回到了站里。他还能上哪儿去呢？他已经隐隐约约地感到，从矿井逃走就是一个错误，一个无法补救的严重错误，这是他亲手毁了自己的一生。不过，现在再回去已经晚了。

“为什么晚了呢？”他突然问自己，“还没有一个人知道呀。我可以说——到外面蹓跶了一会……”“那么箱子呢？”不错，箱子……没有人提着箱子去散步的。这样看来，就不得不对安德烈……对斯维特里……对大家“和盘托出”了。他们会笑的。不，还要更坏一些，他们将“关心”一个悔过的罪人……他们将长久地向他提起这一夜，逃跑和归来。而且将监视他，以防再发生同样的事……

“不，回去不得！”他忧郁地想，“必须走……那边怎样——去了再说！”他固执地蹙紧眉毛：眉毛弯弯的很神气，像他父亲。但父亲可从小不曾从人家的地方逃走过。

南行的火车已经开了。穿旧军用大衣的矿工，大概乘那班车走了，因为不论哪里都看不到他。维克多又到问讯处去问。是的，北行的火车脱班了。

“也许，路上还赶得上吧？”维克多犹豫不决地问。

“可能赶上的。”姑娘冷冷地答应。

维克多走进候车室，找了一个空角落，把箱子放在地板上，就在箱子上坐下来。这儿，在这个角落里很暗；如果翻上大衣领子，没有人会发现他。他就这么做了。

他的精神和肉体都极疲劳。但这种极度的疲劳，直到此刻才感觉到。他闭上眼睛，想打一会瞌睡。可是，忽然一样东西使他大吃一惊。什么？

他甚至不加考虑，拔脚就跑，好像一只被猎人追捕的兔子，完全受着本能的支配。

他听到有人在叫他的名字；他连头也不回一下。一扇玻璃门挡住了他的去路，他用力一推——玻璃震得琅琅响——跑了出去。

原来他跑到月台上来了。但还不是一样。他换了一口气。有人追来了！他感到这一点，仿佛不是用知觉，而是用皮肤。他的脊背好像听到后面的脚步声，又急促，又坚决。他又拔脚飞跑。

“维克多！”——已经清楚地从黑暗中送进他的耳朵。

他既不停留，也不回顾，一口气跑过铁路。突然，他钻进装货的车丛中。他徘徊起来。现在上哪儿去呢？

那时，他的心头涌起一个简单而幸福的念头。他不必等北行的客车了。这列装煤的火车自然是开到北方去的。机车冒着烟，乘务员在旁边忙碌。车子大概就要开了。只要趁现在还没有人追上他，立刻爬到车上去。那么，等到天亮，他已经在远方了！主要的是要远离这个该死的车站，这里，大家都认识他，大家都在监视他……

他抓住了敞车的边缘。

“维克多！”他又听到黑暗中叫喊的声音。

声音好像很熟。但也许是神经过敏吧？不论怎样，事不宜迟。他把箱子抛在敞车上，双手用力一撑，自己也爬了上去。

敞车上装着煤，当维克多身子扑到潮湿阴冷的煤堆上时，刹那间他感到又在掌子里了。纯粹是煤的气味！维克多忽然想到，说不定他此刻躺着的那堆煤，就是他采出来的，就是他亲手采出来的——因为这一定是马丽雅矿的煤。说不定就是他采的煤。所有维克多在他短促的矿工生活中采出来的煤，是不是够机车向北方作一次长途旅行呢？恐怕不够吧！

一阵轻微的震动传遍列车的每个关节；车厢和敞车像骨节一样，先是格的一声，然后吱吱嘎嘎地响起来。“动了！”维克多快乐地想，“马上就要开了！”他在这段时间里初次感到轻松和平静。

有个人喘吁吁地朝维克多的那节敞车爬上来。维克多待住了，整个身体贴在煤上，连呼吸也屏住了。那个人爬了上来，一屁股坐在旁边的煤上。

这时火车又动了一下——开了！……起初慢慢地，好像在试探，在摸索道路，接着车轮隆隆响着，越转越快。一股料峭的寒风在敞车上空呼啸。维克多打了个寒噤。冷得很。“要是睡着的话，会冻死的。”

“维克多吗？”旁边的那个人低低地问。

维克多全身哆嗦了一下。他的第一个动作是抓起箱子往外跳！可是火车现在已经开足速率；只见电线杆子在车外闪过。

“维克多！”旁边的那个人又喊了一声，维克多大吃一惊，听出了熟悉的声音。

“是你吗，安德烈？”

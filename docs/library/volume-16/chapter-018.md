# 十六

“这是你吗，安德烈？”维克多烦恼地说，“你来干吗呀？”

他想起来了，不过两个月之前，他们那列快乐的共青团专车，曾经在这条路上驶过。每站上都有鲜花和音乐欢迎他们；姑娘们穿着白衣服，向他们目送微笑，有时——当火车已经开动时——还有飞吻。他跟安德烈互相依偎着，站在窗畔，遥望顿巴斯怎样展开在他们的面前，一会儿火光烛天，一会儿冒出淡淡的蓝烟；他们幻想着这里光荣伟大的生活，并且相信这种生活一定会出现！为什么不会出现呢？在那个时候他们都是自愿跑来的，他们都是英雄……

“我们开会回来……”安德烈颠颠倒倒地讲道，“不见了你……孩子们说：也许他出去散步去了……可是斯维特里……”

“斯维特里什么？”维克多哑着嗓子问。

“不，他没什么……只说：不，不会的吧！而我呀，往床下一看……箱子没有了……我就猜到……哦，哦，维克多，我害怕死了！你这是怎么啦？！现在叫我怎么办——叫我一个人？！”

是的。同在这条铁路上，同在这些钢轨上，而且又跟安德烈在一起。在山峡之后的什么地方，天空仍旧是一片红光，蓝烟仍旧在袅袅上升，潮湿的水蒸气仍旧一片片地落在人们的脸上和肩上。肚子下面的煤块一抖一抖地不断跳动，仿佛维克多跟安德烈不是躺在敞车上，而是躺在煤筛上。钢轨剧烈地震动，拿他们像矸子似的往上抛，并且无情地把他们送出场子，送出矿井，送出顿巴斯，送出生活……送到哪儿去？为了什么？

“你干吗这样呢，维克多？”安德烈略带责备的神气问。

“那么你，你又干吗呢？”维克多很想恶狠狠地大声回答。但他没有喊出来，只是翻身伏在冷冰冰的、已经盖着一层霜的煤堆上，咬紧牙齿说：

“我们混蛋……混蛋……”仿佛直到此刻他才领悟可怕的事实，感到自己的堕落。电线杆、电线、铁路交轨处的路灯，不断地在他们的旁边闪过；里程标好像杨树桩，根根打进人的心坎里……

火车在减低速率，驶近车站。维克多忽然跳起来，抓起箱子。

“来吧！”维克多疯狂地向安德烈喊道，“跳下去！”接着不再说一句话，从敞车上跳进黑暗里，安德烈也跟着跳下去。

他们跌在松软而潮湿的沙砾上。列车慢吞吞地在他们的身边爬过。最后一节车厢上的电灯闪亮了一下，就消失在烟雾中了。

“你没有摔坏吧？”维克多问。

“还好。”安德烈回答，同时朝维克多走去。

“嗯，那么走吧！”维克多一面发口令，一面站起来。他没有说上哪儿去，安德烈也不问。上哪儿去是明明白白的；他们只有一条路——回去，回到马丽雅矿去……

“那么你的箱子呢？”维克多问，“忘记在敞车上了，嗳，你这个傻瓜！……”

“我……我没有带东西……”安德烈手足无措地供认，“东西在那边……留在宿舍里。”

维克多目不转睛地看了看好朋友。突然他想走到安德烈的跟前去，并且拥抱他。但是他没有这样做，他还不会这样做。他只摇了摇头，压低嗓子说：

“好，我们走吧！”

于是他们就向前走去……

他们不知道，从他们跳车的那个车站到马丽雅矿，有一条横越草原的直路，却沿着枕木走回去。

他们不声不响地走着。在黑夜的寂静中，响亮地传出他们的脚步声。

安德烈忽然快乐地笑了。

“我早就知道了，知道了！”他笑着叫了起来，“我知道你一定不会逃走的。你不是那样的人！是吗，维克多？”

维克多没有回答。

然而，安德烈此刻却不能闷着肚子走路。他很想说说，笑笑，聊聊天，唱唱歌。这一夜他受了多少罪啊！这么多的罪，他一辈子也没有受过。

当他发现床底下没有了维克多那只熟识的箱子时，当他猜到他是从矿井逃走时，他仿佛觉得这不是维克多，不是安德烈引以为豪的好朋友，而是勃拉特青柯之流的坏蛋；当他了解他要从此失去一个朋友，并且孤零零地，完全孤零零地一个人留在矿井里时，他痛苦极了，痛苦得简直想上吊！

当时他不由自主地一口气跑出宿舍，一直跑到车站。他决定要把朋友找到，阻止他，说服他，恳求他回来。他相信，维克多是会回来的。

他只怕车站上找不到维克多，只怕已经追不上他了。一看到维克多坐在候车室远远的一个角落里，他高兴极了，不由得喊起来，以致把维克多喊醒了。后来他随着他跑上月台，又爬上货车。现在他知道已经不会再让朋友逃走了。

“你听我说！”他突然说，“要是我们能在天亮之前走到，那么就绝不会有人知道我们的事了，你不必怀疑！……”他知道维克多愁眉不展地老在想着这件事。

“不！”维克多非常坚决地摇摇头，“我要亲自把经过情形全部告诉斯维特里。”

“是吗？”安德烈不知所措地嘟哝着，“嗯，好吧！要是有人敢笑话你，我一定请他吃巴掌……”

“让他们笑去吧，反正……”

“不，我不让他们笑！”安德烈咕噜着。他凶狠地竖起眉毛，发起牛劲来了。

两个朋友一声不响地走了一阵……

“箱子现在让我来提吧，维克多……”安德烈说。

“不，不要紧。我自己来……”

“我来提一会吧？……”

维克多没有回答，他们又默默地向前走去……

“你可记得普晓河吗，维克多？”安德烈忽然说，接着低声而快乐地笑了，“真是条可爱的河！这儿就没有那样的河……”

“是的……”

“它现在该已经上冻了吧……”

“不，还早呢……”

“早什么？快上冻了……你不冷吗，维克多？如果冷……”

“不，没什么……”

“此刻我想起了普晓河，我真高兴……你还记得七年级甲组的那个弗罗霞吗？溜冰溜得真出色！”

“是的。”

“所有姑娘中要数她溜得最好。她只爱跟你一起溜……我们写一封信给她，你说好吗？”

“何必呢？”

“就是这样！我们活着，身体健康，想起了您……再有，您所认识的维克多和安德烈向您致矿工的敬礼……好吗？”

“她还会对你的矿工敬礼感到多大的兴趣！”

“那么又怎样？当然有兴趣。”

“她老以为我会当飞机师，”维克多冷笑了一声，“告诉你，我还跟她亲过一次嘴呢……”

“哦？！我倒不知道……”

“在一条小船上。可以说是很意外的……后来我们就上这儿来了。”

“矿工，矿工又怎样？”安德烈激动地说，“难道当矿工丢人吗？”

“我并没说……”

“矿工对于人们说来，恐怕比飞行员更加重要！”安德烈继续兴奋地说，“矿工把地下的太阳送到地上。你要知道，老弟，煤——这就是人类的太阳：它发光，发热，供给能源……”

“不错……”维克多想着心事，拖长声音说，接着苦笑了一声。“飞行员我没有当成，倒几乎做了……‘飞行家’了。”

“你别去想它了！”安德烈用恳求的神气喊道，甚至站住了，“作为一个朋友，我请求你：你别再去想它了！”

“怎么能不想呢，安德烈？”维克多简单而伤心地说。

“你别想！你相信我吧……维克多……现在你可以到矿井里去显显颜色了！不，你听我说，你不要跟我争辩，”他害怕朋友会打断他的话，赶紧说，“告诉你，我一看到风镐，真的马上就想到了你。要知道，风镐，那是一种什么机器啊！这种机器正配你的胃口。它需要灵活的人。要年纪轻，有文化，身强力壮。不，你等一等！……你听我说，在马丽雅矿还没有一个人用过风镐……没有一个人了解，除了列斯尼亚克叔叔之外。维克多，你可以去带头……你可以给他们瞧瞧颜色！……”

“你把风镐讲得详细一点……”维克多低声请求。

“讲吗？”安德烈高兴起来了，“这……这有些像机枪，你准会喜欢的……它的力量可了不起，难道手镐可以跟它比吗？它会咯咯地震动……因为里面有压缩空气……”

于是他就匆匆忙忙、结结巴巴地讲起风镐来了。

他们走到马丽雅矿，天已经亮了。他们在山坡上停下来休息，遥望下面的矿井。矿井不认得了。

夜里，村子里降了初霜，把大地万物装扮得光怪陆离。煤矿好像一个新娘，披上了一层轻纱，显得分外妩媚动人。霜盖着树木，盖着屋顶，盖着烟囱，盖着矸子山。年老的矸子山，看来好像积雪的厄尔布鲁士山<sup class="footnote-ref" id="note-ref-45-1"><a href="#note-45" aria-label="查看本页注释 45">[45]</a></sup>。

一轮旭日已经在井架之后露出来，它那快乐的光芒逍遥自在地照射着大地，使地面上的一切都变了样子。井口房沐浴在一片红光中；矿灯房的玻璃窗光辉夺目，发出斑斓的火花；盖霜的屋顶呈现玫瑰红和柠檬黄的色彩，而矸子山却紫得像熟透的樱桃。

在太阳光还没有射到的地方，一切都沉浸在黎明之前的青烟中。黑夜的阴影还在那里徘徊，挣扎，由峡谷和山坳里升起一团团的雾气……

不过，村子已经醒来了：公鸡喔喔啼着，百叶窗噼噼啪啪地打开来；住家烟囱里冒出来的最初几缕炊烟，在阳光的照耀下，变成喜气洋洋的玫瑰红。矿工们的铁公鸡——马丽雅矿的汽笛——突然叫了起来，好像在宣布白天已经光临，它的啼声响彻整个草原……

两个孩子仍旧站在山坡上，神往地眺望着下面玫瑰色的矿井。他们还不知道矿井竟会变得那么美丽动人。

不过，最美丽的要算矿井上的井架。在这个变幻莫测的美妙的黎明时分，唯有它始终保持本来面目，不需渲染，自成一格，傲然地显出自己钢铁的壮美。它那镂空的轮廓，清楚地浮雕在火红的天空中；它的滑轮稳稳当当地在高空转动，而钢缆却勤勤恳恳地一会儿上一会儿下，不知道什么叫疲劳，什么叫休息……井架的美在于它充分显示了人类建筑的朴素大方，这样的东西在自然界里是没有的。

“你瞧！”维克多突然激动地嘟哝着，“不，你瞧那个井架。看到吗？”

现在安德烈也看到了那件使维克多激动的东西：在井架上，在井架的顶上，一颗小星星又谦逊又骄傲地发出红色的光芒。这样说来，昨天矿井终于完成自己一昼夜的计划了。

“而我们却在跑！……”安德烈脱口而出。

“我们再也不跑了，”维克多一本正经地说，“我们再也不到别的地方去了，你听到吗，安德烈？”

“对，维克多……”

“再也不去了！”维克多又说了一遍，“此刻我们不能光带着耻辱回矿井。我们应该这样办。我们应该跟矿井订合同，直到五年计划结束。你听到吗，安德烈？我们要向所有的孩子们挑战。我们不再跑了。永远不跑了！”维克多眼睛望着矿井，又重复了一遍，他的话好像一篇宣誓。

# 十七

当我们那列火车终于到达顿巴斯的时候，东方已经发白了。我和同志们握别后，急急地跳下火车。现在我可回到老家了。

嗳，你好，顿巴斯，你好，亲爱的故乡！迎面吹来一阵寒冷彻骨的晨风。我冷笑一声：“你迎接你的儿子可不温柔哇！”

但在这阵真正顿尼茨草原的寒风里，也闻得到那种从小就熟识的焦煤、浓烟和生命的温暖气味；在冰天雪地里，这种气味即使不能温暖人的身体，也能温暖人的心灵。

我掮起行李袋，朝马丽雅矿走去。

我知道许多人认为顿尼茨草原是忧郁和贫瘠的，特别是在艾蒿枯萎、地面初冻的秋天。但在我看来，即使在秋天，世界上也没有比这片草原更美的地方了。这不仅因为我出生在这儿，对于它有乡土感情，实在因为我深切知道它的确具有引人入胜之处，为地面上任何其他地方所不及。

静静的乡村风景当然幽雅宜人，譬如说：前面流着一条从容不迫的小河，隔河展开一片金黄色的麦田，远处有小小的树林，再有一座黄昏时分钟声当当的钟楼。在这幅田园风光里洋溢着一种太平宁静的气氛。躺在河畔的沙滩上，瞧河水沿着曲折的两岸慢慢地流去，这是多么宁静啊！你会感到心旷神怡……你会觉得逍遥自在，有时心头还有一种甜蜜的淡淡的悲怆，你就不想离开这个地方……事实上还有什么地方更能吸引你呢？周围的一切都是早就熟悉的：一望无际的麦田，接着又是田地，静静的田地，树林间的草坪，以及坐落在峡谷或河岸之上的小村庄……

但我最欣赏的还是顿巴斯那种粗犷的景色，它好像专为爱好梦想的人们而设的。

此刻我站在草原中央的一条大路上，举目四顾，周围沸腾着一片蓬勃的生气。草原上处处都有人居住。在所有的小山上，在所有的悬崖和峡谷里，处处都看得到一种忙碌、陌生、难以理解的生活……在西边的小山之后冒烟的是什么东西呀？……好像一艘烟囱很多的大轮船……工厂吗？什么工厂？怎样建立起来的？那边——东方——青色的高山是怎么一回事？新的井架又是怎么一回事？那边有些什么呢？那边住着些什么人？他们是从哪儿来的？他们在干什么？什么事在使他们伤脑筋？他们要什么？他们爱什么？而那边，在南方，山上一座崭新的白石村显得多美啊！啊！我认得这个地方的。这不是斯丹金村吗？它什么时候变成城市的呀？

草原上每走一步都可以喜出望外地发现新的事物。地平线上的每缕轻烟都是一个新的谜，新的秘密。我真想游遍这片草原，走进草原上数不清的城市和村庄，拦住路上熙来攘往的陌生人，如饥似渴地向他们打听，询问，了解……因为地面上最有趣最美丽的就是——人。

人！我心爱顿尼茨的景色，正因为它是人类亲手造成的。不错，大自然欺侮人，欺侮我的故乡，它既不给它自由奔放的河流，也不给它扶疏苍翠的树林，或者芬芳甜美的青草。然而，人对自然的菲薄礼物却不肯就此甘心。他自己当家作主，在草原上造了森林、河流和高山。因此，在顿巴斯大家不说“灌木林”，而说“植树场”；不说“湖泊”，而说“水库”。就连这儿最大最美的一座树林——大阿拿多尔树林——也是人类双手造成的。

那些地平线上的青山不是天生的，也不是地质变化的产物。它们是人一铲一铲地从地底下挖出来的泥石堆成的金字塔。草原上的这片红光不是闪电，不是太阳；这是人从熔铁炉里放出来的熔液，气势汹汹地冲向半天高空。瞧，远方闪动着一朵蓝幽幽的火花，多么神秘，多么圣洁，多么美丽！不，这不是星星在天空流动，这是人，是一个电焊工在新的建筑工地上辛勤劳动。还有那边——你瞧，你瞧！——天上那座弯弯的彩桥是什么呀？不，那不是虹，也不是光辉夺目的彗星尾巴，更不是寒气逼人的北极光。那是烧得白热的煤饼从炉子里落下来，在炼焦场上碎裂后所放出来的七色光带——地面上没有比这更美丽雄壮、更光怪陆离的景象了！

整个草原都靠人的劳动生活，靠人的劳动呼吸。草原上灯光照耀如同白昼，天空中弥漫着蒸汽形成的朵朵白云；还有从千百只人手造成的烟囱里，飘出绵绵不绝、婀娜多姿的蓝烟。

不错，此刻顿尼茨草原发出来的不是青草的气味，不是紫苜蓿的甜香，而是人类健康的汗气。嗳，好哇！漂亮的气味！光荣呀，光荣归于劳动者，光荣归于他那双强大灵敏的手，光荣归于他那颗坚毅倔强的心！

我焦急不安地走近了马丽雅矿。再过一座山坡，前面就是村镇了。

山坡上，背着我站着两个青年，他们在眺望矿井。

“你们好哇。”我走到他们跟前，一面说，一面站住了。

他们斜着眼睛朝我望望，不乐意地回答：

“您好。”

“你们到马丽雅矿去吗？”

“是——的……”其中一个迟疑了一下说，“到马丽雅矿去。”

我发现他手里提着一只箱子。

“到矿上去工作吗？”我猜着说。

“不——不……我们是住在这儿的。”

我惊奇地望望箱子，接着又望望这两个青年。我发现他们有点窘。但我不便问他们，虽然心里很想弄个明白。

“好吧！”我快乐地说，“那么，我们是同路了！”

他们稍稍犹豫了一下，然后手里提箱子的那一个断然地说：

“我们走吧……”

于是我们就大踏步地并肩走去。

# 二

一个炎热的6月正午，两个好朋友沿着矿山的街道走着：一个叫维克多·阿勃罗西莫夫，一个叫安德烈·伏龙科。在1935年6月，他们两人的年纪加起来，已经有四十五岁了。

“你瞧，槐花也谢了！”维克多快乐地说，“朋友，我们该回企比略基了！”

每年春天，他们总要利用假期回企比略基一次。整个漫长的冬季，他们都等着这几天的假期，作着种种的幻想。他们想到回家，就很高兴，在故乡可以见到亲人，见到老同学，见到普晓河——那条在童年时代跟他们朝夕相处的静静的河。“我们的普晓河真美！”他们亲切地回想着，“是的，实在美得很！”但他们每次回企比略基去，总要恋恋不舍地向矿井告别，好像他们是航行到一个遥远的世界里去，航行到无忧无虑的童年世界里去一样……

可是，亲人们在一年年地老起来，童年时代的朋友先后离开企比略基，飞散到广大的世界里去了，他们认识的姑娘们都出嫁了，只有普晓河永远默默地流着，耐心地听着人们真情流露的自白和光怪陆离的梦想，并且把它们带走，直达海洋……普晓河真是条可爱的河！虽然如此，去年安德烈和维克多在企比略基却只待了一个星期，他们感到无聊，就回家去了。

回家去，现在的意思就是回到马丽雅矿去，回矿上去。归根结底，真正的家，不是人们休息的地方，而是人们劳动的地方。

现在，只有在马丽雅矿，他们才觉得是在家里，除此以外，就没有别的家了。他们的利益，他们的工作，他们真正的同志、对手和敌人，都在这里。这里人人认识他们。他们走在街上，不时跟过路的人点头致意，互相问好。他们已经是正式的矿工，采煤的好手。他们的相片早就挂在大门口的光荣榜上，而且由于风吹雨打而发黄了。

他们仍旧住在“奥尼辛叔叔的宿舍”里，不过两人合住一个房间。他们的一切东西都是共有的，要是其中一人想结婚的话，他们就很难分清财产：书籍、家具、器皿和唱机。

不过，他们还没想到结婚这回事。

“今年我想到休养地去一次……”安德烈若有所思地说，“到海滨去……”

维克多没有回答，只是笑了一笑。好吧！你要到海滨去，就到海滨去！他们只要高兴，哪儿都能去。他们只要说一声，休养证就会立刻给他们送来。但是，他们情愿自己出钱！昨天领到的工钱还原封不动地藏在口袋里；维克多以为他跟安德烈两人，买得起整个世界。

他们漫无目的地在街上走着，摇摇摆摆，既不像散步，又不像赶路。懒洋洋地跟过路的人们说着笑话，嘴里衔着烟卷，两手插在袋里，只用舌头随便把烟卷从一个嘴角推到另一个嘴角。

两人都穿着漂亮的藏青哔叽西装和没有领的衬衫，戴着漆皮遮阳的船长帽。事实上，他们何必要用那种扼紧喉咙的该死的硬领呢？他们在这儿，在矿山的街上，反正跟在家里一样。不论怎样人家总是认识他们的！矿山上没有一个姑娘不知道，维克多用的是什么领带。他爱用的领带是花花绿绿颜色鲜艳的——不是红底子上托着蓝色的斑点，就是鼻烟色上嵌着红色的星花。安德烈一向不用领带，他觉得结领带不舒服，他爱穿乌克兰式绣花衬衫。不过今天他也穿了一件没有领的衬衫，别着一枚晃来晃去的领扣。这种装束充分显出他们的潇洒，显出未婚的青年矿工的落拓：他们无拘无束，要怎样就怎样！

“瞧哪，好漂亮的新郎呀！”井旁一个上了年纪的女人在他们的后面说。

他们听了，哈哈大笑，笑声响得整条街都听见。

他们都是年富力强、无忧无虑的小伙子。他们隐隐约约地感到，他们的身体里沸腾着一股充沛的、生气勃勃的精力，他们无法把它在掌子里用光，因此觉得烦恼……他们有一种预感：他们的面前有一条广阔的路，有一个不平凡的命运。他们只是不知道，也无法想象，这是一条怎样的路，一个怎样的命运。每逢星期天和休假日，他们早上一醒来，就不知道该怎样处置自己，怎样处置自己巨人般的精力——这股精力像酵母一样在他们的身上发作，在他们的血管里汹涌澎湃。他们自己也不知道，一小时以后应该怎么办——去听演讲，还是去喝啤酒……但他们两人都希望，这天早晨能碰上一件极不平凡而又极美丽极崇高的事，因为他们的灵魂欢迎一切美丽和崇高的东西。

安德烈和维克多双手插在口袋里，在街上走着，一面走，一面微微地摇晃着身子。他们脚下的煤渣飒飒发响，他们口袋里的小银币叮当作声。天气很热，赤热的矸子山好像一只大炉子，向村子里送来一阵阵的热浪和刺鼻的硫磺气味：硫铁矿在矸子山上冒烟。

他们无意间踱到了市场上。市场特别热，几匹马在集体农庄的大车旁打瞌睡，迷迷糊糊地用尾巴拂走市场上肥大懒惰的苍蝇。售货员们热得懒洋洋，一声不响；买客也寥寥无几。时候已经到了中午，市场好像一堆篝火，开头很热烈，后来人们一走散，就听其熄灭下去。

孩子们懒散地在货摊的行列间踱来踱去，维克多又骄傲地认为他买得起任何东西，因此反而什么也不想买了。

“卖幸福啊！”忽然他们听到背后一个有气无力的喊声，回过头去，只见一个人，头上戴着一顶压瘪的绿色吉卜赛帽，帽边束着一条绳子代替绸带；他的肩上歇着一只愤怒的老鹦鹉。

“卖幸福啊！”戴绿帽子的人没精打采地又叫了一声，同时对两个青年矿工斜瞅了一下。这不是一个吉卜赛人，而是一个俄罗斯老人，长着一对善良而忧郁的眼睛，留着一口下垂的胡子，他的整个身体显得很干瘪龙钟，就跟他那只鹦鹉一样。

“您卖幸福吗？”维克多冷笑了一声，问。

“我卖，”带鹦鹉的人镇静地回答，仿佛他在卖火柴一样，“你们买吧。”

“我们要幸福干什么？”安德烈笑了起来。

“不，等一等！”维克多顽皮地眨了眨眼睛，打断了安德烈的话，“你等一等！您卖的是什么幸福呀？”他问算命人。

“鹦鹉抽出来，你们就知道了……”

“那您自己不知道吗？”

“我怎么能知道呢？”算命人耸了耸肩膀，“我没有办法知道。”

“这样说来，难道鹦鹉比您聪明吗？”

“鹦鹉吗？不！它是傻瓜。鸟儿怎会比人聪明呢？”他忽然生起气来了，“您说这话冒犯上帝。不作兴！”

“那您还相信上帝吗？”安德烈嘲笑地问。

“唔，不是上帝……自然……科学……全都一样！”算命人没精打采地解释说。他也被炎热和冷落下来的市场的那种凄凉弄得萎靡不振了。但也许只是由于饥饿的缘故。“幸福。命运。”

“有趣！”维克多哈哈大笑，“好吧，我们买五分钱幸福……”

算命人捉下了肩上的鹦鹉，把装有纸牌的小箱子放在它的前面。

“来，鹦鹉，好鹦鹉！”他亲切地对愤怒的鸟儿说，“把这位青年的幸福衔出来吧。”

鹦鹉恶狠狠地在箱子里啄了一下，衔出一张纸牌来。维克多念道：“君生逢黄道吉日，必有意外好运，然切忌绿眼睛与坏邻人。”

“原来如此！懂了，懂了！”维克多哈哈大笑。

“您也买吧，青年人！”算命人对安德烈说。

鹦鹉又怒气冲冲地啄了一下，衔出一张纸牌来。安德烈不由得激动起来，他打开黄色的纸牌，仿佛里面真的写着他今生的命运似的，念道：“君生逢黄道吉日，必有意外好运，然切忌绿眼睛与坏邻人。”

“这是怎么一回事？”安德烈生起气来，“大概纸牌张张都相同吧？”

“不……”算命人尴尬地嘟哝着，“有不同的……要看运气怎样……”

“咱们两人是同命呀！”维克多笑着叫道，同时在朋友的肩上拍了一下。

老实人安德烈这时火极了。他因为自己打开纸牌一刹那的激动而害臊，更因为那头傻鹦鹉和那个戴绿色吉卜赛帽的老骗子戏弄了他而生气。

“你那只鹦鹉是傻瓜！”他怒不可遏地说，“看你年纪虽老，原来是个骗子……干这种勾当，我要把你送民警局……”

算命人垂头丧气地听他骂，既不试图争辩，也不想逃走。大概他一生受过不少打击，涵养功夫很好。

“你不要生气，安德烈，等一等！”维克多说，“我很想把咱们两人的命运彻底弄个明白。整箱卖什么价钱？”他忽然问算命人说。

算命人手足无措地朝他望望：

“什么？！”

“你知道你是什么人吗？”维克多笑了笑说，“你是资本主义残余意识的活标本。懂不懂？对了！……但我想把你所有的纸牌统统买下来，所有的鸦片一下子……”

“要知道这儿各种各样的预言都有，不是全适合您的，”算命人讷讷地说，并且由于激动而脱下帽子，露出了灰白的秃头。“五个卢布！”他忽然说，脸涨得通红。“嗯，算三个卢布吧！……”他像鹦鹉鼓动翅膀似的挥了挥绿帽子。

维克多笑嘻嘻地给了他三个卢布，把所有的纸牌倒在自己的船长帽里。

“瞧吧！”他得意洋洋地说，摇摇盛着纸牌的帽子，“现在我要买卖幸福了。”

他傻头傻脑地向前走去，边走边喊：“卖幸福呀，卖幸福！”可是市场已经散了，没有人了；只有一辆迟到的马车逗留在广场上。车上一个年轻的农妇被喊声惊动，用手肘推推丈夫说：

“彼得罗，喂，彼得罗！你听到吗？在卖什么呀？说不定是我们用得到的东西？”

彼得罗只懒洋洋地摆摆手，回答说：

“不！那是鼓动！”他显然把维克多和安德烈当作文化宫里的工作人员了。

维克多又觉得无聊了。他还是不知道怎样和到哪儿去消磨这个假日的早晨。

“我们去喝杯啤酒吧？”他犹豫不决地提议。

“不。我不想喝，”安德烈回答，“我们还是到火车站去吧。好吗？”

“好吧！”

于是他们就向火车站走去了。

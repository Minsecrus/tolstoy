# 五

维克多的学生巴沙喜欢在同街朋友面前夸口。

“朋友们，你们知道我在跟谁工作吗？跟维克多·菲多罗维奇·阿勃罗西莫夫。哼，就是他！你们知道维克多叔叔怎样采煤吗？就像布琼尼<sup class="footnote-ref" id="note-ref-74-1"><a href="#note-74" aria-label="查看本页注释 74">[74]</a></sup>元帅舞动马刀一样！他的拳头可了不起啦！啊—啊！他的拳头好像活阎王，谁挨着它就得完蛋！矿上谁都怕他，但他谁也不怕，连老祖宗也不怕……我在跟他工作！”

在台阶里，他用充满敬爱的眼光，注视着老师工作。

“哎，维克多叔叔！”他钦佩地嘟哝着说，“哎，您采煤真了不起！……有一次我在杂技团里看斗剑，斗得可狠，但跟您比起来，还是差多了！”

维克多听说，笑了起来。他喜欢人家称赞他，即使是巴沙也好。此刻他觉得身体里真的洋溢着巨人般的精力。从前他梦想一人做两人的事，现在梦想实现了。他不但能够应付裕如地一班完成两个定额，而且要不是地位限制的话——他懊丧地想——他还可以达到更好的成绩。在这种台阶上工作，他已经觉得太挤了。短短的八米工作面，够他什么用呢？不到中午，他早已完工，已经找不到工作的地位了。

“怎么办呢，巴沙？”他关上风镐说，“万事大吉了？”他瞧着最后的几块煤落了下来，然后两手抱住头，伸了个懒腰，没精打采地说：

“那么我们来搭支架吧。”

他不爱搭支架。他认为这是木工的事，不应该叫采煤工做。妈的，他为什么要中途抛开风镐不用，而去顶板下搭支架呢？

他突然激动地说：

“我一个人就可以应付整个场子……”

他说这话时咬牙切齿，怒气冲冲，因为他那股没有用完的精力，正在他的身体里汹涌澎湃。一看到自己忠实的学生脸上露出怀疑的神气，他皱起了眉头。

“巴沙，你怎么，不相信吗？”他声色俱厉地问。

巴沙实在不相信。他可以相信一切，相信自己心目中的英雄能够完成任何奇迹，哪怕是最荒唐的。他可以相信维克多叔叔用一只左手就能打退一百名矿工。他可以相信在那遥远的、他自己连头都不敢伸过去的巷道里，维克多叔叔会遇到舒平，并且单独把他打败。不论怎样的神话，不论怎样的传说，可怜的巴沙都可以深信不疑。然而，他是一个小矿工，是矿工的后代，他无法相信维克多叔叔——即使是维克多叔叔！——一个人能够在一班的时间里应付整个场子——八十米。

他茫然不知所措地喃喃说：

“啊呀，维克多叔叔！……这是绝对办不到的……您真的要……”

“得了！”维克多严厉地打断了他的话，“搭吧！”此刻他又全心全意地钻在工作里了。

离开下班还有两个钟头，可是维克多在工作面上已经没有活可干了。

“嗳，巴沙，”他笑了笑说，“跟我这样的采煤工一起干活，是你的福气。现在你可以随便到地面上玩去了，这不是你的福气吗？我要到安德烈那儿去一下。”

他收拢工具，在一个袋子里藏好，然后爬到安德烈的台阶上去。安德烈还在搭支架。维克多一声不响，在旁边的煤上躺了下来。为什么他忽然觉得那么不开心呢？是由于无聊吗？

斧头发出叮叮的声音，这是安德烈在悬岩下敲板皮。安德烈的工作也快要做完，这样他们两人在场子里就都没有事可做了。他们就只好到地面上去。到地面上去也好，澡堂里不会拥挤，反正他们已经光荣地完成了一天的任务，并且还超过了定额。他们可以问心无愧地正视人们的眼睛……然而，此刻就到地面上去，总觉得有些不好意思！

“这能怪我们吗？”维克多心里想，好像在什么人的面前作着辩护似的，“你们应该多给我们一些余地！”

他仰天躺下来，自在地伸开了两臂。舒服！实在舒服！煤又凉快又潮湿，使人觉得好像夜里躺在浸过露水的草原上，或者普晓河畔的沙滩上……头上的顶板好像一片漆黑的天空，板皮上挂着的矿灯，仿佛远方的一颗星星。人总有一天会飞到星球上去的！要是维克多当了飞行员，他一定参加宇宙航行。目前还没有这样的飞行吧？但是，将来一定会有的！现在他是一个矿工，他努力的方向不是朝上，而是深入。要是打通一座矿井直达地心，那该多么有趣啊！……据说地心里全是熔岩。真好玩……将来总有一天，人类可以达到一切：不论星球，不论地心，或者十全十美的幸福。这恐怕要等到全世界实行共产主义的时候。“真不知道我和安德烈能不能活到那个时候？如果活不到全世界实行共产主义，至少也看得到共产主义的开始吧？”

“共产主义！”他叽里咕噜地说，“可是我们两人却有力没处用。平巷里到处泥泞……路也不修修好……”

“什么？”安德烈大声问道。

“没什么……我只是说着玩……”

不，最好还是不要去想这些个！“想它做什么呀？”他对自己生起气来，“我何必自寻烦恼呢？领导上不想，倒要我去想吗？……那又不是我的事！我是一个矿工，我还是想想矿工的本分吧，想想澡堂和牛肉菜汤吧……”然而，他的脑子里已经无法摆脱这个重要的问题了……

安德烈搭完了支架，恋恋不舍地把斧头放在一旁。

“唉！”他伸着懒腰说，“我才干得有些上劲呢……”

他工作起来不及维克多快，但也觉得工作面太小了。他也很容易做满一个半到两个定额，等身体碰到“边”而不得不结束工作，离开下班往往还有很多时间。

“我们上去呢，还是怎么样？”他一面犹豫不决地问，一面动手收拾工具。他也有一只像维克多那样的袋子。这都是薇拉缝了送给他们的。每次收拾工具，安德烈总要记起薇拉来，并且觉得很烦恼。“她为什么老是缠着我？教我怎么办呢？”但他并没有把袋子抛掉。

“上去呢，还是怎么样？”他又问了一遍。

“上去也行……”维克多停了一会儿回答，“嗳，安德烈，”他出其不意地说，“你想你一个人能在一班之内对付整个场子吗？”

“一个人？”安德烈大吃一惊，“那当然办不到……”

“不，你慢着！你听我说！……譬如说，木材都预先送到，预先在工作面上放好，空气充足，一切都准备妥当，那么你一个人对付得了吗？……”

安德烈稍微想了想。

“不行！”他摇摇头说，“办不到！”他笑了起来，“嗳，维克多，你真喜欢胡思乱想！……”接着他用平常的声调问道：“我们要不要等组长呢？……”

这时组长马基楚克正巧走了来。

“已经干完了吗？”他照例作出惊奇的样子问。他那副吃惊的样子、装腔作势的微笑，以及无聊的玩笑，都说明他这个人很虚伪，很卑鄙。

他开始计算他们的生产成绩。

“英雄，真是英雄！”他一面喊，一面把成绩记在一本漆布面的簿子里。“小伙子，你们要那么多钱干么呀？你们又不喝酒，是吗？”

“你与其为我们的钱操心，不如把我们的工作面放长些，”维克多气愤地说，“你瞧：我们没有发展的余地！……”

“如果再多给你们工作面，国家银行的钱要不够付你们两人的工资了，”组长开玩笑说，“难道你们还嫌钱少吗？”

“钱，钱……”维克多叽里咕噜地说，“你心里就只有一个钱……难道世界上没有比钱更重要的东西了吗？……”

“照你说又怎样呢？”这一次马基楚克真的感到惊奇了，“钱就是一切！”

他怀疑地望望孩子们，叹了一口气。他早就想提出跟他们“合作”：他替他们虚报采煤的成绩，而把拿到的钱平均分摊。他们是突击工作者，因此多报吨把煤，谁也不会怀疑。但他始终不敢下决心。“他妈的，他们是党员。死心塌地的。说不定还会去告发呢！”他又叹了一口气，默默地爬出台阶。

维克多目送他走开去。

“钱！”他吐了一口唾沫，痛苦地说，“你为矿井鞠躬尽瘁，人家却说你想挣大钱。”

“他原来是个彼得留拉<sup class="footnote-ref" id="note-ref-75-1"><a href="#note-75" aria-label="查看本页注释 75">[75]</a></sup>匪徒，你要他怎样？”

“那为什么要把这种家伙留在矿上呢？难道矿上也有他们的位置吗？……”

他们爬到平巷里，遇见列斯尼亚克叔叔。他已经升任采煤区长了。

“啊——啊！”老头儿快乐地招呼他们，“已经干完了吗？真了不起！……要是个个矿工都像你们这样就好了！他们差远了！……如今还有人连一个定额都采不满。”

“请他们滚蛋得了！”维克多说，“不过您要给安德烈和我每人两个台阶。我们能够应付。”

“好……好……我也在那么想呢……你们是两个快手！”他慈爱地瞧着这两个雄赳赳的小伙子说，“不久以前，你们还像没开眼的小猫那样在矿井里乱钻，记得吗？维克多，据说你在澡堂里也弄得最快。是真的吗？”

“是真的！列斯尼亚克叔叔，我手臂很长<sup class="footnote-ref" id="note-ref-76-1"><a href="#note-76" aria-label="查看本页注释 76">[76]</a></sup>……”

“什么话！”老头儿惊奇地说。

“那么您答应给我们两个台阶吗？”

“我想还是让你们做些掘进工作吧？我们在那方面落后了。这条平巷真弄得我苦透了。”

“我们又不是掘进工！您在掌子里多给我们一些地位吧！”

“您瞧，他们总是要求比人家多，”马基楚克走到跟前，挖苦说，“他们永远贪心不足！何必那么贪心呢？真奇怪！”

“我们不是‘粮票骗子’！”维克多骄傲地回答，“我们的那种贪心，你是无法了解的。”

“你看他们！”组长哼着鼻子说。

“不错，就是这样的！”

“粮票骗子”这个名词，在马丽雅矿实行配给制的时期，是指那些只为了粮票才勉强做满最低定额的懒汉。他们认为不必多做，因为不论工作成绩怎样，都会记录下来，他们就可以像一般工人那样领到粮票。何况凭票购买又不需要很多钱！后来，矿山上有了商店，“粮票骗子”就稍微起劲一些了。他们开始多挖一些煤，同时说明道：“我这是为了要买一瓶烧酒，这是为了要买一些香肠！”不过，维克多在那时采煤，既不是为了配给票，也不是为了钱。

“贪心不足！”他一面习惯地在黑暗中走着，一面叽里咕噜地说。“有些人就是那样曲解突击工作者的……”

“我女儿回来了！”列斯尼亚克叔叔出其不意地说，“是的，达莎回来了！”

“我们已经见到她了！”安德烈脱口而出。

“是吗？对了，对了……她说过的。你们晚上到我家去好吗？”列斯尼亚克叔叔邀请着，“瞧瞧我们的莫斯科大学生！”

“好的，”维克多漫不经心地回答，“我们会去的……”

他们跟老头儿说声“再见”，就到地面上去了。澡堂里真的还空空的没有一个人……

晚上，安德烈像是无意地问维克多说：

“那么……我们不去看看列斯尼亚克叔叔吗？”他不敢说去看看达莎。

“不，他的女儿没意思！”维克多说，“神气活现……”

“怎么神气活现？”安德烈生气地问。

“因为……她有些自命不凡。我最讨厌这种人！我不能让一个姑娘来调派我。我，老实说，喜欢指挥人家。”

“为什么？”安德烈低声地问。

“不为什么！”维克多不明白安德烈的意思，“就是这样！你是个女孩子，就得像个女孩子；你是个男子汉，就得像个男子汉。这是我的看法。我爱温柔、文静的姑娘。你呢？”

“我不知道……”安德烈迟疑了一下回答。

那天晚上，他们就没有到列斯尼亚克叔叔家去。

# 六

他们两人留在宿舍里，躺在床上，无聊得很。因此连薇拉来看他们，也使他们感到高兴。她先是怯生生地敲了敲门，然后伸进头来，朝房间里望了一眼。

“我马上要走的！”她一进来就说，脸涨得通红，“你们还没有睡觉吧？对不起，打扰了。聂谢烈特尼同志叫我提醒你们一声，明天要开生产会议……”可怜的姑娘越来越想不出来看他们的新的借口了。

“进来吧，薇拉！”维克多亲热地说，“没关系，没关系，您进来吧。今天他不会咬人的。”

她踏进房间，坐在一只离门最近的椅子边上，准备随时拔脚逃走。她偷眼望望安德烈：还好，他没有生气。她稍微宽了心，嫣然一笑。她的笑容很明朗，平静，快乐。她爱微笑，但不会放声大笑。

为什么安德烈不喜欢她呢？她是一个白净可爱的姑娘，雪白的面孔嵌着一双淡褐色的眼睛，非常引人注意。但除了眼睛之外，就没有什么特色了。她的身体圆滚滚、软绵绵，甚至稍微有些臃肿……将来年纪大一些，一定会长得很丰满。她虽不能算美，但很大方。她的身上有一种可爱的香皂的气味。

她的服装没有一点鲜艳夺目的色彩，身上也不佩带一件漂亮的装饰品：蝴蝶结、缎带、鲜花，一样也没有。矿井里的女共青团员，个个都用一块大红三角围巾包头，只有她老是用一条白色的方头巾。金黄色的头发，包着一条白色的头巾，身上穿着一件朴素的白上衣，围着一条麻布裙子，她的样子很像一朵野生的甘菊。

人们在她旁边走过，也许不会注意到她，但如果一发现，一定会朝她微笑，因为她是那么善良，那么可爱。她待人诚恳，就像向日葵对待太阳一般。女人们喜欢她，老太婆可怜她，上了年纪的矿工都叫她“女儿”。

可是，在青年男子之间，她却不被人注意。她既不是一个调皮淘气的少女，也不是一个嘻嘻哈哈的姑娘，更不是一个活泼好动的女人；她的性格不浪漫放纵，不冒失粗鲁。她也不是一个无声的漩涡，会默默地俘虏男孩子的心。总之，她心里没有一点隐蔽黑暗、暧昧不明的东西。她对任何人都落落大方，开诚相见。她那姑娘时代的内心世界，光明磊落，纯洁无瑕。

她很早就为丧偶的父亲管理家务，而且充分显出女性的贤惠和矿工女儿的乐观。她整天劳动不息，不是在办公室里，就是在家里——一会儿在厨房里，一会儿在菜园里。当没有人在旁边时，她就低声唱歌。

晚上，她给父亲读报，很有耐心地听他对国际问题发表议论，并且听得津津有味。她熟悉矿井里的各种事情，虽然从没有在地下做过工作，甚至没有下过一次井。她也像矿山上所有的人那样，非常关心采煤的成绩，听到计划没有实现，就愁眉不展，看到井架上的红星，就兴高采烈。她是矿工的女儿，将来一定是个矿工的好妻子。可是，安德烈却不爱她，并且害怕她的爱情。

“嗳，怎么样，女儿，办公室工作忙吗？”当薇拉在椅子边上坐下时，维克多快乐地问。他老叫她女儿。他对她非常亲热和气，就像对待一个小姑娘一样；他同情这个文静善良的女孩子，而她对安德烈的那片痴情，使他觉得很有趣。

“办公室工作很忙，小职员简直喘不过气来！”薇拉照例那么回答。过了一会儿，他们两人已经在低低地、津津有味地聊着天了。

安德烈一声不响地躺在床上，翻弄着一本书。他一点不想触动薇拉的感情。要不是她一片痴情，此刻他也会像维克多那样跟她推心置腹地聊聊天了。可是这份恼人的爱情却使他拘束，苦闷，尤其是现在。听着薇拉低低的、几乎有些重浊的声音，他不禁想起另外一个响亮、快乐、大胆的声音来，他后悔他跟维克多没有到列斯尼亚克叔叔家去作客，没有到他那座白屋顶的宁静而幸福的小房子里去。

奥尼辛叔叔也闯了进来，他总是不敲门的。

“有电吗？”他一本正经地问，表示他不是无缘无故来的，接着不等回答，就一屁股坐了下来。

他仍旧在当宿舍管理员，不过已经习惯于这项工作，做起来很胜任愉快了。他的宿舍仍旧不断地有人进进出出，但他也已经看惯这种经常的人事变动。如果宿舍里平静无事，他反而会感到寂寞无聊。他仍旧给新来的矿工讲述各种逸事和神话，灌输许多忠告和教训。对不少年轻的矿工说来，奥尼辛叔叔的讲话，就是矿工大学的第一课。“我们全念完奥尼辛叔叔的学院！”斯维特里常常说。

安德烈和维克多是这所“学院”的光荣，是奥尼辛叔叔心底里的骄傲。他确实认为他们是他一手培养出来的。他以那种孤老头儿容易妒忌的感情爱着他们，但没有把这种感情流露出来。有时他想用自己的一套老办法去教他们，可是突然省悟，现在已经没有这种必要了。事实上，他还有什么东西可以教他们的呢？时代不同了，矿井不同了。现在该轮到他去向青年学习了。但他不愿认输，仍旧自命不凡。他不像别的老顽固，否定机械化，否定矿井里的革新，他只是不承认青年一代是革新者，而硬把这种改革归功于自己，归功于自己的一代。

“这我们从前也有的！”他常常说，“不是你们想出来的，也不会在你们手里结束！”

“难道从前也有电车吗？”维克多天真地问。

“电车算得了什么？呸！……难道电也是你们发明的吗？再好的东西我们也有过！……”

“什么东西？……”

“这些东西，”老头儿生起气来，“你是不会晓得的！老实对你说吧，从前我们酒店里就有一种机器，自动的，会唱戏。庙会上还可以看到一种机器姑娘……连华尔兹舞都会跳……”

“那是不可能的！”维克多高声叫道，同时忍不住哈哈大笑……

这种争论，奥尼辛叔叔一来就要发生，仿佛两代矿工都要举行一次友谊性的竞赛，老的一代想证明他们依旧年轻有为，新的一代想显示他们已经经验丰富。

此刻也展开了这样的争论。不过，今天奥尼辛叔叔走来时，已经全副武装好了，因为大家看到，他的眼睛闪耀着大胆和青春的光芒。

“嗯，”他好像并非有心地说，“我倒想问一声：割煤机现在还在用吗？……”

“在缓斜的煤层上用的……怎么样？……”

“真的吗？”老头儿惊奇地问，同时眯细眼睛，不断地摇着头，“啊呀呀！原来如此！……我还以为你们又发明什么新东西了呢……”

“难道这是老东西吗？”

“怎么不老……还是我们从前发明的呢。”

“你们从前有过什么割煤机呀？”维克多轻视地说，已经有些生气了，“恐怕是木头做的吧？”

“为什么？是真正的割煤机。跟现在用的一样，”奥尼辛叔叔镇静地回答，显出得意洋洋的神气，“好吧，让我来告诉你们一件实在的事吧。你们听好！……”他对所有的人说，接着舔舔胡髭，又用手擦了擦。“这件事发生在1921年。当时我们的矿长是……”

“叶果尔·特罗斐莫维奇。”安德烈接口说。

“你怎么知道的？”奥尼辛叔叔惊奇地问。

“您的故事都是这样开始的……”

“真的吗？”老头儿不好意思地问。接着想了好一阵，才笑嘻嘻地解释道：“那是因为我跟你们讲的，总是实实在在的事情。你们听好……就是如此……那年春天，矿工们都没有下井去。大家都不去！叶果尔·特罗斐莫维奇就问我说：‘嗨，奥尼辛，他们那批家伙怎么都不下井去呀？’我说：‘叶果尔·特罗斐莫维奇，因为春天到了，大家都到菜园里种菜去了。’——‘种菜？他们都是矿工，怎么还要去翻土呢？’原来那年春天闹饥荒，粮食非常缺乏。于是老百姓就自己想法子，种起蔬菜来了。对了……可是矿井里的计划就无法实现。当时领导上开动脑筋，想出了一个聪明的办法。他们说：‘好吧，我们先花三天工夫来翻种他们的菜园，然后让他们下井去安心工作。’这样菜园就翻好了！你以为用什么东西翻的呢？”他眯紧了左眼。

“大概是拖拉机吧……”

“嗤！”老头儿笑了起来，“当时根本不知道拖拉机是什么。”他沉默了一会儿，突然拍拍膝盖，像皮球一样跳了起来，心花怒放地叫道：“用割煤机翻的！你听到吗？用割煤机！……”

“怎么用割煤机？”维克多觉得很奇怪。

“用过的。他们不知从哪儿弄来几台割煤机……马马虎虎的……当时都是那样的……他们把这些机器修了修，装上犁，就拿去翻土！”

“这是不可能的！”安德烈笑着叫道，“用割煤机，怎么行？”

这时，门忽然砰的一声推了开来，一个穿灰色雨衣、帽子拉得很低的高个子，在门口出现了。他的出现那么突如其来，那么出人意外，吓得薇拉大叫一声，连忙用双手蒙住了脸，好像房间里飞进来一只硕大无朋的野鸟。

“啊呀！”维克多也大吃一惊，叫了起来，“斯维特里！这是你吗？”

“不，不是我，”斯维特里一面镇静地回答，一面把皮箱放在地板上，“您好，奥尼辛叔叔！你们还在这儿吗？”他脱下雨衣，把它挂在门后的钉子上。“奥尼辛叔叔，现在你也该装些衣架了！”

“瞧吧！我们的批评家又回来了！”管宿舍的老头笑了起来，“让我们看看，你变得怎样了？”他轻轻地拉他转了一个身，又把他推开了。“一把骨头一层皮！你是回来休养的吧？”

“不。是回来实习的。”

这次意外的重逢，使他们很高兴，很感动，但他们并没有亲吻，也没有拥抱，甚至没有热烈地大声叫喊，仿佛他们不是久别重逢。一个矿工，不论遇到快乐，危险，或者死亡，除了说说粗鲁的笑话，不轻易暴露自己的感情。

斯维特里一来，薇拉觉得很不自在，想不知不觉地溜走：她怕她会妨碍他们。她悄悄走到门口，但奥尼辛叔叔立刻把她叫住了。

“喂，不要走！站住，女儿！……还有事情呢。”他向大家回过头去，庄严地下着命令，仿佛他不是宿舍管理员，而是卫戍司令。这五年来，老头儿已经用惯自己的“权力”了。“小伙子们，我现在命令你们：大家好好地坐在位置上等着。我们马上就来！喂，女儿，跟我来，开步走！”他大声说着，走了出去。

“老头儿仍旧那么清健！”斯维特里等他走后笑着说，“他有没有把臭虫肃清了？”斯维特里在安德烈的床上坐了下来，安德烈觉得他们好像没有分过手。他们原来的团组长又跟他们在一起了。他恐怕又会声色俱厉地问：“同志，你的定额怎样？完成了吗？”但安德烈现在不再害怕这个问题了！

可是斯维特里却问道：

“朋友们，你们还在这儿吗？”

“我们又会上哪儿去呢？”

“我以为你们变得聪明些了。也去学习了。”

“不能大家都去学习呀！”维克多嘲弄地说，“总得有些人采煤呀。斯维特里，你可真的变成知识分子了。瞧你多娇弱呀！还没有戴眼镜吗？大帽<sup class="footnote-ref" id="note-ref-77-1"><a href="#note-77" aria-label="查看本页注释 77">[77]</a></sup>呢？”

“你自己才是木头！我第三十次问你：你为什么不去学习？”

“我们不配！生得太笨！”

“我们其实也在学习，”安德烈插嘴说，“何必说这种废话？我们在技术专科夜校念书呢。”

“噢——噢！到底变得聪明些了，”斯维特里快活地说，“好，现在你们讲些生活和工作的情形给我听吧……”

奥尼辛叔叔和薇拉回来了。他们拿来了酒和点心。奥尼辛叔叔立刻在桌子旁边忙碌起来，“喂，薇拉，女儿！”他下着命令，“拿块干净的台布来！拿一些花来！贵客来啦！稀客临门啦！”他亲切地瞧瞧斯维特里，拍了一下手。“瞧吧！到底回来了！”他大声地说，似乎直到现在才明白斯维特里已经回来了。“啊？回到矿里来了！嗳，我的宝贝！……”

“我又会上哪儿去呢，奥尼辛叔叔？”斯维特里笑了起来。

“对了！没地方去！嗳，聪明人，你的话可真中听呀！孩子们，我们是一步也离不开矿井的！她是我们的奶妈，她是我们的亲娘。”他用惯常的急促语气说，不过他的声音却变得非常恭敬和亲热，他每次讲到矿井总是充满敬爱之情的。“孩子们，让我们来为‘她’干一杯！”他要求道，“诚心诚意地干一杯！”

他们碰了杯，一饮而尽，并且给薇拉也斟了一杯酒，她马上脸红耳赤，但不敢推辞，就抿了一口。

“嗯，现在斯大林诺市怎样了？热闹吗？”奥尼辛叔叔一面问，一面闻闻黑面包皮，“我记得它从前叫尤索夫卡……”

“尤索夫卡你可要不认得了，奥尼辛叔叔！它已经不是尤索夫卡，而是一个大都市了！”

“真的吗？有意思！……人在一年年老起来，而城市却在年轻起来，这是怎么一回事呀？”他笑了起来。

“你们这儿的情况怎样呀？”接着轮到斯维特里问了，“听说我们的马丽雅矿神气得很！”

“怎么不是！”奥尼辛叔叔叫了起来，“现在我们井架上的红星永不熄灭了！”

“神气！怕是雷声大雨点小吧。”维克多一面说，一面拿起一条黄瓜，把它切成两半，蘸了一层厚厚的盐。“就是这么神气！”他气愤地又说了一遍。

斯维特里仔细向他瞧瞧。他们几年没有见面了呀？四年。据说，老朋友重逢，总是首先找寻对方原有的可爱特征。但这种说法是不正确的。相逢时的第一眼，往往是尖锐而含有疑问的：我这个朋友身上有些什么新东西？他还是我的朋友吗？要过一会之后，才能在他的身上高兴或者惋惜地认出原来的特征来。

斯维特里整个晚上用挑剔的眼光打量着维克多和安德烈。他眯细眼睛，用两只瘦长的手臂抱住一个膝盖，微微地摇晃着身子，看着和听着他面前的两个朋友，怎样慢吞吞地、像是很勉强地显露出他们的面目来。但他并不性急，没有设法去催促他们。他认出他所喜欢的维克多的天生的热情和急躁，也认出他所熟悉的安德烈那种不形于色的顽强，以及好玩地覆在他那固执的额角上的乱蓬蓬的额发！……他又像认得他们，又像不认得他们。他们长得多大了呀！他们已经不是五年前那两个怯生生的孩子了，连走路也变得稳健了。他们重重地踏着地板，弄得奥尼辛叔叔那所破旧的宿舍里充满吱吱咯咯的声音。他们的眼睛也变了：那种稚气的惊奇消失了，出现了一种老成持重的神气。这是不足为奇的——在矿灯朦胧的掌子里过了五年，不论怎样的眼睛都会变得像猫头鹰一样尖锐。是的，他们长大了，长大了！变成大人了！而且，一定也变得聪明了，是吗？……

“维克多认为我们的矿井，可以获得更好的成绩。”安德烈一面在房间里踱来踱去，一面慢吞吞地解释。接着，他突然在斯维特里面前站住了，诉起苦来：“我们的工作面太小了……”

“工作时只能发挥一半力气！你懂吗，斯维特里？”维克多插嘴说。

“工作的台阶很短，只有八米，够什么用呢？转身的地方都没有，再加空气又不足……”安德烈继续诉苦说。

“等一等，安德烈！让我来给他解释！……”

薇拉轻轻地从桌子旁边溜了开去。她不愿走开，但又怕妨碍老朋友们的重逢，妨碍他们的谈话。结果她还是没有走，只是悄悄地在安德烈床畔的椅子上坐了下来，动手做自己的事：给安德烈补工作服。孩子们在吵些什么，她没有用心去听。男人们争论他们的事——男人家的事，而她干她的活——女人家的活。她觉得很称心！但愿永远如此！

斯维特里对维克多所讲的很感兴趣。他不再嘲弄地眯细眼睛，而且收起笑容，皱紧眉头，留神地听着，不插一句话。他忽然很羡慕起孩子们来。从他们所讲的话里，闻得到他所熟悉的那种生活和矿井的气味。而这四年来，他却像小学生那样，老坐在课桌旁！

他站起身来说：“孩子们，你们为什么不想办法呀？诉苦有什么用呢？应该打破它！”

“打破什么呀？”维克多弄不懂了。

“打破一切！旧的秩序。旧的成见。旧的定额和劳动条件。把一切都打得干干净净！”

“嗳——嗳！你呀，小伙子，小心点，守些本分！”奥尼辛叔叔发出忠告了。他不爱听这一类话。

斯维特里笑了起来：

“不，不……我们没有任何顾忌！我们要照矿工的做法：彻底干净。消灭一切旧东西！”现在他想一面刺激奥尼辛叔叔，一面鼓励孩子们。事情巧得很！他回到这儿来实习，正巧遇到斗争的最紧张关头。又是斗争——好极了！这是新旧之间永不休止的斗争。这是一种可爱的自然现象。他想，要是没有这种充满火药味的紧张的战斗气氛，他实在无法生活。

他问道：“那么，小伙子，你们没有拿自己的意思跟人家讲过吗？”

“没有……跟谁去讲呀？”维克多摆了摆手。

“可惜。你们的采煤区长是谁呀？”

“列斯尼亚克叔叔。”安德烈回答。

“啊——啊！很好。他是一个聪明人，胆子又大。矿长仍旧是老祖宗吗？”

“老祖宗。又能是谁呢？”

“那么总工程师是谁呢？”斯维特里觉得已经置身在战场上了。他必须知道武力的配备，知道炮兵、后方和后备军的情况。他应该估计到可能遭到的敌人和不期而遇的朋友。“那么党组长是谁呢？”他又问。

“聂察英科……”

“新的，我不认识……是矿工出身的吗？能力怎样？跟老祖宗合得来吗？斗争性强吗？”

安德烈没有立刻回答。他从没想到过，党组长是个怎样的人物？他也从没想到过老祖宗、矿井总工程师和联合企业的经理：他们又是些怎样的人物？

“聂察英科吗？”他若有所思地反问，“他是一个好人……”

“‘好人’，这不是党员对人所用的评价……”斯维特里笑了起来。

安德烈又稍微想了想，然后摇摇头。

“不，”他说，“既然是好人，就一定是同志。”

# 七

从前安德烈认为矿井也像世界一样，安排得很理想，矿井里的秩序也完善无缺，千古不变。现在他才知道，不论矿井，不论世界，一切都在改变，而且应该向好的方面改变。这是生活的规律，运动的法则。

这些改变总是人类促成的。有些人终日忙碌，不知疲劳，永远不会满意，从来不知满足，渴望变更和改造一切，他们就是革命家、革新家或者先进分子。可惜安德烈还不觉得自己就是那种人，但他很想做个这样的人。

在那个炎热的夏天里，两个好朋友初次感到这种伟大的烦恼。以前他们的生活，好像一条静静的流水，从一块石头流到另一块，过了一天又一天；他们满足于这种平静的生活，不想去把它改变。

但现在他们却开始觉得河道太狭了。好像春天里的河流，由于春潮的灌注，突然向平原泛滥，一泻千里，我们的两个孩子，也觉得有股莫名其妙的春潮般的力量、愿望和热情，在他们的身体里冲动，他们每条脉管里的热血，仿佛也在汹涌澎湃……不过，使维克多感到烦恼的，主要是体力过剩——他无法把自己的全部体力消耗在掌子里，在散步上，或者在矿工街的疯狂舞蹈上——而在安德烈身上觉醒并且雄赳赳地出现的，却是一种精神的力量。斯维特里的归来，只是促进他们的成熟，好像一场春雨加速了小麦的生长。

维克多只想望一件事：但愿把整个采煤场子都让给他，使他随心所欲地干一番，显显身手。他要创造一项像伊索托夫那样的新纪录！他相信自己的力量、自己的技巧、自己做矿工的幸运。

不过，安德烈认为维克多的企图只是一种大胆的梦想。“如果场子是直的，就可以通行无阻！”安德烈考虑着，“否则像现在那样分成八个台阶，就得截八次角，钻八趟狗洞……而且再要给整个场子搭支架……偶然创造一项新纪录，出一次风头是可以的！但要天天如此，就办不到了。这样看来，”他继续想，“光靠蛮劲是不够的。还得动脑筋。如果把采煤场子拉直怎么样呢？如果重新调整采煤工的劳动怎么样呢？如果彻底改变矿井里的秩序又会怎么样呢？”

近来，安德烈不论在掌子里，还是在家里，常常想着这些问题。他自己也不觉得，这些问题已经成了他生活中的大事。他知道维克多、斯维特里、列斯尼亚克叔叔和达莎——他们已经把自己的思想告诉她了——以致全国的矿工，都在想着这些问题。考虑这些问题，现在已经是时候了。

晚上，在列斯尼亚克叔叔安静的小房子里，常常发生长久的争论。

维克多暴躁地叫道：

“老是争论有什么用？你们把整个场子交给我，我用实际工作来证明！列斯尼亚克叔叔，您是采煤区长，问题在您身上……”

可是老头儿只怀疑地摇摇头：“嗳，办不到，小伙子！嗳，你会丢脸的！……”

“我？我吗？……”维克多气呼呼地问，“您说我……”他气得话也说不上来，只是激动地向周围环顾着：难道真的没有一个人，没有一个人相信他，相信他的双手，相信他的能力吗？

奇怪得很，支持他的只有达莎一人。只有她相信他。可是维克多偏不喜欢她的支持。他总是不相信她，怕她的支持会突然变成一种嘲弄。

事实上，达莎倒是真正相信他的。不过，她所相信的，不是维克多本人——她对他仍旧抱着一种嘲弄的态度——而是维克多的思想。她已经能够想象那种情景：一条长得没有尽头的采煤场子……好像一片大草原……场子里煤的闪光，好像阳光下的露珠……在这自由天地里，一个英俊的好青年——也许就是维克多，也许是别人，不过这在她都是一样的——独自一人在大胆地刨煤，好像歌谣中的割草人……只听到一片铿铿锵锵的声音。多么有趣！多么富有诗意！她真愿自己也去创造纪录，如果他们答应她的话……

唉，为什么她生来不是个男孩子呢？如果是男孩子，她一定会成个了不起的矿工！她实在爱矿井，虽然她的几个莫斯科朋友无法理解这一层。他们不懂，怎么会有人爱好地下的世界；她奇怪，怎么会有人不爱……

她是在苏联的矿井里长大的，因此不知道世界上还有别种矿井。她从来不觉得开矿是一种苦工。矿井就是她的第二个家，那个家起初虽然有些神秘，后来却变得很可爱；她的父亲、叔叔和邻居们，就都在这个温暖甜蜜的老家里生活和工作。小时候，她爱在沙泥里挖洞，跟男孩子们一起做“矿井”。后来她去工作，也怀着这种有趣的心情。她被派去管矿灯，觉得很高兴。她喜欢像光明使者那样，提着矿工们所期待的矿灯，去到黑暗的掌子里。她喜欢矿工们叫她“萤火虫”。她喜欢矿井里的一切：低低的拱门、潺潺的地下水、嗞嗞的融雪声、新鲜空气流入时形成的一股疾风，还有最主要的，就是由人行道、横坑道和风巷组成的神秘的迷宫——她已经习惯在这座迷宫里大胆地走来走去了。她什么也不怕。在很小的时候，当一般孩子往往还分不清神话和现实的界线时，她已经知道，矿井里既没有妖魔鬼怪，也没有地神风神，只有当点炮工的斯吉邦叔叔和当打眼工的特罗斐姆叔叔。在地面上，特罗斐姆叔叔和斯吉邦叔叔都是文静善良的邻居。但一到矿井里，他们也像她父亲那样，成了三头六臂的巨人了。达莎明白，他们就是真正的魔法师，平常都很和气，只有偶然多喝了些酒，才显得有些可怕。

后来达莎长大了，也下井去工作，最后又到矿专去学习。如今，矿井里每条神秘的巷道，每个秘密的角落，她都叫得出它们的名称，就连矿井里的空气、呼吸、蒸汽和瓦斯，她都能轻易地作出正确的公式来。然而，童年时代对待矿井的诗意态度，却像对神话一般，依旧保留着！看到达莎健美的身体和脚上的马靴，很难使人联想到这一层。达莎从小就被认为是淘气鬼，胆子大得像男孩子。她口齿伶俐，手脚敏捷，会像赶车工一样吹口哨，在男孩子面前不肯认输，常常玩得不是满身乌青肿块，就是头破血流。

“你怕什么呀，爸爸？”此刻她大胆地向父亲进攻，仿佛维克多能不能创造纪录，关键完全在他一人身上，“啊呀，爸爸……你怎么这样拿不定主意啊……”

“你不要性急，不要性急！”列斯尼亚克叔叔皱起了眉头说，“这关你什么事？人家在谈正经事，你还是不要插嘴好。”他嘴里虽然这么说，心里却很高兴，因为女儿也在关心矿工的事。不错，她怎么可以袖手旁观、置身事外呢？她是未来的工程师。我的女儿！……他得意洋洋地看了一眼女儿健美的身体。

她了解这一层，不肯罢休。

“我认为，”她大声叫道（这时安德烈已经忘了世界上的一切，大胆地盯着她看），“我认为这是完全可能的。不但维克多能够创造纪录，别人也有可能。譬如说米佳吧……或者安德烈。你能吗，安德烈？……”

他几乎没有听到她的问话。他全神贯注地在欣赏她，欣赏她那张由于争论而涨得通红的果敢的脸。“她多美啊！世界上没有比她更美的人了！”他说不出她哪一部分长得特别美：眼睛还是嘴唇，因为他不是分开来看她身上的个别部分，他爱她的（他已经爱上她了，虽然还不愿向任何人承认），既不是眼睛，也不是嘴唇，而是她整个的人！在这份爱情里，还没有什么愿望或者激情，只有一种不平凡的恭敬而胆怯的柔情，但即使这样的柔情，也已经弄得安德烈神魂颠倒了。

达莎却在等他的回答。

“你说对吗，安德烈？”她温柔地又问了一遍，但已经有些不耐烦了。

“什么对吗？”他醒悟过来了。

大家全笑了起来，斯维特里滑头地眯细了眼睛。

“我说，”达莎气愤地皱紧眉头说，“你也能像维克多一样创造纪录。对吗？……”

“不，”他低声回答，“我办不到……”他狼狈地摊开双手，低下头，服服帖帖地准备接受达莎的任何嘲弄。但是他不能向她撒谎。

“你瞧，你瞧！”列斯尼亚克叔叔快乐地说，“我没有说错吧？”

达莎不高兴地对安德烈背过身去，但一句话也没有说。奇怪得很，她对这个沉默寡言的小伙子，倒有几分害怕，而且暗地里很尊敬他。

“瞧吧！”列斯尼亚克叔叔得意洋洋地说，“聪明人就说……办不到。说得对！八个台阶——八只角……”

“如果把采煤场子打通怎么样？”斯维特里提议说。凡是久经考验的领导人，总是胆大心细的，斯维特里也不例外。他回到马丽雅矿已经有三个星期了，现在他是列斯尼亚克叔叔的助手。他正在仔细观察，反复考虑，还没有发动攻势。

“得了！”维克多耸耸肩膀说，“打通也好，分成几个台阶也好……对我都一样……我可以保证完成。”

此刻大家都望着列斯尼亚克叔叔，他却神经紧张地捋捋胡髭，想着心事。

“是——的……”最后他说，“对于维克多，这是有可能的。可能办得到……”

“办得到！”达莎欢天喜地地叫了起来。

“是——的……但我们不能光为维克多一人着想，必须考虑到整个煤矿。”

“这算什么话，难道我一人做八人的工作，煤矿就要倒霉吗？”维克多暴躁地说，甚至有些生气了。

“不倒霉。怎么会倒霉呢？很好！”

“那又怎样呢？”

“这样会轰动一时的，不错！……但是下去怎样呢？好吧，就算你一人做八人的工作……就算安德烈也这样……还有米佳……你们三名好手，三位英雄！但是天天一人采一个场子，我怕连你们也要吃不消的。要知道，人可不是机器呀！……创造纪录，办法很好，但要天天如此，就困难了。你平心静气地替国家想一想，这样下去会产生什么后果？……在一个打通的场子里，不分台阶，你就无法安插其他的采煤工了……是吗？这样一来，维克多，你有时就只好做半个场子，甚至不到半个场子……那时我们的矿井就只好搁浅了，它不但得不到光荣和利益，反而会弄得一团糟！你们说是吗？这当然是我老头儿的看法。也许你们青年人有不同的意见吧？”他一面补充说，一面冷笑，并且用嘲弄的目光打量着每一个人，特别是自己的女儿。

大家都觉得很尴尬，一句话也不说。维克多想粗鲁地驳他一下，但被斯维特里阻止了。

“不，你等一等！等一等！……列斯尼亚克叔叔，那么您认为应该怎么办？”他镇定地问。

“这儿还有什么法子呢？”老头儿把两手一摊，“只有放长台阶……别的办法我可想不出来！”

“台阶不论怎样放长，我还是无法转身！”维克多叫道，“又怎样谈得到创造惊人的纪录呢？”

“请问你需要的是什么呢：纪录还是煤？”列斯尼亚克叔叔声色俱厉地问。

“他需要的是荣誉！”斯维特里说。

“不是我个人的荣誉，是整个矿井的荣誉，”维克多叽里咕噜地说，“我要荣誉做什么？我厌倦了……我已经听厌你们这一套了！”他烦恼地挥了挥手，走到窗前，眺望窗外的花园。杨花已经在漫天飞舞……

“小儿子，那么你认为怎样？”列斯尼亚克叔叔和颜悦色地问安德烈，他所宠爱的青年人。

“我吗？”安德烈哆嗦了一下说，“我想……”

# 八

他确实在想着。他从来不参加争论，总是默默地听着，想着，不论在这儿，还是在宿舍里，或者在掌子里。但在掌子里想得最多。矿井里很适宜于思索。世界上恐怕没有一种工人，比矿工想得更多的了。矿工全是哲学家和梦想家！

“孩子们，你们的目标太高！”有一次奥尼辛叔叔听了斯维特里的话说，“当心点，这样会把国家搞得天翻地覆的！从前做矿工的决不敢那么胡思乱想，虽然我们当时也有自己的梦想……”他苦笑了一声。“怎么没有呢！……我们梦想星期六痛痛快快喝一场……要不然就是花斑的乳牛和蓝色的兔子。”

于是，他就在安德烈的床边坐下来，讲矿工们的梦想：

“人人都有自己特殊的梦想。在矿井里没有梦想怎么行呢？一片黑暗！有些人整个星期卖命一样地干活，地面上也不去，睡就睡在矿井里，只是为了想多挣几个钱！……直到星期六才出井去，领了工钱，一脚就走到铺子。买这个，买那个，把所有的钱都买光：有人买一双瓶形的长靴，有人买一件上装，有人买一件花纹古怪的红衬衫。于是，穿扮好了，大模大样地在管理局街上走来走去，卖弄自己的新装，然后到酒店里去。这一去，就要到星期一才露面！他们把身上所有的东西喝个精光：靴子、上装、衬衫，一件都不留……连贴身的十字架也不例外。到了星期一，又照旧做苦工，做到痛饮的星期六。嗳！”他摆了摆手，“但也有人滴酒不进。这些人就在想望一条花斑的乳牛……”

买一条花牛，不是没有可能的。不论哪一个市集里都有花牛。只要有钱，就可以买一条！有不少季工——有奥尔洛夫人，有莫吉廖夫人，也有库尔斯克人——卖命一样地干一冬的活，一个钱一个钱地积起来，如果到春天不间断，不上酒店——事实上很难免！——那么，最后他就可以带一条牛回到乡下去。

关于蓝兔子的梦想就要荒唐得多了。事实上，谁也没有看到过蓝色的兔子。但是，老人们都坚决相信：在废弃的井巷里住着这样一头自由自在的小动物。它不是随便可以让人见到的：胆小的走不到，愚笨的看不见。但将来有一天，蓝兔子会自动出来，人人都可以见到，不问你胆大胆小。到了那个时候，世界上就有真理和公道，矿井就不再是做苦工的地方了。

“难道没有一个人曾经梦想，怎样提高产量和改进技术吗？”安德烈天真地问。

“何必呢？”奥尼辛叔叔露出惊奇的神气，“为了谁的利益呢？比国老板，还是德国经理？不！每个人都只为自己打算。”他稍微想了想，又补充说：“当时又没有实行超额累进工资制……”

安德烈考虑的，不是个人的名利，而是大众的幸福。在不见阳光和天空的地底下，在狭小的掌子里，在低垂的顶板下，矿工安德烈蜷缩着身体，心里想着国家，想着祖国，想着矿工在世界上的地位……为什么以前他没有这些念头呢？因为时机没有成熟，他还不懂事，在矿井里他还是一个乳臭未干的孩子。可是现在……现在他知道矿井里的一切秘密，熟悉每一个黑暗的角落。现在他是这儿的主人。他用做主人的眼光，发现他在这儿当家当得太坏了！他认为他可以采更多的煤，可以把工作搞得更好，可以把劳动组织得更合理。

他已经能够模模糊糊地想象，他应该怎么办。但那只是一种梦想，而不是决定，因此他暂时没有向任何人吐露。

“我应该跟达莎商量一下……”他有时心里盘算着，“她的意见怎样？她是一位专家……”不过，他想跟她商量，并非因为她是一个“专家”，而是因为现在他的思想、愿望和行动，都少不了达莎。现在他的一切问题，都跟她有关系，都跟她分不开。

他想到祖国，同时总要想到达莎，因为他的祖国，也就是她的祖国。他幻想矿井、城市和国家的未来，又会同时幻想自己和达莎的未来，甚至幻想——想到这里禁不住一阵脸红——他们的……孩子们的未来。一切都紧紧地联系在一起：达莎、爱情、矿井、国家、维克多、友谊、成功——为了祖国，也为了达莎，他必须取得成功——而这些东西加在一起，就是安德烈今天的生活。

从前他认为没有维克多，就无法生活；现在他认为没有维克多和达莎，生活就不可思议。

达莎时刻跟他在一起：在他的思想里，在他的梦境中。连工作的时候，他也没有把她忘记。在他的掌子里，他没有把她幻想成一个下凡的天仙，而只是那个手提矿灯的快乐的“萤火虫”。她仿佛是一个女主人，出现在他孤独的台阶里。这儿就是她的家。由于她在他的精神上形影不离，他的工作、思想和生活都变得更加轻松。

有时，他醉心于采煤的工作，暂时把她忘记了。但是，不久，她的形象又鲜明地浮上了他的脑海，出现在波浪形的煤层里，出现在他头上乌黑的顶板上，并且在顽皮地向他微笑。于是他也怯生生地微笑着回答她，同时又开始无声地跟她谈着谈不完的知心话。他们谈到爱情，谈到生活，谈到幸福，谈到未来——像他所理解的那样。他想象着他们平静、美好、融洽的生活，朴素的劳动者的生活。他们一定要有一所石棉水泥顶的白色小房子，就跟列斯尼亚克叔叔的那所房子一样，房子前面也要有一座庭园，庭园里要种满三色堇、石竹和紫菀……安德烈当然还要去学习，免得落在有学问的达莎的后头。他们将一起看书，一起讨论。他们永不离开矿井到别处去。事实上，他们也没有别的地方可去，因为他们是矿工。晚上，维克多将到他们家里去作客。那时，维克多也结婚了，他的房子就盖在他们的旁边。每天晚上，他们两家人将聚集在花园里的槐树下，平静而和睦地一起喝茶，谈天……

这些天真烂漫的梦想，充满那么多无法形容的美妙和迷恋动人的幸福，以致把安德烈弄得头昏目眩了……

然而，他又常常有一种失望的感觉，认为这个梦想是永远无法实现的，因为，对他那样一个不漂亮的小伙子说来，这个梦想实在太美了！难道达莎真会爱上他吗？

不过，有时候，特别是在他的风镐打下大块的煤来、而他也快乐地意识到自己的力量和生活在世界上的意义时，他就变得很大胆，并且相信一切都能实现，达莎一定会踏进他那座白色小房子的门槛来的。

然而，他还没有向她吐露过自己的爱情，一次也没有。他的心里依旧默默地藏着千言万语的情话。事实上，这些话是无法用言语来表白的，它们只能用目光传达。安德烈仍旧偷偷地爱着她，以为没有人知道他的秘密。可怜的孩子，他没有想到，这早就不是一件秘密了，连达莎本人也已经知道了。

“等我跟维克多创造了新纪录，我就去向她表白。”他心里作着决定。

表白爱情和创造纪录，这两件事究竟有些什么关系，连他自己也说不出。不过，他模模糊糊地感到，这两件事是有关系的，而且等到创造纪录之后，他和维克多两人的生活就会完全改变。

其实，离开创造纪录还远得很呢。大家仍旧不时在列斯尼亚克叔叔的家里聚会，研究，商量，争论，但始终做不出决定来。安德烈仍旧一句话不说。

有一次，维克多忍不住发起脾气来：“我们空口说白话，究竟要说到什么时候？你们老实告诉我：你们到底支持我还是不支持？”

“你不要性急！”斯维特里劝告说，“这不是开玩笑的事。”

“你们怕吗？”

“我怕。”

“你怕，你就走开！不要来妨碍我。我一个人搞，我自己负责……”

“如果搞不成功呢？”

“也不关你们的事！我冒险，丢脸丢我的。”

“嗳，不行！”斯维特里说，“盲目瞎干会白白糟蹋好主意的。”

“但这是我的主意！……”维克多叫了起来。

“不，胡说。这已经不是你个人的主意，而是我们大家的主意了。”

“那么现在叫我怎么办呢？”维克多绝望地叫道，“你们大家约束我，妨碍我，连话都不让我说。要知道，我不能再那样工作下去了。实在不能！我受不了烦恼和羞耻！……”

“这一层，我们很了解，孩子！”列斯尼亚克叔叔充满同情地叹了一口气，“我们也在想办法呀。你的主意很好，但是不能实现。”

“不，有可能的。”安德烈突然低声地说。

他说这句话，声音很平静，一点不激动。他不知道，这几个平凡的字眼，具有惊人的力量；他没有想到，他们在发起一件伟大的新事业。

好多年之后，这个晚上将成为历史的插曲，详细情形他们恐怕也会记不清。垂头丧气的维克多，此刻根本没有听清安德烈的话。斯维特里惊奇地瞧了瞧安德烈，但一句话也没说。列斯尼亚克叔叔甚至皱起了眉头。

“啊呀，安德烈！”他烦恼地说，“你说什么话呀！你刚才不是说……”

“不，有可能的！”安德烈涨红了脸，固执地重复说，“只要……只要分分工……”

大家还是不了解他。他讷讷地解释道：

“让采煤工光刨煤，叫支架工替他搭支架，懂吗……”

“什么？！”斯维特里大吃一惊。

这个主意实在意外，也实在简单，正因为太简单了，以前反而没有人想到。直到此刻，他们还不能马上领会这个极简单的主意。可是，这个主意会一脚踢翻根深蒂固的老规矩，而那可不是容易习惯的。自古以来，做采煤工的总是一面刨煤，一面搭支架。这对矿工说来，是天经地义，正像对农民说来，田地必须先耕后播种同样自然。可是现在，既非专家又非工程师的安德烈，竟一句话就打破了这个天经地义。这怎么不叫人大吃一惊呢！

如果安德烈的提议荒唐无稽，大家也不会感到那么惊奇了，因为反对一种完全未知的东西，要比反对积习很深的老规矩，容易得多。一个最空头的幻想家，也可以足不出户，在自己的书室里想出一套“新的”“哲学体系”，或者一无用处的宗教来；这里不需要什么勇气！但是要反对该死的“老规矩”，反对世界上最可怕的力量——习惯的力量，只有真正的革命家，才有足够的勇气。

这种习惯的力量实在厉害，因此，即使像列斯尼亚克叔叔那样聪明大胆的矿工，也无法立刻好好领会安德烈的意思。

“不，你等一等，等一等！”他喃喃地说，“这怎么成呢？顶板怎么管理呢？工钱怎么计算呢？二一添作五地平分吗？”这些问题全是无关紧要的，他一面提出，一面就自己把它们否定了。但他找求这类反对意见并且再三坚持，目的只是在设法给自己找求答案：为什么以前谁也没有想到过那么平凡而聪明的主意？为什么安德烈这个孩子——他的学生和宠儿——却能够那么容易地找到它？

突然他出乎意外地停止了自言自语，大声叫了起来：

“对啊，对啊！一点也不错！”他欣喜若狂地走去拥抱安德烈。

现在大家都聚集在手足无措的安德烈的周围了。

“啊！真的吗？安德烈的主意真能实现吗？”达莎叫道，满怀希望地一会儿望望父亲的脸，一会儿望望安德烈的眼睛。

“有可能的！一切都有可能的！”维克多兴高采烈，声音洪亮，“好吧，现在只等我们去做了！对啊！”他举起两只粗大的拳头，用力挥动着，仿佛马上就要去创造纪录了。

“但是老祖宗呢？”斯维特里忽然问。

但这句话也压制不住大家的兴奋。

“老祖宗有什么？老祖宗跟我们有什么相干？”维克多热烈地叫道，“现在就是老祖宗也不能阻止我们了。”

“当然，老祖宗是个很古怪的家伙，他什么都做得出！”列斯尼亚克叔叔说，“但他是个聪明人……我们首先必须取得矿党委的支持，不巧的是聂察英科在休假……”

“找聂谢烈特尼没用！”维克多挥了挥手，“他做不了主的。”

“好吧，那么我们就去找老祖宗！”

那天晚上，在列斯尼亚克叔叔那所安静的小房子里，人们好像在欢度节日一般。仿佛一切都已经成功了。仿佛老祖宗已经祝福孩子们去创造纪录了。仿佛新纪录已经造成，人们的生活因此过得更美好了。仿佛一切希望，一切梦想都已经实现了：斯维特里梦想新的矿井，维克多梦想荣誉，安德烈梦想跟达莎的爱情和终身的幸福……

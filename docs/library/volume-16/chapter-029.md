# 九

村子里的人们都管马丽雅矿的矿长叫老祖宗，而且背后从不用别的称呼。原来他姓贾多克，名字叫格列勃，父亲的名字叫伊格拿特。有时人家弄错了，把他的父名叫成伊格拿基<sup class="footnote-ref" id="note-ref-78-1"><a href="#note-78" aria-label="查看本页注释 78">[78]</a></sup>，他总是很耐心地把它改正，但是从来不生气。

他原籍白俄罗斯，故乡在维吉勃斯克州的高罗德科夫区。他离开故乡很久了，离开的时候还是一个小孩子，此后就一直没有回去过，而且也不打算回去。但他总是自称为白俄罗斯人，并且因此觉得很自豪。他爱穿绣有维吉勃斯克十字花的衬衫，把马铃薯叫作“布尔巴”<sup class="footnote-ref" id="note-ref-79-1"><a href="#note-79" aria-label="查看本页注释 79">[79]</a></sup>，并且爱吃各种烧法的马铃薯，他说起话来，到如今仍旧有些白俄罗斯腔，特别在激动的时候。

矿井里每来一批同乡，他总是马上去找他们。一到招待所里，就问长问短地问个不休，有没有高罗德科夫人——一定有的——接着长久地向他们打听亲戚（留下的很少）和熟人（人数很多，都先后到过老祖宗的矿井）的情况。然后叫人拿烧酒和“布尔巴”来，开怀痛饮，而且从来不醉。有时用他那根有名的多节手杖——这根手杖即使在采煤场子里也不离手——支着青灰色的方下巴，听着拖长音的故乡的民歌……

他管理马丽雅矿有两年了，成绩很好。自从他管理以来，“计划没有完成”这句话，已经被忘记了。他是一个精明严厉的当家人，精通采矿术，上级很器重他，甚至有些怕他，因此，给他定的计划，总是很确当，使他能够胜任。

然而，他的成功秘密倒不在这里。矿工流动的现象，在那几年里还是很严重，工人一会儿多，一会儿少，好像海洋里的涨潮和退潮。但是，海水的涨落有一定的规律，矿工的流动却没有任何规律可循，连季节也不能作准。人们从来无法推测，明天将刮什么风，有多少人去上工，有多少人离开矿井。

这种矿工流动的浪潮，也侵入了老祖宗的矿井，但他却从没感到劳动力缺乏。这件事他应该感激白俄罗斯人。

关于老祖宗的事，不但在高罗德科夫区家喻户晓，而且传遍白俄罗斯所有的村庄。大家都知道他是一个好同乡，待人接物，和蔼可亲，当了矿长，不骄傲，不忘旧。“嗳，你去找格列勃吧！”退休的老矿工们唠唠叨叨地说，“格列勃在哪儿，哪儿就有饭吃。老祖宗待人，又温存又亲热。”于是，身穿白色长袍和羊皮上衣的白俄罗斯老乡，就大批地涌到老祖宗的矿井里去，而他总是张开双臂，热情地接待他们。

他是一个谦逊善良的人，矿工们没有一个不敬爱他。他过着俭朴的单身汉生活——老婆早已去世，孩子们都已长大而且走散了；公家供给他住的房子，里面冷清清的没有人，他除了在那里睡觉之外，大部分时光都是在人群中过的：不是在矿井里，就是在办公室里，再不然就是在公共宿舍里。在各种宴会上，他总是个贵宾，在矿工的婚礼上，总是主婚人，在婴儿的洗礼上，永远当教父。结婚也好，受洗也好，神父到不到没关系，但是没有老祖宗，矿山上就不曾行过一次洗礼，办过一件婚事。

他身材高大，体格魁梧，虽然有些老态，但仍旧很威严。他用力地撑着手杖，在矿山的街上走来走去，仿佛在平巷里视察一般，凡是遇到他的人，都向他脱帽致敬。他默默地点头作答，脸上没有笑容。他一向难得微笑，也从来不对人说好听话，不跟矿工开玩笑，不拍人家的肩膀，不喊人家“孩子”或者“好汉”。他反对不拘礼节。

但是，他不仅知道每个矿工的名字，而且认识每个矿工的老婆，认识矿山上所有的孩子；他知道那个玩沙泥的脏孩子是谁家的儿子，那个手提洋铁桶到铺子里去打火油、小辫子上扎着大红蝴蝶结的瘦女孩子是谁家的姑娘。他知道所有的事，认识所有的人，因为这就是他生活的主要内容，他活着也只是为了这些事和这些人。人家尊称他为老祖宗，不是没有缘故的。他们尊敬他，怕他——要知道，矿工是不怕任何人的！——并非因为他是矿长，而是因为他是老祖宗。好像在古老的农民家里尊敬族长一样——一个族长即使已经不能起床，仍旧英明神圣，握有大权。

老祖宗在矿工的大家庭里，也就是这样的一个族长。他热爱自己肮脏的亲生孩子，但这是严厉含蓄、不形于色的父爱。

一年前，马丽雅矿发生一场惨案——东场子里瓦斯爆炸——十七名矿工死在井里。老祖宗不躲避受难的家属和他们的悲哀与愤怒，亲自走到每一家去。他不是去安慰孤儿寡妇——这件事他也不会做——而是去劝告，甚至命令他们，应该怎样活下去。

“你哭吧，哭吧！”他一进门，发现女人惶恐地止住了哭声，并且匆匆地用围裙擦着眼睛，就说：“哭吧，怎么能不哭呢？”他在凳子上坐了下来，把手杖夹在两膝之间，然后拿出一条方格子的大手帕，重重地擤着鼻涕，继续镇静沉着地说：“大嫂，像安东那样的丈夫，现在是再也找不到了！真是好男人，工作卖力，又不喝酒……”他像是有意在触动新鲜的创伤。寡妇嚎啕大哭，孩子们也拉住母亲的衣角，尖声地哭起来，老祖宗不动声色地坐在他们中间，慢吞吞地摇着灰白的头，低低地带着教训的口吻说：“是的，杜尼雅，寡妇离不开眼泪！津贴国家会给你的，还有煤和别的东西也不会少。你不愁没有照顾！……现在，你要是再嫁，没有人会说你坏话。这层你要明白。”

“哎哟，您说什么呀，格列勃老爹？”寡妇气愤地埋怨道，“难道我想的是这个吗？……”

“你别闹，杜尼雅，别闹！我看得很清楚。你的孩子们需要有个父亲。瞧他们多么小！……”他把最小的一个孩子拉到身边，继续说：“你什么时候想结婚，什么时候来找我商量。对——了！……不要嫁一个年纪轻的。年纪轻的不合适。你要找个一本正经的男人，老成些的。听到吗？”

“听到，格列勃老爹。您何必提这些个呢，听着怪难受的……”

“你听我说！我是在谈正经，是为你着想。对——了！……我看你最好嫁一个鳏夫。譬如说嫁给盖拉西姆吧。人不坏，工作又卖力，又爱小孩子……就是这样，大嫂！”他一面说，一面站了起来，“人得活下去！……过几时我再来看你……”

于是，他又去到另外一家，去体会另一家的眼泪和悲哀。在那里，他又同样沉着冷静地听着女人的啜泣，老妇的痛哭，孩子的尖叫，他并不去阻止她们，却让她们哭个痛快。然后，他也不说什么于事无补的慰问话，就开始谈实际的问题，谈现在应该怎样生活，应该怎么办……

“莫佳，现在你可以在丈夫的名下领到一大笔国家的抚恤金。听到吗？不过，这笔钱，你可不能随意把它花掉。这不是你的钱，这是他们的钱！”他指指孩子们，“你把钱存在银行里。我要检查的。听到吗？”

“听到，格列勃老爹。”寡妇忧郁地回答。

“嗯，对了！”他点点头，“这样很好！……大嫂，你脾气很大，不过，现在这倒没关系，不碍事。现在像你这样的脾气，反而容易过些。对——了！……如果有再嫁的念头，”他出其不意地说，“那我倒劝你放弃！……你再嫁是找不到人的。你不比杜尼雅。”

“我本来不想再嫁。我有过一个男人，可是被您弄死了……”

“不是我弄死的——是瓦斯。”

“在我反正一样！弄死了，现在我只好带着没有父亲的孩子受苦受难了。”

“不是你带又是谁带呢？你养了他们，你就得教育他们。大嫂，你要明白，你自己的日子已经过完了。现在你要为孩子们活下去。至于你自己的幸福，不必想了。”他说话总是很直率尖锐，既不转弯抹角，也不虚辞粉饰，但这种真心的实话，常常要比空头的同情，更能打动人心。“大嫂，你的幸福现在是在孩子的身上！……”他继续说，“我打算把你们的华夏调到掌子里去，那边工钱大些，他已经长大了。彼佳也该工作了……”

“我不让他们下井去，不让！”马特廖娜尖声地叫道，“不让！”她用身体遮住孩子，好像一只愤怒的母鸡在掩护自己的小鸡。

“嗳，废话，女人家！”老祖宗皱起了眉头说，“矿工除了下井还能上哪儿去呢？大嫂，人得活下去，不能哭哭啼啼过日子。对——了！我把你的彼佳安插到唧筒站去吧，让他去学学。至于安妞泰，让她继续念书。其余几个小的，我们以后再好好地安排。就这么办吧！”他重重地撑着手杖，站了起来，走到别一家去了。

马丽雅矿的矿长老祖宗，就是这样的一个人物。安德烈和维克多现在打算拿自己念念不忘的创造采煤纪录的理想去和他商量。

老祖宗约他们晚上五点钟到办公处去。

在约定时间之前一小时，所有参加“密谋”的人，都聚集在列斯尼亚克叔叔的家里，决定谁到老祖宗那儿去。

“你跟维克多一定要去！”列斯尼亚克叔叔对安德烈说，“你们是发起人……”

“我怕老祖宗会把我们看作小孩子……”安德烈不好意思地说，“他不会相信我们的。我想请您去，列斯尼亚克叔叔……”

“好吧，我去！”老头儿同意了，“老祖宗知道我的。”

“最好斯维特里也去……”安德烈怯怯地补充说。

斯维特里笑了起来：

“全部武器一齐出动吗？”

“你是知道的，我不会说话，”安德烈道歉似的说，“维克多又是急性子……只有你，斯维特里，你是出名的政治家……”他用恳挚的目光望望朋友。

“大家都去吧！”列斯尼亚克叔叔笑着说，“我们一起去对付老祖宗，使他无法脱身！……我们去包围他！……”他说着换衣服去了。

维克多和斯维特里留在屋子里，继续喝着冰啤酒，安德烈和达莎走到花园里去了。达莎发现安德烈紧张的颧骨在微微地哆嗦——他咬咬牙齿，闭紧嘴唇，左颊轻轻地抖动。

“你有些激动，是吗？”她惊奇地问。

“有些激动！”安德烈坦白承认。他无法向她解释，这个计划对他具有怎样的意义……但他再也忍不住不说了。“要是老祖宗同意这个计划……而且计划成功的话……那么我……我有些话要跟你说，达莎……”他嘟嘟哝哝地说，自以为说得人家摸不着头脑。

“真的吗？”她嫣然一笑，“那我等着！”

她知道他要对她说些什么话——他要说他爱她。事实上，他现在说也好，将来说也好，都一样。反正她已经知道他的心事了。她想，要是斯维特里突然向她求爱的话，她一定会弄得手足无措，要是维克多呢，她说不定还会生气……但是安德烈的话，她是能平静地听的。

的确，她感到高兴，十分高兴，因为有人在爱她，而且爱她的又是安德烈——他是一个十分可爱的好青年。她感到又快乐又骄傲，因为她这个姑娘已经值得被人爱了，已经值得被安德烈爱得那么热烈，那么真挚了。“如果我命令他：安德烈，跳到小井里去！他一定会马上跳进去。是的，他一定会不管三七二十一地跳进去！”

“被人家那么热爱是多么幸福啊！”她得意洋洋地想。以前还没有人爱过她，向她表示过爱情。她跟米佳只是从小的朋友。因为她是姑娘而爱她，安德烈还是第一个。而她也因此感激他和爱他。

但是她到底爱不爱他呢？她跟他在一起觉得开心、轻松，甚至很快乐，虽然他老是默默地不说话，只是坐立不安地折断一根根的火柴杆。然而，他却能够带着钦佩的神气，听她闲谈，并且吃惊于她的智慧、她的学问、她那善良的性格。而她也突然觉得自己变得聪明些、和善些、老成些；通过情人的眼睛，她看到自己长大了。这真是一种说不出的快乐！

不过，要是他好久不来，她也从来不觉得寂寞，她难得想到他，即使想到，心里也很平静，看到他，她不会脸红，不见他，心头不觉得若有所失，在月光溶溶的夜里，她照样睡得很好，吃起饭来，仍旧狼吞虎咽，像一般矿工那样。不，书本子里描写的恋爱不是那样的。但说不定是书本子撒谎吧？

最后，列斯尼亚克叔叔出现了。他穿着节日的服装，像是去赴宴会一般。

“孩子们，我们走吧？”他雄赳赳地嚷道，带头走去。

达莎送他们到大门口，然后望着他们的背影好一阵。安德烈回过头来，她向他挥挥手帕；在这一刹那，她觉得她真的有些爱他。

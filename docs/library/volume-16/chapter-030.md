# 十

办公室里除了老祖宗之外，还有矿井总工程师格鲁施柯夫。总工程师长着两条灰白的粗眉毛，一对灵活的孩子气的黑眼睛。这对眼睛以前大概闪耀过欢乐、机智和生命的光芒；但现在它们只是惊惶不安地眨动着。这是一对奇怪的眼睛！它们并没有变得黯淡，也没有丧失原来的活泼和光彩，只是现在，光彩里含有焦虑，活泼中带着惊慌。原来格鲁施柯夫受了一次很重的惊吓，从此老显得有些心神不宁。

一年前，马丽雅矿发生了一次惨案。没有人归罪于格鲁施柯夫，也没有人责备他。这次惨变完全是由于不幸的意外，这一层，大家都很明白，除了格鲁施柯夫一人之外。他连自己也不知道究竟有没有过失。会不会有些地方疏忽，没有注意，没有事先采取必要的措施？他从此就变得胆小、谨慎、多疑，对别人将信将疑，对自己吹毛求疵。

现在与其说他在工作，不如说他在表白心迹。每逢给矿井下命令，他总是马上考虑各种能为自己辩护的解释和证明，以及各种可以引用的法律和章程。他好像永远在作着自我审判。他最注意的是怎样利用公文、指令、证件和附款，来作自己的护身符。他现在就是靠这些东西过日子。

格鲁施柯夫和老祖宗都不知道，安德烈和维克多要求接见的原因。不过，两人都不约而同地感到，那一定不会是矿工的普通要求，而是重要得多的事。格鲁施柯夫已经有些神经紧张了，心里已经在反对他们将要提出的建议了。因为，毫无疑问，他们建议的，一定是些新东西，也就是说，不是没有危险的东西。

老祖宗像平日一样，不动声色。当列斯尼亚克领着孩子们涌进办公室时，他慢吞吞地抬起头来，皱了皱眉头：

“你们这么多人……”

“事情大呀！”列斯尼亚克摊开双手，满面春风地回答。

“全都为一件事吗？”

“全都为一件事。”

“好吧！”老祖宗叽里咕噜地说，“坐下吧。我听着。”于是闭上了眼睛。

安德烈用恳求的目光瞧瞧斯维特里。

“你说吧，斯维特里！……”他喃喃地说。

斯维特里耸耸肩膀，说了起来。

他劈头就说，矿井里的情况使人难以容忍（一听到这几个字，格鲁施柯夫吓得从座位上跳了起来），采煤工和风镐的力量只用了一半，台阶太狭，没有地方转身（“小得真不好意思见人！”维克多插嘴说），先进的矿工们早就在动脑筋，想改进工作，多采一些煤（“不错，不错，不错！……”安德烈嘟哝着），现在矿工安德烈和维克多经过很久的考虑，想出了办法……

“办法？什么办法？”格鲁施柯夫焦急地喊了起来，他感到他的额角和秃头已经在抽筋了。

老祖宗平心静气地沉默着。他好像根本不在听，而在打着瞌睡。他那双眼睛依旧盖着厚厚的眼睑。

“什么办法吗？”斯维特里笑了一声，“就是……”他把安德烈和维克多的计划简短地说了一遍：把整个采煤场子交给采煤工，然后分分工。

“这可不行……不行……办不到！”格鲁施柯夫高声叫道，“这个……没有规定。而且很危险！……就顶板的管理来说……还有你们怎么可以说：矿井里的情况难以容忍呢？那么计划呢？我们不是经常完成计划，甚至超额完成百分之一、二吗……这儿是数字，请你们瞧瞧……费心！……”他非常焦躁，非常烦恼；此刻他把斯维特里和维克多不仅看作不安分的人，而且看作严厉的原告。他皱紧眉头，等待任何一个年少气盛、铁面无情的家伙，对他提出控诉。

可是老祖宗却一声不响。

“您可别激动，格鲁施柯夫同志！”列斯尼亚克叔叔脸上堆满笑容说，“您仔细想想。开头我也摸不着头绪。我也提出同样的问题：顶板啰，工资啰，习惯啰……但终于搞通了……”

“不，不，您别说了！”格鲁施柯夫恐惧地向他摆着两手。“您根本没有彻底想过，没有作过通盘估计……就拿技术保安条例……或者人民委员会最近颁布的通令来看，”他开始神经紧张地翻弄着文件夹，“或者矿山工作规则……这在任何教科书里都有的……”他记起所有这些书本、通令和条文来，原是为了要安自己的心，可是一想起来，反而变得更加惊惶。他心惊胆战地叫道：“不，不，我绝对，绝对反对……你们的提议无法考虑，没有可能……行不通！”

“不，为什么呢？”老祖宗突然低声地说，“这有可能的。”

安德烈快乐地向他转过身去。

“是吗？真的吗？”他一面感激地叫道，一面心里想：“老祖宗真是个好人！”

“完全可能。不是吗？”老祖宗冷冷地肯定，同时用无神的眼睛瞧着安德烈，问道：“就是这一些吗？”

“是的……就是这一些。”

“嗯……好吧！那么，没什么了，再见！”他出其不意地说，接着摇了摇头，拉过了面前的文件来看。谈话结束了。

安德烈手足无措了。

“那么……那么纪录呢？”他完全摸不着头脑，问。

“把创造纪录的念头忘了！”老祖宗声色俱厉地说，“把它忘了！听到吗？”他下着命令。接着又埋头到文件堆里去了。

这时维克多实在按捺不住了。

“怎么把它忘了？不。对不起！这个我们可不能忘！……绝对不能！”他一面大声叫喊，一面用拳头重重地捶着胸膛。

“我说：把它忘了！”老祖宗并没有提高声音，但却威风凛凛地重复说，“懂吗？我的矿井里不会创纪录的。我活一天，就一天没有新纪录！”

“你别说这种话，伊格拿托奇，别说！……”列斯尼亚克叔叔也生起气来了，“你冷静一点。何必这样呢？我们不是来恳求你。我们，老实对你说，是来要求你的。矿井不是你一个人的。我们大家都是主人。”

“那你是一个坏主人，老乡！”老祖宗气得噘起了嘴巴，“一个好主人替自己的狗都想得很周到。可是你呀……难道你给人家考虑过吗？唉，你这个人呀！”他痛苦地说。“可耻！老头儿，可耻！哼，他们，”他轻蔑地对孩子们点点头，“他们毛头小伙子，好高骛远，爱出风头……但你是个老矿工。你也该为同志们着想呀……”

“那你说我在为谁着想呀？”老头儿手足无措了，“难道为我自己吗？”他完全摸不着头脑。

孩子们也弄不懂是什么意思。“我们干了什么坏事了？”安德烈激动地问着自己，“我们又不是为了自己……我们还不是为了矿井……为了大众的利益？！”

显然，只有斯维特里一人具有政治家的敏感，他已经发现了问题的关键。他笑了一声，婉转地问道：

“您害怕纪录吗，格列勃·伊格拿托奇？”

老祖宗立刻抬起头来盯着他看。他不喜欢斯维特里。他已经听人家说过，他是个不安分的人，矿上不论什么人，他都要批评。“初出茅庐！……”他不怀好意地想着斯维特里。“大学生。一味向上爬。现在他们这批人都是这样。念过书，喜欢卖弄聪明，批评人！……”

他皱紧了眉头。

“我什么也不怕，小子，”他忧郁地说，“像我这把年纪，还怕什么呢？”

但斯维特里仿佛没有听到他的话。

“您怕新纪录会增加您的计划吗？”他又天真地问，语气之中似乎很同情老祖宗。

“这层我也不怕。我们的上级是有脑子的，不是小孩子。”

“那么您主要是怕定额提高，对吗？”

“我是为大家着想……”老祖宗不耐烦地摆了摆手，想中止他的盘问。

“但您也为国家着想吗？”斯维特里悄悄地问。

“国家，”老祖宗生气了，提高声音回答，“国家就是我们，就是工人，矿工……”

“对啊！这样说来，国家越有钱，我们矿工也越有钱啰？”

“是的……国家越有钱，矿工也越有钱。”

“那么您以为创造了新纪录，矿工们就会变穷吗？”

现在，列斯尼亚克叔叔、安德烈和维克多也终于明白是怎么一回事了。

“噢，格列勃·伊格拿托奇，格列勃·伊格拿托奇！”列斯尼亚克叔叔兴高采烈地叫道，他觉得心头一松，好像放下了一块大石头，“原来你在担这个心，好心肠！但你不必怀疑，这层我们也考虑过了！创造了新纪录，矿工的工资就要大大提高了！因为煤出得越多，钱也拿得越多……”

“谁拿得越多？”老祖宗非常气愤，“这一个……”他朝维克多点点头，“还有这一个……”他朝安德烈点点头，“再有三四个年轻灵活的……至于其他的人呢？所有别的矿工呢？”

“谁会妨碍其他的人好好工作呢？”安德烈实在弄不懂，“用我们这种方法，大家工作起来都省力。”

“您，矿长同志，不应该向落后分子看齐，应该向先进分子看齐。您应该支持先进分子……”维克多愤愤不平地说。

“你们要什么支持呢？你们已经够狠的了！谁会欺侮你们呢？可是那些老弱无助的，除了我，就没有人保护。”

“这可是尾巴主义啊，格列勃·伊格拿托奇！”斯维特里温和地说，盯了老祖宗一眼。

老祖宗突然大发雷霆。这恐怕还是几年来头一次。他从座位上蹿了起来，举起毛茸茸的大拳头，拼死命朝桌上捶了一下。

“啊——啊！尾巴主义？”他哑着嗓子喊道，“你想给我戴帽子吗？你准是搞惯这一套的……”他一面喊，一面怀恨地瞧着斯维特里。

他的脖子涨得通红，样子十分可怕，吓得格鲁施柯夫以为他马上就要中风了。

“您怎么了，格列勃·伊格拿托奇！”格鲁施柯夫朝他抢前一步。可是老祖宗粗暴地把他推开了，此刻除了斯维特里之外，他什么人也没有看见。

“尾巴主义？”他咕噜着，“哼，你，你！……”他气得上气不接下气，一句话也说不出来。他像关心自己孩子一样关心矿工们。他从来不想到自己。可是人家却反而责备他！

他想：“我自己什么也不要。我既不要大洋房，也不要升官发财，你明白吗，大学生？”他只住一间房子。他总是把自己所有的钱分赠给人家。将来他也不会带什么东西进棺材去的，你们可以放心！……他从来不曾揩过人家一滴油。他把一切都给了他们——矿工、同乡、孩子。

至于国家吗？“嗳！我们的国家是很富饶的，是取之不尽，用之不竭的。”他这样想。

国家……他因为终日无微不至地关心自己的矿井和矿工，难得想到国家。他认为国家是一只极大的聚宝盆，从前属于资本家，现在属于工人。为了它，人们搞革命；为了它，人们流血；为了它，老祖宗自己也流过血。目前他也在尽力为国家服务。因为他采煤不是为了自己！因为他不是老板，也不是老板手下的伙计！……

可是在他那冥顽不灵的心底深处，存在着一种不自觉的观念，仿佛他不是国家派来管理国家煤矿的人，而是工人们自动选出来的劳动组合的组长。他的确很像一个组长，一心一意想巧妙地超过别的组合，并且想从那只国家的聚宝盆里，多为自己的组合捞一把。

他以为矿工们敬爱他，就因为这个缘故。他们尊称他为父亲和恩人，不是没有缘故的！他觉得这种感情比下属对首长的敬爱更可贵，更值得骄傲。而天底下最可怕的事，他认为是被人家批评为神气活现，贪图享受，脱离群众。因为这个缘故，他只住一间毫无陈设的单房间，拒绝公家供给他的马车——总是安步当车，放弃规定的休养，拿到奖金，大家平分：每人所得无几，但自己的一份，常常忘记……

有一次，一个从中央来的宣传员发现了这一点，好奇地问他道：“您对社会主义的看法怎样，格列勃·伊格拿托奇？”老祖宗手足无措了。他难得考虑那么抽象的问题。他受的教育不多，不是工程师，但实际经验很丰富；他熟悉老的矿井，但也只熟悉老的矿井。

“嗯……”他含糊地说，“我想吗？……社会主义——这就是公平合理……人人平均……”“如果你有一件贴身衬衫，就应该脱下来给赤身露体的人穿，是吗？”“大致如此……”老祖宗耸耸肩膀回答，“赤身露体的人在你的旁边，你还卖弄什么衬衫呢？”“是吗……”宣传员笑了起来，“您讲的是乞丐的社会主义。不是平等，而是平均主义。不，格列勃·伊格拿托奇，不是那样的！”于是宣传员像对小学生似的很有耐心地向他解释：我们的国家目前怎样在建设社会主义，将来怎样在普遍富裕的基础上建设共产主义。老祖宗一声不响地听着，既不反对，也不插嘴，只是不相信地摇摇头，心里却想：“嗨，你们这批夸夸其谈的书生！我们凡人活在世界上，只知道脚踏实地，埋头工作。”共产主义在地面上必然胜利，这一点，他虽然也像宣传员那样深信无疑，而且也曾经为它流过血，但他总觉得共产主义是个美好而遥远的梦想，一个上了年纪的人，即使在实际生活中想到它，也有些不好意思。

他不知道他面前的这几个青年革新家，就是活生生的共产主义的化身，而他却要把他们从自己的办公室里赶出去，并且因为他们叫他尾巴主义而大发雷霆。

他忽然觉得非常疲劳，重重地在椅子上坐了下来。他感到很委屈，感到自己已经老了。

他眼睛不看任何人，说：“走开……全都给我走开……回家去……”

孩子们慌忙抓起帽子，他们也忍不住想快些走开。看到老祖宗红得发紫的脖子，听到他沙哑的声音和喘息，实在可怕。

这时，受了一肚子委屈的列斯尼亚克叔叔，突然站了起来。老祖宗充血的脖子也好，他的怒火也好，他的权力也好，什么也没有把他吓倒。他挺直腰骨，又愤怒又庄严地说：“好吧。就这样吧。不过我要声明：这次的谈话并没有结束。现在暂时到此为止。贾多克同志，我们的谈话，”他把声音稍微提高一些，“将到党员大会上去继续。我们要用共产党员的身份谈一谈。因为我们的谈话不是普通的。走吧，孩子们！”他大声说着，走了出去，砰地一声带上了门。

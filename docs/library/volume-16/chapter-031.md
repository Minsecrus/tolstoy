# 十一

达莎不耐烦地等着“代表团”从老祖宗那儿归来。她几次跑到栅门口，朝大路张望。在苍茫的暮色中，每个过路的人，都像期待中的人；每次认错人，已经不是使她失望，而是不安。

“他们在老祖宗那儿怎么待得这么久？”达莎心烦意乱地想，“是好是坏呢？难道老祖宗会不同意吗？那怎么办呢？”一分钟之后她又想：“不会有结果的！到头来他们还不是照旧工作！”不过，她知道“照旧”是不会的，是不可能的，但现在该怎么办，她可不知道，因此坐立不安。

她独自在坐立不安，整个村子里只有她一人。矿山上没有人知道，他们去见老祖宗有什么事。也没有人会想到，在这几十分钟里，可能正在决定着矿工们工作的命运。

村子里的人们天天过着同样的生活。暮色降临大地，人们做完一天的工作，回到家里，脑子里想的，无非是些个人的事情。他们津津有味地用好晚餐，一家老小在槐树下欢聚，闲谈。白天跑累了的孩子们，懒洋洋地伏在妈妈的膝盖上。睡眼蒙眬的看门狗蜷伏在台阶下的窠里。鸡群已经进笼。万物都在归巢中。

羊群——矿工们唯一的家畜——热热闹闹地从山上回到村子里。小羊好像放学的女学生，跳跳蹦蹦地回家去。于是原来没有名字、不会说话的畜生，立刻变成了亲爱的玛尼雅、杜霞、裴凉卡，变成了矿工孩子们的好朋友。达莎看到玛尼雅小姑娘骑在玛尼雅山羊背上，得意洋洋地走进隔壁的院子里；她爸爸走在旁边，小心翼翼地扶住她的肩膀。个个喜气洋洋：手舞足蹈的孩子，吃得饱饱的小羊，但最幸福的还是留着胡髭的爸爸，他是著名的费多洛夫小组里的掘进工。不过，此刻他不是掘进工，不是矿工，也不是著名的突击工作者，他只是一个幸福的爸爸。

在这暮色苍茫的时分，村子里家家户户烧着茶炉子，好像几百只小型的熔铁炉在熔解生铁。茶炉子里的水蒸气，低低地飘浮在篱笆和庭园的上空；木炭的甜腻腻的气味，使矿工想起的，不是白天工作的掌子，而是童年时代的景象：树林子、夏夜的篝火、河上的迷雾……在这个时刻里，人人都会怀念往日的农民生活，向往土地，哪怕是定居很久的矿工。因为这个缘故，矿工都有自己的菜园和花坛，至少在房子的周围有一条狭狭的园地。上了年纪的挖煤工、支架工和司机在田垄间爬来爬去，抽着熄灭了的烟斗，在花木旁边忙碌，吸着嫩芽的新生气味，直到天黑，而这也就是他们的休息……

在这个时刻里，门口的香紫罗兰不知不觉地盛开了。它那扑鼻的浓香，立刻弥漫了整个村子，笼罩着大地上的一切。它好像军号的声音，穿过宿舍和住宅的窗子，敲动了每颗年轻的心。于是，运煤姑娘、选煤姑娘和推车女工就在房间里忙碌起来。她们已经脱下矿工服（硬邦邦的上衣和帆布的裤子），变成身材苗条、皮肤白皙、渴望幸福的普通姑娘。此刻她们在走廊里跑来跑去，仓促地在烘衣室里熨着缎带、蝴蝶结、绸衬衫，用整个宿舍里唯一的一把烫发钳或者烧红的钉子卷着头发，然后像一群天仙似的飘出宿舍：到管理局街上去“受罪”<sup class="footnote-ref" id="note-ref-80-1"><a href="#note-80" aria-label="查看本页注释 80">[80]</a></sup>，正像不久之前到集体农庄的树林里去“受罪”一样……

总之，在这个宝贵的时刻里，村子里人人都想着自己，想着自己的事：他们幻想幸福，追求幸福，有人找到幸福，有人失去幸福，有人希望失而复得……有多少人，就有多少种不同的幸福。

只有达莎一人站在栅门旁，她所想的不是自己，而是父亲和那几个朋友。他们去见老祖宗，也不是为了自己，而是为了大众的利益。

她等着他们，心里很烦躁，最后竟对自己生起气来：“我何必这样焦急呢？他们创造纪录关我什么事呢？我自己还有一个艰苦的冬天得过呢。我就要走了。”

可是，她已经无法不想这件事，无法不为它的结果而坐立不安了。她父亲和朋友们去见老祖宗也是为了这件事。如果村子里的人都知道他们几个人在老祖宗那儿干什么，在建议什么，在为什么事争得面红耳赤，他们也会放下他们的菜园和山羊，抛开他们小小的私事和操心，像达莎一样站在栅门口，焦急地等他们归来。

最后父亲回来了——独自一人。达莎快乐地向他扑过去，但父亲却怯生生地避开她，仿佛害怕盘问一般，接着闷闷不乐地挥挥手，走进房子里去了。达莎明白：在老祖宗那儿没有得到什么结果。

她刹那间手足无措了。“现在怎么办呢？”

她突然生起气来，不是气老祖宗的顽固，而是气朋友们的无用。“哼，都是饭桶！没有本领说服他！”她轻蔑地想，“唉，我为什么没有去呢？要是我去呀！……”她气冲冲地走进房子里。父亲在厨房里发脾气。过一会儿，他从里面冲出来，抓起帽子，一溜烟出去了。

“神经病！……”母亲在后面苦笑着说，“好像倒是我错了……”她怕冷似的裹紧奥伦堡<sup class="footnote-ref" id="note-ref-81-1"><a href="#note-81" aria-label="查看本页注释 81">[81]</a></sup>的白色大围巾，用那种女人家常有的滑稽的温柔语气补充说：“男人家总是那样的：在矿井里不称心，就到厨房里来拿我们出气……女儿呀，咱们娘俩喝茶吧？”她叹了一口气说。

可是达莎此刻在家里也坐不住了。

“我要出去了，妈妈。”她坚决地说。

“上哪儿去？”母亲惊奇地问。

“去看人。”

她围上一条三角头巾，冲到街上去了……“去看人”——这就是此刻必须做的事；她了解父亲：留在家里是办不到的。

她走到俱乐部里。那里今天很热闹，很快乐，她到的时候舞会刚开始。鬈发的米佳穿着一件大红的短袖衬衫，嬉皮笑脸地蹿过来。他在达莎面前顿了顿脚，一把拖住她，就转了起来。达莎觉得好像突然落在火堆里——米佳全身都是火红的，都在燃烧：衬衫、红棕色的头发、面颊、眼睛……达莎好容易才挣脱他那双火热的手，逃开这个既无音乐又无合唱的狂热的矿工的舞蹈。米佳哈哈大笑。安德烈、维克多和斯维特里都不在俱乐部里。

达莎去到煤矿党委会。孩子们不在这儿，也不在党委办公室里。团委会、工会办公室、管理局街、夏花园的电影场，都没有他们的影子……

达莎在村子里的各条街上走了很久，才自己承认她是在找孩子们。“为了什么呢？”“为了狠狠地骂他们一顿……骂他们都是饭桶！哼，我要给他们吃点胡椒！”她自言自语地说。她找了很久，始终找不到，而且越找越焦急。要是此刻碰到他们，她准会扑过去抱住他们的脖子。以后呢……以后她就要破口大骂：骂他们没有把她带去见老祖宗，骂他们搞坏了全部事情……饭桶！

“他们究竟躲在哪里呀？”她心里盘算着，“难道会坐在家里吗？”她忽然想象：孩子们默默地在自己静静的房间里踱来踱去，接连不断地抽着烟，互相躲避着目光，而在这种忧郁的墓地般的沉默中，各人想着自己的心事：维克多想着光荣，安德烈想着爱情，斯维特里想着伟大的倡议。

“我去，去鼓励他们……叫他们不要灰心。他们并没有受到什么损失。”她一面想，一面朝孩子们住着的宿舍走去。她从来没有到他们那儿去过，但她知道他们的宿舍。“明天我要拉他们到老祖宗那儿去，到市党委会去，到联合管理局去。这样的事是不能放弃的！不能！”想到这儿，她已经不是在街上走着，而是跑着了。是的，他们失望了，不干了，但她要担当起来，她要想办法……如果她是一个小伙子，哼，她要亲自去创造纪录！

“安德烈住在哪儿呀？”她走到走廊里，看见管门的老太婆坐在热水炉旁打瞌睡。

老太婆被惊醒了，给她指了方向。

达莎砰地一声推开门，冲进房间里，站住了。孩子们也不在这儿。

她手足无措了。一分钟之前，她想得多么生动：她好像一阵清风，吹进烟雾腾腾的宿舍；她好像一只萤火虫，飞进黑暗的掌子里，她会在门槛上喊道：“喂，孩子们，全体集合！”可是现在发现房间是空的，里面没有一个人。

这时，一个姑娘不好意思地迎着她走过来。达莎不认识她，她长得白皙瘦小，身上穿着一件薄薄的紫色衬衫。“奇怪，她的眼睛会是栗色的，”达莎的脑子里闪过这样的念头，“应该是蓝色的才合适……”

“您好！”她讷讷地说，“一个人也……也没有吗？”

“没有……”那个姑娘也显出了窘态，“我……我也是……偶然……”她的脸涨得通红。

“她来这儿干什么？”达莎心里想，不知道现在该怎么办：走，还是留在这儿等他们……孩子们到底在哪里呀？难道他们真会出什么事吗？

“您知道他们没有回来过吗？”达莎的声音不禁抖动了一下。栗色眼睛的姑娘脸色发白了。

“没有。出了什么事？……”她问，吓得呆住了。

“对了，这一定是薇拉！”达莎猜想，“一定是我的‘敌手’薇拉。”她想起维克多怎样嘲弄安德烈，不禁笑了笑。原来她是这样的，这个薇拉！嗳，她实在是个可爱的姑娘，长得真漂亮……她又朝薇拉看了一眼。姑娘紧张地站在她的面前，不好意思地紧紧抱着一件绣花衬衫——这件衬衫她始终拿在手里。“她一定是在给安德烈绣花衬衫。那么她真的爱他吗？还有床头柜上的那束花，一定也是她拿来的……”

“不。我想他们不会出什么事的，”达莎说，“我可以坐下吗？”现在她已经不想走了。

“嗳，真对不起！”薇拉忽然想了起来，“请这儿坐吧。”她挪过一把椅子。

“他们上老祖宗那儿去，难道安德烈没有告诉您吗？”

“上哪儿去？不，他什么也没说过……”

“可见他一点也不爱她！”达莎心里想，“创造纪录的事，她一定也不知道。”想到这儿，达莎不知怎的竟觉得很高兴。

“您恐怕就是达莎·列斯尼亚克吧？”薇拉突然悄悄地问。

“是的……”达莎觉得很奇怪，“难道您认识我吗？”

“不……我只是猜想……”薇拉窘态毕露了。

“大概安德烈对您说起过我了，是吗？”达莎冷笑一声，生起气来了。真是莫名其妙！薇拉大概在吃醋，在难受吧。哼，拿去吧，拿去吧，马上把您那个大耳朵的安德烈拿去吧！我要他做什么？饭桶！连向老祖宗说明一下都不会！

“不，他没有对我说起过您！”薇拉低声地说，凄苦地微微一笑，“他很少说话……”

安德烈真的没有对她说起过达莎。他一向什么话也不跟她说，而她也已经习惯了，不以为意。他沉默寡言，她反而高兴；如果他跟她说话，她会弄得手足无措的。因为一说话，他就会知道她是一个傻瓜……不，让他沉默吧，只要他不皱眉头、不把她赶走就好了。

但此刻她却酸溜溜地想：“他跟她，跟达莎是不会哑口无言的。他跟她一定无话不谈！”她偷偷地斜眼望望达莎。“当然啰，她长得又聪明又美丽，她是一个城里姑娘，在莫斯科念书。他一定爱她。”她忽然一阵心酸，酸得厉害……谁也没向她说起过达莎，说起过安德烈对她的爱情，但她知道，早就清清楚楚地知道和感觉到这一点。她自己也不明白她这个“消息”是哪儿来的，但就在这一分钟里，薇拉的少女时代结束了：女孩子成了女人，一个懂得恋爱并且准备保卫自己爱情的女人了。

这时她又想到安德烈：她实在不知道他出了什么事。

“请您别瞒我吧……”她匆匆地对达莎说，“安德烈出什么事了？”

“他什么事也没有，没有！”达莎有些生气了，“您那个安德烈是个饭桶！”接着她自己也没有想到似的突然开始颠颠倒倒地讲着今晚的事——创造纪录的思想和在老祖宗那儿的碰壁。

薇拉一声不响地听着。达莎这场颠三倒四的讲话，她没有完全了解，而那套达莎引以自豪的技术名词，她简直一窍不通，但是有一点，她却马上明白了：安德烈很不幸，这位姑娘不爱他……

“她真的不爱他吗？”薇拉想。奇怪得很，这个发现反而使她不高兴。她觉得冤枉，替安德烈觉得冤枉。“像安德烈这样的人，她怎么会不爱呢？”她心里很焦急，“天哪，他多么爱她呀！现在叫他怎么办呢？”在这分钟里，她愿意放弃自己魂牵梦萦的爱情。

这时门外传来重重的脚步声，门开了，孩子们蜂拥进房间里：斯维特里、安德烈、维克多三个人的样子都很古怪。

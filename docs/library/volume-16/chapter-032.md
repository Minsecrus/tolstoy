# 十二

维克多喝醉了。不但醉了，简直可以说是“烂醉”了。他那副软绵绵、懒洋洋、嬉皮笑脸、啼笑皆非的可怜相，说明他不是一点儿醉，而是酩酊大醉了……

一个人喝醉了酒，他的行为常常跟他清醒的时候相反：本来乐天的，会变得愁眉不展；平时沉默寡言的，会滔滔不绝地说个不停。维克多也是那样：清醒的时候顽皮倔强，喝醉了酒变得温和文静，甚至痛哭流涕。他想拥抱每一个人，跪在每一个人面前，莫名其妙地赔罪，忏悔，请求原谅；此刻他觉得人家个个都是好人，只有他一人是坏蛋。

“对不起，我喝醉了！”他那副无可奈何的模样和傻头傻脑的憨笑似乎在那么说，“我喝醉了，你们多多原谅吧。”

可是斯维特里和安德烈却不想原谅维克多。他们也像所有的青年人那样，公平正直，铁面无私，他们不了解，也不能原谅这个罪孽。老实说，在老祖宗那儿碰了钉子，他们个个闷闷不乐，都想“出出气”。老祖宗的拒绝实在太意外，他的理由实在使人摸不着头脑。

“瞧吧！”斯维特里很不高兴地说，“这是一个很好的历史教训：死人总是要拖住活人的脚的。”

但斯维特里也好，安德烈也好，他们根本没有想到酒店里去“出出气”。

“不要紧！”斯维特里抖动一下蓬乱的头发说，“不会到处都是死人的！”

他们在十字路口跟列斯尼亚克叔叔分了手，默不作声地走回家来。在苍茫的暮色中，维克多在半路上不见了。

一小时之前，朋友们在车站附近的一家酒店里找到他。维克多已经“出过气”了。他轻飘飘地坐在一伙喧闹的人群里，拉开嗓子唱着：“芦苇瑟瑟树弯腰呀……”一看到斯维特里，马上闭了嘴。人群也静了下来——在这分钟里斯维特里的样子实在吓人。

“你在创造纪录吗？”他朝一长排空的啤酒瓶投了一个凶狠的眼光，哑着嗓子说，接着，突然抓住维克多的后领，把他一把拖起来。

“别打！别打他！”安德烈一面叫，一面朝好朋友扑过去。

斯维特里没有打他。

他只是用尽力气摇着维克多，摇得维克多眼睛里的世界东倒西歪，团团打转，然后把他从酒店里拖到街上。维克多喜气洋洋地裂开嘴巴笑着。此刻他觉得世界尽管歪歪斜斜，依然光明美丽，朋友们尽管待他粗暴，他们仍旧是天下最善良最可爱的人。他们三个人之中，只有他一个满面春风，自得其乐，但人家并不羡慕他。

安德烈从没见过朋友那种像绵羊一般懦弱的可怜相。他们两人都是新时代的矿工，他们已经认识纵酒不是什么好事。纵酒就是使人失去理智，变成畜生，如此而已！维克多丑态毕露：黄色的口涎流了一下巴，使安德烈有生以来第一次觉得好朋友有些讨厌。

他们就怀着这种嫌恶的感觉，把维克多拖进宿舍里。不料这儿来了两个姑娘——达莎和薇拉。他们只好克制感情，把维克多领到床旁，按他坐下。

“坐着，该死的！”斯维特里声色俱厉地命令，接着朝姑娘们转过身去，愁眉不展地咕噜道：“你们好哇！”他也像安德烈那样在替朋友害臊。

“你们好！”达莎冷冰冰地回答。她双手交叉在胸前，咬紧嘴唇站着，那副神气活像她母亲，当父亲喝醉酒回家的时候。“好！”她又说了一声，向安德烈——不是向喝醉酒的维克多——投了一个使人心惊胆战的目光。她全身都在沸腾。“我真傻，真傻！”她咬咬嘴唇想，“我急急忙忙跑来，想安慰安慰他们，鼓励鼓励他们。而他们却这么快就找到安慰了！”

可是造成所有这些痛苦的罪人——维克多，却若无其事地坐在床上，傻头傻脑地微笑着……他明白他做了一件不漂亮、不正当的事，但他现在感到很舒服，很轻松，很快乐，跟三小时以前大不相同了。他觉得人人都很可亲可爱，生活本身非常简单容易，无需烦恼，不必认真。

“亲爱的……可爱的……”他眼睛望着姑娘们，含情脉脉地说，接着突然快乐地向她们眨眨眼睛。然后，收紧眉毛，问道：“我是猪猡吗？”

“得了！”安德烈皱了皱眉头，打断他说，“坐吧！”

“不，我是猪猡！”维克多洋洋自得地说，“但是为什么呢？”

他觉得他应该把这一层解释明白，免得这些好人误会和烦恼。他站起来，向姑娘们抢上一步，可是身子摇摇晃晃，几乎倒下来。

“对不起！”他抓住床架，说，“我没有得罪什么人吧？”

“躺下。快！听到吗？”斯维特里实在按捺不住了，对他大声嚷道。

“为什么？”维克多觉得很惊奇，“为什么要躺下？这么些好朋友在，为什么要我睡觉呢？我又没有得罪什么人？你们就原谅原谅我吧。”

他又朝达莎走近一步，达莎恐惧而嫌恶地后退了一步，但维克多并没有注意。他以为大家一定很想马上听听他的解释，为什么他喝醉了。他那喜气洋洋的目光，在同志们忧郁不安的脸上扫视了一周，停留在薇拉的脸上——她的双眼满含着怜悯的泪水。

“你瞧，我喝酒了，”他对她说，“但是为什么呀？”他仿佛自己也感到很惊奇似的摊开双手。“我的解释是：我变成猪猡了！”他快乐地笑了，“为什么？因为呀！我要像鹰一样飞上天去，你懂吗？可是老祖宗把我的嘴脸塞在污泥里。”他又笑了起来。“并且把我的翅膀飒啦飒啦剪掉了。”他一面做手势，怎样剪掉他的翅膀，一面嘴里飒啦飒啦地响着。接着又傻头傻脑地哈哈大笑，笑得大家心惊胆战。而他还以为大家觉得滑稽呢。“老祖宗同志是那么向我解释的，他说：你这个矿工不配当老鹰，还是做猪猡吧！因此我就去喝酒……”他做了一个喝酒的姿势，眨眨眼，又想放开喉咙哈哈大笑。

今天晚上所发生的一切，他竭力想在那批喝得醉醺醺的快乐的外路人中间把它们忘掉，可是此刻忽然又记了起来。这些事情本来已经被他忘记，并且被埋葬在啤酒杯里了，但此刻又从心底里浮起来，重新又来扰乱他，折磨他……这究竟是怎么一回事啊？！他，维克多·阿勃罗西莫夫，第一流的采煤工，究竟倒了什么霉，为什么他现在既不快乐又不安心呢？！

“救命啊！”他低低地喊道，突然倒在地板上，嚎啕大哭起来。

这个动作实在太意外，弄得个个都手足无措。安德烈连忙冲过去，抓住他的肩膀说：

“维佳，你怎么了？这是干吗呀？嗳，起来，起来！我求求你！”

可是维克多却仍旧坐在地板上，流着辛酸的、醉醺醺的眼泪。

连斯维特里也不知道现在该拿他怎么办。

于是达莎就果敢地挺身而出。

“来，起来！”她命令道，“傻——瓜！……”

他惊奇地抬头向她望望，停止了哭。

“傻——瓜！……”她重复了一遍，向他高声喝道：“喂，起来！”

他听话地站了起来，莫名其妙地举起双手。就这样站在她的面前，仿佛投降一般。

她已经知道应该怎么办。

“脱去上衣！”她用一种不容反抗的声调下着命令。

他完全摸不着头脑，但已经笑嘻嘻地脱去了上衣，把它扔在地板上。接着又把两只手举得高高的。

“现在脱鞋！”达莎命令道。

他一手扶住床架，跷起一只脚，开始脱鞋；现在他觉得这一切都是很滑稽很有趣的游戏。

“哪一张床是他的？”达莎问。他们指给她看，她很快地拉开被子。

“你瞧！好了！”维克多一面得意洋洋地说，一面把一只鞋子递给她。

“现在脱衬衫和裤子。快些！”达莎又命令道。

薇拉涨红了脸，转过头去。维克多用怀疑和不安的目光向大家扫视了一周，仿佛在问：这个命令也得服从吗？这也是游戏规则之一吗？

“快脱！”达莎不耐烦地嚷道。他就匆匆地脱了起来。

达莎平心静气地瞧着他。他穿着短裤和背心好像一个运动员。他的身体很结实，很漂亮，即使喝醉了酒，也没有一点软弱萎靡的样子。他实在是个强壮的美男子，任何别的姑娘都会注意到这一层，可是达莎却没有注意。她所看到的只是：他醉了，必须让他睡觉。

“哪！”她顿了顿脚，“到床上去！”

“为什么呢？”维克多忽然变得倔强起来，“我不要睡！”

不过，他已经完全在她的掌握中了。

“不，我不要睡！”他又重复了一次，但已经不十分坚持了。

看到他摇摇晃晃地朝床铺走去，她脸上泛出了得意的神色，吃惊于自己的威力，并且已经原谅维克多了。

当然，他服从她，只是因为他喝醉了酒。他不愿得罪任何人。他觉得他在大家面前是个罪人。他的样子又软弱又可怜。朋友们因此轻视他，只有达莎怜悯他。

他服服帖帖地朝自己的床铺走去，但不想睡觉。他还没有把心里所有的话说出来，还不曾把一切解释明白。他必须说明为什么归根结底他不能作一只鹰。可是达莎……他忽然狡猾地眯细了眼睛：哼，他有了主意了——他要作得比她更调皮。他要假装睡觉。他不是没有得罪任何人吗？好吧，他就去躺下吧。

于是他躺下来，把被子拉到头上，但又马上从被窝里探出头来，喊道：“我已经睡着了！”为了证明他没有说谎，紧紧地闭上了眼睛。

他忽然真的睡着了，这使大家都觉得惊奇。他睡着了，睡得像一个白天里玩得筋疲力尽的孩子。脸上那种喝醉酒的不干净的神气消失了：一张柔软润泽的嘴巴婴孩似的半开半张着，两条姑娘式的长睫毛盖着眼睛，面孔显得苍白而可爱。直到此刻，达莎才第一次发现维克多长得很美。

“是的。他睡着了很漂亮！”斯维特里说，仿佛猜到达莎的心事。“达莎，你真有一手！了不起！”他惊奇地摇摇头，“你把他弄得真服帖！”

她不好意思地笑了，怀着慈母般的爱，望望安静的维克多。他轻轻地打着鼾，嘴唇像婴孩般唧唧发响，睡得那么甜！

“我走了。对不起！”薇拉突然神色紧张地说。她始终在坐立不安。说完拔脚就跑，仿佛怕人家会阻止她似的。

“她怎么了？”斯维特里惊奇地问。

接着他望望安德烈，望望达莎，锁紧了两条粗眉毛。“嗳，现在我也得来管管这些事了！”他叹了一口气，想。即使朋友们的私事，他也不能不管。

“我也走了！”达莎说，“安德烈！你送我好吗？”

安德烈默默地点点头。

他们出了宿舍，沿着大街走去。

“你不要生维克多的气，”安德烈低声地请求说，“他是无心的，他不是酒鬼……”

“我并不怪他！”达莎激动地回答，“假若我是他呀，我会把老祖宗的玻璃窗砰砰嘭嘭地打个精光。”

“老祖宗那儿我们白去了一趟，”安德烈老大不高兴地说，“老祖宗是个落后分子。”

“是个落后分子吗？”

“是的，很落后。”

“那么你呢，你是个先进分子吗？”她嘲弄地问。

“我吗？是的，”他简单地回答，“我是个先进分子。我在为国家着想。”

达莎斜眼对他望望，忍住了笑。她只是暗暗奇怪：难道这就是一个半月之前羞怯地替她从车站提箱子回家的安德烈吗？！当时她觉得他很迟钝，说得不客气些，简直很呆笨。现在他怎样了呢？说不定会把达莎也当作落后分子看待吧。

“我们必须马上去见聂察英科，那个党组长。”安德烈自言自语地说。

“他不在矿山上。他在休假。”

“他就要回来的。”

“您想他会支持你们吗？”

“会支持的！”安德烈很有把握地说，“怎么能不支持我们呢？我们的提议是有好处的……”

“好吧！”达莎耸耸肩膀，“相信的人有福了<sup class="footnote-ref" id="note-ref-82-1"><a href="#note-82" aria-label="查看本页注释 82">[82]</a></sup>！”她反驳他，只因为故意想跟他闹别扭。老实说，她不能让他占上风！绝对不能！如果他肯定说：雪是白的，煤是黑的，她照样要争辩一番。他爱上了她，这是人人知道的……而她……她还没有拿定主意。所以，她还得占上风！

“难道你不信党组长会支持我们吗？”安德烈焦急地问，“为什么呢？”

“嘿，还不明白吗！”她转弯抹角地回答；老实说，她也想不出什么话来回答。“在生活里，我们不能随便轻信。必须永远作最坏的准备。”她得意洋洋地作了个结论。

“那么你相信共产主义吗？相信世界革命吗？”

“跟这有什么相干呢？”她生气了。

“不！”他摇摇头，“必须永远相信好事情！”

他说得又坚决又干脆，充分显出男子汉的本色。但是奇怪得很，达莎却不喜欢听他这么说。事实上，她是个男性化的姑娘。她不喜欢人家的保护和安慰，她不需要依靠人，她梦想将来能够支持一个她所爱的人。

她忽然想起了维克多，这个可怜的家伙怎样蜷缩着身子躺在床上，嘴角浮出一个痛苦的孩子气的微笑……他恐怕一辈子要跌跟斗，犯错误，恐怕一辈子需要支持、安慰和亲切的劝告吧。

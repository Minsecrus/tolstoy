# 十三

8月中旬，马丽雅矿的党组长聂察英科休假回来了。回来那天，他就去到了第二班的交接班室里。斯维特里在代替忽然病倒的列斯尼亚克叔叔处理班务，就在那里跟他认识了。

“聂察英科同志，这儿有两个青年人，等您已经等了好久了！”他笑容可掬地说。

“谁？”

“安德烈·伏龙科和维克多·阿勃罗西莫夫。”

“啊——啊！他们有什么事吗？”

“他们有个主意……想跟您商量商量。”

“主意！关于什么？”党组长发生了兴趣，“那么让他们来吧。”

“但是今天您刚到，应该休息休息。”

“好，那么就明天吧。”

于是就这样约定了。当天晚上，聂察英科突然亲自到宿舍里来了。孩子们在房门口看到他，不禁“啊呀”一声叫了出来。

“这个时候你们还招待客人吗，小伙子？”聂察英科快乐地在门槛上问，“我看到你们的灯亮着。可以进来吗？”

“请进来，请进来！……”安德烈手足无措地邀请。

聂察英科是奥尼辛叔叔陪来的，一进来仿佛把整个房间填满了，虽然他身材并不高大，很瘦，很结实，动作很敏捷。

“我好久不上你们这儿来了！”他兴致勃勃地说，“嗳，小伙子，你们还没结婚吗？是时候了，是时候了。有钱的新郎……哦，你们的屋顶漏水！”他发现天花板上有一圈水印子，“这算什么，奥尼辛叔叔？不行！得跟你算账了。”

“嗳，你这个人真不好弄，聂察英科同志！”奥尼辛叔叔窘态毕露，摇摇头说，“人家都说你是好人，好人……”他又在房间里徘徊了一会儿，然后悄悄地溜走了。

聂察英科走到书架旁边，翻弄着宿舍主人们的“藏书”：三两本凌乱的书和十来本小册子。

“你们这儿的文化气息不浓，英雄们，不浓！”他边翻边说，“我真不懂你们：你们都是有钱的采煤工，为什么不买些好书？舍不得钱吗？”

他是来作客的，可是却像在家里一样随便。他的作风就是这样的。他生气勃勃，精神饱满，给人一种愉快的感觉。他的身上还保留着海洋的风味。他穿着一身帆布西装，戴着一顶运动帽，脚上穿着白帆布鞋，一点不像一个党组长，尤其不像一个矿山的党组长。此刻他有说有笑，无拘无束，好像一个活泼的小伙子。

这一类人在群众中被称为带头人物。他们即使自己不愿意，还是常常被选为发起人。他们总是中心人物。甚至在疗养院里休息，他们也会不由自主地参加各种社会活动，组织各种游览、野餐和游戏，他们会因为伙食不好而带头“闹饭堂”，也会成为反对午睡的领袖。他们休息一月，往往比工作半年更疲劳。即使不会唱歌，嗓子不好，他们还是合唱时的领唱……

“我是来听听你们的，”聂察英科放下“藏书”说，“据说你们有了什么主意……”

“说不上什么主意！”安德烈发窘了，“不过，的确有个小小的意见。”

“有个小小的意见吗？”

“是的……”

“好吧，那么就把你们那个意见讲出来吧！”聂察英科一面说，一面走到桌子边坐下，把两只臂肘搁在桌子上。

这些时候斯维特里的眼睛始终盯住他。虽然党组长戴着运动帽，穿着帆布鞋，斯维特里还是很喜欢他。他已经知道，聂察英科绝不是一个浅薄粗鲁、没有深谋远虑的人，像他第一眼给人的印象那样。关于他的事，斯维特里听到很多，特别是从市委老委员列斯尼亚克叔叔那儿。

“我们的聂察英科是一个斗争好手！”列斯尼亚克叔叔又敬又爱地说。这个鉴定斯维特里认为是最重要的：他不喜欢和不信任好好先生式的干部。他喜欢斗争性强的人。而聂察英科正是这一类人。在各种不同的会议上，大家总是情绪热烈、迫不及待地等着他的发言。大家都知道，他的发言决不会枯燥乏味。大家都知道，这个家伙天不怕地不怕，说话毫无顾忌，也决不会离开题目；即使第一书记皱眉，第二书记生气，他还是要说下去的。

在我国，大胆的话比俏皮的话更受人民欢迎。聂察英科不是普通的所谓“毒舌头”，也不是一个口若悬河的演说家。他的演说从不卖弄事先准备好的笑话，或者引人入胜的词句和谚语。然而其中却燃烧着一个不知疲劳的事业家的热情，洋溢着一个全心全意为大众利益服务的人的至诚。他的演说最好不要读，而要听。

“我们的意见很简单……”安德烈犹豫不决地说，“但我不知道该怎样说起……”

“我们不满意！”维克多忧郁地说，“我们没有发展的余地。”

“‘你们’指谁？”聂察英科问。

“采煤工呀……还有谁呢？”

“简单地说，孩子们想在采煤场子里来一次小小的革命。”斯维特里插嘴说。

“我想是不流血的吧？”

“天知道！议会的道路已经试过了——行不通。”

“好，那么讲吧！”聂察英科断然地说，“如果必须流血，那就流吧！对吗？”他整个身体向前挺出，准备听他们讲话。

孩子们你看看我，我看看你。

“你说吧，费佳……”安德烈叹了一口气，喃喃地说，“你讲比较好。”

“好吧！”于是斯维特里就开始把创造纪录的主意，详详细细讲了出来。

“等一等，等一等！”聂察英科忽然惊奇地打断他，“这简单得很！……”

“不能再简单了！”斯维特里微微一笑。

“这只是基本的分工。我说得对吗？”

“是的，是这样的！”

“实在太简单！”聂察英科不知所措地重复说，激动地擦擦鼻梁，“你们跟矿长谈过这件事吗？”

“谈过了。”

“跟总工程师谈过吗？”

“也谈过了。”

“他们怎么说呢？”

斯维特里只耸耸肩膀。

“领导上不支持我们。”维克多忧郁地说。

“为什么？”

“他们怕……可是怕什么，连他们自己也不知道。”

“噢——噢……原来是世界性的权威们在反对你们，而你们不肯屈服，是吗？”

“这件事我们怎能屈服呢，聂察英科同志？”维克多高声叫道。

“你们真大胆！”聂察英科笑了一声说，“来吧，把你们的主意说得详细一些吧。”他就开始询问详细情形，越问越不肯马虎，同一件事，常常问了几遍，一直把细节都弄明白为止。孩子们都很乐意地回答他，于是一切又显得非常简单、清楚、可信。但这种简单的道理，反而使他觉得迷惑不解。他想：“如果真是那么简单明白，为什么以前没有人采用这个办法呢？”这样看来，这里一定有着什么困难，而且这个困难在任何工程师、技术员，甚至经验丰富的老矿工，一定是一目了然的。而他聂察英科看不出来，只因为他不是专家。

是的，他不是专家。他不是矿工，不是工程师，也不是技师。提到自己的教育，他通常总是用伤心的幽默口吻说：“我只受过初等教育，未完成的初等教育。”而这也就是他最伤心的事。

他出生在黑海海滨，是巴拉克拉伐地方渔人的儿子，自己也打过鱼，甚至用尼古拉这个名字作过教名，来纪念海上渔民的守护神圣·尼古拉。他的童年正巧逢到国内战争，他没有念完初等学校。老实说，当时他并未因此觉得悲哀。渔船上的风帆，引诱他去作远方航行，那比读书要有趣得多！

后来他成了共青团员。在他入团的那些日子里，工人学校的入学证，把很多青年送到北方去学习。于是尼古拉·聂察英科也就利用这个机会去到列宁格勒，进了一所工人学校。一个理想的职业在遥远的前面引诱他，他要当一名造船工程师。

那时党的号召响遍全国：派两万五千名志愿工人到农村里去！这件事跟工人学校的学生不相干，但在学生宿舍里却谈得很起劲。他们羡慕这两万五千名志愿工人！聂察英科一听到号召，就热血沸腾。他自己也没意识到该怎么办。即使意识到也没有用。他无法克制内心的激动。他天天在报上看到农村阶级斗争的报道：有人流血，有人牺牲。于是聂察英科就跑去当志愿军。

在农业集体化运动中，他成了一名普通的战士——宣传员、农村图书馆管理员、合作社组织员，最后，当了村苏维埃主席。农村成了他的生活大学，成了他的斗争学院。为了它而放弃工人学校的学业，他从没后悔过。但越到后来，他越感觉到学习的必要。乡下七年制学校里的学生已经超过他。因此，有一个进农业机械化专修班的机会，他就没有放过。他想既然当不成造船工程师，就去做机械化专家吧。他怀着满腔热情跑去学习。可是，专修班的领导很腐败。聂察英科稍微考虑了一下，立刻跟它展开斗争。斗争很激烈，但他到底取得了胜利。他被选为专修班里的党书记。过了两个月，他已经是市委的一名指导员了。

“积极性把我给毁了！”聂察英科后来笑着说，“嗳，我不该暴露自己！……”

可是第三次学习——进省委党校——又半途而废了，原因还是跟上次一样。他立了“安分守己”、“守口如瓶”的“戒约”，但是白费。他不会“守口如瓶”。他偶然在支部大会上说了几句话，立刻引起人家的注意。市委正需要一个诚实可靠、能力强的人，派去搞当地的工业。“将来有机会学习的！”他们答应聂察英科说。他服从了。下一次调动干部时，他被调到铁路政治部里，以后又被调到区里搞煤矿工作。他被认为是个有能力、有前途的干部，但聂察英科自己却烦恼地看到，他在逐渐变成一个单纯的行政干部。不错，他成了一个有经验有能力的组织工作者，他培养了迅速理解事物的本领；每到一个新地方，他总是诚心诚意地钻研业务和技术，夜夜埋头在书本和手册里。可是他缺乏那种基本的、系统的、学校的知识，而它又不是任何直觉、任何才能所能够代替的。这件事常常使他觉得苦闷和焦急。

但这种烦恼的思想，又使他对自己生气。“我是什么人？我怎么可以诉苦？我是党的一名小兵。党知道得最清楚：我应该站在哪个岗位上，应该在哪儿作战，应该死在什么地方！”

但他在心底感觉到，那些虽然忠心耿耿、但却目不识丁的战士，现在对党已经没有多大用处了。现在需要的是工程师党员、农艺师党员、学者党员。干部决定一切。作党委会委员更需要受过教育。一个只受过“未完成初等教育的人”是不能领导人民的。这一点，他现在感觉到多么强烈啊！唉，如果他是一个工程师就好了！他可以怎样支持这些热心策划“采煤场子里的革命”的青年人哪！他可以怎样帮助他们哪！

他应该帮助他们！他是一个经验丰富的党的工作人员，对于一切新的和前进的事物很敏感。根据自己的经验，他知道孩子们是对的。而最值得宝贵的，是孩子们自动提出主意来。“这样看来，他们在为国家着想，这是值得宝贵的！何况又想得那么勇敢大胆！”

“同志们，”他激动地说，“我觉得你们是在计划一件好事情。我还不知道它是不是能够成功，但是我相信……全心全意相信你们的主意。”

“谢谢您，聂察英科同志！”安德烈兴奋地叫道。

“这应该感谢你们，”党组长回答，“孩子们，现在让我们这么办吧。无论如何我要跟老祖宗和总工程师谈一次。明天晚上我到市委去找罗亭同志。或者还是去找茹拉符列夫同志。他是管煤矿的。只是你们把事情的究竟再从头到底仔细讲一遍。”

他在孩子们那儿又坐了一个半钟头才走，走的时候天色已经完全黑了……

# 十五

在马丽雅矿的历史上，有过这样的一件事：它的汽笛……失窃了。

这是好久以前的事，发生在1921年。当时马丽雅矿的矿工们费了九牛二虎之力，复兴了自己心爱的矿井，并且规定了复工的日期。可是就在那个举行复工典礼的前夜，人们发现：汽笛没有了。矿井变成了哑巴。

起初人们简直不相信它是失窃了。试问：谁会要汽笛呢？谁会为了它爬到烟囱上去呢？大家断定是风刮掉的。应该另外装一个上去。

可是到傍晚查明：汽笛的确是人家偷走的。是莎菲亚矿的几个男孩子偷的，偷的动机只是想惹是生非和卖弄胆量。他们得意洋洋地把它抬回家去，眉飞色舞地交给老人们，仿佛在说：你们瞧，马丽雅矿都是些怎样的糊涂虫啊，他们连自己的汽笛都看不住。

马丽雅矿的矿长知道了这件事，大发雷霆。他要求马上报告公安局，逮捕肇事罪犯，并且把汽笛归还原主。总工程师耸耸肩膀说，这样未免小题大做：自己装一个新的上去，就行了！

可是那些上了年纪的矿工，却伤心地大摇其头。

“嗳，不行！”他们说，“新装的汽笛跟老的到底不一样！我们并不否认：新的也许比老的更好，声音也许更纯净更好听。但我们听起来总觉得陌生。我们听惯自己的那一只。每天早晨，当附近一带汽笛齐鸣时，我们分辨得出我们那只沙哑的声音。人家的汽笛尽拉也拉不醒你，可是自己的只要呜的一声，就会使你一骨碌从床上跳起来。”

“我们一向所梦想的是什么呢？”奥尼辛叔叔解释说。当时他还不是宿舍管理员，而是支架工。“我们一向所梦想的是：有一天我们的矿井复兴了，我们的奶妈又能像从前那样向全世界放声高歌。可是现在怎样呢？复兴工作胜利完成了，可是马丽雅矿的嗓子却变了！太倒霉了……人家决不会知道马丽雅矿已经复活了……”

“我不是说过得报公安局吗？”矿长火冒十丈了。

“嗳，不行！”老人们还是不同意他的主张，“这样也不行。我们要用我们矿工的办法，来解决这件事……”

他们就照自己的办法去做。当天晚上，老人们（其中有些人才四十岁；但矿上所谓“老人”，并不是指年龄大的人，而是指工龄长的人）穿上自己的“做客”衣服——每人箱子里藏着的最好衣服：做新郎时穿的“三件头”<sup class="footnote-ref" id="note-ref-87-1"><a href="#note-87" aria-label="查看本页注释 87">[87]</a></sup>黑西服、又紧又硬的白衬领、下摆拖到上衣之外的花边衬衫；那些参加过战争的，穿着整整齐齐的缴来的军装，左面的袋口上别着一个游击队的红结；而那个残废的看守人莫凯伊奇甚至挂起了“乔治十字章”，并且无论如何不肯把这帝俄时代的奖章拿掉，他说这是他用血换来的。他们就这样浩浩荡荡地出发到莎菲亚矿去，去向邻人们打躬作揖，请求他们归还汽笛，并且情愿送几桶家酿烧酒作为赎金。

第二天清早，马丽雅矿的老汽笛又响了起来，它的吼声传遍整个寒气逼人的草原，荡漾在群山、浓雾和被露水浸湿的屋顶之上。虽然没有一个人被它惊醒——因为人人都在等它，根本没有睡觉——但大家都兴高采烈。一听到马丽雅矿熟识的声音，村子里的人们就四面八方地朝矿井跑去，他们的神气又幸福又骄傲。他们聚集在井筒旁边，长久地、声音嗄哑地、参参差差地、但却热情奔放地喊着“乌拉”，并且把帽子和手套抛到井筒里。

汽笛声长久地荡漾在草原的上空……

老人们听到汽笛声，画着十字，好像听见教堂的钟声一般。他们画十字，并非因为相信上帝，而是因为不知道用别种方式来表达自己的感情。矿工的老婆们把小孩子高高地举到头上，悄悄地说：

“你听，孩子，你听！……这是我们的马丽雅在叫哪。从此我们有面包吃了！……”

这件往事，也是那位一肚子故事的奥尼辛叔叔讲给孩子们听的。现在，在交接班室里的那场风波之后，斯维特里在下井去时，忽然莫名其妙地记起这个故事来。一想起来，他不禁又温暖又感动地笑了笑，好像在听奥尼辛叔叔讲故事一般。接着又莫名其妙地想：“我在现在这样的时候到马丽雅矿来，真是幸福！”

表面上看来，交接班室里的那场谈话一无结果：大家吵闹和嘲笑一通，就走散了。而安德烈在人声沸腾的交接班室里断断续续、匆匆忙忙叙述的创造纪录的思想，也无声无息地消散了，好像一根半燃的火柴，被人家漫不经心地抛在湿地上。但这只是表面的看法。这一层，斯维特里比谁都清楚。

那天他因为代理请病假的列斯尼亚克叔叔的职务，遇到许多人。他们全都有意无意地跟他谈起交接班室里的事件。马丽雅矿那种满城风雨的光景，斯维特里还没见过。七十吨，七十吨——安德烈大胆地提出的数字，在人人眼前跳动。不论怎样火辣辣的演讲，也比不上这个简单的数字“七十”，更使人惊心动魄。一个采煤工一班可以采七十吨，而现在他只能采十吨！人们在狭小的台阶——现在他们觉得台阶比以前更狭了——上转来转去，脑子里只是想着这些数字。人人都在估计，这件事他能胜任吗，办得到吗？有人相信，有人怀疑，有人嘲笑，甚至怀恨，但是，相信也好，怀疑也好，嘲笑也好，怀恨也好，大家都很激动。有人在这件事上看到自己矿井的光荣，有人梦想个人的荣誉，有人如痴如醉地盘算着，这样一来采煤工可以挣多少钱。那些文化水平较高的在计算，如果安德烈的方法行得通的话，全矿总共可以出多少煤——算出来的数字太大了，吓得他们目瞪口呆。但也有这样的一些人，他们在这个轰动全村的计划里，只提心吊胆地看到一点：从此以后十个采煤工之中，只有一两个可以留在场子里。因此，我也就不得不离开马丽雅矿了。可是我在这儿住了这么多年，已经习惯了。我在这儿有一座菜园，房子周围的小花园里，还种着几株樱桃树。再有马丽雅矿那只嘎哑的旧汽笛，我觉得要比任何新汽笛更加亲切动听。现在叫我抛下这一切，扶老携幼到哪儿去呢？

那天，组长马基楚克特地爬到维克多的台阶上去谈天。

“维克多，你这个家伙太大胆！”他讨好地对青年采煤工说，“你会搞出事来的！”

“得了，得了……”维克多叽里咕噜地说，“我不怕……”

“人人都在恨你和安德烈呢……”

“人人吗？”

“人人！没有一个例外！大家都很不高兴，他们说：嘿，难道这两个家伙比我们都聪明？他们要比我们挣得更多吗？我警告你，维佳，因为我很喜欢你……天有不测风云……矿井里暗角很多。”

“得了，别啰唆了！……”

“你们还是放弃这个主意的好，真的。”

“跟你有什么相干？”

“跟我吗？我倒没什么！……”马基楚克笑嘻嘻地说，但他的两眼却射出莫名其妙的凶光，“我是好意才这么说的。”

“你给我滚开，彼得留拉杂种！”维克多勃然大怒。“要不然，”他抡了抡风镐，“我就叫你先去见阎王。”

“好吧，好吧……”马基楚克一面嘴里叽里咕噜，一面爬开去。“我是好意。你一定要警告安德烈……”

他自己已经不敢爬到安德烈的台阶上去了。

这时，在安德烈工作的地方却来了个不速之客——差不多完全陌生的采煤工苏霍包科夫。这是一个沉默寡言的矿工，来到采煤区不久，下井的时间也不多。他从部队里服了超限兵役归来，所以非常想家。他没有问好，就在木柱旁蹲下来，一声不响地瞧安德烈搭支架。过了一会才问道：“你有一分钟的工夫吗？”

安德烈一句话不说，把斧头抛在一旁，用期待的目光瞧瞧苏霍包科夫。苏霍包科夫朝他爬得更近一些。矿灯的微光朦胧地照出他那张瘦削严肃的面孔、狭窄高耸的肩膀和那两条很长的手臂。

“你不必做什么鼓动，”苏霍包科夫预先声明，“我受过教育。你把你的计划实事求是地讲一讲吧。”说完，一动不动地等着回答。

在西面一个采煤区里做完工的米佳，出了矿井，在澡堂门口拦住斯维特里。

“你瞧！”他说，“我特地在等你。我问过看门的女人。她说你还没来洗过。”

“真的吗？”斯维特里笑着回答，“你找我有什么事呀？”

“你听我说！”米佳焦急地抓住他的手臂，“你是熟悉这件事的。我知道。我敢打赌这件事不会没有你的份。”

“嗯，可能的……”

“那么你只要告诉我一句话：这是痴心妄想还是可能实现的？你只说一句就够了。从技术的观点来说，”米佳喃喃地请求着，“我作为一个朋友请求你。”

“可能。”斯维特里简短地回答。

“这样说来，你们要实现了？”

“要实现。”

“但为什么要他们两人？”米佳酸溜溜地大声问道，“为什么要安德烈和维克多呢？这样的事为什么要他们来搞呢？”

“因为这是他们的主意，是他们想出来的。”斯维特里回答。可是米佳激动地打断了他的话：

“你听好，费佳！你知道我是土生土长的本地人。从小就在这个矿上。我的父亲是在这儿牺牲的，连他的尸体也没找到……说不定他的骨头正在这儿的什么地方枯朽着……为什么不轮到我，而轮到他们？不，费佳，你要了解，我是作为老朋友那样请求你。我心里从此不会平静了……”

谢辽查·奥且列金下工回到自己那所整洁的新房子里，也觉得心头失去了平静。现在什么也不能使他高兴了：不论娜斯佳手织的彩色地毯，不论盆里的无花果和镜子上的白杨枝，也不论窗明几净的会客室（当地叫“客厅”）——这间会客室平日不住人，但谢辽查从矿井回来，从煤灰飞扬的掌子里回来，老爱得意洋洋地往里边瞧瞧。他在这儿招待朋友、邻居和外地来的客人，他们都一致称赞娜斯佳的整齐清洁和善理家务，佩服男主人的采煤能力和挣钱本领。但此刻这间“客厅”既没使他快乐，也没使他觉得骄傲，连平日那种旺盛的食欲也消失了。他一点不想吃东西，虽然厨房里飘出来逗人的食物香味：娜斯佳正在那里起劲地制过冬用的果酱。一听到丈夫回家，连忙探出头来叫道：“马上好了，马上好了！”说完又回进去了。过了一会儿，她得意洋洋地端着一盘香喷喷热腾腾的东西在谢辽查的身边走过，接着又回来摆桌子。家里这种丰衣足食的光景，在过了几个配给制的艰苦年头之后，使谢辽查觉得格外感动，格外满足。这种光景昨天还使他觉得快乐，此刻不仅不能再安慰他，使他高兴，甚至反而弄得他心烦意乱，仿佛这些盘子和花盆，就是他今天烦恼的根源。

“七十吨，七十吨！”他一面想，一面不停地在房子里、庭园里、花园里踱来踱去，好像找不到一个安身的地方。“难道这是可能的吗？我怎么会没有参加这件事呢？难道他们真能成功吗？难道第一流突击工作者谢辽查·奥且列金这个名字就得落榜吗？”

“来吃吧，弄好了！”娜斯佳叫道。他勉强走到桌子边，闷闷不乐地坐了下来，心不在焉地开始吃饭。

看到他那紧张激动的神色，娜斯佳也吓得不敢作声，不敢问丈夫有什么事。她猜想他是在想矿井，矿井里一定出什么事了。

吃完饭，谢辽查仍旧不能回复平日的安静。他在房子里踱了个把钟头，然后抓起帽子，冲到街上去了。

“你上哪儿去呀？”娜斯佳醋意十足地追上去问，但他只不耐烦地挥挥帽子，就朝孩子们住的宿舍跑去了。

原来宿舍里已经聚集了一大批人。整个黄昏，谢辽查就坐在烟雾腾腾的房间里，听大家一直争论着那个问题——创造纪录的问题；他自己也参加了争论，最后变得快乐和轻松些了。

不过，临走的时候，他又把斯维特里唤到走廊里，悄悄地请求他，不要把他谢辽查·奥且列金隔在这件事情之外，仿佛一切都是由斯维特里一人决定似的……

当天晚上，查科留卡弟兄俩像平日一样一起在家里吃饭。查科留卡老大是个采煤工，查科留卡老二是个支架工。在交接班室里情绪昂奋地说矿井的计划太小、比起邻近几个矿井来太可耻的是老大。这时他在问弟弟：如果安德烈在交接班室里提出的办法可以实现的话，他是不是愿意跟哥哥配合起来工作。至于这个办法能不能实现，他凭自己丰富的采煤经验，是绝不怀疑的。

“我们准可以应付！”他在说服弟弟，“我采煤，你搭支架……好不好？可以采七十吨也不止。你只要心里算一算，数目有多大？”他们两人就这样一直谈到深夜。

那天夜里，安德烈好久睡不着。他知道将要有一场激烈的斗争，他已经做好思想准备，他知道退路是没有的，他也决不后退……那天夜里，聂察英科完全不曾合过眼。他有一个习惯，不论什么事，喜欢亲自追根究底。由于这个习惯，那天他拖了一大包书回家——凡是矿井里所有的关于开矿方面的书：教科书、手册、专论、讲义。他动手在里面寻找解答。自然，安德烈所提出的方法，他没有找到，一个字也没有找到，但也没有发现反对这个方法的论调。直到第二天早晨，他才彻底相信，创造纪录是可能的，他非常兴奋，认为这件事不能耽搁，应该马上到市委去一次。他明白他一个人是对付不了那个顽固的老祖宗的。他必须找到一个有气魄、有能力，尤其要在矿业方面有威信的人，因为只有这样的人才会镇静地倾听他的话，正确衡量这件事的价值，并且加以支持！

聂察英科希望能够在市委找到这样的一个人。他没有碰到罗亭，因为罗亭被叫到省委去了，但他遇见了市委第二书记华西里·谢尔盖维奇·茹拉符列夫。聂察英科就向他作了一个详细的报告。

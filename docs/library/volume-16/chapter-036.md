# 十六

一个人到了成年时期，就很少保持小时候的相貌，他的脸往往变得认不出来，只有在他孩子的身上，才能重新看到他儿童时期的面目。但也有人直到头发灰白，样子仍旧像他小时候的照片。这种人永不会发胖，永不会秃头，也永不会倚老卖老摆架子；不论给他们吃什么，他们总是那么瘦小；不论给他们什么职位，他们永远那么天真怕羞，不失赤子之心。这样的人差不多总是好人。

市委第二书记华西里·谢尔盖维奇·茹拉符列夫就是这一类人。

我认识他有许多年了，最近一次看到他还没有多久——在1950年。他的样子一点没有变，一点没有老。他那对诚挚的眼睛仍旧闪耀着温柔的光芒，即使在他生气或者骂人的时候，也不例外。

我有一张1922年的旧照片，那是马丽雅矿共青团支部的全体照。我爱看这张照片。我发现我的任何一个同时代人的历史，都应该从他的共青团时期算起，因为我们真正的生活是在团里开始的。

我凝视着这张照片，心里非常感动：上面的孩子们都是我所认识的。他们头发蓬乱，眼睛乌黑，穿着皮短衫，无忧无虑地坐在或躺在草地上。他们是第一批当矿工的共青团员，曾经勇敢地到隆隆谷打过土匪，参加过赤卫队，响应过第一次星期六义务劳动，后来又奋勇进入工人学校和专科——也是作过一番斗争的。

我知道他们每人的历史。瞧这个身穿父亲的旧上衣的孩子，后来成了工程师，现在在负责一个矿井；这个穿着没有钮扣的破旧敞领短上衣的顽皮家伙，现在是一名空军上将；这个穿黑色斜领衬衫、头发朝后梳的孩子，变成政治经济学教授；这个灰眼睛的家伙，成了模范矿工；而那个长着一对乌溜溜的黑眼睛、双手交叉在胸前、坐在中央的辅导员，现在已经是共和国部长会议的第一副主席了。

有时遇到几个老朋友，发现大家都变得很厉害，简直要认不出来了。只有一个人没有变，仍旧是照相里的那副样子——一个很瘦的小钳工，长着一对好奇的眼睛，那就是华西里·茹拉符列夫。他的外表一点没有变，也没有老，仿佛他知道永葆青春的秘密。我在1950年看到他，觉得他的样子仍旧跟1935年一样。

不错，他经不起老婆和同志们的再三责难，现在——1950年——终于打起领带，戴起大帽来了，并且早已习惯了。但在1935年，他还戴着鸭舌帽，穿着斜领蓝衬衫，衬衫上的白钮扣一直扣到喉咙，衬衫外面罩一件上衣，下身穿着长裤，裤脚塞在皮靴里——不论戴鸭舌帽，不论戴大帽，一眼看上去就知道他是一个共青团里的老干部，并且不是宣传鼓动员，也不是政治教员，而是共青团市委经济法律部的负责干部——那就是说，他是一个不知疲倦的青年工人利益的保护者，青年见习生的庇护人，矿业学校的组织者，工会里的共青团固定代表，工人俱乐部里青少年组的活动家——企业行政工作者的“冤家”，他们常常像逃避一只讨厌的苍蝇那样逃避他，有时甚至把他从办公室里赶出去，但最后差不多总是对他让步，同意他为青年工人所提出的要求，并且非常敬爱他。拒绝他是不行的。

从他那张开朗善良、稍微有些麻子的脸上很容易看出，他对人家的事情和利益，要比对自己的事情和利益重视万倍：事实上，他没有任何个人的要求。如果有人对他说：“你自己需要什么，你就去请求吧。”他准会弄得手足无措。他没有经历过贫穷，但也不知道什么叫享受。他在矿工食堂里吃饭，觉得心满意足；在矿工宿舍里过夜，睡得又香又甜。成了家之后，他也没有搞过家务，例如：养一头牛，种几畦菜，布置一座小花园。事实上，他并不反对这些东西，而且还鼓励别人去经营。他自己不搞，只是因为没有工夫。他的老婆也是个社会活动家，现在是矿工之妻委员会的主席。

茹拉符列夫一生从来不曾离开过群众。他爱他们，觉得他们虽然形形色色，但都很有趣，而最主要的是他们都需要他。他有一个习惯，最关心矿工的工资，关心他们的日常生活和需要，或者照他自己的说法，“连矿工的汤盆都要闻一闻”。他不是一个口若悬河的演说家，但在宿舍和交接班室里谈话，没有人比他更好。茹拉符列夫热爱工会工作，并且被公认是个矿工委的好主席。他连头发的梳法都是……“工会式的”：不是朝后倒梳，而是两边分开。

自从改做党的工作之后，茹拉符列夫明白他有很多东西需要学习。他的理论知识不够。不过，他在工作中遇到的人，都是矿山上的居民，是他从小就熟悉的。而在党的工作中，最主要的就是人。

不论党把他派到什么地方，茹拉符列夫总是立刻埋头工作，到市委去也是那样。他常常说，市委第二书记就像“拉一车木柴的马”，不过他自己拉车子，却很卖力，很高兴，而且不爱出风头。

聂察英科知道这一层。他知道茹拉符列夫不会把他撵走，不会打发他到下级机关去“预先研究”，他会马上亲自处理一切，像一个有经验的矿工那样仔细考虑，并且作出决定来。但到底会不会作出决定来呢？急性子的聂察英科总觉得市委第二书记过分谨慎小心，遇事不能当机立断。可是现在需要的正是当机立断！虽然聂察英科昨天还对孩子们说过，“这个问题不能草率从事”，可是到了今天，经过一夜的深思熟虑之后，他的看法就完全不同了。他认为现在已经不需要再考虑，一切都是明明白白的，应该行动，行动，立即行动。

他抱着这样的主意，走进茹拉符列夫的办公室，决定“用闪电战征服书记”。

“昨天我们在交接班室里出了一件大事。”他情绪激昂地说，连问好也忘了。

“什么事？”茹拉符列夫镇静地问。

“我们那儿的人反对旧的采煤方法，反对短台阶。”

“真的吗？！”

“他们要求重新组织场子里的工作，”聂察英科看到茹拉符列夫那副沉着的样子，更加起劲地嚷道，“茹拉符列夫同志，可惜您没听到他们说的话！”

“难道他们个个都这样吗？”茹拉符列夫眯缝着眼睛问。

聂察英科一时哑口无言了。

“您怎么，”他惊奇地问，“已经听说过了吗？”

“老朋友，这件事不是已经有一天一夜了吗？”书记开朗地笑了。

“是罗亭同志告诉您的吧？”

“不，罗亭同志什么也没说。我也只见过他一面。不过，我们是靠煤生活，在煤中呼吸的，而天下多的又是传闻。”

“那么您对这件事的想法怎样呢？”聂察英科压低声音问。

“我还没想过。我正打算去找你呢。”

“那么我们去吧！”聂察英科乐得跳了起来。

“晚上我会去的。现在你坐下来，把事情的经过详详细细讲一讲。我知道的只是些‘道听途说’。你要茶吗？”

聂察英科性急地坐下了，谢绝了茶，但把事情的经过讲得很详细，很周到；而对茹拉符列夫那些打破砂锅问到底式的问题，也回答得不厌其详，好像一个经验丰富的矿工。

“没什么了？”等书记的问题提完后，他满怀希望地问，“现在怎么办呢，茹拉符列夫同志？”

茹拉符列夫停了一会儿，好像很勉强地回答：

“怎么办吗？我先要见一见你那些孩子们。好吧，晚上我去一次。”

晚上他真的来到了马丽雅矿的党委会。

“嗳，聂察英科同志，那个在交接班室里发言的小伙子叫什么名字呀？”他问。

“安德烈·伏龙科。”

“啊，对了，对了！”茹拉符列夫不大记得人家的姓名，但却很记得人家的面貌，“是安德烈·伏龙科……我们到他那儿去吧。他住在哪儿，你知道吗？”

“知道。我已经通知他们了。他们等着哪。”

“好，那你带路吧！”

于是他们就向宿舍走去了。

孩子们等待着。靠着薇拉和奥尼辛叔叔的努力，房间收拾得非常整洁。里面闻得到艾蒿的气味。奥尼辛叔叔断定说，艾蒿可以防臭虫，臭虫极怕艾蒿。窗槛上放着一只很大的瓷花瓶，瓶里插着一束大红的石竹花，这是薇拉拿来的。“啊哈！”斯维特里开玩笑说，“这花真有意思！红色象征爱情。”但因为等茹拉符列夫，连他也有些紧张。维克多把刚才买来的书，放在架上最触目的地方。随后，他朝书架望了好一阵，终于心满意足了。维克多和大家一样，认为这一切——架上的书本、窗上的石竹、艾蒿的清香、干净的枕套、薇拉带来的花缎台布——此刻都非常重要，因为它们会影响采煤纪录能不能创造的问题。

茹拉符列夫和聂察英科终于来了。

经过一番介绍之后，大家在桌旁坐下了。主人们局促不安地沉默着。聂察英科也不说话。

“好吧，孩子们，我们就开门见山，谈谈正经事吧，”茹拉符列夫说，“如果我直率地问你们一些话，你们不会见怪吧？”

“不会的……”安德烈代表大家回答。

“你们提出自己的主意是出于正经，还是随便说说？”

“我们为了这个该死的主意，夜里睡也睡不着呢！”维克多热情洋溢地叫道，“我们呀……嗨！”他摆了摆手。

茹拉符列夫笑了起来。他喜欢维克多的这种热情。不过他想试一试孩子们的决心。

“这么说来，现在你们是不愿放弃自己的主意了？”他狡猾地问。

“我们决不放弃。”安德烈耸耸肩膀回答。

“好！”茹拉符列夫兴奋地说，“那么你们把计划再说一遍吧，要详详细细地说……”

安德烈跟同志们交换了个眼色，用拳头遮着嘴巴咳清喉咙，开始匆匆忙忙颠颠倒倒地把自己的主意说了一遍。茹拉符列夫听着他，微微地点着头。

“你是说，场子必须拉直吗？”他问。

“当然。”

“这需要相当时间。还有……”他若有所思地说，“如果暂时维持现在的台阶，先分分工怎么样？可以吗？”他没有把握地问。

“可是可以的，”斯维特里说，“只是效率没有那么大。”

“照你们的办法一班可以采多少煤呢？”

安德烈稍微想了想。

“我想无论如何六七十吨是有的。”他小心翼翼地说。

“一百吨不成问题！”维克多叫了起来。

“目前你一班采十吨吗？”茹拉符列夫问。

“有时可以采十二吨，”安德烈回答，“维克多可以采十四吨。”

“噢！”茹拉符列夫容光焕发地一笑。“十四与……一百！”

“那么您支持我们了？”安德烈快乐地大声问。

“这我可还没说过，”茹拉符列夫狡猾地眯缝着眼睛，“我说：孩子们，先要试一试。先要不声不响地试一试。如果试验成功，这件事本身就能说服人。”

“我们同意你的办法。”安德烈想了想回答。

“我想最好在夜里试，”茹拉符列夫补充说，“在进行修理的空班里。你说怎样，聂察英科同志？”他望望聂察英科。

聂察英科笑了一声说：

“不让老祖宗知道吗？”

“不，老祖宗由我来对付。要知道，他是矿井主人。没有主人的同意，即使夜里也不能在他的地方自由行动。”

“老祖宗不会同意的！”安德烈悲观地说，“我们已经请求过他了。”

“现在只好让我跟聂察英科同志两人去请求他了，”茹拉符列夫笑着说，“那么，孩子们，我们讲定了：夜里找一个进行修理的空班试，好吗？地点当然在你们的采煤区里啰？”

“明白了！”

“你们的采煤区长是谁？”

“是列斯尼亚克。他全心全意支持这件事的。”

“啊！那好极了！”茹拉符列夫满面春风地说，“那么，让他准备一个场子……”

“怎么，一个场子？”维克多叫道，“两个！我跟安德烈有两个人哪……”

“嗳，不成！”茹拉符列夫摇摇头说。“必须先试一个。两个，孩子们，两个不成，不成，”他摆着手，“那样你们会坏事的。而且老祖宗决不会答应给你们两个场子的。”

“不错！”斯维特里喃喃地说。

维克多不好意思地向众人瞧了一眼，垂下了头。

“那么好吧！”他勉勉强强地说，好容易忍住委屈的泪水，“你一个人去吧，安德烈……”他突然转了个身，朝窗口走去。

接着是一片难堪的沉默。“唉！这样不大好！”茹拉符列夫不安地想，“啊，真是为难！事实上，这是他们两人的理想，两人都有权利的。他们年纪那么轻，每人都想显一手；不让他们试一试，都会觉得委屈的。唉，糟糕！”但是他故意一声不响，认为这个问题应该由孩子们自己解决，用他们的友谊来解决。

聂察英科也一声不响。他好奇地一会儿望望脸色苍白的安德烈，一会儿望望维克多，说得正确些，望望他的背影：连背影也看得出心里的委屈——两只肩膀耸得高高的，头缩在肩膀里。

安德烈也沉默着。他眼睛瞧着地板，心里想着达莎。唉，要是达莎在场就好了！她准会解决这个问题。但愿她能真正了解他，不生他的气，不讨厌他……

最后，他抬起头来，慢吞吞地说：

“让维克多去吧……”

“不，不！”维克多猛然转过身来，暴躁地叫道，“我不去。”

“让维克多去吧！”安德烈又说了一遍。“他手脚比我快。他去可以采得更多些。这儿每一吨都能起作用！”他微微一笑，结束了自己的话。

茹拉符列夫仔细瞧瞧他，但什么话也没说。他们就告别了。

“那么，决定在9月1日的夜里吗？就这样决定吗？”

“我们准备好了。”

“那么好吧！我还会来看你们的！”茹拉符列夫一面说，一面同聂察英科出去了。

街上已经黑了。汽车停在党委会附近，司机在汽车里打瞌睡。

“那个淡黄头发的青年叫什么名字呀？”茹拉符列夫上汽车的时候问。

“安德烈·伏龙科，”聂察英科笑了笑回答。

“对，对……伏龙科，”书记若有所思地重复说，“嗯，现在再也不会忘了！”

# 十七

试验的日期终于决定了：9月1日的夜里。还有两天。

30日晚上，“作战本部”——斯维特里的说法——的全体人员聚集在列斯尼亚克叔叔的家里：安德烈、维克多、斯维特里、列斯尼亚克叔叔和达莎。他们只等聂察英科一个人。

安德烈已经告诉达莎，由维克多去创造纪录。

“为什么不是你去呢？”她惊奇地问。

“维克多比我强……”

达莎瞧瞧他，耸耸肩膀。他不安地问着自己：她对这件事的想法怎样？她了解我吗？

但他对自己的决定，从不后悔。

昨天茹拉符列夫和聂察英科一走，维克多就冲到他的前面，握住他的两手。

“朋友！朋友！”他热情地喃喃说，“这件事……我我……到死……到死也不会忘记的。我一定要加倍采煤，为了你，也为了我自己……将来荣誉也属于两人！”

安德烈只笑了笑作为回答。荣誉算得了什么呢？友谊更可贵。

那天夜里，孩子们差不多完全没合眼。他们一会儿翻来覆去地考虑后天“战斗”的细节，想起忘记跟聂察英科讲定，坑木必须预先在工作面上放好；一会儿又想起了很久以前的时候来，那等于是“史前时代”，当时他们刚到矿山，还不是矿工，而是石器时代的“穴居野人”，他们甚至不会拿工具，采不满定额，连累整个场子，因此很怕斯维特里……

“啊，我们当时实在怕你，团组长！”维克多坦白地说，“比见矿长还怕。”

“得了，得了，”斯维特里咕哝着，“反正现在是天不怕地不怕了。睡吧，别啰唆了！睡吧，小鬼！”

但是维克多一夜到天亮没安静过。第二天下井去时还是那样。在交接班室里，在罐笼里以及后来在掌子里，他始终手舞足蹈，坐立不安，嘴里说个不停，弄得斯维特里很担心，怕维克多在创造纪录之前用光精力，等到进行试验时，就会筋疲力尽，萎靡不振。可是，维克多的精力是使不完的。他的体内仿佛贮有大量的电能，足够推动矿井里所有的电车。他满面红光，一身活力，而且相信自己的精力是用不完的。他精神焕发，得意洋洋，好像一个历尽曲折终于踏进理想之境的人一般。达莎向他瞧瞧，一面瞧，一面情不自禁地微笑。

最后聂察英科来了，并且不是独自来，而是跟老祖宗一起来的。这实在是出乎意外，弄得“本部”里的人员都手足无措。他们甚至忘记站起来迎接老头儿。

老祖宗却镇静地走进房间，冷冰冰地向大家问好，只有对斯维特里却充满敌意地白了一眼：他不能原谅他的“尾巴主义”。

列斯尼亚克叔叔马上冲到厨房里去了。

“老祖宗来了，板着脸……”他叽里咕噜地对老婆说，“快烧些土豆吧，老太婆！……也许让他吃些土豆会和气些……”

等大家安定下来，坐好了，聂察英科快乐地问道：

“嗳，怎么样，孩子们，没有改变主意吧？不让步吧？”

“聂察英科同志！”维克多叫道，“您这算什么话？要是现在叫我放弃这件事，老实说，我情愿跳小井！……”

大家都笑了。在这一分钟里他的样子格外可爱——一个鬈发的矿工英雄。连老祖宗也情不自禁地对他笑了一笑：看到矿工的英雄气概，老头儿也不能无动于衷。

“好吧，既然这样……”聂察英科说，于是“本部”的会议就开始了。

决定让维克多在他的场子里进行试验。压缩空气的供应由总工程师负责，老祖宗将亲自检查。坑木将预先在工作面上放好。并且决定派查科留卡老二和包罗伏依替维克多搭支架，他们两人都是共产党员。聂察英科已经跟他们讲过了。

“他们很好，”维克多表示同意，“都是能手。”

“还有运煤……”斯维特里说。

“煤车会准备好的。赶车工可以早晨通知，叫他们做夜班……”

“如果你们同意，”斯维特里小心翼翼地瞧了老祖宗一眼，说，“我愿意监督运煤工作……”

老祖宗一声不响。

“好的！”聂察英科说，“还有什么？”

“风镐，我明天一早预备，你们不要交给任何人，”维克多警告说，“我要亲自检查。”

“风镐我们会替你注意的，”聂察英科笑着说，“你自己，好朋友，明天白天得好好睡觉。”

“那可绝对办不到！”维克多叫道，“我不采满一百吨煤，决不合眼。”

“你得睡觉。你要遵守党的纪律，”聂察英科说，“安德烈同志，这件事你去负责。”

列斯尼亚克太太端来了热气腾腾的土豆、冷盘和伏特加。

“来吧，祝事情胜利完成！”列斯尼亚克叔叔高擎酒杯，说。

大家都热热闹闹地碰了杯，一饮而尽。

老祖宗出乎意料地说：“我这么做是违反自己的本心，违反自己的意思……”他摇摇头，叹了一口气，“是的……我显然是老了，老了……我该告老还乡了，但我不愿妨碍青年人的事业。”他摆了摆手，拿起酒杯。

大家都懂事地一声不响。聂察英科说：

“茹拉符列夫同志来过电话。明天夜里他会来的。”

“那好极了。”列斯尼亚克叔叔兴奋地接着说。

于是大家又谈起创造纪录的事来了。

老祖宗却皱紧了眉头，一声不响地吃着土豆，同时想着：他真的老了，老了，而且凡是他所爱好、了解、宝贵和欣赏的东西，也都随着他一起老了。就连土豆也不同了，没有以前那么香甜可口了……而周围的世界却在变，变得年轻起来……

他忽然想起了1919年……想起了最初的几次共产主义星期六义务劳动……当时他怀着满腔热情工作，并且还鼓舞别人；他做无报酬的工作，比做领工钱的工作更好，更卖力，他装煤给莫斯科，装煤给列宁……

为什么现在他不能了解安德烈和维克多呢？难道他们不是他的孩子吗？说不定他们的心里也熊熊地燃烧着热爱祖国和效劳祖国的火焰呢——这种伟大热烈的爱国心，自从劳动大众掌握政权的那天起，就存在在每个劳动者的身上。他忽然怀着羡慕的心情想：“列斯尼亚克年纪比我轻不了多少，可他却跟他们在一起。”

而他的周围，人们在快乐地喧闹着：叮叮当当地碰杯，喝酒，异口同声地唱歌。他们热热闹闹、诚诚恳恳地欢乐着，好像矿工参加婚礼、洗礼和命名日一般。然而这却不是结婚，不是命名，不是行洗，也不是新年的宴会……这是人们在庆祝创造劳动的前夜。理想在实现中！劳动成为喜事了！

而那个准备明天去创造奇迹的人，此刻比谁都开心。他唱得最响，喝得最多，但是没有醉。最后他走到房间中央，跺跺足叫道：“喂，来跳矿工舞吧！来吧，达莎！”他不等她出来，自己就在地板上跳了起来。

第二天早晨，维克多醒得最早，并且叫醒了同志们。他实在焦急得受不了。他老认为会出什么意外的事，这样他的试验就要取消。他没有吃早点，就跑到矿上。在工具间里拿了自己的风镐，把它拆开，用火油洗净每个零件，然后抹上机油。

他的周围聚集了一批钳工和机工，不怀恶意地取笑他说：“维克多，你简直把风镐当作爱人了……孩子们，瞧他对它多么温柔！……”

关于试验的事，他们一点也不知道。一切都保守秘密，这是做事细心的茹拉符列夫的主意。

“维克多，你这个人老爱自作聪明，”工具间的“上帝”，麻子脸的克伐施宁生气说，“难道装修工具的本领，我们还不如你吗？”

“得了，得了，”维克多不愿跟他啰唆，“我们认得你，计件工……”

他装好风镐，接上压缩空气试了试。风镐转得很轻快，很均匀。他用纱头把风镐擦干净了，交给值班的钳工。

“听好，”他严厉地警告那个钳工说，“不要交给任何人！不然要你的命！”

随后他跟安德烈跑到交接班室里。他们在那里遇见支架工查科留卡老二和包罗伏依，大家就商量了一下，把事情安排定了。

矿上没有别的事情要做了。

“走吧，去吃些东西吧。”安德烈提议说。

维克多叹了一口气，无可奈何地同意了。是的，现在只好耐着性子等天黑了。

吃了早饭，安德烈说：“那么现在，维佳，该睡觉了！”

“睡觉？”维克多哭丧着脸说，“嗳，安德烈，好人儿，你说现在叫我怎么睡得着呢？”

“睡觉，睡觉！”安德烈笑着说，“你要遵守党的纪律。”

安德烈领着苦闷而顺从的维克多回家，逼着他脱去衣服躺下，自己又周到地替他盖上一层薄被。

“现在睡吧！我也要躺一会……”

使他惊奇的是维克多居然马上睡着了：这两天来他实在很疲劳。可是安德烈却睡不着。这些天来，他心里也非常激动，只是不像他朋友那么浮躁。正巧相反，安德烈心里越激动，表面显得越镇静沉着，越不动声色……他也在担心，怕老祖宗忽然改变主意，或者发生什么意料之外的事……只有一点他绝不怀疑，那就是维克多一定能成功。“维佳干得了的，他不会坏事！”他热情地想，“这次的试验我不做他做，那是对的。他精力旺盛，而且比我更热心。”

他躺不住，起了身，轻轻地把一张椅子挪到好朋友的床畔，坐了下来。

“让他好好地睡一觉！”他想，“现在他需要的是力气。他采得满一百吨吗？一百吨多好……如果采满一百吨——马上就会传开去。以后我也用同样的方法……一百吨采不到，八九十吨总可以的。以后让谢辽查·奥且列金、米佳·查柯尔科、苏霍包科夫……说不定别的矿井也会注意……那我们就可以供给更多的煤。生活就会变得更美好！”他突然想起达莎来。是的，达莎。他叹了一口气。她不久就要走了。再过三天就要走了。到莫斯科去。有什么办法！她去学习。漂亮！而他却留在这儿。是的……他又能上哪儿去呢？……可是他们还没好好地谈过一次话。甚至没有表白过心事。应该怪他不好，太胆小。但这些事以后再说吧，等创造了纪录再说吧……将来一切都会解决的，一切都会自然而然地安排得称心如意的……

他沉迷在幻想中，没有发现暮色已经从窗子里溜进来。他只看到维克多的脸忽然变暗了。

“现在几点钟啦？”安德烈清醒过来，悄悄地瞧了瞧挂钟，才安了心。“让他再睡一会吧。还早呢。”他又想起心事来了……不过现在连安德烈自己也说不出在想些什么了。他的思想断断续续，模模糊糊，瞬息万变。

忽然一阵笃笃的敲门声把他吓了一跳。达莎冲进房间，在门槛上就嚷道：“妈妈叫我……”

“嘘！轻点儿！”安德烈向她摆摆手，指指睡在床上的人。

达莎连忙停住，而且吓得用手掌捂住了嘴巴。随后她小心翼翼地蹑着脚走到安德烈跟前，低低地说：“妈妈说，叫维克多不用到食堂去了。吃的东西她都亲自给他准备好了……”

“好的，好的……”安德烈也低低地回答，“只是让他再睡一会儿吧。再稍微等一会儿……你坐吧，坐吧……”

达莎竭力不让凳子发出响声，也在床旁坐下了，而且也像安德烈那样，眼睛望着维克多。

维克多安安稳稳地睡着，并且显然在做着快乐的梦——他在微笑……达莎想起几天前他也同样躺在她的面前，那一次他喝醉了酒，显得非常软弱可怜，好像一个小孩子……但此刻他很强壮，很威武，他就要去创造纪录了，他要独个儿扫荡整个煤层，到明天全矿就会知道他的光荣……此刻他躺着，在梦中微笑，又可爱，又可笑……

她忽然感到世界上没有一个人比他更亲近更可爱的了，她爱他，是的，爱他……一种又快乐又痛苦又幸福的感情紧紧地控制了她，这是她从没体验过的。她猜想这就是爱情，就是歌曲里所唱的、书本里所写的爱情……

她自己也被这个意外的发现惊动了。难道真是这么一回事吗？——她猛然醒悟过来。这个意外的“灾难”怎么会落到她头上来的呢？这几天，大家谈到维克多，想到维克多，大家都喜欢他，称赞他，照顾他——不论父亲，斯维特里，聂察英科，都一样，而安德烈甚至守着他睡觉……结果，她受了大家的影响，把钦佩和友谊当作爱情；不过这一切是马上会弄明白的，马上会过去的……

但是她的心却对她说着另外一套话。她的心此刻被一种疯狂的欢乐所陶醉，已经无法自制了。她忘了世界上的一切，贪婪地瞧着那张亲爱的脸——维克多的粗鲁、恼人而爱嘲弄人的脸。天哪，为什么她爱的正是他，而且对他百看不厌呢？她的眼睛里闪出那么磊落、那么热烈的爱情的光芒，以致安德烈无意中看到她的目光，心中就完全明白了……

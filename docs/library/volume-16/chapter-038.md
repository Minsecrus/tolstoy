# 十八

至于维克多呢，他在床上翻来覆去，过了一会儿就睡着了，根本不知道身边有热情的浪潮在汹涌澎湃。

一只苍蝇落在他湿润的嘴唇上；安德烈无意识地把它赶走了。苍蝇愤怒地嗡嗡响着，在他的头上盘旋。

“原来如此！……完了！完了！”安德烈呆若木鸡地对自己说着首先想到的几个字眼；他不断地重复着，甚至没有想到这几个字眼的意义。奇怪得很，他一点不觉得痛苦，仿佛这个意外的打击把他吓呆了，变成化石了。“原来如此！完了！完了！”他不断地重复着说。

达莎怯生生地抬头向他望望：她觉得安德烈非常镇定；只是他的脸色有些发白。达莎明白安德烈已经猜到一切了。

她不知道现在应该怎么办，应该说些什么……她想不出什么话对安德烈说，而他也不问什么，只是一动不动地坐着。达莎觉得无法再在这儿待下去了。“天哪，怎么会弄得这样糟呢！”她偷偷地对维克多瞅了一眼：在黄昏的微光中，他的脸显得很暗，但他始终在梦中微笑。他决不会想到达莎在爱他，永远不会……她猛然想到自己又在向他出神，如果被安德烈看见，他会痛苦的。她霍地一下站起来，飞快地跑出了房间。安德烈一动不动。

直等跑到街上，她才如释重负，同时觉得非常快乐。“我真爱他，真爱他，真爱他！”她一面想，一面带跳带跑地穿过荒地。“天哪，这多美啊，多……羞人哪！但他永远不会知道的。也没有人会知道。永远不会！”

“但这一切是什么时候发生的？我什么时候开始爱他的——现在还是以前？为什么我不爱别人而爱他呢？不错，他人品好，他强壮，他乐天，而且长得又英俊。但开头我觉得他很笨，简直一点也不喜欢他。我甚至于瞧不起他。我本来以为我爱的是安德烈……天哪，我多么放荡啊！”想到这儿，不禁觉得一阵心战。“难道我两个都爱吗？”

“不过我对安德烈的爱完全不是这样的。我爱他，像爱自己的哥哥一样。我尊敬他。但对维克多呢……对维克多怎样呢？”

她心慌意乱。这是她的初恋，是她第一次打开心房去迎接这种伟大而新奇的感情，于是她这个顽皮、大胆而自负的矿工女儿立刻变为一个坠入情网的怕羞的姑娘了……

可是，难道一个普通的姑娘能够解释：为什么她爱这个而不爱那个？为什么她会坠入情网？

不管怎样，她已经在恋爱了，而且自己知道这一点。她一面感到幸福，一面又害怕幸福；她的内心又快乐，又慌乱，她说不出是惊是喜……只有想到安德烈，她那种新的幸福才受到影响。“现在叫安德烈怎么办呢？他实在是爱我的，他相信……”但她马上又安慰自己：“不要紧，他很坚强。他很快就会熬过去的。何况再过三天我就要走了。”

可怜的安德烈！他将一辈子被认为坚强的，因此也永远不会有人怜惜他！

“这就完了！完了！不必再去想它了！”他自言自语地说，仍旧一动不动地坐在好朋友的床畔。“这件事是无法可想的。无法挽回！无法补救！而且谁也没有错。维克多固然没有错，达莎也没有错。只能怪我天生没有这样的幸福。”

此刻如果有人推醒他，把他从茫然若失的境地中拉出来，并且对他说：“你不要屈服！你要斗争！去争取自己的幸福，去进行竞争！”他怕只会又惊奇又痛苦地笑着回答说：“何必呢？难道值得因此举行决斗吗？跟谁呢？跟维克多吗？可是我知道他比我好。我自己也爱他。同时我也爱达莎。我更愿她幸福。”

“不，这儿谁也没错……这件事是无法补救的……无法补救的……”

“而且我也不要夺取别人的幸福！”

他忽然想到该叫醒维克多了。见鬼，为了这个倒霉的爱情，他把主要的事情都忘了。

“维佳，起来！”他小心翼翼地摇摇朋友的肩膀，“起来，时候到了！”

维克多一骨碌跳了起来……

“什么？睡过头了吗？”

“没有，不过是时候了……”安德烈一面扭亮电灯，一面回答。

“嗳，我也睡够了！真舒服……”维克多伸着懒腰说。接着他无意间瞧了一眼好朋友，大吃一惊：

“安德烈！你怎么了？”

“什么事？”

“你的脸色多难看！……出什么事了？……”

“没什么……”安德烈勉强回答，“快穿衣服吧。嗯，还有……”他像才记起来似的说，“刚才达莎来过了，他们做好饭，在等你呢……”

“啊——啊！”维克多笑了一笑，“那好极了……”

他们穿好衣服，就到列斯尼亚克叔叔家去了。

“瞧，他们到底来了！”列斯尼亚克叔叔不耐烦地大声说，“请坐！请坐！牛肉菜汤要趁热。列斯尼亚克太太今天给我们做了一碗出色的牛肉菜汤：里面和着荞麦粥。”

“牛肉菜汤，太好了！”维克多笑眯眯地说，在餐桌旁坐了下来。一个真正的矿工难得吃煎牛排、牛肉饼和别的单薄的菜；他认为这种菜不够味，天下最可口的东西，还是矿工的牛肉菜汤。这汤的原料实在丰富：其中有番茄、青菜、卷心菜、每人足有一公斤的牛肉、红辣椒，上面再要浇一层厚厚的酸奶油。

“不错……出色的牛肉菜汤！”维克多一面说，一面贪婪地向食物扑去，“吃了这样的好汤，两百吨也采得到……”

“那么多吃一点吧！”女主人殷勤地说。

可是安德烈却勉勉强强地吃着：食物在喉咙里哽住了。他一声不响地把头冲在盆子里，竭力避免跟维克多的目光接触，至于达莎他根本没看到。她躲在一个角落里，从那儿悄悄地望着维克多；她很喜欢他吃的样子：狼吞虎咽，津津有味。事实上，他的一举一动，她现在都很喜欢。

正吃得起劲的当儿，聂察英科来了。大家立刻发现他的神色很激动，不觉大吃一惊。

“出什么事了？”维克多惊慌地问，他的脸色发白了。他以为试验取消了……

“出大事了！”党组长回答，“刚才茹拉符列夫同志打电话给我，他说有一个消息——在中央伊尔明诺矿，采煤工斯达哈诺夫一班就采了一百零二吨。”

“什——么！”维克多惊奇得说不出话来。

“斯达哈诺夫？斯达哈诺夫是谁呀？”列斯尼亚克叔叔惊慌失措地嘟哝着，“从来没听说过……”

“他采用的也是那个方法：分工，”聂察英科继续说，“他自己采，支架工替他搭支架……”

“这样说来，他们抢在我们的前头了？”维克多苦笑着说。他拿那盆出色的牛肉菜汤向前一推，把剩下的汤汁都泼在台布上，站了起来。“完了！”他哑着嗓子说，“我们回家吧！”

“这又是干吗？”聂察英科问。

“回家去吧，五分钟的英雄！”维克多勉强克制感情说，重手重脚地推开椅子。

“嗳，等一等，傻瓜！”列斯尼亚克叔叔阻止他说，“等一等，坐下！……聂察英科同志，”他对党组长说，“你说那个斯达哈诺夫采了几吨啊？”

“一百零二吨。创世界纪录。”

“但维克多可以采得更多！”老头儿叫道，“他会超过斯达哈诺夫的！他会证明像斯达哈诺夫那样的采煤工世界上决不止一个……”

“如果努力一下，可以采一百十五吨！”安德烈激动地说。

现在大家都望着维克多。而他却站着，在信任、友好和温暖的目光下慢慢地安静下来。他觉得他恢复了力量，恢复了勇气和自信……

“好吧！”他终于摇摇鬈发说，“我们要创造纪录！去吧！”

“这样才对，老弟！”聂察英科眉飞色舞地说，“即使不能超过，而只是重复斯达哈诺夫的纪录，证明他的成功并非出于偶然，那也就很不错了！”他的眼睛闪耀着光芒，此刻他比谁都看得远。“走吧，朋友们！走吧！……”

“不，等一等！”列斯尼亚克叔叔严厉地阻止了众人，“走这样的路，必须坐一会儿。”<sup class="footnote-ref" id="note-ref-88-1"><a href="#note-88" aria-label="查看本页注释 88">[88]</a></sup>

大家连忙都坐下了，并且像听到命令似的都一声不响。安德烈甚至闭上了眼睛。

在这千载难逢的一分钟里，各种光怪陆离的幻象和英勇大胆的希望都在安德烈的眼前闪过，在这个鸦雀无声的房间里的每人眼前闪过，仿佛大家都在向未来眺望。

“好吧，维克多！”列斯尼亚克叔叔庄重地说，“但愿今天你的手特别有力，你的镐齿特别锋利，而煤炭特别松软。现在我们走吧！”

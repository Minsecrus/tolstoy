# 二十一

1935年的整个9月，我差不多都是在顿巴斯过的，我永远不会忘记这些日子。大家有一种感觉，仿佛周围的一切都一下子离开了原位，摆脱了常规，毫无顾虑地勇往直前；因袭的垣墙倒塌了，陈旧的堤岸决口了，人的面前突然打开了一望无际的前途，使人惊奇得目瞪口呆……这些日子顿巴斯矿区所发生的一切，诗人会拿它比作伏尔加河上汹涌起伏的春潮，比作叶尼塞河大水冲击期的北冰洋的浮冰，甚至比作在无底深渊上突然涌现新的山峰和土地的地质上的激变。不过所有这些诗人的比喻，终究还不能说明1935年9月顿巴斯所发生的事件，因为当时在活动的不是冰，不是水，不是山，而是人。

人……在报纸上他们已经被称为苏联勇士了。一个矿工在一班的工作时间里采了六节火车的煤，的确像民谣里的勇士，称得上是现代的伊里亚·摩罗梅茨；起初人们简直无法相信，一个普通人可以完成这样的业绩。但斯达哈诺夫的纪录很快就被超过了，而且超过的不止一座矿井；竞赛的火焰从矿井蔓延到工厂；关于铁工布塞根、两位织工维诺格拉多娃、鞋工斯美坦宁的新闻也传布开来——于是，听着这些新闻，每个工人都觉得他自己的心里也磅礴着英雄的气概，焕发着快乐的光彩。

每座矿井都出现了自己的英雄，而且不仅限于采煤工，也有割煤机司机、赶车工、掘进工、石工、支架工和机工。新的名字不断涌现，而且立刻在顿巴斯出了名；人人都觉得光荣！而采煤区长、工程师和技师却大伤脑筋：矿工们不断向他们进攻；人人都提出自己的建议，人人都在自己的工作上发明新东西，人人都要求进行实验……老规矩和老定额被摧枯拉朽地冲破了，顿巴斯只听得一片闹声……

人们再也无法平平静静地独自待在家里了，他们情不自禁地想到人群中去。在进出口的大门旁，在张贴报纸的玻璃窗前，一天到晚围满矿工。他们贪婪地读着有关新纪录的消息，专心地听着无线电的播音，向矿党委打听新闻……好像人们在战时打听前线的消息一样。战事的捷报往往能鼓舞后方最冷静最安分的人，使他们强烈地羡慕前方战士，并且自己也想上火线；同样地，这些关于斯达哈诺夫纪录的消息，也激动了最安分守己的人，引得他们也“技痒难熬”。办事处会突然闯进一个退休已久、领养老金过活的老矿工来，要求让他也到工作面上去。共青团员略波康从医院里跑来。他是第二采煤区的一名采煤工。

“我身体很好，我什么病也没有！”他热烈地、但却徒然地想说服聂察英科，“我心里有病，因为怕落在人家后头！”

在地面上从事辅助工作的工人也跑来找党组长，要求他设法把他们调到地下去。连宿舍管理员奥尼辛叔叔和仓库管理员布尔金——他本来也是支架工——也提出了同样的申请。而且两个老人天天早晨去见聂察英科，打听申请的结果怎样……

在那些日子里，个个矿井的党委会都像一座革命司令部；许多非党员在这一个月里也时常到这儿来，有些还是生平第一次。党委会的小房子挤得很，有人就徘徊在门口、走廊和院子里，有人就坐在阶沿上和庭园里的橡木长凳上，吸着烟，等待着；有人在街头的深红色枫树下聚成一堆，身体依着鹤嘴锄、风镐、铁杆和铁楔，好像赤卫军倚着步枪一般。他们低声地谈论着，谈的都是同一件事：新的运动，地底下的革命……

村子里到处都在谈论新纪录、斯达哈诺夫工人的巨额工资、矿井里的变化——不论在俱乐部里，不论在单身汉的宿舍里，不论在澡堂里，不论在牙医生的待诊室里，不论在食堂里，不论在理发馆里，甚至在市场上那些不久之前改名为“小吃馆”的历史悠久的酒吧间里……

“嗳，现在保持纪录的是谁呀？”理发师一面用肥皂沫涂着我的面颊，一面问，“已经不是阿勃罗西莫夫了吧？”

“扎巴拉。”

“啊！知道！黑头发的，是不是？剃刀没刮痛吧？”

“不，没什么……”

“不过阿勃罗西莫夫还不会罢休，不会！”理发师说，“他跟伏龙科又会想出什么新主意来的。一定会的！他们会动脑筋。现在开矿都用新办法。”

“真的吗？”

“当然啰！打井筒用新法，开场子用新法……还有，您没听到过落顶板的新方法吗？”

“没有。”

“真的吗？”于是他就讲给我听这个新方法，一会儿用矿工的术语，一会儿用理发师的术语。例如说：“搭密列支架好像‘一把梳子’”，或者“剪得像用‘三零’剪发器<sup class="footnote-ref" id="note-ref-95-1"><a href="#note-95" aria-label="查看本页注释 95">[95]</a></sup>剪的一样整齐……”不过他讲得很起劲。

在那些日子里，我最爱挤在交接班室里。那里特别有趣，特别热闹。理发馆、市场、公园、俱乐部——这些都是第二梯队，都是后方。但交接班室已经属于先头阵地了，矿工们在这儿请求战斗任务；他们总是经过一番考虑才请求的。在那些日子里，我在交接班室里没有看到一个懒洋洋地袖手旁观的人。大家都围集在自己的组长的周围。

“叶戈尔·米那伊奇！叶戈尔·米那伊奇！”一个戴钢盔的塌鼻子青年在这样的一小组人中喊着，他腰间挂着一绞绳子，由此可知他是一个运木工。“那么您到底怎么说呢？”

“我不说！”叶戈尔·米那伊奇低声地说，他脸色忧郁，上了年纪，胡子完全盖没了嘴唇。

“不说？！”

“不说。”

“为什么不说呢，叶戈尔·米那伊奇？”

“因为我不愿丢脸。”

“那么我们来说吧，叶戈尔·米那伊奇！您只要听我们好了！啊，叶戈尔·米那伊奇？”运木工用恳求的神情盯着小组长的脸，热情而温柔地嘟哝着，焦躁地等着回答。“您要，我再拿全部计划向您解释一遍吧！……嗯？”

“不。”

“不？！”

“不。”

“那么您到底怎么说啊，叶戈尔·米那伊奇？”

我的周围到处都是这种热烈的耳语。

“难道我们真要落在人家的后头吗？”红头发的美男子米佳·查柯尔科在一个采煤工小组里说，“不，随便你们怎样，我还是要挑战的。”

“是——吗……能不能成功……”一位同志犹豫不决地反对他，但在他的眼睛里也露出了兴奋的光芒。“得考虑一下。”

“据说，红色游击队员矿的扎巴拉采了一百五十吨。”

“哼，这是胡说！”

“大家都那么说……”

“一百五十吨？那么他挣了多少钱？”

有人当场计算了一下。数目很大，但谁也不觉得惊奇。大家对创造纪录者的巨额工资已经听惯了。交接班室里天天都有大字报挂出来：某某矿工完成了百分之几的定额，得到了多少工钱。工人们谈到工资总是很起劲，从来不隐瞒。

“随便你们怎样，”米佳·查柯尔科闷闷不乐地说，“我还是要向维克多挑战的。我又不是第一次向他挑战！”

我亲眼看到米佳·查柯尔科实践自己的诺言。在交接班室里举行的群众大会上——现在几乎天天都有会——维克多大声宣布：

“朋友们，我再要创造新的纪录！现在我暂时不说什么，不过相信世界纪录一定属于马丽雅矿的。完了！”

他还站在讲台上，可是米佳·查柯尔科已经掮着风镐向他走上去。

“我向你挑战，维克多！”他大胆地说，接着用右手稍微举了举风镐。“我要在自己贫瘠的煤层上打破你的纪录……大家听到吗？”他转动身体，叫道，“请大家记住！”

他还来不及下去，谢辽查·奥且列金也走了过来。

“我也向你挑战，维克多！”他一面说，一面不断地䀹动两道白蝴蝶似的粗大睫毛。“窍门现在我们知道了。我不吹牛，我要达到百分之一千！”

于是，就像决堤的河水一般，矿工们一个接着一个向维克多挑战，有的单独一人，有的整个小组，有掘进工，有运木工，有支架工，有点炮工，他们在讲台前站了一分钟，宣布了自己的挑战就走……叶戈尔·米那伊奇小组里那个大胆的运木工也在这儿；他走在自己小组的前面，用公鸡似的、由于激动和骄傲而断断续续的声调，喊出了自己的挑战。叶戈尔·米那伊奇阴郁地板着面孔，走在他的后面。他一声不响地点了点头，表示同意挑战。

安德烈站在我的旁边。他留神地观察着周围所发生的一切。他觉得满意吗？我从他的脸上看不出什么来。

“嗯，现在竞赛展开了，您满意吗？”我悄悄地问他。

“是的。这是竞赛！”安德烈回答，“整个矿井都动起来了！”他腼腆地笑了笑。

但他马上又变得紧张起来了，我不了解是什么缘故。这当儿，采煤工查科留卡老大也向维克多挑战。安德烈突然抛下了我，匆匆地爬上讲台，站在维克多旁边。直到后来我才知道是怎么一回事：原来安德烈恐怕自尊心很强的维克多会因为人家大胆的挑战而生气，并因此出口伤人。

当时我还看到一幕小插曲，但我不懂它的意思。在第三采煤区的窗口附近，离开我不远的地方，矿长老祖宗全身靠着手杖站着，他的旁边是一个瘦弱的白俄罗斯矿工，留着稀稀零零的亚麻色胡子，脖子又细又长，好像仙鹤。他老是伸长脖子，而且还跷起脚跟，因此看上去更像一只仙鹤了。他非常激动：他的脸上交替地反映着各种不同的感情——从胆怯到勇敢。

最后他振作精神。

“我也去，好吗？”他用出乎意外的低音说，“你祝福我吗，格列勃·伊格拿托奇？”

“站住，康德拉特，不干你的事！”老祖宗轻蔑地阻止他，“你去干吗！也想出风头，不怕人笑话……”

“不，我要去！”康德拉特固执地重复说，“哼，我们也不比人家差。”

他真的走了出去。我看到矿长怎样变了脸色，目送着他上去。他的目光里充满惊奇、悔恨、狼狈，甚至羞耻。为什么会羞耻呢？但是我怎能了解这刹那间在老祖宗的心里产生了什么，破碎了什么，崩溃了什么，当他看到那个一向落后的矿工康德拉特——他是那批使老祖宗常常担心的矿工之一——向讲台走去，并且撩起胡子，大胆地向维克多挑战？！

“瞧！是你！”维克多大吃一惊，“你也来吗，康德拉特？”他向安德烈回过头去，快乐地笑着喃喃说：“你瞧，安德烈，怎样的奇迹啊！我们把人民都唤醒了。嘿，我们干得真不错！”接着他突然挺直身体，举起矿灯，兴高采烈地对交接班室里所有的人叫道：“我接受！所有的挑战我都接受！我祝全体向我挑战的人，我诚心诚意地祝你们把我打败！为了我们亲爱的矿井。好吧，不过我也不会停留不进的！”他夸奖地补充了一句。“朋友们，努力吧！……我说得对吗，安德烈？”

“对！”安德烈笑了，“可是你自己也要努力！现在我也要向你挑战……”

# 二十四

罗亭觉得很懊恼。这样的懊恼恐怕有生以来还是第一次。在马丽雅矿开完了党员大会，他就一直坐汽车到市委会去。他走进办公室，一面走，一面怒气冲冲地吩咐女秘书，不要让任何人进去打扰他。

“茶，给我茶！”他在门口就大声叫道，“要浓一点的！”然后走了进去，随身锁上门。

他已经明白，在马丽雅矿犯了错误。“啊——啊……”他烦恼地皱紧了眉头。“我做得多笨哪！”他像平时一样，想起自己行动上的小节，特别痛心，而且认为这些小节就是最可耻的事。“我好像还怪声地叫了一次……”他痛苦地想，“真是太庸俗！简直像神经病！”他愤怒地把烟蒂揿在烟灰缸里，接着又点上一支烟，拼命地吸着。近来他烟吸得很多，真是不应该！每天早晨总觉得有些恶心，嘴里老是有一种苦涩的味道。“近来一切都垮了：心脏、神经……”他在办公室里踱来踱去想，“我搞得筋疲力尽，一身是病。这就是错误的原因。可是现在他们竟说我压制批评。那真受不了！”

是的，这是一个错误。这以前所发生的一切也是错误，一连串的错误。此刻罗亭已经不像昨天那样自以为是和若无其事地把它们摆脱了。他怀着一种莫名其妙的幸灾乐祸的心理，不断地寻找错误，并且把它们一条条地归纳起来。“不过主要的错误，”罗亭突然想，“就在于我跑到顿巴斯来！”

有人怯生生地敲门，声音轻得象是用手指在抓着门似的。

“嗳，这又是谁呀？”罗亭神经紧张地叫道。

但这只是女秘书端茶来。她轻手轻脚地走进来，怯生生地把玻璃杯放在桌子上。她发觉她的首长今天情绪很不好。她一面向门口倒退出去，一面喃喃地说，想平平他的气：

“用点茶吧，谢妙同志，茶很浓，合您的口味！”他的气真的平了一点：他爱人家叫他“谢妙同志”。因为这种叫法有些像地下活动的年代，使人以为他参加过秘密工作，坐过监牢，甚至服过苦役。

事实上，谢妙·罗亭从没参加过地下工作。不错，在1919年他曾经靠拢敖得萨共青团的地下组织：在中学里他有几个朋友，他猜想他们都参加了共青团组织，他多少帮过他们一点忙；要不是他父亲不赞成，他一定加入地下活动了。后来很长一个时期他深深后悔当时没有那么做。直到1921年他方才入团。

不过，罗亭也不是他实在的姓。他原来的姓并不比这个屠格涅夫笔下的姓<sup class="footnote-ref" id="note-ref-97-1"><a href="#note-97" aria-label="查看本页注释 97">[97]</a></sup>难听，可是他却恨它，因为那是父亲的姓，而父亲是一个大粮食商人。直到新经济政策的最后几年，这个姓还可以在敖得萨商店的招牌上看到。罗亭跟家庭早就一刀两断了，那还是在他入团的时候。从前他痛恨作粮食商人的父亲，因为他那该死的身份糟蹋了他的履历。现在父亲是一个合作社的普通职员。罗亭并没有跟他恢复关系，连给母亲也难得写一封信，而且写起来很勉强。

他是五年前来到顿巴斯的。这以前，他在中央工作，在人民委员会里，在大人物的周围，多半是当助手、报告员或者秘书室主任。有一天他觉得这种工作搞厌了。他忽然看到青春消逝了，而他却还一事无成。他害怕了——难道就这么过一辈子吗？难道一辈子就坐在办公室里准备报告提纲，打发走来访的人吗？他就要求到“下层”去。到顿巴斯去。他认为顿巴斯是一个前途不可限量的黄金世界。到了那里他可以大展宏图，一显身手！他觉得离开中央，就是一件英雄的行为，并且感到很自豪。

他们派他去搞行政工作。在去顿巴斯的火车上他就在考虑，首先他应该做些什么。搞市政建设吗？管房屋问题吗？不，这对罗亭不合适。搞这种工作不会有响亮的名气。不，他要做一番事业，可以一鸣惊人；他需要——极其需要——一个“漂亮的主意”。在他到矿山的第一个晚上，当他跟他的临时房东，年老的唧筒工一起坐在庭园里喝茶时，这个幸福的主意居然就产生了。

庭园里开着玫瑰花。从前罗亭不知怎的以为矿山上是没有玫瑰的。他瞧着玫瑰，动了心。于是，就产生了一个漂亮的主意：玫瑰花！有了，矿山上种玫瑰——这就是他的工作，就会给他带来荣誉。他要把全区闹得天翻地覆，要惊动所有的人，他自己也要卖力气，这样一来，他的矿山上就会有玫瑰盛开。还有郁金香，还有蜀葵，还有秋紫菀……而且不仅像现在那样只限于庭园里。它们还应该出现在矿井上！在进出口的大门旁。在管理处前面的院子里。在交接班室和矿灯房的附近。

他的预料没有错——这件事大家都谈得很起劲！这是应该谈谈的：鲜花确实美化了矿工的生活。矸子山畔的花坛有一种说不出的引人入胜的景色。罗亭成了全体主妇崇拜的偶像了。她们成百名地掮着铁锹，到花圃里去领苗，然后分成几队，把苗木种在广场上的花坛里和街道的两旁。邻近的地区也开始吸取罗亭的经验。新闻记者和摄影记者不断跑来。一个狂妄的特写记者竟把罗亭称为“矿工的米丘林”。他的办公室里现在经常挤满了园艺学家、农学家、市政建设人员……

有一天，一个爱好种花的小老头，带着许多大小包裹来找罗亭。他谦逊地向罗亭说，他“从事这个玩意已经很久了”，虽然他只有一座极小的花园，但他居然种出一些颜色很别致的郁金香来，现在他特地跑来向博学多才的罗亭同志讨教。

可怜的老头儿弄错了，他以为罗亭是一个跟他旨趣相投的同好。可是罗亭却三言两语就把他打发到市政建设局去。老头儿只得收起带来的包裹，窘态毕露地走了。他稍微有些生气，因为这位“博学多才的人”不愿把自己的知识和窍门，告诉他这个平凡的无师自通的业余爱好者。老头儿绝对想不到，罗亭同志对种花是一窍不通，他对花毫无兴趣，正像对人毫无兴趣一样。他只爱一个人，那就是谢妙·罗亭，也就是他自己。

整个夏天，新闻记者、游览者和代表团没有断过。后来热潮低落了，人声静止了。并不是因为秋霜冻萎了最后的一批紫菀，而是因为各地矿井现在都有自己的鲜花了。

好吧！罗亭并不生气。这件事他已经厌倦极了。现在他在等待奖赏。每天早晨，每天晚上，他都在等待电报或者电话：任命他去搞新的工作。他考虑各种可能的任命；预先就决定哪些工作可以接受，哪些工作必须拒绝；但最重要的是不要贬低自己的地位。可是他没有等到。

是的，生活不走运，不走运！后来他又两三次想引起喧哗，可是，除了自讨没趣外，一无所得。于是，有一次，在1932年底1933年初严寒的冬天里，他发起了“星期日突击运动”。

“让我们把全部假日贡献给亲爱的矿井吧！”他在全体党员大会上大声疾呼道，“我们大家都到工作面去！我们去挖煤，给大家作榜样！我第一个去！”他高声叫嚷，用火焰般的演说来煽动人家和自己。

于是下一个星期日人们就纷纷下井去了，其中有市委会和市苏维埃的工作人员、报纸编辑、区检察长、市卫生局的医生、国家银行当地分行的经理、啤酒厂厂长，而带头的就是罗亭同志自己。他穿着崭新的矿工服、橡皮长靴，戴着矿工钢帽，手里拿着一盏刻有他名字的矿灯，那是人家送给他的礼物。在地面上这一切看来都很漂亮动人——忙煞了摄影师——可是到了矿井里，就显得荒唐可笑了……在星期六义务劳动时，搬搬煤炭木柴，铺铺道路，种种树木，这是一回事，做这种事毋需特殊的技术，只要有热情就够了；可是到矿井里去采煤，那就完全是另一回事了。不过，直到罗亭那双笨拙的手拿起了风镐，他才了解这一点。

“您只要做给我看看怎样搞，我自己就能……”他虽然心里没有把握，但仍旧勇气十足地对一个采煤工说。采煤工做给他看。他试了试。毫无结果。他又试了试……矿工们不怀恶意地笑了起来。直到下班他才勉勉强强地采了不满一矿车的煤。矿工们好玩地用粉笔在矿车上写道：“罗亭同志采的煤”。他实在也弄不懂，这是在表扬他还是讽刺他。第二个星期日他就不再下井去了。

不久他完全放弃了各种主意，安静下来，开始消沉，觉得无聊了。他对技术毫无兴趣，而市委的日常工作，他也觉得既不美丽，又不快乐；虽然他按照习惯仍旧动不动拉开嗓子，作着火热的演说，但这已经不是烈火，而是灰烬了。罗亭早已熄灭了。

是的，顿巴斯不是他的黄金世界。他来到这里已经五年了，五年来不断地东奔西走，没有在一个地方长待过。他不是在走上坡路，而是在几座小山间转来转去。周围的人们都一个个地赶上他。别的书记都是一帆风顺。他们并不追求荣誉，可是荣誉却自动来到。“这是什么缘故呀？”他酸溜溜地想，“为什么只有我一个人那么不走运呀？”他当然不了解，问题在于他自己，而且除了他自己，不能怪别人；他不了解做党的工作不能摆架子，说空话，不能抱冷淡的态度；一个人如果不爱人，只爱自己，他是不能对人进行工作的。他没有意识到，他不仅落在邻人的后头，而且早就落在生活的后头了，他处在自己的地位上是不稳固的，是偶然的，好像挂在树上的最后一片叶子，又黄又皱，死气沉沉，禁不起一阵大风……

他没有意识到这一层，却老是怀着空虚的希望等待着，老是相信“漂亮的主意”总有一天会落到他的头上，把他拯救出来，使他名震天下。可是，在马丽雅矿的交接班室里，当这个主意突然借安德烈·伏龙科的形象出现时，他竟没有注意，没有想到。

这件事他到如今还不能原谅自己。“像我这样机敏的人怎么会错过这种好机会呢？”他心里想。等到阿勃罗西莫夫的纪录终于创造了，并且传到罗亭的耳朵时，他不但不高兴，反而大发雷霆。“怎么？撇开我？！”他想到的只有这一点。9月1日夜里马丽雅矿所发生的事，他认为不是矿工的劳动奇迹，而是反对自己的狡猾阴谋；通过大堆开采出来的煤，他看到的不是阿勃罗西莫夫和伏龙科，而是茹拉符列夫和聂察英科。“哼！”他愤怒地想，“你们想在我的背后飞黄腾达吗？想爬到我的头上来吗？”他想不出茹拉符列夫和聂察英科参与这件事还有什么别的用意。

于是他诬蔑阿勃罗西莫夫的纪录是欺骗。他甚至想成立一个委员会来调查这件事。可是《真理报》马上发表了斯达哈诺夫纪录的消息，罗亭明白他又碰了一个钉子。然而他却没有向阿勃罗西莫夫道歉，他根本不曾想到这一层。表面上他装得若无其事，暗中却手忙脚乱，竭力想挽回局面，好像一个迟到的旅客，想跳上一列已经开动的火车。他也像一般落后分子那样，比别人更喜欢叫嚣和忙乱。

现在连他也明白顿巴斯矿井进入了一个非常时期。他对自己说：唔，这次不要错过机会了！现在要一鸣惊人了！斯达哈诺夫采了多少？一百零二吨吗？那么，我们就得采二百吨！三百吨！五百吨！这些数目字在他的头脑里跳舞，除了它们之外，他什么也没看到。现在他不分日夜坐着自己的“加士”牌小汽车，在区里东奔西跑，安排新的纪录（他把它们称为“我的炸弹”），废寝忘食，喉咙嘶哑，但情绪很高。他甚至变得年轻了，快乐了，恢复了原来的精力，同时也恢复了原来的希望。怀疑论者变成积极分子了。当扎巴拉采了三百吨时，罗亭比谁都高兴，比扎巴拉本人，比他带到矿上来的摄影记者和新闻记者都高兴。

可是，安德烈·伏龙科却在党员大会上作了这样的发言。又是伏龙科。又是聂察英科！……

“是的，糟了，糟透了！会传到省委会去的。而且说不定会传到中央去。刚才会场里恐怕有新闻记者。我怎么会克制不住呢？是的，太坏了……必须赶紧设法挽回……趁现在还来得及。但是怎么办呢？怎么办呢？怎么办呢？”他一面胡思乱想，一面目光在办公室熟悉的四壁上转动，并且在电话机和电铃上停得最久。但是打电话给谁呢？揿电铃叫谁呢？谁能救他呢？

他机械地揿着电铃。

“喂，茹拉符列夫同志在吗？”女秘书一进来，他就声音嘶哑地问。

“在。他刚来。叫他吗？”

“不，”罗亭想了想说，“不必了。”

但是等女秘书一走，他又后悔不该那么说了。他霍的一声跳起来，匆匆地走出办公室，穿过会客室，走进茹拉符列夫的房间。

茹拉符列夫只有一个人。罗亭马上用锋利的目光刺探他：茹拉符列夫是不是知道马丽雅矿所发生的事？这从茹拉符列夫的脸上看不出来。他像平常一样恭敬地起身相迎；眼睛也象平常一样冷静……“他对别人又是一副面孔！”罗亭忽然醋意十足地想。以前他从不注意茹拉符列夫的面色是怎样的。他们两人之间并没有友谊。罗亭在这儿不曾交上一个朋友。“只有地位平等的人才能作朋友！”他向自己做着解释，可是这儿有谁可以跟他罗亭地位平等呢？但此刻他却惋惜他们之间没有友谊。他不知道话应该怎样谈起。开诚布公地谈一谈是办不到的。他应该怎样对付茹拉符列夫呢？可是茹拉符列夫却一言不发。

“是的……我们组织里有趣的事真多……”罗亭一面说，一面在单人沙发里坐了下来；他想尽可能把这句话说得自然大方，若无其事，甚至试图假笑，可是笑不出来。此刻罗亭的心绪实在太恶劣了。“真的，有趣得很……”

“什么事？”茹拉符列夫低声地问。

“今天马丽雅矿有人公开反对我……真不要脸……”

“开会的事我听到了……”

“哦！”罗亭怀疑地叫道，“你的情报倒快呀！”他嘲笑说。

茹拉符列夫一声不响。

“那么你对这件事有什么感想呢？”

“对什么事？”

“就是对大会上所发生的事？”罗亭焦躁地叫道。

茹拉符列夫耸耸肩膀：

“有什么感想吗？一个人不能禁止人家批评他。”

“但也得看是怎样的批评，是吗？”

“什么？据说，讲得不坏……”茹拉符列夫情不自禁地笑了笑。

“这是谁说的？聂察英科吗？他是区里的第一号捣乱分子，恶意宣传家。早就该把他赶走了。”

茹拉符列夫没有回答，只是用嘴角冷笑了一声，好像在说：“赶走，哼，你试试吧！”而罗亭这时忽然伤心地感到自己的软弱和孤独。

不过他还不愿认输。

“恶意宣传！”他嘟哝着说，“可是，老弟，他们看错人了。我懂得这些把戏！行不通！大家知道我罗亭是个怎样的人！谁会相信这些胡说八道？”

“这可不是胡说八道！”茹拉符列夫低声地说，“红色游击队员矿的确有这样的事。”

“那你已经到红色游击队员矿去过了？”

“为什么？有人从那儿来。他们讲的。所谓：麻袋藏不住锥子，纸包不住火。”

“谁讲的？谁？哪些人？”罗亭跳了起来，“那些搬弄是非的家伙是谁？我要知道他们的名字！名字！”

“你何必激动呢？”茹拉符列夫制止他说，“他们全是些普通人。共产党员。你不必生伏龙科的气，罗亭同志！”他笑了一笑。“伏龙科不说，别人也要说的。麻袋藏不住锥子，纸包不住火。”他重复了一遍。

“哦，真的吗？”罗亭叫了起来。“连你也跟他们一起反对我吗？”他又失去了自制力，“我的威信是你的眼中钉吗？我挡了你们的路吗？”

茹拉符列夫不胜嫌恶地皱起了眉头。

“你这些字用得可不恰当：什么‘我’、‘我的’……”

“但你不要狡辩！不要狡辩！坦白地说！”

“我并不狡辩！”茹拉符列夫忽然皱紧眉头，也站了起来说，“你想知道我的意见，很好！伏龙科是对的。他讲得很对。聂察英科也是对的。他不阻止伏龙科发言也是对的。但你可完全错了。你在党员大会上的行为是不对的，不像一个党员……”

他说这些话，自始至终非常沉着、庄重、谨慎，不提高嗓子，好像在宣读判决书。而这种口气，这种低沉冷静的声音对罗亭的作用比什么话都厉害。罗亭仿佛突然看到那座矗立在茹拉符列夫背后、并且使他的语言变得强大有力的高山——整个伟大的党——他软化了，慢吞吞地倒在沙发上。

“可能……当然……”他含含糊糊地说，“嗯，错误。我承认……我在那边发脾气，在马丽雅矿。不好！但你设身处地替我想一想……”罗亭稍微欠起身来，没有信心地瞧了一眼茹拉符列夫，明白他不会替罗亭设身处地地想想，他不同情罗亭，一点也不同情。

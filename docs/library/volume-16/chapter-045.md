# 二十五

1935年11月6日清晨，一个人数很多的顿尼茨矿工和冶金工的代表团，应莫斯科市苏维埃的邀请，到首都参加十月革命节。代表团里有阿历克赛·斯达哈诺夫、裘康诺夫，有中央伊尔明诺矿的党组长康斯坦京·彼得罗夫，还有顿巴斯其他许多著名人物，其中也有我们的两位英雄——安德烈·伏龙科和维克多·阿勃罗西莫夫。

最近，在安德烈·伏龙科的生活里，发生了几件重大的变化。在他发言反对罗亭的那次党员大会之后不久，区里来了一个省党委派来的调查委员会，跟它同来的还有乌共（布）中央<sup class="footnote-ref" id="note-ref-98-1"><a href="#note-98" aria-label="查看本页注释 98">[98]</a></sup>的一位指导员。委员会工作了不久，但却发现了许多安德烈完全想不到的事。罗亭被撤了职，马上就离开矿区。茹拉符列夫当选为市委第一书记，聂察英科为第二书记。同时他们向聂察英科保证——这次靠得住了！——一年之后一定让他去学习。马丽雅矿矿党委书记的职务，暂时由安德烈代理。

他没有推却，因为“党的信任，好儿子，是值得自豪的”，列斯尼亚克叔叔又严厉又亲热地在大会上对他这样说。不过要做一个像聂察英科那样名副其实的书记，安德烈觉得自己还不够资格。他做党组长也还没有被中央批准，他相信他是不会被批准的：他实在太嫩，太年轻。但他已经爱上了党的活动：他所迷恋的是这个活动最吸引人的一方面——做各种人的工作。

一路上安德烈自然而然地跟彼得罗夫特别接近，好像维克多跟斯达哈诺夫特别接近一样。在斯达哈诺夫的车厢房间里，已经展开了一场地道的采煤工的谈话：他们彼此挑战竞赛，互相交换操作方法和窍门，责骂小组长和运煤工作……而安德烈却悄悄地向那位著名的党组长请教，他是怎样工作的，彼得罗夫很热心地回答他。彼得罗夫有些地方极像聂察英科，也是又年轻，又乐观，又爱说话，也是一位“老大哥”。在代表团里，大家很快就称他为科斯嘉<sup class="footnote-ref" id="note-ref-99-1"><a href="#note-99" aria-label="查看本页注释 99">[99]</a></sup>，而且跟住科斯嘉形影不离。他的周围总是围满了人。

一般人旅行，前半段路上谈的多半是离开的那个地方，后半段路上谈的多半是将要到达的那个地方。他们也是那样，前半段路上谈的多半是关于顿巴斯、老家、矿山的事，后半段路上——过了库尔斯克——谈的多半是关于莫斯科。许多人也像安德烈和维克多那样，是第一次上莫斯科，每人对莫斯科都有自己的要求。青年人梦想戏院和娱乐场所，年纪大些的人考虑买些什么礼物带回家去。不过有一点是相同的，大家都想先到红场去一次，去拜谒列宁陵墓，向列宁行个矿工的敬礼。如果有机会的话，还想参观一下克里姆林宫，但这只是大家的一个理想。

到莫斯科是清晨，全城还沉浸在一片浓雾中。只看到车站附近房子的屋顶，和屋顶上烟囱里冒出来的白烟。这里也像在其他各个车站上那样，闻得到煤的气味。这是长途旅行的气味，是我们这个代表团最爱好的气味。

“瞧吧！”维克多跳到月台上，眉飞色舞地说，“这是我们的煤味儿！”

虽然大清早，还是有不少人来欢迎贵宾。他们一下车，就受到莫斯科人的热烈招待。主人是莫斯科的斯达哈诺夫工作者。他们把顿巴斯的来客带到了十月旅馆，所有到首都来过节的工人代表都住在那里。旅馆的休息室里挤满了人：各地的代表、摄影记者、新闻记者、电影摄影师……一听见顿巴斯的矿工到了，他们都轰动起来：

“斯达哈诺夫在哪里？在哪里？哪一个？”

他们很快就互相介绍认识了。有许多名字安德烈是熟识的。这些工作好手的声誉早已震惊全国。其中有个子矮小的布塞根，他的样子一点不像铁匠，有头发蓬松的浮斯托夫，有纺织女工杜霞·维诺格拉多娃和马露霞·维诺格拉多娃。大家都把她们当作两姊妹，其实她们两人只是朋友和“对手”。可是“维诺格拉多娃姊妹俩”这个称号是人民给她们的，她们不能不接受。

列宁格勒的代表团也坐早车到了，他们的人数很多。安德烈觉得他们每人都有一种特殊的“彼得堡的”<sup class="footnote-ref" id="note-ref-100-1"><a href="#note-100" aria-label="查看本页注释 100">[100]</a></sup>派头。

“知识分子！”维克多望着列宁格勒人的背影，带些羡慕的口气说。他立刻决定今天就去买一件毛衣，来换掉那件西装背心。这件背心他以前不曾穿过，是专门为了到莫斯科来才穿的。

各地的代表——乌拉尔的、西伯利亚的、阿尔汉格尔斯克的、巴库的——络绎不绝地到来，仿佛苏联工人阶级的全部近卫军，都集中在这个十月旅馆里，准备作一次非常重要的检阅。

安德烈和维克多急于想看看莫斯科。他们匆匆地吃了早点，走到休息室里，看到同志们已经穿好衣服，准备出门。他们就一起走，而且都不约而同地朝红场走去。

维克多一路上兴致勃勃地辨认着那些他在电影、画报和明信片上见过的建筑物。他对熟识的建筑物比不熟识的建筑物更感兴趣。他得意洋洋地说着它们的名称：大剧场、工会大厦、莫斯科旅馆、人民委员会大厦、猎品市场地下车站、革命博物馆……好像莫斯科是他早就熟识的城市。

红场到了。大家都静了下来……默默地沿着木块铺砌的路走着，在中途停留一分钟，仿佛爬山一般：那种开阔宽敞的景象使人心惊胆战。

安德烈在自己静静的工作面上想到的红场，就是那样的——宽敞、庄严、雄伟……克里姆林宫上的尖塔。列宁陵墓。像石头雕出般一动不动的哨兵。枝叶上积满浓霜的枞树。在安德烈的想象中，枞树永远是蒙霜的。克里姆林宫的高墙。灰色的石头建筑。还有中央执行委员会圆屋顶上迎风飘扬的那面红旗。这是全世界的最高峰……

但此刻安德烈跟同志们却神态自若地站在这个高峰上，一点也不觉得奇怪。维克多老在微笑。雪花在他们的头上飞舞。斯达哈诺夫在对裘康诺夫说话……两人都穿着讲究的新大衣。一眼看上去，谁也想不到他们是矿工。

但这确实是矿工站在红场上，站在世界的最高峰上！他们抵达这座高峰，走了一段很长很长的路程，他们来自不见天日的地下640、710、830米的地方；以前他们觉得白天的太阳就是一种怪物，因为他们常常几星期不出矿井；以前，除了监工的“去上工！去干活！”的吆喝声之外，他们听不到一句好话；除了“煤黑子”之外，没有别的名字；除了小酒店之外，没有别的乐趣。世界上没有一种劳动比矿工的劳动更痛苦，更可耻；没有一种生活比这种四脚爬的生活更伤心，更可憎。可是现在矿工们却站在红场上，并且不觉得惊奇：他们居然是莫斯科的贵宾。他们的面前就是克里姆林宫，克里姆林宫里住着斯大林。要是奥尼辛叔叔处在安德烈的地位，他的感动一定要比青年人强烈得多！安德烈记起了奥尼辛叔叔的临别赠言，那天老头儿亲自送他们到火车站。

“要是遇到斯大林，小安德烈，不要忘记——你要代表我们马丽雅矿向他致敬。”

“难道我能遇到他吗？”安德烈微微一笑，说，“你说什么话呀，奥尼辛叔叔？”

“怎么不能呢？你不是上莫斯科去吗？”

“嗯，也许我在检阅时会看到他。从远处……”

“那你就从远处向他致敬吧。不要紧！他看得到的……”

现在站在克里姆林宫之前，安德烈想，即使能在远处看到斯大林，也是极大的幸福。即使斯大林不会注意到，他还是要致敬的。他要代表马丽雅矿的全体矿工致敬，象奥尼辛叔叔所叮嘱的那样。

“是的……”安德烈旁边有人叹了一口气，若有所思地说，“朋友们，要是能到克里姆林宫去一次，参观一下，那该多好……”大家都同意这句话，显然，他们想的是同一件事。

“当然，很有趣！历史性的地方。”

“伟大的地方……”

“更好一些呢……”维克多说着自己的梦想，“譬如说，到克里姆林宫里去。比方说，我们打院子里进去。忽然从正门里出来了斯大林同志……嗯？那有什么稀奇呢？”他发现同志们在抿着嘴笑，生气地叫道，“这样的遇见是有的。我在书里读到过的。”

“我可到过克里姆林宫。”一个高尔洛夫卡<sup class="footnote-ref" id="note-ref-101-1"><a href="#note-101" aria-label="查看本页注释 101">[101]</a></sup>矿工忽然低声说，他也是代表，上了年纪，沉默寡言，在火车里安德烈差不多没注意他。大家都向他回过头去。

“到——过？”维克多怀疑地拖长声音问，“什么时候？”

“整整两年半以前。”

“是去参观的吧？”

“不是，”高尔洛夫卡矿工简单而严肃地回答，“我去见斯大林。”

“见斯大林？！……”

“是的！……”那个矿工镇静地回答，同时讲到1933年春天，中央委员会怎样邀请他们，顿尼茨的一批老矿工和工程师，到莫斯科去商量一项有关顿巴斯的决定。

“等一等！”维克多突然激动地打断他说，“你是指1933年关于处理反机械化分子的决定吗？”

“正是。”

“这个决定我知道得清清楚楚！”维克多兴高采烈地叫道，“当时我正在开突击工作者大会。你记得吗，安德烈？”他回头问好朋友，但接着马上又向高尔洛夫卡矿工转过身去：“这样说来，这个决定还是你老爹拟的了？”

“不，不是我，当然不是……”那个矿工带笑说，“那是斯大林同志拟的。不过我们确实提了些意见，这我可以承认……”

“真的吗？”裘康诺夫若有所思地说，“你真幸福，老爹！”

“我自己也感到的。”高尔洛夫卡矿工悄悄地回答。

在从红场归来的途中，有个人——大概是维克多——提议说：

“朋友们，让我们写封信向斯大林同志致敬吧。”

大家都赞成这个主意。于是他们就在街上，在猎品市场，围着阿历克赛·斯达哈诺夫，动手起草致敬的信。斯达哈诺夫把日记簿按在一座灰房子的墙上，写了起来。全文是这样的：“在伟大的十月革命第十八周年纪念日，我们，受莫斯科劳动人民邀请来到首都的人们，通过《真理报》向苏联全体劳动人民致敬！向我们最亲爱的斯大林致热烈的敬礼。”

然后逐一在上面签了名。安德烈在签名时想：

“说不定明天检阅时我会看到他……”

可是当天晚上安德烈就看到了斯大林，在他抵达莫斯科的第一个晚上。这事发生得那么意外，那么简单，弄得安德烈真有点手足无措……当天晚上，斯达哈诺夫工作者被邀请到大剧院去参加庆祝会。斯大林在主席团里出现了。维克多首先看到他。

“你瞧，你瞧！……”他睁大了眼睛，对安德烈喃喃地说，同时跳了起来，高高地举起了双手，屏住呼吸，兴奋和幸福得情不自禁地叫“乌拉！……”

这个矿工的“乌拉”，马上得到斯达哈诺夫工作者们和所有在场人们的响应。这呼声如排山倒海，天崩地坼。安德烈也随着大家情不自禁地叫着，他什么也没有看到，除了那张亲爱熟识的脸和那对慈祥关切的眼睛之外……安德烈也像在场的每个人那样，觉得这对眼睛正在对他看，深深地射进他的心灵，并且正在向他安德烈·伏龙科，马丽雅矿的一个矿工微笑，于是安德烈的心房就快乐地打开来，迎接他的眼睛和微笑……

以后在莫斯科过的日子里，安德烈·伏龙科感到这一见难忘的斯大林微笑的光，照耀着和温暖着一切，包括莫斯科市本身和他在那里所体会和看到的各种事物。他小心翼翼地保存着这个笑容，因为是他生活里最珍贵的东西……

莫斯科殷勤地招待贵宾。她向他们显示了自己历史悠久而青春长存的美，而且不惜流露自己的热情。斯达哈诺夫工作者们，对于这种普遍的关切和敬意，简直觉得有些不好意思。他们尴尬地接受欢迎辞，当莫斯科人向他们献花时，他们真是窘态毕露。不过，他们心里很快乐，因为工人在首都受到那么热情的招待。当然，矿工们是受到特殊尊敬的，也许因为人民用矿工的名字来称呼这个新的运动，也许因为莫斯科人认为矿工的工作最富有浪漫精神和英雄气概。不过莫斯科敬爱一切英雄——飞行家、北极探险家、跳伞家、边境守卫员……

而我们的孩子们也爱上了莫斯科。他们喜欢这里的一切：人们、街道、工厂、剧院、地下铁道的新车站……

“皇宫！”维克多欣喜若狂地叫道，“简直不相信是在地底下……我们那儿也能那样就好了。”

“我们的矿井将来也会像皇宫的……”安德烈说。

“谈何容易！这是办不到的！这儿是地下铁道，没有煤，所以干净。但我们那儿到处是煤。”

可是安德烈想起了斯大林的笑容，固执地说：

“不，我们那儿也会有皇宫的！”

克里姆林宫孩子们也去了。连这一点他们也如愿以偿了。莫斯科的一切对他们都是可能的，所有的门都为他们敞开着。只有一点维克多觉得很遗憾：时间太少。他好像一个吝啬鬼，舍不得花掉每一分钟。他起得最早，睡得最晚，但还老是在担心，怕来不及看想看的一切……

他甚至不愿去看达莎，以免糟蹋时间。

“她能在莫斯科陪我们看些什么呢？”他不高兴地咕噜着，“只是浪费时间。”

可是安德烈却坚持要去找达莎。不去对不起列斯尼亚克叔叔。“达莎也不会原谅我的！”他烦恼地想。

第二天早晨，他们在电报局门口遇见了达莎。他们就一起去给维克多买毛衣。达莎因为这个意外的会见而高兴，并且不掩饰这一点。在百货公司里，她不断麻烦售货员们，亲自给维克多挑了一件绒线衫；接着她出其不意地问道：

“你们还没寄礼物到家里去吗？”

“寄给谁？”

“不寄些给企比略基的亲人吗？”

维克多很赞成这个主意。他们决定马上买一些，打邮包寄去。

“从莫斯科寄去，他们会大吃一惊的……”维克多像小孩子一样快乐地想。

安德烈跟着达莎，一级级地走着走不完的楼梯，一面走，一面想，可不可以送一件礼物给达莎呢？合适不合适？会不会使她不高兴？如果送，送什么呢？香水，手提包，丝围巾？但安德烈认为送这些东西，对达莎是不合适的。忽然他打定主意，买了一只漂亮的公事皮包，怯生生地递给她。

“这给你。”

达莎大吃一惊。

“这是干什么呀，安德烈？……”

但她很喜欢这礼物。她谢了他。为了不要落在朋友的后头，维克多也送了她一件礼物——一枚别针。安德烈看到达莎快乐得涨红了脸，马上把它别在胸口，以后又老是低下头去看。安德烈知道她从此不会把那只别针拿下了……

莫斯科另外有一次会见，也在安德烈和维克多两人的脑子里留下了深刻的印象，而且也是各不相同的。他们跟其他代表们一起，被尼基塔·伊索托夫请去作客。他现在是个莫斯科人了，在工学院里学习，但他招待同乡人，却按顿巴斯的老规矩：酸白菜、糖渍苹果、酸黄瓜露、火辣辣的红胡椒以及矿工惯用的大瓶啤酒。屋子里又暖和又舒服，不过安德烈认为尼基塔·伊索托夫住在这里有些挤，好像以前在工作面里觉得挤一样。他身材非常高大，安德烈望着他，不禁产生一种敬畏的感觉。“在工学院里学习……”他想，“他也像我们那样，是个矿工……而且年纪又不轻。”

“怎么样，伊索托夫同志，学习困难吗？”一个同乡人问他。

“是的，还是采煤容易！”伊索托夫笑着回答，随后向大家望了望，叹了一口气，补充说：“不过学习是必要的，绝对必要！……尤其你们年轻人，我要劝你们……”

维克多惊奇地看着他。像他这样的巨人，竟坐在课桌旁。要是他拿起风镐来，准会超过一切人的！但他却在学习……

维克多若有所思地从玻璃杯里喝了一口啤酒。“也许现在的矿工正应该去学习吧？”他的脑子里忽然闪过了这样的念头……

归去的日子一天天近了。车票已经定好。但离开这个好客的亲爱的城市，实在不愿意。

代表团回去的日期忽然改变了。大家都被留了下来，不论顿巴斯人、列宁格勒人，或者巴库人。不仅如此，各地的斯达哈诺夫工作者还在源源不断地到莫斯科来。他们的人数将近三千名了。大家都预感到将有一件重大的事……

……晚上有人轻轻地敲了敲安德烈的房门。

“进来！”伏龙科回答，他以为来的一定是新闻记者或者摄影记者；自己人总是不敲门就进来的。

可是门开了，进来了一个穿军服的人。他恭恭敬敬地举手向安德烈行了个礼。

“您是安德烈·伏龙科同志吗？”他问道。

“是的，我就是……”

军人又向他行了个礼，然后说：

“伏龙科同志！斯大林同志请您去。汽车就在下面大门口。”

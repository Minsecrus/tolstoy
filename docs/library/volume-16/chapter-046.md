# 二十六

不，这不是梦。安德烈真的到了克里姆林宫。再过一会儿，也许只要一刹那，他就可以见到斯大林了……事实上，这一刹那可来得比他所希望的更快：安德烈还没做好见他的准备。不过，就算让他在这儿，在这个接待室里坐上一整天，他还是来不及做好准备，因为这种事原是无从准备的。

然而，在他的激动中，并没有一丝恐惧。安德烈此刻所体验的那种说不出的新奇感情是很难用文字表达的。首先，这种意外的幸福，他觉得自己不配享受，而且也无法用完成任何奇迹来抵偿……

“请进来！”书记拉开办公室的门，第二次说。

斯大林从容不迫地从办公室里迎着安德烈走来。他左手拿着一只冒烟的烟斗，手臂微微地向上弯曲。右手伸在前面，仿佛在向客人致敬。

安德烈呢，走进房间里，一动不动地站着，好像在地板上生了根。随后忽然醒悟过来，迅速地朝斯大林走了几步。他们在房间中央相遇了。

当然，斯大林非常明白此刻这个矿工的心情，了解他的激动。要是换一个人，没有斯大林那么伟大，没有斯大林那么敏感，为了鼓励安德烈，也许会格外亲热地向他微笑，拍拍他的肩膀，说不定甚至会搂着他的肩膀走到写字台旁，但这样一定会把他弄得更窘，更慌张，以致完全失去常态。

斯大林只是向安德烈伸出一只手去：伸出去时不带笑容，仿佛他们不是第一次碰头，仿佛安德烈是天天到这儿来的，今天他到这儿来，跟平日也没有什么不同。

“您好，伏龙科同志！”斯大林温和地低声说。

于是安德烈快乐而小心地握着那只伸给他的手。这当儿，他觉得跟他一起握住斯大林的手的，还有维克多，还有列斯尼亚克叔叔，还有老祖宗，还有奥尼辛叔叔，还有米佳·查柯尔科，还有达莎以及马丽雅矿的全体党员，全体矿工和所有的人。他，安德烈·伏龙科，马丽雅矿的党委书记，是代表他们跟布尔什维克党的总书记握手的。他代表他们到斯大林这儿来。他只是他们的代表。这没有错；他来到这儿，走进这个办公室，是有合法根据的。

于是他安静下来。

直到现在，他才看到他站在一间浅色板壁的宽大办公室里。斯大林亲切而又有趣地瞧着他，这种神情只有真正热爱人民的人才有。安德烈不再觉得畏缩，信任地直望着斯大林的脸。

一张亲爱的熟识的脸。它比起照片来又像又不像；又像老些，又像年轻些；但比照片更和善，更亲切，更朴素，更可爱……斯大林有趣地瞧着他，但并不马上问他什么，让他有时间镇静下来；他们仍旧站在房间的中央。

于是安德烈就大胆地开始了谈话。他问的那件事，如果列斯尼亚克叔叔、奥尼辛叔叔、谢辽查·奥且列金或者任何一个苏联人，任何一个敬爱斯大林而且会不假思索地为他牺牲生命的人处在他的地位，都会首先提出的。他问道：

“您身体好吗，约瑟夫·维萨里昂诺维奇？”他的声音由于真诚的激动而发抖，斯大林听出了这一点。

“好的，”他立刻回答，“很好。谢谢。您呢？……”他等安德烈回答之后，用一个沉着的手势叫安德烈在写字台旁的一张软椅上坐下。

“请抽烟。”等安德烈坐下了，他含笑说，同时递给他一盒纸烟。安德烈拿了一支烟，但忘了点火，只用手指揉着……

“您是头一次来莫斯科吧？”斯大林一面点烟斗，一面问。

“头一次。”

“喜欢莫斯科吗？”

“哦！”安德烈只惊叹了一声，说不出话来。

“你们在莫斯科受到的招待好吗？”

“好得出乎意料之外，约瑟夫·维萨里昂诺维奇！”

“为什么‘出乎意料之外’呢？”斯大林微微一笑，“我们首都的人是很尊敬矿工的……”

“这我们一辈子也忘不了，斯大林同志……”安德烈坚决地回答。

斯大林已经点上烟斗，吸了一口烟，坐了下来，但不是坐在写字台旁，而是坐在安德烈对面的一张软椅上。

“我请您来，伏龙科同志，”他弯身向对谈者说，“想跟您商量些事情。”

“跟我？”安德烈情不自禁地问，他一听到“商量”两个字，简直大吃一惊。

“正是跟您，因为您是斯达哈诺夫运动的发起人之一。而斯达哈诺夫工作者——这是新的人物，特殊的人物……”

“但您能跟我商量什么呢，人类中最英明的人？”安德烈几乎要叫出声来，“我……我自己还糊涂得很。我刚开始做党的工作，初出茅庐……”他以恳求的神气望了望斯大林，“哦，老天爷，多大的误会啊！他们给斯大林找错人了！您打发我走吧，不要浪费您宝贵的时间了，我请求您……”

斯大林平静地注视着客人的激动。随后身体更向他凑近一点。

“请您告诉我，”他请求道，“这个杰出的运动在你们的矿井里是怎样产生的。创造纪录的经过情形……”

安德烈如释重负地喘了一口气。

“这个我能，”他快活地说，“这个可以……”

他认为这事实在容易。他感到为难的就是应该从哪里说起，并且怎样说得简单一些。

斯大林很有耐心地等着。

“事情是这样的……”安德烈犹豫了一下，开始说，“开头是由于采煤工在台阶里觉得太挤，”可是说到这儿又马上停止了，他怀疑：斯大林同志可知道什么叫“台阶”吗？他是不是应该解释一番？他稍微考虑了一下，认为斯大林是无所不知的。

他就继续讲下去，当时怎样产生了打破旧制度和实行劳动分工的主意，这个主意怎样受到煤矿党组织的支持，但领导上只给他们一个采煤场子做实验，后来维克多·阿勃罗西莫夫同志就去创造纪录，因为他是矿井里最强的采煤工，但在开始实验前一个钟头，他们知道了斯达哈诺夫同志创造纪录的消息，这使他们更有信心，并且想超过斯达哈诺夫的纪录，于是阿勃罗西莫夫就真的做到了，以后马丽雅矿许多别的矿工也都纷纷创造纪录……

“我也是其中的一个，”安德烈不大好意思地补充说，“但超过的数量不大……”

斯大林很留神地听着他，仿佛安德烈所说的每个字，在他都是宝贵的，仿佛在每个字之后，他比讲的人看到的更多和更远。可是当安德烈说完时，他却慢慢地摇着头，安德烈看出斯大林对他所讲的并不满意。

“完了！”矿工用低沉的声音喃喃地说。

“完了吗？”斯大林笑了一声问，接着又摇摇头——安德烈觉得含有非难的意味。“您为什么不把全部真相讲给我听呢，伏龙科同志？”斯大林忽然稍带责备的口吻问，“您不信任我吗？”

安德烈喘不过气来了，他惊慌失措地瞧瞧约瑟夫·维萨里昂诺维奇，不停地䀹动浅色的睫毛。“我什么事骗过您了，斯大林同志？难道这是可能的吗？您说什么话呀？”他心里问着斯大林，几乎有些生气。

“您为什么不讲给我听，譬如说，您所提出的新工作法，曾经受到煤矿行政方面的猛烈反对？不是有这样的事吗？”斯大林问道。

“有的……”

“还有党的市委书记……他叫什么名字呀？是罗亭吗？他甚至说您是捣乱分子，说阿勃罗西莫夫的纪录是骗人的。有这回事吗？”

“不过我们已经把那个罗亭……已经把他赶走了。”安德烈出乎自己意外果断地说。

“做得对，”斯大林点了点头。他的脸变得很严厉，那是他跟安德烈谈话以来的第一次。“早就该把这些罗亭之流……这些空谈家……纨绔子弟……不学无术的人……从所有的岗位上赶走了！”他嫌恶地说，“早就该赶走了！斯达哈诺夫运动在这件事上也帮助了党，真是太好了。不过给你们挡路的不仅限于罗亭之流。难道工人中间就没有反对你们的人吗？”

“怎么没有——有的……”安德烈低声地同意说。

“是的。也有这样的人，他们怕斯达哈诺夫的新办法会影响到他们的工资。对吗？”

“对……”

“据说，在你们的矿井里甚至有这样的组长，他在你们创造纪录时破坏压缩空气管……”

“您连这事都知道吗？”安德烈涨红了脸，惊奇地问。

“是的，”斯大林不由得笑了笑，“这些您刚才为什么不讲给我听呢，伏龙科同志？”

真的，为什么不讲呢？为什么认为到这间最高的办公室里来只能报些喜讯呢？何必夸奖呢？要知道在这个房间里是不能夸奖的。这儿需要的是老实话，全部的老实话。但我却欺骗了斯大林同志，欺骗了……

他坐着，又颓丧又害臊。斯大林也注意到了这一点。

“嗳，党委书记，”他快乐地说，“这些个别事实具有怎样的意义，现在您懂了吧？您是一个领导者，您懂了吗？”

“我还是一个没有经验的领导者。”安德烈喃喃地说，他因为斯大林称他“领导者”而手足无措了。

“但到底是个领导者！”

斯大林站了起来，在地毯上走了几步。然后又走到安德烈跟前。

“这些事实表示，伏龙科同志，”他说，“斯达哈诺夫运动一产生，它的反对派，它的敌人也就出现了。事情总是这样的。旧事物总是要挡住新事物的路。新事物要取得胜利，就必须跟旧事物进行斗争。”他瞧瞧一声不响的安德烈，眯细了眼睛。“好吧，您就把那些反对斯达哈诺夫运动者的情形详详细细讲给我听吧。他们是些什么人？谁在给他们撑腰？他们的实力怎样？还有什么在妨碍这个运动？必须采取些什么补充办法？”

他已经坐不住了。一会儿用轻快无声的脚步在房间里走来走去，一会儿忽然停下来提出新的问题，或者倾听安德烈的回答。

安德烈现在竭力把心里的话都说出来：在回答之前，他先搜索自己的内心和记忆。他的身上出现了奇迹：他的目光变得更尖锐了！有很多事物，以前他认为是偶然的，无关紧要的，不值得注意的，此刻在新的光明照耀下，忽然获得了新的意义。

斯大林对他的回答，显然很满意。

“瞧！您还说是个没经验的领导者，”他突然在安德烈的面前站住了，快乐地大声说，“可是听您说话呀，倒像是个国家要人！”

“您说什么呀，约瑟夫·维萨里昂诺维奇！……”安德烈不好意思地说，但心里却很高兴。

“我想斯达哈诺夫在创造纪录时，也没有自以为是个国家要人吧？”斯大林笑了起来，“恐怕您也只是想着自己的马丽雅矿吧？”

“是呀……”安德烈微微一笑。

“但结果却成了一个全国性的运动！而且决不是偶然的！时机成熟了。您怕也是个采煤工吧？”斯大林出其不意地问。

“是的……”

“受过什么教育？”

“念完七年……”

“念完七年！”斯大林笑了笑，重复说，“革命以前恐怕找不到一个受过七年教育的矿工吧？你们用风镐工作吗？”

“是的……用风镐……”

“您觉得这工具怎样？好吗？”

“工具不坏，很合用。”

“风镐是不是已经落后了呢？”

“您说什么呀，约瑟夫·维萨里昂诺维奇！”安德烈惊奇地说，“我们学会使用还没多久呢……”

“好吧！就算这样吧！”斯大林笑着表示同意，“到底不是手镐了……”

“那是不能比的！”安德烈大声说，“这是技术！”

“你们那儿割煤机工作得怎样？”

“我们那儿没有割煤机……割煤机大半用在缓斜煤层。”

“好吧，那么它们用在缓斜煤层怎样呢？”

“我不知道……我不了解……”安德烈尴尬地坦白说。

“不应该不知道，”斯大林说，“您是个党员，您应该关心一切。”

“现在我去了解，”安德烈匆匆地说，“以后写信告诉您。”

“写信吗？”斯大林眯细了眼睛说，“好吧，好吧，可别骗我！我将等您的来信！”他开玩笑地拿烟斗威吓他。

“我一定写信给您……”安德烈重复说。

“而且不要仅仅限于割煤机。关于开矿工作机械化的一切都可以写。我们这儿，中央委员会，对这件事特别感兴趣。只有机械化，新的技术，加上别的因素，才能帮助我们肃清千百年来体力劳动和脑力劳动的对立，走向共产主义。您认为怎样，伏龙科同志，”他忽然问，他的眼睛里闪耀着快乐的火花，“我们能达到共产主义吗？”

“这一点我们全体工人阶级是坚决相信的！”安德烈激动地说。

“我也那么想：一定能达到的！”斯大林的脸上浮起了笑容，“只要我们全国人民都照斯达哈诺夫的方式工作……”

“照斯大林的方式……”安德烈说，声音低得几乎听不见。

斯大林显然没有听见他的话。他侧着身子站在窗前，点上了熄灭的烟斗，若有所思地凝视着克里姆林宫里的覆有星形霜花的枞树。

安德烈站了起来。他认为应该走了，但同时又不愿走。这儿，在斯大林的地方，所过的每一分钟都是宝贵的：这几分钟足够安德烈回忆一辈子！

“谢谢您，约瑟夫·维萨里昂诺维奇！”他低低地说，声音是从心底里发出来的。

斯大林转过身去，走到安德烈跟前。

“这应该谢谢您！”他亲切地说，同时伸出了右手。

“别忘了写信！”安德烈走到门口，斯大林快乐地提醒他，“我可要等的！……”

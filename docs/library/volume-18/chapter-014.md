# 第十二章

2月出头，一个高大漂亮的女人在轮船快要启碇的最后几分钟里，跳上了一条就要从高加索海滨一个港口启碇的轮船。她穿着一件肩上留有肩章痕迹的皮大衣，手里提着一个小皮箱，仿佛她是突然决定这次旅行的。十级的东北风刮了两个昼夜，旅途看来是艰苦的，乘客也寥寥无几。

这女人在船舱里找好铺位，立刻走到甲板上，可是险些儿没被风刮倒，只得连忙回到舱里。空气混合着细小砂石，在旋转着，咆哮着，呻吟着。呼吸这种奔腾着的空气无比困难，它使人没法咽下嘴去，因为砂子哽塞着喉咙，使人感到像要窒息一般。

她回到船舱里，脱去皮大衣，露出身上那套裁制讲究的墨绿色衣裳和胸前的两条勋章带。她手里拿着一本书，走到休息室里。人们向她致敬，同时嘲笑那种推动一个单身女人去做危险航行的胆量。她克制地回答说要去干一件紧急的事，接着选了一把靠近水汀的沙发，坐下来看书。

在轮船出海的时候，她不曾向两岸瞧一眼。连最初几个浪头撞击船舷、使船身猛烈颤动并且摇晃起来的当儿，她也没有停止自己的沉思。

旅客们很快互相熟识着。一小时以后，许多人都彼此知道了名字和父名，他们谈论着风暴、簸荡和晕船药，谈论着船上的伙食，想出各种游戏方法，一面听无线电广播，一面高声发表自己对国际问题的看法。

只有她一人没有参加大家的谈话。她那美丽但却憔悴的脸现出厌烦的神气。她真害怕她的孤独会被人家破坏。事情果然很快就发生了。起初是那个非常爱好交际的活泼的少校，后来是那个带着女儿从苏胡米来的举动笨拙的瘦长森林学家在她身旁坐下来，并且引她讲话。

过了一会儿，他们知道她是个复员军医，在疗养院里休息了一阵，现在要去访问一个好久不见的病人。

“您选上了一个好日子！”少校哈哈大笑说，森林学家也表示同感说：

“要是您等过了风暴，乘下一班轮船，那就要舒服多了。”

她顺从地同意说最好是应该等过了风暴再走的。几分钟之后，谈话的人们已经用名字和父名来称呼她了。

“您太心急了，太心急了，阿列桑德腊·伊凡诺夫娜，”森林学家一再说，不知道他这话多么刺痛她的心。“我跟维特卡（他这样称呼自己的女儿，她的本名叫叶里扎维泰）的情形不同：我们不能耽搁。”说到这里他就急急地讲，他怎样接到老朋友钦巴耳的热情邀请，现在他带着女儿去作一次考察。

“季米里亚席夫说得好：‘谁在生长单穗的地方种出双穗来，谁就值得赞美，’原话我已记不清了，不过大意是这样。我现在就是要去种些麻栎和雪松。”

在他身上，在这个森林学家身上，一点没有创造家和建设者的风度。他身体细长干瘪，瘦骨棱棱，倒有点像游牧人和流浪汉。这说明大地的号召也达到了这一类人，他们干瘪的身体也站了起来，并且寻求着在什么地方播种自己还没有丧失的信心和希望的种子。

那个少校打算经过敖德萨到里伏夫区去。他失去了家庭，没有任何牵挂，现在除了战场之外，也没有任何地方吸引他。他退入后备役，决定选择一个定居的地方——这是跟他最纯洁和可贵的回忆有联系的地方——喀尔巴阡山脚下一个小村子，在那边人家都知道、都记得他是一个解放者。他想到那边去重新开始他那被战争蹂躏了的生活。

还有两个女人，婆婆和儿媳妇，搬到乌克兰儿子和丈夫的地方去住。他是在受伤之后留在那边工作的。

有两家巴库工人搬到加里宁格勒去住。

行踪无定的旋风在国家上空飞驰，把人们吹向幸福的地方，在那边人们给自己找寻新的安身处和工作。

“我也要给自己找寻一个生活的地方，在那边我将像森林学家所说的麦穗那样生长，”高烈娃忧郁地想。“不过，谁晓得……不知谁说得好：幸福是一种副产物，人们获得它是在努力追求一种完全不同的东西的时候……”

晚上，当黑暗蒙住了海洋的景色、波浪的动荡变得更加剧烈时，旅客们都分散到船舱里去了，只有高烈娃、森林学家和他的女儿以及两个高加索人留在休息室里。一个风雨之夜的忧郁在这里似乎淡一些。

高加索人一清早就喝酒，唱歌，互相拥抱。他们刚吃完早饭就开始喝酒，唱歌，并且一直继续到深晚。他们对什么都漠不关心，除了永远没有尽头的歌曲之外——他们始终没有办法把一只歌从头到尾唱完，这不知道是那种歌根本没有一个结尾呢，还是他们找不到。

半夜里轮船有两次簸动得非常剧烈，把几扇舱门都震开。孩子们被惊醒而哭起来，甲板上传出水手们的说话声，同时在半明不暗的餐厅里重又点上了灯。

高烈娃却一动不动地坐着。

“没有什么可怕的，您说对吗？”森林学家低声问她。

她从沉思中清醒过来，像从瞌睡中清醒过来那样。

“是的，没有什么可怕的。过来，维特卡，坐到我这儿来，”她用白绒线大围巾的一角裹住女孩的身体。

“您打算住到什么地方去？”森林学家问。

“不知道。大概总能找到一个医院的。”

“跟我们一起去住吧。大家挤一挤，我们领您去。”

“不，不，谢谢。”

那么强烈地违反她的理智和自尊心的奇怪旅行快结束了。很难说明这一切是怎么发生的。那天她在船期表里看到伏罗巴耶夫所住城市的名字，再也无法跟自己斗争，不等在疗养院里住满规定的期限，也不通知他，就动身了。

有什么在等待着她呢？不久之前她在那边还是一个很被需要的人，而现在却成为多余的人了。想到这一层真是可怕，但要是不再试一下命运就走，那就更可怕。

从伏罗巴耶夫那儿，她始终没有收到过一封信。她跟高雷歇夫虽然保持着通信，但伏罗巴耶夫的情形他也一点不知道。

这一切都使人感到非常不安。

“也许他已经不在人间了？……也许我只能找到他埋骨之地的一抔黄土？……”

然而，关于伏罗巴耶夫可能死去的念头，幸亏怎么也没有在她头脑里停留，它很快就消失了，只在脸颊上留下两条懦怯的泪水。

就这样带着泪水，她在沙发上睡着了。

黎明时分，轮船驶入了海水呈土色的小湾。在远方，在潮湿的防波堤上可以看到大堆的人群和卡车的行列，但是半罩着蒙蒙细雨的海岸看来却无人居住。

等旅客们纷纷走散了，高烈娃沿着潮湿而泞滑的舷梯下了船。

民警指示她到区委去的路。

肮脏的马路上，风把水潭里的泥浆吹得飞溅，百年古树弯下了腰，发出飒飒的响声，然而在海航之后，即使岸上的坏天气似乎也挺可爱。

伏罗巴耶夫不在区委。女秘书告诉她说，伏罗巴耶夫身体不好，躺在家里休息。

“离开这儿远吗？”

女秘书指给她看对街一座二层楼的房子。

“四号。门没有锁。马上有人要给他送邮件去了。”

“谢谢。”

她走到街上，发现手里拿着小皮箱，不知道该拿它怎么办，就站住了。不过，她决定不再回去，就一口气跑到二层楼上。她感到两膝发软——海航一定把她累坏了。

一扇半开的门立刻投入她的眼睛。她走了进去。

她从黑暗的外室看到大房间的一角、靠壁的一张行军床和斜倚在枕头上的他。

伏罗巴耶夫的脸一点也没有变，只是比以前苍白、憔悴和凝神多了。

隔壁有个孩子在低声唱歌。

他的眼睛离开纸头，等待着，看是谁进来。

“尤黎吗？”他咳嗽了一声，问道。“是你吗？”

“不，是我，”她低低地说，在门口站住了。她望着他，但是看不见，只听到和感觉到他，像是在睡梦里一般。

“是你？……我的苏拉……”他简直没有声音地问。

“是我。”

她穿过房间，没有脱大衣，就小心翼翼地在他床畔坐下来。

“苏拉……我的天！你怎么，是什么风把你吹来的？……”

“是我自己来的，阿廖沙，”她微微一笑，不知道该再说些什么好。“嗯，你怎么样……在你的天堂里？”

他什么也没有回答。他的目光代替了语言。他瞧着她，就像瞧着他自己一样，她担心他会在那里看到些什么。突然他的眼睛慢慢地、羞答答地闪出了那么真实的欢乐光芒，她明白了：一切都很好。

于是她俯下身去，吻着他那没有血色的有点孩子气的嘴唇，同时感到一只激动而有力的长者的手温柔地落在她的头上。

1945年6月—1947年4月

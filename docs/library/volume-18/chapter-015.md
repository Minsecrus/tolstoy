# 附录：主要人物表

阿列克赛（阿廖沙）·维尼阿命内奇·伏罗巴耶夫——退伍上校。

阿列桑德腊（苏拉）·伊凡诺夫娜·高烈娃——外科军医。

耿那箕·阿列克桑德罗维奇·柯磊托夫——区委书记。

叶连娜（列娜，列诺奇卡）·彼得罗夫娜·苏陵娜——区委服务员。

索菲雅·伊凡诺夫娜·苏陵娜——列娜的母亲。

菲尧德尔·伊凡内奇·初曼德陵——胜利农场场长。

谢尔盖·康斯坦京内奇·希罗柯高罗夫——酿酒专家。

奥巴那斯·伊凡内奇·钦巴耳——哥萨克葡萄种植家。

维克多·奥迦诺夫——参加保卫斯大林格勒之战的荣誉军人。

伐尔娃腊（伐利雅）·奥迦诺娃——维克多的妻子。

尤黎·波德聂别斯柯——退伍的青年士兵。

娜塔里雅（娜塔莎）·波德聂别斯柯——尤黎的妻子。

杰联基·高罗德卓夫——退伍的炮兵。

马丽雅·鲍格达诺夫娜·密烈日柯娃——儿童疗养院院长。

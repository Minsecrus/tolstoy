# 一

区里来了一个省粮食委员。

他抽动狡猾的刮得发青的嘴唇，急急地说：

“根据统计资料，您所负责的一区得征集十五万普特<sup class="footnote-ref" id="note-ref-34-1"><a href="#note-34" aria-label="查看本页注释 34">[34]</a></sup>粮食。我任命您，波嘉庚同志，为区粮食委员，因为您是个精力充沛、有上进心的工作人员。我信任您。期限一个月……革命法庭这几天里就会来到。军队和中央需要粮食就像这个样子……”他用手掌在长有硬毛的尖尖的喉结上嚓的划了一下，接着恶狠狠地咬了咬牙齿。“存心隐藏的——枪毙！……”

说完，点了点剃得光光的脑袋，走了。

# 那一首首扣人心弦的安魂曲

——读《灵魂的归宿·俄罗斯墓园文化》

高莽是翻译家，是画家，又是诗人。他从20世纪40年代起就从事中俄文化交流工作，经常陪同中国代表团访俄，接待俄国客人。他的俄汉口译是第一流的，他译诗常以“鸟兰汗”为笔名，译作忠实传神，诗意盎然。高莽半个多世纪来勤勤恳恳，埋头工作，把他的一生献给了中俄人民的友谊，而他的心灵则更是浸透着对俄罗斯文学艺术的无限深情。

最近出版的《灵魂的归宿·俄罗斯墓园文化》收集了高莽近年走访莫斯科、圣彼得堡等地名人墓的记录。全书包括五十篇文章，分文学家墓、艺术家墓、汉学家墓和其他人士墓几部分。文学家墓从普希金到契诃夫，共有七位19世纪作家和诗人，苏联作家从绥拉菲莫维奇到别尔戈利茨，共计十五位。艺术家墓包括从柴可夫斯基到维索茨基，也有十五位。汉学家墓收有比丘林到彼得罗夫，共五位。其他人士墓包括赫鲁晓夫和西林等八位。

这五十位墓主的生活时间，从1799年出生的普希金到近年去世的阿尔希波夫、西林，跨度正好是两个世纪，也就是19世纪和20世纪。从俄国历史看，这是极不平凡的两百年，俄罗斯人民度过了沙皇专制暗无天日时期，又经历了血雨腥风的战争年月，迎来了苏维埃制度的诞生，接着又忍受了内外矛盾的重重苦难，最后又遭遇了苏联解体的剧变。

19世纪俄国出现了一大批才华横溢的作家、诗人、画家、作曲家和歌唱家，他们像一颗颗光辉夺目的明星照亮了漆黑一片的俄罗斯夜空。他们勇敢地冲破沙皇的血腥统治，大胆反映专制制度对人民的野蛮迫害，用震撼人心的语言和诗句激励人民斗志，抚慰他们饱经沧桑的心灵。是的，真正的艺术必须表现人民的苦难，而19世纪的俄国作家、诗人、画家、音乐家又有哪一个不是对下层人民怀着满腔热情，不是全心全意成为他们的代言人？结果他们自然遭到专制当局的残酷镇压，他们也必然无法逃脱悲惨的命运。像普希金、莱蒙托夫这样的天才诗人没有一个不是在“决斗”中倒在血泊里，但他们短暂的一生却始终在讴歌自由，抨击专制。陀思妥耶夫斯基从刑场中死里逃生，又流放西伯利亚，受了四年苦役的煎熬，他的作品又一直在严酷地拷问人的灵魂。高莽站在他的墓前，情不自禁地想：“好像他在无言中也在拷问我的灵魂：你在几十年的风浪中还保持着正常人的状态吗？”他又语重心长地对年轻人说：“我希望每个人成年后都经得起灵魂的拷问。”这真是一句值得每个人永远铭记在心的话：你经得起灵魂的拷问吗？

在雅斯纳雅·波良纳的庄园里，作者站在托尔斯泰墓前，那是一个在林中空地上的土堆，上面没有墓碑，没有十字架，没有任何标志，周围只有橡树、菩提、松杉和枞树，还有白桦。这景象对我来说特别亲切，因为十五年前我也曾默立在这个土堆前，浮想联翩。高莽说：“伟大的托尔斯泰朴实得如同这座土坟。他是俄罗斯大地的一部分，世界的一部分。他属于过去，也属于今天与未来。他在雅斯纳亚·波良纳与大自然融为一体，小小的土坟却是地球上一座巍峨的精神高山。”他又感叹道：“他在人间播撒爱的种子，却终身没有见到爱的世界。”这几句话深刻表达了他对托尔斯泰的崇敬，也说出了我多少年来深埋在心里的感情。

阿赫玛托娃是20世纪俄罗斯最杰出的女诗人，但一生坎坷。她的第一位丈夫古米廖夫也是一位天才诗人，但竟以“人民敌人”的罪名于1921年被判处死刑。他们的独生子成年后也以莫须有的罪名两次被捕入狱。阿赫玛托娃后来又结过两次婚，但都没有得到幸福。

她的墓在圣彼得堡远郊，墓碑非常特别，坟上有一个巨大的十字架，下面是一堵石块垒成的墙。这堵墙象征监狱，墙上嵌着阿赫玛托娃少妇时代的白色浮雕像。据说，这是根据阿赫玛托娃生前的遗愿建立的，她不要建立在风景优美的地点，而要建立在监狱门口，因为她曾在那儿站了三百个小时，苦苦等候探监。这真是血泪斑斑的景象。难怪作为诗人的高莽忍不住感叹说：“人的生命在某些时候可以被任意摆弄，变得无权无能，真的被视如草芥。”而面对着高大的黑色铁十字架，他又无限深情地说：“对待艺术创作，不可轻易地否定作者的苦心探索与追求，更何况谁人不背负着一个沉重的十字架？！”

对阿赫玛托娃的一生，高莽归纳为这样几句刻骨铭心的话：“她来到世间，接受了苦难，又背负着苦难而去。她是母亲中最可怜的母亲，妻子中最不幸的妻子。”

帕斯捷尔纳克是诗人阿赫玛托娃的好友，也是杰出的诗人，而且是著名小说《日瓦戈医生》的作者。他的命运也不见得比阿赫玛托娃好多少。1958年《日瓦戈医生》在意大利首先出版，并获诺贝尔奖。但帕斯捷尔纳克在苏联不但没有因此得到荣誉，反而被苏联作协开除出会，还受到被驱逐出境的威胁，致使他不得不公开声明“自愿”拒绝诺贝尔奖。两年后，他在闷闷不乐中死去，至死也没有看到他那呕心沥血的杰作在苏联出版，尽管在他落葬后有许许多多热情的读者久久不愿离开他的墓地。面对这位才华横溢而身世凄凉的诗人，高莽也无法压抑心头的悲怆，感叹于“具有独立思考的知识分子艺术家少不了生活的磨难”。这也真是一句发人深思的叹息！

爱伦堡是作家，更是一位杰出的政论家。在反法西斯斗争中他几乎每天都要写一篇抨击法西斯德国的文章，使希特勒恨之入骨，扬言德军一占领莫斯科，第一个要绞死的就是爱伦堡。记得当年我们读到爱伦堡的文章，真是痛快之至，觉得多少发泄了我们胸中对法西斯的仇恨。

爱伦堡不仅在反法西斯斗争中爱憎鲜明，而且在对待其他事情上也有自己的独立思考，从不做昧心的事。有一件事很能说明他的铮铮铁骨。1958年帕斯捷尔纳克在国外出版小说并获诺贝尔奖，苏联作家协会等单位动员文艺界知名人士对帕斯捷尔纳克进行谴责。爱伦堡同帕斯捷尔纳克并无深交，但对那次围攻深感不平。他吩咐家人，如有电话找他，全都由他自己来接。果然，作协来电请他出席声讨帕斯捷尔纳克的大会，他也不改自己本来的声音，直率地回答说：“爱伦堡外出了，短期内不会回来。”爱伦堡就这样大无畏地对待这一类不公平的事，显示了他作为一个知识分子的良知和品格。

关于爱伦堡，翻译家姜椿芳还讲过一件事。有一次他们在一起聊天，爱伦堡突然说：“中国人用‘形影不离’形容朋友关系，其实影子只有在阳光充足时才跟在人的后边，阴天就看不见影子了。”这句话含义深长，也是爱伦堡在风风雨雨的几十年人生中真切的体会，具有哲理。

马雅可夫斯基和叶赛宁都是苏维埃时代影响很大的诗人，前者被称为“革命诗人”，后者自称是“最后一个俄罗斯乡村诗人”。乡村诗人在1925年据说是自缢身亡，而革命诗人也在1930年开枪自杀。叶赛宁究竟是自缢还是他杀，至今还是一个谜。他的诗清新自然，充满乡土气息，自然也就倾倒了千万读者，但最大的特色应该说是表现了自由精神，正如他自己说的那样：“只有自由的艺术家，才能带来自由的语言。”

马雅可夫斯基听到叶赛宁的死讯后说：“在今天，死并不新鲜，可是活下去——却困难得多。”这句话其实多少预示五年后马雅可夫斯基自己也走上了绝路。我认为，诗人，真正的诗人，都是社会的晴雨表，他们的诗既能表达群众的欢乐与哀愁，也能反映整个社会的气压，一旦他们感到压力超过极限时，也就只能以死来表示他们的抗争。

高莽凭吊左琴科墓一事，使我特别感动。左琴科是苏联的讽刺作家，20世纪30年代鲁迅、曹靖华等人就译过他的小说，他早年投身革命，当过红军，因病复员，后做过鞋匠、会计等工作，经历丰富。他根据亲身体验，对官僚主义、市侩习气深恶痛绝，就用他独特的讽刺笔法痛加鞭挞，赢得广大读者的共鸣。但这样就引起一味喜欢歌功颂德作品的当局的不满。1946年8月联共（布）中央发表《关于〈星〉与〈列宁格勒〉两杂志的决议》和日丹诺夫的长篇报告，无情打击了一大批苏联作家，点了阿赫玛托娃和左琴科的名。这事表面上是批判文艺界的思想倾向，实际上是与日丹诺夫和马林科夫二人争权有关。日丹诺夫的报告蛮横粗暴，对文艺界人士扣上种种莫须有的帽子，骂左琴科是“市侩”、“贱货”、“无耻文人”，说他的《猴子历险记》是一篇“野兽式地仇恨苏维埃制度的有毒作品”，说他的《日出之前》是“一部诽谤的小说”。其实《猴子历险记》只是一本生动有趣的儿童读物，而《日出之前》则是一种体裁新颖的科学小说。结果左琴科被苏联作协开除出会，连作协所发的食品供应证也被吊销了，而这在战后供应困难时期更是莫大的打击。左琴科受到精神和物质的双重打击，出版社和杂志不仅不再出版他的著作，而且还要逼他归还预支稿费。左琴科走投无路，只得重操旧业当鞋匠，并变卖家中杂物勉强度日。

不仅如此，左琴科还不断受到各种形式的批判，在一次批判大会上他勉强带着有病之身毫不含糊地反驳对他的诬蔑。有人说他是“投机分子”，他回答说：“我是志愿参加红军的。”有人说他在战争期间逃离列宁格勒，他回答说：“我是奉命离开列宁格勒的。”他还提出在对德战争中苏联政府先后发给他五枚战斗勋章，表扬他的爱国行为。但在当时的情况下他也无法为自己辩护，他只能悲叹说：“在这样的环境里，我的文学生涯和文学命运已走到尽头。我已无法摆脱绝境。……我已经没有前途可言！……我的身心已远远超过疲惫！”

就在这种完全绝望的心情中，左琴科走完了人生的道路，于1958年夏天去世。高莽千方百计想去拜谒左琴科的墓，但始终没能如愿，直到1999年夏他才争取到机会去凭吊左琴科在圣彼得堡的墓。高莽为什么坚持一定要去凭吊？原来1946年他在哈尔滨工作时，曾翻译过联共（布）的这一决议摘要和日丹诺夫的报告，当时他不知道左琴科是何许人。几十年来风云变幻，联共（布）决议和日丹诺夫报告早已受到历史的否定，左琴科也早已恢复名誉，他的作品也重新出版，得到更多读者的肯定。当年我国翻译那些文件是完全可以理解的，高莽作为俄语翻译家参与了这项翻译工作也是无可厚非的，但高莽却长期以来精神上感到不能平静，他说：“多少年来，总觉得自己有负于左琴科。我坚持要去，因为放弃这个机会，很难确定何时还能向这位作家表示自己的内疚。”读到这里，我又看到左琴科昂首默坐在墓上那尊神采奕奕的雕像，更是感慨万千，但不论如何，高莽作为翻译家在这件事上是没有责任的，他那种负疚的心理只能表明他那种过人的责任感和坦荡的胸怀，值得我学习。

梅耶荷德是苏联著名戏剧家，他不仅在戏剧导演方面造诣很深，而且理解中国戏剧。梅兰芳对他评价很高，说苏联戏剧家中真正懂得中国戏曲的只有梅耶荷德一人。他的妻子赖赫是一位极有表演艺术才能的演员，也享有盛名。但悲惨的命运没有放过这对同命鸳鸯。1937年12月《真理报》发表一篇评论文章《异己的戏剧》，对梅耶荷德的艺术探索痛加责骂。二十天后苏联政府艺术事业委员会就查封以梅耶荷德命名的国家剧院。那天赖赫在舞台上扮演《茶花女》主角，这是她第七百二十五次扮演这一角色，也是她在这个剧院工作十三年来最后一次演出。

1938年6月20日梅耶荷德出差列宁格勒，突然被捕。同一天，梅耶荷德的莫斯科寓所遭到搜查。夫人赖赫在搜查证上签了字，并在上面写了一句：搜查人员“蛮横无理”。这是她对内务部工作人员侮辱人格的大胆抗议。二十四天后，赖赫在家中遭人杀害，身上有十七处伤，但家中没有遗失任何东西。内务部还命令她的女儿和儿子在四十八小时内腾出寓所，而搬进去的是贝利亚的司机和贝利亚手下一名年轻女郎。

梅耶荷德于1940年2月2日被处决，终年六十六岁。

1999年6月高莽在莫斯科瓦冈口公墓找到他们的合葬墓，墓上一块黑色大理石上刻着梅耶荷德的头像和他们夫妇二人的姓名。其实，这座墓只是象征性的，因为梅耶荷德遭处决后没有人知道他葬在何处，这墓也只能是后人抚慰一对冤魂的纪念罢了。

肖斯塔科维奇是苏联最负盛名的作曲家，但他的遭遇也并不轻松。他一生创作了十五部交响乐，为四十多部电影配了音乐，他在国内外获得大量勋章、头衔，但他脸上总是一副愁容。

早在1936年《真理报》就发表社论，批判肖斯塔科维奇的歌剧《姆岑斯克县的麦克白夫人》，辱骂它是“噪音而不是音乐”。这是当局又一次对文艺界开展批判运动，基调也是斯大林定的。当时肖斯塔科维奇才三十岁，已形成自己独特的风格，因为与众不同，就遭到批判。

肖斯塔科维奇个性很强，对任何人任何事都有自己的看法，这些看法就反映在死后发表的《见证》一书里。他说：“我原以为我的生活充满了忧伤，更难找到比我更不幸的人，但我一回忆起我的朋友和熟人的生活便禁不住不寒而栗。他们中间没有一个人的生活是轻松幸福的。有些人结局悲惨，有些人在极大的苦难中死去，许多人的生活可以说比我更不幸。”

肖斯塔科维奇虽然生活上历经坎坷，但他对音乐和诗的信念始终没有动摇，那就是：“音乐是善，不是恶。诗是善，不是恶。”

在普天下所有的墓上，用黑白两色花岗石做墓碑的恐怕只有赫鲁晓夫一个。这座墓碑不仅构思别致，而且雕刻精美，尤其赫鲁晓夫那个夹在黑白几何体托座上的头像更是栩栩如生。这个艺术杰作原来是俄国著名雕刻家涅伊兹韦斯内的作品，而他同赫鲁晓夫之间还有一段耐人寻味的故事。

涅伊兹韦斯内是位现代派雕刻家。1962年在莫斯科美协成立三十周年的展览会上，他的作品占显著地位。展览会开幕第一天，赫鲁晓夫率党政要员前去参观，一看到他的现代派作品便破口大骂：“驴尾巴甩的玩艺儿也比这些东西强！”还凭空辱骂作者是同性恋者。涅伊兹韦斯内听了无法克制怒火，当场就同赫鲁晓夫顶撞起来，也说了些粗话。事后，赫鲁晓夫的手下人，要他写一份检讨，以消除媒体的影响。涅伊兹韦斯内完全按自己的想法写了一份意见，根本不是检讨，当然也不能发表。赫鲁晓夫下台后，邀请文艺界一些被他批评过的人到他家作客以缓和关系，他三次邀请涅伊兹韦斯内，但涅伊兹韦斯内始终没有去。

赫鲁晓夫去世后，赫鲁晓夫的儿子要求涅伊兹韦斯内替他父亲设计制造墓碑，并说这是父亲生前的遗愿。涅伊兹韦斯内同意了，但必须照他的想法做。结果就做成了这座天下独一无二的墓碑。

黑白两色的墓碑确实意味深长，它可以表示新旧两个交替的时代，也可以看作评价赫鲁晓夫的历史功过，更可以表达艺术家对这位政治人物的爱和恨……

但不论怎么说，赫鲁晓夫墓碑毕竟是一件艺术精品，永远值得人们欣赏和重视。

在中俄友好人士墓中间最值得人敬仰的是阿尔希波夫墓和西林墓。他们的墓都在莫斯科，但不在同一个墓园。

阿尔希波夫在20世纪50年代初率一批苏联专家来华，他是总负责人，在华工作了八年，对中国人民怀有深厚感情。他在八十九岁高龄时再次来华，接受人民友好使者纪念章，并看望一些老友，还到大连金石滩公园种了一株小松树。种好后他弯下身去，轻轻托起松树的一束嫩枝，贴在双唇上说：“亲爱的小松树啊，快快地长吧！你代表我留在这儿了……”充分流露出他对中国的爱。第二年他以九十高龄去世，正如他自己说的那样：“我的根扎在这片土地里了，我的心一半留在中国了……”

西林是一位杰出的桥梁工程师。20世纪50年代中叶，西林参加了武汉长江大桥的修建工程。四十多年来，多少人在这第一座长江大桥上来来往往，但又有几个人知道西林的名字？

西林一生造了许多大桥，包括伏尔加河大桥、第聂伯河大桥、多瑙河大桥，但他最珍惜的还是武汉长江大桥。他几次来华，每次都要去看望他这座血汗结晶的连心桥。他的外孙女卡佳深受外祖父影响，对中国也很有感情。她在莫斯科大学读书时，就研究中国问题，并获得最高的总统奖学金。1997年卡佳第一次来华，在武汉进修三个月，天天欣赏长江大桥，可见她对中国感情之深。

1996年西林因心脏病去世。1999年高莽陪同西林夫人和女儿去扫墓，夫人亲手把墓碑擦得干干净净，久久地坐在碑前凝视西林的像，临别时又把自己的脸贴在西林的像上，贴了好长一会儿。在西林的墓碑上，除了他的像之外，背景还有巍峨壮观的武汉长江大桥图。西林背靠着他精心杰作的大桥，脸上永远露出安详的微笑。

这本图文并茂的《灵魂的归宿》内容实在太丰富，我只能从中举出一小部分来介绍，而它给人的思索却是无穷的。读这部书我的眼前不断浮现出一个又一个我熟悉和不很熟悉的人的影子，而耳朵里仿佛听到一首又一首扣人心弦的安魂曲。

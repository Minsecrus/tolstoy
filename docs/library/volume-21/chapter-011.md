# 谈法捷耶夫的悲剧

——给蓝英年的第二封信

英年同志：

读了您写的《法捷耶夫之死》和《访法捷耶夫故居》两文，我的眼前立刻浮现出一个白发如银、面色红润的俄罗斯老人的脸，那就是法捷耶夫。1949年10月我在上海参加了第一个苏联文化代表团的接待工作，代表团团长是法捷耶夫，副团长是西蒙诺夫，陪同代表团来沪的是诗人萧三。我当时还是个二十几岁的青年，对法捷耶夫和西蒙诺夫怀着无限敬意，有机会亲睹他们的风采，当然十分兴奋。尤其对法捷耶夫感到特别亲切，因为早在1939年我就读过鲁迅翻译的《毁灭》，后来又看到了《青年近卫军》。但遗憾的是法捷耶夫在上海只逗留一天，第二天因另有任务就单独先回苏联，把代表团留给西蒙诺夫带领。西蒙诺夫在我国也已出名，他的小说《日日夜夜》使我们看到斯大林格勒血战的酷烈，而他的短诗《等着我吧》更是在苏联卫国战争中起了鼓舞爱国热情的巨大作用。现在这位诗人就同我国的诗人萧三坐在一起，滔滔不绝地交流着难以抑制的喜悦之情。西蒙诺夫当年相貌英俊，留着小胡子，风度翩翩，说话风趣，引人入胜。萧三则老成持重，透露出充满智慧的诗人气质。同桌赴宴的还有一位漂亮活泼的女翻译家，西蒙诺夫叫她索尼雅，后来知道她就是著名的戏剧家孙维世<sup class="footnote-ref" id="note-ref-11-1"><a href="#note-11" aria-label="查看本页注释 11">[11]</a></sup>。孙维世留苏多年，说得一口流利的俄语，很能喝酒，频频向客人敬酒，说什么“谁不干，谁就是胆小鬼”。事情过去都已半个世纪了，但此情此景仍历历在目。

法捷耶夫在1956年开枪自杀，西蒙诺夫以后又写了不少作品，我虽然没有再见过他，但看到他后来的照片，简直无法相信，这个形容憔悴的老人就是当年风流倜傥的西蒙诺夫。萧三在十年动乱中以莫须有的罪名坐了七年多牢，而孙维世则仅仅因为遭江青忌恨在“文革”中受尽酷刑而被折磨致死。

往事如烟，沧海桑田，世界发生了多少翻天覆地的变化，给我们心里留下多少悲凉和沉思！但我想，如果人类只沉溺在痛苦的回忆中，或者讳言历史的悲剧而不从中吸取必要的教训，一味用粉红色的幕布来掩盖血淋淋的事实，那就不仅愧对千万死不瞑目的冤魂，而且无颜向子孙后代交代这一段刻骨铭心的惨痛历史。每想到这一点，我总感到心情沉重，不寒而栗。

英年同志，法捷耶夫的遗书于1990年终于公之于众，您把它译成中文，这是一件大好事，使我们对法捷耶夫的悲剧有了正确的理解。法捷耶夫的遗书写得直率明了，一开头就说“我看不出再活下去的可能，我为之奉献终生的艺术已被党的自负而无知的领导所扼杀，现已无法挽救”。短短两句话就把他自杀的原因说得清清楚楚。接下来又进一步叙述了当年苏联作家的遭遇。“优秀的文学干部在当权者罪恶地纵容下，或被从肉体上消灭，或被折磨至死，其人数之多，甚至历代沙皇暴君做梦也难想到。优秀文学人才过早夭亡，余下的多少能创作具有真正价值作品的人，活不到四五十岁。”这段话真是字字血泪，读了使人心碎。法捷耶夫在临终之前说出这样的话，一则表示他对整个苏联文学界的悲惨处境已有深刻的认识，二则反映他对自己几十年来作为文艺总管的罪孽也有了痛彻心肺的觉悟。

在临终的最后时刻，法捷耶夫回顾自己的一生（他从1934年苏联作协成立起就是领导人之一，1946至1954年任作协总书记，1939至1956年还是苏共中央委员），又说出令人断肠的控诉：“把我变成一匹拉车的马，一生吃力地拉着不计其数的平庸的、不合理的、任何人都能胜任的官僚主义事务。甚至现在当我总结自己一生的时候，多少呵斥、训斥、训诲以及不过是思想意识的毛病向我袭来，而我本应是我国优秀人民引以为荣的人……”除了控诉自己不幸的遭遇，法捷耶夫又进一步揭发当年苏联文学的状况。“文学——这新制度的最高产物——已被玷污、戕害、扼杀。暴发户们在以列宁学说宣誓时他们的自负已背离伟大的列宁学说，令我对他们完全不信任，因为他们将比斯大林更恶劣。”

法捷耶夫毫不隐讳地指出苏联文学已被玷污、戕害、扼杀。应该说这是他以惨痛的生命代价换得的最后觉悟。说到法捷耶夫同斯大林的关系，爱伦堡的话是一针见血的。他说：“法捷耶夫同斯大林的关系是严守纪律的士兵同权力无比的总司令的关系。”而法捷耶夫还亲口对爱伦堡说过这样的话：“我最怕母亲和斯大林，但也最爱他们两人。”

斯大林当年确实是一位权力无比的总司令，而法捷耶夫也真的是一名严守纪律的士兵。正因为总司令的权力无比而士兵又严守纪律，在斯大林专政年代苏联遭到处决、关押、流放的作家竟达两千人之多。这是一幅多么阴森恐怖的图画！当然我们也不能说这两千名作家都是富有才华、成绩卓著的优秀人才，但他们毕竟是对人民对社会有贡献的人。任何时代任何国家的作家都不是一声令下就能写出为读者所喜爱的作品来的，即使像当年苏联那样人口超过亿万的大国也不可能出现成千上万的作家。因此在短短三十年里消灭两千名作家，这是多么残酷的罪行！而对一个国家来说，消灭两千个有思想的脑袋又是多么巨大的损失！要实现这样的暴行，只有权力无比的总司令才能做到。不过，光有总司令不行，还得有严守纪律的士兵执行他的命令。当然，我们也不能把迫害苏联作家的罪责全部归到法捷耶夫一人身上。

斯大林这个词是从俄文“钢铁”一词演变而来的，而斯大林其人确实具有钢铁一般的性格。他的残酷专政当然不仅仅限于文艺一个领域，在消灭敢于对他的独裁说一个“不”字的政治对手方面的罪行，更是罄竹难书。不过，我们是从事俄苏文学工作的人，我们首先有责任来研究、探讨这方面的问题，从而使广大读者认清事实真相，不再受形形色色的谎言和谬论的影响而颠倒是非，混淆黑白。您说是不是？

在评价法捷耶夫的功过上，当然首先不能回避他那“文艺总管”这一角色。是他忠实执行总司令的一切命令，对文艺工作者（当然首先是作家）实行严格的监控，使他们老老实实做一名完全服从专政指挥棒的“文人”，如果稍有反抗，或者发出不同的声音，就会遭到家破人亡的下场。像这样严酷的专政，应该说超过任何一个俄国沙皇。托尔斯泰在沙皇统治下一生遭到种种难以描述的迫害，但他还能够面对沙皇无辜绞死几名农民一事发表《我不能沉默！》这样震撼世界的檄文。试问，要是托尔斯泰生活在当代，他有机会发表这样义正辞严的抗议吗？难怪法捷耶夫在遗书里明确地指出，在消灭作家的血腥罪行上“其人数之多，甚至历代沙皇暴君做梦也难想到”。法捷耶夫毕竟是有才华的作家，他只用一句话就表达出那种骇人听闻的滔天罪行。当然，要发出这样动人心魄的悲鸣，自己的心首先必须受到震动，也只有这样才能做到真正的忏悔。我想，在斯大林死后到法捷耶夫自杀的三年里，法捷耶夫一定在反复回顾自己悲剧的一生，他想到那些惨遭杀害的作家同行和他们的孤儿寡母，他的心一定在不断地淌血，他想向人倾诉，但没有人会听他的忏悔。于是他不得不借酒浇愁，以缓和内心的剧痛，但酒毕竟无法治疗他的心病，他只能用枪来结束自己的生命。

正如您在文章中指出的那样，除了在肉体上参与消灭大批有才华的作家之外，法捷耶夫还对苏联文学犯了另外的罪行，那就是忠实执行一条有利于巩固斯大林专政的文艺政策，具体地说要所有苏联作家都按照所谓“社会主义现实主义”的方法从事创作，而“社会主义现实主义”也就是要在作品中处处突出党的领导，苏联人民在各个领域的胜利都应归功于党的领导，而斯大林则是党的化身，因此也就是文艺作品要处处歌颂斯大林。谁要是不这样做，而在作品中强调反映真实生活，表现人民群众是创造历史的真正英雄，谁就是反对党的领导，反对斯大林这位英明的领袖，谁就是没有党性，这样的作品就不能发表，发表了就要受到口诛笔伐。在苏联文学中当然也有不少优秀的作品，但一些歌功颂德、粉饰现实的平庸之作泛滥成灾也就不足为奇了。

法捷耶夫作为斯大林的文艺总管确实起了无人可以替代的重要作用。他一方面具体“指导”苏联作家的作品，使它们纳入“党性原则”这一轨道，而他自己既是一位有才华的作家，又是文艺总管。这种双重身份使他在处理自己作品时也着实感到为难。法捷耶夫在苏德战争结束后很快发表长篇小说《青年近卫军》，受到各方面重视。小说主要描写克拉斯诺顿地区一批青年同德国法西斯顽强搏斗的英勇事迹，小说真实反映苏联青年在战争中不惜自我牺牲的爱国精神。但是，就在读者和文艺界对这部作品的一片赞扬声中，当时苏联报纸在斯大林授意下猛烈批评《青年近卫军》，质问法捷耶夫克拉斯诺顿的党组织到哪里去了。法捷耶夫只得公开承认错误，决定重写，但他心里明白，要是硬加入党领导这一情节，全书就会走样。事情果然是这样，修订本发表后苏联就出现了两种截然相反的意见，一种是肯定修订本改得好，因为加入了党的领导这一重要情节，一种是认为修订本改糟了，因为凭空插入党的领导这一情节，违反了当时的实际情况，也就是违反了生活的真实。法捷耶夫在文艺上毕竟是内行，他懂得凡是有价值的作品首先必须忠实于生活的真实，只有真实才具有艺术的魅力，才能震撼读者的心。他凭着自己的才华和对生活的真实体验写出了初稿，接着又在以斯大林为首的党的批评下违心地进行重大修改。这里就在他身上发生了无法调和的矛盾，也就是作家的艺术良心同文艺总管的党性之间的冲突。必须指出法捷耶夫取得作协领导地位之后，他的权力欲越来越膨胀，以至达到权迷心窍的地步，而他的良知也就越来越受到损害，做了一系列错事。从他当时的身份和认识出发，他当然首先服从“党性”，很快作了重大修改，以致损害了小说的艺术价值。这件事发生在法捷耶夫自己身上，他在当时的情况下也只能这样做，但我们可以想象当时他的内心一定很痛苦，而在有了觉悟之后，就更感到深深的悔恨。

在对待其他苏联作家的作品上，这一类问题就不胜枚举。读了您最近写的《反社会主义现实主义的作家——也谈格罗斯曼》一文，更可以清楚地看出法捷耶夫当年的困难处境，也就是他的悲剧的深度。

我知道格罗斯曼还是在20世纪40年代。那时我读了他的纪实作品《特烈勃林卡地狱》（当年的时代出版社就出过中译本），心灵上受到无法形容的震撼。特烈勃林卡是波兰一个小火车站，离华沙六十公里，在德国法西斯侵略欧洲期间，一度被纳粹秘密警察头子希姆莱看中，建立了一个死亡集中营，在十三个月时间里总共屠杀了近百万人。当年用火车从四面八方运送到这里来的无辜平民每天有六十节车厢，每节车厢密密地装着150到200人。凡是被送到这里来的无一能够生还。战争临近结束时，纳粹为了掩盖血腥罪行，把杀人工厂彻底焚毁，又把埋下的尸体全部挖出来烧掉。斯大林格勒大战后德国败局已定，格罗斯曼作为《红星报》记者随同红军攻入特烈勃林卡车站。他从被俘的纳粹党卫军嘴里听到他们怎样用杀人工厂屠杀了大量平民，其中主要是犹太人。格罗斯曼深为感动，就用他亲自调查所得写出这部读了令人毛骨悚然的《特烈勃林卡地狱》，于1944年发表。战争结束后，纽伦堡国际军事法庭审判纳粹战犯，《特烈勃林卡地狱》成了一件有力的罪证。我当年读了这本书更懂得法西斯的野蛮暴行，决心要同形形色色的法西斯主义作斗争。我认为，如果无视和忘记人类历史上这一段可耻的记录，将是一切有良知的人的耻辱。

从《特烈勃林卡地狱》的创作这件事上，我们可以清楚地看出，格罗斯曼是一位具有大爱大恨的作家，这样的作家总是真诚地同人民站在一起，他的作品也总是要真实地描写人民的生活，反映人民的欢乐和苦难。但是，格罗斯曼后来的遭遇却是多灾多难的，正如您在文章中介绍的那样。

早在1941年苏德战争发生后，格罗斯曼就以记者身份来到斯大林格勒，直接参加了斯大林格勒会战。根据在前线的亲身见闻，他创作了长篇小说《为了正义的事业》。这部小说生动地描写了战争的残酷，指出双方伤亡惨重，真是尸横遍野，血流成河。除了战争的血淋淋场面外，他还深刻描写不同人物在战时的内心活动，可以说是入木三分，感人至深。1950年格罗斯曼把《为了正义的事业》手稿寄给《新世界》杂志主编西蒙诺夫。我们知道，西蒙诺夫自己也写过反映斯大林格勒大战的小说（《日日夜夜》），在读者中有一定影响。现在格罗斯曼写了同一题材的长篇小说，而手法又与西蒙诺夫以正统手法写的小说截然不同，这自然不符合西蒙诺夫的口味。他把这部稿子搁着一直没有采用，也没有退稿。不久，特瓦尔多夫斯基接替西蒙诺夫任《新世界》主编。特瓦尔多夫斯基是位诗人，以写长诗《华西里·焦尔金》著名。他富有正义感，又有较高的艺术鉴赏水平。他读了《为了正义的事业》，大为赞赏，亲自赶到格罗斯曼家，表示决定在《新世界》上发表这部小说。接着特瓦尔多夫斯基又找法捷耶夫商量，法捷耶夫读完手稿，同意特瓦尔多夫斯基的看法，还专程到格罗斯曼家向他表示祝贺。但法捷耶夫做事谨慎，他又请作协书记处所有成员阅读手稿。在书记处同意后，他才就内容提了些枝节意见，批准在《新世界》上发表。

《为了正义的事业》1952年在《新世界》上连载完毕，得到读者普遍好评。法捷耶夫又指示提名这部小说为斯大林文学奖候选作品。但是谁也没有料到这事两个月后会风云突变，原来有些肯定这部小说的作家竟来了个一百八十度大转向，斥责这部作品有重大政治错误，检讨自己水平太低，不能看出问题。

怎么会发生这样的突变？原来有一个叫布宾诺夫的作家给斯大林写了一封长信，尖刻批评《为了正义的事业》。布宾诺夫也写过一部描写战争的小说《白桦》，但《白桦》比较平庸，没有引起重视，根本不能同《为了正义的事业》相比。布宾诺夫却在信里恶意攻击说：格罗斯曼未能塑造出斯大林格勒会战中一个有分量的鲜明的典型人物。小说根本没有表现苏联人性格的主要特征，没能以丰富和壮丽的感情震撼读者的心灵。在《为了正义的事业》里苏联人的形象写得苍白、屈从、暗淡。作者竭力表现不朽的功勋是普通人建立的……而他笔下的普通人首先是一群无足轻重的人。格罗斯曼根本没表现作为前线和后方胜利组织者党的领导。对共产党的组织和鼓舞的巨大作用也只轻描淡写地提了一下，并未用艺术形象表现出来。

这封告密信像一颗重磅炸弹，不仅直接落在格罗斯曼头上，而且还击中了法捷耶夫和特瓦尔多夫斯基。法捷耶夫不得不在1953年2月24日召开的作协理事会上公开作了检讨，重述了布宾诺夫的意见。特瓦尔多夫斯基也以《新世界》主编的身份承认了错误。

不过，苏联在这个时期发生了重大变化，斯大林于1953年3月去世，苏共党内斗争激烈，文艺界也出现重大转机，开始“解冻”。1954年苏联召开第二次作家代表大会，法捷耶夫在大会上当着外国代表团的面向格罗斯曼道歉，承认原来对《为了正义的事业》的批评是不公正的，并要尽快出版小说的单行本。同年七月法捷耶夫还给格罗斯曼发了一封电报说：“小说《为了正义的事业》即将出版。不在书记处讨论。问题已彻底解决。紧握您的手。”格罗斯曼在完成了《为了正义的事业》之后，又继续创作它的续编《生存与命运》，并于1960年完稿。正如您所详细介绍的，《生存与命运》内涵更加深刻，反映出来的生活真实更加丰富，触及的问题也更加尖锐，以致在1964年格罗斯曼去世时还不能在苏联发表。

通过格罗斯曼事件，我们可以更清楚地理解法捷耶夫的悲剧。他确实是一位富有才华的作家，而且始终没有完全丧失知识分子的良知，遇到问题也总是反复思考，竭力想弄清是非，但是他毕竟是一位严守纪律的士兵，而身为“文艺总管”不免又陶醉于自己“一人之下万人之上”的权力，常会随着“总司令”而滥用权力。但他的良知至死并没有完全泯灭，当“责任”和“良知”在他身上发生冲突的时候，他也只能借酒浇愁。在遗书未发表前，苏联官方都把法捷耶夫的自杀说成是由于他长期酗酒以至酒精中毒，还发表了医生的证明，但现在我们明白那是当年当权者欺骗老百姓的又一卑劣政治手法。我们说纸包不住火，俄国人说口袋藏不住锥子，意思都一样，那就是谁想一手遮天，最后都只能以失败告终，因为正如高尔基所说的，“真理是血的海洋也淹不没的”。您说是不是？

# 诗人无语对苍天

——记普希金像的三起二落

又是清明时节，春雨绵绵，使人郁闷。我走在汾阳路上，仰望街心花园里的普希金像，又一次看到诗人无语对苍天的神态，不禁思潮起伏，感慨万千。

1837年2月10日，这位俄罗斯大诗人在饱受沙皇专制迫害后，最终又在预先布置的阴谋中惨遭杀害。一百年后，旅居上海的俄侨为了纪念这位杰出的诗人，集资在汾阳路（当年叫毕勋路）上建立了一座纪念像。那是1937年2月的事，正当日本侵华战争前夕。当时我还小，在家乡念书。第二年我随家避难上海，一面进中学读书，一面跟俄侨老师学习俄语。普希金和其他俄国作家开始进入我这个少年的心，我如饥似渴地阅读他们的作品，心灵上感受到热爱祖国、向往自由的感情，也爱在普希金像下漫步。

不久，太平洋战争爆发，日军进入租界，上海已完全处于日本人的控制下。有一天，我发现普希金头像不见了。后来才知道日军搜罗一切金属制品去造枪炮，连普希金的头像也未能幸免。我感到满腔悲愤，欲哭无泪。

经过八年艰苦卓绝的抗战，日本宣布投降，上海也结束了日军占领的黑暗时期。1947年2月，上海俄侨再次集资重建普希金像。那天参加重建仪式的人不少，有俄侨代表如汉学家罗果夫，也有我国文艺界人士，如姜椿芳、戈宝权等，我也参加了这个仪式。大家都欢庆这位讴歌自由的俄罗斯诗人又同上海市民朝夕相处。

但怎么也没有想到这位诗人在异国土地上会再一次遭殃。在“文革”中，他的头像又被中国的“造反英雄”砸烂了。当年，我同几位“牛鬼”难友拉板车经过汾阳路，有时席地坐在人行道上休息，一面喝着两分钱一杯的“大众茶”，一面茫然望着被毁的普希金像旧址，心里感到无法宣泄的悲凉。

我们终于熬过了十年浩劫，雨过天青，拨乱反正。1987年8月，上海市民终于再一次为普希金建像。我又一次恭逢其盛，参加了重建仪式。我站在人群中，回顾往事，百感交集。普希金像在他乡异国的土地上就这样经历了三起二落的遭遇。我仰望诗人傲然挺立的英姿，他那掷地有声的诗句不禁又在我的耳际回响：

愿望之火在我们胸中燃烧，

残酷的命运绝不能把我们摆弄！

# 无声的控诉和无言的宣誓

一个身材高大、肩膀宽阔的老头儿，袒胸露臂，筋脉毕现，两只粗壮的脚稳健地踏着大理石台座，双目悲愤地瞪着前方。黑色的大理石台座上摆满一束束鲜红的菖兰、玛瑙色和粉红色的康乃馨。周围是一队队的少先队员、共青团员和从各地前来凭吊的人们。这里是白俄罗斯共和国首都明斯克远郊哈丁村的卫国战争纪念地。哈丁是个小村，只有二十六户农家，但也像苏联无数被炮火吞噬的城乡那样，遭到了一场浩劫。1943年3月22日，希特勒匪军节节败退，被迫撤离哈丁村。撤离前，他们把全村居民驱赶到一座仓房里，四周架起机枪，在仓房上浇上汽油，把村里男女老少全部活活烧死。那些试图从仓房里冲出来的人，一个个都被机枪扫死。村里的房子全部被焚毁，全村一百四十九个居民遇难，其中包括七十六个儿童。唯一幸存的是个老铁匠，他当时正巧不在村里。当他回到村里时，德军已撤离，哈丁村已被夷为平地，村里已没有一个活人。老铁匠在死难的乡亲中认出自己小儿子的尸体。他把儿子抱起来，遥望苍天，热血沸腾，胸膛里充满对法西斯匪军的无比愤怒和对死难亲友的无限悲痛，木然呆立在一片废墟上。战后，这位老铁匠就作为法西斯罪行的目击者和受害者，一遍又一遍地向前来凭吊的人们控诉这一血腥的罪行，直到他生命的最后一天……

如今，老铁匠的巨大塑像屹立在哈丁村上，继续作着无声的控诉，而在塑像附近则是那座仓房和二十六户农家留下的废墟模型。每户农家都只剩下断垣残壁，但墙角砌起一个个残缺不全的烟囱。每个烟囱上都镌刻着全家死难者的名字，还标明他们的年龄，其中包括儿童，有十几岁的，有三五岁的，甚至只有一岁的。烟囱顶端安了一口铜钟，每隔三十秒二十六个钟同时齐鸣，仿佛在永不休止地悼念死难的人们。据说，像哈丁村这样彻底被毁的村子，光是白俄罗斯就有一百八十六个，留下哈丁村作为代表，其实也就是悼念千百个遭到浩劫的乡村。

在离老铁匠塑像不远，还有四块巨大的正方形黑色大理石，引起人们的注意。三块大理石中心都有个花坛，每个坛里各种着一棵高大的白桦树；第四块大理石上没有种树，中间是一个用天然气燃烧着的长明火。三棵枝叶繁茂的高大白桦和一堆熊熊燃烧的烈火，看来像是奇怪的凑合，其实却是含意深长的象征。原来在苏联卫国战争中，白俄罗斯有百分之八十以上的房屋被毁，四分之一的居民牺牲。这里，三棵生气蓬勃的白桦象征饱经战火煎熬而顽强地生活下来的四分之三的人民，而一堆永不熄灭的烈火则表示四分之一死难的烈士，他们的爱国精神永垂不朽。

老铁匠神态生动的造像、几十户农家触目惊心的废墟和一根根残缺的烟囱、烟囱顶上每半分钟敲响一声的丧钟、三棵从黑大理石花坛中长出来的参天白桦和一堆熊熊燃烧的长明火，这一切综合在一起，好像一部扣人心弦的悲怆交响曲，给人留下难忘的印象。

是的，希特勒发动的战争给苏联人民造成史无前例的灾难。当时两亿人口的国家牺牲了两千万人。几乎没有一个家庭的餐桌上没有留下空位，没有一个人的身上或心灵上没留下难愈的伤痕。

现在，卫国战争的炮声静止已有四十年了，被战火烧成废墟的地方早已矗立起一幢幢款式新颖的高楼大厦，满目凄凉的战场上已建成一座座现代化的城市和美丽的乡镇，城乡人民都满怀信心地在各自的岗位上埋头建设，过着幸福的和平生活。

不过，苏联人民并没有忘记惨痛的历史教训。我们在莫斯科、列宁格勒、基辅、明斯克和埃里温都看到规模浩大、展品丰富、设计别致、发人深思的卫国战争纪念馆、纪念碑、烈士陵和综合纪念群。纪念馆的洁白大理石墙上，从上到下密密麻麻地排满死难烈士和卫国英雄的名字，名字都用金字嵌成，金光闪闪，上面冠以获得的勋章和奖章的图案。陈列的实物有烈士用过的衣服、武器和书籍，有大幅照片、画像、雕塑，有被子弹打穿的党证和团证，有小学生在列宁格勒被围困时期写下的日记：“×月×日，今天奶奶饿死了……”“×月×日，今天妈妈死了，我们没有食物了……”讲解员向我们说明，在列宁格勒被围困的九百天里，牺牲了一百万人，单是饿死的就有二十四万四千人，但这个英雄城市始终没有屈服。

为了悼念死难的烈士，珍惜幸福的和平生活，苏联人民在战后形成了几种特殊的习惯。我们在各地瞻仰烈士陵的时候，常常看到一批批新婚夫妇来到墓地。新郎新娘身穿结婚礼服，在男女傧相伴同下，手捧鲜花，徐徐而来，有的还有专为新娘提裾的提纱童。新郎新娘先向烈士献上花束，默立致哀，然后在墓前摄影留念。在莫斯科红场，也可以看到许多新婚夫妇来到列宁墓前献花致敬。据说，新婚夫妇到结婚登记处登记后的第一件事，就是拜谒烈士陵或纪念碑，在烈士陵前摄的纪念照也就是他们最珍贵的结婚照。

再有一件事给我们留下难忘的印象，那就是在各地烈士陵和无名英雄纪念碑前常有四名武装青年守灵。一般是两男两女，男的全副武装，手持步枪；女的也是武装，但下身穿裙子，白鞋白袜，有的头上还扎着两个白色的蝴蝶结。他们分两行站立在烈士墓前，精神抖擞，神态严肃，双目平视，一动不动，使人觉得他们已同烈士纪念碑自然地融合成一个整体。我们起初不知道，以为他们是值岗的士兵或民警，后来才了解，他们都是高年级学生。而且按照他们的习惯，给烈士守灵是一种莫大的荣誉，只有品学兼优的学生才配享受。每班守灵的时间是半小时。半小时不算长，但要一动不动地立正半个钟头可也不容易，何况又是风雨无阻的。我们在基辅正好看到换岗。只见从一百来米外的入口处，四个武装学生迈着正步，雄赳赳地向岗位走去。他们的步子迈得那么高，腿和身子正好形成九十度，使人觉得他们好像是武装仪仗队，正在接受国家领导人或贵宾的检阅，尽管没有乐队伴奏，也没有专门检阅的人……

离开苏联已有十天了，但哈丁村老铁匠悲愤的形象、烈士陵前新娘身上洁白的长纱和守灵青年严肃的神态，却一直萦回在我的头脑里。我仿佛听到老铁匠正在严正地控诉法西斯暴行，看见一对对幸福的年轻人在最快乐的日子也不忘对前辈烈士的悼念和感激，还听到青年学生在守灵时作着庄严的宣誓：保证继承先烈的光荣传统，随时准备为祖国和人民的利益献出一切……

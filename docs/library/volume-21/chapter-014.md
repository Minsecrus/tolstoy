# 反法西斯斗争中的《时代》

上海一向是个特殊的地方，在当年反法西斯斗争中也不例外。1941年6月22日，希特勒突然进攻苏联，揭开苏德战争的历史，同时扩大了第二次世界大战的范围。当时，上海已被日军占领，只剩下英、法两块租界，还保持相对的特殊性。但随着战事的发展，日本军事上不断取得优势，敌伪对上海的控制也就越来越紧，上海人已很难看到一张说真话的报纸、听到一则报道国内外大事的广播。其实不仅上海，在我国所有沦陷区都无法知道国际形势和战争消息。

就在这样一种令人窒息的时候，1941年8月上海街头忽然出现了一份大开本的中文杂志，那就是《时代》周刊。它的出现立即吸引了广大市民的注意，仿佛久旱遇到了甘霖。《时代》周刊主要登载苏德战争的电讯、战地特写、通讯、军事述评和战争题材的文艺作品。《时代》的创刊，一方面使关心国事的上海市民精神振奋，仿佛在污浊的空气里吹进来一股清风，另一方面也使日本军国主义者及其盟友德国法西斯分子大为震怒，他们发现在他们所控制的地区里竟然公开传出反法西斯的声音，实在是难以容忍的。而《时代》的影响却不断扩大，在我国东南一带沦陷区和新四军地区都可以读到这本杂志。

《时代》是怎样创办的？原来在德国进攻苏联后，上海成了远东最大的宣传中心。日本利用敌伪报刊和电台大量散布他们的谎言，希特勒也在上海设立电台，出版他们的宣传品，如《远东画报》。面对这样的形势，姜椿芳同志作为地下党代表同塔斯社远东分社社长罗果夫商量，决定在上海出版一种中文报刊。原先想出日报，但因有困难，决定先出周刊。当时上海已有俄文的《时代》杂志，发行人是苏籍犹太人匝开莫。中文《时代》周刊就利用这个关系，也以“苏商”名义，而发行人仍用匝开莫的名字。

1941年12月7日，日本偷袭珍珠港，发动太平洋战争，“二战”形势起了变化，日军开进租界，上海环境进一步恶化。原来依靠英美势力出版的中文报刊全部被查封，但《时代》打着“苏商”招牌，日方无法公然禁止，因为苏日还有外交关系，日本也不愿苏联直接干涉日军在远东的军事行动。不过，日方对《时代》始终非常忌恨，千方百计想破坏它的出版。到了1943年春，敌伪借口外国人不能在中国出版中文刊物，想进一步控制《时代》。他们不敢公然查封《时代》，但作出规定，必须把全部中文稿送敌伪警察局审查后方能付印。为稿件内容，敌伪方面经常刁难，制造种种麻烦。他们把发行人匝开莫找去，姜椿芳就装做翻译陪同前去。敌人常严词训斥匝开莫，指责哪篇文章内容不妥，不准发表，匝开莫脾气急躁，再凭他的苏联国籍，毫不屈服。双方剑拔弩张，闹得十分紧张。这时，老姜总是格外冷静沉着，以他“翻译”的身份，和颜悦色地在一旁“劝和”，以打破僵局，最后达到稿件照登的目的。敌伪方面还认为“那个苏联人很坏，不讲道理”，“姜先生态度比较好”。他们不知道这种交涉，真正的“灵魂”不是匝开莫，而是姜椿芳。

1944年春，国际反法西斯斗争形势不断好转，日伪内心恐慌，正式下令禁止《时代》出版，但对《时代》工作人员并未中止盯梢、监视和迫害，而重点对象则是姜椿芳。

《时代》创刊时参加工作的只寥寥几人，当时上海懂俄文的中国人很少，而能从俄文翻译的更少。姜椿芳就要我替《时代》（后又加上《苏联文艺》月刊）译稿。当时我还在中学念书，俄语是课余私自跟一位俄国教师学的，虽也学了三年，但水平有限，这一点老姜是知道的，但由于俄文译者实在缺乏，我也就在他的一再鼓励下，大胆地开始在翻译上蹒跚学步。在我正式进《时代》工作之前，我只能利用晚间和星期日课余时间做些翻译。当时没想到从此我就走上翻译道路，而姜椿芳则是我走上翻译道路的领路人，也是我这辈子永远感激的良师益友。

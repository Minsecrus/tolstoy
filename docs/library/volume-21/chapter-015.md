# 苏联呼声电台和《每日战讯》

1941年苏德战争爆发后，塔斯社除了创办报刊外，还在上海设立了“苏联呼声电台”。苏联呼声电台用华语、俄语和英语几种语言广播，电台呼号是XRVN。当时广播电台呼号的第一个字母照例都用X，后面三个字母可以自己决定。苏联呼声电台为什么用XRVN？这一点，即使当时在电台工作的人也不一定知道。原来RVN是塔斯社社长罗果夫的姓、名和父名的第一个字母。

在孤岛上海，所有电台播出的除了为敌伪做宣传的谎言之外，就是歌颂“大东亚共荣圈”和麻痹人们斗志的靡靡之音。因此，苏联呼声电台的开播可说是给上海市民和附近沦陷区人民带来反法西斯斗争的真实消息，也传出健康的音乐和歌声。许多雄壮动听的苏联歌曲最先就是通过苏联呼声电台播放的。听众对苏联电台的反应十分热烈。为电台工作的，除了中国人和苏联人之外，还有从纳粹德国逃亡出来的犹太人和波兰人。国籍虽然不同，但大家有一个共同的目标，那就是反对法西斯主义。当时我也有部分时间在电台工作，翻译广播稿。记得有一位苏籍女广播员，精通英、法、俄几种语言。她能手里拿着一份英文稿直接用俄语念出来，不出一点差错。战后，联合国在上海和平饭店召开过一次小型会议，她就出色地担任了同声翻译的工作。电台负责音乐节目的是一位年轻的中国人，我记得他早晨来上班，常常嘴里咬着大饼油条，一边吃，一边拿出唱片来放。解放后，他去苏联学指挥，成了新中国最早的一名杰出指挥。他就是后来中央交响乐团团长李德伦同志。

除了《时代》周刊和苏联呼声电台之外，苏德战争期间上海还出过一张英文报纸《每日战讯》。每日一小张，在上海几条大马路设点免费赠阅。《每日战讯》主要刊登塔斯社的战讯，偶尔也有短篇述评，全都是有关反法西斯战争的，很受懂英语的市民特别是学生的欢迎。因为读者既可以知道战争消息，又可以把它当作英语补充资料，学到不少军事方面的词汇。我当时白天还在学校念书，每天总去拿一大叠《每日战讯》在同学中分送，有同学戏把它叫作《淡来黄牛丝》<sup class="footnote-ref" id="note-ref-12-1"><a href="#note-12" aria-label="查看本页注释 12">[12]</a></sup>，报纸一到，大家就纷纷吃起“黄牛丝”来。这也说明当年大家对时事十分关心。

《每日战讯》的主编是一位苏籍爱沙尼亚人，姓彼得斯，英语很好，是一位很风趣可爱的老人。说是主编，其实这张报纸的编辑、定稿、校对只有他一个人。报纸在武定路一家小印刷厂印刷出版。彼得斯的“编辑室”就在印刷厂楼上。我有时也到他的“编辑室”同他闲聊，他常常说说笑话。有一天，我走进他的房间，发现他神采飞扬，情绪特好。我问他什么事这样高兴。他边笑边说：“嘿，该死的法西斯分子，今天我可给他们一个好看了！”原来那天他在印刷厂门口看见有两个穿军服的意大利兵在马路上走，他就赶快跑到房子转角处去小便。当时上海成都路有个意大利兵营，里面住着为数不多的意大利兵，身上穿的都是法西斯军服，而武定路一带那时还很荒僻，很肮脏，随地小便是不稀奇的，因此彼得斯这一行动也不算太反常。彼得斯一面讲，一面大笑，笑得泪水都流出来。可见当年大家对法西斯分子是怀着怎样的仇恨和蔑视啊。

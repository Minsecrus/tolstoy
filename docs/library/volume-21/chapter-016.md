# 肖洛霍夫含恨焚稿

20世纪70年代初，勃列日涅夫对肖洛霍夫说：“你别往伤口上撒盐了。”肖洛霍夫听了回家就气愤地对家人说：“看来党不再需要我写战争与战前生活的小说了。”接着就把他最后一部长篇小说《他们为祖国而战》（其中部分章节曾发表）的手稿一把火烧掉了。<sup class="footnote-ref" id="note-ref-13-1"><a href="#note-13" aria-label="查看本页注释 13">[13]</a></sup>

《他们为祖国而战》早在1943至1944年在《真理报》和《红星报》上同时分章连载，后来又被搬上银幕。这部小说的部分章节发表后我曾把它译成中文。虽然没有读到全文，但在我的印象中，这部长篇仍表现了肖洛霍夫创作的一贯特色：以细腻的笔触描写普通人（这里是战士和下级军官）的日常生活（主要是战斗生活），他们的悲欢离合，他们的喜怒哀乐，真实，生动，又处处流露出对人的爱和对法西斯敌人的恨。也可以说通过战士平凡的战斗生活，深刻地反映出苏联人民在卫国战争中的大爱大恨。

1941年6月22日希特勒入侵苏联，肖洛霍夫立刻投入战斗，先后担任《真理报》和《红星报》记者，写了不少战地通讯和以战争为题材的短篇小说。其中1942年发表的《学会仇恨》一篇对培养苏联人民仇恨法西斯的感情起了特别重大的作用。当年我在翻译这篇小说时也觉得满腔悲愤，其中一个情节久久不能忘怀。作者写到一个女学生怎样被法西斯分子糟蹋后的景象：

她躺在被蹂躏的土豆茎上，一个小姑娘，简直还是个孩子呢，周围则狼藉着染血的练习簿和教科书……她的脸被军刀砍得血肉模糊，手里却紧握着一个打开的书包。我们拿雨衣盖住她的身体，默默地站在一旁。后来战士们都默默地走散了，可我仍站着，仿佛精神错乱，嘴里喃喃地念着：“巴尔科夫、巴洛文金编，自然地理，中学教科书。”这是我在草上看到的一本教科书。这本教科书我是熟识的。我的女儿也在念五年级。

肖洛霍夫自始至终参加了四年卫国战争，同战士们斗争在一起，他饱览了战争的残酷、人民的苦难，深深体会到人民的感情，更何况他自己也遭遇到家破人亡的悲剧。在前线，他曾几次遇险。有一次他乘坐的汽车遭到敌机扫射，一颗子弹从左边射过，离他只差二三十厘米。斯大林格勒战役期间，有一次他乘坐的飞机在着陆时坠毁，他幸免于死，但是受了重伤，脑震荡和内脏错位。再有，他的母亲就是当敌机轰炸他家乡维约申斯克镇时在家门口被炸死的。

肖洛霍夫就是这样通过亲身经历懂得了战争，并培养了对法西斯的深仇大恨。有了这样丰富的生活经历和刻骨铭心的感情，再加上杰出的艺术才华，肖洛霍夫创造出震撼人心的战争小说，赢得了千百万读者的心。因此，他作为一位有良心的老作家怎么也无法接受总书记对他的警告，以致含恨焚毁《他们为祖国而战》的全部手稿，这是一个多么可悲的情景啊！

肖洛霍夫在1965年获诺贝尔文学奖，在瑞典的颁奖仪式上说：“我作为一个作家，无论过去和现在都认为自己的天职在于，用我过去和将来的一切作品，向劳动的人民、建设的人民、英雄的人民表示敬意……我希望我的书，能够帮助人们变得更完美，心灵更纯洁，能够唤起对人的爱，唤起人们积极地为人道主义和人类的进步理想而斗争。如果我多少能做到这一点，我就是幸福的。”

肖洛霍夫确实如他自己所说是为人道主义和人类理想奋斗了一生。当然这并不是说他没有做过错事说过错话，他也曾参与批评过一些不该批评的作家，在几次大会上说过不该说的话。但他作为一个深受读者爱戴的作家，他的作品既反映了时代的真实，也表达了人民群众的感情。

但这样一位作家却遭到勃列日涅夫的无情训斥，怎能不叫他伤心至极，以致把宝贵的手稿付之一炬。

肖洛霍夫的焚稿，不禁使人想到勃列日涅夫的“创作活动”。勃列日涅夫从1964年掌权到1982年病故，前后掌权十八年。这十八年在当时的苏联被吹嘘为“发达的社会主义”，这位领导自然得意非凡，除了到处表现自己，还从事起了文艺活动。1978年他发表了一部长篇小说，由三个篇名组成：《小地》《复兴》和《生荒地》。这部百万字的“皇皇巨制”立刻被吹捧为天才之作，第二年就获得苏联最高文艺奖——列宁文艺奖，而且全国掀起一阵肉麻吹捧的文章，包括一部分惯于奉承拍马的作家，印数更达到了天文数字。苏联作家协会还发给勃列日涅夫作协第一号会员证，更是荒唐可笑。

勃列日涅夫不让肖洛霍夫创作和出版真正有价值的作品，自己则不择手段请人代笔写作。他自己没有动过笔，没有写过一张稿纸，真是一场空前荒唐的闹剧。难怪勃列日涅夫逝世后苏联有位评论家说：“这一文学事件本身，比起其他为了满足领导古怪要求而破费的大笔款项来，大概不算昂贵。但我认为公众意识和社会道德所蒙受的精神损失是巨大的。全民演出了一出荒诞可耻的戏，不论演员还是观众都并不信以为真。这大大加强了人们不关心政治和玩世不恭的消极风气，腐蚀了人们的思想和灵魂。”

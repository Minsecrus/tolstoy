# 登峰造极的艺术

1862年托尔斯泰同索菲娅·别尔斯结婚，当时托尔斯泰三十四岁，索菲娅十八岁。婚后，两人过了一段比较幸福的生活。这时，托尔斯泰的艺术才华开始充分发挥出来，他在19世纪60年代写出震惊世界的皇皇巨著《战争与和平》，19世纪70年代发表了又一部艺术杰作《安娜·卡列尼娜》。这两部作品奠定了托尔斯泰作为19世纪俄国文学顶峰的地位，赢得了世界亿万读者的热爱。

这两部作品是在怎样的历史背景和具体条件下创作的，托尔斯泰创作这两部小说的精神动力是什么，他创作的过程怎样，他的艺术才华怎样达到顶峰，作品发表后读者和文艺界的反应又怎样……这些都是热爱托尔斯泰作品的读者十分关心的问题。《托尔斯泰艺术才华的顶峰》一书通过翔实的材料、细致的分析，对这些问题都作了解答，使我们对这两部名著的产生经过和艺术成就有进一步的了解。

早在20世纪60年代初，托尔斯泰在创作了几个中短篇小说后，企图写长篇小说。起初他想写一部反映十二月党人的小说。1825年十二月党人为推翻沙皇专制统治起义失败而血洒广场的事件，在托尔斯泰心里始终无法摆脱。事情虽过去四十年，但还没有一位作家如实描写过这件事。托尔斯泰查阅大量史料和档案，深入思考这一重大历史事件，进行构思，但由于种种原因没能实现这一创作意图。

不久，他就转而想写一部反映1812年俄国抗击拿破仑入侵为题材的小说。他又遍阅有关历史资料、宫廷档案，想尽可能弄清当时的真实情况，作为创作长篇小说的依据。在查阅历史资料时，他发现史学家在叙述历史事件时，往往随意篡改历史，甚至吹牛撒谎，以达到不可告人的目的。但作家是艺术家，艺术家描写历史必须真实，不能随心所欲，昧着良心胡编乱造。再有，史学家总是把帝王将相、英雄豪杰作为历史的中心人物，竭力加以美化，肉麻地对之歌功颂德。托尔斯泰说：“在史学家看来，在达到某一目的上起促进作用的就是英雄；在艺术家看来，这种和生活各方面都一致的人物不可能也不应该是英雄，而应该是人。”

除了查阅史料外，托尔斯泰又同许多经历过这一年代的老人交谈，竭力掌握真实情况。于是19世纪初俄罗斯社会的全景图在作者头脑里渐渐形成而且越来越清晰，他对待各种人物的爱、憎也越来越分明。他要在一部长篇小说里宣泄胸中汹涌澎湃的感情，歌颂俄罗斯人民的勤劳勇敢，朴实善良，鞭挞达官贵人的昏庸专横，残忍伪善。经过五年的艰苦努力，终于创作出了一座有559个人物画像的艺术长廊，使全世界读者为之震惊。

在完成了《战争与和平》后，托尔斯泰又开始构思另一部长篇小说，那就是《安娜·卡列尼娜》。《安娜·卡列尼娜》写于1873—1877年，主要反映俄国历史大变动时期的社会情况和家庭生活。古老的俄国封建社会受到西欧资本主义浪潮的冲击，整个社会剧烈动荡，而在家庭生活方面尤其惊心动魄。托尔斯泰注意到俄国妇女在这一时期的遭遇特别悲惨，他对她们的不幸倾注满腔同情，决心用艺术手段来表现她们的痛苦。他创作《安娜·卡列尼娜》，在人物塑造上更加精雕细刻，在内心描写上更加入木三分。例如，安娜出走后日夜思念家里八岁的爱子谢辽查，好不容易鼓足勇气趁卡列宁不在时回去看望，还买了玩具带去，刚同儿子热烈拥抱欢叙母子之情时，不想卡列宁从外面回来，她惊惶失措，来不及同儿子话别，就夺门而逃，不想还是被卡列宁撞见，离家时过分慌张竟把带来的玩具又随手带了回去。这一情节着墨不多，但母亲爱子之情跃然纸上。

在安娜最后对人世绝望而决心卧轨自尽时，她坐在马车上思绪翻腾如波涛起伏，她一面眺望街道两旁的景象，一面回顾自己短促而悲惨的一生，往事一幕幕出现在她眼前，但画面不是静止不动的，不是前后连贯的，不是条理清晰的，而是断断续续、忽隐忽现、缺乏逻辑的。这种情绪充分反映一个走向绝路、面对死亡的女人的紧张而矛盾的心理状态。像这样激动人心的心理描写在文学史上是空前的。有人说，心理描写是俄国文学作品中的一大特色，例如普希金和其他俄国作家的小说也有细致的心理描写，但他们的心理描写往往是静止的，固定在某一特定的时刻，而托尔斯泰的心理描写不仅细致入微，而且是绵绵不断，写出一个人在特定环境特定时刻心理活动的全过程。这好像一集电影，出现的画面不是静止不动，而是一幅幅连续不断，使人在观赏时觉得更加生动逼真，扣人心弦。在这里，托尔斯泰的艺术才华确实达到了登峰造极的地步，不能不使人折服，叹为观止。

在创作这两部长篇杰作之间和之后，托尔斯泰还做了许多其他工作，如在乡村开办农民子弟学校，亲自编写出版《启蒙课本》《新启蒙课本》，发表《论国民教育》一文，上军事法庭替殴打军官而被处死刑的士兵希蒲宁辩护（虽然希蒲宁还是被枪决，但这事在托尔斯泰心里刻下难以愈合的创伤，直到四十年后还使他感到疼痛和愤慨）等等。此外，托尔斯泰从青年时代起就不断探索生命的意义，他在哲学、知识、科学、宗教等领域多方面进行探索，他在艺术作品中也探索这些问题，发表哲理性的思考。因此，可以清楚地看出，不论在小说里还是其他论著中，托尔斯泰那颗热爱人民特别是苦难人民的心总是在剧烈跳动，难怪他自己说他在写作时总是把一块肉留在墨水缸里。

读《托尔斯泰艺术才华的顶峰》一书，我们可以清楚地看出托尔斯泰在这一时期的多方面活动，作者古谢夫是俄国研究托尔斯泰的著名专家，中译者秦得儒教授也长期研究托尔斯泰，熟悉托翁创作，他的译文更是忠实流畅。我相信，本书在中国出版，对热爱托尔斯泰作品的中国读者来说，是一件值得庆幸的事。

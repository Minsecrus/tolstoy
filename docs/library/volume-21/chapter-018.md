# 学习鲁迅

国内首次出版《鲁迅全集》，是在抗战初期，《全集》共二十卷，定价二十元，但预订只收八元钱。我当时在中学读书，这种书价，勉强还能承受。

《鲁迅全集》出版后，我就反复读，并在同学间传阅。任溶溶是我的同学，我们当时是十四五岁的青少年，对鲁迅的感情非常深。《鲁迅全集》共二十卷，前十卷是鲁迅的创作，后十卷是他的翻译。从数量看，鲁迅把一半时间花在创作上，把另一半时间花在翻译上。可以说，我读俄文、英文，走上了从事翻译工作的道路，是受了鲁迅的影响。我以为，鲁迅是中国20世纪最伟大的文化巨人。他无论涉及哪一个领域，都有非常明确的指导思想。其目的就是改变中国社会的现状，改变中国人的命运。他写“祥林嫂”，其中心思想是反封建。他深刻地揭露了封建社会“吃人”的本质。鲁迅身体不好，时间又紧，但他还是翻译了俄罗斯、日本及东欧一些弱小民族的作品。这些地方的人民也饱受封建专制的奴役，其遭遇和中国人民相似。鲁迅从事翻译工作，是借“他山之石”来鼓起中国民众反封建的勇气，并使知识分子扩大眼界，提高创作水平，借此来达到提高整个国民素质的目的。

鲁迅从事翻译工作开始于“五四”时期，他同时还鼓励年轻人从事翻译工作，像冯雪峰等，都受到了鲁迅的影响。应该说，从“五四”时期以鲁迅为首的作家开始较多介绍外国文学以来，中国读者能看到不少外国文学作品。这和鲁迅当年的大力提倡是分不开的。鲁迅逝世于1936年10月，他没有看到抗日战争以后及至现代社会的情况，但他站得高、看得远，深刻地认识到反封建、倡民主，提高国民素质的重要性。

我们今天纪念鲁迅，深感责任重大。就翻译界的情况而言，译介工作还远远不能满足读者的要求。翻译界还是以老为主，中青年的中坚力量很不够。一些大学生，学好了外语到中外合资企业去赚大钱，真正甘于寂寞来从事翻译工作的，真是凤毛麟角。有些大学生中外文基础都很好，但他们的工作条件、生活条件都没有得到落实，无法从事他们心爱的工作，这是值得大家深思的问题。

再说从事翻译的稿酬实在太低，而且过了五六年不变，这是很不合理的。翻译这个非常重要的宣传阵地，还没有得到有关部门的重视，对培养人，那就更欠缺了。中国的出版事业近年来有明显的成绩，但细加分析，书籍的外观很美，但书的质量还有待进一步的提高。值此纪念鲁迅逝世六十周年之际，说说自己的感想。

# 我读些什么书

一个人一生能读多少书？海外有位学者说：“大约两千本。”他指的是中等字数的书。我想了想，觉得不是完全没有道理。一个人一生读书的时间就算是五十年吧，每年若读四十本，就有两千本，一年五十二周，每周若读一本书，应能读五十二本，但一年中难免因病因事无法读书，扣去十二周，少读十二本，剩下的就是四十本。这是指智力一般、精力中等而又工作的人而言，智力和精力过人而又有大量时间读书的人，当然不在此例。

现在，图书馆藏书数以百万计，爱书的人个人藏书往往也不止两千。生命有限，书海无边，选什么书读，确是一大学问。当然，人各有志，行当不同，兴趣各异，读书也只能因人而异，不可能定出一份标准书目，强求一律。

那么，我怎样选择书呢？没有什么标准，但大致有三个方面：第一，好书；第二，工作上需要读的书；第三，调剂精神的书。

先说好书。什么是好书？我认为书不是时装，不是皮鞋，不用一味研究今年流行什么款式，时兴什么色彩。当然，了解一些新思潮，知道一些新观念，也是必要的，但不必刻意求新，更不能拿“时代新潮流”作为读书的标准。书是人类知识的结晶，书是文化积累的成果。任何门类的书都要经过广大读者的鉴定，都要通过历史长河的考验。“优胜劣败”、“自然淘汰”这一规律我看也适用于图书。因此，所谓好书，我主要指经过时间和读者考验得到公认的第一流作品。读一本好书，同读一本平庸的书，所花的时间、精力相同，而得益却大不相同。精神食粮同物质食粮一样，贵在精而不在多。你从一本好书中得到的益处，就远远超过一本平庸的书。因此我的原则是少而精，好书不妨多读几遍，尽量多从中吸收养料。至于从事新闻、编辑和其他工作的“杂家”，自然另当别论。

第二，工作上需要读的书。我从事文学翻译，为了做好工作不得不读些有关的书。例如，为了更好地领会原作精神，就得多读些有关原作者和作品的图书资料。又如，目前我在译19世纪小说，为了弄清书中涉及的历史事件，不得不找有关的书来读。总之，要译好一部书，非读不少书不可。

第三，调剂精神的书。工作之余，除了运动和听音乐之外，我也翻阅各种报刊和轻松的书，主要是古代诗词和旅游笔记之类。但因整天伏案同中外文打交道，平时一天下来（有会议和其他活动除外），常常头昏眼花，无法再继续阅读，而面对琳琅满目的中外图书，只能望书兴叹，深感心有余而力（目力）不足了。

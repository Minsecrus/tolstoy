# 堂堂正正做人，认认真真翻译

——许钧<sup class="footnote-ref" id="note-ref-14-1"><a href="#note-14" aria-label="查看本页注释 14">[14]</a></sup>·草婴对谈录

许钧：草婴先生，您是我国著名的俄苏文学翻译家。无论就思想观念而言，还是就文学观念而言，您翻译的作品在解放后都起到过相当大的影响。您是从1938年开始学习俄语的，同时参加了新文字研究会。如果从为《时代》杂志、《苏联文艺》译稿开始算起，您从事翻译已经有六十年的历史了。在这漫长的文学翻译生涯中，您积累了丰富的翻译经验。我想请先生给广大读者介绍一下，您翻译过哪些主要作品？现在是不是还在翻译？

草婴：我从1938年开始学习俄语，1941年苏德战争爆发后上海创办《时代》杂志，我从创刊号起就在课余为它翻译有关苏德战争的通讯、特写等，接着又为《苏联文艺》翻译短篇小说。1945年苏德战争结束后，我正式参加时代社任编译。20世纪50年代起作为专业会员参加作家协会，专门从事文学翻译，译了一些苏联小说，主要是肖洛霍夫的小说《新垦地》第一部和第二部《顿河故事》《一个人的遭遇》等，还译过尼古拉耶娃的小说《拖拉机站站长和总农艺师》。20世纪60年代起开始翻译古典作品，主要是托尔斯泰的小说，至今已翻译出版《托尔斯泰小说系列》十二卷，包括三个长篇《战争与和平》《安娜·卡列尼娜》《复活》，中短篇小说四卷：《一个地主的早晨》《哥萨克》《克鲁采奏鸣曲》《哈吉穆拉特》和自传体小说《童年·少年·青年》，还有莱蒙托夫的小说《当代英雄》。现在主要修订旧译，也译些短篇。

许钧：就我所知，您是国内为数不多的专门从事文学翻译的翻译家，国内翻译界，大多数人是业余从事翻译工作。翻译外国文学作品，首先有个选择问题。在不同时代，不同的政治、文化、社会氛围中，一个人选择翻译的作品，可能会不同。先生翻译的这些作品，都是自己选择的吗？有哪些方面的原因，促使您选择或接受了这些作品的翻译？

草婴：我从事翻译工作最初是为了参加反法西斯斗争，想通过翻译让读者了解反法西斯斗争的真实情况，从而增加中国人民对抗日战争胜利的信心。其次，我一向喜爱俄苏文学，因此也想通过翻译让中国读者欣赏到一些好的文学作品，丰富大家的精神食粮。我之所以介绍肖洛霍夫的作品，是因为我认为在苏联作家中，肖洛霍夫是继承19世纪俄国现实主义文学传统很出色的一个，尤其是继承托尔斯泰的传统，发扬他的人道主义精神。当然，肖洛霍夫所处的时代不是托尔斯泰所处的时代，他有他的局限性，我们不能脱离具体社会条件去要求一位作家，同样也不能这样去要求肖洛霍夫。不过，在同时代的苏联作家中肖洛霍夫是较有胆识的，敢于在作品中尽可能反映生活的真实，较少受教条主义的影响。

许钧：是的，肖洛霍夫是苏联作家中影响最大的一位。我看过一个材料，说截至1980年1月，他的作品用苏联各民族的54种语言和30多种外国语言出版了974次，总印数达7900万册。他的主要作品在中国都有译本，有的还不止一个译本。不同的译家对有的作品还有不同的译名。

草婴：解放后，在20世纪50年代，我首先读到苏联作家尼古拉耶娃的小说《拖拉机站站长和总农艺师》，觉得这部作品在关心群众疾苦、反对官僚主义方面对我们有借鉴作用，就把它翻译出来。译文发表后引起读者的热烈反应，当时还受到胡耀邦同志任第一书记的团中央的重视，先是在《中国青年》上转载，并号召全国青年向女主角娜斯嘉学习，但没想到在不久后开展的反右斗争中，这本书被当作毒草，并有几位作家因此受到牵累。我始终认为这本书值得介绍，娜斯嘉精神不论何时何地都应该提倡。

许钧：在解放后的一段时间里，我国外国文学翻译工作有一个宗旨，叫做“为革命服务，为创作服务”。苏联和有关社会主义国家的文学的翻译介绍工作受到特别的重视。先生对翻译作品的选择，如您自己所说，差不多就是根据这双重的标准，一是政治的标准，二是艺术的标准。若两者统一，翻译就会受到支持与鼓励。若不符合政治标准，艺术性再强，也难出版。政治标准是第一位的。您为了翻译外国文学作品，在“文化大革命”中，听说还成了批斗的重点对象，吃了不少苦。这在今天看来，特别对一些年轻的翻译工作者来说，是难以想象的。

草婴：是的。在“文化大革命”中，我因翻译肖洛霍夫作品成为重点批斗对象，主要因为江青认定肖洛霍夫是“苏修文艺鼻祖”，我就成了他在中国的吹鼓手、代理人，全家都受冲击，我也两次处于生死边缘，好不容易挺了过来，但我始终不承认我在这件事上犯了罪。

我翻译托尔斯泰作品始于20世纪60年代初，曾出版《高加索故事》，后因“文革”受阻。“文革”后我花了二十年时间，向中国读者较系统地介绍他的作品。我特别重视他的作品，主要是因为他宣扬人道主义思想。我觉得人类发展到今天，除了物质上高度发展外，更需要推广人道主义思想，而在东方，由于长期的封建统治和愚民政策，对“人”的不尊重情况尤其严重，种种愚昧、落后、野蛮的行为都是由于不尊重人的基本权利，不把人看作是世界的主人。此外，托尔斯泰作品的艺术魅力也是我重点介绍的一个原因。

因此，可以说我翻译的选题都是由我自己决定的，但在“文革”中我和其他几位翻译家也曾被迫翻译过一些由工宣队派定的小说，如《人世间》《现代人》《你到底要什么？》《落角》等。

许钧：去年，我为《中华译学丛书》主编了一部书，叫《翻译思考录》，其中有的文章谈到了影响或决定翻译活动的诸要素，您谈的这些问题对深入研究很有价值。在书中，还有江苏作家张国擎写的一篇谈翻译的文章，他对翻译家的功绩给予相当高的评价，其中还特别提到了您。先生在六十年的翻译实践中，对翻译有着自己明确的追求，虽然在“文革”中译了一些工宣队分派的作品，但总的来说，您所翻译的，都是自己喜爱的作品。这一点，看来非常重要。要翻译好一部作品，首先要喜欢它，要有一种强烈的兴趣和驱动力。我读过先生翻译的不少作品，发现前期的译作与后来的译作有一些微小的差异，特别在句法上，前期的比较谨饬，后来的比较灵活。有的人说草婴先生的译文有自己的风格。您对这种说法怎么看？另外，我想知道，先生有没有自己的翻译标准和原则？

草婴：在几十年的翻译实践中，我不能说已经形成了自己的风格，但对自己的要求还是有的。我觉得翻译家首先应该明确自己的地位和作用，一个文学翻译家是原作者和译文读者之间的桥梁，他必须时时想到原著作者和译文读者，始终对两者负责。翻译家在翻译之前首先要认真阅读原著，同时考虑两点：第一，这部作品是不是值得翻译；第二，这部作品是不是适合我翻译。在决定翻译之后，就应反复阅读原著，使作品里的形象渐渐在译者头脑里浮现出来，同时培养对其中人物的感情。一部作品的成败首先要看作家对他所塑造的人物有没有真情实感。一个作家如果对他所塑造的人物没有感情，他就不可能创作出一部好作品。同样，一个文学翻译家如果对他所翻译作品中的人物没有感情，也不可能翻译好一部作品。道理很简单，文学创作是一种艺术工作，而任何艺术都离不开艺术家的思想感情。文学翻译也是一种艺术工作，只不过这种工作不能离开原作，因此是一种艺术再创作。钢琴家演奏是作曲艺术的再创作，还有导演和乐队指挥都是艺术再创作。至于文学翻译的标准，各人有各人的说法。我则认为一部好的文学翻译作品应该是译文读者读后的感受相当于原文读者读后的感受。当然，要达到这个要求并不容易，这里有时代背景的差异，有不同民族风俗习惯的差异，还有不同语文本身的特点。翻译家要适当处理这些问题，确实要花一番功夫，使译文读者也能尽量欣赏到原著的艺术魅力。

至于我翻译的作品，当然有我的追求。就风格而言，我想应该切近原作的风格。我从事翻译也有从不成熟到比较成熟的过程。翻译的艺术追求是没有止境的。

许钧：先生刚才谈到文化、风俗、语言的差异对翻译造成的障碍，还有时代背景的问题。这在翻译中确实需要认真下功夫解决。可以说，这也是翻译需要解决的主要任务。德国的本雅明写过一篇文章，叫《翻译家的任务》，其中就谈到，所有的翻译都必然要面对出发语中的各种异质因素，如何处理这些因素，需要细加研究。不能视而不见，也不能有意回避，更不能随意“归化”。先生翻译过俄国和苏联许多的作品，如托尔斯泰、莱蒙托夫、肖洛霍夫的作品，这些作家都有自己的创作个性，在风格上都有追求，先生在翻译时，是怎样尽可能传达他们的风格的呢？

草婴：我认为凡是好的作家都有自己的风格，这种风格是他长时期生活和写作逐渐形成的，我们读名家的文章都会清楚地感觉到他独特的风格，而不会跟其他作家混淆。文学翻译的风格要复杂些，因为它既有原著作家的风格，又有文学翻译家的风格，可以说是两者加起来形成的风格。原著作家的风格只有一个，但文学翻译家十个就有十种风格，因此一种原著，尤其是名著，应该容许有不止一个译者来译，让读者自由选择他所喜爱的译本。文学译本不同于科技译本，不可能有一种标准的译本。不过，我这样说并不是支持那种单纯以追求利润为目的的翻译，更不要说那种利用现成译本东抄一句、西抄一句的“翻译”了。至于翻译家确定他的翻译选题，应考虑他自己的风格比较适宜翻译哪些作家的作品。就我自己来说，比较喜欢朴素自然的作品，不太欣赏辞藻华丽的文章。因此我不翻译那种不合我自己口味的作品，也就是我自认为译不好的作品。至于如何传达原作者的风格，我想这是一个十分复杂的问题。我还是强调理解与领悟，这是传达的前提。只有理解领悟了原作的风格，才能想办法传达，而正确传达原作的风格是翻译家首要的任务。

许钧：先生强调要翻译合自己口味的作品，这非常重要。我想，只要选择了合自己兴趣和口味的作品，译家与原作家兴趣相近，气味相投，恐怕对传达原作的风格就有一种保证。语言的差异会给传达风格带来困难，但一个好的翻译家，具有语言的艺术造诣，一旦受到原作的触发，就有可能尽情发挥出来，在贴近原作的同时，达到与原作风格的一种融合。我不懂俄语，但读先生的译作，不同作家在您的笔下还是有区别的。能不能请先生谈一谈，在漫长的翻译生涯中，您体会到文学翻译成功的关键是什么？许多翻译家都说翻译难，甚至比创作还难，您觉得主要有哪些困难？如何克服？

草婴：我做了一辈子翻译，并不觉得自己有什么成功的经验。我平生只追求一点，那就是：“堂堂正正做人，认认真真做事。”做翻译工作也是这样。至于困难确实是有的，我常常感到自己的中文水平不够，翻译表达时不能得心应手，运用自如；我的外文水平也不够，翻译时较多使用各种工具书，花的时间也就多了；此外，我的知识面不广，文学素养不足，都是造成翻译上困难的原因。但我相信勤能补拙，只要不怕麻烦，不惜多花功夫，总能克服各种困难，做好自己的工作。

许钧：看来先生特别强调译者本身的素养。首先是态度要认真。除了翻译活动本身的局限以外，翻译的困难是相对的，只要译者本身有较高的艺术修养和中外文的良好条件，不断修炼，翻译的困难可以成为译家的用武之地。这是辩证的看法。先生谈的几点，语言非常朴素，但道理很深刻。关于具体作品的翻译，我想就《安娜·卡列尼娜》的翻译提几个问题。托尔斯泰谈到《安娜·卡列尼娜》的创作时说到：“饭后我独自躺在这张沙发上，吸着烟……我不知道我是在竭力思索呢还是在与瞌睡作斗争，突然有一条非常漂亮的贵妇人的光胳膊在我面前掠过，我不由得仔细看看这个幻影。接着出现了肩膀、脖子，最后是一个美丽的女人的形象，她身穿白衣裳。她那双含怨带恨的眼睛看着我。为了摆脱它，我必须给它找个化身。这就是写作《安娜·卡列尼娜》的起因。”当然这并不是托尔斯泰创作《安娜·卡列尼娜》的唯一动机，但是，这个幻想的出现，对托尔斯泰的创作无疑具有重大作用。在翻译过程中，“这个幻影”对您产生过实际的影响吗？

草婴：我在翻译时总是尽量领会原作者在创作时的思想感情，以便较好地在译文中加以表达，对于《安娜·卡列尼娜》也是这样。托尔斯泰在塑造安娜时，是倾注满腔热情的，他不仅赞美安娜的外貌，而且充分展示安娜的内心世界。他对安娜的不幸遭遇始终掩盖不住真挚的同情，而对造成她一生痛苦的贵族社会和以卡列宁为代表的官僚体制则怀着无法克制的仇恨。正是出于这种大爱大恨，托尔斯泰创作了这部震撼人心的艺术杰作。我在翻译时竭力领会托尔斯泰的这种思想感情，并尽可能完善地把它表达出来。

许钧：托尔斯泰特别注重人物形象，特别是神态、容貌的描写，您在《安娜·卡列尼娜》译本序中作了分析。比如作者通过笔下不同人物的眼睛来精心塑造安娜，通过伏伦斯基、吉娣、陶丽和列文的眼睛，充分展现安娜，把她塑造成了世界文学中一个不朽的形象。我不懂原文，但读了您的译文，安娜的形象栩栩如生，尤其是安娜热恋伏伦斯基时的神态的描写，让人读了难以忘怀。就像您在译本序中所写的——“双颊和下巴分明的酒窝，嘴唇的优美线条，荡漾在整个脸上的笑意，眼睛里闪烁的光芒，动作的优美和灵活，说话声音的甜美和圆润，回答人时半是嗔怪半是撒娇的媚态，”——跃然纸上，令人神魂颠倒。凭我的感觉，翻译应该是很传神的，这凝聚了先生再创造时所付出的心血。我想请先生谈一谈，您在再现原作人物的形象时有没有遇到特别的困难？您是如何尽量给予传达的？

草婴：人物形象是文学作品的灵魂。作家的水平主要看他塑造人物的能力，翻译家的水平在很大程度上也要看他用另一种语言重新塑造人物的能力。托尔斯泰是塑造人物形象的大师，他的长篇小说更是色彩斑斓、栩栩如生的人物形象的画廊。我在翻译他的作品时着眼点也是怎样较完善地传达他的人物形象，但限于自己的水平，并不总能尽如人意。这也是困难之处。不过我在翻译过程中总是竭力使人物形象在头脑中浮现出来，然后考虑怎样使之在译文中尽可能清晰地再现，使译文读者也能较好地看到这些形象。

许钧：这就是翻译中的形象思维。看来，翻译与创作一样，特别在文学翻译中，要有形象思维。有的年轻译者忽视了这一点，只是在文字的层面去求忠实与等值，忽视了形象的再现要有形象思维才能实现。看得出，先生在翻译这部作品时，对人物是倾注了自己的感情的。不过，在人物形象的再创造时，您的审美观、道德观和意识形态方面的因素对您选择词汇，特别是词汇的褒贬等感情色彩的把握上，是不是有实际的影响？

草婴：我在翻译一部作品时比较注意作品所表达的感情色彩。如果作者的思想感情我很难理会或者我并不赞同，我是不愿翻译他的作品的。至于翻译选择词汇，我也努力注意保存作者的原意，当然在遣词造句上也会遇到困难，但这是翻译家在工作中必须克服的困难，没有什么取巧的办法。

许钧：翻译一部外国文学作品是一个再创造的过程。先生谈到了文学翻译对译者的素质的要求，谈到了文学翻译中形象思维的问题，特别强调了翻译中所遇到的困难。目前，我国又出现了新的翻译高潮。由于翻译任务多，好的译家忙不过来，许多年轻译者也就有了翻译的机会。我发现一个问题，在高校学外国文学的研究生中，很多都接受了翻译任务。他们学习任务重，加之翻译的基本素质又有些欠缺，有的翻译质量确实不高。这里有客观的原因，但不能否认有的青年译者对翻译的困难认识不够，把它看得过分容易，也缺乏严肃的态度和精益求精的精神。听说有的抓过一部书就译，译的速度快得惊人。我想请先生具体谈一谈翻译一部文学作品的实际过程。有哪些主要环节？

草婴：我翻译一部作品一般要经过三个步骤：第一步是熟悉原作，也就是反复阅读原作，读懂原作，考虑怎样较好地表达原意，通过几次阅读，使人物形象在头脑里逐渐清晰起来。第二步是动笔翻译，也就是忠实地逐字逐句把原著译成中文。第三步是先仔细读译文，看有没有脱漏、误解的地方，逐一加以更正；然后再从中文角度来审阅译稿，务使中文流畅易读，有时也请演员朋友帮我朗读译稿，改正拗口的地方；在交编辑审读后，再根据编辑所提的意见，认真考虑，作必要的修改。在校样出来后，我也坚持要自己至少通读一遍。这就是翻译的过程和主要环节。

许钧：先生说的这些经验非常珍贵。最后，我想再请教先生，作为资深的翻译家、上海文学翻译家协会会长，您对目前我国文学翻译的状况有何评价？对年轻文学翻译工作者有什么希望和要求？

草婴：对目前我国文学翻译的状况，我是忧多于喜。我们处于改革开放的时代，许多事情都需要造就新的形势，而翻译工作在今天尤其重要。但遗憾的是有关方面对这项工作还没有足够的重视，对文学翻译的意义和作用也缺乏应有的认识。作为翻译家，我常常感到焦虑，但除了在各种不同场合进行呼吁之外，也没有其他办法。《译林》能关心这个问题，并开辟《翻译漫谈》，我认为是一件好事，希望这个专栏能越办越好，对促进和繁荣文学翻译事业起更大的作用。

# 附录：文化积累和傻子精神

——从《战争与和平》新译本谈起

王西彦

正当人们为目前文化沙漠化现象继续扩大而忧心忡忡时，我却想起了一个文化积累的问题。

中国是一个文明古国，有长达数千年之久的文化历史即文化积累，真正可以说是源远流长。从先秦到明、清，单就哲学思想的发展而论，每个时代都各具特色，内容异常丰富复杂；先秦时代“百家争鸣”的蓬勃气象，尤其令人神往。而哲学思想的发展，又不可避免地影响甚至决定文学的发展，因为每一个诗人作家，都要接受当时哲学思想的熏陶，并表现在他们的作品里。从这种地方，可以看出文化传统或文化积累在历史上的作用。而这种文化传统或文化积累，更包括演变过程中所融入的外来思潮的影响。早在秦、汉时期，中外就存在文化交流，东亚方面为朝鲜和日本，中、西亚方面则有阿富汗、伊朗、土耳其、伊拉克等国，汉武帝时张骞两次出使西域，更是为人所共知的历史事实。印度的佛教，西汉时已传入中国，至隋唐而特盛，有的哲学发展史上辟有“佛学时代”的专章，论述外来的佛学如何和儒、道两家的学说互相渗透融合。这种情况，愈到后来就日益明显。

对文化的兴盛和积累，起决定作用的自然是时代和社会条件。以文学发展的历程来说，从先秦的诗经和楚辞，到汉赋、唐诗、宋词、元曲，以至明清小说，每一种体裁的兴起和诗人作家的产生，都可以从时代和社会条件得到解释。但不容忽视的是，这中间还有个人努力的因素。只要读过《报任安书》，就可以知道司马迁那部被鲁迅称之为“史家之绝唱，无韵之《离骚》”的巨著《史记》，决不是偶然的产物。我们读唐诗时，经常可以从那些被后人推崇为大诗人的作品中，看到例如“文章千古事，得失寸心知”、“读书破万卷，下笔如有神”、“为人性僻耽佳句，语不惊人死不休”（杜甫）、“两句三年得，一吟泪双流”（贾岛）、“鬓白只应秋炼句，眼昏多为夜读书”（杜荀鹤）、“吟安一个字，捻断数茎须”（卢延让）之类句子，说明那些流传千古的名篇佳作，都是心血所化，实在来之不易。再看作品的数量，一部《全唐诗》中所保存的，就十分可观。至于后出的小说巨著《红楼梦》，它是作者曹雪芹忍受“茅椽蓬牖，瓦灶绳床”的清贫生活，以“披阅十载，增删五次”的艰辛努力写出来的，真是所谓“字字看来都是血，十年辛苦不寻常”。

历代文学前辈们这种对待写作的虔诚态度，我把它称之为“傻子精神”。

“五四”新文化运动的两个主要口号“德先生”（民主）与“赛先生”（科学），都是在外来思想的冲击之下形成的。产生于“五四”时期的新文学，被称为“开山祖”的鲁迅曾一再提到他所接受的外来影响。他从1815年5月起陆续写出了《狂人日记》《孔乙己》和《药》等小说作品，被当时认为“表现的深切和格式的特别”而激动了青年读者的心；鲁迅指出，“这激动却是向来怠慢了绍介欧洲大陆文学的缘故”，因为“1883年顷，俄国的果戈理就已经写了《狂人日记》，1883年顷，尼采也早借了苏鲁支的嘴，说过‘你们已经走了从虫豸到人的路，在你们眼里面还有许多份是虫豸。你们做过猴子，到了现在，人还尤其猴子，无论比那一个猴子’的。而且《药》的收束，也分明的留着安特莱夫式的阴冷”。他还说到自己的写起小说来，“大约所仰仗的全在先前看过的百来篇外国作品和一点医学上的知识，此外的准备，一点也没有”。他更说到在中国“小说家的侵入文坛，仅是开始‘文学革命’运动，即1917年以来的事，自然，一方面是由于社会的要求，一方面则是受了西洋文学的影响”。很明显，在鲁迅看来，不仅被人轻视的小说家侵入文坛是受了西洋文学的影响，他自己的小说作品更是在此种影响下产生的。这种情形，十分雄辩地证明了文化发展和文学演变，都和外来思潮有着密切关系。

其实，就作家接受外来影响而论，何止是鲁迅呢。鲁迅以后的现代重要作家，可以说几乎没有例外。这有作品本身和作家的自白作证明。由于种种原因，给予中国作家以最大最深影响的是19世纪俄罗斯诸现实主义大师，如果戈理、屠格涅夫、陀思妥耶夫斯基、托尔斯泰和契诃夫等。事实上，这些大师们的名著也介绍得最多，最为中国读者所熟悉，其中特别是列夫·托尔斯泰。这不仅由于托尔斯泰的不朽名著《战争与和平》《安娜·卡列尼娜》和《复活》的艺术力量，也由于他对中国古典哲学的关心和所引起的共鸣，他的伦理思想和中国古典哲学有着颇为密切的联系，例如他的“勿以暴力抗恶”的主张和老子“不争而善胜”的信念，他的“道德自我完善”的原则和孔孟“修身”的精神，都有某种一致性。他的作品给予中国现代作家的巨大影响，自然也和这种情形不无关系，因为他不但是以伟大作家的身份，同时又以虔诚的道德家的身份出现在中国读者眼前的。

早在20世纪初，“五四”新文化运动以前，中国就有多种托尔斯泰作品的译文，如《复活》（《心狱》）和《安娜·卡列尼娜》（《婀娜小史》）等。随后又有了一些介绍评论文章。《战争与和平》可能因篇幅浩瀚，中译出现得较晚。其实，它可以说是托尔斯泰最重要的作品，在这部巨著里，他倾注了自己几乎全部的生活经验和人生感受。每次读完它，总要使我联想起托尔斯泰同时代作家柯罗连科的一段话。1908年托尔斯泰八十大寿时，柯罗连科写了一篇祝贺文章，大力赞扬托尔斯泰在创作范围和艺术视野上的宏伟：“托尔斯泰的艺术范围不是一条小径，不是一条林间通路，不是一条阳关大道，而是一片辽阔广大的视野，无边无际地展开在我们面前，上面有一条条蜿蜒的河流，一簇簇树林和远方的一个个村落。你走近任何一个地方，都会听见人群中嘈杂而生动的谈话声。再走近些，你就会在其中看到一个个的人物。而所有这一切，都各自过着充实的、真正的生活——生气蓬勃，别开生面，丰富多彩。”接着，他以左拉的《崩溃》和《战争与和平》作比较：“左拉在《崩溃》里处理着和托尔斯泰在《战争与和平》里同样的主题，然而你试把他所描述的情景和托尔斯泰所描述的情景比较一下。就以队伍的行进为例吧。在左拉的描写中，这是一些‘作战单位’。你看到它们，听到它们行进的声音，观察到它们在总的冲突中的行动。然而这些毕竟是集体单位，它们仿佛是一个个团块在平面上移动。你充其量不过在其中看出一个主要人物和接近小说的基本线索的个别团体。但在托尔斯泰的描写中，受检阅的或赴战的部队却不是一个集体单位，而是具有一个个生命的一大群人麇集在一起。在你面前常常出现许多生动的人物：将军、军官、士兵，各人具有自己的特点，怀着这一瞬间各自偶然产生的感受，而在这可惊的运动过去并消失之后，你还能回味到在全体群众中喧噪而过的这一批有生命的人。”我也不能忘记托尔斯泰的英国友人艾尔默·莫德在他的《托尔斯泰传》中对《战争与和平》的评价，他认为这部巨著所以能够激荡每一个读者，“是它形式的明晰和色彩的生动。仿佛它所描写的，人们看得见；它所发出的声音，人们听得见。作者从不用自己的口吻来说话；他把人物带到台口上，让他们自己谈话，感受，行动；他们所做的是这样地真实，每一个动作都惊人地准确，正合乎每一个人物的个性。我们仿佛面对了真人一样，我们看见他们还比我们在现实生活中所能看见的更清楚。我们不仅能够分别每一个人物的语言和感情，而且能够分别他们的神情，他们惯做的姿势和走路的模样。”至于这部巨著的主要主题，“如果我们可以从它的许多潜在的主题中挑选一个出来的话，那么，还是托尔斯泰最心爱的那个主题：什么是善？什么是恶？什么我们应该同情？什么我们应该排斥？”因此，“这部书探讨人生最深刻的经历，从摇篮起，到坟墓止；仔细阅读这部书，我们就会比从前更好地了解人生，更清楚也更严肃地观察人生。”我想，我们每一个《战争与和平》的读者，都能从上面所摘引的两位托尔斯泰同时代人的颂扬和评论里获得启发。就我自己在阅读这部巨著时的感受来说，作品一开始，从彼得堡女官安娜·舍勒家的晚会写起，一下子就是几十位人物纷纷登场，然后更是几条线索交错发展，各种矛盾纷纭杂呈，战争场面与和平生活相互出现，时间从1805年到十二月党人运动的酝酿，空间从俄罗斯到西欧，场景从首都到外省，人物从帝皇到士兵，真是包罗万象，气势磅礴，不禁叹为观止。的确，《战争与和平》不愧是世界文学历史上一个伟大的奇迹，一座辉煌的丰碑。

可是，尽管20世纪初就开始介绍托尔斯泰，他的这部稀世巨著，不仅较晚才出现中文译本，而且在很长时期里，读者所能读到的只是一两个从英译转译的或者虽译自俄文原著却还不能算十分完善的本子。这不能不说是一种遗憾。对我这个托尔斯泰的崇仰者来说，一部直接从俄文原著译出的更为完美的中译本，一直是十分殷切的期望。关于文学作品的翻译，诗人歌德在他和秘书爱克曼的谈话录里，曾经提到年轻人如果学好了德文，就能够通过德文翻译读到外国作品：“不可否认，依靠一种很好的译文，一般可以学习到很多东西。弗里德里希大帝不懂拉丁文，可是他根据法文译本读西赛罗，并不比我们根据原文阅读来得差。”但重要的是，能够使读者获益的，应该是“很好的译文”，它要求译者精通原文，更善于表达原著的精神风貌，运用适合当代读者口味的语言，所以有人认为翻译是一种艰辛的再创造。

满足我这托尔斯泰热心读者的殷切期望的，是不久前出版问世的《战争与和平》的新译本。因为怀着一种有如大旱之望云霓似的心情，我贪婪地读了四大卷还留有油墨香味的译本，满怀喜悦地告诉自己道：“洋洋四大卷，近一百二十万字！译好它不容易！确实不容易！”

我说“不容易”，也不只是出于手头这颇为沉重的四大卷《战争与和平》，而是更联想到译者前后以二十来年的时间，不知疲倦地埋头于托尔斯泰几乎全部重要作品的翻译。人们都知道，精通俄文的草婴先生，把他的毕生精力都奉献给了自己热爱的翻译工作，在翻译托尔斯泰作品以前，就译出了不少例如肖洛霍夫等苏联重要作家的作品。他从事托尔斯泰作品的翻译，开始于20世纪60年代初，刚译出了一个中、短篇小说集《高加索故事》，就被“文化大革命”那场浩劫打断了。“文化大革命”结束后，他立刻又挥动起那支勤勉非凡的译笔，不顾在浩劫中受伤害的腰脊的病痛，也不顾当时住房条件的不便，他立下翻译托尔斯泰全部重要作品的宏愿壮志，克服种种困难，冷静沉着地工作起来。在严寒天气，他依靠一个煤炉取暖；到了盛夏季节，他关闭卧房外面走廊里搭成的全部玻璃窗以避炎热。就在这种情形下，他先译成《安娜·卡列尼娜》，接着是《复活》。最近几年，住房条件有所改善，他花了六年时间奋力完成《战争与和平》的翻译。托尔斯泰在谈到自己写作《战争与和平》的情形时说：“我在最优越的生活环境里，花了五年连续不断的艰巨劳动，写成了这部作品。”而草婴先生，则在并不能算是优越的生活环境里，花了更多时间连续不断的艰巨劳动，完成了中文翻译。在这一点上，我要说的是，创作固然是一种艰巨的创造性劳动，需要作家秉赋有一种忘我的虔诚态度，一种无私奉献的傻子精神；翻译也是如此，也需要同样的秉赋，同样的精神。据我所知，草婴先生除了已经译成出版的托尔斯泰三大巨著《战争与和平》《安娜·卡列尼娜》和《复活》，已经译成正待陆续出版的还有自传体小说《童年·少年·青年》以及四卷中、短篇小说，总共约有四百万字。应该承认，这个数量，在中国的翻译界也是罕见的，且不说译文的质量问题了。

最近一个时期，和对文化沙漠化现象的扩大表示忧虑的同时，经常被提起的还有一个文化断层问题。其实，后一问题也可以说是前一现象的一个方面，一种后果。对这情况作深入的分析研究，非我的能力所及，我只愿就文化积累和个人努力的关系，表示一点自己的期望。几年以前，有一家文学期刊就“新时期文学十年”这个总题目要我提供一些看法，我虽指出了“文化大革命”结束后十年间文学界存在的问题，但对前途仍抱有乐观态度。当时，我的主要观点是要有作品，要让作品来说话。现在，又是几年过去了，我的观点仍然没有改变。只须想一想，如果在我们的文化园地里能不断出现新的花朵和果实，还哪里会有什么沙漠化和断层现象呢？

不用说，文化沙漠化和断层现象，归根结底是一个人的问题。歌德很重视民族文化的作用，他在《谈话录》里说：“如果一个有才能的人想迅速地幸运地发展起来，就需要有一种很昌盛的精神文明和健康的教养在他那个民族里得到普及。”同时，他也重视诗人作家个人的努力，个人对专业的专心不旁驰博鹜。他以自己为例：“假如我没有在石头上费过那么多的工夫，把时间用得节省些，我就很可能把最珍贵的金刚钻拿到手了。”他更重视诗人作家的人格修养，认为近代文学界的弊病，根源就在于“一些个别的研究者和作者们人格上的欠缺”，“伟大的目标，对真理和德行的爱好和宣扬，在这个领域里也是很稀罕的现象。甲吹捧乙，支持乙，因为希望借此得到乙的吹捧和支持。真正伟大的东西这班人看来是可厌恨的，他们总想使它淹没掉，让他们在‘猴子世界称霸王’。”歌德的话说在一个世纪以前，我仍然愿意引为警惕。在我们中国，鲁迅逝世前曾劝告后人不要做“空头文学家”，即徒有虚名而无作品的作家，他的话也说在半个世纪以前了，可是在今天的文化界，岂不是存在着一些整天忙于自我炫耀却不愿埋头从事创造劳动的“空头文化人”吗？这种情况，实在无助于文化沙漠化和断层现象的消除。

由于读到《战争与和平》的新译本，而感到莫大喜悦，对它的译者重译托尔斯泰的几乎全部重要作品所表现的坚定意志和艰辛劳动深表敬佩，因而从文化积累的角度提出一个虔诚的期望：什么时候在文化界能少出现一些热衷于赶热闹的“空头文化人”，多产生几个甘守寂寞而献身自己的专业的“傻子”，对改变我们令人忧虑的某些文化现象也许会不无裨益的。

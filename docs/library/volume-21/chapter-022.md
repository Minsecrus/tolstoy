# 翻译家草婴纪事

谷苇

草婴把他新出版的译作《复活》从书橱里取出来，郑重地签上名，盖上印章，送给我。

在这一刹那，我脑海里浮现的，并不是眼前这位满面溢着欣慰笑意的著名译作家。时光似乎迅速倒流到十二年之前，1975年1月28日，那是江南的严寒季节，加上已是暮色苍茫的时候，即使坐在室内也深深地感到一阵阵的寒意。瘦弱、憔悴的草婴坐在我对面，身上穿着单薄的灰得发白的旧咔叽劳动服，一面随便地和我聊着天，一面注意着楼下隔着一个花园的出版社的大铁门。

“这么晚了，怕是不会再有车子来了吧！”我站起身来，随手整理好写字台上的书报，准备“打道回府”了。

“不，说好还有一车水泥要来的。”草婴很认真，显然不打算“早退”。我看着他又瘦又弱的身躯，和他身上单薄的衣裳，心里真有说不出的凄凉之感。说什么好呢？这正是十亿人民都深陷在“史无前例”的漫漫长夜中的时候，全中国的知识分子都位列“老九”，无休止地在接受“劳动改造”和“再教育”。这天，正轮到草婴“参加劳动”——为出版社正在兴建的大礼堂装卸建筑材料，而我只是偶然在下班之后，留在办公室里看点闲书。草婴走来找个“稍息”的地方，才有这片刻的闲话机会。

突然，出版社的大铁门咣啷一声打开了。随着一阵“嘟嘟”的汽车喇叭声，一辆满载水泥的载重卡车沉重地停了下来。接着就是嘈杂的人声，我知道那是在卸车了。

草婴呢？早在大铁门响动和汽车喇叭高叫的时候，就冲到楼下去了。但是，我还没有离开办公室，就听到有人叫着奔上楼来说：“不好了，不好了，草婴腰骨压断了……”

我赶紧奔下楼去，草婴已经被送到附近的瑞金医院急诊间去了。

以后，听说草婴被送回家，“绝对卧床休息”。很长、很长的时间，没有再看到他消瘦、憔悴的身影。但是，断断续续传来的消息说，草婴的伤很使他痛苦，一天二十四小时直挺挺地睡在硬板床上，一动也不能动。医生说，只能这样硬挺着，等待被折断了的腰骨自然愈合。病人随便动一下，都有使断骨错位的危险。家属得到的暗示则是：重则有生命之忧，轻则也可能下肢瘫痪、半身不遂。

亏得草婴惊人的毅力，他居然就这样在板床上一动不动地躺了半年多，总算接上了骨头。过了一年才终于从病床上爬了起来。他还记得，就是1976年1月8日，他支撑着久病方愈的病体第一次走出寓所门外，正好就听到人家收音机里传来了周恩来总理逝世的消息。

黑夜再长，也有尽头。1976年10月中旬，“四人帮”被粉碎的喜讯传到上海，沉寂的出版社大院开始沸腾起来。而挺身出来贴出第一张揭批“四人帮”“狗头军师张”大字报的，正是久病新愈的草婴。

草婴终于重新拿起了他的译笔。他开始根据俄文原著翻译托尔斯泰的《安娜·卡列尼娜》，接着是《复活》《战争与和平》……这些名著，过去已有中译本传世，而且译者周扬、汝龙、董秋斯，都是读者熟悉的著名作家。但是他们当时都是根据英文译本转译的。草婴以为有必要根据托翁的俄文原著重译一遍，于是他开始了自己的工作。他制订了一个庞大的计划：译成《托尔斯泰文集》十二卷，四百万字；再译成《肖洛霍夫作品集》三卷，一百万字。共计五百万字的译文，要在短短十五年内完工，没有一种唐玄奘取经的精神，恐怕是不行的。

……现在，我终于拿到了草婴的译作《复活》；《托尔斯泰文集》十二卷也已完成二分之一了。目睹书橱内草婴的新译作足足排成一行，我不能不赞叹这位译作家付出了多么艰巨的劳动！他已年逾花甲，而且两次“死里逃生”——除1975年那次骨折外，1969年从“隔离审查”的小屋中放出来时，他突然上吐下泻大量鲜血，五天五夜滴水不进。结果动了手术，胃切除了四分之三。然而这一切都没能使他放下译笔。他就是这样一个人：三十多年前选定的道路，他要毫不犹豫地走到底。

1923年3月24日，盛草婴出生在他的故乡浙江镇海。抗战爆发，故乡沦陷，没有念完中学的草婴逃难到了上海。这时他十四岁。

草婴的父亲是位西医，思想比较开明。因此草婴得以阅读了一些进步书籍，如《西行漫记》《苏联见闻录》等等。他从书中开始认识苏联这个新兴的社会主义国家，渴望进一步了解那里发生的一切。1938年3月的一天，他找到了“登报招生”的一个俄国女人苏依柯娃，向她学习俄文。苏依柯娃要了四元大洋的学费，说定每星期教他一小时课。实际上除了一本哈尔滨印的《俄文津梁》之外，没有任何的俄文语法、字典以及其他教材。

尽管如此，草婴还是感谢这个俄国女人，因为她毕竟是他学习俄文的“启蒙者”。

一个很偶然的机会，草婴参加了“拉丁化新文字研究会”。大概有人发现这个醉心学习俄文的少年，出奇地关心苏联的一切，便把他介绍给了“贺一青”先生。后来草婴才知道贺先生的真名是姜椿芳，是位活跃在沦陷区、国统区文化界多年的中共地下党员。这样，草婴就自然地受到了党的关怀与教育。

1941年苏德战争爆发，塔斯社在上海办了《时代》杂志，主持者就是姜椿芳与陈冰夷。姜椿芳介绍草婴进了这家杂志的“中文版”工作，并常常指定草婴为杂志翻译一些短文发表。这些现在已不易找到的短短的译文，应该是草婴的“处女作”。这时，他刚满十八岁。

不久，《苏联文艺》在上海出版。草婴在第二期上发表了他译的普拉多诺夫的小说《老人》。这是他完成的第一篇文学译作。

1941年到1945年间，苏联利用它和日本的外交关系，继续在沦陷后的上海扩大文化、宣传工作。1945年5月，苏联时代出版社表示欢迎草婴正式参加工作。而草婴正值在雷士德工学院附中和松江中学毕业，考进了南通农学院，却因患肺结核病停学在家休养。他很乐意进“时代”工作，但是由于父亲的反对，他不能不以“走出家庭”的代价来换取工作的自由。这样，一直工作到1951年，他才因病离开了“时代”。20世纪50年代初期他就被吸收为中国作家协会会员，成为著名的专业翻译家。

在俄罗斯与苏联的文学巨匠中，草婴最最为之心折的是两个人：托尔斯泰与肖洛霍夫。他认为肖洛霍夫正是最好地继承了托尔斯泰。

1953年开始，苏联《真理报》与《星火》杂志同时以连载形式发表肖洛霍夫的《被开垦的处女地》第二部。这在苏联文学界是件大事，当然也受到了中国文学界的重视。

《世界文学》编辑部约请草婴按期及时把这部作品译成中文，在《世界文学》刊出。于是，苏联报刊每次发表肖洛霍夫的原著一、两章，中国《世界文学》也随即披露草婴的译文一、两章。这样的“同步工作”一直进行到1959年，《被开垦的处女地》第二部才全部发表完毕。后来出单行本，改名为《新垦地》。

在此期间，1956年12月31日与1957年1月1日，苏联《真理报》发表了肖洛霍夫的《一个人的遭遇》，在国际文坛上引起广泛注意。草婴也很喜爱这部作品。因此当《世界文学》要求他赶译的时候，他很快就交卷了。4月份发表译文，接着出单行本；不久同名电影文学剧本也由他译出，交《文汇报》连载刊出。

当时还在上海一家报社任社长、但已炙手可热的张春桥，从苏联访问回来，在上海文学界的一次会议上说：“即使在苏联，肖洛霍夫和他的作品也是有争议的。”虽然闪烁其词，但其倾向性已完全可以辨别出来。于是，有些原本称赞过肖洛霍夫与其作品的人，一时也随风转向。有位作家原先对《一个人的遭遇》赞不绝口，现在也公然声称：“我早就说过，肖洛霍夫和他的作品没有什么意思。”

好心的朋友意识到文学的批判往往导致政治的批判，便悄悄地提醒草婴：是不是应该改弦更张，别再去碰肖洛霍夫了。

草婴，却很固执。他信奉的是郑板桥老先生的《竹石》诗：

咬定青山不放松，立根原在破岩中，

千磨万击还坚劲，任尔东西南北风。

对于自己认定是于世人有益的工作，他是“一旦相爱，永远相爱”的。任何闲言碎语，任何风刀霜剑，都不顾了。

1960年，中苏关系恶化。文艺界的“反修防修”之声日高。上海文学界在张春桥、姚文元等的策动下，搞了一个“七七四十九天会议”，从批判西欧19世纪文艺开始，把巴尔扎克、托尔斯泰，直到当时还健在的肖洛霍夫，通通推上了缺席审判的“被告席”。

草婴在大大小小的会议上，自然而然地也被列为“帮助对象”。人们对他的“文艺思想”以至世界观等等，开展了“热情的帮助”。此时此际，他的处境与心情，是可想而知的。然而，他并未中止自己的工作。

肖洛霍夫的作品既已不能再翻译出版，他只好回过头来，再译托尔斯泰的作品。但他只译成了一本《高加索故事》，一场几乎把整个中国推落无底深渊的风暴卷来了。

在满街喧嚣着“造反有理”和“文化大革命就是好”的吼声中，多少学者、专家含泪亲手毁去自己积存多年的手稿，烧毁长期相随的工具书和参考资料。有人也劝说草婴夫妇把满屋子的图书，特别是那些最容易被视作“罪证”的肖洛霍夫和托尔斯泰的原著，赶快销毁，或者捆扎起来送到“废品收购站”去。但是，他们终于没有听从。

草婴和他的夫人盛天民有一个同样的想法：阅读和翻译世界名著是光明正大的事。这些书一本也不能烧，不能卖。如果违心地亲手去毁灭它们，那就是背叛自己的事业。

当臂缠红袖章的“无产阶级革命派”来到草婴家里，采取“革命行动”的时候，足足两大卡车，装走了草婴的全部藏书。不久，他们夫妇都被“隔离审查”。随后有好几年，草婴时时以“戴罪之身”经受着各种磨难，一直到腰骨折断。

然而，这一切总算过去了。

人，总是为了希望，为了理想而活着。

当漫漫长夜过去之后，“劫后幸存”的草婴更加珍惜自己的时间与精力。他加倍努力地继续自己的工作。在不到十年的时间里，译成了十几本新作。他把所有的时间都贡献给了文学翻译工作。

种瓜得瓜，种豆得豆。草婴也终于尝到自己劳动所结出的甘果。

他常常收到远方读者的来信，赞扬他的辛勤劳作给人们带来的快乐。是译作者忠实而又优美的译文，使人们的心与托尔斯泰、肖洛霍夫的心，相接近了。

南京大学的一位教授给草婴的信上说：

看着您译的书（《安娜·卡列尼娜》与《复活》），想着您辛勤劳动所达到的高水平的翻译，心中升腾起的——除了敬意还是一片敬意。托尔斯泰在中国能找到您这样一位译者，在九泉之下，一定会欣然微笑。

广西一位大学教师告诉草婴：在“十年浩劫”中，他所有的书都被抄走了。只有草婴译的《一个人的遭遇》，实在舍不得，被他埋藏在墙洞里，才得以保存下来。

一位上海的老干部，买了一本草婴的译作，辗转从另一位译作家那里打听到草婴的住所，亲自找上门来，要求签名留念。

就在不久以前，草婴到北京参加中国翻译家协会的成立大会。他在大会上被选举为副主席。一天晚上，突然来了两位老朋友，也都是著名的译作家。这对夫妻带来了自己已经长大的女儿，手里拿着一本三十年前，她做小学生时读的草婴的译作，一定要请译作者签一个名。

在兰州大学，因为听草婴讲托尔斯泰与肖洛霍夫，热情的听讲者甚至把教室的门都挤塌了。

在说起这一切的时候，草婴的话语哽塞了。好一阵，才说了句：“就是这些读者，我亲爱的朋友，给了我最大的鼓舞和巨大的力量。为了他们，我愿意像春蚕一样，吐尽心中的丝。”

是的。这就是草婴的心声：

我已不那么年轻，可以随便地浪费时光；

我也还没有那么老，可以平静地等待死亡。

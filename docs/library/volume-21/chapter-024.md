# 记我们的Captain草婴

汪礼彤

母校附中1938级，和其他班级一样，是个普通的班级，也是个出人才的班级。除工程师、专家、企业家等外，较知名的有任根鎏（任溶溶）、孙纪廉（孙梁）、汤国祥（汤兴伯）、邱长清、盛峻峰（草婴）、黄振兴（黄振声）、鲁平等同学。其中草婴是我国翻译界中贡献突出、最受尊崇、译作等身的德高望重的前辈之一。

草婴祖籍浙江镇海，1923年生，父为名医，书香门第，家学渊源。1938年进母校附中，是JIA班的Captain（班长）。当时他受抗日救国热潮影响，阅读进步书刊并在同学中传播，参加进步组织，还介绍同学去苏北参加新四军。他在校仅两年，后转入松江中学学习，但作风好，颇受同学爱戴，有两件事还得到初中部主任钮森（Newsam）的赞许。一是他和孙纪廉等办了一份名为《莽涛》的油印刊物，宣传进步思想，他的第一篇高尔基小说译文就是在这上面发表的。钮森见到刊物后，叫草婴去谈话，对初中生能办这样的刊物，颇为赞许。二是当时校方要初中学生也着西式校服，草婴带头抵制，钮森叫去询问原因，草婴答称：西服料子是日货，同学不愿买，而且价格太贵。钮森点头认可，此后即未推行。1939年十五岁时，他冒险开始课余学习俄文。1941年夏，为了参加反法西斯斗争，受姜椿芳之请，开始为上海《时代》《苏联文艺》等杂志译稿。1945年任时代出版社编译。1952年华东作家协会成立，成为专业会员，从此他把全部时间投入翻译苏联、俄罗斯文学作品。1958年任《辞海》编委，为外国文学科主编。他先后曾任上海市人大代表、市政协委员、上海作家协会副主席和华东师范大学兼职教授。1986年和1992年连续当选为上海翻译家协会会长和中国翻译工作者协会副会长。现为上海文联副主席和上海文史馆馆员。五十多年来翻译了肖洛霍夫的《新垦地》《顿河故事》和《一个人的遭遇》、尼古拉耶娃的《拖拉机站站长和总农艺师》以及列夫·托尔斯泰的全部小说（包括三部长篇小说《战争与和平》《安娜·卡列尼娜》《复活》和几十篇中、短篇小说）等作品三十多部、七八百万字。1987年在莫斯科国际翻译会议上获苏联最高文学奖——高尔基文学奖，他是中国唯一获得此项大奖的翻译家。

草婴热爱人民，为人正直、坚毅，爱憎分明，有见解，不随波逐流、人云亦云。他凭着智慧的直觉和敏锐的洞察力，在早期就觉察到极左路线的危害而坚决抵制；对摧残知识分子、灭绝人性的十年浩劫，更是痛心疾首。1955年和1957年，有人分别要他揭发批判著名翻译家满涛和傅雷，但他认为，作为一个朋友、一个人，总得保持一个人的人格。他熟悉满涛和傅雷，知道他们不是反革命，所以坚决不写批判他们的文章。1960年中苏关系破裂后，他因翻译肖洛霍夫的作品受到许多不应有的批判。到十年浩劫，因江青说肖洛霍夫是“苏修”文艺鼻祖，他就成了肖的吹鼓手、反动学术权威、漏网右派等。他们全家都受到很大冲击，他和爱人被隔离审查、批斗，两个孩子被送到农村。但他从来不认为肖洛霍夫的作品是“毒草”，因而受到更多的批斗、更多的苦难。一次强迫劳动扛水泥时，他还没有准备好，一袋水泥就压上身来，结果他的第十二胸椎压缩一厘米多而骨折。医生说，这病很难治，只能睡在硬板上，要躺半年多，而且一动不能动。一般人很难做到，弄不好就会下身瘫痪。草婴硬是凭着他顽强的毅力在硬板上躺了一年多，才逐渐恢复健康，不过至今留下了腰痛后遗症。近二十多年来他始终十分小心仔细地护理着自己的腰，只坐特殊的合适的椅凳，不坐沙发，腰疾未恶化，他才能一直坚持从事他热爱的翻译工作。

草婴有抱负，有理想，事业心极强，十分勤奋，坚韧不拔，锲而不舍。他说他最重要的一条体会就是要把所有的思想、精力、时间都集中起来，放在自己的主要工作上，而不要把自己的心分散到不同的领域里去，这样才能有所成就。他认为人的一生是短暂的，时间是有限的，能把毕生的精力都集中去做好一件事，就算不错了。五十多年来他就是在这样的心情下从事翻译工作的。他时间抓得紧，工作细水长流，从年头到年末，没有特殊原因，没有一天休息，天天都在笔耕，坚持不懈。他自控能力强，计划安排好，工作生活都很有规律。他不赶热闹，更不愿自我炫耀，而是不知疲倦地埋头爬格子。爬几十年格子，不但艰辛，有时也相当寂寞，因为翻译一部长篇作品，从动笔到定稿到出版，时间漫长，要好多年才能出版。解放以来，草婴无级别，无职称，无固定收入，稿酬又较低。草婴友人曾几次介绍他去从事级别较高、待遇优厚的行政工作，他都一一谢绝。他甘于寂寞，默默奉献，以毕生精力献身于自己热爱的翻译事业。这从他后期翻译托尔斯泰的全部小说这一浩大工程可见一斑。草婴从青年时代起就喜爱托尔斯泰的作品，因为被作品里面强烈的人道主义精神所感动并欣赏托翁非常高超的艺术技巧。同时他又千方百计想通过最好的艺术精品来净化人的心灵。而且他觉得他翻译托尔斯泰的作品比较适合，因为托翁是他最崇敬的人物。他认为翻译家与原作者有了心灵上的沟通，原作的精华才能较好地表达出来。因此年过半百、劫后余生的他就下决心从1977年起全力投入翻译托尔斯泰小说全集，历时十八年，至1995年全部完成，共十二卷四百万字，其中被称作19世纪俄国社会的“百科全书”、有一百一十五万多字的《战争与和平》就花了六年，其间遭遇大女儿因患绝症不幸病逝的伤痛，亦未中断。著名作家王西彦撰文誉之为“忘我的虔诚态度和傻子精神”，认为“这在中国翻译界也是罕见的”，并“对译者的坚定意志和艰辛劳动深表敬佩”。

草婴治学严谨，工作认真，总是选择有价值的艺术精品介绍给读者。在翻译过程中不厌其烦地查找资料，反复推敲，不断修改，精益求精，力求译文忠实、准确、优美、流畅、传神，尽量避免佶屈聱牙、艰涩难懂。他在翻译《一个人的遭遇》时，还请演员试朗诵，对不上口的地方，再进行修改。就是在校对译文清样时，也要反复校改好几遍。所以他在翻译界，很受人尊敬。他的译著深得读者好评、热爱。有一次他在南京签名售书时，有位中年读者拉着他的手很激动地说：“您的译文可说叹为观止。”有读者来信说“托翁巨著无与伦比，您的译文也是无与伦比”。1955年译的《拖拉机站站长和总农艺师》适应当时反官僚主义的形势需要，发行一百多万册。团中央号召全国青年学习女主人公娜斯嘉，译稿在发行量数百万册的《中国青年》杂志上连载两期，在青年中广为传播，影响很大，娜斯嘉成为当时青年的学习榜样。团中央第一书记胡耀邦也给予积极评价。

草婴现已年过古稀，但他仍忧国忧民，不愿无所事事，碌碌无为。他心里翻腾着对未来的憧憬，在多方观察，不断探索，尽力做一些力所能及而有意义的事情。他说：“真、善、美是人类永远值得追求的。”他毕生都在执着地追求真善美，坚信世界会越来越美好。

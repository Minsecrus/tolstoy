# 草婴印象记

章海陵

一代人有一代人的文学心灵。在一次外国文学研讨会上，笔者看见一批批中年学者前来问候翻译家草婴，几乎众口一辞提及：“当年迫不及待地盼望的就是《世界文学》上市，新杂志到手，首先要读的就是您译的肖洛霍夫《被开垦的处女地》（《新垦地》）。”我的青少年回忆也因而苏醒：在福州路闷热的旧期刊书店里，因空气不流通，很多顾客双颊像鸡冠似的又红又烫，我本人也像饥肠辘辘觅食的公鸡，顽强翻寻每一本过期的《世界文学》，用“吃”一样的眼光细读草婴的译文，啄着上面像纯净白米般的字、词、句和标点（这是今天令我流泪怀念的文学滋味）。不久，书市上出现了人民文学版草婴译的《被开垦的处女地》第二部。过来人一定记得，那是一个连漂白剂都缺乏的困难年代，印书用纸呈深棕色，须在阳光或强光下看得清上面的字，可是书页的喷香气味却很醉人，至今我都认为，“那是用芝麻酱下脚料制的纸，可以用来充饥。”

先是读《被开垦的处女地》，再是读《一个人的遭遇》《当代英雄》和《高加索故事》，草婴译作中的顿河草原、高加索群山令我欣喜若狂。别的读者可能和我一样吧，对于外国文学作品中描绘过的地方有一种印象和概念，尽管对于那块从未涉足过的天地永远也说不清楚，可心里却是有数的。草婴译作中展示的国外风光，与我心中的“印象和概念”竟是如此吻合，译笔圆了我少年五光十色、缥缈虚无的“俄国梦”。所以，当我第一次见到草婴本人时，头几个问题竟像连珠炮似地涌出：“您去过国外吗？您到过顿河吗？您去过高加索吗？”草婴以他特有的、富于魅力的、略略腼腆的微笑摇头否认。但我还想继续问：“您赶过马车吗？您会犁地吗？您打过仗吗？……”我终于没再问，因为我已发现了自己的冒失和鲁莽。草婴，中等个子，瘦瘦的，文雅端庄，亲切而和蔼，是一位再典型不过的知识分子。

可是，对草婴翻译的许多疑惑，仍然没解除。譬如，肖洛霍夫《新垦地》里中农哥萨克梅谭尼柯夫“割私有制的尾巴”，不眠之夜回忆雪夜参观莫斯科红场的情景：那湿漉漉的大旗在雪花和朔风中上下翻飞，再被刷亮的灯光由下面一照，竟像鲜血在腾涌……草婴在这里译出了如闻其声的动态，更译出了气氛：夜深人静的红场被灯光照得如同白昼，那肃穆得有点森严的自然气氛和梅谭尼柯夫崇敬、虔诚、略带惶恐的心理气氛。所有这些气氛是如何从原文中“译”出来的呢？再譬如，列夫·托尔斯泰的《霍斯托密尔》中母狼喂小狼的段落，草婴是这么译的：“母狼走到那只最小的前面，垂下尾巴，嘴向下伸了伸，抽搐几下，张开牙齿锋利的嘴，使劲一咳，咳出一大块马肉来，……”译文中的这个“咳”何其传神！不是吐，不是呕，不是呛，不是抖，也不是弹，而是“咳”。一个字极鲜明地“咳”出了母狼的特性，其中包括狼的凶残，也包括了母性的慈祥。问题是，这个“咳”又是怎么浮现在草婴的脑海里，最后出现在他笔端底下的呢？

在草婴的译作里，春、夏、秋、冬的天气一应俱全，仿佛格外纯净、格外美妙、格外清新，还有那些欢乐的、忧郁的、幽默的、悲哀的、英勇的人物性格，各个不同，栩栩如生，还有那略略发黑的镶银马刀，那油腻腻的肮脏的烟荷包，那令人头昏眼花、烟气缭绕的教堂大厅……草婴全都译得那么逼真、那么洁净、那么明确。关于这一切，草婴说，他译作品之前，不仅把原文反反复复地看几遍，而且在心里仔仔细细地温习几遍，有时甚至还要画个画面，每一细微末节都不能放过。

文学翻译不许译者“喧宾夺主”，不能添加任何原作不具备的东西。可是，译作要吸引人，文字非有生命力不可，而它唯有在原创性的写作激情中才能产生。草婴的译文分明是具有生命力的，难道他融入了属于自己的文学精魂？我想起托尔斯泰说过：“在艺术创作中创作者与鉴赏者融成一个共同的‘我’。……在艺术中，这种融合可能是崇高的，也可能是卑鄙的。”我认为，草婴的译作之所以动人，可能就因为他在翻译的进程中，作为与众不同的鉴赏者，把自己透透彻彻地和原作者融合在一道了。他这位鉴赏者读原作比一般的鉴赏者有更多的心得、更多的体会，足有资格当作者的知己。对于作者的幽默，别人或许不过颔首而笑，而优秀的译者可能整天自得其乐，仿佛这也是他个人的内心喜悦。至于书中人的悲哀，别人可能会一时流下同情之泪，而卓越的译者则久久忧伤，好像那是他永远无法愈合的心头之痛。笔者曾遇到为草婴译作《新垦地》中的狗鱼大爷笑得泪水婆娑的读者，也见到为草婴译作《安娜·卡列尼娜》女主人公心向神往的文学爱好者，道出“对安娜这样的女人不可求也不可遇”的悲恸，而全然忘却自己是在阅读。

似乎可以这么说，草婴的译作是他与原书作者托尔斯泰和肖洛霍夫合作的结晶，而他是一位高明的“合作者”。其次，我想肯定的是草婴的工作态度。他译书仔细认真，全力以赴，有一种锲而不舍的顽强和耐心。我见过他译文的初稿：字迹工工整整、一笔一划，就是涂抹也涂抹得清清楚楚。我依稀体会出他的用心：全心全意为读者着想，让读者保持轻松愉快然而又是全神贯注的阅读情绪。草婴力图译得既口语化又规范化，文字力求清新而优雅。他在“得、地、的、还、就、已、了”这类小笔触特别下功夫，改过来又改回去：唯恐读者读起来“文气”不顺。同时，草婴也很照顾原文的内在节奏，以及情绪气氛。我曾听见大学外语系教翻译课的老师说，师生们一块儿对照草婴的译本读原版著作时感到极大的享受，大家时而为译文的忠实佩服不已，时而为对应的巧妙拍案叫绝。我也听有些编辑说，他们已养成了一种“讨厌”的职业习惯，看稿时常常情不自禁更留心别字、错句以及误用标点。而这一类瑕疵在草婴译作文稿里是很难发现的。草婴对自己的译作很严谨，每一字、每一句都要反反复复推敲，只要时间条件允许，他甚至会无数遍地修改下去。“润饰文字是没有底的”，草婴经常这么说。

20世纪60年代初，草婴以翻译《新垦地》《顿河故事》和《一个人的遭遇》等肖洛霍夫著作在译坛奠定名家地位，此刻中国反对苏联现代修正主义的政治形势也告形成，肖洛霍夫的作品尤其是史诗《静静的顿河》与短篇小说《一个人的遭遇》成了批判的重点。但就在这时，草婴翻译的头一批托尔斯泰译作结集《高加索故事》出版了。托尔斯泰是19世纪俄国文学巨人，作品艺术成就和思想含量超过肖洛霍夫。这时草婴四十刚出头，正是事业上出成绩的大好时机。可是，“文化大革命”很快来到，草婴遭批判，受迫害，九死一生……草婴过去翻译上的优异业绩成了他的“罪状”，而罪名就是“肖洛霍夫在中国的代理人”。他曾受到这样的指控：“为什么肖洛霍夫的作品，被你译得那么好？”这番情形跟肖氏的《一个人的遭遇》中的一个情节简直不谋而合：苏军战俘在德国集中营受尽虐待，一个法西斯军官热衷于用学到的俄语辱骂战俘，而且用方言骂，而这方言恰好是主人公家乡的粗话，被勾起乡愁的主人公感到“有股清新的风袭来”。草婴说：“‘文革’中受到这样的批判，令我哭笑不得，无奈中感到‘安慰’，但更多的是悲凉。”

“悲凉”一说令我震惊，但多么确切！那个年月，俄国文学爱好者为读不到新译作怅然若失，而杰出的翻译家面对的却是事业被中断，而且看样子是永远地中止，这是怎样的折磨！人道的、永具魅力的俄国文学真是苦难的文学，连在中国的遭遇也是如此。我联想到瞿秋白在时日不多的临刑前产生强烈的阅读渴望，极想读中国曹雪芹的《红楼梦》和俄国高尔基的长篇巨著《克里木·萨姆金》。对草婴而言，“文革”磨难也不仅是不得翻译，还有力不胜任的体力劳动。体格瘦削的草婴后来被一袋重重抛下的水泥砸断腰骨，不得不一整年躺在硬板床上，白天黑夜忍受着剧痛。很多熟人都以为草婴将终身残废，但他还是站立了起来：似乎冥冥之中仍有使命在召唤。这使命就是草婴还是要从事俄国文学翻译。“文革”浩劫结束，草婴已五十三岁。但就从这时起，一直到20世纪90年代中期，草婴翻译了十二卷《托尔斯泰文集》，修订《肖洛霍夫文集》三卷。当然，这只有在打倒了祸国殃民的“四人帮”，特别是三中全会以后，草婴才可能放手大干。草婴社会活动和外出讲学的任务很重，但他始终有个通盘计划——远期的，近期的，当年的，本月的，甚至每一天的。在各种各样的计划中，译书是头等大事，一切活动都以它为轴心。草婴耐得住寂寞。许多带娱乐性的社会活动尤其是外国电影观摩，在别人看来是求之不得，或机会难得，草婴却毫不动心地放弃、避开了，因为要译书。其实，草婴译书的速度并不快，但十分稳定，每隔两三年，总有一两卷《托尔斯泰文集》上柜，读者甚觉欣慰：草婴还在勤奋、专心地工作！不少中青年同行则感叹：“比比草婴先生，我们真惭愧！”

草婴常说：“聚精会神地工作一小时，就能做好多事情。”这个道理人人都懂，但远非人人能做到。生活中有许多麻烦、意外、苦恼和不愉快也向草婴纷至沓来，但他始终情绪稳定地应对，心灵深处只有一个声音：专心译书，专心译书。他特别欣赏郑板桥的咏竹诗：“咬定青山不放松，立根原在乱崖中。千磨万击还坚劲，任尔东西南北风。”他常常以此自勉和勉励青年朋友。是的，无精神压力的环境何尝不是另一种“磨难”、另一种考验？许多在“文革”时期为不能读书写作而苦恼的彻夜难眠的文化人，到了宽松年代不知不觉沉湎于闲散玩乐，仍然一事无成！

草婴给笔者留下很深印象的是这样一件事：这年夏天的一个傍晚，我拜访他时发现他的神情不同往常，忧郁，思想也不太集中，但又显得激动。我匆匆告辞，他却要求我再坐一会儿，并解释：今天他译托尔斯泰长篇《安娜·卡列尼娜》“安娜之死”那一章，“心里真难过……”是啊，“亲人”死了，我在心里想，诚恳深挚的安娜是托尔斯泰的“亲人”，草婴也是，尽管血统上他是中国人。草婴又岂止是在难过呢？

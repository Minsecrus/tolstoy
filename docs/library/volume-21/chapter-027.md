# 庆贺“时代”[15]的“双喜”

“时代”十年了。十年，本来算不上是一段很长的时间，但是，这十年，不论对中国或对世界说来，却实在是太不平凡，太了不起了。这十年也确实称得上是一个大时代。

“时代”在这个大时代中产生，成长，在最艰苦的环境中跟各种黑暗势力进行战斗，同时又不断地在战斗中壮大。日本宪兵的黄皮靴、国民党特务的黑魔掌，全都拦不住大时代的前进，它们同样也吓不倒“时代”，绞不杀“时代”。因此，“时代”对这个大时代所作的一份贡献，也是绝不能抹煞的。

现在，“时代”在它的十周年上改为公营了。这对“时代”说来，是一件值得大大庆贺的喜事：这是“时代”的“蜕变”，是“时代”将更向前跨进一步的表示。在这“双喜临门”的日子，我衷心地向“时代”祝贺，愿“时代”前途无量，“时代”的朋友们个个快乐、健康。

（原载于《时代》，1951年第11期）

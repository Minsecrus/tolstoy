# 过年杂感

每逢日历撕到最后一页的时候，人的感想往往要比平时多一些，特别是这一次——1957年。

是的，1957年确实是不平常的一年。从世界范围来说，至少有两件事情会永远留在人类的历史上：一件是苏联的两颗人造卫星上了天；另一件是六十四国共产党和工人党的代表，在莫斯科欢聚一堂，庆祝十月革命四十周年，还联合发表了宣言。在我们国家里，也有几件大事情：第一个五年计划已经胜利完成，给国家工业化打下了一个初步的基础；在政治战线和思想战线上展开了一场剧烈的斗争。“右派”的猖狂进攻，在全国人民的反击下，已经遭到可耻的失败。在全国范围内展开了轰轰烈烈的全民整风运动，在广大干部中掀起了“下乡上山”的热潮。

如果说，人类历史有飞跃前进的时期，那么，我想，今天的世界就是处在这样的时期里。我们生逢这样的时代，应该说是莫大的幸福；但同时也感到需要百倍努力，才不至落在时代的后面。

1957年对我个人来说，也是一个不平常的年头，因为我已在5月间被批准加入中国共产党。我是一个文艺工作者，过去参加实际斗争较少，没有经过很好的锻炼，知识分子的毛病相当严重。今年在上海市政协和作协参加了反右派斗争，一方面认识了政治战线和思想战线上敌我矛盾的尖锐性，明确了敌我矛盾和人民内部矛盾的界线；同时也深深体会到知识分子要改造自己，必须参加实际斗争，光凭书本上的一些理论知识是不能解决问题的。

印度有句谚语：“一滴水要不干掉，只有落到大海里去。”我觉得这句话正好说出个人和集体的关系。不论怎样大的一滴水，如果不落入海洋里去，早晚要干涸的。我参加组织以后，首先感到的，也就是那种一滴水归到大海里去的愉快感觉。

1957年过去了，我觉得1958年又是一个重要的年头。在苏联，紧随着两颗人造卫星的上天，原子破冰船的下水，预料1958年在科学研究方面一定又会出现各种新的创造，取得各种新的成就，为人类幸福作出更大的贡献。我们的第二个“五年计划”将在这一年开始，我们要在十五年后在主要工业产品产量方面赶上和超过英国，因此这一年又是一个重要的起点。

面对着1958年厚厚的新日历，我感到欢欣鼓舞，信心百倍。在党的领导下，我要做好自己的工作，加强实际锻炼，为加速实现共产主义的伟大理想，献出自己的力量。

1957年大除夕

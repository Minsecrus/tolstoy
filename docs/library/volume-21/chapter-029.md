# 人生最初的欢乐

——介绍《初欢》

电影《初欢》是根据苏联作家费定的同名小说改编的。小说《初欢》和《不平凡的夏天》在1948年获得斯大林奖金一等奖，是费定的三部曲的第一和第二部（第三部还在写作中），发表以后受到苏联读者的热烈欢迎，并且被译成好几国文字。这两部已经发表的作品，确实称得上是一部伟大的史诗，它写下了十月革命前后俄国社会的重大变化，显示了革命暴风雨中形形色色的人物，而尤其突出地刻画了作为“时代典型”的革命的新生一代。

这里我们暂且撇下《不平凡的夏天》，只来谈谈《初欢》。

俄国1905年的革命失败以后，反动的沙皇政府变本加厉，对人民实行愈益疯狂的镇压，成批的革命者被投入监狱，被流放出去做苦工。在反动势力的影响下，知识分子圈子里的颓废情绪增长了，许多人退出革命，躲进了“为艺术而艺术”的象牙塔里。表面看来，革命力量似乎已经衰落，反动政权重又巩固了自己的统治地位。但这只是表面的假象。事实上，在反动势力空前猖狂的情况下，劳动群众正在聚集力量，积极准备掀起新的革命高潮。

1910年夏天，在伏尔加河畔的一个城市里，工业学校的学生伊斯维可夫跟商人密什可夫的女儿里莎手拉手地在丁香和槐树丛里散步。里莎笑着说：“我大清早醒来，连自己也不相信中学已经毕业了！”伊斯维可夫说了句“恭喜你”。接着递给了她一束丁香花。这种情景，使人感到在这样的年岁里，生命就像一束初开的丁香，在阳光下领受着青春的欢乐。

不过，伊斯维可夫的欢乐绝不仅仅限于跟姑娘散步和谈心。整个社会的空气虽然沉闷，他却已经找到了一条通向真理的道路。在老革命家彼得·彼得洛维奇的教导下，他参加了一连串的地下活动：学习排字，印刷传单，做联络工作……在黑暗的王国中能找到一线光明，并且为争取一个光明的新世界而斗争，这是人生最大的欢乐，也就是青年伊斯维可夫的“初欢”。

伊斯维可夫这个人物，就是作者企图通过他来表现的“时代典型”。他坚定、刚强、机智，时时刻刻忠于革命的理想，经得起各种严酷的考验。他跟同志们一起在地下印刷所里工作，废寝忘食，不幸中了铅毒。给他看病的医生，无意中把他的秘密泄露出去。于是，伊斯维可夫被捕了。宪兵中校卜洛杰采夫对他施行残酷的刑罚，要他在一张白纸上写出同志们的名字来，但是一个真正的革命者不会出卖同志，也不会玷污自己洁白的灵魂。因此，银幕上一再出现那张没有字的白纸，是富有深刻的象征意义的。这也充分显露出导演的才能。

演伊斯维可夫的青年演员谷尔什诺夫，理解原作的精神，突出地表现了当时俄国革命青年的性格。给人印象最深的是，当最后他夹杂在流放犯中间，踩着没脚的泥泞，昂着头向流放地走去时的那副神气。当一个人真正对革命抱着无限信心而又蔑视个人一切苦难的时候，才能表现出这种伟大的气魄来。

里莎在伊斯维可夫被捕后，在父亲的威逼哄骗下，终于嫁给了庸俗透顶的舒勃尼可夫。洁白的新娘礼服，映着晶莹的泪水，里莎也挣脱不了旧社会里许多弱女子的命运。是的，里莎是个娇弱的姑娘，她的家庭出身、思想、性格跟伊斯维可夫没有一点相同的地方，因此，很自然的，他们之间也只能留下一段青春的“初欢”罢了。

作家巴斯杜霍夫和演员兹维杜金是当时俄国知识分子的一种典型。他们远离劳动人民，远离当时的革命斗争，生活空虚无聊，但又瞧不起一切人。巴斯杜霍夫高唱着“为艺术而艺术”的滥调，兹维杜金也只是为了要表现艺术才到下层去“体验生活”，结果当然无法把高尔基的《夜店》演好。费定写这两个人物，一方面是揭露当时一般知识分子的面目，同时拿他们来跟革命知识分子伊斯维可夫相对照，使后者更加突出。而最主要的是，费定在这里清楚地说明一个真理：一个人如果站在革命斗争之外，他的生活必然是空虚的，没有意义的。

彼得·彼得洛维奇和他的爱人克莎娜都给人留下难忘的印象。彼得·彼得洛维奇的沉着、老练、机警，处处都表现出一个久经考验的工人阶级老战士的风度。克莎娜从一个普通的家庭妇女，通过实际革命锻炼，成为工人阶级中觉悟的一员。这一发展过程也是很自然的。

《初欢》的内容非常丰富，接触到的有政治、道德、艺术、生活等各方面的问题。要把这样一部大作品改编成为电影，不是一件简单的事；要完整地在电影里保持原作独特鲜明的风格，更加不容易。然而，《初欢》的改编者，基本上还是成功地完成了这个艰巨的任务。因此，这部影片也应该说是苏联电影艺术上一个新的成就。

# 顿河草原上的花朵

——介绍《顿河故事》

看过长篇小说《静静的顿河》或者《被开垦的处女地》（后更名《新垦地》），或者短篇小说《一个人的遭遇》，谁也不能不被这些文学杰作的艺术魅力所吸引，而叹服于作者雄伟的气魄和穿纸欲破的笔力。肖洛霍夫写成《静静的顿河》，前后花了十四年工夫。他动手写第一卷时，才二十岁；当第一卷和第二卷在《十月》杂志首先发表的时候，他还是一个二十三岁的青年。这种稀见的天才简直叫人难以相信。但是，更使人吃惊的是，在这以前肖洛霍夫已经写出一批出色的短篇小说——《顿河故事》。

肖洛霍夫的第一个短篇“胎记”，发表在1924年，当时他才十九岁。以后一年多的时间里，他又写了二十多个短篇，分别刊登在《青年列宁主义者》《农民青年杂志》《新生代》《星火》等报刊上。这些短篇后来又以不同的编选方式、用不同的书名结集出版。在1926年新莫斯科出版社出版的《顿河故事》集里，老作家绥拉菲摩维奇写了一篇序言，热情地向读者介绍这位青年作家和他的作品。他写道：

“肖洛霍夫的短篇小说好像草原上的鲜花，富有生命力。素朴、鲜明，使人感觉到讲的事好像就在眼前。形象化的语言，那种哥萨克人说的多彩的语言。简洁，而这种简洁却充满生活气息、紧张和真实。在紧要关头保持分寸，使作品显得真实有力，对于所讲述的事，具有丰富的知识。尖锐的、洞察一切的眼力，有能力在许多征象中挑出最典型的来。所有这些才能说明肖洛霍夫将发展成为一个可贵的作家。”

后来的事实证实了绥拉菲摩维奇的预言。

《顿河故事》里的小说尽管都独立成篇，每篇都有不同的题材、情节和人物，可是它们却有着一个共同的主题，那就是：十月革命和国内战争的风暴，怎样摧毁了顿河两岸哥萨克的古老生活方式，加剧了他们的阶级分化，哥萨克中的上层反动分子，怎样死抱住自己的特权和地位，对革命展开疯狂的顽抗，哥萨克中的贫雇农和年轻一代，怎样经过曲折的斗争，走上革命道路，并且对革命事业显示出无限忠忱，以及苏维埃政权怎样通过尖锐复杂的斗争，在顿河两岸确立起来。

肖洛霍夫出生在顿河边上，长期生活在哥萨克中间，最熟悉哥萨克的生活和他们性格的特点，因此他的作品大多是描写顿河哥萨克的，而《顿河故事》和《静静的顿河》在这方面色彩尤其鲜明。

十月革命胜利后，年轻的苏维埃政权开始确立，但是在十四个帝国主义国家联合国内反革命势力的进攻下，它面临着一系列最严峻的考验。两条道路的斗争，在各种不同的战线上都表现得极其尖锐复杂。革命和反革命力量，正在做着你死我活的决战。这种斗争深入到全国的每个角落，每个家庭。这在哥萨克聚居的地区，也没例外。不但没例外，而且，由于哥萨克的历史条件和剽悍性格，阶级斗争往往表现得格外尖锐，格外激烈。在一个家庭里，父子、兄弟、夫妇往往由于立场不同，产生无法调和的矛盾而成为敌人，甚至于酿成流血事件。在《顿河故事》中，描写这一类家庭冲突来反映尖锐的阶级斗争的，就有好几篇。

在“看瓜田的人”里，父亲当了白军警卫队长，两个儿子却拥护红军。做母亲的因为同情红军俘虏，给他们送些吃的东西，就被丈夫活活打死。大儿子投奔红军，被白军俘虏，落在当白军走狗的父亲手里；做父亲的灭绝人性，亲自押儿子去枪毙，儿子跟其他几个俘虏途中脱逃，父亲又穷追猛赶，非把儿子弄死不肯罢休，最后自己却受到应得的惩罚。在“蛀孔”里，做父亲的和做哥哥的，因为儿子和弟弟同情贫农，就用草叉活活把他戳死。在“漩涡”里，当了白军军官的儿子，亲自下令枪毙打算投奔红军的老父亲和哥哥。

像这一类尖锐的家庭冲突，一方面反映了苏联革命初期阶级斗争的严酷，一方面也显示了哥萨克上层分子的反动本质，和他们垂死挣扎的狰狞面目。

当然，阶级斗争是错综复杂的，除了反映在家庭生活上之外，它还反映在其他各方面。在“死敌”里，为了争夺乡村中的领导权，贫雇农和富农之间就展开了一场血战。贫农叶斐莫不顾富农威胁利诱，始终坚持立场，全心全意保卫革命的利益，最后终于为革命事业流出了最后一滴血。在“道路”里，当了一辈子毡靴匠的福玛老爹，通过实际生活，提高了阶级觉悟，更加认清了敌人的残酷本质，在临难以前慷慨地对儿子说：“不，彼得，他们从我福玛嘴里是逼不出什么来的！……让他们打死我吧，他们这么做可以拿到钱，可是叫我离开从小走过来的道路，那是办不到的。”

在这一类真实而生动的斗争故事里，年轻的作者不仅显示了艺术上的杰出才能，而且表现了鲜明的立场和分明的爱憎。他无情地揭露哥萨克反革命分子的反动本质和灭绝人性的凶恶面目；他热情地歌颂革命者的优秀品质和崇高风度。而且常常用对比的手法，来显示两者之间本质的差别。在“粮食委员”里，作者一方面写出波嘉庚父亲至死不悟的反动根性，一方面就表现了波嘉庚的高贵品质。波嘉庚当了粮食委员，为完成征粮任务，东西奔走，对革命事业忠心耿耿，在危急的关头，为了拯救一个孤儿，情愿把自己的马让给孤儿骑而牺牲了自己的生命。在“希巴洛克的种”里，普通的红军战士希巴洛克，亲手枪毙了混进革命队伍里的女间谍，却千方百计地抚养一个新生的婴儿，表现了对下一代的真挚的爱。

除了革命和反革命两类形象之外，作者还在故事里描写了哥萨克中的一些落后分子。例如“浅蓝的原野”里的扎哈尔老爹，“吃了一辈子老爷的鞭子，就像吃娘的奶一样”，他在老爷面前跪了一辈子，临到孙子长大参加革命被俘之后，他不但自己去向杀人不眨眼的老爷叩头求饶，竟妄想叫孙子也去下跪，可是觉醒了的孙子却狠狠地回答他说：“去吧，到你老爷那儿去，告诉他：扎哈尔老爹跪了一辈子，他儿子也跪了一辈子，可是他的孙子们不愿意再跪了。你就那么去对他说吧！”又如在“有家庭的人”里，满头白发的老船夫，在哥萨克白军的逼迫下，杀死了两个亲生的儿子，以保全其他七个孩子，可是他这种懦怯的错误行为，最后还是免不了受到最严厉的惩罚：儿女的蔑视和良心的折磨。对于这些老一代的哥萨克，年轻的作者始终以严正的态度，揭示他们落后的思想意识给自己带来的苦难，处处表现出“怒其不争”的愤激心情。不过，在划分敌我界线的时候，作者始终立场鲜明，把落后的哥萨克划在人民范畴之内，而把他们跟参加反革命活动的哥萨克上层区别开来。因此，除了“怒其不争”之外，热情的作者对于他们的遭遇也多少流露出“哀其不幸”的感情，这也是很自然的。

在《顿河故事》里，肖洛霍夫一方面忠于他自己写作的信条，不粉饰现实，不回避矛盾，本着高度党性的精神，大胆地写出革命斗争的尖锐性和复杂性；一方面又处处透露出革命乐观主义的精神。例如在“野小鬼”里，天真活泼的米施卡，虽然在生活中遭到不少苦难，特别是父亲被反革命分子所杀害，可是他的立场、他的爱憎已经很鲜明，最后还单独骑马去把红军部队找到，来消灭袭击村庄的匪帮。就是通过这样一个七八岁的孩子，作者也让大家清楚地看出，革命的前途是无限光明的。

《顿河故事》里写的虽然都是三四十年前的旧事，但是今天我们读起来，还是感到惊心动魄。通过这些生动的故事，我们更能了解苏联革命初期阶级斗争的尖锐复杂、世界上第一个社会主义国家建立的艰难困苦，因而也更加珍重社会主义阵营所取得的一切胜利果实。作品里所描写的革命者的高贵品质，反革命分子的狰狞面目，以及落后的哥萨克的懦怯可怜，都从不同的方面教育了读者。此外，通过《顿河故事》，再对照肖洛霍夫以后的作品《静静的顿河》《被开垦的处女地》（《新垦地》）《一个人的遭遇》等，我们可以更全面地了解这位伟大的真正人民作家的创作道路，知道他在文学生活中是怎样雄健地迈出第一步的。

（原载于《读书》，1959年第16期）

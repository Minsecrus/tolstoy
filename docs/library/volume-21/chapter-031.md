# 给有志于文学翻译的青年同志

常常收到青年同志来信，要我谈谈：翻译文学作品要具备哪些条件，怎样才能做好这项工作，我从事文学翻译有些什么“心得”，以及诸如此类的问题。每次收到信，一方面被青年同志的热情所感动，一方面心里却有点惶恐。说实话，我除了译过几本文学作品以外，谈得到有什么“心得”？再说，我自己也做不好这项工作，又怎么能给别人提忠告呢？

但是，看到青年同志的热情和志向，我想，虽然没有什么“心得”可谈，就来谈谈从事文学翻译工作的一些体会和对这项工作的看法。

首先，有人问：文学翻译这项工作难不难？我的看法是也难也不难。什么叫也难也不难呢？就是：做不难，要做得好很难。其实，世界上什么事都是这样的。懂得外国语，会写中国字，把一篇外国文学作品译成汉语，确实并不难。但是，要把它译得像瞿秋白同志译高尔基的《海燕》那么优美，就很不容易。不过，这里主要的问题倒不在于确定难不难，而在于怎样正确对待困难。毛主席教导我们，要在战略上蔑视困难，在战术上重视困难。这是一条颠扑不破的真理，不论做什么工作，都应该抱这样的态度，文学翻译工作当然也不例外。因此，我以为要做好文学翻译工作，首先就要有既蔑视困难又重视困难的态度。蔑视困难，可以鼓舞勇气、加强信心，用革命的气魄去对待工作，克服学习和实践中的各种障碍；重视困难，可以培养毅力，脚踏实地，勤学苦练，用科学的态度去努力做好工作，不会产生轻易求成的侥幸心理。

谈过正确的态度，接着来谈谈跟做好文学翻译工作有关的几个问题，也可以说是几个应该努力的方面。

第一，文学翻译工作必须政治挂帅。文学翻译是文学艺术工作中的一种。大家都知道，文学艺术是上层建筑，是为一定的经济基础服务的，因此，文学翻译也不能例外。在我们社会主义社会里，文艺必须为生产服务，为政治服务，也就是为工人阶级的革命事业服务。不明确这个最基本的道理，做文艺工作一定要犯错误，做文学翻译工作当然也一定要犯错误。文艺工作者必须具备正确的立场，做文学翻译工作也必须具备正确的立场。把外国文学作品介绍过来，目的是为了借鉴，好让我们自己的社会主义文化发展得更快更好。我们一方面不能拒绝借鉴外国的东西，同时也不能迷信外国的东西。介绍外国的文学作品，就不能不有所选择，有所取舍，不能不根据国家的需要，分别轻重缓急，有步骤地做去。“为艺术而艺术”——这是资产阶级文艺的口号，是反动的，表面上要使文艺超脱于政治，其实还是为资产阶级的政治服务。同样的，“为翻译而翻译”——这也是一个错误的观点。脱离政治，闭门翻译，就会把一些对社会主义文化不利的“毒草”原封不动地搬过来。因此，搞文学翻译的先决条件，也像搞其他工作一样，就是必须政治挂帅。我以为有志文学翻译的青年同志，首先必须努力提高政治水平，好好学习马克思列宁主义，培养鉴别文学作品的能力，这样才有可能正确地做好文学翻译工作。

第二，培养祖国语文的使用能力。从事翻译工作，有人以为主要就是要学好外国语，以为懂得外国语就行了。这种看法是片面的，也可以说是错误的。从我自己从事翻译工作上，以及从我看到的一些初学翻译的同志的译稿上，我深深地感到，祖国语文修养的重要性对一个搞翻译的人来说，决不下于外国语文的修养。外国语文的水平不论怎样高，如果没有相当的祖国语文的修养，就不可能做好翻译工作，特别是文学翻译。怎样才能学好祖国的语文呢？毛主席在《反对党八股》这篇文章里指出：“语言这东西，不是随便可以学好的，非下苦功不可。”他还明白地指示我们，要从三方面来学习语言：第一，要向人民群众学习语言；第二，要从外国语言中吸收我们所需要的成分；第三，要学习古人语言中有生命的东西。我以为凡是从事翻译工作的同志，特别是有志于文学翻译的青年同志，必须重视祖国语文的学习，懂得“语言这东西，不是随便可以学好的”，必须长期地下苦功，从不同的方面去学，要多听多读多写，努力培养和提高祖国语文的使用能力。

第三，真正学好外国语文。做翻译，不论口译笔译，也不论译理论文章或者文学作品，一定要学好外国语，这道理谁也明白，不用说得。但是，怎样才算真正学好外国语，却是一个值得研究的问题。常常有人问：学好一种外国语究竟需要几年？这问题很不容易回答，因为各人学习的条件不同，每天所花的时间有多有少，各人的天资也多少有些差别。但是，说实话，要学好一种外国语，是很难速成的。语言是人们交际的工具，这工具必须不断地使用，不断地磨炼，才能锋利，才能有光彩。拿祖国语文来说，一个人从牙牙学语起，到大学毕业为止，学习和使用语文的时间大概总有二十年吧。在这二十年里，他天天听人家说话，天天自己说话，等进了学校以后又差不多天天读书写文章。也就是说，他天天通过听、说、读、写的实践，不断地提高语文的使用能力。但是，我们能不能说，每个大学毕业的人，都真正学好祖国的语文了呢？恐怕不能吧。学习祖国语文尚且要花这么多的工夫，学习外国语文也就可以推想而知了。我说这话，不是要泄正在学习和将要学习外国语的同志的气，而是希望大家能更加体会毛主席的指示：“语言这东西，不是随便可以学好的，非下苦功不可。”有志于文学翻译的同志，特别要理解这个道理，因为一般说来，文学作品是语言的艺术品，词汇特别丰富，成语谚语用得也多，要很好地理解外国作品，非在外国语文上花极大的苦功不可。

第四，注意提高文学修养。要从事文学翻译，光是学好祖国语文和外国语文还不够。上面说过，文学翻译是文学艺术工作中的一种，因此它跟其他翻译工作比起来，有相同的地方，也有不同的地方。相同的地方这里且不去说它，现在来谈谈不同的地方，也就是文学翻译的特点。关于文学翻译，茅盾同志有一段话说得很透彻，我想在这里引用一下：

“文学作品是用语言创造的艺术，我们要求于文学作品的，不单单是事物的概念和情节的记叙，而是在这些以外，更具有能够把读者吸引进去的艺术意境，即通过艺术的形象，使读者对书中人物的思想和行为发生强烈的感情。文学的翻译是用另一种语言工具，把原作的艺术意境传达出来，使读者在读译文的时候能够像读原作时一样得到启发、感动和美的感受。像这样的传达，自然不是单纯技术性的语言外形的变易，而是译者通过原作的语言外形，深切体会了原作者的艺术创造的过程，把握住原作的精神，用另一种语言把它再创造出来。因此文学翻译的工作，就不仅仅是原作语文的改写，而是把原作的内容，在自己的思想、感情、生活体验中找到最适合的印证，同时还必须运用适合于原作风格的文学语言，把原作的内容与形式正确无遗地再现出来。”

文学作品要“具有能够把读者吸引进去的艺术意境”，翻译过来的文学作品，也必须具有这样的艺术意境。一个文学翻译者能不能把原作的艺术意境充分传达出来，这除了祖国语文和外国语文两方面的水平之外，就得看他的文学修养了。而文学修养也需要长时期艰苦的劳动才能取得。有人以为要提高文学修养，只要多看几本文学书就行了。这也是不全面的看法。多看多读古典的和现代的优秀文学作品，是可以提高文学修养，但是对从事文艺工作的人来说，比读书更重要的，是深入生活。没有广博丰富的生活体验，就很难“对书中人物的思想和行为发生强烈的感情”。一个文学翻译者，如果自己不能被原作所感动，他就不能通过译文去感动读者，也就是说，无法把原作的艺术意境充分传达出来。因此，有志于文学翻译的青年同志，一方面要多看多读优秀的文学作品，学习文艺的基本理论，另一方面就要不断地丰富自己的生活体验，与劳动人民打成一片，了解和学习他们的思想感情，增加实际生活的知识，从各方面来提高文学修养。

第五，多做翻译的基本训练。画家学画要经过基本训练，音乐家学唱也要经过基本训练。任何文艺工作（也许不限于文艺工作）都要经过相当时期的基本训练，才能熟练。做翻译工作也是这样。在外语学院学习的同学，有翻译课，就是进行翻译的基本训练的。从事文学翻译，特别需要基本训练。什么是文学翻译的基本训练呢？文学翻译的基本训练从哪里入手呢？我认为，首先就是要从一般的翻译开始。一个人如果不能翻译一篇新闻报道或者一封普通的信件，那就很难想象他能翻译一篇小说或者一首诗。这道理很容易明白，拿作家来做比方吧。如果作家不会写一封普通的信，他还写得成小说或者特写吗？作家开始写小说以前，他一定写过许多其他的文章（包括日记、笔记、通讯等等），而这些一般性的写作，也可以说是作家基本训练中的一部分，而且是极重要的一部分。要做一个文学翻译者，首先必须重视翻译各种不同性质、不同体裁的东西，要学习翻译一些较浅的理论文章，翻译一些新闻报道之类的记叙文，翻译一些信件日记，当然也要翻译一些短小的文学作品，像特写、小品、故事、童话之类。总之，要各种东西都翻译一些，要由浅入深，循序渐进，千万不要一开始就想译一部几十万字的长篇小说或者几千行的长诗，结果事倍功半，吃力不讨好，反而影响做文学翻译工作的信心。

上面几点是我在工作中深切体会到的，也是自己觉得需要不断努力的方面，提出来给青年同志作为参考。我相信，在我们社会主义的条件下，凡是人民所需要的工作都有光明的前途，有志于文学翻译的青年同志，只要能抱正确的态度，勤学苦练，有毅力，有恒心，将来在介绍外国文学的工作上一定能作出贡献。

（原载于《外语教学与翻译》，1959年第10期）

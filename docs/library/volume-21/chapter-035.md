# 草婴同志答本刊[17]记者问

记者（朱剑）：听说您正在新译托尔斯泰的《安娜·卡列尼娜》和《复活》等俄国文学名著，读者很关心，认为您所从事的是一件十分有意义的工作。请问，在艰苦的翻译劳动中，你有什么新的感受？你觉得研究和翻译的关系如何？有人主张，一个翻译家必须同时也是一个研究家。撇开个人，您随便谈谈这个问题可以吗？

草婴：我在1963年订了一个计划，想比较系统地翻译列夫·托尔斯泰的小说，包括三个长篇、自传体三部曲和几十个中短篇小说，字数约四百万，原定1976年完成。可是当我才译出了十多个中短篇小说时，参加“四清”和史无前例的十年就迫使我中断这项工作达十二年之久。粉碎“四人帮”后，不少读者和朋友要我继续这个计划。在各方面的热情鼓励和支持下，我就重新翻译托尔斯泰的作品。现在，《安娜·卡列尼娜》已完稿，正开始翻译《复活》和一些中短篇。我希望在20世纪80年代末能完成全部计划，来报答大家的愿望。

我想，如果在翻译方面也应该“百花齐放”，名著可以有几种不同译本的话，那么，我的翻译也就是在这种思想指导下的一种尝试，我将永远欢迎读者和同行的批评指教。

至于翻译和研究，我认为是有联系的。要翻译文学作品，必须对作者的思想和原作的风格有所了解，这样才能传达原作的艺术特色，尽一个译者的责任。但翻译家和研究家毕竟有所不同，他们的关系我觉得有点像几何学里的交切圆——部分相同，部分不同。一个翻译家除了熟悉作者和原作的思想艺术特点外，还需在语言文字上多下功夫，使译文在一定程度上成为再创造的艺术品。

记者：您觉得要开展世界文学名著翻译、介绍和研究工作，当前在理论上有哪些迫切需要解决或讨论的问题？

草婴：缺乏这方面的研究，没有发言权，请原谅。

（原载于《外国文学研究》，1981年4月2日）

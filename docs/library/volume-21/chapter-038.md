# 文学翻译者的福音

翻译文学作品，经常接触各种宗教词语，有时借助外汉词典，可以解决部分译名，但现有几种外汉词典有些译法不统一，同一词语几种译法，使译者煞费斟酌，难决取舍；有些宗教词语，只有译名而无必要说明，甚至根本阙如。这是文学翻译者的普遍苦恼。

我翻译俄国文学作品，尤其是托尔斯泰作品，接触到的宗教词语特多，主要是东正教，也有部分是天主教。接触最多的是神职人员称呼、教堂礼仪、宗教节日、教义神学、圣经典故，等等。有些词语虽属常见，但一词多义，也不易确定该用哪一义。例如，俄语священник一词，照俄汉大辞典有司祭、教士、牧师、神甫四义。这几个名词在东正教、天主教和耶稣教用法有同有异，“外教”译者不易划清界线，选用合适译名。类似问题不胜枚举。现在有了《宗教词典》，这类问题迎刃而解。又如大斋、小斋、显现节、降临节、净礼、圣事等节日礼仪，我也似懂非懂，要做脚注，更感困难。还有遇到圣经典故，直接查阅《圣经》，也相当费事，往往为一个典故，要翻半天《圣经》。现在通过《宗教词典》，这些问题一举手就可以查到，确实方便得很。

总之，《宗教词典》问世是文学翻译者的一大福音。我相信凡是从事文学翻译工作的同行都会热烈祝贺我国第一部《宗教词典》的出版，而对辞书出版社和《宗教词典》全体编写同志表示衷心的感激。

（原载于《辞书书讯》，1982年8月1日第2期）

# 丰子恺的翻译生涯

丰子恺是一位杰出的画家、作家、美术家和音乐教育家，同时也是一位卓越的翻译家。他在青年时代受五四运动的影响，认为要丰富和发展我国的新文化，必须大量介绍外国文学、音乐、美术作品。因此，丰子恺从青年时代起学习日语、英语，很早就以日语、英语翻译文学作品。他翻译的第一部作品是屠格涅夫的小说《初恋》。《初恋》于1931年4月由开明书店出版，在《译者序》中，丰子恺说：“这稿子是我的文笔生涯的初恋。”这句话很有意思，一方面说明丰子恺的文学生涯是从翻译这部俄国名著开始的，另一方面也证明他对外国文学和翻译工作怀有深厚的感情。

丰子恺一生翻译作品数量很大，范围很广，据初步统计有三十多种，此外他还译过不少美术、音乐、教育等方面的文章。有些翻译文章汇集出书，如《孩子们的音乐》《生活与音乐》《艺术教育》《音乐概论》《艺术概论》《现代艺术十二讲》等。这些艺术方面的译作介绍西方音乐和美术，对20世纪二三十年代的文艺界起过很大影响，作出了很大的贡献。

在20世纪20年代，丰子恺还译过日本厨川白村的著名文艺理论集《苦闷的象征》，列入“文学研究会丛书”，于1925年3月由商务印书馆出版。凑巧的是，鲁迅也在1924年10月将此书译出，交北京未名社列入“未名丛书”于1924年12月出版。事后，1927年11月27日，丰子恺通过陶元庆介绍，到景云里拜访鲁迅。在谈到《苦闷的象征》时，丰子恺对鲁迅说：“早知道你在译，我就不会译了！”鲁迅也说：“早知道你在译，我也不会译了。”《苦闷的象征》的两个译本同时流传，反映了两位翻译大家的不同风格。

解放以后，丰子恺面对新的形势，觉得新中国需要更多更广泛地介绍外来文化。于是，虽已年过半百，决心学习俄语。他以顽强的意志，努力自学俄语。经过两年多的刻苦学习，读了不少俄国文学名著，如托尔斯泰的《战争与和平》，屠格涅夫的《猎人笔记》等，并着手从俄语直接译出《猎人笔记》。随后，丰子恺又与丰一吟合译俄国作家柯罗连科的自传体小说《我的同时代人的故事》。这部小说共四卷，九十余万字，分三册于1957—1964年陆续出版。除了文学作品外，丰子恺还翻译了不少苏联音乐和美术方面的著作，如《中小学图画教学法》《苏联音乐青年》《音乐的基本知识》《幼儿园音乐教学法》《唱歌和音乐》和《西洋美术词典》等。

丰子恺晚年还译了不少日本文学作品，如夏目潄石的《旅宿》，石川琢木的《石川琢木小说集》，德富芦花的《不如归》，中野重治的《肺腑之言》等。

1961年丰子恺应人民文学出版社之约，翻译日本古典小说《源氏物语》。《源氏物语》问世于11世纪初，是日本古典名著，被誉为日本文学的高峰。全书近百万字，用日本古文写成，采取散文和韵文配合形式，又织入近八百首和歌，还广泛运用汉诗文，大量引用《礼记》《战国策》《史记》《汉书》等中国古籍中的史实和典故。因此，翻译这样一部巨著，难度确实是相当大的。假如没有扎实的古典文学基础、渊博的历史知识和功力深厚的语文根柢是很难译好这部作品的。丰子恺凭着他卓越的中文和日文水平，炉火纯青的艺术素养，终于十分出色地完成了这一艰巨任务，向我国广大读者介绍了一宗宝贵的文化财富。

丰子恺译《源氏物语》能取得这样大的成就，不是偶然的。他在这项翻译工作中确实付出了大量的劳动，倾注了无限的热情。有一件事足以说明他当时怎样热衷于这项工作。他在接受这个翻译任务后不久，参加上海市政协组织的参观团去江西各地访问。他在旅途中还念念不忘《源氏物语》的翻译工作。曾戏填《浣溪沙》一首：

饮酒看书回十秋，

功名富贵不须求，

粗茶淡饭岁悠悠。

彩笔昔曾描浊世，

白头今又译“红楼”<sup class="footnote-ref" id="note-ref-18-1"><a href="#note-18" aria-label="查看本页注释 18">[18]</a></sup>，

时人将谓老风流。

丰子恺翻译这部名著，前后花了四年时间，而且始终沉浸在这种艺术的再创作活动中。他在翻译时常常情不自禁地说：“这项翻译工作简直是一种享受”。一个艺术家能陶醉在创作活动中，说明他已真正进入角色，精神上已同艺术融为一体，这是一种很高的境界。一个翻译家能陶醉在翻译这种再创作的活动中，说明他已深入原作所创造的艺术境界，同原作者在思想感情上发生一定的共鸣，甚至融为一体，这样的翻译应该说已达到理想的境界，因此他的译文能如此忠实传神，具有强大的魅力。

在十年动乱中，丰子恺也像不少真正有成就的艺术家那样受尽迫害，他长期的辛勤劳动被诬蔑为反党罪行。但丰子恺作为一个真正热爱祖国、热爱社会主义的有良心的艺术家，既没有屈服于“四人帮”的暴行，也没有丧失对光明重照大地的信心。他在将近十年的“牛棚”生活中，也没有中止为人民服务的艺术生涯。他常常利用清晨批斗前的时间，悄悄地写随笔，画画，译书。特别是翻译工作，他抓得更紧，在1970到1972年间，他又译出了日本古典名著《竹取物语》《莎洼物语》和《伊势物语》。他译完这三部物语，把译稿仔细包封起来，并且说：“将来总有一天能出版！”这句话充分反映了丰子恺对国家前途的信心，也表现了一位艺术家对艺术价值的信心。现在这三部物语已于1984年由人民文学出版社合为一册出书，用名《莎洼物语》，列入“日本文学丛书”。丰子恺先生的预言已经实现，这是可以告慰于丰老在地下之灵的。

1973年丰子恺在“靠边”时重读夏目潄石的作品，特别爱好他的《草枕》（中译名《旅宿》）一文。20世纪50年代，丰子恺已将此文译出，编入《夏目潄石选集》出版。十余年后他重读此文，更加爱不释手。1974年他把此文重新翻译一遍，译毕与自己的旧译对照，在新译稿稿首写上这样的话：“夏目潄石《旅宿》，十余年前译成交人民文学出版社刊行。今重译一遍，各有短长，此稿交治均保留纪念。1975年元旦子恺记。”就在同年9月，丰子恺含冤与世长辞了。

综观丰子恺的文笔生涯，可以说是从初译《初恋》开始，到重译《旅宿》告终。这说明翻译工作在丰子恺的一生中占有很重要的地位。丰子恺重视翻译，决不是仅仅出于个人的兴趣，而主要是出于炽烈的爱国热情，力图多介绍些东西方的优秀文化财富，来促进和繁荣祖国的文化事业，丰富人民的精神生活。今天我们纪念这位卓越的翻译家，就是要学习他严肃认真的工作态度，精益求精修改译稿的作风，不断提高翻译水平，尤其要学习他不畏艰难险阻，踏踏实实为社会主义文化事业鞠躬尽瘁死而后已的精神。

（原载于《上海美术通讯》，第25期，1985年12月15日）

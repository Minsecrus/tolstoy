# 谈谈交叉与体例问题

《辞海》一次次修订，在知识方面、信息方面不断增加、丰富、更新。形式主义、“左”的成分、戴帽减少了，越来越向丰富、健康的方向发展，总的说来是好的。我另一方面感到，20世纪60年代初，浦江饭店集中时，对统一平衡、非常强调——这个学科哪些人物写多少字，大致有个规定。例如作家，一类可以写四五百字，二类少一些，写二三百字。作家和艺术家之间也有平衡问题，不能作家特别多，艺术家特别少。科与科之间，一学科里国与国之间，19世纪、20世纪之间，都有综合平衡、比例恰当的问题。在我的印象里，当时各学科之间联系、讨论、研究商量的机会都比较多，因为集中在一起。现在分头修订，原先的比例关系部分被打破了，其中一部分是合理的，但有相当一部分有些过头了。有些二流、三流的艺术家，写得很长，超过一流专家。这样，人物之间，学科与学科之间的平衡被打破了。同样，外国文学中日本作家二三流，写了四五百字，英国作家一流的，也不过三四百字，反而字数少些。学科与学科之间，国与国之间，时代与时代之间，这方面的综合平衡需要强调，要“一本书主义”。20世纪60年代初，提出要强调“一本书主义”，即《辞海》本身就是一部书，前后、左右之间、各学科之间一定要服从一本书的统一原则，否则各行其是，我愿意多写，就拼命多写；我要少写就少写，对平衡问题注意不够。现在修订情况在发展，一部分老同志，因年岁关系，当初执笔，现在不参加了；新参加的一部分同志可能对编写要求了解得不那么清楚。新写的同志总是从本身出发，我对这位作家了解较多，充分地写，三流作家可写到一流作家的字数。虽然有主编把关，毕竟相当吃力。有些同志写得很长，删掉得很多，他不高兴。其实，删是为了综合平衡，全局考虑，1989年版还得在这方面多做工作。

另一意见，《辞海》体例是统一的，但有些地方过分强调整齐划一，不重视实际情况。外国文学一千多作家，等于给每个人写个小传，是非常浓缩的，一两百个字，三四百个字写出来，等于写简历。每一个作家情况不一，出身怎样，后受什么教育，后干什么，出什么书，有什么见解，有哪些重要作品，得过什么奖金，等等。既然每个作家情况不一样，你不能规定一套死的格式。从要求来说，尽可能照顾到各个方面，但是不可能非常统一。如过分统一，就没有个性了。例如有些可以强调受过什么教育，有些根本没必要；有些参加过政治活动，对他的创作有影响，这可以写；有些没有影响的，则根本不要写。

得过的奖金，文学有诺贝尔奖，这是世界性的。国别性的奖金，西方各国多得很，法国有法国奖，英国有英国奖，日本也有，美国也有，苏联有列宁奖金、斯大林奖金。不能定出一套死的标准，奖金一律不写，或要写都写。有些获了奖，影响非常大，这要写，但并不是说每一个作家得了奖都非常重要，非在《辞海》里交代清楚不可，也不能因为这个作家得了奖没有收，另一个作家也不能收。这种方式过分要求整齐划一，而不是从每个人、每个条目的具体情况出发考虑。实际上这里也有辩证关系，一方面要求整齐划一，有比例；另一方面具体条目由实际内容来决定，对奖金问题，有些要提，有些不提。不能太死板。查辞书是要了解这个人最主要的东西，还得强调实事求是，既要整齐划一，又不能过分死板，规定得太死，并不有利。

（原载于《辞海通讯》，1986年11月5日第5期）

# 爱伦堡的骨气与运气

第二次世界大战后期，纳粹德国面临死亡，希特勒下令要吊死两个人，一个是爱伦堡，一个是卓别林。他痛恨卓别林，因为卓别林在电影《大独裁者》中扮演希特勒，扮得惟妙惟肖，而且竭力加以丑化，气得希特勒咬牙切齿，必欲置之死地而后快。他痛恨爱伦堡，因为爱伦堡在战时写了大量政论，揭露法西斯主义和希特勒的面目，就像一颗颗子弹穿透希特勒的心脏，使他无法忍受。

爱伦堡战时在《真理报》和《红星报》上发表这样的政论，几乎每天一篇，苏联人民和全世界反法西斯者读了都无比痛快，因为爱伦堡说出了他们心中的满腔仇恨，他也就获得崇高的敬意和爱戴。苏联人民有拿旧报纸卷烟吸的习惯，但只要发现报上有爱伦堡的政论，就把它收藏起来，舍不得卷烟烧掉，可见人民对爱伦堡感情之深。

爱伦堡是一个多才多艺的作家，他写政论，写小说，也写诗。他的小说有《巴黎的陷落》《暴风雨》《巨浪》（又译《第九浪》《九级浪》）等。但不论小说或诗，在读者中影响最大的还是政论。

爱伦堡长期居留法国，同西欧知识分子接触很多，又积极参加和平运动，在国际上享有很高的声誉，回苏联后继续从事写作和社会活动，但在苏联有人把他说成“自由派”作家，以别于法捷耶夫、苏尔科夫等正统派作家。

1953年初苏联发生“医生案件”。所谓“医生案件”是斯大林一手炮制的又一个冤案，也是战后他开展大清洗的序幕，矛头直指贝利亚等政治局委员。当时有一批医生以莫须有的罪名被捕，其中有不少犹太人。斯大林一向仇恨犹太人，在这一点上他跟希特勒可说是“同仇敌忾”。他强迫一批犹太著名学者联名写公开信给《真理报》，谴责被诬蔑的犹太医生。爱伦堡是犹太人，在国内外又有影响，当然逃不掉被迫签名这一关。但爱伦堡考虑再三，觉得自己签这个名，就是支持斯大林的暴行，良心上过不去，并成为千古罪人。最后决定直接写一封信给斯大林。信的全文如下：

敬爱的约瑟夫·维萨里昂诺维奇：

我决定打扰您是因为有个问题我自己无法决定，而我又认为它极其重要。

今天明茨和马里宁两位同志让我看了致《真理报》编辑部的信，并建议我签名。我认为同您交流我的疑虑是我的责任，并想听取您的忠告。

我认为在我们社会主义国家里解决犹太人问题的激进办法是完全同化，即属犹太种族的人同他们所居住地区的民族融合。我担心以种族属性联结在一起的苏联文化活动家的联名信只会加强民族主义的趋势。信中使用“犹太人”一词会使民族主义者和不明白并不存在犹太民族的人受到鼓舞。

我特别担心这封《致编辑部的信》将影响和平运动的开展和加强。每当在各种委员会和记者招待会上提出为什么苏联已不存在犹太中学和犹太文报纸时，我总回答战后已无犹太人居住区，犹太种族的新一代苏联公民不愿从他们居住地和民族当中分离出来。公布这封由犹太学者、作家、作曲家签名的信表明他们具有某种共同性，将煽起令人厌恶的反苏宣传……

从进步的法国人、意大利人和英国人以及其他国家的人的观点来看，没有作为一个民族代表的“犹太人”的概念，他们认为“犹太人”是宗教属性的概念，因此诽谤者会利用《致编辑部的信》达到自己卑鄙的目的……

敬爱的约瑟夫·维萨里昂诺维奇，我想您能明白我自己无法解决这些问题，所以才斗胆给您写信……

致以崇高的敬意

伊里亚·爱伦堡

爱伦堡写出这封信后，就在等待专政机关来抓他。他心里明白，斯大林看到信后一定会大发雷霆，决不会放过手无寸铁的爱伦堡，何况在斯大林的极权统治下还不曾有一个人敢于这样“斗胆写信”，公然反对斯大林的“英明决策”。

出人意料的是3月5日苏联向全世界广播：斯大林死了。这条消息从此改变了苏联的历史，而爱伦堡也就逃避了一场生死浩劫。4月4日清晨爱伦堡接到一个友人的电话，说《真理报》发表了有关医生案的消息。消息中说，医生们（总共15个）受到非法控告，他们毫无罪过，他们的供词是“用苏维埃法律所不允许并极严厉地禁止的侦讯方法”获得的。在那条消息后面还有一条简讯：那个不久前由于协助揭发了“穿白衫的凶手”而得到列宁勋章的女医生，她的勋章被收回了。

这则消息使悬在爱伦堡头上的达摩克利斯剑总算移开了。但爱伦堡并不仅仅关心个人的安危，而是深入考虑整个苏联文艺界那种脱离实际、脱离人民群众的僵硬局面，并揭露个人迷信造成的恶果。他写了一篇中篇小说《解冻》在报刊上发表，立刻引起强烈的反响，有人痛骂这篇小说，但成千上万读者积极拥护它。

《解冻》怎么会有这样大的影响呢？《解冻》写的就是1953年3月斯大林去世后苏联所发生的巨大变化。爱伦堡晚年在《回忆录》里写到他用这个题目的用意时说，在乌沙科夫大字典里写道：“解冻是冬季或在冰雪融化的春季到来时的温暖天气。”爱伦堡说：在经受了严冬的考验之后，一株株草儿、未来的蒲公英娇嫩的星形芽儿正在穿透地面，柳树开花了，从各地飞来的鸟儿唧唧地叫个不停；喧闹、不安而又欢乐……还有什么能比这一切更为甜蜜的呢？但晚上的天气还冷，手指还得挨冻。所有这一切正是发生在四月初，在气候转变的那些天里，当时在街道的一侧是寒冷而空虚，冰柱还在原地未动，而在另一侧则是阳光、喧哗、春天。

爱伦堡正是怀着这样的心情来描写这一重大的历史时期的，他也因此获得了更多读者的心。《解冻》确实是苏联历史上一个转型期，也就是“乍暖还寒时分”。这一点在苏联文艺界表现得尤其明显。

1958年10月23日瑞典文学院授予作家帕斯捷尔纳克诺贝尔文学奖。帕斯捷尔纳克写诗，也写小说。他的著名长篇小说《日瓦戈医生》写于1945—1955年。他是第二个获得此奖的俄罗斯作家（第一个是长期侨居国外的蒲宁）。《日瓦戈医生》完稿后，苏联不予发表和出版，结果就由米兰一家意大利出版社出书，而在苏联国内还引发了一场批判帕斯捷尔纳克的运动。当时苏联对帕斯捷尔纳克进行围攻，当局还通过老作家费定要帕斯捷尔纳克拒绝接受此奖，否则就将以叛国行为论处，因为诺贝尔文学奖就是叛徒的奖金。苏联作协还组织批判会，狠批帕斯捷尔纳克。当时，爱伦堡也奉命去参加这种批判会。爱伦堡同帕斯捷尔纳克并无深交，但他对那种围攻深感不平。他吩咐家人，如有电话找他，全都由他自己来接。果然，作协来电请他出席声讨帕斯捷尔纳克的大会，他也不改变自己本来的声音回答说：“爱伦堡外出了，短期内不会回来。”爱伦堡就是这样大无畏地对待这一类不公平事情，再一次显示他作为一个知识分子的良知和品格。

1964年赫鲁晓夫被迫下台。勃列日涅夫上台后，斯大林主义又渐渐抬头，“发达的社会主义”口号掩盖了苏联逐渐走向解体的形势。爱伦堡于1967年病逝，终年76岁。综观爱伦堡的一生，他不愧为一个有良知的知识分子。他经历了几十年风风雨雨，饱览了人世间风云变幻，但作为知识分子，他始终保持一个人的骨气。不在任何压力下低头哈腰，而且敢于冒死向斯大林进言，这一点确实非常难能可贵。至于他斗胆上书反对迫害犹太人又因斯大林突然去世而逃过一劫，只能说是运气，也就是他自己说的：“命大”。

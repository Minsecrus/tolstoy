# 为了文学与和平

——在莫斯科第七届苏联文学作品翻译家国际会晤上的发言

两年前，我曾访问莫斯科、列宁格勒、基辅、明斯克和埃里温等地，凭吊了苏联卫国战争烈士陵，看到了终年熊熊燃烧的长明火，听到了哈丁村<sup class="footnote-ref" id="note-ref-19-1"><a href="#note-19" aria-label="查看本页注释 19">[19]</a></sup>的丧钟，四十多年前的往事像电影般一幕幕浮现在我的眼前，不禁思潮起伏，心情激荡。

我的青少年是在烽火连天的年月度过的。1937年日本军国主义的大炮轰击了中国土地，也把我从平静的少年生活中惊醒过来。我痛苦地看到祖国处在灭亡的边缘，人民过着地狱般的生活。我读了不少书，苦苦思索，希望找到一条救国救民的道路。我看到十月革命给人类带来了曙光和希望，社会主义是唯一的出路。为了更好地了解世界上第一个社会主义国家，同时又因喜爱俄国文学，我从1938年起开始秘密学习俄语。当时上海已被日军控制，学俄语极其困难：既找不到有经验的老师，也没有合适的教科书，连一本俄汉词典都没有。再说，学俄语还有不少麻烦，甚至可能被日本宪兵逮捕。但我不顾各种困难和危险，白天在中学念书，晚上和星期日偷偷自学俄语。这样继续了三年多。

1941年希特勒匪帮对苏联发动血腥战争。不久，上海出版《时代》周刊和《苏联文艺》月刊，向中国读者介绍苏联人民英勇的反法西斯斗争。我开始为这两本刊物翻译战讯以及反映战争的特写和短篇小说。因此可以说，我的翻译生涯是同苏德战争同时开始的。当时我才十八岁，白天在学校念书，晚上在家里翻译，直到苏军攻克柏林，战争结束。我住在远离苏德战线的上海，但可以说，我自始至终参加了这场伟大的反法西斯斗争。我清楚地记得几次重大的战役和战争的全过程。但更重要的是，我明白战争给人类带来的浩劫，深信保卫和平是人类头等大事。

战后我继续翻译俄苏文学，译了三十多部书。在苏联作家中我尤其喜爱肖洛霍夫的作品。我从1953年起译了《新垦地》（旧译《被开垦的处女地》）第一部和第二部、《顿河故事》。1957年初，我在《真理报》上读到《一个人的遭遇》，深受感动，立即把它译成中文。译文发表在《世界文学》和《文艺学习》上，获得普遍好评。后来我又译了《一个人的遭遇》电影文学本。肖洛霍夫作品深受中国读者喜爱，也被中国作家和文艺工作者公认为艺术杰作。作为译者，我也很高兴。但当时做梦也没有想到，“文革”一来，翻译肖洛霍夫作品竟成了“滔天罪行”。我全家为此遭了殃，我自己两次落到死亡边缘。但即使在这样的苦难时刻，我也深信：光明必将战胜黑暗，严冬终会过去，人民将宣告我无罪。

1976年10月，“四人帮”被粉碎，中国人民取得了伟大胜利。在中国共产党第十一届三中全会以后，中国大地上出现了真正的春天。我也像所有文艺工作者那样，享受到工作的自由，感到欢欣鼓舞。我又重新从事自己心爱的工作——翻译俄罗斯文学作品。

在所有俄国作家中，我最喜爱列夫·托尔斯泰。我在青年时代就深受中国伟大作家鲁迅的影响。鲁迅说：“俄国文学是我们的导师和朋友。因为从那里面，看见了被压迫者的善良的灵魂的辛酸与挣扎。”

关于托尔斯泰，鲁迅说过这样的话：“看几页托尔斯泰的书，渐渐觉得我的周围，又远远地包着人类的希望。”（1922年《无题》）鲁迅的话虽短，却包涵着重大的真理。在旧社会，很难保持对人类光明前途的信心，就像在数九隆冬有时很难相信，会有春暖花开的日子。托尔斯泰深刻揭示人民大众在不合理社会里的悲剧，但同时他又给人以信心：真、善、美终将胜利，假、丑、恶决不能在大地上猖狂到底。

我喜爱俄苏文学，尤其热爱托尔斯泰和肖洛霍夫，因此决心向中国人民系统介绍他们的作品。除了上述肖洛霍夫的作品外，我已译出了托尔斯泰的《安娜·卡列尼娜》《复活》和他的几十个中短篇小说，现正在翻译《战争与和平》。我计划翻译《托尔斯泰文集》十二卷和《肖洛霍夫作品集》八卷，目前全部翻译计划已完成一半以上。

有人说，我的计划过于庞大，不是一个人所能胜任的。不过，在有生之年我将尽力而为。我深信把俄苏文学珍品介绍给中国读者，意义重大。

普罗米修斯盗天火，给人类照亮了走向文明之路，自己因此受尽折磨。翻译家有时也会遇到重重困难，甚至惊涛骇浪，但我们应克服困难和障碍，做好自己的工作，以增进各国人民之间的文化交流，加深相互理解，保卫世界和平。

（原载于《文学报》，1987年7月30日）

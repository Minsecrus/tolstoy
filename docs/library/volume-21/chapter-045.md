# 苏联文艺界的新变化

俄语系研究生杨直：目前，苏联文艺界有些什么新的变化，文学与改革的关系如何？

草婴：关于苏联当代改革跟文学艺术的问题，因为这个题目很大，我只能简单讲讲。今年夏天我到苏联去，看了一部电影《悔悟》。影片开始就讲苏联的某个城市市长大人突然去世。市长大人生前是个非常高大的人物。市民们号啕痛哭，哀悼市长的去世。大家把他送到公墓落葬。第二天早晨，忽然发现了市长的尸体被挖出来放在公共场所，靠在一幢房子的墙上。人们看到这具尸体，有的大哭，有的吓得慌张乱跑，有的去叫民警。当人们重新把市长的尸体安葬在墓地后，第三天早晨，这具尸体又在街头出现了。这是谁干的呢？结果发现，这是一位中年妇女。她在夜里把这具尸体挖出来，并抱到街上示众。原来格鲁吉亚有一个风俗习惯，一个人死了，如有人对他刻骨仇恨的话，就要把他的尸体挖出来示众。接着就写这位妇女控诉死者生前的种种罪行。

第二部电影叫做《做一个青年容易吗？》。电影的开始，就是一个青年罪犯被关在监牢里，面向观众，讲他自己犯罪、堕落的经过。他讲的事情全部用电影纪录片的方式进行介绍。

这两部电影，很明显同他们目前的改革事业分不开的。我与两年前到苏联去作比较，感到苏联的改革事业，确实取得了十分显著的进展。在文学艺术领域，用各种不同的方式、手段来表现改革的必要性。

苏联现在处在一个全新的历史时期。这个时期还在总结从十月革命到现在正反两方面的经验、教训。在文艺领域中，一方面揭发对改革不利的消极现象；另一方面是反思，重新审查、评价文艺界几十年来的人、事和作品，以前那些被批判的，被处决的，被清除的，被关押的作家，现在一个个地重新审查，重新作结论。总之，现代苏联文坛思想很活跃。他们敢于说话，敢于写文章，敢于表达自己的意见。最活跃的是话剧，其次是电影、小说和诗歌。话剧《狗心》是个老剧本。作者本人早在20世纪40年代就去世。《狗心》的故事很简单：一位科学家用人的心肝动手术，然后移到一条狗的身上去，这条狗有了人的心肝之后变得既不像狗又不像人。作家借这个东西狠狠地讽刺、挖苦那些没有真才实学的科学家、学者。这样的剧本，以前是绝对不许上演的，现在上演了，大受欢迎，反应非常强烈。

现在他们提出一个公开性，即任何问题都要向人民群众公开出来。过去做错的事一件件加以纠正。苏联报纸杂志的面貌也大不一样了，现在连《真理报》上也可以看到不同的意见，公开地进行争论。这种情况是空前的。

（原载于《文学报》，1988年1月14日）

# 蜡炬成灰泪难干

——悼倪海曙同志

人的一生可以用来工作的时间一般是五十年。有人把一生的时间、精力和智慧全部用在一项工作上，锲而不舍，坚持到底，终于做出卓越的成就。倪海曙同志就是一个突出的例子。他从事文字改革和语文现代化工作，从二十岁起到七十岁去世，正好是五十个春秋。他先后编写了五十多种著作，发表了四百多篇论文，真说得上是著作等身。

我认识海曙同志还是抗战初期，在上海新文字研究会。当时他二十岁，我十五岁。他经常身穿一件黑布长衫，戴一副黑边眼镜。老成持重，沉默寡言，一派学者风度。从那时起，我就把他当作老大哥。他是一位虔诚的拉丁化新文字研究者和推行者，在战时的上海难民收容所做拉丁化新文字扫盲试验，有几万难民参加学习，取得很大成绩。

他在震旦大学学过医，后转复旦中文系，攻读语言学、文字学和音韵学，目的就是要更好地做文改工作。后来上海沦为孤岛，他辍学在家研究文改历史和理论，过着寂寞清贫的书斋生活。那时我常去四川北路他的寓所，看到四壁书架林立，图书琳琅满目，写字台上总是放着一叠叠写好的稿子。处身在国破山河在的苦难年月，忧国忧民是共同的心情，我们无话不谈，但谈得最多的还是文化方面的问题。他也爱好文艺，曾抄录契诃夫的短篇小说，后来还翻译过拉·封丹的寓言，把唐诗改写成白话。他在文艺方面的才华也是很出众的。但海曙同志深受鲁迅和瞿秋白的影响，深感文盲泛滥是民族生死攸关的大问题。不解决这个问题，中国不可能富强。而鲁迅的“将文字交给一切人！”的伟大号召从那时起也就成了他终生奋斗的目标。

抗战胜利后，海曙同志曾在《时代日报》主编《新语文》《方言文学》等副刊，编写了多种语文专著。全国解放后，他更满腔热情地投入文字改革和语文现代化工作，主编《新文字》《语文知识》等刊物，后调中国文字改革委员会，做了更多的贡献。

十年动乱时期，我们音讯不通，但都遭到浩劫。我被隔离斗室，“反省”自己的“罪孽”，有时也不免思念一些老友，包括海曙同志在内。我确实很为他担忧，因为深知他为人刚正不阿，个性极强，“士可杀而不可辱”正是他性格的最好写照。“四人帮”粉碎后，我们在上海重逢，我才知道他因搞文改工作，被流放到贺兰山脚下劳动，被牛车压断腿骨，受尽折磨。他说有几次他实在受不了凌辱，准备豁出一条命去抗争，但一想到一家老少，尤其是他热爱的文改事业，才好不容易克制怒火。不过，他身心遭受的伤害因此也格外惨重。

“文革”后，他继续致力文改工作，还不顾年老多病，不辞辛劳，深入黑龙江和湘西土家族苗族自治州，倡导“注音识字，提前读写”小学语文教学改革实验，写出好几篇有价值的调查报告，受到教育界和语文界的重视。

海曙同志从事语文工作，呕心沥血，五十年如一日。正如他的老师陈望道先生生前所说：“倪海曙为了文改工作是随时都愿意献出生命的。”但正像一切改革事业那样，文改工作也是道路坎坷，阻力重重。海曙同志在工作中也常遇到各种不顺心的事，他终于心力交瘁，于2月27日不治。临终前仍念念不忘文改工作，最后喊了一句“文改万岁！”与世长辞，真可说是蜡炬成灰泪难干！

去年10月，我得知姜椿芳同志和倪海曙同志都得了癌症，心情十分忧虑，就设法弄到几种抗癌新药由我爱人送往北京，满心希望他们能药到病除，恢复健康。没想到椿芳同志和海曙同志还是相继去世，我在三个月里先后失去两位相交半个世纪的挚友，感到无比悲痛。这两个朋友，一个致力于百科全书事业，一个从事文改工作，行业尽管不同，但都把整个生命奉献给造福人民的事业，都一直奋斗到生命的最后一刻，并且遗憾地抛下未完的工作。但千秋功过，历史自有公正评说，人民也不会忘记他们的功绩。而他们的可贵精神也将激励我在有生之年做好应做的工作。

（原载于《新民晚报》，1988年3月25日）

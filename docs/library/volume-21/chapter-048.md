# 普希金铜像下的回忆

最近，列宁格勒一位作家来沪，要到普希金铜像前献花致敬，白桦邀我同去。普希金铜像离我家近在咫尺，我欣然同意。到了铜像前，我给那位作家翻译了基座上的中文，上面刻着三个年份：1937年初建，1947年再建，1987年重建。这三个年份确实意味深长，也勾起我苦涩的回忆。这个铜像最初是由上海苏侨集资建立的，时间正好是抗日战争爆发前半年。“八·一三”后上海沦为孤岛，珍珠港事件后租界也被日军占领，普希金纪念碑遭到浩劫，铜像被日军拿去熔铸枪炮。

1947年春，普希金铜像再建。当时主其事的是塔斯社远东分社社长罗果夫。普希金铜像是由苏联一位雕塑家雕塑的（可惜我已记不清他的姓名），那天的再建仪式简单而庄重，中苏两国有不少人参加，我也躬逢其盛。当时大家心情愉快，觉得灾难已经过去，俄国大诗人神采飞扬的塑像将世世代代屹立在环境幽静的上海街头。

上海解放后，我常陪苏联作家和朋友晋谒普希金像，表达对诗人的敬意，交流两国人民的友谊，当时谁也没有想到普希金铜像还将再一次遭到厄运。在“文革”横扫“封资修”毒草时，外国诗人的铜像没有幸免于难。我不知这一次浩劫究竟发生在什么时候，因为当时我已失去自由，一度同外界隔离，更无法去瞻仰诗人的风采。后来，冲击神州大地的特大风暴终于过去，多灾多难的普希金铜像也终于在1987年重建，普希金又怀着沉思，瞻望着如今变得车水马龙的十字街头。

从普希金铜像，我不由得又想了罗果夫。罗果夫是位汉学家，精通中文，对我国人民感情深厚。他在抗战初期以新闻记者身份来中国，曾去战地采访，也到过延安。后在重庆主持塔斯社工作。1941年在苏德战争爆发后，他来到上海，任塔斯社远东分社社长，创办《时代》杂志，先出俄文版，接着又在姜椿芳等地下党同志协助下出中文版。当时德意日法西斯党徒在上海开展宣传活动，印刊物，办电台，拼命为法西斯侵略战争张目。针对他们的活动，罗果夫凭他的魄力和机智在上海开展一系列宣传工作。他出版《时代》《苏联文艺》等刊物，发行英文《每日战讯》、俄文《新生活报》，还创办苏联呼声电台，用几种语言广播战讯。在成了孤岛的上海，上海市民很难听到第二次世界大战的真实情况，《时代》杂志和苏联呼声电台在这方面就起了重要作用，使大家不受法西斯蒙蔽，从而也增强了对抗战必胜的信念。德意日法西斯分子因此对罗果夫恨之入骨，多方阻挠罗果夫工作，但因碍于当时日苏还维持外交关系，不能公然下令禁止。日本军国主义分子几次写信威胁、恐吓罗果夫，但罗果夫毫不畏惧，工作如旧。最后，日方不惜采用卑劣手段，派人在霞飞路（现淮海中路）嵩山路口向罗果夫所乘汽车开枪，但枪没有打中，罗果夫幸免于难。这次事件后，苏方为罗果夫安全计，把他调离上海。抗战胜利后，罗果夫再度奉派来上海，主持塔斯社工作，直到全国解放。

罗果夫除从事新闻工作外，爱好文学，对中国文学尤其热爱，他曾同姜椿芳和戈宝权同志合编《高尔基研究年刊》《普希金文集》《奥斯特罗夫斯基研究》等重要文集。他曾要我帮助他翻译鲁迅、郭沫若、茅盾等人的作品，后来用俄语出版的有《阿Q正传》《鲁迅文集》、郭沫若的《苏联银行》等书。记得有一次他同我一起翻译鲁迅的《门外文谈》时说：“草婴同志，生命很短促，什么事都得赶紧做。”当时我才二十三四岁，不能完全领会他这句话的含意。随着时间的推移，我越来越感到它的深刻意义，也常常想到罗果夫。

我国解放后，罗果夫回国任苏中友协副会长，主编过《苏中友好》杂志。20世纪50年代他曾随代表团两次来中国。我见到他，只感到他沉默寡言，不像以前那样热情洋溢了。前几年，我两次访苏，都没有机会见到他。只听说他年迈多病，又加老年丧偶，老境寂寞凄凉。前不久，我得知罗果夫病逝，不胜惆怅。我的眼前又浮现出笑声爽朗、体重120多斤的罗果夫的形象。在普希金铜像下，我回忆起四十多年前的往事，仿佛又看到罗果夫生气勃勃地站在揭幕礼上讲话。是的，历史曲折，道路坎坷，但我们不会忘记罗果夫，因为他曾在苦难的年月同我们共过患难，并肩工作过，他是中国人民的真正朋友。

（原载于《联合时报》，1989年5月26日）

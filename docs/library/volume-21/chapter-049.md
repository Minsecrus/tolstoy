# 《文学巨人托尔斯泰》序言

中学是人生的一个重要阶段。中学生开始接触到知识的汪洋大海，思索各种人生问题，感情日趋丰富成熟。他们渴望更多地了解世界，更好地探索历史进程，更有意义地安排自己的一生。从这个意义上说，《中学生文库》确是每个中学生的良师益友。

在外国文学方面，莎士比亚、巴尔扎克和托尔斯泰是三位巨人，他们的作品是三座蕴藏丰富的矿山。挖掘这些矿山，不仅能丰富我们的文学知识，增进我们的艺术素养，而且能启迪我们的思想，陶冶我们的心灵。对中国读者来说，托尔斯泰的作品尤其亲切感人。这是什么缘故？我想，除了无与伦比的艺术天才之外，托尔斯泰所处的环境，他所经历的道路，在不少方面跟我们有共同之处；他这个融东西方文化于一身的大师，在心灵上同我们东方人更接近。

对托尔斯泰的思想和创作，列宁写过几篇文章，作了精辟的分析，归纳起来主要是三个方面：第一，托尔斯泰表达了时代的呼声；第二，托尔斯泰反映了千万人民（主要是农民）的思想和感情；第三，托尔斯泰的作品具有高超的艺术技巧。托尔斯泰的生花妙笔为我们描绘了19世纪沙皇俄国暗无天日的图画；沙皇制度的专横残酷和假仁假义令人发指，而广大农民所受的重重苦难和牛马生活，更使人读了义愤填膺。

托尔斯泰是一位伟大的人道主义者。他爱真理，爱生活，爱人民，爱全人类；他恨虚伪，恨专制制度，恨反动统治，恨一切不公平的行为。就是怀着这样的大爱大恨，他从事创作，揭露黑暗，歌颂光明，控诉罪恶，宣扬人道。

托尔斯泰作品所以能震撼读者的心灵，一方面是他用高超的艺术手腕塑造出一个个有血有肉的人物，入木三分地剖析人物的内心世界；另一方面是他用一颗赤子之心，号召人们热爱真理，热爱生活。

不过，托尔斯泰也是一位充满矛盾的人物，他所生活的时代和环境使他的思想永远处于痛苦的探索之中。要了解托尔斯泰不容易，要真正看懂托尔斯泰的作品也不容易。

章海陵同志从事托尔斯泰研究多年，熟悉托尔斯泰的生平、思想和创作，并有自己独立的见解。我相信，这本《文学巨人托尔斯泰》一定会有助于读者更好地了解托尔斯泰，也有助于更好地阅读他的艺术杰作。

（《文学巨人托尔斯泰》，上海教育出版社1990年1月版）

# 草婴在“杜定宇教授科研教学成果展”上的讲话

非常高兴参加今天这么一个展览会。首先我代表上海翻译家协会向杜定宇教授表示祝贺，对这次展览会的取得成功也是抱着满腔的热望。下面我讲一些自己的感受，同协会没有关系，说明在先。我觉得在今天能看到这么一个展览会应该说是含义比较深刻的。我感觉到像杜定宇教授这样的一个人物在我们文化界艺术界是有他的特殊性的。他的特殊性就是他既搞教学又搞科研，既翻译美术理论又搞戏剧辞典，他可以说在戏剧、美术这两方面都取得了很大的成就。而在这两个方面他又运用了他精通外文和中文的特长，把大量的资料介绍过来。今天的展览会很充分地显示了杜先生三十多年来埋头苦干，做了这么多的事，作为一个同行我感到很高兴。对于我们这些从事文字工作或者说是文化工作的人，我总感觉到在每一个历史时代总是有一些不太健康的、不太正常的现象。譬如说就拿文化工作来说，我看中国历史上或者是最近的多少年来凡是从事文化工作的人，从事文字工作的人绝大部分都是非常寂寞的，得不到应有的重视，得不到应有的肯定。但是中国文化上的可贵之处，就在于尽管寂寞尽管沉闷，尽管各方面待遇都很差，但是还有一批人在默默无闻地埋头工作。我觉得这是我们中国文化界的值得骄傲的地方。尽管今天大家都在讲改革开放，我觉得改革开放是大家谁都拥护的，我们大家都举双手拥护，这点我的感觉特别深刻。因为我去年到美国去了几个月，我跑了十几个城市——主要是探亲——以前我还去过几次苏联，我有个很深的感受，就是如果中国要成为一个现代化的国家，必须大力地进一步地了解世界，另外一方面也要让世界了解中国。我的感受就是我们到现在为止太不了解世界，世界也太不了解我们中国，尽管我们现在电视剧、电影、小说各方面的东西介绍得也不少，但是要真正了解今天的世界，了解今天的世界文化，我看这个距离还是相当大的。反过来要世界了解我们中国，我看这个距离也是挺大的。外国人总的来说对我们中国还是很不理解。我们要解决如何成为现代化国家的问题，我觉得改革开放当然需要，但改革开放要怎样改革开放呢，光是几部汽车，光是几幢高楼大厦，光是卡拉OK，这些都是不够的，我们还得在精神文明这方面做点工作，从文化上做点工作。我感到任何一个国家，任何一个历史时期的社会，如果它是进步的，它是兴旺发达的，是繁荣的话，它必然是大量地吸收外国的文化。这从我们中国的唐朝开始一直到“五四”，一直到现在都是这样。其他外国也同样有这样的情况，日本的明治维新大量地吸收了外来的文化，所以它自己本民族的文化得到高度的发扬，当前的世界也是这么个情况。凡是能更多吸收外来文化的国家它必然是进步必然是发展。反过来如果闭关锁国，拒绝接受外来的文化，这个国家肯定不可能进步。我之所以有这个感受，是觉得像美国这么个国家，尽管它存在很多缺点，很多毛病，但是你不能不承认它在二百多年的时间里面把一片空的土地建设成为现在这么一个国家，其中有很大的一个原因，就是它吸收了全世界好的文化。美国的移民政策在这方面给它帮了很大的忙。一方面它把世界上各种好的文化吸收进来，把好的文化界的科技界的第一流的人才都吸收进来，这样它就可以用比较短的时间把一个国家搞到这么富强的地步。在文明方面达到现在这么一个比较高的水平。反过来我们看一看现在世界上那一些有几千年文明历史的国家，从埃及开始到中东一直到我们亚洲——印度，也包括我们中国在内，几千年搞，搞到现在这个地步，国家还是那么贫穷，文化还是那么单调，甚至于有些还是相当迷信，我们只要看看伊朗、伊拉克这些国家就明白了。所以我作为一个翻译工作者，我也借此机会大声疾呼，就是说我们应该重视外来文化的翻译，外来文化的介绍。没有文化谈不上现代化，没有文化的翻译也根本就不可能有改革开放，所以从这样一个角度来说，我就认为，杜定宇教授搞这么一个展览会，展示了他几十年来埋头苦干的工作成就，这意义就特别重大了。刚才杜宣同志也讲到了，就是像这样的一个活动我们是应该加以鼓励的，应该加以支持的，让更多的人了解。我们作为一个现代的国家，我们天天都在叫要两个文明一起抓，对于真正有文化成就的有文化意义的事情，我们决不能给以冷淡。那么在看这个展览会的时候我也特别有感受，我觉得文化工作本身实际上是一个积累的过程，文化需要积累，几百年几千年的文化积累起来会达到一个高的水平，当然这个积累，包括大量吸收外来的文化。但是文化不能破坏，文化不能革命，我们的文化大革命这个革命已经把我们的文化糟蹋破坏到淋漓尽致的地步了，所以我们今天痛定思痛，应该大家作出一个很明确的结论，就是文化只能创造，只能积累，不能破坏，不能革命，只有这样，我们建设现代化的国家的目标才能够达到。因此今天号召全社会都来重视文化，都来重视文明建设，我觉得是有非常大的意义的。因此不管外面整个社会上现在的风气怎么样，我们并不否定现在的社会怎么样怎么样，但是另外一方面我们作为文化人作为文艺工作者，就有责任也有理由来大力宣扬我们应该做的文化工作，来宣扬我们应该提倡的精神文明。所以看了杜定宇教授这个展览会我确实是有不少的感想。由于限于时间就拉拉杂杂这么说几句，请同志们指正。谢谢。

1993年3月12日

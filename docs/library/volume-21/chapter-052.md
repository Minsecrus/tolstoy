# 文学翻译的困惑

近来有些朋友、同行来访，谈到目前文学翻译情况和个人打算，使我浮想联翩，心情苦涩。

他们多半是中年人或接近老年，有的已年过古稀。其中一部分是大学教师，他们除了努力培养人才之外，业余翻译些文学作品，水平也相当不错。有的毕生从事文学翻译工作，生活上历经风霜雨雪，工作中饱尝甜酸苦辣。大家对当前的文学翻译事业忧心忡忡，感到前途茫茫。他们中也有人想改行，放弃教育工作和文学翻译，去做商业翻译。他们说到目前文学作品的译稿出版困难，有些选题出版社根本不考虑，有些译稿早已完工，也因书店订数奇少，无法开印，不能同读者见面。有位退休老教授多年起早摸黑，挤时间译书，熬得视力极度衰退，几近失明，而译稿也不能“见天日”。有几位译者比较运气，译稿能够出版，但有的出版社“以不变应万变”，紧紧守住新闻出版署多少年前公布的“稿酬暂行规定”，尽管上面早已明确宣布，这种规定不是法律、法规，只是参考性文件，可执行也可不执行。事实上，目前出版社支付的翻译稿酬极不合理，远远不能适应现在的物价。记得20世纪50年代的稿酬是千字十一元，而现在译经典名著的稿酬也只有千字二十一元，四十年里书价涨了多少倍，纸价涨了多少倍，印刷、排工又涨了多少倍，而译者稿酬却只增加了不到一倍，这实在是太不成比例了……

有的同行说到目前有些进出口公司急需翻译，情愿出三五百美元的月薪聘请翻译人才，如果出国去当“口译”，每天也有三五十美元的报酬。面对当前文字翻译的困难，再加上工作上种种不顺心事，他们对自己的前途产生种种想法也就不足为奇了。听着他们这种出自肺腑的“心事”，我不能不感到困惑。做了半个世纪的文学翻译工作，个中甘苦我是有体会的，尤其经过十年“文革”非人的苦难之后。但我对文学翻译工作的信心始终没有动摇，因为看到广大读者热情喜爱优秀的外国文学作品，严肃的文艺工作者也殷切期望能读到更多的外国文学精品，我觉得有责任在有生之年再多译几本好书。当然，各人的情况不同，不能用简单化的方式强求大家作同一选择。暂时摆开文学翻译去搞一阵商业翻译，在当前经济改革的形势下也无可厚非，何况有些外贸工作对促进经济建设还有更直接的作用。这个道理我是明白的，我也很同情那些不得不作出痛苦选择的同行，但我的内心还是很不平静，我总觉得以中国之大，现有的文学翻译力量实在太少，后继乏人已是不容讳言的事实，而少得可怜的现有文学翻译家还有一部分要改行，这景象不能不使人感到悲哀。怎样度过这个非常时期，克服困难，使文学翻译事业能坚持下去，并争取一个较好的前途？这是一个值得思考的问题。但我认为首要的是各有关方面，包括文艺和出版界领导，能重视文学翻译对繁荣文艺和建设精神文明的重要作用，进一步改善外国文学出版状况，坚决改变目前不合理的稿酬办法，遵照新闻出版领导机关的精神，实行版税制和基本稿酬加印数稿酬的不同付酬办法，提高译者收入，保证译者在市场经济的新形势下能得到合理收入，安心工作，继续为文学翻译事业作出贡献。

（原载于《文学报》，1993年2月4日）

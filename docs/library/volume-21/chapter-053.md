# 进历史易　出历史难

——读《中国抗日战争图志》有感

近年来，我自觉已不易被一本书或一出戏所激动，更不易因读了一本书或看了一出戏而思潮起伏，难以平息。这也许是年龄的缘故，也许是因为经历了几十年风风雨雨，感情渐趋平淡，对事物的反应也日益迟钝。然而，读了杨克林、曹红编著的《中国抗日战争图志》，我的心情却久久不能平静，三大卷所包含的几千张图片、大量史料，悲壮激烈，动人心魄，一下子又把我带回到青少年时代。是的，我们这一代人的青少年时期就是在日本军国主义血腥侵略的苦难中度过的，我们目睹了日本鬼子的种种暴行和中国人民遭受的空前浩劫，义愤填膺，立志要为千万死难同胞报仇雪恨。正是出于这种单纯的忧国忧民的感情，我苦苦探索救国救民的道路，读了些书，也做了些事，以勉强宣泄心头的屈辱和悲愤。

八年抗战终于胜利，我也和全国人民一样欢欣若狂，觉得吐了一口恶气，精神上卸掉了镣铐，对国家的前途和人民的幸福第一次有了信心，当然，对战争造成的苦难，特别是一些朋友在抗战中的牺牲还是难以忘怀。但是，时间毕竟是一种可怕的强大力量。原来鲜明的印象逐渐模糊，层出不穷的新事物冲淡了过去的记忆，新的感情掩盖了旧的感情。这看来是一种普遍现象，任何社会任何时代都无法避免。我想，这既是人类的幸福，也是人类的悲哀。不过，重大的历史事件即使在有些人的头脑里会变得淡薄，但毕竟不可能从历史上被一笔勾销。好人好事即使暂时被歪曲，坏人坏事即使能逞强一时，但历史终究会站出来说话，主持公道，还历史以本来面目。朱可夫元帅有一次说：“进历史易，出历史难。”这句话真是意味深长：任何重大的人或事必然会在历史上留下痕迹，但一旦进入历史，你想再从历史上抹掉可就难了。日本军国主义侵略中国就是这样的一个例证。

杨克林、曹红夫妇和他们的文友历尽千辛万苦编著的《中国抗日战争图志》把这一历史事件用图片和文字真实地重现出来，这对千万死难的同胞是至诚的纪念，对经历过这一时期苦难的人们是一大抚慰，而对子孙后代则是一种意义深远的教育。为此我向广大读者郑重推荐这部有价值的好书。

1993年1月于上海

（原载于《解放日报》，1993年3月2日）

# 值得一读的小说

——《生活与命运》

有人说，格罗斯曼（1905—1964年）的长篇小说《生活与命运》是“本世纪真正的《战争与和平》”。这个评语引起我的注意，因为我认为至今还没有一部小说称得上是20世纪的《战争与和平》。一口气读完这部小说，不禁心情激动，思绪万千。小说背景是1942年的斯大林格勒大战，但作者写的远不止这场震惊世界的战役。20世纪上半世纪发生了两次世界大战，不过最酷烈的还是要数希特勒德国和苏联之间的生死搏斗。希特勒出于法西斯的变态虐待狂心理建造史无前例的杀人工厂，利用先进的科学方法屠杀几百万犹太人，还剃去他们的头发，拔下他们的金牙，再把骨灰当作肥料。同时他又驱使千百万德国人入侵欧洲各国，蹂躏平民百姓。另一方面，苏联人民浴血奋战，保卫祖国土地，悲壮动人，可歌可泣，五十年前的这些往事我是比较熟悉的，因为当时我正在翻译苏德战争的电讯稿和战地通信，后来又译了些反映这场战争的小说。然而读了《生活与命运》，我深感自己对这段历史的认识还很肤浅，许多严酷的事实，不论是作战的哪一方，我往往被冠冕堂皇的文告和隐恶扬善的文艺作品所蒙蔽。现在，通过这部小说，知道了不少硝烟掩盖下的内幕，特别是苏联方面错综复杂的内部斗争，感到惊心动魄，引起不少思索，从而也比较理解为什么苏联终于解体。

格罗斯曼这部小说完成于1960年，但直到他1964年去世也没有同读者见面，而当时苏联一位评论家则说：“这部小说要在二百五十年后才能出版。”但历史毕竟比评论家公正，《生活与命运》在1988年就同苏联广大读者见面了，虽然离作者去世已有二十多年。关于这部小说，作者曾严正声明：“里面没有谎言和诽谤，只有真实和对人们的爱。”他还说：“读者的审判确是比任何其他审判更为可怕的审判，这也就是心灵的审判，良心的审判。”读这部小说，我觉得这几句话作者是发自肺腑，凡是真正的作家、艺术家都应把它奉为信条。托尔斯泰在《塞瓦斯托波尔故事》里曾说：“这个故事里的英雄是我全心全意热爱的。我要把他的美尽量完善地表达出来，因为不论过去、现在和将来他永远都是美的。这英雄不是别的，就是真实。”《生活与命运》是不是有资格被称为当代的《战争与和平》我们姑且不论，但格罗斯曼的话则表明他确实是遵守托尔斯泰的教导写作的，因此他的成就也就决非偶然。

《生活与命运》在中国已有几个译本，我读的是翁本泽等译的上海译文出版社1993年的版本。

（原载于《文汇读书周报》，1994年3月12日）

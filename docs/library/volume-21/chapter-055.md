# 纪念我们的同学金培林

1938年秋，我进雷士德初中部念书。当时，抗日战争的烽火正席卷神州大地，每个中国人心中的爱国火焰熊熊燃烧。我们同学大都血气方刚，面对日本军国主义的滔天罪行，眼看国土不断沦丧，同胞惨遭屠杀，更是无法按捺心中的悲愤。我们在课余阅读进步书刊，组织读书会，畅谈救国救民之道，还参加拉丁化新文字研究会等进步组织，结识了一批志同道合的朋友。

我们班里有个同学，叫金培林，跟我同龄。金培林体格强壮，感情热烈，个性耿直，对当时上海孤岛的气氛觉得特别压抑，无法继续安心读书。1940年10月，金培林终于背着家人，秘密奔赴苏北，参加了新四军。当时苏北情况十分复杂，是日伪、国民党和新四军三方势力角逐的地区，斗争格外激烈。金培林到达苏北后就在军部参加宣传工作，改名劳盾。他工作认真踏实，得到领导的充分信任，跟同志相处也十分融洽。

1941年金培林接受一项任务，到上海把一名加拿大记者偷偷领到苏北。他利用在雷士德学到的英语，加上他的勇敢机智，成功地完成了这项任务。他告诉我，要他装扮成一名“仆欧”，陪同这位“外国老板”从上海搭船到苏北，再乘车去新四军军部。他对他学到的英语能“派上用场”，感到十分高兴。也可以说，在同学中他是最早把学到的英语用于爱国工作的。

金培林悄悄离家出走后，他的全家都十分焦急，四处打听他的行踪，也曾来追问我（他去新四军是由我介绍的，但当时不能公开）。后来他的父亲曾去苏北探望，看到儿子在新四军生活、工作很好，比较放心，同时肯定那边抗战工作的意义。

1942年日本鬼子在苏北进行“扫荡”，给新四军造成重大损失，人员伤亡不计其数。一次，金培林工作的报馆受到“扫荡”，报馆全体人员奉命撤离。金培林在撤离时不幸腹部中弹，虽经抢救，终因流血过多，献出了年轻的生命，那时他才十九岁。

金培林牺牲后，他的全家在悲痛之余决心为儿子报仇雪恨。他父亲关闭了开在虹口区多年的五金店，举家移居苏北，支持新四军抗战。他的哥哥金坚是位西医，原在北浙江路海宁路口开了一家私人诊所。弟弟牺牲后，金坚关闭了上海的诊所，带着家人去新四军做军医，也以实际行动参加了抗日战争。

抗战八年，终于胜利，但牺牲惨重。据有关资料记载，中国人民伤亡人数高达三千五百万。炎黄子孙在这场民族浩劫中经历了罄竹难书的苦难，唱出了一曲又一曲惊天地、泣鬼神的悲歌，发扬了我中华民族的浩然正气。

岁月无情，转眼半个多世纪过去了。当年的同学少年经历不同，遭遇各异，但都谱写了自己的生命之歌，为祖国作出了贡献。如今大家都垂垂老矣，但回顾青少年往事，犹历历在目，心潮起伏，难以平静。在这样的时刻，我总要想起金培林，想起他短暂而光辉的一生。我有时想，金培林如果不是过早地献出生命，他后来的生命轨迹将会怎样？……我无法找到答案，但我敢肯定他定会无保留地把自己的聪明才智奉献给他所热爱的祖国，为多灾多难的同胞增添欢乐和幸福。

金培林牺牲已五十二年了，谨以此文慰问他在天之灵。

（原载于《雷士德工学院六十周年校庆纪念》，1994年）

# 草婴访谈录

问：苏联解体，是否会对其文学创作发生影响呢？

答：我一向认为，文学与政治有时有一定联系；但文学不能代替政治，政治更不能代替文学。

中外文学在任何历史阶段里都会出现无数作品。但岁月无情，真正能够“留”下来的作品极少。像中国多少年来，能够耐读的作品也不过是少数的几部名著，国外也是如此。像英国的莎士比亚、法国的巴尔扎克、德国的歌德、俄国的普希金等人的作品，也是有限的。

现在回过来看苏联文学。十月革命之后，苏联涌现了不少好作品。这有两个原因：其一是俄罗斯文学有优良的传统，曾出现过普希金、果戈理、莱蒙托夫、托尔斯泰、契诃夫等大作家，因此苏联文学先天比较充足。另外，十月革命和以后的这段历史，是20世纪历史上最重要的历史时期。因此，在十月革命之后，产生了许多优秀作品和有影响的作家。

1991年苏联解体，苏联人民在对他们所走过来的道路进行了反思的同时，对文学作品也进行了反思。肯定了反映这段历史进程的杰作，像《静静的顿河》《日瓦戈医生》等。但过去比较受重视的作家，如法捷耶夫、西蒙诺夫等，其评价就有所降低。在苏联作家中，现在继续被肯定的还有一定的数量。苏联文学史上曾经辉煌过的四五十位作家，现在看来，大概有三分之一可以留下来吧？！其原因是有些作家的作品还没有很好地反映出苏联人民的思想感情，在文学中过多地搀杂了非艺术的成分，减弱了这些作品的生命力。文学作品在激烈而复杂的变革时期，淘汰率尤其厉害，苏联文学就面临这种状况。

问：翻译工作的创造性体现在哪里？

答：文学翻译是一种特殊的创作工作。“翻译”是艺术的再创造。当一部出色的作品被翻译成另一种文字时，其中就凝聚了翻译家的劳动成果。

翻译家翻译作品，有两种情况，其一是由出版选题决定的；其二是由翻译家自己选择的。傅雷翻译巴尔扎克作品，满涛翻译果戈理的作品，之所以比较成功，是因为原作者和翻译家之间在气质、习惯、语言等诸多方面比较接近。

这些条件决定了翻译家能翻译好某些（部）作品而翻译不好另一种（类）作品。有些出版社并不重视这种情况，其实这一点是极其重要的。一位严肃的翻译家是明白这一点的——就我而言，我仿佛翻译托尔斯泰的作品比较合适；托尔斯泰也是我最崇敬的人物。翻译家与原作者有了心灵上的沟通，原作中传情达意的东西就会较好地表达出来。

问：你是如何看待目前翻译界存在的那种并不景气的现状的？

答：这个问题，并不仅仅是翻译界的问题。凡是处在历史变革时期，整个社会的思潮，整个人民的感情，必定会出现一段相当困惑的阶段。原来的老一套有的被冲垮了，新的东西正在形成之中。目前经商热潮的冲击是最大的冲击，它直接影响了几亿人的工作和生活。许多人因此迷茫起来。回想起我当时走上“翻译道路”时，其背景是日本人打进来了。“反法西斯”高于一切，其他一切的一切都是无足轻重的。人有了明确的目标就朝前走！我相信，目前翻译界的这种现状只是暂时的现象。所以我们要清醒地意识到生产精神产品的重要性——人生于世，你到底要什么？你想赚钱，那就快去经商；你想消闲，那就快去游山玩水……总之，人各有志，而“选择”又充满了人生的时时刻刻。目标明确了，生活就不会迷失方向，人也就不会无所适从了。

我年轻的时候，是边读书边翻译的，条件比较艰苦。像当年翻译莎士比亚作品的朱生豪，就因为贫病交困，32岁就去世了。傅雷的生活也极其清苦，被错划为右派后是靠有关方面每月津贴二百元钱维持生活的。但他们都为中国读者留下了独具风格的翻译作品。

问：评价一部文学作品的标准是什么？

答：放眼世界，能获得诺贝尔文学奖的作品是比较优秀的作品，然而获奖并非是唯一衡量作品优劣的标准。但从评奖也可以反映出东西方文化存在着巨大的差异以及方方面面的复杂因素。

一部文学作品，尤其是长篇小说，能经得起时间的考验必须要具备三个条件：第一是“引人入胜”，第二是“动人心魄”，第三是“发人深省”。这三个条件决定了该作品能使读者读得下去、放不下手，读者在激动之余获得道德的升华。除此之外，还要经过时间的考验。这个时间的概念是几十年、几百年乃至更漫长的岁月。文学艺术最高的审判官是千百万读者。评论家只是读者的代言人，他要讲的，只不过是读者想讲而没有勇气讲、想讲而讲得不够完整的心里话。

（原载于《上海教育报》，1995年5月16日，尊里采访草婴）

# 日本宪兵同姜椿芳“交朋友”

1944年冬，日本宪兵驻沪总队的一名军曹，姓中谷，身穿便服来到长乐路姜椿芳家。中谷说一口俄语，公然提出要同老姜“交朋友”。老姜凭他多年从事地下工作的丰富经验，深知“来者不善，善者不来”，但碍于当时形势，不能不竭力同他周旋。中谷先询问老姜在时代社工作的情况，又打听苏联人在上海有几个电台，事后老姜把经过告诉了当时塔斯社社长施维卓夫（罗果夫因遭日方暗杀，虽幸免于难，但已离开上海，此事以后再谈），施说：“我们没有任何秘密，我们的活动都可以告诉他。”从此以后中谷每隔一两天就去找老姜一次，有时在清晨，老姜尚未起床，有时在深夜，老姜已睡觉，有时老姜一家正在吃饭，中谷还把老姜一家人都拍了照。说是“留作纪念”。

为了表示“友谊”，中谷还给姜家送去一瓶食油、几棵白菜、一些土豆，老姜就以同等代价买了香烟“还礼”。中谷还在老姜家吃过一次饭。有一天，中谷提出请老姜到日本军人俱乐部吃饭，老姜估计这一去可能回不来，就同父母和《时代》同仁作了交待，告了别，毅然赴宴。但日方并不想立刻扣留老姜，还想利用他的关系了解《时代》和塔斯社的情况。敌人为什么不立刻对老姜下毒手，这是同当时整个战争形势分不开的。到了1944年，日本军国主义在太平洋连连失利，希特勒德国在欧洲也节节败退，在这种情况下日本还想维持日苏外交关系以备万一，因此尽管对苏怀恨在心，表面上仍不得不做出“友好”的姿态。老姜经过分析懂得日方这种心态，因此也就继续敷衍中谷，目的则是为了能留在上海继续做自己要做的工作。中谷为了表示对老姜的“友谊”，还请他去看过舞蹈，老姜也就请他看京戏以表示“礼尚往来”。日方除了重点控制姜椿芳的行动外，对《时代》有关人员也采取种种卑劣手段。如《时代》的送报员和排字工人都曾被敌伪机关逮捕、传讯，事后又告诫他们不准把被捕、传讯的事说出去。

1945年4月，苏军已反攻到柏林附近，法西斯德国面临末日，希特勒无可奈何自杀，日本在太平洋的处境也日暮途穷。中谷这时不再去找老姜。姜椿芳和时代同人都忙于自己的工作，准备以实际行动迎接反法西斯斗争的最后胜利。1945年8月8日，苏联对日本宣战，那天早晨上海日本宪兵乘车来到时代社和塔斯社，把姜椿芳和时代同人以及苏联工作人员监禁起来，登记了各人的住址，然后释放，但威胁大家要待在家里，随叫随到。姜椿芳同志看到情况紧急，日方可能对他下毒手，当夜没有回家，第二天一早就乘车去常州老家暂避。那天，中谷果然带了几个日本兵到长乐路找老姜，结果扑了个空，他就对姜师母作了一番威胁，然后离去。几天后日本宣布无条件投降，老姜立即回到上海，带领大家重新开展工作，积极筹备创办《时代日报》，时代社也就进入了一个新的时期。

老姜的勇敢机智和冷静沉着，从这件事上也充分表现出来，但他为人一向极其谦虚，从不拿这事炫耀自己，因此连许多朋友也不知道这段传奇生涯。

（原载于《新民晚报》，1996年7月24日）

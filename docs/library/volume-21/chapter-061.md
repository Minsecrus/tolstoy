# 中学生活杂忆

我的中学时代是在抗日战争中度过的。

1937年夏，日本军国主义对华发动全面侵略战争，当时我才14岁，小学毕业不久。那年12月我随父母从浙江宁波逃难到上海。眼看日本鬼子轰炸中国城乡、强占中国领土、屠杀中国人民、强暴妇女的种种兽行，我这个血气方刚的少年怎么也无法克制满腔怒火和对敌人的刻骨仇恨。我在上海租界努力搜求各种进步书刊，如饥似渴地阅读，试图从中找寻救国救民的道路。我花了8块大洋订购了二十卷的初版《鲁迅全集》，买了斯诺的《西行漫记》、林克多的《苏联见闻录》、邹韬奋的《萍踪寄语》等书籍。同时阅读了许多俄罗斯文学作品。

我在1938年夏考入雷士德工学院附中，那是所开设在上海租界、由英国人创办的学校。学校里的课程大部分用英语教学，教师有一半是英国人。我进这所学校是受家庭的影响。我父亲是西医，但富有爱国思想和人道主义精神。他痛感中国的贫穷落后，受尽外国的欺凌压迫，主张工业救国，因此满心希望儿子能学习工程，将来做个工程师。

学习俄语

在进雷士德附中之前，我因受进步书刊和俄罗斯文学作品影响，很想除了英语之外再学习俄语，以便掌握俄语这一工具，直接阅读俄语书刊，扩大视野，了解苏联社会情况，欣赏俄苏文学作品。当时上海有个别俄侨在报上刊登广告，招收学生学俄语。我就按址找上门去，遇见一位戴深度近视眼镜的中年俄国女教师。她看到一个愣头愣脑的中国少年，感到很惊讶，用生硬的汉语问我要干什么。我告诉她我要学俄语。她仔细向我打量了一下，开门见山地说，她的学费标准是每小时1元银洋。我心里盘算了一下，每月付4元钱我还是能承受的，再多可就不行了，因为当时要学俄语完全是我自己的主意，家里根本不知道，而父亲给我的零花钱是每月5元。这在当时也不能算少。于是我就对她说，我决定每周学习一次。她又问：“只学一次吗？”显然她认为每周学一次太少。但我也不好意思向她坦白，我只能承担一次的学费。她又告诉我课本用哈尔滨出版的《俄文津梁》，《俄文津梁》共四册，从第一册读起。这课本是当时唯一供外国人学俄语的教材，而且只有在霞飞路（今淮海中路）一家俄侨开的书店有卖。我照她的指示买了第一册课本，每周一次上她家学习。当然先从32个字母学起，她教我发音，教我课文，并用简单的汉语给我讲解。开头困难还不太大，我也学得津津有味，方法是她每教一课，我就回家反复诵读课文，直到能背诵为止。

当时我在雷士德初中读书，功课并不繁重，我就利用晚间一部分时间复习俄语，每星期日上午到老师家上一小时课，但接下来困难越来越大，因为除了《俄文津梁》之外，当时中国没有一本《俄汉字典》，也没有一本俄语语法书，而教师又不是正规师范学校毕业的，不懂教学法，她的汉语水平也实在可怜。我渴望有一本字典，帮助我确切理解课文。后来听人说，日文里有一部分汉字多少还能看懂，尽管我从来没有学过日语。我下决心要去买一本《露和辞典》（《俄日辞典》），但这种辞典在上海只有内山书店有卖。内山书店是日本人内山完造开的，在四川北路底，靠近虹口公园。鲁迅先生生前常去那里，同内山老板聊天。我那时住在法租界，从来没有去过四川北路，因为四川北路是日本人控制的地区，到那里去必须经过外白渡桥，而外白渡桥上有日本宪兵站岗，任何人经过他们的岗哨都必须脱帽鞠躬。我一个人不敢去内山书店，幸好高中部的同学梁于藩（他后来做过中国驻联合国大使）知道我的愿望，愿意陪我去内山书店。雷士德工学院和高中部当时都在虹口（初中部则在忆定盘路即今江苏路），他们每天上学都要经过外白渡桥，对日本宪兵的岗哨根本不放在眼里。那天他陪我去四川北路。我们故意不戴帽子，免得在日本人面前脱帽，只在经过桥上时微微点点头。我们终于找到了内山书店。我花了几块钱，买了一本厚厚的《露和辞典》回家。一路上说不出有多高兴，但在经过外白渡桥时心里还是有点忐忑不安。我想万一日本宪兵发现我手里拿着一大本《露和辞典》，他会怎么想。还好我们经过大桥没有遇到麻烦，日本人没有发现这本“危险的书”。

这本《露和辞典》确实给我解决了一些俄语问题，减少了学习上的困难。但日语毕竟不同于汉语，有些俄语生字还是无法查出意思。后来我通过新文室研究会认识了姜椿芳同志（解放后他创办了上海俄文专科学校，也就是现在的上海外国语大学，后来又创办了中国大百科全书出版社）。他是地下党的一位领导人，在哈尔滨学的俄语，俄语水平很好。他看到我这个中学生在努力学习俄语，很感兴趣，就向我了解学习的情况，问我有什么困难，并愿意替我解答问题。他答应每两三星期在另一位地下党员家里同我见面一次，我可以把不懂的问题向他提出，他尽力给我解答。他确实给了我不少帮助，但可惜他太忙，没见面几次就中断了。

组织读书会

在中学时期，除了秘密学俄语外，我还和几个思想一致的同学在学校里开展读书活动。我们除了自己阅读进步书刊外，还在同学中组织读书会，交流读书的心得体会。我们分头购买上海能买到的各种进步书刊，我也把零花钱大部分都用在购买书报上。那时我父亲已支持我课余学俄语，学费也由他支付，但要买书报，钱总是嫌不够，因此我就竭力节省不必要的花费。在中学念书时我基本上不进电影院和剧场，尤其在初中几年。这一方面是为了省钱，另一方面是因为没有什么值得看的电影，不愿把时间浪费在电影院里。

我们在同学中传布进步书刊，范围越来越广，影响也不断扩大。我每天去学校，除了课本外，还要带许多书给同学们传阅。我当时骑自行车上课，后面的书包架上常常缚一大包书，这样我的书包就成了一座流动图书馆。我在班级里一直是班长，跟同学们的关系很好，大家也比较信任我。我的同学后来有的成了工程师、外交官，有的经商，有的做文艺工作。现在老同学碰头，常常谈起中学时的情景，也记得当年阅读书刊的事。前不久遇见一位旅居美国多年的同学，他比我小两岁，他说他记得我在学校里常主动借书给他看，他也不知道为什么，后来才明白我在对他“做工作”。谈到这60年前的旧事，我们不禁相对一笑。

我在初中时还跟几个同学办过一个油印刊物，叫《莽涛》，主要刊登我们写的有关抗日和爱国的文章，后来被初中部主任英国人钮森知道了，他把我叫去，向我了解刊物的内容和目的。他不懂中文，我就随便给他作了解释，说主要是同学们爱好作文，有个园地发表，大家都感到高兴。我还以为他要批评我，甚至禁止我们办刊物，结果他不但没有批评我们，还对我们赞扬了一番。这使我们感到很意外，办刊物的劲道也更足，但没有出几期就停刊了，我也转了学。

在雷士德念书时，我们一律穿蓝布大褂。后来，学校作出规定，学生一律要穿藏青法蓝绒上装和灰色法蓝绒长裤，上装胸口还钉有金色校徽。这种校服很神气，但我们听说做校服的法蓝绒都是日本货，初中部同学就坚持穿蓝布大褂，不穿西式校服。钮森知道了，又把我叫去，问我们为什么不肯穿西式校服。我说我们知道做校服的料子都是日本货，我们不愿买日本货，因此不愿穿西式校服。钮森听了问我，难道没有别国货吗，我回答说没有。他沉默了一阵，没有再说什么，放我走了。这样我们在初中几年里就一直穿蓝布大褂，没有穿过西式校服。

开始翻译工作

1941年6月22日希特勒军队入侵苏联，世界反法西斯斗争全面展开。我那时在高中读书，一面继续学俄语。8月间，姜椿芳同志告诉我他正在创办一本杂志，叫《时代》周刊，内容主要刊登苏联报刊文章，介绍苏联人民反法西斯战争的情况。他说上海找不到懂俄语的人，要我帮他们翻译稿件。我说我没有做过翻译，没有经验。他说不要紧，翻译翻译就会了，翻译好了他还可以替我校阅。这样我就开始在晚上和星期日利用课余时间翻译战地通讯、特写等文稿。《时代》周刊在1941年8月20日创刊，在上海和新四军解放区发行，影响很大，尤其是在日军占领的地区新闻控制很严，老百姓得不到正确的消息，只有通过《时代》才知道反法西斯战争的真相，从而也就增强了抗日战争胜利的信心。后来时代社又创办了《苏联文艺》杂志，专门介绍苏联文艺，发表小说、诗歌、剧本和文艺理论，内容主要也是反映苏联人民反法西斯斗争的，我替《苏联文艺》也译过小说和文章。记得我翻译的第一篇短篇小说是普拉东诺夫的《老人》，刊登在《苏联文艺》第二期，内容是写一位普通苏联老人怎样勇敢地消灭法西斯匪帮。

我读高中的几年正是反法西斯战争最激烈的时期，我一直在课余为《时代》和《苏联文艺》译稿。但这件事在同学中知道的人很少，我留意保密，免得引起麻烦，因为当时上海处在日本人控制下，尽管地下党利用苏联和日本仍保持有外交关系这一特殊情况出版刊物，但日本人还是不放松对《时代》的监视，进行种种破坏活动，为它工作的人也常被盯梢甚至受盘问。我在那几年秘密做翻译工作还好没有遇到麻烦，学校里的功课也还能应付，成绩也不算差，只是不注意运动，健康受到影响，得了肺结核，休息过一些日子。

以上就是我在中学时期经历的几件事，也是由国难临头、法西斯侵略造成的。回顾半个多世纪前的往事，以及当年的一些师友，不胜感慨。但现在还能聊以自慰的是我没有虚度我的青少年时期。

# 无名英雄真功臣

我从1958年起参加《辞海》修订工作，负责外国文学科，接触不少一起工作的人，也认识了一批专家学者，得益不浅。事情过去已有四十多年了，有些人和事在我的记忆中逐渐淡忘，但也有些人和事却始终留在我的脑海里。现在我想谈谈有关石西民同志的一些事。

石西民同志当时是上海市委文教书记，顶头上司就是当年炙手可热的柯庆施，旁边就是“四人帮”的军师张春桥，他处境不易可以想见。石西民受命领导《辞海》的修订工作，前后多年，给大家的印象是认真负责，平易近人，实事求是，尊重知识。

《辞海》是一部百科性包括语词的辞书，修订难度很大，不仅需要各方面的专门人才，充分发挥大家的专业知识，更难的是要抗拒当时相当泛滥的“左”的流毒，尽量按照客观真理来编写条目，使这部工具书更具有使用价值，较少错误。在这方面，我认为石西民同志是起了不容抹煞的正确领导作用的。

《辞海》先后定出“前三性”和“后三性”。前三性是“政治性”、“科学性”、“通俗性”，后三性是“知识性”、“正面性”、“稳定性”。定出“前三性”和“后三性”作为修订《辞海》的标准，其实就是要求大家按照通俗辞书的特点来编写、修订，不要受脱离实际的教条的影响，从而避免了不少谬误。这种修订工作的指导思想我认为是同领导分不开的，而当时代表市委负责《辞海》修订工作的石西民就有够格的学识和修养。

记得20世纪60年代初，我们集中在浦江饭店工作时，石西民经常来浦江同大家一起商讨修订事宜，他总是以十分诚恳和虚心的态度听取大家的意见，有时也讲讲自己的看法。为了表明自己对修订工作的重视，石西民几次说：“我现在就做一件事，就是修订《辞海》。”这话一方面是鼓励大家要充分重视这件事，集中精力做好工作，另一方面也表明在当时夸夸其谈、不切实际的气氛中，像修订《辞海》这样的工作倒是一件利国利民的实事，他愿意倾注全力同大家一起投入。

我还记得当年石西民曾不止一次说：“同志们可以相信，将来《辞海》修订本出版后你们不会在书中找到‘石西民’三个字。”现在回想起这事，我又重新翻阅了几个不同版本的《辞海》，确实没有找到石西民的名字，这引起我不少感想。不知怎的，我忽然想到天安门广场上的人民英雄纪念碑，也想到国外不少地方的无名英雄纪念雕塑和一年四季永不熄灭的长明火。人类在历史的长河中为取得一点点进步不知付出了多少血的代价，而其中只有少数人留下名字，多数人都是默默地献出了生命，让后人多一点文明，多一点幸福。因此，对任何领域的无名英雄我们都应该表示最大的敬意，感激他们无私的奉献。

在《辞海》修订工作中也有许多无名英雄，我们绝对不该忘记他们，而石西民就是其中一位功勋卓越的无名英雄，值得我们永远尊敬和怀念。今天，《辞海》又出了一种新版本，我想，石西民同志地下有知一定也会感到欣慰的。

（原载于《新民晚报》，1999年9月24日）

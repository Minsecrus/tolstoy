# 改革开放更需要外国文学

20世纪中国的变化可以说是空前的，而这必须同中国的具体历史结合起来看。

中国经历了几千年的封建专制统治，渐渐形成了特殊的“国情”。闭关锁国，夜郎自大，关起门来称王称霸，这已成为历代统治阶级的“天经地义”。而老百姓世世代代只能跪倒在金銮殿前，高呼“万岁！万岁！万万岁！”只能享受当奴隶的福分，不敢乱说乱动。

到了20世纪，西方文明不断涌进中国，使国人看到“天朝”之外还有五光十色的大千世界。当然，真有机会出国去实地考察的毕竟是极少数，因此通过各种渠道来了解外面的世界就成为大多数国人的要求。在众多渠道中外国文学是一条极其广阔的途径。正是通过外国文学的介绍（当然后来又增加了电影、电视等手段），大家看到了一个个国家和他们的人民，了解各种不同的风俗习惯，接触到各种思想学说。知道了外面的世界，才能拿它同自己的生活进行比较，才能明白封建病毒在这块神州土地上是多么根深蒂固，才能理解鲁迅痛心疾首地呐喊的“吃人的社会”是怎么一回事。

外国文学在20世纪源源不断地介绍到中国，对中国社会的变革确实起了不可估量的重大作用。尤其自“五·四”以来，凡是有远见卓识的作家都十分重视外国文学。他们从外国文学中汲取营养以提高写作水平，同时又翻译优秀作品来扩大广大读者的视野，丰富人民的精神生活。这方面，最重要的意义，我认为是破除几千年来封建社会愚民政策造成的恶劣影响，使大家渐渐认识人生活在地球上应该占有的地位和可以享受的权利。也就是说，人生下来不是命定得充当某个皇帝的驯服工具，不能有自己的思想，不能有自己的语言，而应该人人都享有做人的基本权利。

改革开放以来，广大人民迫切要求了解世界的真实情况，大家希望彻底消除封建社会的遗毒，跟上世界前进的步伐。在这样的形势下，更多更好地介绍优秀的外国文学就成了当务之急。近年来，在外国文学领域取得了不少可喜的成绩，外国文学工作者默默地进行了辛勤的耕耘，这是有目共睹的。但同时也存在不少问题，有关方面对外国文学工作远远不够关心，更没有从今后发展需要有计划地培养这方面的专门人才。不过，面对一个即将来临的新千年，应该看到我们肩上的担子更加沉重，我们要让更多读者看到我们自己所处的地位，认清世界大势，努力把更多优秀的外国文学作品介绍过来。

（原载于《文学报》，1999年12月30日）

# 人民是地球的主人

今年是世纪之交的一年，按照中国习俗是龙年。回顾过去的20世纪，不胜感慨。联合国秘书长安南说，20世纪是血腥的世纪。我很赞同这一说法。不是吗，20世纪人类发生过多少次大大小小的战争，死了多少人，毁了多少个家庭！光是两次世界大战，伤亡的人数就有几千万。希特勒推行法西斯主义，用杀人工厂的科学办法先后屠杀的犹太人就有六百万；日本军国主义发动侵略战争，光在南京一地就杀害了三十万中国老百姓。但是直到今日，德国还不断出现新的纳粹分子，为希德勒招魂；日本右翼分子还矢口否认南京大屠杀事件。这样血淋淋的事实难道还不能促使人们深思吗？

我是在1941年开始从事翻译工作的，当时刚十八岁，正是出于对法西斯的仇恨，为了揭发其罪行而翻译反法西斯斗争的真实情况。时间过得真快，一转眼六十年过去了。我陆续译了一些作品，动机多半是要歌颂真善美，抨击假恶丑。我的中心思想就是，人民是地球的主人，不能让少数人掌握多数人的命运，每个人生活在地球上都有追求真理的自由，维护真理的自由，坚持真理的自由。不能容许地球上再发生集体屠杀的悲剧，更不能容许人类使用高科技毁灭自己。要做到这一点，我认为必须千方百计呼唤人的良知，必须在任何情况下分清是非，维护真理。作为知识分子，我认为这是我的首要责任。编辑朋友问我龙年有什么打算，要我用几百字来回答这问题，我不知道说什么好。但我想，我已走过了人生的大半路程，今后还将走下去，在我有生之年，我还将大声疾呼：“人民是地球的主人！人民要真正当家作主！”

（原载于《新民晚报》，2000年2月9日）

# 庆祝《上海翻译家》创刊

上海翻译家协会出版会刊《上海翻译家》，要我写几句话。不免想到协会创办的缘起，想到与我们协会关联甚深的一位前辈——中国翻译工作者协会的创办人姜椿芳同志。“文革”期间，他在秦城单身牢房被关了六年零八个月，狱中他反复思考一个问题：中国怎么会发生“文化大革命”这样的悲剧？最后他得出结论：中国长期闭关锁国，与世隔绝，全民文化水平太低，容易受愚弄。他决定一旦出狱要做两件事：一是编纂一部大百科全书，一是组织和培养翻译人才。

全国译协就是由他亲自策划成立的。他还要全国各地也成立译协。上海翻译家协会正是在他亲自直接推动下于1986年3月15日成立的，至今已有十六个年头。上海译协在此期间得到各方面支持，会员人数已达五百，但协会至今没有一份会刊。今天，《上海翻译家》创刊就填补了这个空白，相信椿芳同志地下有知也会感到高兴的。

2000年3月31日

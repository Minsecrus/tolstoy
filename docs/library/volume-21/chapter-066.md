# 纪念托尔斯泰逝世九十周年

托尔斯泰的最后遗作

列夫·托尔斯泰于1910年10月28日以八十二岁高龄离家出走，11月7日得肺炎在阿斯塔波沃车站去世。就在同年9月9日，托尔斯泰收到捷克报纸编辑布尔潘的来信，说他们想出版一套“阅读丛书”，发表有关“社会主义和国民经济”的文章，要求托尔斯泰参加。托尔斯泰欣然同意，动手写作，并几次改动，但直到出走没能完成这篇文章。文章虽然没有完成，但托尔斯泰关于社会主义的想法已比较清楚地陈述出来。这篇文章收在《托尔斯泰全集》第三十八卷。在苏维埃时代极少转载，也没有人提及。在我国也没有见到过中译。苏联解体后，这篇文章才在俄罗斯报刊上被介绍，受到读者的注意，学术界对之尤其重视。有人指出，托尔斯泰早在十月革命前就预见到苏联诞生后的发展道路，最后必然会走向解体。

长期以来，由于受到艻联官方的舆论导向，我们往往把托尔斯泰看成是位天才艺术家，写出了无与伦比的艺术杰作，但同时又是个天真无知的思想家，对社会科学一无所知。其实这是不符合实际情况的。不错，托尔斯泰是一位艺术方面的巨人，但由于他一生勤奋好学，博览群书，他不仅研读大量艺术作品，而且看了许多自然科学和社会科学方面的重要著作。一次他在写给朋友的信中说：“我已读完《资本论》，相信要是参加考试我是考得出的。”的确，托尔斯泰读书一向十分认真，他读书常作眉批，在他的藏书中《资本论》上就有许多眉批。这也说明他不是一般性地阅读，而是边读边思索的。

《论社会主义》一文是他生前最后一篇遗作，俄罗斯学术界把它看作托尔斯泰对社会主义社会的英明预言，应该说不是没有道理的。今年是托尔斯泰逝世九十周年，特译此文以志纪念。

（原载于《文汇读书周报》，2000年10月28日）

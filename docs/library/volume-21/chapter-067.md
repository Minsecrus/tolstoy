# 催人泪下　发人深思

——荐《我家》

遇罗克的弟弟遇罗文写的《我家》，中国社会科学出版社出版，是一本值得每个人尤其是年轻人阅读的好书。一个普通的六口之家的家史生动地反映了20世纪50—70年代中国社会的历史，读了催人泪下，发人深思。父亲是个爱国敬业的留日工程师，1957年被打成“右派”；大儿子遇罗克在“文革”中因反对“血统论”而作为现行反革命被迫献出27岁的生命。从此一家人就过着在血泪中挣扎的日子。坚强的母亲挑起精神和物质的双份重担，苦苦支撑这个残破的家，但她每天上班路过儿子被判死刑的工人体育场，不得不扭过头去，直到去世。这是多么令人痛彻心扉的情景啊！

历史是人类文明发展的反映，也是人类耻辱的记录。谁想歪曲历史，回避历史，掩盖历史的真相，粉饰历史的丑恶，早晚定会受到历史的严正审判。人类只有不断从历史中总结经验教训，避免重蹈犯过的错误，才是前进的明智行为。

（原载于《文汇读书周报》，2001年5月5日）

# 少年凯歌的悲歌

——介绍《少年凯歌》

少年时代的伤痕有时会在人身上终生留下来，而心灵的创伤则更难愈合，有的甚至会一直渗血，隐隐作痛。读完人民文学出版社出版的《少年凯歌》，不禁有这样的感慨。这本字数不多的回忆录，真实、朴素，通过他的青少年岁月，深刻地反映出持续十年亿万人血泪斑斑的悲剧。

“文革”开始时，凯歌在北京一所重点中学念书，他以十四岁的年纪迎接了这场浩劫。他的父母都是电影工作者，正直敬业，一心想为祖国的电影事业尽一份力，但由于强加于父亲的“历史问题”，给全家带来无穷苦难：父亲挨批斗、遭囚禁，家里被抄家。凯歌就读的学校干部子弟很多，他们的遭遇虽各各不同，但都很难逃出肉体的迫害和精神的折磨。就连白发如银的女校长也被剃成阴阳头，站在讲桌上，胸前挂着大牌，接受起来造反的学生种种无礼的审问和拷打。

当时特别使凯歌难忘的是他亲眼目睹老舍临死前的情景。1966年8月24日他无意中在太平湖公园看到这位“人民艺术家”。原来前一天他同北京其他一些作家、戏剧家在文庙内遭到毒打，他也被殴成重伤，额上的血虽有洁白水袖的包裹，仍然涓涓而下。接着他在另外两个地方再遭痛欧。凌晨被送回家中，身上的伤口与单衣相贴连，非用温水不能分离。老舍就是在这种羞辱和折磨下跳进太平湖，“自绝于人民”的。

在首都度过三年“红色恐怖”的岁月后，在“知识青年到农村去接受贫下中农的再教育，很有必要！”的号召下，凯歌又加入二千多万青少年的队伍，背井离乡。他来到万里之外的云南景洪，用锄头和砍刀开山锄草，建立橡胶园，一干又是两年，他再次看到一幕幕人间惨剧：一个十六岁的上海知青砍倒一棵大树，当场被大树活活压死；一个十七岁的北京女青年到农场几月就疯了，据说在她的床下发现一张被撕破了的毛主席像，上面涂满墨迹。她被宣判为现行反革命，从此单独住在风雨无遮的草棚中，不吃食堂的食物，守着仅有的一只木箱。夜里，她开始凄厉地嗥叫，但谁能想到她当时在荒野中曾多次遭到强奸……

陈凯歌就这样带着渗血的心回忆一桩桩令人悲愤欲绝的往事，同时又一次咀嚼自己的青春，探索人生的道路，他“渐渐懂得，艰难和困厄乃是普通中国人的正常生活”，并“渐渐懂得，人性也是植物，需要在美好环护下，才有清香。我们当时的人性，是在泥污里再三被践踏，又被阳光晒枯了的一条裤腰带”。

读了《少年凯歌》这本书，我更懂得陈凯歌是一位具有思想和良知的艺术家，我也相信，在《黄土地》《霸王别姬》等优秀电影之后，他一定会制作出更加震撼人心、发人深思的好片子来。

（原载于《文汇读书周报》，2001年9月29日）

# 《上海翻译家》创刊词

在等待中，在期盼下，由上海翻译家协会主办的《上海翻译家》诞生了。

《上海翻译家》旨在通过译界信息的传送，使广大会员更多地了解译界近况，同时架起上海翻译家协会与中国译协和兄弟译协之间的桥梁；通过译者译著的介绍，加强会员间的联系、促进会员间的交流，展示翻译家的风采。《上海翻译家》将开设“译界人物”、“成果展示”、“翻译论坛”、“译界传真”、“译著征集”、“协会近况”、“会员心语”等栏目。

《上海翻译家》真诚希望得到广大会员的关心，支持和帮助。欢迎大家积极来稿，在翻译园中播下您的种子、展示您的风采。让我们大家一起分享您的成功！分享您的快乐！

会员多一份关心，《上海翻译家》就多一份幸运；会员多一分支持，《上海翻译家》就多一份成功；会员是《上海翻译家》的主人，主人的辛勤耕耘、主人的关爱呵护，《上海翻译家》必将会健康、茁壮地成长！

（原载于《上海翻译家》，2002年4月28日第1期）

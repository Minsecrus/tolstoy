# 《当代英雄》后记

《当代英雄》译成于1964年。两年后“文化大革命”开始，我因翻译肖洛霍夫作品成为重点冲击对象，受批斗，抄家，隔离，家里所有物品、图书、译稿全部被抄走，全家遭殃，我两次处于生死边缘，好不容易才挺过来。十年浩劫过后，抄家物资发还，对我来说，除了图书之外，最宝贵的是未经发表和出版的译稿，其中就包括莱蒙托夫《当代英雄》的全部译稿。

《当代英雄》可以说是劫后余生，因此也就具有特殊意义。《当代英雄》正式出版于1978年，距今已有二十多年了。现在，上海文艺出版社出版《当代英雄》中译本，我为它重见天日后再次同中国读者见面感到欣慰。

书中插图三幅都出自莱蒙托夫之手，从中可以看出莱蒙托夫不仅是位杰出的诗人和作家，而且具有很高的绘画天赋，真正说得上是位多方面的天才。

草婴

2003年3月

（《当代英雄》，上海文艺出版社2003年6月版）

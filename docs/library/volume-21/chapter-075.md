# 岂止一个人的遭遇！

——纪念小说《一个人的遭遇》发表五十周年

1955年12月31日和1956年1月1日的《真理报》发表肖洛霍夫的小说《一个人的遭遇》。一篇不长的小说在报上分两期连载，本来也不奇怪，但上篇放在岁尾、下篇放在年首，占用了两年的大块版面，这可真是史无前例。

当时我从《真理报》上读到这篇小说，当即被它深深感动。我从1941年苏德战争爆发，到1945年战争结束，一直替《时代》周刊和《苏联文艺》月刊翻译有关战争的电讯、通讯、特写和短篇小说，对苏联反法西斯战争的全过程，印象深刻，关于苏联人民的英勇抗敌和壮烈牺牲，脑子里也留下不少难忘的场景。

但是，在读《一个人的遭遇》时，我的内心怎么也无法平静。我立刻把它译成中文，译文很快就在《世界文学》上发表。我在翻译时心情激动，一边擦眼泪，一边停下笔来。书中主人公安德烈·索科洛夫的形象鲜明地浮现在我眼前，他的故事一字一句都打动我的心。苏联人民在卫国战争中的损失粗略估计超过四千万人，因此战后几乎家家餐桌上都留有一个空位子，摆有一副没人动用的餐具。这是一幅多么令人心酸的景象。索科洛夫的遭遇，是当年千百万苏联人的遭遇，具有普遍性。战前他有一个温柔的妻子、一个儿子、两个女儿，有自己的房子，可以说过着美满的生活。德国入侵苏联，索科洛夫参了军，但不久敌机把他的家炸成一片废墟，妻子和两个女儿炸得影踪全无，儿子当时不在家，总算活了下来，而且也参了军。索科洛夫在战争中曾被德军俘虏，受尽折磨。最后他冒险带着德国军官开车逃回自己人一边，才知道家里发生的悲剧。更出乎意外的，就在胜利那一天，儿子也在攻占柏林时牺牲了。没有了亲人，只剩下了他一个人。

作者在小说里写道：“我在远离故乡的德国土地上，埋葬了我那最后的欢乐和希望。儿子的炮兵连鸣着礼炮，给他们的指挥员送葬。我的心里仿佛有样东西断裂了……”索科洛夫通过朋友的帮助，好不容易找到一份司机的工作，并寄住在朋友家里。他无意中遇到一个孤儿，就冒充他的父亲，小孩也以为真是他的亲生爸爸，两人从此相依为命，走他们人生的道路……

故事并不复杂，内容也不算曲折，战争在1945年结束。事情就发生在战后第一年，也就是1946年。那么，肖洛霍夫为什么要到1955年才发表这篇两万多字的小说呢？是他在头脑里反复酝酿迟迟没能定稿，直到十年之后才完成呢？虽然这不是主要原因。大家知道，当年苏联发表文艺作品都要合乎意识形态的标准，否则就不能通过。法捷耶夫写《青年近卫军》就是一个例子。《青年近卫军》初稿早在战时就发表了，但遭到严厉批判，因为书里没有写党的领导，而像青年近卫军这样的组织不应该没有党的领导。后来法捷耶夫在新版时纠正这一严重“错误”，书才得以出版。

战后苏联发表了不少以战争为题材的作品，但都竭力遵守上面的规定。直到1953年斯大林去世后，爱伦堡首先发表了《解冻》，从此苏联文艺界才开始“解冻”，作家先后发表反映生活真实的作品。

肖洛霍夫在这种时候写出《一个人的遭遇》，而《真理报》又用这种特殊的方式加以发表，这就不是偶然的了。1955年，战争结束已经十年，苏联社会的氛围有了显著改变，许多事都作了重新评估，文艺作品也开始注意真实反映生活，抛弃教条主义的条条框框。但在战争时期和战后初期，“不是烈士就是叛徒”那种违反国际惯例的情况在苏联普遍存在，因此在卫国战争中因当过俘虏的苏军惨遭屠杀的不计其数。这样，文艺作品中描写俘虏的题材无形中就成了一大禁区，即使像肖洛霍夫这样的大作家也不能发表这方面的作品，而《一个人的遭遇》要在战争结束之后十年才能见报，也就可以理解了。

肖洛霍夫在这篇小说里，没有英雄，没有烈士，只有普通老百姓。但这样一篇作品的震撼力却是强大的，尤其是它的结尾：

“两个失去亲人的人，两颗被空前强烈的战争风暴抛到异乡的砂子……什么东西在前面等着他们呢？我希望：这个俄罗斯人，这个具有不屈不挠的意志的人，能经受一切，而那个孩子，将在父亲的身边成长，等到他长大了，也能经受一切，并且克服自己路上的各种障碍，如果祖国号召他这样做的话。

“我怀着沉重的忧郁，目送着他们……本来，在我们分别的时候可以平安无事。可是，万尼亚用一双短小的腿连跳带蹦地跑了几步，忽然向我回过头来，挥动一只嫩红的小手。刹那间，仿佛有一只柔软而尖利的爪子抓住了我的心，我慌忙转过脸去。不，在战争几年白了头发、上了年纪的男人，不仅仅在梦中流泪，他们在清醒的时候也会流泪。这时重要的是及时转过脸去。这时最重要的是不要伤害孩子的心，不要让他看到，在你的脸颊上怎样滚动着吝啬而伤心的男人的眼泪……”

肖洛霍夫通过这样一个短篇，首先表现的是一个普通苏联人的悲惨遭遇和坚强性格，控诉法西斯的残酷罪行，但更深一层的意义则是反映人对人的爱，特别是上一代对下一代的爱，而这种爱也就是人道主义精神。这种爱是人类最高的精神境界，而肖洛霍夫长期受到批判也就是在这一点上。当年有人认为《静静的顿河》没有反映阶级观点，主角葛利高里没有投身红军，没有参加革命，根本不是英雄人物，因此自然不能成为全书的主角。但肖洛霍夫从来不为这种文艺理论所左右，始终按照他的观点写作。他要真实地描写生活、塑造人物，表现人对人的爱，也就是人道主义精神。也正因为这个缘故，评论家说他的作品违反阶级观点，是在宣扬“人性论”。

《一个人的遭遇》中文译文发表后，先是得到文艺界的共同赞扬，但到了1960年中苏关系破裂，批判修正主义成为时尚，“文革”一开始江青就公开指名道姓辱骂肖洛霍夫是“苏修文艺鼻祖”，而我也被说成是“肖洛霍夫的吹鼓手、代理人”，受尽迫害。

1965年肖洛霍夫获得诺贝尔文学奖。最近，联合国教科文组织把今年定为肖洛霍夫年。这都说明，肖洛霍夫在世界文坛上的特殊地位，也表明人道主义是人类共同追求的精神财富。

（原载于《文汇报》，2005年10月10日）

# 爱因斯坦年杂感

——写在反法西斯战争胜利六十周年之际

联合国把今年定为爱因斯坦年，我觉得意义深长。今年是反法西斯战争胜利六十周年，在这样的时刻来纪念爱因斯坦，就把人类历史同20世纪最伟大的人物联系起来。我不是自然科学家，对爱因斯坦的科学成就所知甚少，但通过自己走过的道路，深感爱因斯坦对保卫人类文明的贡献是难以估量的。

20世纪30年代，希特勒在德国上台不久，爱因斯坦就一眼看穿他的狼子野心。他在1935年的手稿里就写道：“这个人智力有限，并且不适宜做任何有益的工作，他对于环境和天资比他好的一切人，都妒忌痛恨到极点。他出身中下层阶级，这只不过使他有足够的本阶级的自大狂，甚至去仇视正在为争取比较平等的水平而斗争的工人阶级。但是在一切中间他最憎恨的，还是那同他永远无缘的文化和教育。凭着他的拼死冒险夺取权力的野心，他发现他的一些混乱的和渗透着仇恨的演讲，在那些处境和倾向同他自己相仿佛的人中间，博得了狂热的欢呼。他在街头、在酒店里，找到这种人类的渣滓，并把他们组织在自己周围。这就是他开始他的政治生涯的途径。”爱因斯坦进一步指出：

“但是真正使他取得领袖资格的，是他恶毒地仇视一切外国的东西，特别是歧视一个没有自卫力量的少数民族，那就是德国的犹太人。他们理智上的敏感使他感到不安，于是他就以某种借口，认为这种敏感是非德国的。

“对这两个‘敌人’的不断咒骂，使他赢得了群众的支持，对于这些群众，他许下了要给以光荣凯旋和黄金时代的诺言。他为他自己的目的，狡猾地利用了几个世纪以来德国人对军事训练、命令、盲目服从和残忍的口味。于是他就成了‘元首’。

“他玩弄大战以前人们早已熟悉的、荒唐的、假爱国的漂亮词句来蛊惑人心；同时他进行所谓‘亚利安人’或者‘北欧人’的种族优越性的欺骗宣传，这种优越性是反犹太主义分子为了达到他们阴险的目的而捏造出来的神话。他的混乱而反复无常的人格，使人们不知道他对自己不断叫嚷着的胡言乱语实际上会相信到什么程度。然而那些麋集在他周围的，也就是那些通过纳粹浪潮浮到上层来的，却多半是些冷酷的专事嘲骂的人，他们完全明白他们的无耻手法都是些骗人的勾当。”

瞧，早在第二次世界大战之前，希特勒当上纳粹头子不过两年，爱因斯坦就把他看透，真可说是入木三分，这是何等的预见，何等的眼力！

爱因斯坦对希特勒的揭发，自然逃不过纳粹的耳目。1933年上半年他在比利时逗留了近半年。9月9日因逃避德国特务谋杀，转移到英国。10月17日又到了美国。当年他发表了一篇声明，表示不回德国。他在声明中说：“只要我还能有所选择，我就只想生活在这样的国家里，这个国家中所实行的是：公民自由，宽容，以及在法律面前公民一律平等。公民自由意味着人们有用言语和文字表示其政治信仰的自由；宽容意味着尊重别人的无论哪种可能有的信念。”

爱因斯坦到美国后一方面继续他的物理学研究，一方面高度关心人类的前途。他深切懂得原子能的威力，看到纳粹德国正在全力研制原子弹，并有可能取得成功，他就于1939年8月写信给美国总统罗斯福，要他注意德国正在加紧提取铀元素以制造原子弹。为此爱因斯坦具体提出：

“在政府同那批在美国做链式反应工作的物理学家之间有一种经常接触是可取的。要做到这一点，一个可行的办法是，由您把这任务委托给一位您信得过的人，他不妨以非官方的资格来担任这项工作。他的任务可以包括以下几个方面：

联系政府各部门，经常告诉你们进一步发展的情况，并且提出政府行动的建议，特别要注意为美国取得铀矿供应的问题。

设法加速实验工作。

爱因斯坦最后指出：“我了解到德国实际上已经停止出售由它接管的捷克斯洛伐克铀矿出产的铀。”

罗斯福总统重视爱因斯坦的建议，积极采取措施，终于在1945年8月在广岛和长崎丢下两颗原子弹，决定法西斯主义的彻底失败；使人类摆脱了毁灭的命运。

回顾这一段历史，我个人也有刻骨铭心的记忆。我在1941年十八岁时开始翻译工作。当时上海已在日军控制下，上海地下党利用苏联和日本还有外交关系这一情况，由姜椿芳同志出面同塔斯社秘密商量，在上海开展工作。1941年6月22日德国入侵苏联，同年8月20日《时代》周刊中文版就在上海创办。当年上海懂俄文的只有很少几个人，姜椿芳同志要我也为《时代》翻译电讯、战地通信等稿件。《时代》就利用苏方通讯社和报刊消息，向中国读者介绍苏德战争的情况。这样，不仅上海读者能看到《时代》，解放区和大后方人民也从这本刊物知道反法西斯战争的真相，从而增强抗日战争胜利的信心。从1941年到1945年这四年里我一直参加《时代》的翻译，而从1942年起我又为那年创刊的《苏联文艺》月刊翻译以反法西斯为内容的文艺作品。因此，我对反法西斯战争的全过程至今记忆犹新。

1945年4月底希特勒自杀身亡，5月9日苏军攻占柏林。这样，德意日三个法西斯国家就只剩下一个日本还在亚洲顽抗。8月6日美国在广岛投下第一颗原子弹，8月9日又在长崎投下第二颗原子弹。8月8日苏联向日本宣战。在这样的形势下，日本不得不由天皇出面正式宣布投降。世界反法西斯战争就此取得最后胜利。

1945年那几个月的事件确实影响到人类的命运，尤其是8月份。那时我已正式参加塔斯社，从事翻译工作。记得8月9日那天早晨，我按时到淮海路（旧名霞飞路）常熟路（旧名善钟路）口的淮海公寓（旧名盖斯康公寓）上班。一到办公室，就听同事们说：“不好了，不好了，苏联向日本宣战了！”我和同事们慌忙收拾稿件，准备撤离，但不等我们理好东西，一卡车日本宪兵就先到了。他们在弄堂口布下岗哨，其中日本兵拿着刺刀从楼梯冲上来。我们的办公室在三楼。当时我和两个同事就从三楼后楼梯往上跑，暂时躲在四楼以上的后阳台，直到中午才假扮成居民走出弄堂。几天后，上海的日本军方就停止军事行动，到了十五日日本正式投降。

回顾这段历史，我不由得对爱因斯坦产生崇高的敬意，更加体会到他在20世纪对人类的贡献。

最近，我读了许良英教授等人编写、由辽宁教育出版社出版的《走近爱因斯坦》一书，深受教益，对爱因斯坦的思想和人格有了更多的了解，我觉得这是对爱因斯坦年最好的纪念。我写这篇短文也是受到它的启发，而且这里的引文不少就出自这本书，这里再摘录几段与读者共享。

1952年爱因斯坦在给日本《改造》杂志的声明中指出：

“在原子弹的制造方面，我所参与的就只一件事：我签署了一封给罗斯福总统的信。信中强调有必要进行大规模的实验，来实现原子弹的制造。

“我完全明白，如果这些实验证明是成功了，那该是威胁人类的可怕的危险。可是我却感到非采取这一步骤不可，因为德国人很可能也会抱着完全成功的希望在同一问题上进行工作。

“我认为，在战争中杀人并不比通常的谋杀更好些……”爱因斯坦在谴责战争的罪恶之外同时指出，“由百折不挠的信念所支持的人的意志，比那些似乎是无敌的物质力量有更强大的威力。”

爱因斯坦到了晚年，他对自己提出更高的要求：“在长期生活中，我把我的全部精力都用在追求对物理实在的结构稍微深入一点的了解。我从来没有做过系统努力去改善人类的命运，去同不义和暴政作斗争，或者去改进人类关系的传统形式。我所做的仅仅是：在长时期内，我对社会上那些我认为是非常恶劣的和不幸的情况公开发表了意见；对它们保持沉默，就会使我觉得是在犯同谋罪。”

爱因斯坦一生对人类作出那么大的贡献，对法西斯主义的灭亡起了无人可以代替的作用，到了晚年对社会的种种不义，竟觉得如果沉默自己就成了帮凶，犯了同谋罪。这种崇高的精神境界在科学界没有第二个人，在全世界也没有第二个人。因此，联合国定今年为爱因斯坦年真是再确当不过了。说真的，我们每个人从爱因斯坦身上又能感受到多少非凡的人格魅力！

（原载于《文汇报》，2005年8月8日）

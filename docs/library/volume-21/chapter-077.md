# 苦难与坚强

——《一个人的遭遇》给我的启示

半个世纪前，肖洛霍夫发表的小说《一个人的遭遇》，我擦着眼泪把它译成中文，发表在《世界文学》上，得到读者的好评。这篇小说怎么会产生这样深远的影响？我认为它首先写出了人的苦难与坚强。一个汽车司机在法西斯侵略战争中家破人亡，心灵饱受创伤。原来美满的家庭，最后只剩下他一个孤老头子。但他没有完全消沉，他遇到一个战争孤儿，就谎称是他的父亲，用全部父爱来抚育他，温暖他那颗稚嫩的心。

肖洛霍夫以人道主义精神和高超的艺术手法，描绘出战争给人造成的深重苦难，同时又塑造了一个普通人在苦难中所展示的坚强性格。

我觉得，苦难是历史造成的，谁碰上了也无法逃避，但重要的是要有坚强的性格，能面对任何苦难。文艺作品在这方面应该起积极作用，这也是作家对读者的责任。

肖洛霍夫在结束这篇小说时写道：“不，在战争几年中白了头发、上了年纪的男人，不仅仅在梦中流泪；他们在清醒的时候也会流泪。这时重要的是能及时转过脸去。这时最重要的是不要伤害孩子的心，不要让他看到，在你的脸颊上怎样滚动着吝啬而伤心的男人的眼泪……”

（原载于《新民晚报》，2006年5月14日）

# 那高邈的天空

参加书展签名活动，遇到王选<sup class="footnote-ref" id="note-ref-20-1"><a href="#note-20" aria-label="查看本页注释 20">[20]</a></sup>女士，十分高兴。王选是我心中有胆有识的人物，通过接触更增加了对她的理解。她谈到她读过的《战争与和平》中的一个情节，安德烈负伤躺在战场上，他头上什么也没有，只有高高的天空，虽不清澈，但极其高远，上面缓缓地飘着几片灰云。他心里想：“多么宁静、多么安详、多么庄严，一点不像我那样奔跑。不像我们那样奔跑、叫嚷、搏斗……我以前怎么没见过这高邈的天空？如今我终于看见它了，我是多么幸福！”

人人头上都有一片天，王选头上也有一片天。尽管她不像安德烈那样负伤躺在战场上，她却也有像安德烈那样的感受。应该说，她也是伤痕累累，虽不是身上的，而是心灵上的，但心灵的伤痕往往比身体的伤痕更深入骨髓，痛彻心肺。王选仰望蓝天，她一定也看到一个高邈的天空。她在同我短暂的接触中，没谈别的，只谈安德烈负伤这一场景，这使我特别感动。她长期为细菌战受害者出入异国法庭，慷慨陈词，几经挫折，百折不挠。

我们知道，日本从1931年到1945年投降，前后十四年对华侵略，践踏了大半个中国，占领过930余座城市，造成4200万难民无家可归，3500多万人伤亡……而实际受到日军摧残的更远不止这些，如被掠往日本的劳工就有四万多名，其中近七千人死在日本；遭到蹂躏的中国“慰安妇”更不计其数。而由王选女士率领起诉的日军生化武器案也是其中的血腥案例。

我想，托尔斯泰通过塑造安德烈这一人物的悲壮遭遇，就是在启发人们注视那高邈的天空，升华人们的精神境界，关怀人们的苦难和不幸。我们每个人在历史的暴风雨中都可能受到不同程度的折磨，但我们任何时候都不应忽视头上那高邈的天空，永远关怀大地上人们的苦难与伤痛。只有这样的人，才会在需要的时候发出愤怒的控诉，以争取正义与真理在人间的凯旋。

（原载于《文汇报》，2006年9月22日）

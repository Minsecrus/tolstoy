# 勇敢者的凯歌

——为吴钧陶《留影》作序

一个人从少年时期起在病榻上卧了六年，身上有好几处地方一直流脓流血，骨骼畸形，动了好几次大手术，但终于克服了一次又一次的磨难，站立起来，这是人世间少见的奇迹。吴钧陶就是这样一个令人感动的人。

我认识吴钧陶已有几十年了，尽管我原来也知道他曾长期患病，身体有点残疾，行动不很方便，但我绝没有想到他在青少年时期竟遭遇过这样的苦难！

读了这部反映他青少年时期同疾病斗争的经历，我这个虽然也从小多病、中年也遭遇许多苦难的人，也不能不感到震惊。读了他这本回忆录，我懂得了什么叫苦难，什么叫折磨，什么叫坎坷，同时我也更深切地领会到什么是真正的坚强，什么是真正的乐观，什么是真正的毅力。

我们生活在这个世界上，生活在这个历史时期，精神上的感受总是波澜起伏，难以言说。我们眼看着一个个原本朝气蓬勃的生命在各种暴风雨下惨遭冲击，有的就此消失，有的怀着一颗破碎的心灵勉强存活，而要真正保持健康的心态，不屈服，不气馁，顽强地同命运进行搏斗，那是极少数。

也因为这个缘故，那些能顽强与命运搏斗的人的生动经历，就特别具有激励人的力量，值得后人学习。吴钧陶在青少年时期尽管受到重重磨难，但以后他还是在编辑、翻译各方面做了大量工作，他以后的道路也并不平坦，但他始终能勇敢面对，积极生活。他在夫人伴奏下常在各种场合引吭高歌，引人入胜，使人受到鼓舞。

我认为他唱的是生命的凯歌，是勇敢者心灵的呼声，给人们带来无穷力量。我衷心希望他的光辉榜样将继续增加我们的信心，使这个世界多一些阳光，少一些阴雨。

（原载于《老年作家》，2007年总第3期）

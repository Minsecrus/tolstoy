# 熔铸中西　海纳百川

大概二十多年前，作为上海市人大代表，我与罗竹风、杜宣等在人代会上呼吁：经济滑坡是有形的，精神文化上的滑坡却是无形的，它所酿成的隐患，可能会影响几代人。中国文化重地，也是海派文化的发源地——上海，正在“水土流失”。几年前，有媒体记者采访我时问道：现在有没有什么东西让您比较担心的？我告诉他：我比较担心的，就是现在不少人比较浅薄，过分追求个人利益。

我常常想，要改善人们的生活，物质建设固然重要，但更重要的是提高人的精神。没有高尚的情操，物质条件只会培养人的贪欲。要提高人的精神风貌，需要做大量的工作，而优美的文艺作品，则能在这方面起重大作用。

我从事俄罗斯文学翻译几十年，就是因为俄罗斯文学中的人道主义、苦难意识，对人的精神世界细致而深刻的探索以及现实主义的表现手法，滋育了中国文学。严肃的文学，应该真实反映广大人民的生活；有良知的作家，就应该表达人民的思想感情，尤其是人民的苦难。俄罗斯文学的视野和俄罗斯的土地一样，比较广阔，它思考的不是一时一地、一个家庭的问题，而是整个民族乃至人类的精神向度。这样一种传统对海派文化很具有借鉴意义。

“五四”以来，上海拥有一批以鲁迅、巴金等为代表的文学翻译家。文学翻译成为上海文化发展中不可或缺的一部分。世界上各种不同样式的艺术模式所具有的不同味质的养分，对我们都是极有益处的。今天，上海亟需培养一批年轻的文学翻译家。因为译介外国的文学作品，只有本国人用本国的语言才最合适。每个民族都有自己的表达习惯，外语与汉语不仅仅是文字不同，它们的语法、句式也不一样。列夫·托尔斯泰的作品，如果由俄罗斯人翻译成中文，我们阅读起来就会很不适应。

现在上海有了这本弘扬海派文化的中英双语的《红蔓》杂志，这对于介绍外来文化，并把海派文化传播出去，无疑起到了推动作用。我很希望它以后能刊登一些翻译作品，为繁荣上海文学翻译做点贡献。

熔铸中西，海纳百川。上海历来有包容、吸收各种外来优秀文化的传统，在繁荣海派文化的过程中，上海的文学翻译工作者任重道远、大有可为。

（原载于《红蔓》，2015年5月刊）

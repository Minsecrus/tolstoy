# 在苏联塔斯社上海分社的岁月

1941年，在中共地下党员姜椿芳的指引下，我加入了苏联塔斯社上海分社，为世界反法西斯和中国抗日战争奉献自己的青春和年华，这段经历至今难以忘怀。能够参加反法西斯斗争，缘于我学习俄文。1937年抗日战争爆发，我随全家从宁波逃难到上海，那时我怀着忧国忧民的情怀，读了许多介绍苏联的书籍，如《萍踪寄语》、《苏联见闻录》等，开始对十月革命后发生的一系列事情感到新奇。为了能够直接阅读俄文报刊，我决心学习俄语。老师是位俄国侨民。

一个很偶然的机会，我参加了“拉丁化新文字研究会”。在研究会里，认识了一位名叫贺一青的先生。后来我才知道贺先生的真名叫姜椿芳，是中共地下党员。姜椿芳同志早年学过俄语，就主动问我：“学俄语有困难吗？”我回答他说：“困难很多，老师不懂中文，课文很难理解。”于是，姜椿芳让我每隔三四个星期到宁波路一个地下党员家里去一次，在那里姜椿芳为我逐一解答遇到的难题。这样的学习坚持了一年多。

1941年6月22日，德国法西斯入侵苏联，苏联开始了卫国战争。8月20日，苏联塔斯社上海分社创办了中文《时代》周刊，姜椿芳同志出任《时代》周刊负责人。当时在上海懂俄语的人很少，总共只有三四人。姜椿芳同志吸收我参加《时代》周刊的工作，那年我只有18岁。在姜椿芳同志的指导下，我利用晚上和星期天偷偷在家翻译有关反法西斯战争的战讯、通讯报道、战地特写、特稿等。《时代》周刊出版以后，在全国影响很大，不光上海人民而且全国人民，其中包括解放区、大后方的人民都是通过这份刊物了解反法西斯战争的真实情况的。1942年塔斯社上海分社又创办了《苏联文艺》杂志，我又开始为杂志翻译苏联文学作品，第一篇译作是普拉多诺夫的短篇小说《老人》，发表在第二期的《苏联文艺》上。

1945年，世界格局发生了较大的变化，4月30日希特勒自杀，5月9日德国投降。也就在这个月我正式到塔斯社上海分社工作，被聘为《时代》周刊编辑。8月6日，美国在日本广岛扔下第一颗原子弹；8月8日，苏联正式向日本宣战；8月9日美国在日本长崎扔下第二颗原子弹。

就在8月9日那天，我去塔斯社上海分社上班，分社位于现在淮海中路常熟路口的淮海公寓三楼。早上8点，我一到办公室，因为获悉苏联向日本宣战的消息，我和我的同事们都感到大事不好，日本兵会来报复，于是赶紧收拾文件、稿件，准备撤退。不到半小时，一卡车日本兵就把淮海公寓层层包围住了。当时我在后阳台上看到了日本兵，已经没有地方可跑了，我和另一个同事急中生智，从后楼梯跑上四楼，在那里躲了三个小时，直到中午才装作楼里的居民大模大样地从楼上走下来，一出淮海公寓弄堂，我们就飞一般地往家里跑了。后来得知，日本兵抓了两个苏联同志。

一个星期以后，即8月15日，日本由天皇出面宣布投降。世界反法西斯战争至此宣告结束。我又回到塔斯社上班，一直工作到1951年。

由于在塔斯社工作，每天翻译反法西斯战争的战讯、通讯报道、战地特写的缘故，我对整个反法西斯战争的战况和发展了解得一清二楚，因此有朋友开玩笑地说我是“二战老兵”。

（原载于《世纪》，2015年10月）

# 附记

2016年

10月24日，草婴先生逝世一周年。11月17日下午，上海市文联、上海翻译家协会举办“译笔求道路漫漫——草婴与俄罗斯文学翻译”研讨会。俄罗斯联邦驻沪副总领事列·伊·伊格纳坚科，上海市文联党组成员、专职副主席沈文忠，上海翻译家协会老会长夏仲翼，资深翻译家冯春、葛崇岳、裘因、杨伟民、陈建华，众多翻译、出版界的专家学者，草婴先生家属、生前好友等近百位嘉宾齐聚一堂，以简朴和学术的方式，共同缅怀这位为中国文学翻译事业作出杰出贡献的前辈大师，感怀他的业绩、品格和风范。

1990年，时任上海市政协委员的草婴先生与多名市人大代表、市政协委员联名呼请：在宋庆龄陵园内东南面建设一家儿童活动的专门场所。经多方努力，1996年5月29日，上海儿童博物馆诞生。

11月初，经事先见面沟通，草婴家人来到拟闭馆改陈的上海儿童博物馆参观，与馆方就辟建一处集展示和互动为一体的阅读主题空间，以纪念缅怀草婴先生达成共识。草婴家人捐赠草婴先生的手稿、眼镜、钢笔等四十五件珍贵物品，用于陈列布展。

12月30日，草婴书房公众号，由布洛奇卡工作室线上运营。次年6月8日，“草婴书房”进校园，盛天民向上海外国语大学附属中学俄语班学生赠送一批草婴译《托尔斯泰短篇小说集》。

2017年

2月22日，上海儿童博物馆重新开馆，“草婴书屋”正式对外开放。紧扣儿童受众的认知需要，主题空间设计“草婴与上海儿童博物馆之缘”、“草婴的朋友圈”、“草婴的求学时代”、“翻译手卡”、“《诺言》故事会”五个板块，采用实物互动和情景还原等“可视化”手段，巧妙架起适龄儿童与大家草婴关于信仰、兴趣、态度等方面的“对话桥梁”。

4月，三卷本《中国翻译家研究》由上海外语教育出版社出版，“草婴篇”列入“当代卷”。

12月15日，草婴文学翻译奖、草婴外国文学教育基金在上海外国语大学俄罗斯东欧中亚学院设立。

2018年

1月1日，草婴纪念集《疾风知劲草》由上海文艺出版社出版，盛天民主编。

3月28日上午，《草婴》特别展系列活动在宁波市宁波帮博物馆开幕，旨在纪念缅怀先生，感召大家通过阅读经典的文学作品，抛弃浮躁，回归本真，践行草婴先生所彰显的对事业的执着，对生命的珍视。草婴长子盛元良、女儿盛姗姗出席。盛姗姗将两件珍贵的草婴手稿捐赠予宁波帮博物馆。

特别展以“少年草婴”、“译笔求道”、“一生的坚守”三个部分，展示了草婴翻译托尔斯泰小说全集的珍贵手稿、生前使用过的物品、来往信函等等，令公众全面了解这位杰出文学翻译巨匠的人文情怀和对事业的执着追求。展览还在宁波书城等地进行了流动展览推送。

开幕式后，还举办了“译笔求道——草婴与俄罗斯文学翻译”读书沙龙。

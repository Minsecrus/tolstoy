# 马克思致恩格斯

曼彻斯特



1867年8月16日凌晨两点［于伦敦］



亲爱的弗雷德：



这本书的最后一个印张（第49印张）刚刚校完。用小号字排印的附录《价值形式》占了1(1/4)个印张。



序言也已于昨日校完并寄回。这样，这一卷就完成了。这本书能够完成，完全要归功于你！没有你为我作的牺牲，我是不可能完成这三卷书的繁重工作的。我满怀感激的心情拥抱你！



附上两个印张的清样。



15英镑已收到，非常感谢。



我的亲爱的、忠实的朋友，祝好！



你的 卡·马克思



等书出版以后，我才需要索回清样。

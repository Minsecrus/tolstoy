# 第14封：恩格斯致马克思

1847年



布鲁塞尔



1847年1月15日星期五［于巴黎］



亲爱的马克思：



……你用法文写东西驳斥蒲鲁东，这很好。但愿在这封信到达的时候，这本小册子 已经完成。不言而喻，我完全同意你从我们的书 中引用你所需要的东西。我也认为蒲鲁东的协作社同布雷的计划 是一回事。我已经把这个善良的布雷忘得一干二净……

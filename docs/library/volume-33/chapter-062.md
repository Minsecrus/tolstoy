# 第62封：马克思致斐迪南·拉萨尔

1862年



柏林



1862年4月28日于伦敦哈弗斯托克小山梅特兰公园路格拉弗顿坊9号



亲爱的拉萨尔：



……至于我的书 ，没有两个月是完不成的。为了不致饿死，最近一年来我不得不从事极其乏味的机械呆板的工作，而且往往整月整月不能为我的这部著作写一行字。此外，我还有这样一个特点：要是隔一个月重看自己所写的一些东西，就会感到不满意，于是又得全部改写。无论如何，这部著作不会因此而受到什么损失，而且德国读者当前正做着远为重要的事情……

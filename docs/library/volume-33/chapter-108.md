# 第108封：马克思致恩格斯

曼彻斯特



1868年10月10日于伦敦



亲爱的弗雷德：



……正如你所知道的，奥哲尔先生提名自己为切尔西的候选人，我认为他没有成功的希望。自从根据我的提议取消了“国际工人协会主席”的职位 从而也永远取消了奥哲尔的“主席”称号以来，去年整整一年他对我们都非常冷淡。现在他因为自己在布鲁塞尔代表大会上重新当选而表示感谢，并希望我们给他的选举委员会写封信支持他为候选人。我们同意他的要求，只是因为这样做对国际有利，并能引起伦敦工人对国际的注意。



你上次在这里逗留的时候，曾经看到关于1844—1845年爱尔兰土地关系的蓝皮书 222 。我在一家小旧书店里偶然发现了关于1867年爱尔兰租佃者权利的报告和记述（上院）。这是一个真正的发现。当经济学家先生们围绕地租是因土地的自然差别而作的支出或仅仅是对土地所投资本的利息这个问题进行纯教条式的争论的时候，我们这里的农场主和大地主之间却在进行一场实际的生死斗争，这就是：除因土地的差别而作的支出以外，地租还应当包括多少不是由大地主而是由租佃者把资本投入土地而得的利息。只有抛开互相矛盾的教条，而去观察构成这些教条的隐蔽背景的各种互相矛盾的事实和实际的对立，才能把政治经济学变成一种实证科学。



祝好。



你的 卡·马·

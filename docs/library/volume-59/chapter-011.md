# 第三部　在梅尔切斯特

“新郎啊，她跟任何别的姑娘都不一样！”

——萨福80（H.T.沃顿）

1

他产生了新的观念：传教士为他人奉献的精神，在性质上有别于学者的争强好胜。一个人不必非得在克里斯特敏斯特的院校获得双优的成绩，只需具备普通的知识，照样可以传经布道，为同胞们做好事。他以前想入非非，后来甚至妄想当主教，那决非高尚、神圣的热忱，而是一种渴望披上一层法衣做外装的庸俗野心。他的整个计划即便起初并没有向上爬的野心，但恐怕后来也染上了这样的色彩；这种野心为高尚的人所不齿，是文明社会人为的产物。在目前，在同一条道上孜孜不倦为自己谋福利的年轻人何止千千万万。一个和妻子一起昏昏庸庸地吃喝，一起虚度人生的笨伯，也要比他强上几分。

以非学者的身份加入教会，只能做个卑微的教区牧师，在一个偏僻的乡村或城市贫民窟度过一生，不可能提升到更高的位置；不过，也许这本身就寓含着伟大和高尚的成分，这也许是真正的宗教热忱，是一种洗清罪恶的办法，值得一个忏悔的人采取。

跟以前的想法相比较，这种新的观念大有可取之处，使衣衫褴褛、孤苦伶仃的裘德精神振奋了起来。在以后的几天里，这种念头中止了他求知的生涯——一种在十几年中占用了大部分时间的生涯。可是在相当长的时间里，他停滞不前，没有去推行自己的新计划，而是忙忙碌碌地干些零碎活，在附近的村庄树墓碑和凿碑文，情愿让那五六个屈尊俯就跟他打招呼的农夫和老乡将他视为仕途的失败者和废品。

在产生了新想法之后，他的人情趣味（即便最讲究精神生活、最勇于献身的人也不能缺少人情趣味）是被苏的一封来信唤起的，信封上盖着新邮局的邮戳。她显然很为他担忧，信中叙及她自己的事只用了片言只语，说她通过了获得女王奖学金的考试，将要去梅尔切斯特师范学校求学，以便更好地从事自己的职业——这种职业由她自己选定，但也受到了他的部分影响。梅尔切斯特有一个神学院，那是一个清静的城市，给人以安慰感，几乎完全是一种基督教的格调；在那儿，世俗的学问以及理智的智慧没有立足之地，他所具有的为别人献身的精神比他缺少的才华更受人敬重。

他在攻读神学著作的同时，必须干些石匠活儿。在克里斯特敏斯特居住期间，他曾忽略了神学，埋头刻苦钻研平俗的古典著作。到了下一座城市，一边学习一边打工，不失为上策。他对那个新地方所产生的浓厚兴趣完全是苏一手造成的；可是，与从前相比较，苏更不适合于充当该角色；其中伦理上的矛盾，他并非看不出来。不过，他把这一切都归结为人类的弱点，希望自己爱她时，只是把她视为朋友和亲戚。

他觉得可以把未来规划一番，从三十岁起开始传经布道——这个年龄对他具有很大的吸引力，因为他的榜样就是三十岁开始在加利利教诲人类的。他将有大量的时间从容不迫地学习，同时通过揽工积累资金，以便上神学院，修神学院必需的课程。

圣诞节来临后，转眼又过去了。苏上了梅尔切斯特师范学校。对裘德而言，这种季节最难找到新工作，于是他给她写信说自己推迟一两个月去梅尔切斯特，等到白昼变长些再说。谁料她竟欣然同意了，这使他后悔自己不该提这种建议——看来她并不是十分喜欢他，尽管她对他那天夜里突然来访又悄悄溜掉的古怪行为从未说过一句责备的话。而且，她也闭口不谈她和费洛特孙先生的关系。

可有一天，苏突然寄来了一封感情十分激烈的信，说她非常寂寞和苦恼，讨厌自己所待的地方，说那儿比哪个地方都糟糕，还不如以前的那个设计圣物的店铺。她还说她没有一个朋友，问他是否能立即到那儿去；不过，即便他去了，她也只能在有限的时间里跟他相见，因为她那个学校的制度是非常严格的；她上学都是费洛特孙先生的主意，她真后悔当初不该听他的话。显而易见，费洛特孙的求婚进展并不怎么顺利。裘德为此没名堂地高兴起来，打点好行装，便去了梅尔切斯特，心情之愉快是数月来从未有过的。

这是他生活中新的一页，于是他四处寻找不卖酒的旅馆，结果在通往火车站的街上找到了一家符合这种标准的小店。他吃了些东西便出了店门，走到冬天惨淡的阳光下，跨过大桥，拐了个弯，前往克洛斯教堂。天气雾蒙蒙的，他来到这座全英国最典雅的建筑群的大墙旁，驻足仰望。巍峨的教堂只能看得到房脊，直插蓝天的尖塔愈往高处愈细，最终消失在缭绕的云雾之中。

此时华灯初照。他绕过拐角，来到教堂西边的正门口，但见四处散放着许多石块。他认为这是个好的征兆，说明该教堂是在进行大规模的修复。他心里充满了迷信的念头，觉得这是万物的主宰做出的安排，让他有大量的石活儿干，以等待时机去从事高尚的事业。

那个生气勃勃的姑娘眼睛亮亮的，前额宽宽的，长着一头浓密的乌发，目光中有时表现出果敢，有时温情脉脉，好似他看过的西班牙铜版画上的女子；一想到她近在咫尺，他身上就涌起一股暖流。其实她就在克洛斯教堂这儿，在那幢面朝着教堂西门口的房子里。

他沿着宽展的砾石路向那幢房屋走去。那是一座世纪的古代建筑，曾经是宫殿，现为师范学校，窗户都是直棂及横棂的，房前带一个庭院，由一道墙把它和外边的街道隔开。裘德推开院门，走到房门前说要见自己的表妹。他被小心翼翼地引进一个候客室，没多大一会儿，苏就走了来。

她虽然在这儿只待了很短一段时间，但是与他上次见到她时的样子相比却发生了变化。她的那种轻快活泼的劲儿已荡然无存，原先充满了动感的线条现在变得有些呆板，对习俗隐晦但巧妙的挑剔神态也飞到了爪哇国。而且，她也不像是写信召他来的那个女子。显然，那封信是在冲动之下匆匆写就的，但细想之后却产生了悔意，可能是想到了他最近的那次丢人的行为。裘德见到这情形，情绪异常激动。

“那次我去找你，半截却可耻地溜跑，你不会把我看成个堕落的浑蛋吧，苏？”

“我不愿朝那方面想。你已经做了足够的解释，使我了解了其中的原因。我希望自己永远都不会对你可敬的品质产生一丝一毫的怀疑，我可怜的裘德！你来这儿我感到很高兴！”

她穿一件带花边小领的紫红色学生礼服。衣服做得很朴素，优雅地紧贴在她那轻盈的身躯上。她的发式以前很时髦，现在头发却紧紧地绾成了髻。从她的神态看，她已经被严格的纪律约束得服服帖帖，但她的内心深处却闪射出一线光亮，因为纪律的威力还没有能够触及那儿。

她走上前来的时候，态度倒是挺亲热，但裘德感到她恐怕并不想让他以超过表兄妹关系之外的方式吻她，尽管他极希望那样做。她既然已了解到了他最丑恶的一面，即便他有资格当她的情人，她也不会将他视为情人的，而且永远不会，这一点他看得出来。这使他坚定决心，准备讲出自己在婚姻上出现的纠葛；以前由于害怕失去跟她相会的欢乐，他一拖再拖，迟迟不敢说出这桩心事。

她出了校门，随他上街，二人边溜达边谈，净说些即景应时的话。裘德说他想给她买件小礼品，而她有点难为情地直言相告说自己肚子饿得发慌。她说学校里的伙食吃不饱，所以请她吃一顿正餐、茶点和晚餐合而为一的饭，便是世界上她最渴望得到的礼品。裘德听了，把她带进一家饭馆，把种类并不丰富的饭菜统统点了些。饭菜虽不怎么样，但他们却有机会心情舒畅地促膝交谈；因为屋里没旁人，他们的谈话无拘无束。

她给他讲学校当时的情况，说那儿生活艰苦，学生鱼龙混杂，来自于该主教管区的各个地方。她说一大早起来，必须在煤气灯下工作；对于一个不习惯受约束的年轻人来说，她不由得满腹怨愤。裘德静静地听着，但这些并非他特别想知道的事情——他想了解的是她跟费洛特孙的关系，而恰恰是这一点她却没讲。他们坐着吃了一会儿，裘德突然冲动地把手按在了她的手上；她抬起头嫣然一笑，用自己娇小、柔软的手非常大方地抓住他的手，把他的手指一个个扳开不动声色地看着，仿佛那是她正在选购的手套似的。

“你的手很粗糙，裘德。”她说。

“不错。如果你整天用木锤和凿子干活儿，你的手也会变粗糙的。”

“我并非不喜欢你的手，这你知道。我觉得，一个人的手因工作而变得粗糙，倒有高尚的意味……不管怎样，能来这座师范学校，我还是挺高兴的。瞧着吧，经过两年的学习，我会成为完全独立的人！我想我会以优异的成绩通过考试的，费洛特孙先生再动用动用他的关系，把我弄进一座大学校教书。”

她终于触及了这个话题。

“我怀疑……我觉得，”裘德说，“他对你一腔热情，也许想娶你呢。”

“快别说傻话啦！”

“他大概说过这方面的话吧？”

“即便说过，那又怎么样？像他那么大的岁数！”

“唉，苏呀，他的岁数并不十分大。我明明看见他……”

“我敢肯定，不是看见他吻我了吧？”

“那倒不是。不过，他用胳膊搂住了你的腰。”

“噢……我想起来了。可我当时没想到他会那样做。”

“你这是在为自己开脱，苏，多不好啊！”

她那一贯敏感的芳唇开始颤抖，眼睛一眨一眨的，显然她在思索对这通责备的应答之词。

“我知道如果把所有的情况都讲出来，你一定会生气的，所以我才不愿交底！”

“很好，很好，亲爱的，”他息事宁人地说，“其实我没资格问你，而且我也不想知道底细。”

“我偏偏要讲给你听听！”她带着一种天生的任性说，“情况是这样的……我答应过他，曾许诺说两年之后待师范学校毕业，拿到文凭，我就嫁给他。按照他的计划，我们将到大城镇的综合学校教书，他教男生，我教女生——学校里的教师结过婚后往往都是这样做的，能挣到丰厚的收入。”

“苏啊苏！……当然，这样做是对的……你恐怕也只能如此了！”

他瞥了她一眼，目光跟她的相遇。他的眼中露出怨怪的神气，显然他说的并非心里的话。接着，他把手从她的手中抽回，将面孔扭开转向窗户。苏无奈地打量着他，一动也未动。

“我知道你会生气的！”她说话时，语气里不夹带任何感情的成分。“好吧……就算我做得不对！不该请你来看我。咱们最好别再见面了，隔上一长段时间通通信就行了，信的内容只谈正事！”

他所无法容忍的正是这一点，她大概心里很清楚。他听后，立刻转过了身来。“哦，那是不行的，”他连忙说，“你订你的婚，跟我没任何干系。我完全有权利在我情愿的情况下见你，我会那样做的。”

“咱们不要再谈这个了。今晚咱们说这些怪扫兴的。两年后的事情，现在谈有什么用！”

他觉得她像个谜团一样，干脆把这个话题搁置了起来。“咱们到大教堂里坐坐怎么样？”吃完饭后，他这样问道。

“大教堂？可以吗？不过，我倒情愿到火车站坐坐。”她回话说，声音里仍残留着几分不快。“那儿现在是这座城市生活的中心，大教堂兴盛的时代已经过去！”

“你还真够现代哩！”

“假如你像我前几年一样始终生活在中世纪的氛围里，你一定也会讲求现代气味！四五百年之前，大教堂倒是个非常好的地方，可如今时过境迁……再说，我也并非追求现代风尚。你应该清楚，我的思想比中世纪的人还古老。”

裘德的表情有些沮丧。

“好啦，我不再多说了！”她嚷嚷道，“不知道按照你的眼光看待我这个人有多坏哩，否则你就不会如此看得起我，就不会关心我是否订了婚。还有点时间，咱们绕克洛斯走走，然后我就进去，不然今夜我会被锁在校门之外。”

他把她送到学校门口，二人便分了手。裘德深信在这个凄楚的夜晚，他的不幸来访加速了她跟费洛特孙订婚的过程，想起来真让人感到难过。她用行动而非语言表示了对他的谴责。尽管如此，第二天他却忙忙活活开始找起了工作；在这座宁静的城市，工作不像克里斯特敏斯特那么好找，因为一般来说这儿的石活儿少，而匠人大多是长期工。不过，他一步步挤进了门里。起初，他在山上的坟场凿石碑，后来干上了自己朝思暮想的工作——整修教堂。这种工程规模非常大，教堂里所有的石刻品都要经过检查，大部分都要用新的取代。

要完成这项工程，也许需要几年的劳动。他对自己使用木锤和铁凿的技术充满了信心，觉得要逗留多久全取决于自己。

他在克洛斯大门附近的寓所，就是让教区牧师住也不寒碜，租金在他的工资中占很大的比例，一般的匠人是不愿付如此之高的租金的。他的卧室兼起坐间里悬挂着教区长住宅及主教住宅的那种加框照片，女房东当年做心腹女仆时曾在这儿居住；楼下小客厅的壁炉架上摆着一座钟，根据钟上的题词可以得知，这是同伴们在这位思想严肃的女人结婚时送给她的礼物。除过这些摆设，裘德又取出了自己亲手雕凿的教堂用品和纪念碑的照片，摆在房间里。原来，房间是空着的，现在有了他这样的房客，女房东应该是很满意的。

他在该市的书店里找到许多神学著作，于是开始刻苦研究，这次的读书精神和方向跟从前相比都有所不同。他读了教会的书，读了佩利和巴特勒的作品。另外在休息时他还阅读纽曼、蒲赛及其他许多现代作家的书。他租了一架小风琴放在寓所里，用来练习弹奏单节和双节的圣歌。

2

“明天是个好日子，咱们好好痛快痛快。到哪儿去好呢？”

“我的假从三点钟到九点钟。不管到哪儿去，只要能打个来回就可以。别去参观什么遗迹，裘德……我不喜欢那种地方。”

“哦……到沃德堡去吧。然后，如果愿意的话，咱们还可以爬爬芳特山，总共用一下午时间就够了。”

“沃德堡是哥特式建筑遗址……我讨厌哥特风格！”

“不，不，恰恰相反。那是古典式建筑……大概属于哥林特风格吧，里面挂着许多画哩。”

“哦……那就行。一听哥林特这名称我就喜欢。咱们一言为定。”

这席对话是他们相遇几个星期之后进行的，第二天早晨他们做好了出发的准备。这次郊游的每一个细节都散发着诱人的光芒，裘德不敢细想自己过的是怎样一种矛盾的生活。苏的行为在他的眼里是个可爱的谜，除此之外他再也说不出个什么。

他兴高采烈地到校门口去接她；她出现时，衣着打扮跟修女一般朴素（她是被迫这样打扮，而非出于本愿）；二人一道悠闲地溜达到车站；车站到处有脚夫在喊“请让路”，火车的汽笛在尖鸣——这一切形成了一幅美丽、晶莹的图画。没有人盯着苏瞧，因为她的服饰过于平凡。裘德心里快慰地想，只有他一人知道苏的衣服遮住了她的丽质。只要到一家服装店（她真正的生活或者她的本性跟这种地方无缘）花上十英镑，就会让梅尔切斯特所有的人看呆眼。列车员以为他们是一对情侣，便把他们单独塞进了一个包厢里。

“他倒是好意，但白费苦心！”苏说道。

裘德没吱声，心里觉得她的话既没必要又残忍，而且还带有一部分不真实性。

他们来到沃德圃囿和城堡，在画廊里转着看。出于个人爱好，裘德流连于德尔·萨尔托、圭多·雷尼、德·里贝拉、萨索弗拉托、卡罗·多尔斯及其他一些画家的宗教体裁的作品前。苏耐着性子站在他身旁，偷眼瞧他的面孔，发现他在欣赏圣母图、神圣家庭图和圣人图时，脸色变得很虔诚和神往。待到看出这种情况，她就朝前走几步，立到莱利或雷诺兹的画作前等他。很显然，她对表哥产生了浓厚的兴趣，就像一个人逃出了迷宫，对另外一个正在朝外摸索的人感兴趣一样。

走出城堡时，还剩下很长一段时间供他们支配。裘德建议先吃点东西，然后马上朝北走，穿过一片高地往七英里开外的车站去，坐另一条道上的火车返回梅尔切斯特。苏欣然同意了，因为不管到哪儿，只要能强化今天的自由感，她都愿意。于是二人上了路，把附近的那个车站抛到了身后。

其实，那是一片开阔的高地，既宽展，地势又高。二人边交谈，边蹦蹦跳跳地朝前走。裘德为苏砍下长长的一根树杈做手杖，比她本人还高，上面带一个大大的曲把，使她看起来如牧羊女一样。走到半路，遇见一条东西走向的大道——这是从伦敦通往“天涯海角”的古道。他们停住脚步，议论起来。想当初这儿曾经人来车往，而今却满目苍凉，风儿席卷大地，刮起麦秸和草梗。85

他们横过古道，继续赶路，但走了没半英里，苏就露出了疲倦之色，裘德开始为她感到担心。二人已经行了很远的路，如果赶不到火车站，事情就麻烦了。走了许久，那辽阔的丘原上和萝卜地里也不见一户人家。但又过了没多大一会儿，他们碰见了一个羊圈，旁边有个牧羊人在扎篱笆。那人告诉他们附近只有一座房舍，那是他和他母亲的住所，说时用手指了指前边的一个升起袅袅青烟的小山洼，建议他们到那儿歇脚。

他们依计走到那儿，进得屋来，迎接他们的是一个掉光了牙齿的老妪。他们尽量表现得彬彬有礼，因为身为外乡人，无论是歇脚还是留宿，只能取决于主人对他们的看法。

“多么漂亮的房子。”裘德说。

“哦，漂亮不漂亮我不知道，只知道必须立即修盖房顶，能不能搞到茅草还很难说呢。如今的茅草贵得要命，用瓷盘盖房顶恐怕也比用茅草便宜。”

他们坐着休息时，那个牧羊人走了进来。“你们别管我，”他说话时道歉似的摆了摆手，“你们愿待多久都可以。不过，你们是不是打算乘火车连夜赶回梅尔切斯特？那可就不行了，因为你们不熟悉这儿的地理。我倒愿意送你们一程，可即便如此也赶不上火车了。”

裘德和苏一听，跳起了脚。

“你们可以留下来过夜……你说是不是，妈妈？我们表示欢迎。这儿条件不好，可总比没地方住强。”接着，他转向裘德悄悄问，“你们是夫妻吧？”

“嘘……不是的！”裘德说。

“哦……我可并没有恶意，绝对没有！那好吧，她到我母亲的房间里，待她们走后，我和你就躺在外间屋。明天一大早我叫醒你们，赶头一班火车。现在的这趟是赶不上了。”

他们考虑了一下，决定接受对方的邀请。二人重新坐下，和牧羊人母子共进晚餐，吃了一顿煮咸肉及青菜。

“我很喜欢这种生活，除过万有引力定律和生物发生律，不受任何清规戒律的约束。”苏趁着主人们收拾碗碟的时候说。

“你只是觉得自己喜欢，其实并不喜欢。你十足是一个文明社会的产物。”裘德说道，由于想起了她订婚的事，声音里带了些许醋意。

“才不是呢，裘德。我固然喜欢读书什么的，但我渴望重新过幼年时的那种生活，享受幼年时的那种自由。”

“那时的情形果真使你如此难以忘怀？在我看来，你身上好像没有丝毫反习俗的痕迹。”

“哦，是吗？你怕是不了解我的内心世界！”“什么样的内心世界？”

“以实玛利式的。”

“你是一个实实在在的都市小姐。”

她显得很是不同意他的说法，转过了身去。

次日晨，牧羊人按照自己先前说的那样把他们叫醒。天空明亮、晴朗，到火车站的四英里路程很愉快就走完了。他们抵达梅尔切斯特后，向克洛斯走去。那座古老的建筑物又要将苏禁闭起来了；当学校的山墙出现在眼前时，她露出了惊恐之色。“这次恐怕要受罚了！”她喃喃地说。

他们按了按硕大的门铃，然后等在那儿。

“噢……我为你买了样东西，差点忘了给你。”她语调急促地说，一边在衣袋里摸着。“这是我才照的相片。你喜欢吗？”

“哪能不喜欢！”他高兴地接了过来。

守门人走了来。他打开门时，脸上好像有一种不吉利的兆头。

苏闪身进了门，回头望望裘德，挥了挥手。

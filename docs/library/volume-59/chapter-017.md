# 2

如果安排事物的不是上帝，那就是女人。第三天上午，他收到了苏的一封短信，其文如下：

下个星期请你别来了。为了你自己，千万别来了！在那首病态的赞美诗以及暮色的作用下，咱们未免太随便啦。望竭你所能，不要再想此事。

苏姗娜·弗洛伦斯·玛丽

那种失望的心情是很明显的。他知道她最终作出这种决定时，带着怎样的情绪，脸上有着什么样的表情。但不管她的情绪如何，他不能说她的观点是错误的。他在回信中写道：

我同意你的安排。你是对的。我觉得现在我应该学会自制。

裘德

他在复活节前夕把信发走，于此，二人的安排似乎已成定局。但除过他们自身，另外还有一些力量和规律在发生着作用。复活节次日晨，他接到了寡妇艾德林发来的消息，因为他曾叮咛过艾德林，要她在姑婆病情恶化时给他发电报。电文如下：

你姑婆病危，速来。

他扔下工具，立刻就动身上路了。三个半小时之后，他来到玛利格林附近的丘原，紧接着进入那片洼地，沿着捷径往林子里走。到了对面的坡上，他遇见了一位农工，那人刚才从小径对面的一扇大门旁望着他走过来，这时不安地移动着身子，像是要跟他讲话。“从他的脸上可以看得出，姑婆已离开了人世。”裘德对自己说道，“可怜的老人家啊！”

情况正如他所料，这个汉子是艾德林夫人打发来向他报告噩耗的。

“你姑婆咽气前躺在病床上，和安着玻璃眼睛的玩具娃娃一样，不会认出你来的，所以你在不在跟前都无所谓。”这位农工说。

裘德回到家中。到了下午，当一切都料理停当，负责入殓的人喝完啤酒告辞之后，他一个人在静悄悄的屋子里坐下来。两三天之前，他虽然和苏有约不再来往，但把这个消息告诉苏是绝对有必要的。于是他修书一封，以最简单的词句写道：

“朱西拉姑婆已去世，死得有些突然。星期五下午举行葬礼。”在中间的几天里，他一直待在玛利格林，或到周围转转。星期五早晨，他去看了看墓坑是否已挖好，同时心里在纳闷，不知苏会不会来。她没有写信来，这似乎表明：她来的可能性要大于不来。针对她唯一可能搭乘的那班火车，他计算好时间，然后在中午时分把房门锁上，穿过那片洼地，来到高原边缘的棕房子旁。他站在那儿，放眼眺望北边辽阔的原野，以及阿尔弗利逊所在的较近的地方。在那个地方的后面，有两英里的距离，一股白烟从画面的左边移向右边。

即便现在，也还得等很长时间才能知道她究竟来了没有。不过，他还是等了下去。最后，一辆小巧的雇脚马车停在山脚下，一位乘客走了下来。马车往回驶去，那位乘客往山上走来。他认出了她——她今天看起来特别柔弱，仿佛热烈地使劲一拥抱，就能把她挤死。不过，他再也没福分拥抱她了。爬坡爬到三分之二的地方，她突然一偏脑袋，露出关切的表情，他知道她这时已认出了他。她脸上很快绽出忧愁的微笑，直至他往山下走了几步跟她遇在一起，那笑容才消失。

“我觉得，”她不安地脱口说道，“让你一个人送葬未免太凄惨！所以……最后……最后我还是来了。”

“亲爱的苏，你是多么可靠啊！”裘德喃喃地说。

可是，苏具有奇特的双重天性，叫人无法捉摸，所以她不愿站在那儿过多地寒暄，尽管离葬礼还有一段时间。此刻的这种哀婉的现象是不常有的，即便有可能再次出现，也得等若干年之后。裘德很想留下来把事情好好考虑考虑，和她谈谈。可是，苏要不压根没看到这种情况，要不就是看得比他还清，硬是不允许自己产生那份感情。

这种凄楚、简单的仪式很快就结束。他们几乎一路小跑往教堂赶，因为殡葬承办人是个大忙人，一小时后还要到三英里开外的地方主持一个比较重要的葬礼。朱西拉被埋在新坟场，远离祖宗的墓地。苏和裘德到坟场时，是肩并肩去的，而现在回到熟悉的家中坐下来喝茶。他们的生活，最后在为亡人送葬时连接在了一起。

“你说姑婆自始至终都反对婚姻？”苏喃喃不清地问。

“是的。她尤其反对咱们家族里的成员结婚。”

她和他的目光相遇，把他盯了一会儿。

“咱们出生于一个不幸的家族。你说呢，裘德？”

“她说咱们家族的人做丈夫或妻子都不称职。当然，家族里的婚姻都是不幸的婚姻。不管怎样，我的情况就是例证！”

苏没作声，后来才用发抖的声音试探地说：“裘德，丈夫或妻子告诉第三者，说他们的婚姻不幸，这种做法算不算错？如果婚姻仪式是神圣的，这样做也许是错的；然而如果婚姻只是可悲的契约，以管理家务和纳捐纳税的实际方便为基础，为了让子女继承田产和钱财，必须让别人知道他们的父亲是谁，那么我觉得夫妻的任何一方都可以说出心中的伤痛和悲哀，甚至还可以站在房顶上喊出来。你说是不是？”

“我以前好像对你说过这种话。”

没过多大一会儿，她又接着说道：“男女之间并不为具体的过失便生厌恶之感，你说这种夫妻多不多？”

“大概很多吧。例如，如果有一方爱上了第三者，就会出现这种情况。”

“要是除过你说的那种情况呢？例如，一个女人如果不愿跟自己的丈夫住在一起，只是因为……”说到此处，她的声音发生了变化，于是他猜出了她的意思，“因为她有些反感——肉体上的反感、恶心，或不管用什么词吧——可她又尊敬和感激他，那她算不算天性不良呢？我这仅仅是在列举一种现象。她是否应该克服掉自身的拘谨呢？”

裘德向她投来忧虑的目光，随后将目光掉开说：“出现这种情况，我的所作所为总是和我的信条背道而驰。我希望自己是个循规蹈矩的人，但恐怕我并不是；从循规蹈矩的人立场讲话，我的回答是应该克服；要是根据我的经验和公正的天性，我却要说不应该……苏，我坚信你生活得并不幸福！”

“我当然是很幸福的！”她反驳道，“一个女人刚刚结婚八个星期，嫁给了一个自己选择的男人，她怎能不幸福呢？”

“好一个‘自己选择的’！”

“你怎么重复别人的话？……欸，我得搭六点钟的火车赶回去。你大概还要留在这里吧？”

“我还要待几天料理姑婆的后事。这座房子要归别人了。我送你上火车，好不好？”

苏笑了笑表示反对，说道：“我看不用了。送我一程就行了。”

“先别急……你今晚走不成了。没有去萨斯顿的火车了。你必须留下来，明天再回去。如果你不愿住这里，艾德林夫人有的是房间。”

“好吧。”她举棋不定地说，“我并没告诉他，说我一定回去。”

裘德到隔壁的寡妇家去解释情况，几分钟后转回来又重新坐下。

“太可怕了，咱们都受着环境的约束，苏……太可怕啦！”他蓦然说道，眼睛紧盯住地面。

“太可怕？怎么说这话？”

“关于我悲惨的遭遇，我不能全盘托给你。至于你那一边，你就不应该嫁给他。早在你出嫁之前我就看到了，可我觉得自己不能干涉。我错了，因为我当时应该阻止你！”

“你凭什么做出这样的猜测，亲爱的？”

“因为……我可以透过你的羽毛看穿你的心，我可怜的小鸟儿！”

苏的手放在桌上，裘德把自己的手按在了她的手上。她见状便将手抽了回去。

“咱们谈了那么多，你还这样就太荒唐啦，苏！”他嚷嚷道，“要论起来，我比你更严肃和正统。对如此单纯的举动你竟表现出不乐意，这就证明你心里矛盾得让人觉得可笑。”

“也许我过于拘谨了。”她后悔地说，“我只是觉得那是咱们玩的一套把戏，也许玩的次数太多了。你可以握我的手，愿握多久就握多久。这样子好吗？”

“好，非常好。”

“不过，我必须告诉他。”

“告诉谁？”

“理查德。”

“欸，你要是觉得有必要，当然可以告诉他。不过，这里边不包含有任何意思，告诉他只会叫他白白心烦。”

“哦……你敢保证这其中只含表兄妹之情吗？”

“绝对保证。我心中爱的情意已荡然无存。”

“这倒是个新闻。怎么会落到这种地步？”

“我见阿拉贝拉了。”

她在突然的打击面前向后一缩，随即好奇地问：“你什么时候见的她？”

“在克里斯特敏斯特时。”

“原来她已回国，可你从未告诉过我！现在，你大概准备和她一道过活吧？”

“当然。就跟你同你丈夫住在一起是一样的。”

她望了望窗台上那因为无人照料而枯萎了的绣球和仙人掌盆景，又透过盆景眺望窗外遥远的地方，后来眼睛都开始变得潮湿了。

“怎么啦？”裘德用温柔的语气问。

“如果你曾经对我说的话是真的……我是说当时是真的，现在当然已不再真实……那你为何如此高兴回到她身旁呢？你的心怎么能这么快就倒向了阿拉贝拉？”

“大概是老天的特意安排，促使它倾斜吧。”

“不，这不是实情！”她有些气愤地说，“你在戏弄我，仅此而已。因为你认为我生活得并不幸福！”

“我不清楚是否这样，我也不想知道。”

“假如我不幸福，那也是我的过错，说明我是个坏人，因为我没有权利厌恶他！他在各方面都对我体贴入微；他博览群书，掌握着丰富的知识，是一个非常风趣的人……依你之见，裘德，一个男子应该娶和自己同龄的女人，还是娶比自己年轻的女人——像我和他一样，年龄相差十八岁？”

“这取决于双方彼此的感情如何。”

他没有给她机会让她得到自我满足，于是她只好管自用压抑的语调说下去，眼泪都快流出来了。

“既然你对我讲了实话，我觉得我也必须以同样坦诚的态度对待你。也许你已经看出我想说什么话了。我虽然喜欢费洛特孙先生做我的朋友，却不喜欢……把他当丈夫和他一起过活，对我来说是一种折磨！……瞧，我都说出来了……我实在憋不住了……尽管我一直装出幸福的样子。我想，你会永远瞧不起我的！”她低头把脸埋在那双放在桌布上的手上，无声地抽泣起来，身子一抖一抖的，把单薄的三条腿的桌子弄得乱摇晃。

“我结婚才一两个月。”她仍然伏在桌上，把脸埋在手上抽泣着说。“据说，结婚之初，一个女人如果有不顺心的事，过五六年就会习以为常了。但这等于说：截肢也没有什么可苦恼的，因为安上假腿或假胳膊，过一段时间也会习惯的！”

裘德几乎连话都说不出来了，但最后还是说道：“我早就觉得有问题，苏！我早就觉察出来了！”

“可事情并非像你想的那样！有问题的只是我本人，是因为我的邪恶——我想你得这样认为，也是因为我单方面的排斥感，其中的理由我不能披露，其实在一般人的眼里不能算为理由！……从道义上讲，他是个好人，但是让我万分痛苦的是：每当他想干那种事的时候，我得做出反应。那种事的基点是双方自愿，可我却有一种可怕的履行契约的感觉！……真希望他能打我、对我不忠，或者干明目张胆的事，使我能够毫不愧疚地把心里的感受说出来！可他什么错事也不做，只是在觉察到我的感情后对我稍微冷淡了些。这就是他没来参加葬礼的原因……唉，我感到非常痛苦，不知该怎么办好！……别靠近我，裘德，不许你靠近我！别过来，别过来！”

可他已经跳起身来，把脸贴在她的脸上——或者说贴在她的耳朵上，因为她的脸不容易接近。

“我告诉过你不要这样，裘德！”

“我知道你告诉过……我只不过想安慰安慰你！全都是因为咱们相遇之前我结过婚，对不对？如若不然，你一定会嫁给我当妻子，是不是，苏？”

她没回答，而是很快站起身，声称要到坟场去，在姑婆的坟头稳定一下情绪，说完便走出了房门。裘德没跟着去。二十分钟后，他看见她穿过林中的绿茵地向艾德林夫人家走去。没多大一会儿，她支派一位小女孩来取她的包，并告诉他说她由于太疲劳，当晚不能再见他了。

裘德坐在姑婆家孤寂的房间里，观望着寡妇艾德林的农舍消失在夜幕之中。他知道，坐在农舍里的苏也同样孤独和沮丧，于是又怀疑起自己所虔诚信奉的格言：“万事皆会如意。”

他早早就上床睡了，但苏近在咫尺的感觉使他时时从睡梦中醒来。接近夜里两点钟，正当他开始睡得比较踏实时，却被尖厉的叫声所惊醒——他过去长住玛利格林时，对那叫声非常熟悉。那是被夹住的野兔所发出的叫声。这种小动物有一种习惯。不重复自己的叫声，充其量也只不过叫一两声，把疼痛一直忍到第二天早晨，等设置夹子的人走来一棍子击在脑袋上了事。

裘德在小的时候连蚯蚓的性命都不忍伤害，此时便开始想象那只腿被夹伤的野兔是如何痛苦。倘若夹得不好夹住后腿，兔子就会在天亮前的六个小时里拖着夹子走，直至夹子的铁齿把它腿骨上的肉完全撕掉；那时候，如果夹子的劲小，它得以逃脱，也会因腿生坏疽而死在荒野里。如果夹得好夹的是前腿，骨头会被夹碎，兔子在无法脱逃的情况下硬要逃跑，它的腿可能会被扯成两截。

差不多过了有半个小时，野兔又发出了惨叫。不使它摆脱痛苦，裘德再无法安睡，于是他飞快穿好衣服下了楼，借着月光穿过绿茵地朝着传来声音的方向走去。抵达那位寡妇的花园前，他在旁边的树篱跟前停住脚步。胡乱扑腾的兔子拖动着夹子，发出微微的咔嗒声；他循声找过去，用手掌在兔子的脖颈背后猛砍一下，兔子一伸腿便死了。

他正要从那儿跑开，却瞧见有个女人在邻近农舍底层的一扇敞开的窗口向外张望。“裘德！”一个声音怯怯地叫道——那是苏的声音，“真是你吗？”

“是的，亲爱的！”

“我一直没能睡着觉，听见兔子的叫声，就禁不住想着它是多么的痛苦，后来我觉得必须走过去把它打死。可你却赶到了我前边。这让我真高兴……应该作出规定，不允许使用这种钢夹子！”

裘德来到窗前——那窗台非常低，可以一直看到她的腰部。她拔掉窗栓，把手放在他的手上。她默默打量着他，脸上沐浴着月光。

“兔子的叫声把你吵醒了吧？”他问道。

“不，我压根就没睡着。”

“那是怎么啦？”

“唉，你应该很清楚的。你有自己的宗教信条，我知道你一定会觉得，一个满腹忧虑的已婚女子不该把心事吐露给一个男人，就像我对你诉苦那样，因为那是弥天大罪。我现在后悔真不该对你说心事！”

“别后悔，亲爱的。”他说，“也许我以前是那样看待问题的，可现在我已开始和自己的信条分道扬镳了。”

“这我是知道的，我知道！正因为如此，我才发过誓决不干扰你的信仰。不过……我见到你是多么高兴啊！……欸，我原来并不想再见你，因为咱们之间的最后纽带——朱西拉姑婆已辞别了人世！”

裘德抓住她的手吻了吻。“还有一条纽带更为牢固！”他说道，“至于我的信条或宗教，我再也不会管它们啦！让它们滚蛋吧！请允许我帮助你，即便我的确爱你，即便你……”

“别说啦！我明白你的意思，可我不能加以承认。就这样！你愿怎么想就怎么想吧，可你不能逼着我作出答复！”

“不管我怎样，我都希望你生活得幸福！”

“我是不会幸福的！很少有人能理解我的感受，人人都会说我胡思乱想、吹毛求疵，等等，对我加以谴责……在文明社会里，爱情通常是悲剧，而我的情况决不是这种自然的悲剧，而是人为的悲剧，只有各自东西方可得到解脱！……如果我另有人可以倾吐心事，我还来找你，那也许我就做错了。可是没人听我的，而我必须找个人讲讲！裘德，在我嫁给他之前，我虽然也知道婚姻是怎么回事，但从未作过通盘考虑。都是因为我太愚蠢，没有什么可为自己开脱的。我已到了成熟的年龄，自以为非常有经验。所以，当卷进了师范学校的那场风波之后，我便昏头昏脑、满怀自信地匆匆办了事。我认为，一个人如果做下了蠢事，应该允许他更正。我敢说，出现这种情况的妇女大有人在，只不过她们屈服了，而我却在反抗……将来的人回首咱们这些不幸的人所处的时代，不知会怎样评价咱们野蛮的习俗和迷信哩！”

“你心里的苦事太多了，亲爱的苏！我多么希望……我希望……”

“你现在得回屋里去啦！”

在一阵冲动之下，她伏在窗台上，哭泣着用脸依偎他的头发，随后几乎不被察觉地轻轻吻了吻他的额头，接着很快缩回身，这样他就不能搂抱她了。她要是不缩回去，他肯定会那样做的。她关上窗户，而他回到了自己的屋中。

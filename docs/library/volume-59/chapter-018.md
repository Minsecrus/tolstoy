# 3

裘德整整一夜一直在回想着苏的那番哀痛的自白，心里的确感到很难过。

第二天早晨她该走的时候，邻人们瞧见她和她的同伴以步代车，消失在了山路上——那条山路与通往阿尔弗利逊的一条冷清的大道相连，一小时后，他沿着原来的路线返回时，脸上带着狂喜的表情，而且狂喜中掺杂着不顾一切的成分。一定是发生了什么事情。

当初在寂静无人的公路上分手时，他们由于心情紧张、情绪激动，便迷乱地询问对方：他们的关系到底应该亲密到什么程度？后来，他们几乎吵起了架；她泪水汪汪地说，他既然计划当牧师，产生吻她这样的念头（他已表示了这种愿望）是不大合适的，即便在告别时也不合适。随后她又作出了让步，声称吻本身并没有什么，所有的一切都取决于里边包含的思想。如果按表哥和朋友的情分吻她，她没有什么可反对的；如果以恋人的情分吻她，她是不能允许的。“你能不能起誓，你的吻不含那种情分？”她问道。

不能，他不能发那样的誓。二人发生分歧，于是便掉头各走各的路。在相距二三十码的时候，他们同时扭过头来望对方。这回眸一瞥，打消了他们之间或多或少保持的隔阂。他们都飞快地往回跑，半路相遇，想也没想便搂抱在一起，如胶似漆地吻个不停。二人最后分手时，苏的脸颊通红通红，而裘德的心扑扑乱跳。

这一吻竟成了裘德生涯的转折点。待到返回家中独自沉思时，他看到了一种情况：他和那个超尘脱俗的人之间的亲吻。虽然在他罪孽深重的一生中像是最纯洁的一刻，但只要他心怀这种不应该有的柔情，就会产生强烈的矛盾，使他无法追求有朝一日荣当宗教卫士和仆人的理想，因为在这个宗教里，往最好处看，性爱是一种脆弱的表现，而往最坏处看，则是该下地狱的罪恶。苏满怀热情所说的话，其实是冷酷的真理。如果他心中只知道不顾一切地捍卫自己的爱情，勇往直前、满腔激情地爱她，那他实际上就不配研究通常意义上的伦理道德。显而易见，无论从天性上还是社会地位上，他都不适合于阐述世人共认的信条。

说来也怪，他头一次追求学问的抱负由于受到女人的影响而夭折，第二次致力于当使徒的愿望也因女人的作用而化为泡影。“这难道得怪女人吗？”他问自己，“还是怪人为的条条框框把正常的两性冲动置入家庭可恶的天罗地网，阻止人们前进的步伐？”

他过去一直有一种愿望，想当一名先知，不管地位多么卑微，为苦苦挣扎的同胞们服务，丝毫不考虑个人得失。可是，他的妻子离开他和另一个丈夫住在一起，他自己也陷入了反常的爱，他所爱的人可能为了他的缘故而不满于现状；在这种情况下，根据普通人的观点，他几乎连体面都够不上，还敢有什么痴心妄想？他毋需多想，只需看看明显的现实：他自诩为守法的宗教传教士，可他的所作所为已使之成为骗人的鬼话。

傍晚暮色降临时，他到花园里挖了个浅坑，把自己所有的神学书和伦理学书一股脑儿扔了进去。他知道，在这个真正信仰宗教的国度里，大多数书的价钱比废纸高不了多少，所以他宁肯用自己的方式销毁，这样做固然会损失几个铜板，却可以多几分精神的满足。他先点燃一些活页小册子，再把整本的书尽可能裁开，用三齿叉挑着散到火苗上。火焰熊熊，照亮了屋后、猪圈以及他的面孔，那亮光一直持续到书本差不多全部烧光。

现在认识他的人寥寥无几，但村民们路过时会隔着园篱跟他搭话。

“大概在烧你姑婆的破烂吧？唉，在一座房子里住上八十年，旮旯拐角免不了会堆满这种玩意儿。”

将近夜间一点钟，杰雷米·泰勒、巴特勒、陶德瑞、斐利、蒲赛、纽曼及其他一些人撰写的书，才连纸页和封面全部化成了灰烬。夜里静悄悄的，当他用叉子翻动碎纸片时，他觉得自己已不再是伪道学，一颗解脱了的心获得了宁静。他可以像从前一样有自己的信仰，但他闭口不谈；他不再拥有和展示传播信仰的书籍了；作为书的主人，人们自然会认为他应该先受到书的影响。带着对苏的爱，他现在可以以普通罪人的身份出现，而不是表里不一的伪君子。

那天的前半天，苏和他分手之后，自己到了车站，一路上泪水涟涟，那是她在怪自己不该又跑回去让他亲吻。裘德不应装出一副并非恋人的样子，诱使她在冲动之下做出了违犯习俗或错误的举动。她倒倾向于把那称作错误的举动，因为她的逻辑概念极为混杂；在事情未做之前，她认为应该做，但做完之后却又认为做错了。换句话说：有些事情在理论上是正确的，在实践上却是错误的。

“我可能太软弱了！”她昂首阔步朝前走着，突然说出这句话来，还时不时洒下几滴眼泪。“他的吻火辣辣的，像恋人之吻……不错，是这样的！我再也不给他写信了，至少很长时间不给他写信，让他知道我也有尊严！但愿他会因此而非常伤心——明天早晨盼信信不来，一天又一天地盼信总不见信来。他会因为焦虑而痛苦！让他瞧瞧厉害！那样我才高兴哩！”她一方面为裘德将在她手里受痛苦的折磨而流下怜悯的眼泪，另一方面又为可怜自己而潸然泪下——两种眼泪混杂在了一起。

这个对丈夫心生厌恶之感的身材苗条的少妇，这个步态轻盈、感情细腻、敏感的女孩子，这个按性格和本能不适合与费洛特孙保持夫妻关系中的交往，也许和任何男人都不适合有那种事情的姑娘，此时紧一阵慢一阵、气喘吁吁地走着，眼睛里生出了倦意——那是无望地眺望和担忧的结果。

费洛特孙在她抵达的车站接她，见她满脸的愁云，还以为她在为姑婆的辞世以及葬礼而难过。他开始讲述自己一天里所做的事情，说他那个在附近一座小学里当校长但多年没见面的老朋友吉林哈姆先生今天跑来看望他了。她坐在公共马车的顶端丈夫的身旁，沿坡而上向城镇进发时，眼睛观望着白色的路面以及路边的榛树丛，带着自我惩罚的神态突然说道：

“理查德……我让弗利先生把我的手握了老长一段时间。我想知道，你是不是认为那样做不应当？”

他显然在想着风马牛不相及的事情，这时从沉思中醒过神，不置可否地说：“哦，是吗？你为什么让他握你的手呢？”

“我不知道。反正他想握，我就让他握了。”

“但愿他会感到高兴。我觉得这不算什么新奇的事情。”

他们陷入了沉默。如果这事拿到法庭上让一位洞察秋毫的法官评判，他也许会记录下这样一条有趣的事实：苏避重就轻，没有说不检点的重大过失，只字未提接吻的情况。

傍晚用过茶点后，费洛特孙坐在那儿核算学生的出勤人数。苏仍然异常静默、紧张和忐忑不安。最后，她声称自己累了，便早早去睡觉了。检查出勤数额的枯燥乏味的工作把费洛特孙弄得精疲力竭，待他上楼进入卧室时，已经十一点四十五了。他们的卧室白天俯视布莱克莫尔峡谷，可以看到三四十英里的地方，视野甚至远及外维塞克斯，而此时远处的景色却笼罩在神秘的黑暗之中。他走到窗前，把脸贴在玻璃上，敛声屏息地凝视着苍茫的夜色，心中遐想不已。“我认为，”他最后说道，“必须敦请委员会另换一家文具店。这次送的练习簿没有一本是对的。”说话时，他连头也没回。

没听到回声，他以为苏在打盹，又继续说道：“教室里的通风机必须重新安装。那风老是冲着我的脑袋吹，吹得我耳朵都发痛。”

由于屋里的气氛跟平时不一样，显得异常寂静，他转过了身来。在这个破败的“旧林园”，楼上楼下全都镶着沉重、阴森的橡木壁板；庞大的壁炉架直抵天花板，跟他为她新买的闪闪发亮的铜床架以及桦木家具形成了奇特的对比，两种风格在颤悠悠的地板上似乎隔着三个世纪在相互打招呼。

“秀！”他叫道（他叫她的名字总发这个音）。

她不在床上，但显然她刚才在床上躺过，因为她那边的被子撩到了一旁。他心想她可能是把厨房里的什么活儿忘干了，跑到楼下张罗去了，一会儿就会回来。这样想着，他脱掉外套，无声无息磨蹭了几分钟，后来见她还没来，便拿着蜡烛走到楼梯口，又喊了一声：“秀！”

“哎！”她的声音从远处的厨房传到了他的耳中。

“深更半夜跑到那儿干什么？无缘无故地白受累！”

“我不困，正在看书呢。这儿的火更旺些。”

他上床睡下，夜里不知什么时候又醒转来。甚至到了这个时辰，苏还没有上床睡觉。他点亮蜡烛，急匆匆跑到楼梯口，又叫起了她的名字。

她像以前一样，又“哎”了一声，但这次的声音又小又闷，他起初弄不清是从哪儿传来的。楼梯下有个大大的衣帽间，没安窗户，声音好像来自那里。那儿的门是关着的，但没有锁或门闩。费洛特孙心里一惊，朝衣帽间走去，怀疑她突然精神错乱了。

“你在这里干什么？”他问道。

“夜太深了，我怕打搅你，就跑到了这儿。”

“可这儿没床呀？而且也不透气。欸，你待上一夜，会给憋死的！”

“哦，不，我想不会的。别为我担心了。”

“可是……”费洛特孙说着抓住门柄，把门拉了一下。她用一根线绳从里边把门拴着，这一拉便把绳子给拉断了。衣帽间里没放床，她把几条毯子铺在地上，在这狭窄的空间里为自己营造了一个小窝。

当他朝里窥视她时，她从窝里跳出来，眼睛瞪得大大的，浑身打着哆嗦。

“你不该把门拉开！”她语调激愤地说，“你这样做是不合适的！唉，你走吧，请你走开吧！”

她身穿白睡衣苦苦央求着，后边衬托着昏暗、杂乱的窝，这使她显得十分可怜，他见后很是不安。接着，她又一次恳求他不要打搅她。

他说：“我好好地待你，什么事都由着你，而你却对我有这种感觉，太不近人情了！”

“是的。”她淌着眼泪说，“我全明白！这样做是不对的，大概我就是这么个坏女人吧。很抱歉。不过，也不能全怪我一个人！”

“那还怪谁呢？怪我吗？”

“不……我不知道！大概也怪普天下之物吧，因为所有的一切都是那么可怕和残酷！”

“唉，说这种话是没有用的。半夜三更把家弄得不成家，有多不好啊！要是不注意，伊利莎会听见的！（他指的是女仆）你想一想，镇上的两个牧师，要是让他们谁看见，会多么糟糕呀！我可不愿闹出丑闻，苏。你太任性，太难让人理解了。不过，我决不会再干扰你；我只劝你不要把门关得太严，不然明天早晨会闷死的。”

次日晨，他一起床就立刻去查看衣帽间，可是苏已经下了楼。她躺过的地方有个小窝窝，上方挂着蜘蛛网。“一个女人的厌恶感竟然超过了对蜘蛛的恐惧，那该是多么强烈的厌恶感啊！”他苦涩地对自己说。

他发现她正坐在早餐桌旁。于是，他们几乎一言不发地开始吃饭。外边的路面比客厅里的地板高两三英尺，镇上的居民走过人行道（或者不如说是马路，因为人行道在该地区极为少见），都要跟这对幸福的夫妻点头打招呼。

“理查德，”她猛不丁说道，“我和你分开住，你不会介意吧？”

“分开住？结婚前分开住，结婚之后还分开住，那为什么还要结婚呢？”

“我要是把原因告诉你，你会更生我的气的。”

“不妨让我听听。”

“因为我当时觉得自己没有别的选择。我在很久以前就答应要嫁给你，这你该记得，后来过了一些时候，我后悔不该许下那样的诺言，于是就企图找个体面的办法解除婚约。但由于找不出办法，我变得有些轻率，对世俗观念掉以轻心。你知道后来发生了什么样的风波；你花了那么多时间和心血才使我进了师范学校，可我却被逐出了校门。我当时吓坏了，觉得唯有让婚约生效，才能挽回局面。当然，在所有的人里边，我最不应该在乎那种谣言，因为我觉得我从来没把那种东西往心上放过。然而，我是个懦夫，和许许多多的女人一样，反潮流的思想彻底崩溃了。如果没发生那种情况，我当时伤害一下你的感情，也比嫁给你后终生伤害你强……你是那样宽宏大量，从未相信过那些谣言。”

“我必须如实相告：我当时考虑过其中的可能性，并问过你的表哥。”

“啊！”她叫了一声，神情既痛苦又诧异。

“我并非怀疑你。”

“可你向人打听过我！”

“我相信了他的话。”

她的眼里充满了泪水。“要是换上他，就决不会打听！”她说道，“你还没回答我的问题呢。你允许我离开你吗？我知道提这样的要求是多么不合乎常理……”

“的确不合常理。”

“但我还是要提这样的要求。有关家庭的法律应该根据个人的性格而制定，因为性格分不同的种类。一些规定给别人能带来适意的生活，给性格奇特的人带来的则是痛苦！……你到底允许不允许我走？”

“可咱们结了婚……”

“如果一个人明知自己没犯罪，却因为受到法律条文的约束而痛苦，在这种情况下，把法律条文挂在心上又顶什么用呢？”她愤愤地说。

“可你不喜欢我就是犯罪。”

“我喜欢是喜欢你！但我认为我的感情不会超过这个范围……因为，一对男女如果和我的感受一样还以亲密的方式生活在一起，那就是通奸——不管在什么样的情况下，不管是否合法。好啦，我把心里的话都说出来啦！……你到底让不让我走，理查德？”

“你如此逼我，真让我感到难过，苏姗娜！”

“咱们为何不能达成一致，还对方自由呢？咱们签订了婚约，也一定能取消它——当然并不是从法律上，而是从道德上，尤其咱们还没有新的顾虑，没有孩子需要照料。咱们可以做朋友，相见时双方都不感到痛苦。啊，理查德，做我的朋友吧，怜悯怜悯我吧！过不了几年咱们俩都会死去，那时谁还会追究你曾经使我得到过解脱呢？你可能会觉得我性情古怪、过于敏感或者荒唐可笑。唉……我生性如此，如果不伤害别人，为什么非得让我受苦呢？”“可你伤害了我。你曾经发过誓，说要爱我的。”

“不错，的确是这样！不对的是我！我总是做错误的事情。宣誓永远地爱一个人跟宣誓永远信奉一种教条同样是不正确的。也跟宣誓永远喜欢吃某种食品或者喝某种饮料同样地愚蠢！”

“你的意思是要离开我独自生活？”

“哦，如果你硬要我这样，我可以独自生活。不过，我原意是和裘德住在一起。”

“作为他的妻子？”

“形式由我选定。”

费洛特孙不安地蠕动着身子。

苏继续说道：“‘无论男女，谁要是让这个世界或者周围的环境替他（她）选择生活的方式，那他（她）除过像猿猴那样模仿，再无须其他的能力了。’这是约翰·斯图特·米尔的话。我把这话体会得很深。你为何不能依着做做呢？我希望自己能遵循他的教导，以至永远。”

“我不管什么约翰·斯图特·米尔！”他呻吟着说，“我只想过平静的日子！请允许我说：我已经猜出你曾经爱现在仍然爱裘德·弗利——这在咱们结婚之前，我是料所未及的。”

“你既然已开始猜疑我爱他，那你可以继续猜下去。不过。假如我以前就爱他，你想我还需要请求你放我走去跟他住在一起吗？”

这是她在最后时刻丧失勇气后说出的话，费洛特孙觉得并不具备说服力。正在这时学校的钟声敲响，他也就没必要作出回答了。她变得如此令人费解，于是他把这视为一个妻子所能够提出的最无理的要求，和她其他的古怪行为是一样的。

这天早晨，他们像往常一样来到学校，苏走进教室。他每次回过头，都可以隔着中间的玻璃壁看见她的后脑勺。在教课和听学生回答问题时，由于思路迷乱，想集中也集中不起来，他的前额及眉毛产生了痉挛。临到最后，他扯下一片便条纸，在上边写道：

你的要求搅得我无法工作。真不知道我在干什么！那个要求是认真提出来的吗？

他把纸片折得非常小，交给一个小男孩让他送给苏。那孩子迈着不稳的步子跑进了教室。费洛特孙瞧见他的妻子转身接过条子，低下漂亮的脑袋阅读，微微绷着嘴唇，免得在那么多学生的炯炯目光下失态。他看不见她的手，但是却看得见她换了姿势。没过多久，那孩子走回来，却没有拿回复的字条。但几分钟之后，苏那个班的一个学生送来了一张小小的纸条，和他的一样，上边只用铅笔写了几个字：

万分抱歉，我的要求是认真的。

费洛特孙的神色更加不安了，两道眉毛交界的地方又抽搐起来。没过十分钟，他把刚才那孩子喊起来，派他又送去一张字条：

上帝知道，只要合情合理，我不想阻挠你。我只想使你生活舒适和幸福。你提出要和你的情人住在一起，可我不能同意如此荒唐的要求。不然，你会失去所有人的尊敬和爱戴，而我也一样！

过了一会儿，那间教室里出现了相同的一幕，接着便送来了回音：

我知道你是为了我好。但是，我并不想受到尊敬。“使人类以最丰富多样的形式发展”（引自于你所崇拜的亨伯特的著作），在我看来要比受人尊敬重要得多。毫无疑问，我的趣味是很低的，在你的眼里简直低得无可救药！假如你不让我去找他，那么你是否能满足我这样一个要求——住在你的家中，但和你分居？

对此，他没有写回信。

她又写了一个字条说：

我理解你心里的想法。但你能不能怜悯怜悯我？算我求你了——我求你对我发发慈悲！如若不是无法忍受，出于迫不得已，我决不会提这样的请求！我作为一个可怜的女人，衷心希望当初夏娃没有堕落，那样就可以像原始基督徒信仰的那样，使人类以温和的方式在乐园里繁衍生息。我不愿说无聊的话，只求你对我开开恩——即便我对你并不好！我可以离开这儿到国外去，或任何一个地方去，再也不打搅你。

将近一个小时之后，他送来了回复的字条：

我不想使你痛苦，对此你非常清楚！请给我一点时间。我可能会同意你最后的那项请求。

她写来一张字条说：

衷心感谢你，理查德。你对我这么好，我真不配。

这一整天，费洛特孙透过玻璃隔壁失魂落魄地望着她，心里感到非常孤独——跟未认识她之前一样地孤独。

但他信守诺言，同意在家中和她分居。在新的安排之下，开始的时候，他们吃饭时遇在一起，她的情绪还比较稳定，但后来由于各自的处境都很为难，她的心情便受到了影响，每一根神经都像竖琴一样绷得紧紧的。她说话模棱两可、杂乱无章，不让他说出清晰明了的话来。

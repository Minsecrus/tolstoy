# 6

当初返回故乡萨斯顿当小学校长时，费洛特孙引起了居民的兴趣，也唤醒了他们对他的记忆。居民们虽然并不像别的地方那样推崇他在各学科所取得的成就，对他本人却真心地敬重。归乡后不久，他娶回家一个漂亮的妻子。大伙儿说他的妻子太漂亮，他如果不注意会让他尴尬的……大家都很高兴有她这样一位街坊。

苏离家出走之后，在一段时间里并没有引起人们的议论。她在学校里的那个助理教师的位置，她走后几天之内就由另一位年轻女子接替了。这件事也未招来非议，因为苏的工作只是临时性的。可一个月的时间过去了，苏仍未露面，又加之费洛特孙无意中对熟人说他不知道妻子现在何处，于是居民们开始起了疑心，竟致仓促下结论，认为苏对他不忠，从他身边逃走了。这位小学校长对工作愈来愈懈怠，愈来愈无精打采，使这种看法显得合情合理。

虽然费洛特孙除过跟他的朋友吉林哈姆讲过，对其他人一概守口如瓶，可一旦人们普遍对苏的行为产生误解，他的诚实和爽直的本性就不允许他再沉默下去了。一个星期天的早晨，学校委员会的主席来到学校里，在处理完学校的事务之后把费洛特孙拉到一个学生们听不见的地方。

“请原谅我多嘴问一声，费洛特孙，因为大家都在议论呢。你家里的那件事是不是真的？你的妻子并未去访亲探友，而是和情人秘密私奔了吧？如果真是那样，我为你感到难过。”

“没什么，”费洛特孙说，“这件事并无见不得人之处。”

“她是去看望朋友了吗？”

“不是。”

“那又是怎么回事呢？”

“她出走的性质按通常的意义会让人为当丈夫的感到难过。可是，我却同意了她的做法。”

那位主席的表情好像没听明白他的话。

“我的话都是真的，”费洛特孙又以气恼的语调说，“她请求我允许她跟她的情人走，我便同意了。我为什么不能同意呢？她是成年人，怎么做人该由她自己定夺，而不是由我。我不是看管她的狱卒。话只能说到这里啦。我不希望受到别人的盘问。”

孩子们见他们俩一脸的严肃相，回家后便告诉了他们的父母，说费洛特孙夫人出了新鲜事儿。费洛特孙的小女仆——一位刚毕业的学生对外界透露，说费洛特孙先生曾经帮助他的妻子整理行李，问她需要多少钱，还给她的年轻恋人写了封友好的信，让他照顾她。委员会的主席经过深思熟虑，把这事跟其他的校董谈了。后来，他们要求费洛特孙私下去见他们。会晤进行了很长的时间，末了小学校长回家时，脸色显得苍白而憔悴。吉林哈姆正坐在他的房子里等他。

“唉，正如你料想的那样。”费洛特孙疲倦地一屁股坐在椅子上说，“他们要求我递辞职报告，因为我行为可耻，使我的那个遭受痛苦折磨的妻子得到了自由，或如他们所言，‘纵容她通奸’。可我偏不辞职。”

“要是我，恐怕就辞了。”

“我偏不辞。关他们屁事！这又丝毫不影响我的公务。他们要是高兴，可以开除我嘛。”

“如果你把声势造出去，这事就会上报，那你就永远也别想到别的学校任职了。你该看到，他们必须考虑为人师表的问题，考虑你的行为会影响孩子们，影响全镇的伦理观。照一般人看来，你的情况是无法辩护的。这话你得允许我说出来。”

可是对这一番忠告，费洛特孙却拒不听从。

“我不在乎，”他说，“除非他们开除我，否则我就不走。如果辞职，我就等于承认自己的行为是错误的。我一天比一天更加相信，在上帝的眼里，在所有诚实、正直的人眼里，我的行为是正确的。”

吉林哈姆看出，他的这位顽固不化的朋友早晚保不住这样的位置，但他什么也没再说。在适当的时间里——其实只过了一刻钟，正式的解雇公函便到了，那是校董们在费洛特孙离开之后起草的。费洛特孙的回复是不能接受解聘书，并召开了公众大会。他的朋友见他虚弱不堪、病容满面，就劝他留在家中不要参加大会，可他还是去了。他站起来反对校董们的决定，列举理由时态度很坚决，就跟他对朋友讲时一样。同时，他认为这属于家庭问题，和他们无关。校董们对他的话进行了批斥，坚持认为教师个人的古怪行为在他们的管辖范围之内，因为这会影响学生们的伦理观。费洛特孙说他不明白，一种以慈悲为本的行为怎么会对伦理观造成危害。

所有的体面人物以及经济宽裕的镇民一致反对费洛特孙。但是，却有十几位社会下层人站起来为他说话，这叫费洛特孙感到有些意外。

上文交代过，有一些奇特、风趣的走南闯北的江湖人士，在秋夏两节出没于维塞克斯境内名目繁多的集市和庙会，他们把萨斯顿当作他们的栖息地。虽然费洛特孙没跟他们当中的任何一个人搭过话，可现在他们却一副侠肝义胆，为身处危境的他进行辩护。这些人里包括两个下等杂役、一位经营气枪射击的汉子、几个为枪装弹药的女士、两个拳击赛经纪人、一位蒸汽机旋转木马经理，还有两个走街串巷卖扫帚的女人（她们自称是寡妇）、一位姜饼摊贩、一位管理船形秋千的人和一个“力量测试员”。

除过这班侠义的支持者，另外还有一些具有独立见解的人，他们的家庭生活也并非一帆风顺。大家走上前跟费洛特孙热情地握手，然后言辞激烈地在会上发表意见，结果引起了大骚乱。一块黑板被打破，教室里的三块窗户玻璃成了碎片，一瓶墨水泼在了镇议员的衬衣前胸上，教堂守门人被巴勒斯坦的地球仪狠狠砸了一下，以至于他的脑袋穿破了撒马利亚；许多人被打得眼发青、鼻子流血，其中竟有一个是可敬的教区牧师，肇事者是一位思想解放的烟囱工，此人向着费洛特孙一边。费洛特孙看到鲜血在牧师的脸上流淌，伤心得几乎呻吟出了声，觉得这场面太不幸、太可耻。他顿生悔意，认为校董对他提出要求时，他应该辞职。回到家后他就大病一场，第二天早晨连床也下不来了。

这次可笑又可悲的事件给他带来了一场重病。他孤苦伶仃地躺在床上，怀着一个中年人伤感的心情终于看到，他的学术生涯和家庭生活都一败涂地、前景黯淡。吉林哈姆都是在傍晚来看他，有一次提到苏的名字。

“她对我一点也不关心！”费洛特孙说，“她何必要操这份心呢？”

“她不知道你病了。”

“这样对我们俩都好。”

“她和她的情人住在哪里？”

“大概住在梅尔切斯特。起码，他们不久前住在那儿。”

吉林哈姆回到家坐下来，经过思考，最后给苏写了封匿名信。他怕苏接到信的希望渺茫，信封上写的是裘德的名字，寄往主教管区的首府。这封信抵达目的地后，被转往地处北维塞克斯的玛利格林，又从那儿被那个曾经服侍过裘德姑婆的寡妇转到了阿尔布利坎，她是唯一知道裘德现在住址的人。

三天后的傍晚时分，落日把余晖倾洒在布莱克莫尔峡谷的低地上，谷里的乡民们觉得萨斯顿各家各户的窗户在余晖中像火舌一样在燃烧。生病的费洛特孙仿佛听见有人向他的家中走来。几分钟后，卧室的房门被叩响了。费洛特孙没吭声，来人犹豫地推开门走进来——原来是苏！

她身着轻盈的春装，似幽灵般出现，进屋时轻飘飘如飞蛾一样。他把目光落到她身上，脸色红了一下，似乎欲言又止。

“我本不该来，”她带着惊恐的表情俯身望着他说，“可我听说你病了——病得很厉害；再加上，我知道你承认男女之间除肉体之爱外还有别的感情，所以我就来了。”

“我病得不厉害，亲爱的朋友，只是不舒服罢了。”

“这我可不知道，恐怕你只有患了重病，我才该到这儿来。”

“是呀……是呀。我真有点希望你不来！我的意思是你来得太早了些。不过，既来之则安之。我想你没听说过学校里的事吧？”

“没有……有什么事？”

“没别的，就是我要离开这儿到另外一个地方去。我和校董们意见不合，只好分道扬镳，仅此而已。”

无论现在还是以后，她连一时一刻都没想到，就因为放她走，他给自己招来了多么大的麻烦。这种情况一次都没在她的脑海里闪现过，她也没听到过萨斯顿传来的任何有关消息。二人净谈些鸡毛蒜皮的琐碎事；当他的茶水送来时，他吩咐那位惊异的小女仆给苏也摆个杯子。那个女孩子对他们俩的事所表现出的兴趣远远超出了他们的想象；她下了楼后，吃惊得睁大眼睛，两手乱舞。呷茶的时候，苏走到窗前，若有所思地说：“日落的景象简直太美啦，理查德。”

“从这儿观日落是最美的，因为太阳的余晖穿透谷里的迷雾创造了这种美。可是我却欣赏不到，因为夕阳照不到我躺的这个阴暗角落。”

“你想不想看这幅美景？就好像天堂启开了大门。”

“想倒是想，可我看不到。”

“我帮你的忙。”

“不行，床是移不动的。”

“你看着我怎么做。”

她走到放镜子的地方，把它用手拿到窗前能照得到太阳的位置，然后移动镜子，直至镜子把阳光折射到费洛特孙的脸上。

“这下你可以看到红彤彤的大太阳啦！”她说道，“我相信这能使你高兴——我衷心希望你能高兴！”她说话时，显得天真、善良，同时又怀着忏悔的心情，仿佛她愿为他赴汤蹈火。

费洛特孙凄惨地笑笑。“你真是个奇怪的人！”他喃喃地说，眼睛里太阳的光芒在闪闪发光，“发生了那样的事，你竟然想到来看我！”

“过去的事就不用提了！”她连忙说，“我得乘公共马车去赶火车，因为裘德不知道我到这儿来了。我来时他不在家，所以我必须立刻回去。理查德，你的身体状况比我预料的好，这叫我非常高兴。你不恨我吧？你一直都是我十分要好的朋友。”

“我很高兴你这么想，”费洛特孙嗓音嘶哑地说，“我并不恨你！”

当他们断断续续交谈的时候，这个阴暗的房间里很快就暮色一片了。待蜡烛送进来，也就到了她离去的时候。她把手放在他的手中，或者说在他的手上掠了一下，因为她接触他的手时动作非常轻。正当她快要把门关严之际，他喊了声“苏”。因为在她转身离开时，他注意到她的脸上挂着泪花，嘴唇在颤抖。

喊住她是一种下策——他在喊时便意识到了，可他却不由自主地做了。

苏走了回来。

“苏，”他含混不清地说，“你想跟我和好，留下来吗？我会原谅你的，把过去的事情一笔勾销！”

“不，不行，不行！”她慌忙说，“事情是无法勾销的。”

“你的意思是说，他实际上已成了你的丈夫？”

“你可以这么想。他正在跟他的妻子阿拉贝拉办离婚。”

“他的妻子！他有妻子，这对我可是个新闻。”

“那是失败的婚姻。”

“和你的一样？”

“是的，和我的一样。他这样并非全为了自己，多半是为了她。她写信来说这是对她的开恩，因为离了婚后她可能重新结婚，过体面的生活，裘德同意了她的请求。”

“一个妻子……对她开恩……啊，是呀，使她彻底解脱的确是一种恩典……可我不喜欢这种说法。我可以原谅你，苏。”

“不，不。我做了那样的事，是个非常坏的人，你不能再叫我回到你身旁了。”

苏的脸上露出惊恐的表情。每当他由朋友转为丈夫，她便惊恐万状，采取一切防御的手段抵制他做丈夫的感情。“我得走啦。我还会再来的——行不行？”

“甚至到了现在，我都不想让你走。我请求你留下。”

“谢谢你，理查德，但我必须走啦。既然你病情不似我原先想的那么严重，我就不能再待了！”

“她是他的人，从头至脚都属于他！”费洛特孙说道，但声音很轻，她正在关门，所以没听见。

她害怕费洛特孙旧情复发，而且也可能有点不好意思让他知道，以男人的观点来看，她的感情转移显得草率和肤浅；所以，她没有告诉他，她和裘德的关系至今仍架在半空。

费洛特孙躺在床上辗转反侧，像在地狱里受煎熬，脑子里一个劲在想：那个穿着漂亮的女人姓他的姓，对他既同情又厌恶，简直让他发狂，可是她却要急不可耐地回到她的情人身边。

吉林哈姆非常关注费洛特孙的事，对他本人也十分担心，所以每个星期要沿着上山的路到萨斯顿去两三趟；来回得走九英里的路，而且时间必须选在茶点与晚餐之间，在学校里辛苦了一天之后。苏探望费洛特孙以后，他又一次来访时，他的朋友正在楼下。吉林哈姆留意到，他原先的那种心神不定的情绪不见了踪影，现在显得比较稳定和镇静。

“你上次走之后，她到这儿来过。”费洛特孙说。

“不会是费洛特孙夫人吧？”

“是她。”

“啊！你们和好啦？”

“没有和好。她只是到这儿来，用白白的小手拍平我的枕头，当了半小时体贴入微的护士，然后就走了。”

“哦……活见鬼！岂不是有点太骚情啦！”

“你说什么？”

“哦……没什么！”

“你是什么意思？”

“我的意思是：她是个喜欢挑逗人、难以捉摸的女子。假如她不是你的妻……”

“她的确不是，而是另一个男人的妻子，只不过还名不正法不容罢了。我一直在想——这念头源于我和她的那次谈话——我应该对她开恩，彻底解除我们在法律上的束缚。她这次回来，我说我原谅了她，请她留下来，可她拒绝了我的请求，所以我觉得更需要解除我们的关系。我认为正是那样的事实敦促我下了决心，只是我当时没意识到罢了。如果她不属于我，把她绑在我身上又有什么用呢？我知道……我确信她一定会把我走的这一步视为莫大的恩典。因为作为同胞，她同情和怜悯我，甚至为我流泪，可要是把我当作丈夫，她却无法容忍我。她讨厌我——掩饰这一事实是不顶用的。只有把我已经开始了的事情做完，才能表明我的男人气概，表明我的尊严及怜悯之心……从人情世故上来讲，使她得到自由，也是较好的选择。由于我做出了对我们而言是最好的决定，我前程被毁，陷入了绝望的境地，可她并不知道。我所面临的是可怕的贫困，因为别人再不会聘我当教师。在我的后半生里，由于没了工作，我可能将为了糊口东奔西颠、疲以奔命。这种困难，我一个人反而比较好承受。我可以告诉你，使我动了还她自由念头的，是她带来的一条新闻——弗利也在做同样的事情。”

“哦……他也有配偶。好一对奇怪的情侣！”

“欸，我并不需要你对此发表看法。我想说的是：我还给她自由，不可能会对她造成伤害，而会给她开辟出一条幸福的道路，这是她做梦也没想到过的。那时，他们就能够结为良缘，那本是他们最先就该做的。”

吉林哈姆没急于回答。“我也许并不同意你的理由。”他说话的时候语气温和，因为他虽然不同意费洛特孙的观点，但却心怀敬意。“不过，我认为你的决定是对的，但愿你能付诸实施。可话又说回来，我担心这恐怕行不通。”

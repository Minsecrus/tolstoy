# 3

苏到家时，裘德正在门口等她，准备去办结婚的第一件手续。她紧紧抓住他的胳膊，二人默默无语地走在一起，像真正的同志常有的那样。他见她心事重重，便忍住了话头。

“喂，裘德，我和她谈过了。”她最后终于说道，“真后悔不该去！不过，她提醒了我一些情况，倒是件大好事。”

“希望她对你还算客气。”

“她很客气。我由不得都喜欢上她了——只那么一丁点！她的天性并非鸡肠小肚；而且，我感到非常高兴的是，她的困难一下子全部解决啦。”她解释了阿拉贝拉怎样应召欲返，说阿拉贝拉可以就此恢复原来的状况。“我对她讲了咱们的老问题。阿拉贝拉的话使我越发觉得，惯例性的合法婚姻庸俗到了不可救药的地步，是捕捉男人的陷阱，一想起来就让我受不了。我后悔不该答应你，让你今天早晨张贴结婚预告！”

“噢，没关系。什么时候结婚都行。我原以为你也想把这事赶快办了呢。”

“说实话，我跟从前一样，并不觉得着急。要是跟别人，我也许会有点急的。你我家族里的人所具有的美德虽然为数极少，但我认为忠实可靠可以算作咱们的美德。既然我实际上已是你的人，你实际上也是我的人，我就一点也不害怕失去你。其实，我现在比过去更心安理得，因为理查德获得了自由选择生活的权利，这打消了我的内疚感。我曾经觉得，咱们以前欺骗过他。”

“苏，你这种情况，就好像并不仅仅是基督教国家的公民，而更像灿烂的古代文明中的一个女人，是我在过去浪费掉的那些钻研古典著作的岁月里所阅读过的书中人物。每逢这种时候，我觉得你可能会说出这样的话：你在圣路上遇到一位朋友，刚刚跟他谈起过奥克塔维亚及莉薇娅最近的情况；或者你刚听过阿斯帕齐娅的雄辩词；或者你目睹了普拉克西特列斯怎样雕刻最新的维纳斯像，同时耳闻了芙里尼如何抱怨自己已厌倦为普拉克西特列斯当模特儿。”

此时他们已来到教区牧师的门前。苏退后一步站住，而她的恋人向大门走去。正当他举手要敲门时，她喊了声：

“裘德。”

他回过头来。

“等一等，你不介意吧？”

他走回到她身旁。

“让咱们再想想。”她胆怯地说，“有天夜里，我做了个非常可怕的梦！……而且，阿拉贝拉……”

“阿拉贝拉对你说什么来着？”他问道。

“哦，她说：当人们被婚姻绑起来的时候，如果妻子遭到丈夫的殴打，可以让法律撑腰；如果夫妻俩吵架……裘德，当你通过法律得到我的时候，你认为咱们能似现在这般幸福吗？咱们家族里的男男女女在一切都顺心如意的情况下是十分宽宏大量的，可一旦受到压制，就会变得桀骜不驯。难道你不害怕法律义务会导致冷淡无情的态度吗？难道你不认为法律义务会葬送掉以自然感情为核心的爱情吗？”

“老实讲，亲爱的，你如此危言耸听，开始让我也感到害怕啦！咱们回去再想想。”

她面露喜色。“是啊，好好想一想！”她说。

他们俩转身离开牧师的大门。苏挽起他的胳膊，在回家的途中低声吟诵诗句：

谁能使蜜蜂不游荡于花丛？

谁能使斑尾林鸽的脖颈不改变颜色？

谁都不能！

连披枷戴锁的爱情也……

对于结婚的事，不管他们仔细考虑了没有，反正他们没采取行动。他们似乎生活在梦中的乐园里。两三个星期过去了，而事态却毫无进展，阿尔布利坎的教民们谁也没听到他们公布结婚的消息。

就在他们的婚事一拖再拖的时候，一天早饭前，他们收到了阿拉贝拉寄来的一封信和一份报纸。裘德看见信封上的笔迹，就跑到苏的房间告诉了她。苏穿好衣服，便急忙下了楼。她打开报纸，而裘德拆开了信。她扫了一眼，便把第一页报纸递到他跟前，用手指着上面的一则消息。可是，他正在专心致志地看信，一时没扭过脸来。

“你瞧一瞧！”她说。他侧过脸阅读起来。这份报只在伦敦南区发行，上边用线圈出的广告栏目只报道了在滑铁卢路圣约翰教堂办理的一桩婚事，新婚伉俪是“卡特莱和顿恩”——即阿拉贝拉与那位酒馆老板。

“好啦，事情结局圆满。”苏满意地说，“不过，咱们亦步亦趋地学，似乎就庸俗了些。我还是很高兴的……那个可怜的女人不管有什么缺点，我想现在总算衣食有安了。这样想，总比为她感到不安好。也许，我也应该给理查德写封信，问问他的情况吧？”

可是，裘德仍然没有分出心来。他仅仅瞥了一眼那则结婚通告，然后用一种忧虑的声音说：“你听我念念这封信。我该怎么回复以及该怎么办呢？”

亲爱的裘德（我不愿显得太生疏，称你为弗利先生）：

我今天寄给你一份报纸，以便让你知道我和卡特莱于星期二又举行了一次婚礼。我们的事最后总算完全彻底地解决了。不过，我写这封信，主要是为了一件私事——就是我去阿尔布利坎时想跟你谈的那件。我当时不便告诉你的女友，很想亲口讲给你听，因为那样比写信解释得更清楚。裘德，情况是这样的——我虽然以前从没告诉过你，但离开你八个月之后，我生下了咱们俩的一个男孩。那时我在悉尼，跟我的父母住在一起。此事很容易证实。我离开你之前，没想到会发生这样的事；后来我身在异国他乡，再加上咱们的吵架留下的伤痕太深，所以我觉得不便写信言明此事。我当时正在寻找好的工作，所以孩子由我的父母照料，一直跟他们待在一起。由于这种情况，我在克里斯特敏斯特遇到你时以及咱们办理离婚手续时，我就没有提。他现在已到了懂事的年龄。我父母最近写信来，说他们那儿的日子非常艰难。他们认为我在英国有了舒适的家，就不应该把孩子再让他们负担了，因为孩子的父母都还活着。我倒想把孩子留下，跟我一段时期，可他年纪太小，帮不上酒馆里的忙，恐怕好多年内都帮不上忙。这样，卡特莱自然就会觉得他碍事。碰巧澳大利亚有几个朋友要回英国，我父母就把孩子交给朋友们，打发他来找我。他来后，我得请你收下他，因为我不知如何安顿他才好。他的确是你合法的儿子，对此我敢冲天起誓。如果有谁说他不是，那你就替我骂他们撒的是弥天大谎。不管我前前后后都干了什么错事，自从咱们结婚一直到分手我对你都是诚实的，而且那之后也是诚实的。

你的阿拉贝拉·卡特莱

于朗伯斯区“三只角酒馆”

苏听完后惊慌失色，低声问道：

“你打算怎么办，亲爱的？”

裘德没回答，苏焦灼地望着他，一口一口喘着粗气。

“这对我是当头一棒！”他低声说道，“也许是真的呢！反正我也无法澄清。当然，如果孩子的出生日期跟她说的吻合，他就是我的。我不明白，那天我在克里斯特敏斯特遇见她，当晚和她一起到这儿来，她为何没告诉我？……啊，对啦，我现在记起来了：她曾说过有件心事，如果我们破镜重圆，她就告诉我。”

“那可怜的孩子，好像谁都不想要他！”苏说着，眼里泪水汪汪。

裘德此刻已稳住了情绪。“不管他是不是我的，他对人生该会有什么样的看法呀！”他说道，“我必须说，如果我的境遇好些，我丝毫都不会犹豫去考虑他是谁的孩子。我会收留他，把他养大。孩子的父母是谁——这种鄙俗的问题，说到底又算得上什么呢？我们时代的所有儿童，都是我们成年人共有的孩子，应该受到大家的照料。父母溺爱自己的子女，厌恶别人的子女，这就像阶级感情、爱国主义、自救主义及其他品德，实际是一种可耻的排他利己思想。”

苏跳起来，怀着热烈的崇拜情绪吻了裘德。“对，正是如此，我最亲的人！咱们让他到这儿来！假如他不是你的儿子，那反而更好。但愿他不是你的——不过，也许我不该这么想。如果他不是你生的，我很想收下他做咱们的螟蛉之子！”

“你怎么高兴，就怎么设想他吧，我爱管闲事的小同志！”他说，“我觉得，我无论如何都不愿丢下那个不幸的小家伙不管，你可以想想一下他在朗伯斯那家酒馆里的生活以及那儿的不良影响——一个不想要他，而且实际上几乎很少见他的母亲，和一个与他素昧平生的继父。‘让我出生的日子，以及那个宣称怀上男胎的夜晚见鬼去吧！’这就是那个男孩——也许是我的儿子——过不了多久便要说出的话！”

“噢，不会的！”

“离婚诉讼时我是原告，所以我觉得的确应该由我监护他。”

“不管是不是那回事，咱们都必须收养他。这是我的看法。我会尽我所能当好他的母亲。咱们怎么说也能养得起他。我将更加努力工作。不知他什么时候来？”

“大概在几个星期之内吧。”

“我希望……咱们何时才有勇气结婚呢，裘德？”

“你有勇气的时候，我就会有的。完全取决于你，亲爱的。你只要说一声，咱们就办事。”

“在那孩子来之前吗？”

“当然。”

“也许那样更像个家。”她低声说。

裘德用纯粹公事公办的正规语气给阿拉贝拉写了封信，要求孩子一到就送来，没提阿拉贝拉的消息使他感到多么意外，没对孩子的父亲究竟是谁发表看法，也没说明他当初要是知道孩子的情况，是否还会以同样的态度对待她。

在那列按时刻表应在第二天晚上十点钟左右抵达阿尔布利坎站的下行火车上，可以看见一个脸色苍白的小男孩坐在阴暗的三等车厢里。他有一双惊恐的大眼睛，戴一条白色的毛围巾，围巾外边挂着把钥匙，用普通的线绳拴着绕在脖子上。钥匙在灯光下偶尔闪闪发亮，招来周围人的目光。他的帽箍上插着他的半价车票。他的眼睛固定地盯着对面座位的后背，从不朝窗口那儿望；甚至列车到站报站名时，他也不移动自己的目光。另一座位上有两三个乘客，其中一个是女工，膝盖上放着只篮子，篮子里有只小斑猫。女工不时把篮子盖揭开，小猫伸出脑袋，做几个顽皮、滑稽的动作。乘客们见了哈哈大笑，只有那个脖子上挂着钥匙、帽箍上插着车票的孤独的男孩是个例外。他用又圆又大的眼睛观望着小猫，似乎心里在说：“所有的笑声都源自误解。天底下其实并没有值得笑的东西。”

有时候停车，列车员会回头往车厢里瞧瞧，对男孩说：“放心，小伙子。你的箱子在行李车上很安全。”男孩无动于衷地应一声，想微笑却笑不出来。

他就像一位老者扮成少年的模样，扮演技巧拙劣，以致漏洞百出，暴露出本来面目。有时，这位生命如旭日东升的孩子心头会卷起远古时代的暴风骤雨，脸上的表情像是在回首似烟似海的时光，对自己看到的场景却似乎漠不关心。

旁的乘客一个接一个合上了眼睛，甚至连那只小猫也厌倦了它局限性极大的游戏，在篮子里蜷伏起身子，可那个男孩子却一如往初。他似乎加倍地提高了警惕，宛如遭受奴役的侏儒神，呆呆坐在那儿望着旅伴们；他看到的仿佛不是他们的血肉之躯，而是他们整体的生命。

这就是阿拉贝拉的儿子。阿拉贝拉做事总是马马虎虎，迟迟没给裘德写信，一直到孩子下船的前一天，无法再拖的时候，她才写信告诉了裘德。其实她几个星期前就知道孩子要来，正如她所言，那次到阿尔布利坎，主要是想对裘德讲明孩子的身世以及他近期要来英国的消息。就在她接到前夫回信那一天的下午时分，孩子抵达了伦敦码头。负责送他的那家人，把他安顿到一辆去朗伯斯的马车上，把他母亲的地址告诉给车夫，跟他道别，然后就管自走了。

孩子来到“三只角酒馆”，阿拉贝拉把他上下打量一番，那神气像是在说：“你跟我料想的一模一样。”她让他饱餐一顿，塞给他一点钱，也不管天色渐晚，就打发他乘下一班火车去见裘德。她丈夫卡特莱出了门，她不希望他回来时看到这孩子。

火车抵达阿尔布利坎后，孩子被撂到了冷冷清清的站台上他的箱子旁边。检票员收了他的车票后，觉得情况不对劲，便问他这么晚了独身一人要到哪儿去。

“到春季大街去。”小家伙漠漠地说。

“哦，从此处到那儿有很远的路，差不多都出了城。等你到那里，人们都睡了。”

“我必须去。”

“带着个箱子，你得雇辆车。”

“不，我得走路去。”

“这样吧，你最好把箱子留下，回头来取。乘公共汽车可以走一半的路，但剩下的路你得步行。”

“这我不怕。”

“你的朋友为什么不来接你，嗯？”

“我想他们不知道我要来。”

“你的朋友叫什么？”

“妈妈不让我说。”

“我能做的，就是为你保管这箱子。现在你就走吧，能走多快就走多快。”

孩子没再说什么，出了站来到街上，向四周看看——没有人跟踪也没有人注意他。他往前走了一段路，向人打听起他要去的街道。别人告诉他直走，走到城镇的边缘就到了。

孩子迈起四平八稳、机械的步子赶路，步态缺乏个性，犹如波浪翻滚、微风吹拂或云彩飘游。他丝毫不差地按那人指的路走，目不斜视，对什么东西都不看。可以看得出，这个孩子的人生观跟当地的孩子不一样。普通的孩子都是先注意细节，再逐步观察一般现象；先注意眼前的，再逐步理解广泛的道理。这孩子似乎一开始就留意生活的普遍性，历来对细节不闻不问。显然，在他的眼里，那些房屋、柳树及远处朦胧的田野并非砖盖的住所、削去顶梢的树木及草地，而是人类抽象的居处、植物以及辽阔的黑暗世界。

他一路来到裘德住的那条小胡同，叩响了裘德家的门。裘德刚刚睡下，而苏也要进隔壁自己的卧室，却听见了叩门声，于是便走下楼来。

“爸爸在这儿住吗？”那孩子问。

“谁是你爸爸？”

“他的名字叫弗利先生。”

苏跑上楼，到裘德的房间告诉了他。裘德一听便急急忙忙下了楼，可她心里着急，仍觉得他动作迟缓。

“他怎么……来得这么快？”她见裘德走来，便问道。

她把孩子的眉目细细端量一番，然后就突然走开，到隔壁的那个起坐室去了。裘德把孩子抱起来，使孩子的脸跟他的脸在一个水平线上，既忧郁又温柔地仔细看着他，说如果知道他来得这么快，就一定会去接他的。随即，他把孩子暂时放在一把椅子上，回头去找苏，因为他知道苏那高度敏感的神经又受到了刺激。他发现她在黑暗中，正伏在一把扶手椅上。他用胳膊搂住她，脸贴着脸低声问：“怎么回事？”

“阿拉贝拉说的是实话——都是真的！我在他身上看见了你！”

“哦，不管怎样，这是我生命中的一个应该有的部分。”

“可他的另一半是她！这才是我无法忍受的！不过，我应该……我努力适应吧。是的，我应该这样做！”

“爱吃醋的苏啊！我曾说过你缺乏性意识，现在我把我的话全部收回。没关系，时间会把事情纠正过来……苏，亲爱的，我有个想法！咱们可以教育和培养他，将来送他上大学。我自己没实现的事业，也许可以通过他完成吧？你知道，现在情况好了，穷人上大学比较容易了。”

“啊，你真是个爱做梦的人！”她说完，拉起他的手回到孩子身边。

那孩子望着她，目光就跟她刚才端量他时一样。“原来，你真的是我妈妈？”他问道。

“怎么？我看起来像你爸爸的妻子吗？”

“哦，是的。他似乎很喜欢你，你也喜欢他。我能叫你妈妈吗？”

孩子脸上露出渴望的表情，而且哭了起来。苏忍不住，立刻也潸然泪下，因为她就像竖琴，别人的心中哪怕吹来最轻微的感情细风，也会拨动她的琴弦，在她的心里引起强烈的震动。

“如果你想叫，可以叫我妈妈，我可怜的宝贝！”她说着，俯身把脸贴在他的脸上，不让他看见自己的眼泪。

“你脖子上挂的是什么东西？”裘德故作镇静地问。

“是我箱子上的钥匙，那箱子还存在车站。”

他们忙活起来，为他弄了些晚饭，还为他临时搭了张床。孩子吃完饭，上床立即就睡着了。裘德和苏走过来，看着他的睡态。

“他叫了你两三声妈妈，才睡着了。”裘德悄声说，“多奇怪，他竟然渴望叫你妈妈！”

“哦……这是值得深思的。”苏说，“他那颗如饥似渴幼小的心灵提供给咱们的思考，比天上所有的星星提供的还多……我想，亲爱的，咱们是否必须鼓起勇气，把婚礼办了？逆流行舟不会有好处。我觉得我正在跟自己的亲人交融在一起。裘德呀，结过婚后，你可要好好疼爱我！我想关心这孩子，做他的母亲。咱们的婚姻合法化，可以使我做他的母亲更容易些。”

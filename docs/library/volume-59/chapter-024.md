# 4

他们对举行婚礼的另一次，即第二次尝试，虽然紧跟着那个古怪的孩子来到他们家的第二天就开始了，却也是经过较慎重考虑的。

他们发现那孩子喜欢默默地静坐，板着离奇古怪的面孔，眼睛盯着现实世界中所看不到的物体。

“他的脸就像墨尔波墨涅的悲剧面具，”苏说，“你叫什么名字，亲爱的？你告诉过我们了吗？”

“他们一直管我叫小时光老人。这是我的绰号，因为他们说我面老。”

“你的谈吐也很老。”苏温柔地说，“裘德，怪就怪在，这些显得异常老的孩子几乎全都来自于年轻的国度……你受洗时，他们给你起的什么名字？”

“我从没受过洗。”

“为什么？”

“因为我死的时候，省得为我举行基督徒的葬礼。”

“哦……那你的名字不叫裘德喽？”他的父亲有些失望地说。

孩子摇了摇头。“从没听说过这个名字。”

“当然没听说过，”苏急忙说，“因为她一直都在恨你。”

“咱们给他做洗礼，”裘德私下对苏说，“就选在咱们结婚的那天吧。”话虽这么说，那孩子的到来还是搅得他心神不宁。

他们的处境使他们感到难为情。他们觉得，到监督登记处登记结婚比到教堂结婚少招人耳目，便决定这一次避开教堂。苏和裘德一起到本地区的登记处申请；他们俩成了形影不离的伴侣，几乎做任何重要的事情都相伴而行。

裘德·弗利填写申请表格的时候，苏站在他身后看着他一个字一个字地写。这种四方表格她以前从未见过，登记着她和裘德的姓名。它将使他们之间轻松的感情、他们之间的爱成为永恒。想到这里，她的脸上露出了痛苦和忧虑的表情。

“配偶的姓名”……（她心想：他们将成为配偶，再不是恋人了）……“地位”……（多么可怕的字眼）……“身份或职业”……“年龄”……“住址”……“居住时间”……“举办婚礼的教堂或场所”……“男女双方居住的区县”。

“这样做破坏了咱们的雅兴，”她在回家的路上说，“好像比在法衣室里签署结婚合同还要鄙俗。在教堂结婚，倒还有点情调。不过，咱们这次争取把事情了结掉，亲爱的。”

“是啊。‘聘妻不娶，岂不是傻瓜？应该把妻子迎回家中，免得他阵亡后，别人把她娶走。’这是犹太立法者所说的话。”

“你对《圣经》太熟悉了，裘德！你真的该去当牧师。我只会引用世俗作家的话。”

在结婚证颁发之前的这段时期，苏出外为家里办事，有时路过登记处。她偷偷朝里边张望，看见墙上贴着有关他们即将喜结良缘的通告。这叫她无法忍受。她已经经历了一次婚姻，再把她的这次婚姻放在同一个模式里，便破坏掉了她和裘德爱情的浪漫情调。她出外通常都牵着小时光老人的手，心里老是胡思乱想，觉得人们都把这孩子当成了她的，把他们即将举办的婚礼视为对昔日错误的弥补。

与此同时，裘德决定请唯一活在人世、曾经和他早期在玛利格林的生活有过联系的老寡妇艾德林夫人来参加婚礼，以此使他的现在和过去产生丝丝缕缕的联系。艾德林夫人是他姑婆的朋友，在姑婆临终前的病中服侍过她。他对她是否肯来几乎不抱希望，然而她却来了，还带来了一些稀罕的礼物——苹果、果子酱、黄铜烛花剪子、一只白锻碟子、一个火盆、一大包做被褥用的鹅毛。她被安置进裘德家的一个闲着的房间，早早便歇息了。他们在楼下透过天花板，可以听见她在屋里按照礼拜规程大声而虔诚地念祈祷文。

可她睡不着觉，发现苏和裘德也没睡（其实，这时才十点钟），便又穿上衣服下了楼。大家围着火一直坐到深夜——小时光老人也包括在内。这孩子老是不说话，所以大家几乎感觉不到他的存在。

“哦，我不像你们姑婆那样反对结婚。”这个寡妇说道，“我希望你们这次结婚快快活活，事事如意。对你们家的事我恐怕比任何一个活着的人都知道得多，这是我最大的希望。上帝知道，你们家的人在这方面是很不幸的。”

苏的呼吸变得沉重起来。

“他们全都是些好心人，碰见苍蝇都不忍打死。”这位来参加婚礼的客人继续说道，“可他们一遇到不顺心的事情，心情就变得很坏。毫无疑问，正因为如此，传说中的那个人才做出了那种事情——只是不敢肯定他是不是你们家的。”

“做了什么事？”裘德问。

“哦，那是传说。他被绞死在了棕房子旁的山头上。那儿离玛利格林与阿尔弗利逊之间的里程碑不远，旁边有一条岔道。那是老早的事了，当时我的祖父还活着，而且被绞死的并不一定是你们家的人。”

“竖绞架的地方我倒也知道，”裘德低声道，“可我从没听说过这段故事。怎么……那个人——也就是我和苏的祖先——难道杀死了他的妻子？”

“其实并非那回事。他的妻子带着孩子逃离家门去投奔朋友，不幸孩子死在了异乡。他想要回孩子的尸体埋在家族的坟地里，可她硬是不肯。做丈夫的夜里赶着挂马车跑去，闯入那户人家想把棺材偷走，却被当场抓住。他冥顽不化，不肯讲明他私闯民宅的原因。人家把他按盗贼判了，绞死在棕房子的那个山头上。他死后，他的妻子就疯了。不过，他也许并不是你们家族里的人。”

这时，一个细微的声音慢腾腾从壁炉旁的阴影里传过来，仿佛从地缝里钻出来似的。“妈妈，我要是你，就不嫁给爸爸！”那是小时光老人的声音，把他们都吓了一跳，因为他们已忘记了他的存在。

“噢，那不过是种传说。”苏故作快活地说。

在举行婚礼前的这个夜晚，他们听寡妇讲完那段令人兴奋的往事，便起身跟他们的客人道夜安，然后去歇息了。

次日晨，苏精神愈来愈紧张，出发前私下把裘德拉到起坐间里。“裘德，我想让你吻我，作为恋人衷情地吻我。”她依偎到他怀里，颤抖着身子说，眼睫毛上挂着泪珠，“以后再也不会有这样的吻了！我真后悔不该着手办这件事。不过，我觉得既然开了头，就不能半途而废。昨晚的那个故事太可怕啦！我今天的心情都给破坏掉了。我觉得咱们家族就像阿特柔斯的家族一样，笼罩着悲剧的阴影。”

“或者跟耶罗波安的家族一样。”那位昔日的神学理论家说。

“是啊。咱们俩结婚，好像过于草率。我要像对我前夫那样对你山盟海誓，你也要像对你前妻那样向我信誓旦旦，全然不顾往事给咱们留下的前车之鉴！”

“如果你内心不安，我也不快活。”他说，“我原来还希望你会非常高兴呢。不过，不高兴就是不高兴，假装是不顶用的。你觉得这是件悲惨的事，我也有同样的感觉。”

“我只是觉得像那天早晨一样，令人感到不高兴，没别的意思。”她嘟哝道，“现在，咱们还是继续进行咱们的事吧。”

他们挽起胳膊向前边提到过的那家登记处走去，除过寡妇艾德林，没有别的证人跟随他们。这天天气凄冷、沉闷，从泰晤士河边的王宫那儿吹来一片潮湿的雾，在城镇里弥漫开。在登记处的台阶上，进去的人们留下了泥脚印；门口放着湿淋淋的雨伞。登记处的屋里聚集着一些人，我们的这对情侣看到一位士兵和一个年轻女子正在举办婚礼。婚礼在进行的过程中，苏、裘德以及寡妇艾德林站在不显眼的地方；苏看着墙上的那些结婚通告。屋里的气氛在一般人看来并没有什么特别的地方，但苏和裘德这样性情的人却觉得凄凉。法律书籍占满了一堵墙，羊皮封面都发了霉；别处放着邮局里用的姓名地址录及其他参考书；四周的架子上堆放着一卷一卷的文件，用红带子扎着；一个壁凹处放着几个铁保险柜；地板上和门口的台阶一样，被前边来的人踩得脏兮兮。

那位士兵满脸的不高兴，显得很不情愿，而新娘则阴郁而畏怯；显然，她马上就要做母亲了；她的一只眼青肿着。婚礼很快就结束了，那两人和他们的亲友们三三两两朝外走。其中有个当证人的在经过裘德和苏的身旁时，好似从前就认识他们一样，用随便的语气对他们说：“看见刚刚进来的那一对了吧？哈哈！男的今天早晨才从监狱里放出来。女的到监狱门口把他直接带到了这儿。一切花销，都由她付钱。”

苏扭头看见一个令人讨厌、头发剪得很短的汉子，胳膊上挎着位大脸盘、长着麻点的女人——那女人，由于喝了酒，并且因为自己的欲望马上要得到满足而心里得意，所以红光满面。他们嘻嘻哈哈跟正在朝外走的那对新婚燕尔打过招呼，走到了裘德和苏的前边去。这时，裘德和苏愈来愈缺乏自信。苏把身子朝后缩，对自己的恋人咧着嘴，好似一个马上就要大放悲声的孩子。

“裘德……我不喜欢这儿！我后悔咱们不该来！这地方让我感到毛骨悚然。难道这就是咱们爱情所达到的巅峰吗？简直太不合人意啦！如非结婚不可，还不如到教堂去，那儿不似此处庸俗气十足。”

“亲爱的小姑娘，”裘德说，“你的脸色是多么不安和苍白啊！”

“事已至此，大概必须在这儿举行了吧？”

“不。也许并不一定必须在这儿。”

他跟办事员说了几句话，然后又走了回来。“不用了，咱们不必非得在这儿或任何别的地方结婚；即便到了现在，除非咱们高兴，否则可以不结婚。”他说，“咱们可以到教堂结婚，如果结婚证不一样，就再领一张。不管怎样，咱们先出去，等你的心情平静些，我的心情也平静些，再仔细商量这件事。”

他们仿佛做了坏事一样，满脸愧色地偷偷溜出去，让一直留在门口处的艾德林回家等他们，说如果需要办事的话，他们就叫进来几个路人为他们作证。到了外边后，他们转入一条不常有人去的胡同，在那儿来回踱步，就像他们很久以前在梅尔切斯特的市场上一样。

“亲爱的，现在该怎么办呢？我感到事情乱成了一锅粥。不过，你高兴怎么办我都愿意。”

“可是，裘德，亲爱的，我给你添了烦恼！你本来是想在登记处把事办了，对不对？”

“呃，老实讲，我一进到登记处里边，就觉得好像不太感兴趣了。那地方丑陋不堪，使你觉得沮丧，几乎也同样令我感到沮丧。我想起了你今天早晨说过的话：咱们该不该结婚？”

他们漫无目的地朝前走着。后来，她停下来，又用她细小的声音说：“像这样优柔寡断，似乎太没有出息啦！不过，这又比再一次草率行事强得多……我觉得那儿的情景太可怕了！那个邋遢女人脸上的表情令我难以忘怀；岂不知，那并非她情愿委身于那个囚犯几个小时的事情，而是必须终生厮守。还有另外的那个可怜的女子，为了逃避由于自己性情软弱而造成的名义上的耻辱，就自贬身价，不顾真正的耻辱，为一个瞧不起她的暴君当奴隶；对于那样的男人，只有永远躲开，才是她唯一得救的机会……这是咱们教区的教堂，对不对？咱们要是按普通的方式结婚，就得在这儿举行仪式吧？里边好像正在做礼拜或什么的。”

裘德步上前去，朝大门里望了望。

“嗨，这儿也在办婚礼，”他说道，“今天所有的人好像都在跟咱们干同样的事情。”

苏说：“我想是因为四旬斋刚过，所以才有成群结队的人要结婚。咱们过去听听，看在教堂举办婚礼感觉如何。”

他们迈进教堂，在后边的座位坐下，观看在圣坛前举行的仪式。那对新人好像属于富裕的中产阶级，这类婚礼一般都办得体面而有意思。他们即便隔着很远的距离，也可以看见新娘手中的鲜花在颤抖，可以听见她机械地喃喃细语——由于心中害羞，她好像根本不明白那些话的含义。苏和裘德一边听，一边各自回想着他们在过去如何举办同一形式的自我束缚仪式。

“这可怜的女子！她结婚跟我再次结婚不一样，因为我现在已深有体会。”苏悄声说，“你瞧，他们初次涉足，把结婚视为理所当然之事。然而咱们俩，起码我个人，有过过去的经历，再加上我也许有时候过于神经质，醒悟到了结婚的可怕性和严重性，认为如果执迷不悟再结一次婚，实在是不道德的行为。来到此处看见这种场面，使我对在教堂结婚也感到害怕，就像刚才害怕在登记处结婚一样。咱们俩都属于优柔寡断、胆小怕事的人，裘德。别人有信心的事，我却狐疑满腹。我反对再做肮脏的交易，再缔结契约！”

他们苦笑了一下，接着便悄声你一言我一语地说起眼前活生生的教训。裘德说他也认为他们俩脸皮太薄，还说他们就不该出生，更别提共同去干那最荒谬的事情——结婚了。

他的未婚妻打了个哆嗦，认真地问他是否确实觉得他们不该再若无其事地去签那终生的契约。“如果你觉得咱们不够坚定，明明知道结婚发誓时要说假话，那岂不是太可怕了！”她说。

“既然你问起来，我大概真的有这种感觉。”裘德说，“别忘了，亲爱的，如果你愿意，我会跟你结婚的。”就在她举棋不定之际，他又承认道：他虽然认为应该结婚，但又和她一样害怕他们不能结婚，也许是因为他们很古怪，与众不同的缘故。“咱们都过于敏感，这才是问题的真正症结，苏。”他宣称道。

“和咱们一样的人恐怕要多于咱们的想象。”

“哦，我不清楚。结婚的意愿是好的，对许多人无疑也很合适，但对于咱们却没有好的结果，因为咱们属于古怪一类的人，一遇到家庭关系中出现强制的成分，就会丧失热忱和冲动。”

苏依然觉得他们并不十分古怪和特别，所有的人都和他们一样。“人人的感觉都逐渐会和咱们的一样，咱们仅仅是稍微超前一些罢了。再过五十年或一百年，这对夫妻的后裔在行为和感觉上恐怕还不如咱们呢。那时候，他们将比咱们现在更清楚地看到混乱的人类都是些他们将害怕生儿育女。”

“多么可怕的诗句！……不过，我心理扭曲时，对自己的同胞的确有这种感觉。”

他们就这样低声争论着。最后，苏以比较欢快的语气说：

“算啦，这种普遍性的问题不关咱们的事，咱们何必为此烦恼呢？不管咱们的原因有多么大的差异，结论都是一样的：不可改变的山盟海誓对咱们俩是一种冒险。裘德，咱们回家去吧，不要让咱们的梦破碎！行吗？你真好，我的朋友，对我的意愿总是百依百顺！”

“你的意愿跟我的很相似。”

趁着教堂里的人都把注意力集中在那一对新人身上，观看结婚的行列鱼贯走入法衣室，裘德在一根柱子后轻轻吻了吻苏。然后，他们走出了教堂。在教堂门口，他们一直等到两三挂刚刚离去了一会儿的马车又返回，等到那对新婚夫妇来到日光之下。

苏叹了口气说：“新娘手里的鲜花，不幸地很像古代点缀祭祀物——小牛的花环。”

“不过，苏，男人的境况并不比女人强。有些女人就看不到这一点，她们不去反抗环境，却把矛头指向男人——另一个牺牲品。就好像在人群里，女人只知道骂那个挤她的男人，岂不知那男人也无可奈何，只是把别人加在他身上的压力传递了过来。”

“是啊，有些女人就是这样。其实她们应该和男人联合起来，去反对共同的敌人，反对环境的压迫。”新娘和新郎此时已乘车离去，而苏和裘德也随着看热闹的人们从教堂前走开。“不，咱们不要结婚啦。”她继续说道，“起码目前不要结婚。”

他们回到家，挽着胳膊从窗前走过时，见艾德林寡妇正朝外张望。“喂，”待他们步入家门时，他们的客人嚷嚷道，“看见你们那么恩爱地走过来，我心里还在对自己说呢：‘他们终于打定主意结婚啦！’”

他们三言两语地解释了他们并没有打定主意。

“怎么？你们真的没结婚？老天呀，我活到这把岁数，总算看到‘仓促结婚悠闲悔’这句古训被你们俩糟蹋啦！如果新思潮把大家朝这方面引，我这就回玛利格林去！哎呀呀！我年轻的时候，没有人害怕结婚，天不怕地不怕，只怕挨炮弹和饿肚子。我和我可怜的男人结婚时，全当玩了一场‘羊拐子’游戏。”

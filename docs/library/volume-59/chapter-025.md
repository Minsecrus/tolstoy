# 5

小说家旨在描写书中人物的心理和行动，目的不在于对上文的那场严肃的辩论发表个人的看法。那对情侣虽然也有愁眉苦脸的时候，但他们的幸福是毋庸置疑的。裘德儿子出人意料的出现，经证明，非但没有像以前所想象的那样搅得他们心神不宁，反而使他们的生活中出现了一种新的高尚无私的舐犊之爱，对他们的幸福有益无损。

确切些说，由于他们总是事事求全、思前想后，所以孩子的到来也使他们对未来多了一份思考。特别令他们忧虑的是，这孩子目前似乎尤为缺乏一般孩子的那种前途有望的迹象。不过，这对情侣尽量不去过于热烈地展望未来，起码在一段时间里如此。

在上维塞克斯有一个古老的城镇，人口有九千到一万的样子；该镇可以被称作“斯托克秃山”。这座城镇，连同它那荒凉、丑陋的古代教堂，以及它那到处是红砖房的新郊区，都处于白垩土质的广阔麦田里。在人们的想象中有一块三角区，阿尔布利坎城、温顿塞斯特城以及夸特肖特军事重地各占一个角，而斯托克秃山则位于三角区的中心地带。从伦敦往西去的大道通过该镇，出镇不远分为两个岔道，再西行大约二十英里又合二为一。这一分一合，在火车问世之前，曾经给乘马车旅行的人带来了无穷无尽的疑问，不知选哪条道才好。但现在，那些疑问连同教区不动产收税人、乘马车旅行的人，以及为此争论不休的邮车车夫，都已经不存在了。现在的斯托克秃山镇居民，恐怕没有一个知道在他们镇分开的两条路到了前方又合为一条；因为，如今没有人整天赶着车来往于这条西行的大道。

如今，斯托克秃山镇上大家最熟悉的景物是它的公墓，坐落在铁路旁的那片颇具诗情画意的中世纪废墟间。现代教堂、现代坟墓和现代灌木丛在爬满了青藤的残垣断壁间，总显得有些格格不入。

在本故事涉及的那一年，六月初的一天，该镇风貌虽无引人入胜之处，却有许多外地人乘火车纷纷来到这儿，特别是乘下行车的，几乎全都在这儿下了车。原来，这个星期要在该镇举办全维塞克斯农业展览会。农展会的巨大帐篷在镇郊空旷的地方伸展开，活似一支包围该镇的军队所驻扎的营盘。一排排的帐子、木屋、布棚、亭子、门廊和游廊——各式各样非永久性的建筑物应有尽有，在草地上占了有半英里的面积。参加展览会的人们成群结队走过镇子，径直前往展览场地。沿途的道路两旁净是游艺摊、货亭和叫卖的小贩，把通往会场的道路变成了市场，使一些不注意节约的人尚未抵达他们特地前来参观的那个展览会的门口，便几乎已囊空如洗了。

这是一个热闹的日子，一个先令日。在风驰电掣赶来的游览车当中，有两列几乎是在同一分钟从不同的方向驶入了两个邻接的车站。其中有一列，和前边到达的几列一样，是从伦敦来的，而另一列来自阿尔布利坎，走的是条支线。从伦敦来的火车上走下一对夫妻：男的又矮又胖、大腹便便，长着一双小短腿，活似安在两根木桩上的陀螺；和他相伴的女的却体态婀娜，脸孔发红，身着黑装，浑身珠光宝气、亮光闪闪，仿佛裹着锁子甲似的。

他们东张西望。男的仿效其他的一些人，也想雇辆马车，而女的却说：“不要急急忙忙的，卡特莱，到展览馆反正也不太远。咱们顺着街道走到那儿得啦。说不定我还可以拣上一件便宜的家具或旧瓷器哩。我多年没到这儿来了。我在阿尔布利坎当女招待的时候，有时候倒是和我的男朋友来这儿玩玩。”

“你总不能搭游览车把家具运回去呀。”她的丈夫——朗伯斯“三只角酒馆”的老板以浑浊的声音说。这两口子的酒馆处于“人口稠密，优越的饮酒地区”。当初他们正是看到了这样的广告词，才被吸引了去，在那儿一直住到现在。从这位酒馆老板的体态看得出，他也和店里的顾客一样，正在逐渐受到他所出售的美酒的影响。

“要是看上值得买的东西，回头我想办法运回去。”他的妻子说。

夫妇俩溜达着朝前走。可没等进到镇里边，她的注意力就被一对领着个小孩的年轻男女吸引了去。那三个人从二号站台出来，阿尔布利坎来的火车就是停在那个站台。他们走在这对酒馆夫妇的正前方。

“老天爷呀！”阿拉贝拉说。

“怎么回事？”卡特莱问。

“你知道那对男女是谁？认不出那男的了吗？”

“认不出。”

“我不是让你看过他的照片吗？”

“是弗利？”

“对。正是他。”

“噢，他大概跟别的人一样，也是想来开开眼界。”卡特莱跟阿拉贝拉新鲜劲正浓的时候，他不管对裘德产生过怎样的兴趣，可自从她的魅力、特点、假发以及嘬出的酒窝成为讲过的故事之后，这种兴趣也就减弱了。

阿拉贝拉调整着她和丈夫的步子，使他们恰好跟在那三人的后边——在川流不息的人群中，悄悄地跟踪并不是件难事。对于卡特莱的话，她回答时都含含糊糊，因为前边那几个人比任何别的景物都令她感兴趣。

“他们好像很恩爱，也爱他们的孩子。”酒馆老板说。

“他们的孩子？那不是他们的孩子！”阿拉贝拉说话时，突然莫名其妙地换上了穷凶极恶的语气。“他们结婚时间不长，哪会有这么大的孩子！”

她那死灰复燃的母爱本能很强烈，使得她驳斥了丈夫的猜测，可转念一想，她又觉得除非万不得已，她不准备把话讲明。卡特莱先生蒙在鼓里，只知道他妻子和其前夫所生的孩子在大洋彼岸跟孩子的祖父祖母在一起。

“噢，可能不是他们的孩子。那女的看起来还像个小姑娘。”

“他们仅仅是恋人，或结婚不久，收养了那孩子，这谁都能看得出来。”

所有的人都在朝前走。他们所谈论的那对男女——苏和裘德对自己的处境却浑然不知。农业展览会距他们住的城镇不到二十英里，他们决定把今天作为游览日，将锻炼、游玩和受教育融为一体，而且花钱不多。他们并非先考虑自己，还特意把小时光老人也带了来，想方设法让他像其他孩子那样欢笑；在这次他们十分喜爱的旅程中，从某种程度上讲，小时光老人妨碍着他们进行欢快、无拘无束的交谈。但过不了多久，他们就不再把小时光老人视为旁观者了，彼此怀着柔情蜜意，那份感情就连最羞怯的人也难以掩饰。他们觉得周围净是陌生人，所以不像在家时那样着意地掩饰内心的感情。苏身着崭新的夏装，似鸟儿般灵巧、轻盈，大拇指按在白色的布阳伞伞把上，走起路仿佛脚不沾地，好像一阵比较大的风就能把她吹过树篱，刮到那边的地里。裘德身着浅灰色节日盛装，真心为有她这样的伴侣感到自豪，这不仅因为她外表迷人，更因为她言谈举止都跟他息息相通。他们之间心有灵犀，每一个眼神、每一个动作都能跟语言同样有效地表达心意，使他们就好似一个整体的两个部分。

他们带着孩子走过旋转栅门，而阿拉贝拉和她的丈夫跟在后边不远处。进到围墙内，这位酒馆老板的夫人看见前边的那两个开始在孩子的身上花时间，指指画画地为他讲解许多有意思的东西，包括有生命的和无生命的。每次尝试都遭到失败，始终引不起孩子的兴趣，他们的脸上会闪过一丝忧愁之色。

“瞧她把他缠得多紧！”阿拉贝拉说，“噢，我认为他们没有结婚，要不然他们就不会这样如胶似漆了……我怀疑他们没结婚！”

“可你不是说过他娶了她吗？”

“我只是听说他打算娶，听说他们把婚期推迟了一两次，又准备结婚……瞧他们那样子，就好像展览会上只他们两个似的。我要是他，就不会如此傻兮兮地丢乖露丑！”

“我看不出他们的举止有什么特别的地方。如果你不说，我绝对注意不到他们在相爱。”

“你从来什么都看不见。”她反驳道。

不过话说到这里，卡特莱在观察情侣或夫妻的行为上，目光的确跟芸芸众生是一样的，洞察秋毫的阿拉贝拉所看到的现象没有引起他的注意。

“他被迷得神魂颠倒，就好像她是天仙一样！”阿拉贝拉又说，“你瞧他扭过脸看她，让目光盯在她身上的样子。我觉得她爱他不如他爱她爱得深。在我看来，她虽然也尽了自己的能力，够爱他了，但她的心肠并不特别热。他如果愿意的话，可以让她伤心，但他脑子太简单，不会那样做。瞧，他们现在朝驭马展厅去了。咱们也过去。”

“我不想参观驭马。咱们没必要跟着那两人打转转。如果咱们是来看展览的，那咱们就看咱们的，让他们看他们的。”

“哦……假如咱们各走各的，互不相干，约好一个小时后在某个地方会面——就在那个糕点棚旁，你说怎么样？你可以看你爱看的，我也可以看我爱看的。”

卡特莱没加以反对，于是二人便分了手。他去了表演制麦芽酒的展厅，而阿拉贝拉朝着裘德和苏走的方向追去。可没等她撵到他们跟前，便遇到了一张笑脸——她未出嫁时的朋友安妮和她撞了个满怀。

安妮对这次不期而遇先自开心地笑将起来。“我还住在那儿，”她笑够之后立即说道，“我马上就要结婚了，可惜我的未婚夫今天没能来这儿。老乡们乘游览车来的很多，只是这阵子不见了他们的影子。”

“你碰见裘德和一位年轻女子在一起了吗？那女人不知是他的女朋友、妻子或什么的。我刚才瞧见他们啦。”

“没碰见。几年了，连他的影子也没瞧见过。”

“哦，他们就在这附近。你瞧，他们在那儿，在那匹灰马旁边！”

“噢，那是他现在的女人……你说是他的妻子？他又结婚啦？”

“我不清楚。”

“那女人长得还蛮漂亮！”

“是啊，没什么可挑剔和怀疑的。不过，也没多少可炫耀的，瞧她那瘦瘦小小、不稳重的样子。”

“裘德长得也蛮不错哩。你真该把他紧紧抓在手里，阿拉贝拉。”

“我知道应该那样。”阿拉贝拉嘟哝道。

安妮哈哈大笑。“你一点没变，阿拉贝拉，总是这山望着那山高。”

“哦，我倒要问问，哪个女人不是这样？至于他身边的那个女人，恐怕连爱情是什么都不知道，起码不知道我所说的爱情。这一点可以从她的脸上看得到。”

“也许，亲爱的阿比，你也不知道她的所谓爱情。”

“我坚信自己并不想知道！……啊哈，他们朝艺术展厅去了。我也想去欣赏几幅画哩。咱们到那边去，怎么样？……嗨，依我看，全维塞克斯的人都来了！韦尔伯特医生在那儿。多年不见了，可他跟我那时候认识的他一样，丝毫都不显老。你好，医生！我刚才还在说哩，你一点都不显老，仍然跟我还是个小姑娘时一样。”

“这只是因为我经常服用我的药丸，才有这样的结果，夫人。一盒才两先令三便士，管保灵验，有政府的印章为证。我建议你买盒服用，学我的样，以防将来年老色衰。只花两先令三便士。”

医生从背心口袋里掏出一盒药，阿拉贝拉只好出钱买。

“另外，”他收下药钱之后又说道，“请恕我眼拙，夫人……你该不是弗利夫人，即从前的顿恩小姐，住在玛利格林附近吧？”

“不错。可我现在是卡特莱夫人了。”

“啊……你失去了他？他可是个有前途的年轻人呀！你要知道，他当过我的学生，我教他学已消亡了的语言。请相信我，他没用多长时间，知识就几乎跟我一样渊博了。”

“我失去了他，但当时的情形你是想象不来的。”阿拉贝拉干巴巴地说，“是法律拆散了我们。你瞧，他就在那儿——虎虎有生、身体强健，正在和一位年轻女子一道进入艺术展厅。”

“啊……我的天！他显然很喜欢她。”

“都说他们是表兄妹。”

“这种表兄妹的关系为他们的爱大开方便之门，你说是不是？”

“是的。她丈夫跟她离婚时，肯定也是这么想的……咱们也去欣赏欣赏那些画吧？”

他们三个穿过草地，走进了展厅里。裘德和苏不知道自己引起了别人的兴趣，他们领着孩子走到展厅一端的一件模型跟前，聚精会神地观看了老半天才走开。阿拉贝拉和她的朋友们在适当的时候也凑到了模型跟前，见上面的题字是：“克里斯特敏斯特红衣主教学院模型——作者：裘·弗利和苏·弗·玛·布莱德赫。”

“原来是在欣赏他们自己的作品，”阿拉贝拉说，“江山易改，本性难移。裘德不讲求务实，脑子里总念念不忘学院和克里斯特敏斯特。”

他们匆匆忙忙把画浏览一遍，然后就到音乐台那儿听军乐队的演奏。他们站着听了一小会儿，裘德、苏以及那个孩子从另一边走了过来。阿拉贝拉并不在乎他们会认出她来。其实，裘德他们在军乐声中飘然若仙，深深沉浸在精神享受中，注意不到遮在珠光宝气帘幕下的阿拉贝拉。阿拉贝拉沿着听众的外围，从那对情侣的身后经过，因为她今天对那对情侣的举动意想不到地着了迷。她从后边仔细观察他们，见裘德抓住了苏的手；那两人站得非常近，可能是为了掩饰他们心照不宣、灵犀相通的感情。

“傻瓜，笨蛋！简直像两个孩子！”阿拉贝拉不高兴地低声自言自语道。她回到朋友们的身边，沉默寡言，一副满腹心事的样子。

这个时候，安妮开玩笑地对韦尔伯特说阿拉贝拉又热恋起了前夫。

“喂，”医生把阿拉贝拉拽到一边说，“你想要这种玩意儿吗，卡特莱夫人？我通常是不做这种药的，可有的时候别人跟我要，所以我就得准备一些。”他掏出一小瓶清澈的药水来。“这是春药，古代人用的，效力很好。我是通过研究古人的著作才开了窍；据我所知，这种药百试百灵。”

“是用什么做的？”

“这个……其中的一种成分是用鸽子心脏的汁液提炼出来的。装满这么一小瓶，用了一百只鸽子的心脏。”

“怎么弄到那么多鸽子？”

“我把秘密告诉你吧。先弄一块鸽子非常喜欢吃的石盐，把它放在房顶的鸽棚里。用不了几个小时，鸽子就从东南西北四面八方飞来。那样一来，我想要多少只就捕多少只。在使用这种药水时，要想办法让你渴望得到的男人喝酒，在他的酒里掺上十滴。不过你别忘了，我之所以跟你讲这些，是因为我从你的问话里觉得你有意购买。你必须信任我！”

“好吧，我可以买一瓶送给我的哪个女友，让她在她的男朋友身上试试。”她取出五先令的药钱，然后把药水瓶塞进了她那宽敞的怀里，过了没多大一会儿，她声称要去跟她的丈夫会面，随即迈着方步朝糕点棚走去。裘德、苏和那个孩子去了园艺展厅，阿拉贝拉瞥见他们站在盛开的玫瑰花丛前。

她停下来把他们观察了几分钟，然后怀着有点愤怒的心情去找她的配偶。她发现卡特莱坐在吧台旁的一条凳子上，正热火朝天地跟为他斟酒的一位打扮得花枝招展的女招待聊天。

“我觉得你在家里对这种生意已经厌倦了！”阿拉贝拉阴沉着脸说。“你跑了五十英里的路，从你自己的酒吧来到这儿，该不是为了在这儿泡酒吧吧？走，带我看展览去，也学学别的男人怎样对待他们的妻子！瞧你，别人还会以为你是个孑然一身的光棍汉，没人照料你哩。”

“咱们商量好在这儿碰面，我除了等待，还能做什么？”

“好啦，咱们现在碰上面了，那就走吧。”她说道。依她的心情，太阳把阳光洒在她身上，她都会跟太阳吵上一架。这位大腹便便的男子和这位服饰华丽的女人，就和基督教国家普通的夫妻一样，你怨我恨、相互数落着一道离开了糕点棚。

与此同时，那对与众不同的情侣却领着那个男孩流连忘返于花廊之中——这儿是一座富于魔力的宫殿，非常合他们的欣赏趣味。苏注视着鲜花，原本苍白的面孔泛上了红晕，沾染了玫瑰花的色彩。欢乐的景象、新鲜的空气、悦耳的音乐，以及和裘德一道游玩所带来的兴奋心情，加快了她的血液流动，使她眼里放射出愉快的光芒。她非常喜爱玫瑰花。阿拉贝拉刚才目睹的一幕原来是：她几乎拗着裘德的意愿硬让他留下——她看着牌子上这种花的名称，把脸贴近鲜花，只隔着一英寸远闻花香。

“多么可爱的花，我真想把脸贴到上边去。”她说道，“不过，那样做大概是违反规定的，对不对，裘德？”

“是的，你这个傻孩子。”他说道。随后，他调皮地把她轻轻推了一下，使她的鼻子插到了花瓣中间。

“警察会来干涉咱们的，到时候我就说是我丈夫的错！”

她抬头望着他，脸上含着微笑——那种微笑，刚才在阿拉贝拉眼里是那样意味深长。

“高兴吗？”他低声问。

她点了点头。

“为什么高兴？是因为你来参观了全维塞克斯农业展览会，还是因为咱们大家一起来啦？”

“你总是提出五花八门的荒唐事情，想让我承认。我高兴是因为我长了见识，参观到了这些蒸汽犁、打麦机、切草机、牛、羊和猪。”

对于一贯闪烁其词的同伴所表现出的迷乱，裘德感到很满意。随即，他忘掉了自己所提的问题，因他已经不再想听到答复。可就在这时，苏却说道：“我觉得咱们回到了古希腊的欢乐气氛中，忘掉了自身的痛苦和忧愁，忘掉了自古希腊以来二十五个世纪留给人类的教训，正如你的克里斯特敏斯特一位伟人所言……可咱们眼前仍有一道阴影——只有一道。”她说着，用眼睛看了看那个一脸老相的孩子。他们带他看一切可能引起小孩兴趣的东西，可这个孩子对什么都无动于衷。

孩子知道他们在说什么、想什么。“我非常抱歉，爸爸和妈妈，”他说道，“请你们别往心里去！我也是由不得自己。我心里老在想，这些鲜花用不了几天就会凋谢的，不然我会非常喜欢它们的！”

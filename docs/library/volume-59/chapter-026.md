# 6

这对情侣的生活以前无人注意，可自从那天他们的婚礼悬而未决，除过阿拉贝拉之外，别的人也开始观察和议论起他们。春季大街以及周围一带的居民一般都不明白，也不可能明白苏和裘德内心的思想、感情，不明白他们的处境及恐惧。一个孩子突然出现，把裘德叫爸爸，将苏称为妈妈；为不引人注目打算在登记处举办结婚仪式，却半途而废——这两种奇怪的现象，再加上有关于他们离婚诉讼时无人提异议的流言蜚语，对一般人来说只有一种解释。

小时光老人——他虽然已正式取名叫“裘德”，但这个绰号对他很恰当，故一直沿用——傍晚放学归来，便复述其他的孩子问他和议论的话。苏和裘德听了，感到十分痛苦和难过。

结果，继他们那次在登记处结婚未成不久，他们俩便雇个人照看孩子，自己出了几天门——据说是去了伦敦。待返回家中，他们带着非常淡漠及疲惫的神气放出风声，说他们终于合法地结了婚。苏以前被人称作“布莱德赫夫人”，现在则公开采用了“弗利夫人”的称号。有好几天的时间，她显得苦闷、畏怯和不安——这样的表现似乎就是一种佐证。

然而，他们神不知鬼不觉地离开家去结婚，这本身就可以被称为错误，使人们仍觉得他们的生活非常神秘。他们原以为此举可以给邻人们造成好印象，这时才发现并不是那么理想。人们对活人的秘密所产生的兴趣，并不逊色于对死者的丑事。

面包店的杂役及杂货铺的伙计以前来送货时，常对苏脱帽致意，这些日子却省掉麻烦，不再给她这种荣誉了；附近匠人的妻子们在人行道上碰见她，则目不斜视地朝前走。

固然不错，没人欺负他们，但一种令人感到压抑的气氛开始盘桓于他们心头，特别是在展览会之行以后，仿佛那趟旅行给他们施加了某种邪恶的影响。他们这种性格的人，一方面在这种气氛里痛苦不堪，一方面又不愿理直气壮地把话公开说出去以减轻压力。待他们准备采取补救措施，却已为时太晚，产生不了效应了。

请他雕墓石和凿碑文的顾客愈来愈少。过了两三个月，当秋季来临时，裘德发现自己只得重操旧业，四处打零工了；眼下出现这种情况尤为不幸，因为他去年付离婚诉讼费迫不得已欠下的债至今都未还清。

一天傍晚，他与平时一样，坐下来跟苏及孩子一起进餐。“我在想，”他对苏说道，“不能再在这儿待下去了。当然，咱们适应了这里的生活，但如果能到一个没人认识咱们的地方去，咱们的心情会轻松些，机会也多些。所以，不管你觉得怎样为难，咱们恐怕都必须搬迁了，我亲爱的小可怜！”

苏一想到自己成为怜悯的对象，心情总是会受到很大的影响，于是她难过了起来。

“哦……我并不感到遗憾。”她过了一会儿说，“这儿的人看我时的眼光，让我觉得十分不舒服。你租这栋房子和摆这套家具，全是为了我和孩子。你自己并不需要，这笔钱是没必要花的。不过，不管咱们做什么，到什么地方去，都不能让我跟孩子分离，行不行，亲爱的裘德？现在我已无法和他分开了。他幼小的心中阴云笼罩，让我见了心如刀绞。真希望有朝一日能拨开他心头的浓雾。而且，他是那样地爱我。你不会让我和他分开吧？”

“当然不会，亲爱的小姑娘。不管咱们到何处去，都会有舒适的家。我可能要四处奔波，到各个地方寻活儿干。”

“当然，我也要做点事情，直到……直到……噢，我要是不能帮忙描字，那我就得干别的活儿。”

“别急着找活儿干，”他后悔地说，“我不想让你去工作，希望你留在家里。招呼孩子和你自己，就够你忙活的了。”

这时传来了敲门声，裘德跑去开门。接着，苏可以听见有人说：

“弗利先生在家吗？……白尔维利公司最近在附近的乡下修复了一个小教堂，派我来问你愿不愿去那儿干活儿，雕刻十诫全文。”

裘德想了想，然后说他可以去。

“那活儿不需要多高超的技术，”信使继续说道，“牧师是个老脑筋，不同意对教堂大动干戈，只允许清理和修补。”

“多么好的老人！”苏自言自语道。她从心里不赞成修复中过了头的可怕行为。

“十诫的全文都固定在教堂东头，”信使又说道，“需要和那堵墙一道修补，按通常的规矩，本该把它们全拆掉，算作报废的材料由承包人拉走，可牧师硬是不同意。”

双方商量好了条件。然后，裘德回到了屋里。“啊，你瞧吧，”他高兴地说，“不管怎样，又揽了一件活儿。你可以去帮忙——至少你可以试试嘛。别人的活儿已竣工，所以教堂里只有咱们两个人。”

次日裘德去了教堂，那儿离家只有两英里的路程。他发现那位公司办事员说的话都是真的。上面凿刻着犹太戒律的石碑威严地耸立在基督教圣器的上方，成为圣殿一端的重要饰物，具有上一世纪的那种朴实无华的格调。由于碑框由装饰性泥灰制成，不能取下来修补，有一部分被潮气腐蚀得面目全非，需要更换。他把这件活儿干完，彻底清理了一遍，然后开始重凿碑文。第二天早晨苏也来了，想看看能提供什么样的帮助，也因为他们喜欢待在一起。

教堂里寂静无人，给她增添了信心。裘德为她搭了个较低的、很安全的架子，但她往上爬的时候仍胆战心惊。她站在架子上开始描第一块碑上的字，而裘德着手修补第二块碑的破损部分。她为自己的本事感到十分得意，那是她在克里斯特敏斯特的圣物店里描经文时学来的。这儿好像不会有人来打搅。悦耳的鸟鸣，以及十月间树叶的沙沙声，透过一扇敞开的窗户传进来，跟他们的谈话声混在一起。

但是，这种舒适、安宁的景况没有持续多长时间。十二点半左右，外边的砾石路上响起了脚步声。老牧师和教堂执事进来巡视，见一个年轻女子在帮忙干活儿，不由露出了诧异之色。他们继续朝前走，进了一条甬道；这时教堂的门又开了，走进来一个小小的身影——原来是小时光老人哭哭啼啼地跑了来。苏曾告诉过在哪儿可以找见她，让他放学后愿意的话就到这儿来。她下了架子问道：“怎么回事，亲爱的？”

“我无法留在学校里吃饭，因为他们说……”接着，他讲述了一些孩子是怎样嘲笑他，说他只有个名义上的妈妈。苏听后很伤心，对架子上的裘德表示了内心的愤怒。孩子到教堂的墓地去了，苏转回去干活儿。可就在这时，大门又开了，一个系着白围裙、样子一本正经的女人走进来——她是教堂的清洁工。苏认出了她，知道她在春季大街有些朋友，她常去那儿看望她们。这位教堂清洁工望着苏，张着大嘴，把手扬了起来。她显然认出了裘德的伙伴，就像对方已认出她来一样。接着又进来两位女士，她们跟清洁工说了几句话，也步上前来，看着架子上的苏，观察她用手描字，挑剔地打量着她那以白墙为衬托的形体。后来，苏变得精神紧张，全身哆嗦起来。

这两位女士又回到原地，另有几个人正站在那儿压低声音交谈。其中有一个说道（苏听不清是哪一个）：“我想她是他的妻子吧？”

“有的说是，有的说不是。”清洁女工答道。

“谁说不是？她应该是他的妻子，或嫁的是别人——这是非常清楚的！”

“就算是他的妻子，他们也才结婚没有几个星期。”

“邪了门啦，怎么请他们俩来修这两块圣碑！不知白尔维利怎么能想起雇用他们！”

清洁女工认为白尔维利不知道他们有过失，而原先跟那位老妪说话的女人解释了她为什么说雇用这对情侣是很荒唐的。接下来，大家用很低的声音窃窃私语。教堂执事穿插了一件趣闻轶事，由此可判断出他们窃窃私语的内容。虽然趣闻轶事很明显是根据眼前的情形所讲的，但他说话时用的声音，使教堂里的每个人都能听得见。

“是啊，这种现象是让人不能理解，可我的祖父给我讲过一件极为邪恶的事，那才是咄咄怪事哩。事情发生在吉米德旁边的一个教堂里，从这儿走路去也没多远，当时也是请人修描十诫。那些年月，十诫大多用的是金字黑底，我所说的教堂也是如此。那座教堂很古老，尚未翻修。大约一百年前，他们的十诫跟咱们的一样，需要修补，可工匠得从阿尔布利坎请。他们希望能在一个星期天修好，所以工匠们必须在星期六的晚上挑灯夜战。工匠们很不情愿，因为那时跟现在不同，加班是不加钱的。那年头，全国没有一个真正信教的——牧师、事务员及教民统统一样。为了让工匠赶活儿，牧师在下午的时候供给他们大量的酒喝。傍晚时分，工匠们自己又买了些酒——地道的朗姆酒。天愈来愈晚，他们愈喝愈糊涂。到了最后，他们干脆把酒瓶和酒杯放到圣餐桌上，拉过一两个支架，舒舒服服地围坐在一起，一大杯一大杯地边斟边饮。据说他们把酒一喝光，便人事不省地烂醉如泥。他们不知这样躺了有多长时间，醒转时天上正响雷滚滚、大雨倾盆。在夜色里，他们似乎看见一个黑影，腿非常细，两只脚古里古怪，正站在梯子上替他们赶活儿。天亮时，他们看见活儿真的被赶完了，一点也记不起是不是自己干的。他们回了家，跟着就听说星期天的早晨教堂里出了件大丑闻——教民们去做礼拜时，发现十诫碑文上句句都没有‘不’字。体面的人好长时间都不肯到那儿做礼拜，后来只得去请主教重新为教堂做神祷。这就是我小时候听到的故事，信不信由你们。全是因为今天的情形，才使人想起了这段传说。”

那些不速之客又朝碑文上瞥了一眼，仿佛是想看看裘德和苏是否也漏掉了“不”字。接着，他们便陆续离开了教堂，最后连那位老妪也走了。苏和裘德一直在不停地工作，他们打发孩子去上学，然后又默默地一声不响。后来，他定睛瞧了瞧她，这才发现她在不出声地淌眼泪。

“没关系，同志！”他说道，“没什么大不了的！”

“谁想按自己的方式生活，大家就说他坏，这种情况让我无法忍受！其实，都是因为公众舆论，才把好人逼上绝路，使他们最终成为邪恶之徒！”

“你千万别灰心丧气！那只不过是个可笑的故事。”

“是啊，可那是针对咱们讲的！我来这儿非但没帮上你的忙，恐怕还给你惹下了祸！”

认真考虑一下他们的处境，引来那样一段故事当然不会让人感到高兴。可是，没过几分钟，苏好像又看到这天早晨的情形也有滑稽的一面，于是便擦擦眼泪，笑将起来。

“真是笑死人啦！”她说道，“天下那么大，偏偏请咱们两个经历奇特的人来这儿修补十诫！你自己就是个堕落的人，而我……又是这样的情况。……哈哈，老天呀！……”她把手罩在眼上，一阵一阵、不出声地笑着，直笑得全身发软。

“这就好，”裘德欢天喜地地说，“现在没事啦，我的小姑娘！”

“唉，可情况还是很严重的！”她拿起笔，站直身子，叹了口气说，“你看到了吧，他们认为咱们没结婚。他们硬是不相信！岂有此理！”

“他们是否那样想，我并不在乎，”裘德说，“我也不愿花丝毫的力气使他们相信咱们结了婚。”

他们坐下来吃饭——那是他们为了不耽误时间特地带来的饭菜。吃完饭，正准备干活儿，一个男子走进了教堂。裘德认出他是承包商维利。维利冲他打个手势，叫他到一边说话。

“情况是这样的……别人对我提意见来着。”他显得有些难为情，喘着粗气说，“我不知道是怎么一回事，也不愿调查……不过，我恐怕得请你和她离开，把没干完的活儿交给旁人去干！这是上策，可以避免发生不愉快的事情。这个星期的工钱我照样付给你。”

裘德是位很有个性的人，不愿小题大做，所以拿了工钱就走了。他收拾好工具，苏洗净了画笔。后来，他们的目光遇在了一起。

“咱们怎么会脑子如此简单，竟认为自己能干这种活儿！”她说话时，语调低沉、悲伤，“咱们就不该……我就不该到这儿来！”

“我没料到会有人闯入如此僻静的地方看见咱们！”裘德说，“算啦，事情已无可挽回。当然，我可不愿硬留下不走，毁掉维利的生意。”

他们无可奈何地坐了几分钟，然后出了教堂，赶上小时光老人，一路上满腹心事地朝阿尔布利坎走去。

弗利对教育事业仍怀着冲天的热情。由于他经历坎坷，所以他不遗余力地积极推行“机会均等”的观点。他加入了镇上在他刚来时方才成立的工匠互促会。该会会员都是些年轻人，分属各类教派——国教、公理会、洗礼教、唯一神教、实证教及其他（当时不可知论派别几乎还无人听说过）。他们的共同愿望是扩大知识面，由此产生了紧密的联盟。会费数额不高，会址舒适宜人。裘德态度积极，造诣非同一般，特别是因为他见解独到，知道读什么书以及怎样读——这是他多年和厄运作斗争积累起的经验；于是，他被选进了委员会。

他在从事教堂修复工作时被解雇几天之后，仍未找到别的活儿干。一天傍晚，他跑去参加上述的委员会所召开的一次会议。他去得晚，别的与会者均已到齐。他进入会场时，大家拿疑虑的目光望着他，几乎连声招呼也没跟他打。他猜想刚才一定讨论或提出过有关他的问题。在处理完一些常规事务之后，有人提出说该季度会员人数发生了突然减少的现象。一位委员（其实是个心地好、性情耿直的人）开始以难懂的语言分析可能存在的原因，要大家多注意他们的章程；因为，如果委员会缺乏威信，大家一盘散沙似的连个起码的共同行动标准都没有，互促会肯定会完蛋。当着裘德的面，委员们再没说深入的话，但裘德知道这意味着什么。于是，他当下坐到桌旁，写了份辞职书。

就这样，这对情侣的处境愈来愈窘迫，使他们不得不离开。他们所欠的购物账单接踵而至。同时裘德面临着一个问题：姑婆的那套笨重的古旧家具如何处置？他要是离开这儿，还不知会流浪到哪个地方哩。这种情况，再加上对现钱的需要，迫使他作出了拍卖的决定——即便他十分想留下那些珍贵的物品。

拍卖日来临了。在裘德布置下的这栋小房子里，苏为他们三人做最后一顿早餐。天碰巧下起了雨，而且苏也感到身体不舒服。再加上她不愿把可怜的裘德一人丢在如此凄惨的气氛中（他必须留下一段时间），于是她便听从拍卖商的建议，躲入楼上的一个房间。那儿可以不受拍卖的影响，关上门买主是进不去的。裘德在这个房间里找到了她。小时光老人也在屋里，另外还有他们为数不多的几只箱笼、包裹，再加上不在拍卖之列的两把椅子和一张桌子。他们俩坐在这儿，边思考边谈话。

没铺地毯的楼梯上响起了上楼下楼的脚步声；人们前来看货——有些货是罕见的古董，可以作为无价的艺术品收藏。他们的房门被敲了一两次；为了防止别人闯入打搅他们，裘德写了张“请勿打扰”的字条贴在门板上。

他们很快就发现，那些前来买东西的顾客所谈论的并非家具，而是他们个人的历史以及过去的行为，所涉及的范围出人意料之外，让他们难以忍受。他们原以为没有人认识他们，自己住在安乐窝里，这时才真正发现以前的想法是多么傻。苏无声地拉起同伴的手，二人你看着我，我瞧着你，听着那些闲言碎语——小时光老人奇特而神秘的身份是那些揣度和猜测的一项主要内容。最后，拍卖在楼底下的房间开始了。他们可以听见每一件熟悉的东西拍卖的情况——珍贵的东西卖得很贱，而他们不经意的东西反而出人意料地卖上了好价钱。

“人们不理解咱们，”裘德深深叹了口气说，“我很高兴咱们作出了离开的决定。”

“问题是应该到哪儿去？”

“应该到伦敦去。在那儿可以按自己喜欢的方式生活。”

“不，不能去伦敦，亲爱的。我很了解伦敦，咱们在那儿不会幸福的。”

“为什么？”

“你就想不来吗？”

“因为阿拉贝拉在那儿？”

“这是主要原因。”

“可到乡下去我老是提心吊胆，害怕最近遇到的事情会重演。从某个方面来说，我又不愿把孩子的历史对世人解释清楚以缓和咱们的处境。为了使他跟过去一刀两断，我决心保持沉默。我现在已厌倦了教堂里的活儿了，即便让我干，我也不想干啦！”

“你应该学学古典式建筑。哥特式毕竟是一种野蛮人的艺术。普金的观点是错误的，而雷恩的看法才是正确的。你该记得克里斯特敏斯特大教堂的内部装饰——说起来，那儿还是咱们初次相互见到对方面孔的地方哩。在诺尔曼那颇具诗情画意的精雕细刻之下，所掩盖的是粗野的人古怪而幼稚的模仿——他们要模仿的是业已消失、只保留在朦胧传说中的罗马形式。”

“不错……你以前说过的话，几乎已使我信服了这种观点。可一个人总得工作，可以去干自己瞧不起的活儿。如果没有哥特式教堂的活儿，我就必须干别的活儿。”

“我希望咱们俩能干一种跟自身处境无关的工作。”她怀着一腔愿望微笑着说，“我不适合于教书，你也不适合从事教堂艺术。你应该去修火车站、桥梁、戏院、音乐厅或旅馆——只要跟个人品行无关，干什么都行。”

“我干那些活儿不在行……我应该去烤面包。我从小就随姑婆做面包生意，这你知道。但就连面包师也得传统化，才能招徕顾客。”

“但除过在集市和庙会上经营蛋糕、姜饼摊，因为在那种地方人们只对货物的质量感兴趣，对其他的情况一概不闻不问。”

这时，他们的思想被拍卖商的喊叫声所打断：“现在拍卖这把古香古色的橡木高背长靠椅，独一无二的古式英国家具，值得引起所有收藏家的注意。”

“那是我曾祖父留下的东西，”裘德说，“我多么希望能留下那件可怜的古董！”

随着一件件东西的出手，下午过去了。裘德他们又累又饿，但由于听了那番闲言碎语，在顾客未离开之前，他们不好意思出去。然而，在拍卖最后一批东西时，他们觉得必须立刻走，冒雨把苏的东西送到他们临时的住所去。

“接下来拍卖两对鸽子，全都活蹦乱跳、肥肥壮壮，星期天的晚餐，可以做香喷喷的馅饼吃！”

在整个一下午里，对这些鸟儿的拍卖是最令人痛苦、揪心的事情。它们是苏的宠物。当发现再也无法留住这些鸽子时。她比跟所有的家具分手都感到难过。那些宠物先定了个很低的价，随后逐渐加价，最后成交。她听着这一切，试图不往这方面想，免得流眼泪。买主是个家禽贩子，那些鸽子毫无疑问注定要在集市日之前遭屠戮。

裘德注意到了她那掩饰不住的难过心情，便吻了吻她，说该去看住所那边收拾的情况了。他准备先和孩子去，马上就回来接她。

当只剩下她一人时，她耐下性子等待，可总不见裘德回来。最后，她便自个儿前往临时住所，而这时参加拍卖的人已走光。走不多远，在经过家禽贩子的店铺时，她看见她的鸽子被关在门口的一只带盖的篮子里。她见景伤情，渐浓的暮色更加重了她的悲哀。她一阵冲动，便行动了起来，先飞眼环顾四周，继而拔掉篮盖上的木栓，接着又继续朝前走。篮盖被从里边顶开，鸽子们扑腾腾便飞走了。家禽贩子闻声向门口奔来，气得破口大骂。

苏浑身打着哆嗦赶到临时住所，发现裘德和那孩子正在为她安排住处。“买东西的人在把东西拿走之前就得付钱吗？”她上气不接下气地问。

“我想是的。怎么啦？”

“因为……唉，我干了件如此缺德的事！”接着，她带着痛苦和后悔的态度作了番解释。

“如果家禽贩子没把鸽子抓回来，我会付给他钱的。”裘德说，“没关系的，别为此而苦恼，亲爱的。”

“我真蠢！为什么自然法则要生物自相残杀呢！”

“是那样吗，妈妈？”小时光老人认真地问。

“是的！”苏语气激烈地说。

“唉，那些可怜的鸽子必须碰运气啦。”裘德说，“拍卖的账一结算，咱们还了人家的钱，就离开这地方。”

“到哪儿去？”小时光老人焦急地问。

“咱们必须秘密地走，不让任何人知道咱们的行踪……这次反正不能去阿尔弗利逊、梅尔切斯特、萨斯顿或克里斯特敏斯特。除过那些地方，随便上哪儿都行。”

“为什么不能到那些地方去，爸爸？”

“因为咱们的头顶上罩着一片阴云。不过，‘咱们并没陷害过任何人，没败坏过任何人，也没欺骗过任何人！’也许因为咱们干了‘咱们自己认为正确的事。’”

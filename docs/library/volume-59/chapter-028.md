# 第六部　重返克里斯特敏斯特

……她拼命作践自己的身体，揪下头发，到她寻欢作乐的地方，抛得满世界都是。

——摘自《以斯帖》（经外书）

有两个人走向堕落——一个女人和我，我们在这漆黑的世界里以死为乐。

——罗·布朗宁

1

他们抵达克里斯特敏斯特时，车站上生机勃勃，到处都有戴草帽的小伙子在迎接年轻的姑娘；那些女孩子衣帽光鲜，打扮得花枝招展，长得跟迎接她们的人极为相像，似一家人一般。

“这地方气氛欢乐，”苏说，“啊，对啦，今天是纪念日！……裘德，你真滑头，今天来这儿是你特意安排的。”

“是的。”裘德不动声色地说。他接过最小的孩子，让阿拉贝拉的儿子紧跟在后边，由苏招呼他们自己生的那个较大的孩子。“我觉得反正要来，索性今天来得了。”

“可我害怕这气氛会让你难过！”她说道，同时上上下下担心地打量着他。

“噢，不能让这妨碍咱们的正事。在安顿下来之前，有一大堆事情要做哩。当务之急是找住处。”

他们把行李以及他的工具存在车站，然后走上了熟悉的街头；街上欢庆节日的人们都在朝同一方向流动。来到“四通八达”，他们正要到有可能找到住处的地方去，而裘德却看了看大钟以及匆忙行走的人群，对苏说道：“咱们先去看游行，把找住处的事搁一搁，怎么样？看完游行可以去找住处嘛。”

“咱们是不是应该先弄个安身的地方？”她问。

可他的心思似乎全在周年庆典上。于是，他们一起沿着大街走去——裘德怀抱最小的孩子，苏领着她的小女儿，阿拉贝拉的儿子满腹心事、沉默寡语地走在他们旁边。身着华衣丽服的漂亮姐妹们，以及年轻时没上过大学的温顺、无知的家长们，在当兄弟的或做儿子的护送下成群结队涌向同一方向；他们脸上的表情很明显，让人觉得他们是有史以来，天下最有资格参加这种盛典的人。

“我感到，那些年轻人每一个都反衬出我的失败，”裘德说，“万勿自以为是，这便是我今天要上的一课！这是我的耻辱日！……如果当初没有你的挽救，我亲爱的宝贝，我早就由于绝望而走向毁灭啦！”

她从他的脸上看得出，他又陷入了狂躁、自我折磨的心境。“咱们最好赶快去张罗自己的事情，亲爱的。”她说道，“我坚信，这种情景会触发你心中旧日的忧愁，对你没有任何好处！”

“哦……咱们离得不远了，就可以看得到啦。”他说。

左侧有一座带着意大利式门廊的教堂，螺旋状的柱子上满都是藤蔓浮雕；他们打教堂那儿拐了个弯，沿小巷前行，直至一座圆形礼堂出现在裘德的视野里；礼堂顶端是闻名遐迩的天窗灯笼式屋顶——那在他心目中是凄惨的象征，象征着他放弃了希望；因为在那个深思熟虑的下午，他正是从那个屋顶，才最终认清了大学城，认为他的努力是徒劳无益的，自己不可能成为大学里的一员。

今天，在横亘于该礼堂及附近那座学院之间辽阔的空地上，站着一群翘首以待的人。人群中由两排木栅隔出一条通道，从学院的门口直达介乎于学院和礼堂之间的一座高大的建筑物门口。

“就是这地方，他们就是要从这儿经过！”裘德一阵激动，突然喊了起来。他挤到人群前边，傍着木栅占了个位置，怀里仍抱着最小的孩子，而苏和另两个孩子紧紧跟着他。他们身后的人群又合拢，说说笑笑的，相互打着趣。这时，马车一辆接一辆停在学院的那扇较低的门前，从车上走下一些庄严肃穆、身裹大红袍的人物。天空阴云密布，黑沉沉的，不时炸响轰隆隆的雷声。

小时光老人打了个冷战。“真像上帝的最后审判日！”他低声说。

“他们仅仅是些有学问的博士。”苏说。

等待期间，大滴大滴的雨点掉落在他们的头上和肩上；庆典迟迟不开始，让人感到烦躁。苏又后悔地说不该到这儿来。

“时间不会长了。”裘德头也未回地说。

可游行队伍还是没来；人群中有个人为了消磨时光，便欣赏起附近那座学院的门面；他说他弄不清门面正中的那些拉丁文字是什么意思。裘德凑巧站在他近旁，便解释了一番。他发现周围的人都在饶有兴趣地侧耳倾听，便接着讲解起柱子中楣上的雕刻（他多年前曾对此做过研究），并对城内其他学院门面上烦琐的石刻展开了批评。

看热闹的人群，也包括大门口的两名警察，全都呆呆望着他，就像里考尼安人望着保罗一样，因为裘德无论谈起任何话题，都慷慨激昂、口若悬河。他们似乎在纳闷，不明白一个外乡人对他们城市里的建筑怎么比他们自己还了解得多。后来，他们当中的一个说道：“喂，我认识那人，他叫裘德·弗利，多年前曾在这儿干过活儿。你们不记得了吗，他曾有个绰号叫‘圣贫民窟的导师’，因为他的宗旨就是传播知识。我想他已结了婚，怀里抱的就是他的孩子。泰勒肯定认识他，因为他谁都认识。”

说话者是个名叫杰克·斯太格的汉子，裘德以前和他一起为学院修理过石头建筑。这时，补锅匠泰勒恰巧站在不远的地方，他听见有人提自己的名字，便隔着木栅冲裘德喊叫道：“我的朋友，你旧地重游，使我们不胜荣幸！”

裘德对他点了点头。

“上次你远走高飞，好像并没有飞黄腾达，对不对？”

裘德对此也表示认可。

“除过又多添了几张嘴！”又一个声音传来，裘德认出说话人是乔大叔——过去所认识的另一位石匠。

裘德和气地说，对此他不能够否认。他们就这样你一言我一语地，就好像裘德跟整个看热闹的人群对起了话；补锅匠泰勒问裘德是否还记得拉丁文的使徒经，是否还记得那天晚上在酒馆的挑战。

“你没有那种命，对不对？”乔插言道，“你的本事还不够大，没能使你如愿吧？”

“别再回答他们的问题了！”苏央求道。

“我觉得我讨厌克里斯特敏斯特！”小时光老人悲伤地嘟哝道；他隐没在人群中，没人能看得见他。

可裘德虽然发现自己成了大家打听、盘问和议论的中心，却并无退缩之意，反而想把心里的想法公诸于世，因为那些想法没有什么让他感到惭愧的。于是，过了一小会儿，就听他情绪激动地高声对广大群众说道：

“这是一个难以回答的问题，我曾经试图找出答案，在目前这个欣欣向荣的时期也有千千万万个青年在权衡这个问题。对于一个年轻人，是不考虑自己的才能，盲目地走自己的路，还是先考虑自己的才能和个性，再酌情调整方向呢？我试过后一种方法，遭到了失败。但我不承认我的失败就证明我的观点是错的，或者我的成功就能证明它是对的，即便当今的人都以成败而论事，只着眼于偶然的结果，却不管本质上的好坏。假如我的结局是摇身变成上等人，就像咱们现在看到的陆续来到的那些穿红着黑的绅士一样，大家肯定会说：‘瞧那个年轻人多明智，按照自己天生的个性发展。’但如果我的结局并不比当初强，大家又会说：‘那家伙异想天开，自行其是，瞧他有多愚蠢！’”

“我失败了，但这并非因为我意志不坚定，而是由于我的生活太贫困。通常要花两三代的时间才能够实现的事情，我却企图用一代人的时间完成；而且，我的冲动，我的感情及欲望（也许别人称之为罪恶）过于强烈，势必会阻挠一个不具备优越条件的人。谁要想获得真正的好机会，成为这个国家的一个大人物，他的血就得像鱼一样冷，心似猪一般贪。你们也许会嘲笑我，我也愿意让你们那样做，因为我无疑是个很合适的嘲笑对象。但我认为，如果你知道我近几年都有过怎样的经历，你们会转而同情我。他们要是知道我的情况，”他朝学院那边陆续抵达的导师们偏偏头，“可能也会对我产生恻隐之心。”

“他病容满面，看起来疲惫不堪——这是真的！”一个女人说。

苏的脸色愈来愈不安；不过，她虽然站在裘德的近旁，却没有人看得见她。

“我死之前，也许能做件有益的事情，能够作为榜样去告诫人们不要做自己不该做的事，这对世人有教育的意义。”裘德继续说道。他开始讲演的时候虽很平静，现在却有些痛苦。“当今人的思想和社会都动荡不安，致使许多人郁郁寡欢，而我也许只是这种动荡不安状况的一个渺小的牺牲品！”

“别跟他们讲这些！”苏看出了裘德的心情，眼里含着热泪悄声说，“你并非那种情况。你为了追求知识曾勇敢地奋斗过，只有天下最卑鄙的人才会责怪你！”

裘德把怀里的孩子挪动了一下位置，使其更舒服一些，最后说道：“我虽然生着病，又生活贫困，但这还不是我最糟糕的一面。最为糟糕的是：我原则性混乱，在黑暗中摸索，不去学习榜样，而是靠本能行事。八九年前初到这儿时，我有一整套固定的人生观，可后来它们一个个消失了。我越往前走，越没有把握。我认为，如果我现在还有生活准则的话，那就是随心所欲，只害自己，不害别人，以及脚踏实地地给我最爱的人带来欢乐。好啦，先生们，既然你们想知道我的状况如何，我都告诉你们了。愿这对你们大有益处。我不能再朝下讲了。我觉察到咱们的社会机制出了些毛病，具体是什么毛病只有那些比我有远见卓识的人能找得出……不过，他们恐怕也找不出，至少在咱们这个时代找不出。‘谁能在活着的时候知道怎样才对人类有益呢？又有谁能说得出，在他死之后天下会出什么事呢？’”

“好啊，好啊。”群众吆喝道。

“讲得妙！”补锅匠泰勒也叫喊道。接着，他悄声低语地对周围的人说：“这一带唯利是图的牧师多的是；有一次咱们的大师休假，他们当中的一个跑来顶替，像这样的布教，少于一个畿尼都不肯干。嗨，我发誓他们没有一个愿干的。就是愿干，也得叫人把布教词提前写好。而这个小伙子仅仅是个工人呀。”

就在这时，一辆马车驶来，一位迟到的博士身上裹着长袍，嘴里气喘吁吁。可是马儿没能停到该停的位置，待博士跳下车，走进大门后，车夫就下了车，开始朝马肚子上踢。这种情况作为实例，给裘德的话加了注释。

“这儿是全世界最信奉宗教、最讲求教育的城市，”裘德说道，“如果在这儿学院的大门口能做这种事，那我们该如何评价我们所堕落的程度呢？”

“遵守秩序！”有位警察刚才跟同伴一道忙于开学院对面的大门，这时喊叫了起来。“喂，伙计，游行队伍通过的时候，请你把嘴闭上。”

雨下得更大了，所有带伞的人都把伞撑开了。裘德没带伞，而苏也只带了把小伞，一半是遮阳用的。她的脸色惨白，但裘德当时却没注意到。

“咱们走吧，亲爱的。”她悄声说，一边尽力用伞为他遮雨，“别忘了，咱们还没住处呢，东西也都在车站放着；再者，你的病根本就没好。淋了雨，恐怕会伤你身子骨的！”

“他们这就过来啦。稍等一下，我就跟你走。”他说。

六只大钟当当地鸣响，周围房屋的窗口开始闪现出人的面孔。院长和新博士组成的游行队伍走了过来，他们那穿着黑红两色长袍的身影穿过裘德的视野，就像高不可攀的行星掠过望远镜的镜头。

他们行进时，认识他们的人们喊叫着他们的名字。游行队伍抵达古老的伦恩圆形礼堂，欢呼声直冲云霄。

“咱们到那边去！”裘德叫嚷道。虽然雨在不停地下着，他却似乎觉察不到，带着一家人绕到礼堂那儿。他们站在礼堂前的稻草上——那是为了防止车轮发出刺耳的声音而铺设的。礼堂四周墙壁上那稀奇古怪、霜蚀雨淋的半身石像阴沉忧郁地望着游行队伍，尤其是望着落汤鸡似的裘德、苏以及他们的孩子，仿佛觉得他们太荒唐，不该到这儿来。

“真希望能进去！”裘德充满激情地对苏说，“你听——我在这儿能听见几句拉丁文讲演词，因为那些窗户是开着的。”

然而，除过风琴声以及每次讲演完时人们的高喊、欢呼声，裘德站在雨地里，并没有听见多少拉丁语，只偶尔有几个带着“um”或“ibus”词尾的单词传入他的耳中。

“唉，我直至生命的终结，都只是一个局外人！”他过了一会儿叹了口气说，“现在咱们走吧，我耐心的苏。你真好，为了满足我愚蠢的愿望，在雨地里等了这么久！我再也不会关心这个天打五雷轰的地方了，我发誓再也不会了！可是，咱们在木栅那儿时，你为何全身抖得似筛糠？啊，你的脸色多么苍白呀，苏！”

“我瞧见理查德在另外一侧的人群里。”

“啊……是吗？”

“他显然跟咱们所有的人一样，是来圣地观看节日景象的。由此判断，他可能住得不太远。他和你一样，对大学抱着一腔热望，只是表现得没有你强烈罢了。他肯定听见了你对公众所讲的话，但我想他没看见我。他似乎没朝这边注意。”

“哦，他注意了又怎么样？你心里已经不再为他牵肠挂肚了吧，苏？”

“对，我想是的。不过，我是个意志薄弱的人。我知道咱们的作为没有错，可我莫名其妙地害怕他，对他有一种敬畏感或者恐惧，那是由我并不相信的传统习惯造成的。有的时候，这种感觉袭上心头，就像一种偷偷来到的瘫痪病，使我愁苦万分！”

“你累了，苏。噢，我给忘了，亲爱的！对，咱们这就走吧。”

他们着手寻找住处，最后终于找到了一个看起来还不错的旅店；该店位于米尔丢巷——一个对裘德有着无法抗拒魅力的地方，但在苏看来却并不怎么引人入胜；这是一条紧靠一座学院后墙的窄巷，可是却和学院没有任何联系，巷里的小屋被学院高大的建筑物遮得阴暗无光。学院和这条巷子虽然仅一墙之隔，但两处的人却过着迥然两样的生活，仿佛住在地球的两端。有两座房屋上贴着招房客的告示。裘德他们一行人来到其中的一个房屋前，敲响了门。来开门的是个女人。

“啊，你听！”裘德没跟开门的人问好，却这样嚷嚷道。

“听什么？”

“那钟声呀！会是哪个教堂呢？那声音很耳熟。”

这时，不很远的地方又响起一串钟声。

“我不知道！”女房东不客气地说，“你敲门就是为了问这个？”

“不，是来找住处的。”裘德醒过神来，这样说道。

房主把苏的身段仔细打量了一会儿。“我们没有空房了。”她说着便关上了门。

裘德面露狼狈之色，而小时光老人却一脸的沮丧。

“没关系，裘德。”苏说道，“让我试试吧。你不了解路数。”

他们在不远的地方又找到一家旅馆，但这家店主不仅端详了苏，而且把小时光老人和那两个小孩子也打量一番，然后客气地说道：“很抱歉，我们不收带孩子的房客。”说完也关上了店门。

那个小些的孩子一咧嘴，不出声地哭了起来，好像本能地感到麻烦正在逼近。小时光老人叹了口气。“我不喜欢克里斯特敏斯特！”他说，“那些高大古老的房屋是监狱吗？”

“不是，它们是学院。”裘德说，“也许有朝一日，你要到那儿学习。”

“还是不去的好！”小时光老人说。

“咱们再碰碰运气。”苏说，“这次我把外套裹紧些……离开肯尼特桥来这儿，就像离开该亚法来见彼拉多……我现在看上去怎么样，亲爱的？”

“这回没人会注意到了。”裘德说。

他们又寻到一家客店，进行第三次尝试。这儿的老板娘比较和蔼，但空房间却很少，她只同意收下苏和孩子们，而苏的丈夫得另找地方。他们只好接受了这种安排，因为他们耽搁了找住处，一直到这么晚，境况很狼狈。老板娘要的房租高得让他们难以承受，但他们还是同意了。他们不敢挑剔，因为裘德现在来不及去寻找较长久的居处。苏在这家客店的三楼占了套后屋，里边有个小房间让孩子们住。裘德留下喝了杯茶；他高兴地发现，从窗口可以看见另一座学院的后墙。接着，他吻了四位亲人，便出去买几件必需品，同时也给自己找住处。

他走后，老板娘上楼来想跟苏聊一会儿天，了解了解这家房客的情况，苏不善于敷衍，坦率地讲了一些有关他们近来的困难和流浪生活的情况。后来，让她感到吃惊的是，老板娘突然问道：“你真的结婚了吗？”

苏犹豫了一下，随后冲动地告诉老板娘，说她和她的丈夫都各自有过一次不幸的婚姻，所以一想到第二次缔结难以取消的联姻便心惊肉跳，害怕婚约里的条件会扼杀他们的爱情；他们希望在一起生活，有两三次企图办事，但终究缺乏勇气去重蹈覆辙。她说这番话，按自己的意思是她结了婚，而老板娘的看法则不然。

老板娘面露为难之色，随后下了楼。苏坐到窗前沉思，望着外边的雨景。这时，有人走进店里弄出些响动，接着，楼下走廊里一男一女在说话；这些打破了苏的宁静。原来是老板娘的丈夫回了家，她正在解释情况，说他不在家时来了几位新房客。

那男的雷霆大怒，蓦然提高了嗓门。“谁让你收这样的女人！也许都快坐月子啦！……另外，我不是说过不收孩子吗？大厅和楼梯都才油漆过，被他们踢脏怎么办！像他们那样跑来，你应该知道事情有些蹊跷。我让你招单身客人，你却招了一家子。”

做妻子的劝解了一番，但做丈夫的似乎硬坚持自己的观点。过了一会儿，苏的房门被敲响，老板娘出现在了门口。

“对不起，夫人。”她说道，“我不能让你们住满一星期了。我丈夫不同意，所以我必须请你们离开。你们今夜可以留下住，因为天色渐晚，已到黄昏了。但我希望你们明天一大早就离开这里。”

苏很清楚，她本来有权利住一个星期，但她不愿在那对夫妻之间制造不安的因素，于是便答应按对方的要求离开。老板娘走后，她又朝窗外眺望。她发现雨已经住了，便对小时光老人提出建议，说安顿小的们睡下后，他们就出去另寻住处，为明天预订下，那样到了明天他们就不至于像今天这样走投无路了。

此时，裘德打发人从车站刚刚送来了他们的箱笼。他们没解行李，走出旅店，来到了湿漉漉但并不令人觉得讨厌的街道上。苏决定先不把店里要她离开的消息告诉丈夫，免得让他心神不宁，因为他也许正在为自己找住处发愁呢。在小时光老人的陪伴下，她走了一条街又一条街，问了十几家旅店，但她单枪匹马的，成绩要比和裘德在一起时差得多。没有一家旅店答应明天租房间给她。每一个房东见这样的一个女人和小孩在暮色中寻觅住所，都斜着眼看他们。

“我本就不该出生，对不对？”那孩子阴郁地说。

苏最后精疲力竭，便回到了那个并不欢迎她，但至少可以暂时安身的地方。她出门时，裘德来过，留下了他的地址。但她知道他的身体仍非常虚弱，于是坚持自己的决定不去搅扰他，等到明天再说。

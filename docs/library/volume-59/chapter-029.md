# 2

苏坐在那儿望着房间里没铺地毯的光裸裸的地板（这家旅店其实只不过是座破旧的农舍，坐落在城里罢了）。过了一会儿，她又透过没挂窗帘的窗户观望外边的景色。对面不远的地方是萨科法格斯学院的外部围墙，静悄悄、黑乎乎，连一扇窗户也没有，把积蓄了四个世纪的阴森、顽固和腐朽的气氛抛入她住的这个小房间，使这儿晚上不见月亮，白天没有阳光。越过这座学院，还可以看得见鲁布里克学院的轮廓，再往远处能瞧见另一座学院的塔楼。她心想一个思想单纯的人所具有的主导思想会产生奇怪的效应，裘德正是受了那种思想的支配，才把自己一往情深地爱恋的她以及孩子们安顿到了这种凄惨的环境里，因为昔日的梦想仍在他心头萦绕。甚至到了今天，他还是听不清那些学院的墙壁针对他的愿望所发出的冷酷无情的回响。

在另找住处时遭到失败，这家旅店里竟无爸爸的安身之处——这两件事实给小时光老人留下了深刻的印象。一种不露行迹的恐惧似乎像阴云一样笼罩在他心头。沉寂被打破了，只听他说道：“妈妈，明天怎么办呢？”

“不知道！”苏垂头丧气地说，“恐怕这会让你爸爸操心的。”

“真希望爸爸身体棒棒的，这儿又有他住的地方！那样的话，问题就不大了！可怜的爸爸呀！”

“是那样的！”

“我能帮上忙吗？”

“帮不上！咱们有无穷无尽的麻烦、不幸和灾难！”

“爸爸离开这儿，是为了给我们小孩腾地方，对不对？”

“这是部分原因。”

“留在这个世界，还不如脱离这个世界，对不对？”

“差不多是这样的，亲爱的。”

“因为我们小孩的缘故，你们才不能有好的地方住。”

“这个……人们有的时候讨厌小孩。”

“既然小孩添这么多麻烦，人们为什么还要生他们呢？”

“哦……因为这是自然规律。”

“可我们并没要求出生呀。”

“的确如此。”

“我的情况更糟，因为你不是我的亲生母亲。当初你要是不愿意，就不必收留我。我千不该万不该，不该来打搅你。我曾给澳大利亚的亲人添麻烦，现在又给你们添麻烦。要是当初不生下我就好啦！”

“这由不得你，我亲爱的。”

“我认为一旦生下不想要的孩子，就应该立即弄死他们，免得他们有了灵魂，长大后到处添麻烦！”

苏没吱声。她满腹疑虑地在考虑着如何对待这个思想过于沉重的孩子。

她最后得出结论：只要情况允许，对这个像成年朋友一样关心她困难处境的孩子，她应该开诚布公、坦率直言。

“咱们家马上就又要添一口人啦。”她迟疑地说。

“怎么添？”

“又有一个婴儿要出生了。”

“什么？”那孩子狂乱地跳起身来，“啊，天呀，妈妈，你不该再生啦！这么多孩子，难道还不够你受的吗！”

“对，是不该，我很抱歉！”苏喃喃地说，眼睛里含着晶莹的泪花。

那孩子痛哭失声。“你不关心我们，你不关心！”他痛苦地大声指责道，“妈妈，你怎么能如此邪恶和残酷？在家里生活改善之前，在爸爸的身体康复之前，你不该生孩子！这一下，咱们的困难就更大啦！咱们无安身之处，爸爸被迫离开，明天咱们就会被赶上街道，而你马上又要生孩子！……这是故意的！……故意的……故意的！”他呜呜哭着来回踱着步。

“你必须原谅我，小裘德！”她恳求道，胸脯跟那孩子的一样一起一伏的，“我现在无法解释……等你再大些，我会解释的。目前咱们身处困境，就显得我是故意的！我现在无法解释，亲爱的！可我并非故意的……由不得我啊！”

“是故意的，肯定是的！因为你如果不同意，就不会有人来打扰咱们的生活！我不原谅你，决不，决不！说你关心我，关心爸爸或我们当中任何的一个，我都决不会再相信了！”

他起身走入隔壁的小房间，那儿有张地铺。她听见他说：“如果没有我们小孩，就一点麻烦也没有了！”

“别那么想，亲爱的，”她有些专横地喊道，“快睡觉吧！”

第二天早晨刚过六点钟，她一觉醒来，决定于早饭前赶到裘德的旅店去（裘德给她留过旅店的地址），趁他还没出门，把发生的事情告诉他。她起床时轻手轻脚，免得吵醒孩子们，因为她知道孩子们一定被昨天的那番折腾弄得累坏了。

她到了裘德的那家无名小店时，发现他正在吃早饭。他之所以选这样的旅店，是因为想省下钱来为她付店钱。她对他解释了自己被赶出店的情况。他说他为她操了一夜的心。不过，现在是早晨，女房东要求她离开那件事似乎已不似昨天晚上那般令人心灰意冷了，甚至连她另找地方时所遭到的失败也不像当初对她打击那般大了。裘德同意她的看法，认为不值得硬赖着不走，非住满一个星期。他觉得应该采取行动搬走。

“你们都到这家旅店来住上一两天。”他说，“这是个粗人待的地方，对小孩不太好，不过有这地方住，骑着马好找马嘛。在郊区——在我住过的别雪巴，有的是旅馆，你既然来了，就跟我一起吃早饭吧，我的小鸟？你敢肯定你没事吗？时间还很宽裕，能赶回去在孩子们醒来之前为他们准备好早点。实际上，我也和你一起去。”

她和裘德急急忙忙吃了饭，不出一刻钟他们便一起上了路，决定立即搬出苏的那家过于讲究体面的旅店。到了那儿，走上楼去，她发现孩子们住的那个房间寂静无声，便以胆怯的声调呼唤老板娘，求她送茶壶和早点上来。老板娘很勉强地照办了。苏取出几个自己带来的鸡蛋放入开水壶里，让裘德看着，而她去叫孩子们，因为此刻已大约八点半钟。

裘德站在那儿低头望着小壶，拿着手表计算煮鸡蛋的时间，背对着孩子们住的那间小内室。苏突然的一声尖叫，惊得他转过身去。他看见那个房间（或最好称套间）的门敞开着（刚才苏推门时，那门板吱扭扭地发出沉重的声音），苏瘫倒在刚进门的地板上。他奔上前去抱她时，眼光射向那张小地铺——那儿没有一个孩子。他迷乱地望望四周。门背后有两个挂衣服的钩子，而现在却是悬挂着那两个最小的孩子的躯体，每人脖子上都绑着一根捆箱子用的绳索；在几码开外的地方，小裘德的躯体也以同样的方式吊在一只铁钉上。这个大孩子的旁边有一只翻倒了的椅子；他那呆钝的眼睛斜视着外边的房间。而那个小女孩以及婴儿的眼睛却是闭着的。

眼前那怪诞、极其恐怖的情景吓得裘德几乎瘫软了下来。他让苏先躺在那儿，急忙用小刀割断绳子，把孩子们放到床上。在短暂的忙碌之间，他触摸到孩子们的身体，觉得他们似乎已死去。他抱起晕倒了的苏，将她放在另一个房间的床上，喘着粗气叫来老板娘，然后自己去请医生。

当他赶回来时，苏已经醒过来；那两个慌乱的女人正弯着腰拼命地想把孩子们救转来，而那三具死尸一动不动，这种情景使裘德失去了自制。住得最近的医生走进屋，但正如裘德原先揣测的那样，请医生是多余的。孩子们已无法救活。他们的尸体虽然尚未僵冷，但据估计他们在绳子上吊了有一个多小时。这对父母在事过之后能够理智地分析情况时，认为那个大孩子可能在睡醒之后，到外间屋找苏，发现她不在，于是，他那原本就让昨天的事件和谈话弄得非常沮丧的病态心理就变得更加灰冷。另外，地板上还找到一张字条，只见那孩子用随身携带的一小截铅笔写道：“这样做，是因为家里孩子太多。”

看到字条，苏的精神彻底崩溃了。她有一个可怕的想法，认为她和那孩子的谈话是导致悲剧的主要原因。于是，她心如刀绞，感到无边无际的痛苦。他们不管她愿意不愿意，把她抬到底下一层的房间里。她躺在房间里，每抽一口气，瘦弱的身体便抖动一下，眼睛呆呆盯住天花板，老板娘怎么安慰她都无济于事。

从这个房间里，可以听见楼上人们的动静。她请求允许她回到楼上，但老板娘说孩子们如果仍有希望的话，她在跟前反而有害无益，还提醒她多注意身子骨，免得给肚子里的小生命造成危险。她听了这一番话，这才作罢，但是却不住地询问情况。最后，裘德下了楼，告诉她孩子们已没有指望。刚一能讲话，她便把她跟那孩子说过的话对裘德讲了一遍，声称她认为自己是祸根。

“不，”裘德说，“他那样做是出于他的天性。医生说在咱们这一代有这种孩子，在上一代是找不到的，他们是新人生观的产物。不待他们长大，有足够的力量抗拒恐怖的人生，他们似乎就看到了种种恐怖的现象。医生说这是一种序幕，标志着人们之间将出现普遍的悲观厌世思想。那个医生可谓远见卓识，却不能安慰……”

裘德先前为了她强压住自己的悲哀，而现在却失去了控制。苏见了顿生怜悯之心，忙着安慰他，从某种程度上就顾不得用尖酸刻薄的语言责备自己了。待人们散尽，她才被允许去看孩子们。

小时光老人的脸上反映出了他们的全部遭遇。在那幼小的身躯上集中着裘德第一次婚姻不祥的乌云和阴影，集中着他第二次婚姻中出现的意外、错误、恐惧和过失。这孩子是所有一切的中心，所有一切的焦点，一切的一切都在他一人身上反映了出来。他曾为先前那对父母的草率行为而呻吟，为他们不协调的结合而发抖；为了这一对父母不幸的遭遇，他却葬送了生命。

旅店里静下来时，他们什么也做不成，只能等待着验尸官来调查。这时，从后边厚厚的墙壁那儿传进来一种压抑、浑厚和低沉的声音。

“是什么声音？”苏屏住痉挛性的呼吸问。

“是学院圣堂里的风琴声。风琴师大概在练琴。那是《诗篇》第七十三章里的圣歌：《上帝把真正的爱赐给以色列》。”

她又抽泣起来。“天呀，我的孩子啊！他们没做过坏事呀！为什么死的是他们，而非我！”

随即又是一片寂静——后来这寂静被外边两个人的说话声所打破。

“毫无疑问，他们在谈论咱们！”苏痛苦地说，“咱们在这个世界，在天使以及世人面前丢人现眼！”

裘德侧耳倾听……“不，他们不是在谈论咱们，”他说，“那是两个持不同观点的牧师，正在辩论东向祈祷的问题。上帝呀，还说什么东向祈祷，所有的一切都在痛苦地呻吟！”

又是一阵静寂。后来，一股无法控制的悲哀又袭上她的心头。“似乎天外有个声音在说：‘你不该！’它头一次说：‘你不该学习！’然后它说：‘你不该劳动！’现在它又说：‘你不该坠入情网！’”

他试图安慰她，便说道：“你这是太痛苦啦，亲爱的。”

“可这是事实！”

他们就这样等待着。后来她又回到了自己的房间。婴儿死的时候，他的衣服和鞋袜放在一把椅子上，而现在裘德怕她睹物伤情，想把东西拿开，可她硬是不准许。他每一次去拿的时候，她都央求他不要动。老板娘也试图去拿，她便疯了似的勃然大怒。

裘德害怕她突然发作，但更害怕她死呆呆地默不作声。“你为何不跟我讲话，裘德？”有一次她在沉默了一会儿之后嚷嚷了起来，“你可不要离开我！看不见你，我会忍受不了寂寞的！”

“别怕，亲爱的，我就在这儿。”他说着，把脸贴近她的脸。

“是啊……啊，我的同志，咱们完美无瑕的结合，好一个合二为一……如今却染上了鲜血！”

“只是罩上了死亡的阴影——仅此而已。”

“唉，虽然我当时并不知道，但确确实实是我使他走上了那条路！我对那孩子说的话，只能跟成熟了的人说。我说世道在跟咱们过不去，与其活着还不如死了的好，而他竟信以为真。我还告诉他家里又要添一个孩子，他听后情绪低落。他当时谴责我时所说的话是多么尖刻啊！”

“你为什么要那样做，苏？”

“我也不知道。可能是想讲真话吧。我不忍心对他隐瞒生活的真相。但我并未实事求是，出于不应该有的谨慎，我跟他讲的话云遮雾罩……我比我的女同胞明智些，但并非一个地道的明白人！我真该说些好听的假话，而非模糊朦胧的真情！我缺乏自我控制能力，瞒也瞒不住，说也说不清！”

“你的做法在大多数场合是很奏效的，只是对咱们家的情况也许就不行了。他早晚都会知道。”

“我还在为我的宝贝婴儿缝制新衣呢，这下永远也不能看他穿衣，永远也不能和他说话啦！……我的眼睛已哭肿，几乎连东西也看不清了，可仅仅一年之前我还自以为很幸福哩！那时咱们相亲相爱，沉溺于自我，完全忘掉了他人的存在！不知你记得不记得，咱们声称要尽情寻求欢乐。我曾说自然界的意图、自然界的法则以及生存的原则就是要咱们按天生的本能去寻求欢乐，而人类文明却把束缚这种本能作为己任。瞧我都说了些多么可怕的话！如今，命运在咱们的背上扎了一刀，就是因为咱们太傻，信从了自然界的话！”

她沉默了下来，静静地思索，后来又说道：“也许，他们死了更好。是啊……我总算明白啦！花儿在鲜嫩时摘掉，总比凄凄惨惨地慢慢枯萎掉强！”

“对，”裘德附和道，“有些人说，孩子死于童年，做家长的应该高兴才是。”

“可他们不了解情况！……噢，我的孩子们，我的孩子们呀，你们能再起死回生吗？可以说，那大孩子想结束生命，不然他就不会那样做。他的死倒没什么可奇怪的，那是由于他那无可救药的阴郁天性所导致——可怜的孩子！但另外的两个孩子——你和我的亲骨肉，则死得不应当！”

苏又望了望那搭在椅背上的小衣服，以及那放在椅上的鞋袜，全身似琴弦一般颤抖起来。“我是个可怜虫，”她说，“不配留在人间，也不配升天堂！种种事情令我魂不守舍！该怎么办呢？”她痴痴盯住裘德，紧紧抓住他的手不放。

“没有办法啊，”他答道，“事情该怎么样就怎么样，凡事都由天定。”

她起先没作声，片刻之后才沉痛地说：“一点不错！那是谁说的话来着？”

“那是大合唱《阿伽门农》152里的歌词，自出事后一直萦绕在我心里。”

“我可怜的裘德，你什么都没有得到！我比你还强一些，因为我毕竟还得到了你！想不到人在无人帮助的情况下寒窗苦读，却落到一贫如洗、走投无路的地步！”

他们就这样岔开话题暂时谈了一会儿，但随后她的悲哀又排山倒海般涌来。

陪审员按时来看了死尸，验尸官也验了尸。接着，就在早晨举行气氛悲惨的葬礼。报纸上的报道把一些好奇的人招到出事地点瞧热闹。那些人站在那儿，像是在数窗户上的玻璃以及墙上的石块。这对年轻的父母到底是什么样的关系？这一疑问，更增加了那些人的兴趣。苏曾宣布要为自己的两个小宝贝送葬，可最后却撑不住劲，躺倒在了床上。棺材被趁机抬出旅店。裘德登上灵车，车便开走了。店老板见了如释重负，现在只有苏和她的行李还留在店里，他盼着当天就把她请出去。由于他妻子做下倒霉事，招进这些外乡的房客，结果在这个星期把旅店弄得臭名远扬，只有客人走了，风波才能平息。到了下午，他跟房主私下商谈了一下，认为这儿发生的悲剧如果使别的客人却步不前，就应该设法改换旅店的门牌号码。

裘德亲眼看着那两口小棺材——一口装着小裘德，另一口装的是两个年龄小的孩子——放入墓坑之后，便急匆匆赶回来照料苏。苏仍在她的房间里，于是他暂时没去惊动她。不过，他一直操着心，四点钟左右又跑了来。老板娘认为苏仍睡在床上，但是去看过之后回来说卧室里根本不见苏的人影，而且她的帽子和外套也不翼而飞，显然是出了门。裘德急忙赶赴他住的那家旅店，也没看见苏的人影。他想了想种种可能性，然后一路向墓地奔去。他进了门，便朝不久前举行过葬礼的那个地方走去。此时，那些因为这件命案是悲剧而跟来观看的人已经散去。一个汉子手握铁锨，正往那个躺着三个小孩的普通墓坑里填土，可他的胳膊却被一个女人拉住不放。那女人站在填了一半的墓坑里，苦苦央求着。原来是苏！她穿着带颜色的衣服，没顾得上换他买的丧服，但这样的衣服看上去比普通的丧服更让人觉得心酸。

“他在填土。等我和我的小宝贝最后见上一面，再让他填！”她看见裘德，疯了似的喊叫起来。

“我想再看看他们。噢，裘德……求求你，裘德……我想见见他们！谁知道你竟然在我睡着了的时候让人们把棺材运走！你说过在钉棺之前，我可以再看看他们，可你说话不算话，竟让人把他们运到了这里！噢，裘德，你对我也算残酷的了！”

“她求我把墓再挖开，将棺材刨出来，”那个手执铁锨的汉子说，“她脸色不好，该送她回家去。看起来，她理智都不清了。可怜的人！现在已不能再挖出来啦，夫人。跟你丈夫回去吧，别伤心啦。感谢上帝，马上又有新生命降生，以消除你的悲哀。”

但苏依然可怜巴巴地不住口央求：“我就不能再见他们一次——只一次？让我见见他们，好吗？只是看他们一眼，裘德，时间不会长！你要是同意，我将非常高兴，裘德！我将乖乖地听你的话，再也不违背你，裘德！看完后，我就安安静静地回去，再也不来看他们啦！好不好？……我为什么就不能再看他们一眼呢？”

她喋喋不休地说着，弄得裘德心里难过到了极点，差一点软下来，也跟着去求那汉子让步。可那样做不会带来好处，反而可能使她的情况更糟。他看出必须立刻送她回家去。于是他百般哄劝，温柔地低语，还用胳膊搂她、扶她。最后，她丧失了希望，做出让步，被迫离开了墓地。

他想雇辆马车送她回去，但由于钱囊羞涩，她反对那样做。于是，他们迈着慢腾腾的步子朝旅店那儿走。裘德佩戴着黑纱，她穿着棕红两色的衣服。他们原打算当天下午搬到另一家客店去，但裘德看到这是不切合实际的。最后，他们又走进了那座现已被他们所痛恨的房子。苏一进门就躺到了床上，裘德跑去请医生。

医生来后，他在楼下等了一个晚上。直到很晚的时候，他才得知苏这次早产，生下的孩子跟坟墓里的那几个一样，是一具死尸。

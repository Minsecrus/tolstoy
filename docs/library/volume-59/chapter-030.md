# 3

苏希望自己死去，可是却慢慢恢复了健康，而且裘德也在自己的本行业找到了工作。他们现在已换了住处，就在别雪巴那个方向，距讲究礼仪的圣西拉教堂不远。

他们常默默而坐，想着他们的处境。命运无情且顽固地干扰他们的生活，更令人悲哀的是还直接跟他们作对。当年，苏的智力如星光闪烁，曾有过朦胧、奇特的幻想；她觉得这个世界就像梦中的诗歌或旋律，半睡半醒时出奇地美妙，而彻底醒来后却觉得荒谬绝伦；上帝的行为似梦游者一般机械呆板，不像圣贤那样深思熟虑；上帝在创造生存条件时，似乎从未考虑过受这些条件制约的人在感情上会有所发展，达到现今善于思考、受过教育的人所具有的程度。可磨难使抽象的敌对势力变成了朦朦胧胧的人之间的抗衡。她改变了原来的想法，觉得她和裘德正在落荒而逃，躲避一个迫害他们的人。

“咱们必须逆来顺受！”她伤感地说，“上帝把开天辟地来所有的愤怒都发泄在了咱们身上。作为他可怜的臣民，咱们必须服从，没有别的选择。咱们必须这样做。跟上帝抗衡是不顶用的！”

“咱们只是和人以及无情的环境抗衡罢了。”裘德说。

“不错！”她喃喃地说，“我心里似翻江倒海一样在思索！而今，我变得像野蛮人一样迷信起来！……不管咱们的敌手是何人或何物，我都只好臣服。我已经再也没有战斗的勇气，再也没有进取的精神。我一败涂地，彻底被打败啦！……‘咱们在这个世界，在天使以及世人面前丢人现眼！’我现在总是在重复这句话。”

“我和你有同感！”

“咱们该怎么办呢？你现在倒是有了工作，但别忘了，这只是因为咱们的历史和关系还不大为人所知……他们如果知道咱们未正式举办婚礼，就很可能会解雇你，就像在阿尔布利坎时一样！”

“这我倒不清楚。也许他们不至于那样。尽管如此，我觉得应该使咱们的婚姻合法化——你一能出门，咱们就办事。”

“你觉得应该吗？”

“当然。”

裘德想了想，然后又说道：“有那么一些人，即所谓的诱奸者，好人躲避唯恐不及，我近来觉得我就是他们当中的一员。一想到这里，我就感到震惊！我以前没意识到，也没意识到我对你的行为是错误的，只知道我爱你胜过爱我自己。然而，我的确是他们当中的一员！不知道他们当中是否还有跟我一样糊涂、简单的人！苏……我就是这种货色。我诱奸了你……你原是个超尘脱俗的人——一个飘逸秀雅的人，按照天意应当洁白如玉，不容玷污。可是，我却使你蒙上了污垢！”

“不，不，裘德！”她连忙说，“别把莫须有的罪名扣在人头上。要怪就只能怪我。”

“当初你离开费洛特孙时，是我为你撑腰打气；如果没有我，你也许不会逼他放你走。”

“没有你，我也会那样做的。至于咱们的结合，没签订合法的婚约反而成了件好事。正因为如此，咱们才没有亵渎各自头一次婚姻的庄严性。”

“庄严性？”裘德有点诧异地望着她，同时意识到她已经不是从前的那个苏了。

“是的。”她声音有些发抖地说，“我有一种可怕的恐惧感，觉得自己的行为蛮横无礼。我一直觉得——我仍是他的妻子！”

“谁的？”

“理查德的。”

“噢，天呀！……为什么？”

“我解释不清，只是时时产生这念头。”

“这是你意志不坚定而产生的结果——一种不健康的幻想，毫无道理也毫无意义！别再为此心烦啦。”

苏心神不定地叹了口气。

家中经济状况的改善冲淡了这种争论所造成的不愉快，要是在以前，他们一定会为之感到高兴的。几乎刚一到达该地，裘德就意外地找到了可心的工作，重干起了老本行，而且夏季的天气很适合他那虚弱的身体。从表面上看，他的日子单调乏味、千篇一律，但经历了动荡不安的生活之后，这种日子令人十分欣慰。世人似乎忘掉了他曾有过叫人难为情的越轨表现；他每天都到以前不准许他入内的学院里，攀上栏杆和墙头干活儿，以及修理那些以前不许他凑近的坍塌的石头棂窗；他埋头工作，仿佛从未有过其他的愿望。

另外他还有一种变化——现在，他不常去教堂做礼拜了，最令他担心的是：自那场悲剧发生之后，苏和他在思想上已背道而驰。过去发生的种种事件使他在看待人生、法律、传统及信条时，眼界更为开阔，然而对苏却没有产生同样的效果。昔日她见解独到，智慧如明亮的闪电刺向那些他当时敬重而现在蔑视的习俗和礼法，而今她却判若两人。

一个星期天的傍晚，他回来得很迟。她当时不在家，但没多一会儿就回来了。他发现她默默无言、心事重重。

“在想什么，小姑娘？”他好奇地问。

“唉，说不清楚！我觉得咱们在生活中一直都表现得自私自利、漫不经心，甚至冒犯了天威。咱们一味追求自我欢乐，可是却徒劳无益。岂不知自我克制才是更为高尚的道路。应当抑制肉欲，抑制可怕的肉欲，抑制致使亚当遭到天罚的肉欲！”

“苏！”他喃喃地说，“你这是怎么啦？”

“咱们应当不断地自我抑制，为神圣的职责做出牺牲。可我过去总是恣意妄为，随心所欲。我多么希望能彻底摆脱邪恶，摆脱一切可怕的错误，摆脱一切罪恶的行为！”

“苏，我亲爱的，你心里太苦啦！你并不是一个邪恶的女人；你自然的本能是非常健康的。也许，你不像我所希望的那样激情满怀，但你善良、可爱、纯洁。正如我常说的那样，你是我所认识的女人中最空灵超俗、最不讲求肉欲的一个，同时又不缺乏人之共有的性爱。你说起话为何跟从前不一样了？咱们并不自私自利，只有当慷慨大度不能给别人以好处时才表现出自私。你曾说人之本性是高尚和坚忍不拔，而非邪恶和堕落的，最后我终于觉得你说的是至理真言。而现在，你似乎对人的看法急转直下！”

“我渴望有一颗谦虚的心，以及千锤百炼的思想，但我从未如愿过！”

“你历来勇敢无畏，无论在思想还是感情方面都是如此，应该得到更多的爱，而我给你的却是有限的。我那时受到狭隘信条的约束，看不到这一点。”

“别这样说，裘德！我希望我的每一句勇敢无畏的话以及每一种勇敢无畏的思想都从我的历史中连根拔掉。自我否定才是至关重要的！我再不能使自己蒙羞受辱了。我真想用针扎得我遍体鳞伤，让体内的坏水像鲜血一样流出！”

“嘘！”他说着，把她可爱的脸拥入怀中，就仿佛她是个婴儿，“丧子之痛才使你成了这样。忏悔的不应该是你，我的含羞草，而应该是天下的那班坏蛋——可惜他们永无忏悔之意！”

“我不该再这样下去啦。”她在他怀里依偎良久，然后说道。

“为什么？”

“这是自我姑息。”

“怎么又弹起了老调！世界上能有什么比咱们相互的爱更美好？”

“有的，这取决于什么类型的爱，你我之间的爱是错误的。”

“我不同意，苏！算啦，你希望什么时候到教堂的法衣室签字结婚呢？”

她没吭声，过了一会儿才不安地抬起头说：“永远也没有那一天。”

他不明白她话里的全部含意，所以听后声色未动，什么也没说。过了几分钟，他以为她已睡着，但当他悄声细语说话时，却发现她一直醒着。她坐直身子，叹了口气。

“今晚你身上有一种难以形容的奇怪气味或气氛，苏。”他说，“我并不是单指思想上，也指你的衣服上。一种植物的香气，我似乎知道，却又记不起来。”

“是香火味。”

“香火？”

“我到圣西拉教堂做礼拜，染上了那儿的香火味。”

“哦，圣西拉教堂？”

“是的。我有时候到那儿去。”

“真的？你竟然到那儿去！”

“你知道，裘德，平时上午你工作的时候，家里是很寂寞的。于是我就想……想起我的……”她停下来，直到控制住了喉管里的哽咽，才又继续说了下去，“我到圣西拉教堂，是因为那儿离得近。”

“哦……当然，我没有反对的意思。只是这对你而言有些奇怪。他们绝对想不到他们中间竟有一个这样的人物！”

“你指的是什么样的人物，裘德？”

“呃……坦白地说，一个怀疑宗教的人物。”

“我已经够苦恼的了，你怎么能如此刺痛我，亲爱的裘德！我知道你并非故意的，但你不该说那种话。”

“我再不说了。不过，我的确感到十分意外！”

“好啦，我还有事情想告诉你，裘德。你听了不会生气吧？自从孩子们死后，我想了很多很多。我觉得我不该再做你的妻子——或者充当你妻子的角色。”

“什么？……可你是我的妻子呀！”

“那是你的观点；可是……”

“当然，咱们害怕举行仪式，许多人处于咱们的位置也会感到害怕的，这其中有充足的原因。但经验证明咱们错误判断了自己，把自己估计得过于懦弱。你似乎已开始尊重仪式礼节，那咱们为何不立即举办婚礼呢？你当然是我的妻子，苏；除过法律，你在所有的方面都是我的人。你刚才说那话是什么意思呢？”

“我认为我并非你的妻子！”

“并非？假如咱们当初举办了婚礼呢？那你就会觉得是我妻子了吧？”

“不，即便那样我也不会有这种感觉。我会觉得比现在还糟。”

“不怕我说你脾气乖张，可这是为什么呢，我亲爱的？”

“因为我是理查德的人。”

“啊……你以前就对我提示过这种荒谬的念头！”

“那时只是我的一种印象；随着时间的推移，我愈来愈相信：我要不属于他，要不谁也不属于。”

“我的天呀，咱们俩整个儿颠倒了个位置！”

“是的，也许是这样的。”

几天之后，那是一个夏日的黄昏，他们正坐在楼下的同一个小房间里，忽听有人叩响了木匠家的大门（他们在一个木匠家寄宿）。过了一会儿，他们房间的门也被叩响了。未待他们去开门，来人已将门推开——一个女人的身影出现在他们面前。

“弗利先生在这儿住吗？”

裘德和苏都吓了一跳，他机械地应了一声，因为那是阿拉贝拉的声音。

他客气地请她进来，阿拉贝拉进屋后，背着光在窗前的凳子上落座，他们可以看得清她的轮廓，却无法瞧得见细处以判断她的整个容貌及神气。但他们觉得她似乎已不如卡特莱活着的时候条件舒适，衣着打扮也不似那般精神了。

三人就那次悲剧展开了一次尴尬的谈话。悲剧发生之后，裘德觉得自己有责任立即通知阿拉贝拉，便写了一封信，可阿拉贝拉一直没回信。

“我刚从墓地那儿来，”阿拉贝拉说，“我经过打听，找到了孩子的坟。我当时不能来参加葬礼……不过，对于你的邀请我还是要表示感谢的。我在报上看到了关于那件事的报道，觉得自己不便露面……是的，我当时不能来参加葬礼。”她重复地说。她想做出悲恸欲绝的样子，但根本无法达到理想，于是便笨拙地重复起了自己的话。“不过，我很高兴我找到了他的坟。裘德，你是干石活儿的，应该有能力为孩子们竖块墓碑。”

“我会那样做的。”裘德悲哀地说。

“他是我的孩子，我自然为他感到难过。”

“但愿如此。我们都为他难过。”

“另两个孩子不是我生的，我的悲伤就不那么强烈，这也是很自然的。”

“当然。”

从苏坐的那个阴暗的角落传来一声悲叹。

“我经常想着让我的孩子跟我在一起，”卡特莱夫人又说道，“那样的话，事情就可能不会发生了！当然，我并不想把他从你妻子的身边夺走。”

“我不是他的妻子。”苏说了一句这样的话。

她的话突如其来，弄得裘德哑口无言。

“哦，请你原谅，”阿拉贝拉说，“我还以为你是呢！”

裘德从苏的口气中得知，她的话里隐藏着异乎寻常的新观点。而阿拉贝拉只理解了表面的意思，自然没听出深切的含意。她显然也为苏的话感到吃惊，但平静下来后，就继续泰然自若、不遮不掩地谈论起了“她的”孩子——孩子活着的时候，她未尽一点心意，此刻却装出一副悲伤的样子，好像这样才能对得起良心。她转弯抹角说起了往事，并且对苏又提出了疑问。可是却没听到回答。原来苏已不为人觉察地离开了房间。

“她说她不是你的妻子？”阿拉贝拉换种声音，又继续说起了话，“她为何要那样说呢？”

“无可奉告。”裘德简短地说。

“她到底是不是你的妻子？她有一次告诉我说她是的。”

“对于她的话我不便加以评价。”

“噢——我明白啦！好吧，我该走啦。今晚我住在这个地方。既然发生了那件令咱们感到悲伤的事情，我觉得自己有责任来一趟。我在我曾经当女招待的那家酒馆过夜，明天返回阿尔弗利逊。家父已回国，我和他住在一起。”

“他从澳大利亚回来啦？”裘德无精打采地问。

“是啊。在那儿过不下去，受了很大的罪。家母死在了炎热的天气里，患的是痢疾什么的。家父带着两个小的刚刚回国，在我们原来的旧址附近找到一座房子，眼下我为他理家。”

甚至在苏离开之后，裘德的前妻仍拘于礼节，表现出有良好教养的样子，限制自己逗留的时间，以合乎最体面的标准。待她离去，裘德如释重负，跟到楼梯那儿喊苏，为她的情况感到惴惴不安。

没有人回答。出租房屋的那个木匠说苏没有回来。裘德迷乱起来，见苏不在，感到非常惊慌，因为天色已经很晚了。木匠把妻子喊了来。那女人猜想苏去了圣西拉教堂，因为她常到那儿去。

“夜色已深，她肯定不会去吧？”裘德说，“教堂已经关了门。”

“她认识管钥匙的，一旦需要就可以把钥匙拿到手。”

“她这样子有多久啦？”

“噢，大概有几个星期啦。”

裘德深一脚浅一脚地朝教堂的那个方向走。以前他在该地区住时，曾到那儿去过，当时他幼稚的思想比现在更难让人理解；自那以后，他就再也没有接近过圣西拉教堂。到了教堂，不见一个人影，但大门显然没上锁。他取下门闩，一点响动也没弄出来，进去后又随手把门关上，一动不动地站在里边。在一片寂静之中似乎有一种细微的声音，像是喘息或抽泣，是从教堂的另一端传过来的。他在昏暗之中朝那边走去，地毯使他的脚步无声无息；那片昏暗中，只有外边透进来的星光在闪着极其微弱的光。

裘德可以看得到，在圣坛台阶的上方高悬着一个庞大、结构坚固的拉丁式十字架，大概跟它所要纪念的原物一样大。它似乎被肉眼看不见的铁丝吊在空中，上面镶嵌着大颗的宝石；当十字架静静地、几乎不被人觉察地前后摆动时，那些宝石在外边射进来的微光里淡淡地闪烁。在十字架的地板上，有一团黑衣服似的东西，从那儿又传来了他刚才听到的那种抽泣声。那是苏的身影，平伏在地上。

“苏！”他低声叫道。有一样白东西露了出来，原来是苏扬起了脸。

“你来这儿干什么，裘德？”她说话时语调有些严厉，“你不该来！我想一个人待着！你为什么要闯进来呢？”

“你怎么能这样问呢？”他立刻责备地说。他看见她这种态度，不由伤透了心。“我为什么要来？如果我不能来，那我倒想知道，究竟谁才有权利来！我爱你胜过爱我自己，也胜过——远远地胜过你对我的爱，难道就不能来吗？你为何抛下我，独自到这里来？”“请你不要指责我，裘德，我受不了这个。我常常跟你说起我的情况，你必须面对现实！我是一个可怜虫，被内心的矛盾折磨得发了疯！阿拉贝拉来时，我再也无法忍受，感到苦恼极了，只好躲到了这儿。她似乎仍是你的妻子，而理查德仍是我的丈夫！”

“他们现在跟咱们已没有关系！”

“你错了，我亲爱的朋友，他们跟咱们是有关系的。我现在对婚姻的看法已不同以往！……老天夺走了我的孩子，向我表明了天意。阿拉贝拉的孩子杀死我的孩子，便是一种惩罚。正义消灭邪恶！我该怎么办呢？我是一个罪大恶极的人，不配跟普通人在一起生活。”

“太可怕啦！”裘德说话时，眼泪都快流了出来，“你并没做错事，却如此悔恨自己，实在不应该，也不合乎常理。”

“哼，你是不了解我有多么坏！”

# 4

那个在苏的思想转变过程中被她视为不可分离的丈夫的男人，仍然住在玛利格林。

孩子们惨死的前一天，费洛特孙在克里斯特敏斯特看见苏和裘德冒雨观望游行队伍向大礼堂挺进。可他当时对同伴吉林哈姆却只字未提。吉林哈姆是他的老朋友，在玛利格林村他的家里做客；其实，那天到克里斯特敏斯特去，还是此人建议的呢。

“你在想什么？”回家的路上，吉林哈姆问他，“是在想你一直没弄到手的大学学位吧？”

“不是，不是。”费洛特孙态度生硬地说，“我在想今天看见的一个人。”过了一会儿他又补充了一句，“我看见了苏姗娜。”

“我也看见她了。”

“你怎么没说呢？”

“我不想让你注意到她。不过，既然你看见了她，你就应当对她说：‘你好吗，我从前的宝贝？’”

“呃，是呀，我可以那样说。不过，不知你是怎么想的——我反正完全有理由认为，我休掉她时，她是无辜的，做错事的是我。是的，的确如此！很叫人难堪，对不对？”

“自那以后，她显而易见在不遗余力地使你的决断正确化。”

“哼，你的挖苦一钱不值。毫无疑问，我当时应该耐心地等待。”

周末的时候，吉林哈姆回萨斯顿附近他的学校，而费洛特孙按照老习惯前往阿尔弗利逊赶集。他沿着漫长的山坡朝下走——这山坡他在裘德未涉足之前就已经熟悉了，但他的历史却不如裘德的和此处联系得那般紧密。来到镇上，他又像往常一样买了份当地的周刊。当他在一家酒馆坐下休息，准备为回家的那五英里路鼓劲时，他从衣袋里取出那份周刊看了起来。那篇题为“石匠子女奇怪的自杀案”的报道映入了他的眼帘。

他虽然不轻易动感情，可这次却感到很痛心，同时也有些困惑不解，因为他不知道裘德的大孩子年龄是否跟报上说的相符。可报纸总得讲事实，这是毋庸怀疑的。

“这一下，他们的苦难达到了极限！”他说道，同时心里一个劲在想苏，想着苏离开他后所落的下场。

阿拉贝拉在阿尔弗利逊安下了家，而这位教书匠每个星期六都来赶集，所以他们自上次分手后在几个星期内再度重逢也不足为奇了。这次他们相见，正是阿拉贝拉刚从克里斯特敏斯特回来的时候——她在克里斯特敏斯特逗留的时间比起先打算的要长得多，因为她关注上了裘德，尽管裘德自那次会晤后再没跟她见过面。费洛特孙是在回家的路上碰见阿拉贝拉的，那时她从镇外已走到了镇子跟前。

“你出来散步喜欢走这条路，是不是，卡特莱夫人？”他招呼道。

“我刚刚开始走这条老路，”她回答说，“我当姑娘时以及嫁人之后都住在这一带。我一生中所有令我感兴趣的往事都和这条路有千丝万缕的联系。最近，往事又在我心头翻腾起来，因为我去了一趟克里斯特敏斯特，在那儿看见了裘德。”

“啊？他们是怎么承受那场可怕的灾难的？”

“以一种非常奇特的方式，非常非常奇特！她已经不跟他住在一起了。我去拜访他们时，从他们的言谈举止就觉察到事情在朝那方面发展，但就要离开克里斯特敏斯特之前才听到了确切的消息。”

“不跟她丈夫住在一起？哦，我还以为灾难会使他们联结得更紧密呢。”

“他根本就不是她的丈夫。他们多年以夫妻的名义在一起，但实际上她一直没嫁给他。孩子的死没有使他们迅速行动起来合法地把事办了，她竟然奇怪地对宗教热心起来，就跟我痛失卡特莱时一样，只不过热情更高罢了。别人告诉我，她声称她在上帝和教会的眼里是你的妻子，只属于你；任何人为的事情都无法使她属于别人。”

“哦……真的？……他们分居啦？”

“你知道，那个大孩子是我生的……”

“哦——原来是你的儿子！”

“是的。唉，可怜的小家伙……不过得感谢上帝，他是合法婚姻的产物。也许，她首先感觉到的是我应该处于她的位置。谁说得准呢！至于我的情况……我马上就要离开这儿了。眼下我得照料父亲，这种气氛单调的地方是不能够住的。但愿我用不了多久便可以回到克里斯特敏斯特的酒馆里，或者到别的大城镇去。”

他们分了手。费洛特孙往山上才走了几步便又站住，然后快步走回来把她叫住。

“他们住在哪儿？以前的地址也可以！”

阿拉贝拉把地址给了他。

“谢谢你。再见！”

阿拉贝拉脸上泛起狰狞的笑容，继续走她的路；从开始有秃梢柳树的地方起，直到镇子第一条街上的古老的济贫院，她一路上练着嘬酒窝的绝技。

与此同时，费洛特孙爬着山坡向玛利格林走去。在这一段漫长的时期里，他第一次开始对生活有了憧憬。他向那座偏僻的学校行进，在从草地上的大树下走过时，不由留住脚步停留了一会儿，想象着苏跑出门来迎接他。就因为他大发慈悲放走了苏，他遇到了极大的麻烦，那是任何表示怜悯之心的人都无法比拟的，不管基督徒也罢异教徒也罢。在那班满嘴仁义道德的人手里，他饱受几乎让人无法忍受的颠沛流离之苦。他差一点没被饿死，而今完全依靠这座村庄里小学的一丁点收入生活，而村里的牧师由于跟他交朋友遭到了世人的非议。他常常想起阿拉贝拉的话，说他应该对苏严厉一些，用不了多久苏的反抗精神便会崩溃。可他性情倔强，似乎不通情理，全然不管别人的看法以及自己所学到的原则，深信自己对妻子采取的措施是正确的，而且这种观念从未动摇过。

原则可以根据一方面的感情而推翻，也可能会受到另一方面感情的影响而改变。过去他由于本能的驱使给了苏自由，现在这本能并没有因为苏跟裘德同居而使他看低她。即便不是出于爱，他也仍然以自己奇特的方式希望得到她。且不论这是否明智之举，反正他很快就觉得如果能让她回到他身旁，他将非常高兴，但必须要她心甘情愿才行。

他发现，为了抵制世人残酷无情的冷嘲热讽，得讲究一下策略，而跟前就有现成的材料。他可以找个体面的借口，就说他以前错怪了苏，跟她离婚也是错误的，先把她弄回来复婚；他从中可以得到些安慰，恢复原来的事业，也许能重返萨斯顿小学，甚至还有望作为无牧师资格的传教人进教会。

他觉得该给吉林哈姆写封信征求一下意见，就说他准备给苏写信，问吉林哈姆怎么看待。吉林哈姆回了信，自然认为：她既然已离开，就最好不要再理她；如果她为人之妻，就该是那个男人的妻子，因为她和他生过三个孩子，有过那样悲惨的遭遇；那个男人对她的爱似乎异常强烈，所以这对情侣到时候可以合法地结合，使一切都妥妥帖帖、体体面面、平平稳稳。

“可他们是不会结婚的——苏不愿意！”费洛特孙自言自语地大声说，“吉林哈姆这个人太实际。岂不知她受到的是克里斯特敏斯特思想和教育的影响。我很清楚，根据她的观点婚姻是不可解除的，我也知道她的观点来自何处。虽然我并不这么看，但我将利用那种观点以推行我的观点。”

他给吉林哈姆写了封短信：“我知道自己是完全错误的，但我不同意你的话。至于她跟他同居，和他生了三个孩子一事，我觉得那只不过使她的教育更加完善罢了，可惜我不便用旧道理为我的看法提供逻辑和道德上的辩护。我将给她写信，以了解那个女人的话是否属实。”

其实在动笔之前他就打定了主意，所以给朋友写不写这封信都不重要。不过，这是他为人处世的方法。

于是，他寄给苏一封经过仔细推敲的信，字里行间表现出一丝不苟的严肃性，谨慎地掩饰住他那异教徒式的感情免得吓坏她。他说他已得知她的观点发生了巨大的转变，于是便觉得有必要讲明他的人生观在他们分离之后由于一系列事件的影响也产生了巨变。他写这封信并非出于强烈的爱，对此他不愿加以隐瞒。他写此信是出于一种愿望，希望他们的生活即便不幸福美满，至少也不要成为灾难性的失败——以前他按照自己所认为的正义、仁慈和合理的原则办事，差点使他们的生活一塌糊涂。

他发现在我们这个文明古国里，按天生、放纵的正义感行事，是不允许的，是会受到惩罚的；如果想获得一份财物和荣誉，就必须按照学到的、经过培养的正义感行动，不要去管博爱仁义那一套。

他建议她到玛利格林来找他。

经过再三思考，他删去了倒数第二段，又把信重抄一遍，立即发了出去，然后有点激动地等待着事态的发展。

几天后，一个人影穿过笼罩着克里斯特敏斯特城别雪巴郊区的白雾，朝着裘德·弗利自他和苏分居之后所住的那个地方走去。此人到了他的寓所，胆怯地叩响了房门。

时值傍晚，所以他正好在房间里。他似乎预料到了来客是何人。跳起身亲自跑去开门。

“能出来陪我走走吗？我不愿进屋里去。我想……我想跟你谈谈，和你一块儿到墓地去一趟。”

说这番话的是苏那颤抖的声音。裘德戴上了帽子。“天气阴冷，不适合于你出门。”他说，“不过，如果你不愿进屋，我不妨跟你出去吧。”

“是的，我不愿进去。我不会耽误你很长时间的。”

裘德十分不自在，开始的时候无法再朝下说；她也是一样，神经紧张得缩成了一团，似乎失掉了主动攀谈的勇气。他们在浓雾中似阴间的鬼魂一般走了老半晌，不出声音，也没有表情。

“我想告诉你一件事，”后来她说道，声音急促、低沉，“免得你从别人的口中偶然听到。我准备回到理查德的身边。他宽宏大量，答应原谅过去的一切。”

“走回头路？你怎么能……”

“他打算和我复婚。那是走走形式，是做给世人看的，因为他们只管形式，不顾实质。不过，我理所当然早已是他的妻子，任何事情都没改变这一点。”

他蓦然转过脸来，带着近乎于凶狠的痛苦表情。

“可你是我的妻子！不错，你是我的，这你是知道的。我一直在后悔，不该顾面子就弄虚作假跑到外边去，回来时装出一副已合法结婚的样子。那时我爱你，你也爱我，咱们亲密无间，这些都是婚姻的基础。现在咱们依然相爱，我仍然爱你，你也依旧爱我——这我是知道的，苏。因此，咱们的婚姻并没有废除。”

“是的，我明白你的观点。”她自我抑制着，表情绝望地说，“但我还是准备跟他复婚，即所谓的再次结婚。严格地说——别怪我多嘴，裘德——你也应该和阿拉贝拉破镜重圆。”

“是吗？上帝呀，还有什么呢！以前咱们差一点结婚，如果你我当初合法地办了手续呢？”

“我会觉得反正都是一样——咱们的婚姻不算数；我还会回到理查德的身旁，而且只要他吭声气，婚礼也不用再办了。不过，我认为‘凡事都有其自身的价值’，所以我情愿再举行一次结婚仪式……我求求你，不要挖苦和吵嘴，把我置于死地。我曾经是个极为要强的人，也许对你残酷无情。可是，裘德呀，我求你对我要以德报怨！我现在成了弱者，你可不要报复我，而应该对我仁慈一些。噢，你可要对我——一个努力改邪归正的既可怜又可恶的女人仁慈些！”

他无奈地摇摇头，眼圈都湿了。丧子的打击似乎摧毁了她的理智，以前敏锐的思想现在已模糊不清。“全都错啦，全都错啦！”他声音沙哑地说，“这是错误行为，是堕落！这会让我发疯的。你到底喜欢他吗？你究竟爱他吗？你明明知道自己并不爱他！你们的结合是丧失理智的卖淫；愿上帝原谅我说这样的话——可这是事实！”

“我不爱他，这我得承认，也表示最深切的忏悔。不过我将服从他，从服从中学会爱他。”

裘德争辩、劝说、恳求，但她的观念丝毫都不动摇。天地之间似乎只剩下了她所坚持的这一件事情；由于她在这方面坚定不移，她所具有的别的一切冲动和愿望都变得不重要了。

“我好心好意想让你知道实情，想把情况亲口告诉你，”她用伤心的语调说，“免得你从别人那儿听到后，觉得我瞧不起你。我甚至把我不爱他这样最令人忌讳的事实都袒露给了你。我没想到你会因此对我这般粗暴无礼。原来我还打算求你……”

“为你主婚吗？”

“不是。我是打算在你情愿的情况下把我的箱子送去。不过，我想你不会情愿的。”

“嗬，我当然愿意效劳。怎么？他不来接你，把你从这儿娶走吗？他不肯纡尊降贵，这样子做吧？”

“不是的，是我不让他来。我主动去找他，就像我离开他时一样。我们准备在玛利格林的小教堂里举行婚礼。”

裘德称她的行为是执迷不悟，但她甜丝丝的言谈中却含着凄楚；裘德出于对她的怜悯，非止一次情不自禁地潸然泪下。“我从不知道哪个女人像你这样凭着感情的冲动悔恨不已。刚刚想着你会按理智的步骤朝前走，苏，可你却突然转了弯！”

“哦，算啦，不提这些了……裘德，我必须跟你告别。可我还想让你跟我到墓地去一趟。让咱们在那儿分手吧——在那些以自己的死使我明白我观点错误的孩子们的坟边。”

他们朝着墓地的方向走去，守门人听了他们的解释后打开了门。苏常来常往，摸黑也熟悉那里的路。他们来到墓前，静静地站着。

“我想咱们就在这儿分手吧。”她说。

“悉听尊便。”

“请你不要因为我按信仰办事就认为我心狠。你对我慷慨的爱是举世无双的，裘德！你在世俗道路上遭受失败（如果你真的失败了的话），应该得到赞扬，而不是受指责。别忘了，人类最优秀、最伟大的人往往在世俗道路上失意潦倒。凡志得意满者或多或少都自私，而忠心虔诚者则失败。‘善心不求善报。’”

“对于那一章的看法，咱们不谋而合，我亲爱的人儿；咱们就按那一章的内容友好地分手吧。当你称之为宗教的一切思想都化为乌有时，那一章里的词句将依然根深蒂固地留于人间。”

“好啦，不要辩论了。再见，裘德，我犯罪的同伙，我最善良的朋友！”

“再见，我误入歧途的妻子。再见！”

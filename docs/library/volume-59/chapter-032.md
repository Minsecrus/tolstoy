# 5

第二天下午，克里斯特敏斯特那令人眼熟的浓雾仍笼罩着所有的景物。依稀可见苏那苗条的身影走向火车站。

裘德这天没心思上班，也不便到苏可能经过的那块地方。他朝着相反的方向，走到一块凄凉、奇特但平坦的地方，那儿的树枝朝下滴着水，暗藏着患咳嗽病和肺结核的危机，是块他以前从未涉足过的地方。

“苏走啦，离开了我！”他凄楚地低声自言自语。

就在这段时间里，苏已经乘火车离开克里斯特敏斯特，来到了通往阿尔弗利逊的公路上，换乘有轨电车向那座城镇行进。她请求费洛特孙不要来接她。她说她想主动去找他，主动走入他的家门，主动走到壁炉旁。

这是星期五的黄昏时分。之所以选这个时候，是因为那位教书匠从这天的四点钟起，直至下星期一的上午都没有课。她在黑熊店雇了辆小马车前往玛利格林；走到篱路的尽头，离村子还有半英里路程的时候，她下车后让马车先行一步，把她带来的那堆行李送到学校去。马车返回时跟她相遇，她问车夫是不是看到校长家的门开着。车夫说是的，还说校长亲自把她的东西拿了进去。

现在她进玛利格林村，就不会太招眼了。她从水井旁经过，从树下走到另一侧的那座漂亮、崭新的学校跟前，没敲门便直接拉开了校长住房的门闩。费洛特孙站在屋子当中，按她的要求在等待她。

“我来了，理查德。”她说话时，脸色苍白，浑身颤抖，一屁股坐到了椅子上，“我简直不能相信，你竟然原谅了你的……你的妻子！”

“原谅了你的一切，亲爱的苏姗娜。”费洛特孙说。

这番话说得很有分寸，并不热烈，可她听了那亲昵的语气吓了一跳。随后，她又稳住了神。

“我的孩子死了……他们死了也好！我甚至感到有点高兴，因为他们是罪孽的结晶。他们用自己的生命教会了我怎样为人！……他们的死是我洗除罪恶的第一步！……你愿意收留我吗？”

他为她可怜巴巴的话及语调所深深打动，做出了超出自己意图的事情——他俯身吻了吻她的脸颊。

苏难以被人觉察地微微向后一缩身子，脸上的肉在他嘴唇的接触下发出颤抖。

费洛特孙的心向下一沉，因为欲望正在他身上涌动。“你仍然厌恶我！”

“噢，不，亲爱的……我……我在潮湿的空气里坐了这么半天的车，身上有点发冷。”她说道，脸上急忙堆起善解人意的微笑，“咱们什么时候举办婚礼？很快吗？”

“如果你真心希望结婚，我想就在明天一大早吧。我让人捎信给牧师，就说你来了。我把全部情况都跟他讲过了，他非常赞成，说咱们的生活将过得美满、如意。但是……你是否拿定了主意？你知道吗，如果你觉得不能结婚，现在反悔为时还不算太晚！”

“我想好了，可以结婚！我想把婚事快快地办了。请你告诉牧师，告诉他立即办事！我对这件事急不可待，不能让我等的时间太长！”

“你先吃点、喝点，然后就到艾德林夫人家你的房间休息。我让牧师明早八点半为咱们主持婚礼，趁着村里还没人到处走动……这样子对你是不是太急促了些？我的朋友吉林哈姆来这儿帮着操办仪式。他心肠够好的了，从萨斯顿大老远赶来有多不方便啊。”

普通女人都特别注意具体的东西，而苏却与众不同，她好像连屋里的什么东西也没看见，周围环境的什么细节也没注意到。可是，她走到客厅的另一侧想放下手筒时，却啊地叫了一声，脸色变得更加灰白了。她的表情就像被判处了死刑的囚犯瞧见了自己的棺材。

“怎么啦？”费洛特孙问。

原来写字台的盖儿碰巧开着，她去放手筒时瞥见里边放着一份文件。“哦，没什么，只是有点意外，实在太可笑啦！”她回到饭桌旁，哈哈笑着借以掩饰。

“噢，对啦，”费洛特孙说，“那是许可证……才送来的。”

这时，吉林哈姆从他在楼上住的房间里走下来，苏紧张地穷于应付，净谈些她认为他有可能感兴趣的话题，闭口不提她自己的情况，岂不知对方最感兴趣的恰恰是她本人。她顺从地吃了些饭，然后准备到离这儿不远的住处去。费洛特孙陪她走过草地，在艾德林夫人家门口跟她道了别。

那位老夫人把苏送到她临时住的房间，帮着她解行李。在那堆东西里，她翻出一件刺绣得很精致的睡衣。

“噢……我不知道怎么把这也打进了行李里！”苏连忙说道，“全是出于无意。这儿另外还有一件呢。”她取出来一件非常朴素的新睡衣，是用未经漂白的粗布做成的。

“这一件漂亮极啦，”艾德林夫人说，“而那一件跟《圣经》上说的麻袋布片别无二致！”

“是的，但我要的就是这件。把你手里的那件给我。”

苏接过睡衣，拼尽全力撕起来，那撕衣服的声音响彻了整幢房子，似鸮的尖叫。

“天呀，天呀！这是怎么……”

“这是通奸的标志！它代表的是我现在已没有了的感情……我很久以前买下它，是为了让裘德高兴。必须把它销毁！”

艾德林夫人无奈地摊摊手，苏情绪亢奋地继续把睡衣撕成碎条投入火中。

“你本来可以把它给我嘛！”那位寡妇说，“眼看着如此漂亮的衣服在大火中化为灰烬，多让人心疼啊。倒不是说这种绣花睡衣对我这种老女人有多大的用，因为我已经过了穿花衣服的年龄。”

“这是该诅咒的东西，使我想起我情愿忘记的往事！”苏又重申自己的观点说，“它只适合于投入火中。”

“天呀，你太严苛了。你说这种话，也是在诅咒你那可爱、无辜的孩子！我以生命保证，这不合宗教信仰。”

苏把脸扑在床上呜呜哭起来。“噢，别说啦，别说啦，这是在要我的命！”她由于悲痛全身颤抖不已，身子一软跪倒在地上。

“听我一句话，你不该跟这个男人复婚！”艾德林夫人愤怒地说，“你仍在眷恋着另外的一个！”

“不，我必须跟他复婚，因为我属于他！”

“得了吧！你属于另外的一个。如果你们起初不愿再受婚约的束缚，那也是情有可原、问心无愧的；你们可以继续在一起生活，最后再走上正轨。那毕竟只涉及到你们两人，与别人是无关的。”

“理查德说他愿意让我回来，所以我必须回来。当初假如他拒绝收下我，我也就没多大的责任非得放弃裘德了。可是……”她把脸仍埋在床单上，而艾德林夫人却离开了房间。

就在这段时间里，费洛特孙已回到他的朋友吉林哈姆的身旁，见吉林哈姆仍坐在饭桌前。不一会儿，他们立起身，走到外边的草地上想去抽一会儿烟，苏的房间里亮着灯光，一个人影在百叶窗那儿晃来闪去。

显而易见，苏那难以描绘的魅力给吉林哈姆留下了深刻的印象。此时，他在沉默了一阵子之后说道：“好啦，你最后总算又得到了她。她总不会再次离开你吧？这颗梨子已落入你的手中。”

“是的……我想我是对的，应该相信她的话。我承认我的决定里有自私的成分。她对我这样的老厌物无异于璀璨的明珠，除此之外，这件事还能在教会人员及教外俗人的眼里恢复我的正确形象——那些人因为我放她走的缘故一直都没原谅我。这样一来，我便可以在某种程度上回到原来的老路上。”

“好呀，既然你认为应该和她复婚，那就以上帝的名义现在就办事吧！我历来反对你开笼放鸟的做法，那简直是自杀！如果你对她不是一味地纵容，现在该也当上了督学或牧师啦。”

“我知道我给自己造成了无法弥补的损失。”

“一旦再圈住她，就不要放她走了。”

这天晚上，费洛特孙闪烁其词，态度模棱两可。他不愿明正地承认：他把苏又收回身旁，从根本上并非是对放走苏的后悔表示，而主要是人性的本能对习俗观念的勇敢反抗。他说：“是的，我会那样做的。不管放她走有多么公正，对于以我这种观点看待其他事物的人，都是缺乏逻辑性的。”

吉林哈姆望望他，心里感到纳闷，不知被世人的嘲笑及自身的肉欲所激起的叛逆精神是否会让费洛特孙拘守礼法对苏残酷起来，一改往昔那种非正统、乖僻的宽容态度。

“我觉得不能只凭一时的冲动，”费洛特孙又说道，心里愈来愈感到必须酌情采取行动，“我违背了教会的训导，可我并非蓄意跟教会作对。女人有着奇特的影响力，可以引诱你没名堂地就发起慈悲来。不过，我现在明智了些。适当地严厉一点，也许……”

“不错，但只能逐渐勒紧缰绳。一开始不要太用力。她终究会服服帖帖的。”

这种谨慎是没必要的，不过费洛特孙却未如此说。“记得为了我同意她跟情人私奔一事大家发生了争吵，当我离开现场时，萨斯顿的牧师对我说：‘要想恢复你和她的地位，你就得承认：你没有用明智和严厉的手段拦住她是错误的；她要是愿意，你得收回她，将来对她严厉些。’但当时我一意孤行，对牧师的话充耳不闻。我做梦也想不到，既然离了婚，她却又产生了这样的念头。”

艾德林夫人家的大门吱扭一响，有人朝学校这边走了过来。费洛特孙打了声招呼。

“哦，原来是费洛特孙先生，”艾德林夫人说，“我正找你来着。我刚才到楼上去帮着她解行李；实不相瞒，先生，我觉得这事办不得！”

“什么事？婚礼吗？”

“是的。她那是在逼自己——可怜的小东西。你不知道她心里有多痛苦哩。我从不起劲地拥护宗教，也不反对它，但让她这样做是绝对不应当的，你该劝止才对。当然，对于你收她回来一事，大家会交口称赞，说你心地宽宏，可我却持不同的看法。”

“这是她的愿望，我也愿意。”费洛特孙板着脸冷淡地说。听到反对的呼声，他这时变得不合情理地执拗，“这样，可以挽回因疏忽而造成的损失。”

“我不相信！她只能是他的妻子。她和他生过三个孩子，而他对她一往情深。怂恿那个可怜无助的小东西做这种事，既可恶又可耻！没有人为她出谋划策。只有一个人关心她，可她顽固地不允许他接近她。真不明白她最初怎么产生了这样的念头！”

“无可奉告。我自己是说不清楚的。那全是她心甘情愿的，话我只能说到这里，”费洛特孙生硬地说，“你在反对我，艾德林夫人，这是很不应当的。”

“哼。我知道你听了我的话一定会生气，但我不在乎。事实终究是事实嘛。”

“我没有生气，艾德林夫人。你这么好心的邻居，我怎么能生你的气哟？但我倒想知道怎么做对我和苏姗娜才是上策。我想，你不会跟我们到教堂去了吧？”

“不去！我要去，就吊死我……真不了解现在的事态风云！如今，婚姻变得过于严肃了，让人望而却步，打内心里感到害怕。我们那个时候把结婚看得很随便，也没有什么不好的。我和我可怜的男人喜结良缘时，设宴请了整整一个星期的客，把教区里的酒都喝光了，后来借了两先令半的硬币才开始过起日子！”

艾德林夫人回到她的农舍去后，费洛特孙郁闷地说：“真不知道该不该结婚——至少不知道该不该把事办得这么仓促。”

“此话怎讲？”

“如果她真的是出于对责任或宗教产生了新的看法，才违背心愿逼着自己这样做，我也许应该劝她稍微等等。”

“事已至此，你不该打退堂鼓——这是我的看法。”

“现在我不好推迟婚事，这倒是真的。可我心有疑虑。因为她在看到许可证的时候不由惊叫出了声。”

“好啦，老伙计，不要疑神疑鬼啦。我愿意明天早晨为她主婚，而你愿意接受她，这就行啦。我一直良心不安，觉得自己当初没有坚决地反对你放她走；既然今天已到了这种地步，我唯有帮着你把事情纠正过来，心里才会踏实。”

费洛特孙点了点头。他见他的朋友如此忠实可靠，说话也就更加坦率了。“毫无疑问，此事一经传出去，许多人都会认为我是个软心肠的傻瓜。但是，他们没有我了解苏。她虽然令人难以捉摸，但她的心眼是诚实的，我觉得她没干过违背良心的事情。她跟弗利同居，但这说明不了任何问题。她离我而去时，她认为那并非越轨行为。现在，她改变了自己的看法。”

次日晨，这两位朋友根据各自的观点默认：那个女人应该在她自称为原则的圣坛上成为牺牲品。八点钟刚过几分，费洛特孙就跑到艾德林寡妇家把苏接了来。头一两天罩在低洼地的浓雾此刻聚到了这儿来，草地上的树木把它们团团拢住，然后变为大滴的水珠倾泻下来，新娘已万事俱备，穿戴好了衣帽。在死气沉沉的晨曦里，她一生中从未似今天这般更像她名字所表示的百合花。她历经磨难，厌倦了世事，满腹的悔恨；神经上的紧张感影响到了她的血肉之躯，于是她显得比从前更加瘦小——即便在最健康的日月里，她也不是个大块头女人。

“是时候啦。”教书匠大度地拉起她的手说。可他遏制住冲动没去吻她。因为昨天她受惊吓的情景仍令人不快地滞留在他的脑海里。

吉林哈姆跟他们会合，大家一道走出了房子。艾德林寡妇仍然坚决拒绝帮着操办婚礼。

“教堂在何处？”苏问道。自从旧教堂拆除以来，她从未在这一带住过，而现在满腹心事，忘掉了新教堂的地址。

“就在前边。”费洛特孙说。紧接着，教堂那雄伟、庄严的塔楼便从浓雾中闪现了出来。牧师已来到了教堂里，见他们进来，便打趣地说：“天黑得几乎都需要点蜡烛了。”

“理查德，你真的希望我成为你的人吗？”苏喘着气悄声问。

“当然，亲爱的，在这个世界上我最想得到的就是你。”

苏没再说什么。费洛特孙有两三次闪过念头，觉得这样做不太符合当初放她走的人道原则。

站在那儿操办婚礼的总共有五个人：牧师、书记员、新婚男女以及吉林哈姆。接着，那神圣的仪式又重新举办了一次。教堂中殿里有两三个村民，当牧师念到“天配良缘”时，可以清晰地听到那些人里边有个女人的声音说：“好一个‘天配良缘’！”

苏和费洛特孙就像自己从前的化身，把多年前发生在梅尔切斯特的那熟悉的一幕又重演了一遍。在结婚簿上签过名之后，牧师恭喜这对夫妇，说他们完成了一件高尚、正确和宽仁大义的事情。“结果好就一切都好。”他微微含笑地说，“愿你们从‘火中获救’之后，能够白头偕老。”

他们出了空荡荡的教堂，来到了学校里。吉林哈姆想当晚赶回家，于是早早就走了。他也对新婚夫妇表示了祝贺，在分手时对把他送出了一段路的费洛特孙说：“我将把喜讯告诉你家乡的人们，他们听了一定会为之喝彩的。”

教书匠走回来时，苏正在装模作样地干家务，仿佛她一直住在这儿似的。但他一接近，她就显得有点胆怯，他见了觉得良心上受到了责备。

“你放心，亲爱的，我还和从前一样，决不会闯入你私人的天地。”他一本正经地说，“复婚是为了改善咱们的社会影响，即便不是我力主，从这一点看也是很应当的。”

苏的脸上出现了一丝喜色。

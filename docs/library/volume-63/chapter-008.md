# 第二幕

高穹顶哥特式小房间

浮士德从前的书斋，毫无变化

梅非斯托（掀帘进来，当他掀帘回顾时，可以看到浮士德躺在一张旧式的床上）

倒霉人，且躺在这个地方！

陷进了难于挣脱的情网！

谁为了海伦魂消肠断，

心神就很难恢复正常。

四顾

6570　我朝这上下四壁观看，

一切都如旧，毫无改变；

只觉得蜘蛛网添了许多，

彩色玻璃则更加昏暗；

纸张变黄了，墨水已干，

6575　一切都还在原来的地点；

曾用来签字卖身恶魔，

这枝鹅毛笔还搁在这里。

嚄！笔管的深处还凝着

我向他骗取的鲜血一滴。

6580　对这样一件稀世的东西，

愿收藏名家能碰上运气。

旧皮衣还在旧钩上悬挂，

使我想起了那回的笑话，

我曾经教导那个娃娃，

6585　他成了青年怕还在消化。

我真的生出了这种心潮：

让这件温暖蓬松的皮袄，

由我来披上自命讲师，

像人们公认的不减分毫。

6590　学者们很会弄这种玄虚，

对恶魔来说早已成过去。

取下皮大衣抖动，有蝉、甲虫、蛾子等飞出

昆虫合唱

欢迎又欢迎！

欢迎大恩翁。

嗡嗡乱飞舞，

暗里一只只，

只要你养殖，

我们就成群，

跳来找老子。

6600　坏人坏主意，

深藏深心里，

虫子却很快

钻出皮大衣。

梅非斯托

幼小的生物多令我惊喜，

6605　播了种自有收获的时机。

我把旧皮衣再次抖动，

上吧！转吧！千万个旮旯，

钻进破盆尘封的碎片，

在这种杂物霉堆的里面，

浮士德穿的旧皮大衣！

6650　手持钥匙像圣彼得一样，

问题根本就不在这些，

老师的禀性只是谦抑。

6660　自从那尊长无故走失，

老师都不知该如何克制，

从耳根一直熏黑到鼻孔，

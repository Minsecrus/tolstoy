# 第五编 1500年以前诸孤立地区的世界

本编涉及两个基本问题：为什么研究世界史应从1500年这一年开始？为什么是西方人在15世纪后期和16世纪初叶做出的巨大发现和惊人探险中起了主要作用？前一问题将在第十八章中予以回答；后一问题是本编余下各章要讨论的主题。

人们往往想当然地认为，只有西方人才能做出那些改变人类生活道路、开创世界历史新纪元的富有历史意义的发现。这种观点是完全没有道理的，尤其是如果考虑到中东的穆斯林和东亚的中国人所具有的伟大的航海传统的话。那么，为什么西方会率先从事至今仍可感到其影响的海外事业呢？第十八章、十九章将分析伊斯兰世界和儒家世界的传统社会，第二十、二十一章将考察与此形成对照的西方社会的动力来源。

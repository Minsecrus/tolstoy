# 历史对今天的启示：历史与关于历史的流行理论

1492年，哥伦布登上了圣萨尔瓦多岛——巴哈马群岛中的一座小岛。他认为自己到了东南亚的东印度群岛，故将当地居民称为印第安人——这个名称一直沿用到今天。哥伦布去世后不久，巴尔博亚于1513年到达了太平洋，麦哲伦的探险队于1519年至1522年完成了环球航行，此时哥伦布的假设被证明是错误的。

人们认为美洲是一个“新世界”，这导致了对印第安人起源的思索。他们要么起源于美洲大陆，要么就是从其他地方迁徙到那里。在美洲大陆单独起源的观点被认为是不可思议的异端邪说，因为那将意味着存在二元的创造——在大西洋彼岸的伊甸园里也有一对亚当和夏娃——一个与《旧约全书》的教义完全冲突的信条。因此，人们一致赞同，印第安人一定是亚当和夏娃的后代。现在，又产生一个新的问题：这些后代是怎样从东半球移居到美洲大陆的呢？有关这个问题历来争论不休，在过去4个世纪里差不多提出了几十种理论，而且，直到今天仍然有新的理论在不断提出。

绝大多数理论都是错误的，因为它们更多地依据信念，而不是理性。各种不同的流行理论盛行一时便一闪而过，每一种理论都反映了其所在时代的知识和偏见。最早的一种理论是犹太失落部落说，因为在当时，《旧约全书》所记载的古希伯来人种学资料几乎是“原始”生活方式的唯一已知样式。因此，早期的理论家确信，印第安人是希伯来部落的后裔，这些希伯来部落在公元前721年为亚述王所征服并从撒马利亚被带走。有些失落部落说的支持者认为，这些希伯来人是穿越神秘的亚特兰蒂斯大陆到达美洲大陆的，但大多数人则认为，有一条穿过波斯和中国到达白令海峡的道路。

18世纪，欧洲人对古代地中海沿岸诸民族尤其是腓尼基人的成就印象深刻；腓尼基人以其航海技术而闻名。人们认为，腓尼基人曾绕过非洲的好望角，也曾越过大西洋到达美洲。然而，由于19世纪在埃及的考古发现，这个国家开始被认为是美洲印第安文明的发源地。中美洲存在着与埃及金字塔非常相像的金字塔，所以，这一理论被广泛认为是真的。其他许多关于美洲印第安人起源的流行理论时兴时灭。这样，我们的“印第安佬”便被追溯到希腊人、特洛伊人、罗马人、伊特拉斯坎人、塞西亚人、蒙古人、中国佛教徒、曼丁哥人或其他非洲人、早期爱尔兰人、威尔士人、北欧人、巴斯克人、葡萄牙人、法国人、西班牙人甚至穆和亚特兰蒂斯这两个“消失的大陆”的幸存者那里，这两个大陆据说1.1万年以前就分别沉没于太平洋和大西洋底。

所有这些提法都被证明是不能成立的，或至少是值得怀疑的，当然有一个例外：10世纪后期斯堪的纳维亚人在纽芬兰的定居得到了科学的确定。为什么这么多人相信或仍在相信这么多毫无根据的理论？一个原因是，他们错误地认为相同的习俗意味着共同的起源。实际情况恰恰相反，人们可以到任何一所重点大学的人类关系领域的档案部门，去要一份世界上所有具有某些特定习俗如表亲联姻的民族的目录。你将很快从全世界民族中得到几十个具有相同婚姻习俗的例子，而他们的这种婚姻习俗不可能来自同一个源头。但是，早期的作者不熟悉现代人类学，所以很自然地认为，在遥远的过去，相同习俗之间存在着历史的联系。

同样，经仔细检查，表面上相似的制度或结构也被证明是完全不同的。人们在埃及和中美洲都发现了金字塔，但是，中美洲的金字塔主要是宗教仪式的中心，而埃及的金字塔是巨大的陵墓。同样重要的是这一事实：最新的发掘工作揭示了中美洲的金字塔几千年来不断演进的过程。这一长期的发展阶段推翻了金字塔的建造技术是从大西洋彼岸完全成熟地移植过来的理论。同样，在加利福尼亚被称为“尤基”（Yuki）的土著语言中，ko这个词意指“go”（去），kom意为“come”（来），然而，没有人根据这个例子断定，尤基语和英语在历史上存在联系。

即使少数古代东半球的航海者确曾到达过美洲大陆，他们的文化将立即统治美洲大陆的习俗这种提法也是值得怀疑的。那些认为小群希伯来人、希腊人、罗马人、腓尼基人或其他民族可能到达过美洲大陆、并在广大地区的土著居民中传播他们的文化的人，应该考虑一下18个西班牙人（16个男人和2个女人）的经历，他们在科尔特斯到达那里6年前在尤卡坦海岸因为船只失事而流落当地。除两个男人沦为当地酋长的奴隶外，所有的人都被用来献祭并按仪式被吃掉。幸存者中的一个人完全变成了土著，他戴着精巧的鼻塞和其所皈依部落的耳环，拒绝放弃新的生活去重返科尔特斯的队伍。同样，我们知道维京人的确曾在纽芬兰登陆，但他们却因当地印第安人的敌对行为而被迫放弃了建立殖民地的努力。这样，在现代连发步枪和机枪出现之前，小的登陆群体要么被全部消灭，要么被当地的文化同化。

这就是1968年在新墨西哥州的圣菲召开的一次学术专题讨论会得出如下结论的一些原因；该结论是：“到目前为止——除了维京人的接触（即在纽芬兰）外——在哥伦布之前，还没有从一个半球传播到另一个半球的人工制品的确凿考古发现。”同样，这次讨论会还一致认为：“没有确切的迹象表明，在哥伦布之前人类曾越过大洋把任何一种植物或动物从东半球引入美洲大陆，或者从美洲大陆引入东半球。但这绝不是说，这种情况不可能发生过。”<sup class="footnote-ref" id="note-ref-1-1"><a href="#note-1" aria-label="查看本页注释 1">[1]</a></sup>

这类讨论对研究历史的人来说，有什么意义呢？首先，它提出了人类文明是如何发展的这一基本问题——人类文明是从一个或几个早期的中心向外扩散，还是在世界各个不同的地区独立创造。这个问题不仅涉及美洲印第安文明的起源，而且牵涉全球诸文明的起源。文明是从中东向西北欧、北非、南亚和东亚传播，还是在这些不同的地区独自发展呢？扩散传播论者和独立创造论者长期以来一直争论不休。

我们正渐渐地认识到，这个问题不是一个非此即彼的问题，而是一个扩散传播和独立创造两者的不同程度的问题。这种不同程度不是由基于预先概念的浪漫推测决定，而是由细致研究和对结果的客观评价决定。考古学家对人类史前史的发掘越多，他们越能认识到人类的所有分支对其环境的反应都是具有创造力的。他们的反应和成就的性质及程度极不相同，这种不同取决于他们各自的历史和地理背景，尤其是如前所述的他们受外界刺激的影响程度。

对历史研究者来说，同样重要的是这一事实：许多门外汉仍然抱有这种幻想，即各种欧洲人、亚洲人或非洲人高举文明的火炬，在前哥伦布时代的美洲大陆的海岸登陆。事实是，今天的人类如在最初的旧石器时代一样，沉迷于对神秘事物的崇拜。他们墨守虚幻而简单化的解释，甚至在这种解释与已知的事实不一致时仍是如此。我们的食物采集时代的祖先迷信他们的图腾和巫师即巫医。现代人对于飞碟、占八卦、纸牌算命以及占星术具有类似的迷信。本书的读者将认识到洛杉矶的加利福尼亚大学天文学教授乔治·埃布尔所作的下述报告的重要性：

我曾对选我的天文学概论课程的全体大学生进行民意测验，发现大约三分之一的人对占星术感兴趣，并相信占星术。通过与国内其他地区的同行们的讨论，我了解到这些地区的比例大致相同，而且它可能相当准确地反映出相信占星术的美国人的比例。据估计，美国大约有5000多名占星学家在这个领域谋生，有1200多家日报开辟了占星术的专栏。<sup class="footnote-ref" id="note-ref-2-1"><a href="#note-2" aria-label="查看本页注释 2">[2]</a></sup>

埃布尔教授的报告作于1975年。那年以后的民意测验表明，相信占星术的人在不断增加。1980年至1985年间，美国青少年相信占星术人数的比例从40%上升到55%。<sup class="footnote-ref" id="note-ref-3-1"><a href="#note-3" aria-label="查看本页注释 3">[3]</a></sup>鉴于从16世纪现代天文学发轫之时起，相信占星术的人就日渐减少这一事实，今日占星术的卷土重来，确实值得人们予以特别的关注。

与此相似的是，《新闻周刊》1996年做过一次民意测验，结果显示48%的美国人相信UFO（不明飞行物）真的存在，29%的人认为人类已与外星人有过接触，而另有48%的人相信，政府有意掩盖了人类与外星人接触的信息。更为特别的是，有的占星师声称他们看见猫王在天王星上啃炸鸡。在这方面，美国人并非与众不同。在法国，1995年有近 5万名纳税人宣称自己依靠从事占星师、巫医、巫师或类似的职业获取收入。与此形成鲜明对照的是，法国当时只有3.6万名天主教牧师和6000名精神科医生。<sup class="footnote-ref" id="note-ref-4-1"><a href="#note-4" aria-label="查看本页注释 4">[4]</a></sup>

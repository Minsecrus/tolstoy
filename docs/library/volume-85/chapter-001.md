# 序言

<span class="original-page-marker" id="page-vii" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 vii 页</span>

亚太战争已经结束七十多年了。然而，时至今日，这场战争仍然困扰着日本与其两个最重要的邻国——韩国和中国——之间的关系。这三个国家究竟能否解决有关如何纪念战争的争议？如果能够，又应当如何解决？正是这个问题促使我写下这本书。

我没有经历过战争，在成长过程中也没有听到过关于战争的亲历讲述。我的父亲出生于战后，战争结束时，我的母亲也还是个小孩子。他们都没有战争的记忆。不过，他们曾经告诉我，我的祖父是一名木匠，曾被征召为技术人员，支援驻满洲的日军；而我的外祖父是一名小学教师，免于服兵役。这则关于祖父和外祖父的转述，是我个人与这场战争之间唯一的联系，尽管这种联系是间接的。

然而，在日本长大的过程中，无论在家里还是在学校，我都接触到了许多有关战争的绘本和电影。我至今仍记得，我通过《愤怒的地藏》（Okorijizō）和《赤脚阿元》（Hadashi no Gen）了解了广岛和长崎的原子弹轰炸；通过《玻璃兔》（Garasu no usage）和《萤火虫之墓》（Hotaru no haka）了解了东京及其他大城市遭到的轰炸；通过《姬百合之塔》（Himeyuri no tō）和《对马丸》（Tsushima Maru）了解了冲绳战役。这些书籍和电影给我留下了深刻的印象，因为其中很多描绘了与我同龄的孩子所遭受的苦难。可是，战争在我心中仍像是遥远的过去，因为战后日本的经济繁荣为我提供了庇护。

直到2001年秋天，我才对战争，或者更准确地说，对战争的纪念产生了强烈的兴趣。当时，我刚刚进入密歇根大学的社会学博士项目，“9·11”恐怖袭击就发生了。袭击的非人道性质，以及美国政府的强硬回应，都令我震惊。美国政府似乎并不在意对阿富汗和伊拉克平民造成的附带伤害。我在这些平民与广岛、长崎的平民之间看到了相似之处：他们都是一种美国民族主义的受害者，这种民族主义不承认“敌国”人民的人性。

<span class="original-page-marker" id="page-viii" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 viii 页</span>

于是，我决定考察日本民众如何应对原子弹轰炸，以此撰写一部对美国民族主义的历史批判。

不过，我很快就意识到自己的天真。许多日本公民纪念原子弹轰炸，是为了以民族主义的方式表达日本的受害者身份，同时轻忽日本军队给亚太地区人民造成的苦难。的确，21世纪初，美国政府在阿富汗和伊拉克发动战争之时，日本首相小泉纯一郎也反复参拜日本民族主义的神圣场所——靖国神社，在韩国和中国引发了强烈抗议。新历史教科书编纂会推广的民族主义历史教科书，又进一步加剧了争议；这部教科书将日本过去的侵略美化为反抗西方帝国主义列强的英勇自卫行动。因此，我对日本民族主义和美国民族主义都感到失望。

然而，随着研究的深入，我发现原爆受害者曾经批判日本对亚太战争的纪念中的民族主义，并且带头推动纪念日本战时暴行受害者的工作。他们能够这样做，是因为他们的受害意识从根本上说具有世界主义性质：他们承认战争受害者的苦难，而不问其国籍。这使我开始深入探究，日本的其他行动者，包括但不限于活动人士、政治家、历史学家和历史教师，如何尝试纪念外国战争受害者。具体而言，这些考察使我得以辨识日本、韩国和中国之间跨国互动的历史，以及这些互动如何在不同的时期将世界主义注入日本的官方纪念。这种跨国视角也帮助我探究，日本的民族主义纪念如何与韩国、中国，乃至美国的民族主义纪念相互联系。

于是，我开始理解，多种相互纠缠的因素如何使日本与韩国、中国之间的争议显得无法解决：民族主义与世界主义之间的矛盾，纪念与历史书写之间的张力，日本既是加害者又是受害者的双重身份，这一地区民族主义的负面反馈循环，等等。当然，我知道，关于日本与韩国、中国之间争议的著作已经有很多，但我仍决定撰写这本书，因为我觉得，个人经历和学术探索的历程能够为我提供一个独特的视角。最重要的是，我迫切希望与东亚及其他地区的人们——学者、教育工作者、学生，以及关心此事的公民——分享我的研究和思考成果。

<span class="original-page-marker" id="page-ix" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 ix 页</span>

借助这些成果，我们可以立足于战争结束七十周年这个时间点，重新审视争议的原因，探索解决的可能性。

我之所以能够完成这本书，完全是因为在这一过程中得到了许多导师、同事和机构的慷慨支持。首先，我要感谢我在国际基督教大学和哈弗福德学院的导师，分别是 Azumi Kōya 和 Mark Gould。在 Kōya 的鼓励下，我决定到美国攻读研究生学位。当我作为交换学生在哈弗福德学院学习时，Mark 也为我打下了出色的社会理论基础，而这些理论基础至今仍帮助我分析当代世界的复杂现实。

在密歇根大学，我在三位历史社会学和政治社会学学者 Julia Adams、Michael Kennedy 和 Howard Kimeldorf 的指导下，开始思考并撰写有关战争纪念政治的研究。他们对我的理论取向、方法论取向和专业取向产生了决定性的影响。密歇根大学确实为我提供了适合我的研究生教育：跨学科，而且具有国际性。政治学者 John Campbell 与我分享了他对日本政治的详尽知识；Ram Mahalingam 则将我引入文化心理学，这对于理解纪念同时具有集体性与个体性的特点至关重要。我要感谢 Julia、Michael、Howard、John 和 Ram 对我研究的指导。我也感谢密歇根大学，以及安德鲁·W. 梅隆基金会／美国学术团体理事会，为我提供奖学金和其他资源，使我得以完成研究生阶段的学习。

在夏威夷大学马诺阿分校担任助理教授期间，我于2011—2012年获得了美国社会科学研究理事会和日本学术振兴会提供的博士后研究资助。这项资助使我能够在东京大学社会科学研究所度过一年，收集这本书所需的一手和二手资料，并完成书稿初稿。我感谢当时担任研究所所长的末广昭和石田浩，以及 Thomas Blackwood 和田边俊介，他们接纳我作为访问研究员。我还要感谢当时在东京大学攻读博士学位的 Aoki Yoshiyuki，他将韩国报纸的文章译成了日文。

此外，我有幸在2013—2014年获得哈佛大学美日关系研究项目的博士后研究资助。

<span class="original-page-marker" id="page-x" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 x 页</span>

这项资助给了我整理书稿、准备投稿所需的时间和资源。在哈佛，我有幸结识了两位年轻的历史学家 Mimaki Seiko 和 Tim Yang。我感谢他们通读整部书稿，并帮助我澄清自己的论点。我也要感谢 Thomas Berger、Alexis Dudden、Fujihira Shinju 和 Susan Pharr，他们慷慨地花了一个下午，参加对书稿的深入讨论，给我提出了许多富有见地的意见。

在哈佛担任博士后研究员期间，我还有机会参加莫琳与迈克·曼斯菲尔德基金会组织的下一代日本领导力项目。参加这一项目，使我得以仔细思考自己论点的政策含义。Victor Cha、Chris Nelson、Sheila Smith 和 Scott Snyder 参与的讨论，尤其拓宽了我的视野，使我能够将历史问题与东亚国际关系的其他议题和维度联系起来考虑。

此外，在撰写本书的不同阶段，我还收到了 David Johnson、David Leheny、Ivo Plsek 和 Franziska Seraphim 的意见。他们的意见要求很高，但对于完善我的论点极其有用。我尤其感谢 David Johnson；在夏威夷大学马诺阿分校，他和 Hagen Koo 都是非常出色的导师与同事。我也要感谢各位编辑的慷慨支持：Susan Campbell 和 Kim Greenwell；夏威夷大学出版社的 Pamela Kelley；Westchester Publishing Services 的 Michael Bohrer-Clancy；以及夏威夷大学出版社两位匿名审稿人提供的有益反馈。他们的意见与编辑指导发挥了很大作用。

最后，我要感谢我的父母 Saito Hideo 和 Fumiyo，以及我的妻子 Miki。父母不仅在我小时候让我接触到许多有关亚太战争的绘本和电影，也支持了我出国留学的决定。当我完成书稿最终版本时，妻子还教会了我一条重要的道理：只有我们自己保持和平，我们才能期待一个和平的世界，而践行和平要从日常生活开始。

因此，我将本书献给东亚及世界其他地方所有希望让世界变得更加和平的人们。

# 第一章 跨国分隔，1945—1964年

<span class="original-page-marker" id="page-20" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 20 页</span>

历史问题所围绕的亚太战争，并不是一场边界清楚、单一的事件。相反，它是从日本与中国之间一连串武装冲突中发展而来的：这些冲突始于1931年9月的九一八事变，最终导致1937年7月第二次中日战争爆发。随后，日本于1941年12月与美国及其他盟国开战，并迅速向太平洋和东南亚推进。然而，战争形势在1942年6月的中途岛战役中开始逆转，日本愈来愈难以抵挡盟国的攻势。到1945年6月底，盟国已经在冲绳群岛击败日军；7月26日发表的《波茨坦公告》要求日本政府“立即宣布所有日本武装部队无条件投降”。<sup class="footnote-ref" id="note-ref-ch1-1"><a href="./chapter-011#note-ch1-1" aria-label="查看原书注释 1">[1]</a></sup> 日本政府拒绝了这一最后通牒，盟国则以进一步的军事行动回应。美国分别于8月6日和9日在广岛、长崎投下原子弹。8月8日，苏联也撕毁了《苏日中立条约》，向满洲国、千岛群岛和南萨哈林发动进攻。这些军事行动终于促使日本政府于8月14日接受《波茨坦公告》。次日，裕仁天皇通过广播宣读《终战诏书》，正式向盟国投降。<sup class="footnote-ref" id="note-ref-ch1-2"><a href="./chapter-011#note-ch1-2" aria-label="查看原书注释 2">[2]</a></sup>

日本政府随即命令文官和军官销毁机密文件。陆军省最彻底地执行了这一命令。他们不仅销毁了省内的机密文件，还销毁了地方政府层面的陆军相关文件。

<span class="original-page-marker" id="page-21" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 21 页</span>

内务省和外务省也销毁了大量机密文件。<sup class="footnote-ref" id="note-ref-ch1-3"><a href="./chapter-011#note-ch1-3" aria-label="查看原书注释 3">[3]</a></sup> 销毁战争相关文件的行动一直持续到8月28日盟军抵达厚木海军航空基地为止。

盟军于9月8日占领东京后，盟军最高司令官道格拉斯·麦克阿瑟下令，以破坏和平罪逮捕43名日本文职和军事领导人；这一罪名通常被称为甲级战争罪。盟国还逮捕了涉嫌常规战争罪和危害人类罪的人，这两类罪分别称为乙级和丙级战争罪。占领期间，超过1万名日本人因这三类战争罪而被逮捕或起诉。<sup class="footnote-ref" id="note-ref-ch1-4"><a href="./chapter-011#note-ch1-4" aria-label="查看原书注释 4">[4]</a></sup> 1946年1月，盟军最高司令部进一步颁布《国际军事法庭宪章》，为起诉甲级战犯嫌疑人作准备。

与此同时，盟军最高司令部实施了使日本非军事化和民主化的政策。10月，它释放了遭日本政府监禁的共产党人和其他活动人士，清除了学校中具有军国主义思想的教师，并鼓励妇女参与政治及成立自愿团体。12月，它终止了政府对神道教的支持，命令日本政府暂停学校课程中的修身、日本历史和地理三门科目；这些科目曾在向日本国民灌输民族主义的过程中发挥核心作用。<sup class="footnote-ref" id="note-ref-ch1-5"><a href="./chapter-011#note-ch1-5" aria-label="查看原书注释 5">[5]</a></sup> 盟军最高司令部还从公职、企业和大学中清除了战犯嫌疑人、军国主义者以及曾与战时政府合作的人。<sup class="footnote-ref" id="note-ref-ch1-6"><a href="./chapter-011#note-ch1-6" aria-label="查看原书注释 6">[6]</a></sup>

同时，盟军最高司令部要求日本政府制定新宪法。由于币原喜重郎首相领导的日本政府不愿对战前的《大日本帝国宪法》作重大改变，盟军最高司令部进行了干预，于1946年2月把自己拟定的草案交给日本政府。日本政府以盟军最高司令部的版本为依据起草新宪法，并于4月向公众公布。新宪法草案与战前宪法相比包含许多重大改变，例如剥夺天皇的政治权力，保障基本人权和两性平等，并放弃作为主权权利的战争。在占领之下这些深刻变革正在进行之际，远东国际军事法庭——亦称东京审判——于1946年5月3日开庭。

<span class="original-page-marker" id="page-22" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 22 页</span>

## 东京审判与逆转路线

东京审判由来自11个盟国的11名法官组成：英国、英属印度、美国、中华民国、法国、荷兰、澳大利亚、新西兰、加拿大、菲律宾和苏联。这11个国家也分别派出了一名检察官及其辅助团队。受审的28名甲级战犯嫌疑人包括：曾于1941年12月决定对美开战的前首相东条英机；参与1937年7月卢沟桥事变的陆军将领板垣征四郎；以及在1937年12月指挥进攻南京的另一名陆军将领松井石根。这三人与其余25名甲级战犯嫌疑人由一个日本和美国律师组成的团队辩护。<sup class="footnote-ref" id="note-ref-ch1-7"><a href="./chapter-011#note-ch1-7" aria-label="查看原书注释 7">[7]</a></sup>

东京审判的焦点之一是破坏和平罪，即甲级战争罪；其定义为计划、共谋和实施侵略战争的行为。尽管纽伦堡审判已经认定侵略战争是国际法之下可以惩处的犯罪，东京审判的11名法官在这一问题上仍有分歧。<sup class="footnote-ref" id="note-ref-ch1-8"><a href="./chapter-011#note-ch1-8" aria-label="查看原书注释 8">[8]</a></sup> 不过，在审判临近结束时，澳大利亚、英国、加拿大、新西兰、中华民国、苏联、菲律宾和美国的法官形成了多数意见，接受纽伦堡审判的立场；来自英属印度、法国和荷兰的三名法官则持异议。<sup class="footnote-ref" id="note-ref-ch1-9"><a href="./chapter-011#note-ch1-9" aria-label="查看原书注释 9">[9]</a></sup>

日本被告对所有指控均不认罪。东条英机的首席辩护律师清濑一郎把亚太战争解释为自卫行为。清濑认为，中国军队应为卢沟桥事变负责，日本之所以向盟国开战，是因为“日本别无选择，只能行使自卫权，仅仅是为了在这种不可能维持的处境中生存下去”。<sup class="footnote-ref" id="note-ref-ch1-10"><a href="./chapter-011#note-ch1-10" aria-label="查看原书注释 10">[10]</a></sup> 东条也把战争辩护为自卫行为，声称自己在法律和道德上都作出了正确决定。<sup class="footnote-ref" id="note-ref-ch1-11"><a href="./chapter-011#note-ch1-11" aria-label="查看原书注释 11">[11]</a></sup>

除破坏和平罪外，东京审判还起诉了违反战争公约的行为，例如虐待战俘，以及危害人类罪，例如杀害平民。检方提交了一系列证言，涉及日本在战争期间针对亚洲各地平民实施的暴行，如日军在新加坡处决民众，以及在荷属东印度强迫当地妇女充当军队的“慰安妇”。<sup class="footnote-ref" id="note-ref-ch1-12"><a href="./chapter-011#note-ch1-12" aria-label="查看原书注释 12">[12]</a></sup> 在这些针对亚洲平民的暴行中，南京大屠杀是法庭调查最为详尽的事件，因为中华民国的检察官提交了大量证据和证言。

<span class="original-page-marker" id="page-23" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 23 页</span>

虽然由于政府的审查，日本民众在战争期间并不知道这场屠杀，但证据和证言如此充分，被告及其辩护律师只能提出简短的反驳。<sup class="footnote-ref" id="note-ref-ch1-13"><a href="./chapter-011#note-ch1-13" aria-label="查看原书注释 13">[13]</a></sup>

1948年11月4日，澳大利亚籍审判长威廉·韦布公布了长达1,445页的判决书。东京判决认定日本政府领导人曾共谋侵略，驳回了日本只是行使自卫权的说法。判决也认定了日本针对盟国所犯的常规战争罪。<sup class="footnote-ref" id="note-ref-ch1-14"><a href="./chapter-011#note-ch1-14" aria-label="查看原书注释 14">[14]</a></sup> 包括东条在内的7名被告被判处死刑。16人被判处终身监禁，其中包括后来担任法务大臣的贺屋兴宣。包括后来担任外务大臣的重光葵在内的2名被告被判处有期徒刑。另有2名被告在审判期间死亡，第3名则因精神疾病而被排除于审判之外。除多数意见外，菲律宾法官德尔芬·哈拉尼拉还提交了单独意见，批评量刑过轻。威廉·韦布虽然同意多数意见关于起诉破坏和平罪的法律依据，却也在自己的单独意见中暗示天皇负有战争责任。印度法官拉达宾诺德·帕尔、法国法官亨利·贝尔纳以及荷兰法官 B. V. A. Röling 提交了不同意见。帕尔否认起诉破坏和平罪的法律依据，而贝尔纳和 Röling 则接受这一依据，却不赞同多数意见对它的论证。贝尔纳还质疑法庭不起诉裕仁天皇的决定。<sup class="footnote-ref" id="note-ref-ch1-15"><a href="./chapter-011#note-ch1-15" aria-label="查看原书注释 15">[15]</a></sup>

东京审判虽然揭露了日本的战争罪，却没有起诉所有甲级战犯嫌疑人。盟军最高司令部起初曾计划进行多轮国际军事审判。然而，这场审判暴露了严重的组织与后勤问题，以及盟国之间的分歧。<sup class="footnote-ref" id="note-ref-ch1-16"><a href="./chapter-011#note-ch1-16" aria-label="查看原书注释 16">[16]</a></sup> 到20世纪40年代后期，美国及其西方盟友与苏联及其卫星国之间的冷战也愈发激烈。因此，盟军最高司令部把政策重点从彻底的非军事化和民主化转向迅速重建和重新武装日本，使其成为对抗共产主义的盟友。作为这一“逆转路线”的一部分，在7名甲级战犯被处决后的次日，即1948年12月24日，盟军最高司令部从巢鸭监狱释放了19名甲级战犯嫌疑人，其中包括后来出任首相的岸信介。

<span class="original-page-marker" id="page-24" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 24 页</span>

此外，盟军最高司令部只提供审判记录的缩微胶卷，而且仅可在美国国会图书馆等少数指定地点查阅。这与纽伦堡审判形成鲜明对照，后者的庭审记录和判决书在德国出版了42卷。

1950年6月朝鲜战争爆发后，盟军最高司令部政策的逆转路线进一步加快。盟军最高司令部要求日本政府于1950年8月建立警察预备队，以便在美军调往朝鲜半岛之时，日本能够进行自卫。在朝鲜战争酝酿期间，盟军最高司令部还从公职、报社和企业中清除共产党人，并停止了共产党报纸《赤旗报》的出版。此外，1951年6月，盟军最高司令部开始允许前战犯嫌疑人、军国主义者及曾经的合作者重返公职。在逆转路线的背景下，吉田茂政府于1951年9月8日签署《旧金山和约》，正式接受东京判决，作为恢复日本独立的条件。

## 对东京审判的否定、接受与批判

在国内，吉田政府否定东京判决，并以此作为释放战犯的正当依据。正如法务大臣大桥武夫所说：“远东国际军事法庭及盟国的其他法庭并不是依据日本国内法开展审判的。因此，法庭和国际法判定为战争罪的那些行为，就日本法律而言，绝不能视为犯罪。”<sup class="footnote-ref" id="note-ref-ch1-17"><a href="./chapter-011#note-ch1-17" aria-label="查看原书注释 17">[17]</a></sup> 释放战犯获得了日本民众的广泛支持。曾被列为战犯嫌疑人的人于1952年5月成立了战争受刑者世话会，游说政府建议尽快释放战犯。日本红十字会、宗教组织和其他非政府组织也支持释放战犯。1953年11月举行要求释放巢鸭监狱全部战犯的全国大会时，支持战犯的签名已达约3,000万份。<sup class="footnote-ref" id="note-ref-ch1-18"><a href="./chapter-011#note-ch1-18" aria-label="查看原书注释 18">[18]</a></sup>

恢复独立后，吉田政府首先结束了将战犯、军国主义者和合作者逐出公职的清洗，使鸠山一郎、岸信介、重光葵等许多人得以重返具有影响力的政治职位。

<span class="original-page-marker" id="page-25" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 25 页</span>

国会还在1952年6月至1953年8月间通过了三项决议，建议对战犯予以赦免、减刑和假释。<sup class="footnote-ref" id="note-ref-ch1-19"><a href="./chapter-011#note-ch1-19" aria-label="查看原书注释 19">[19]</a></sup> 保守派政治人物最为积极地支持这些决议。例如，执政的自由党议员田子一民主张释放战犯，理由是东京判决“遭到印度帕尔法官有说服力的反驳。所有辩护律师也都认为法庭不公正……注定要在战争的错误之上再添更多错误”。<sup class="footnote-ref" id="note-ref-ch1-20"><a href="./chapter-011#note-ch1-20" aria-label="查看原书注释 20">[20]</a></sup> 重光葵领导的改进党议员一松定吉也认为，战犯实际上是“爱国者”，政府应该拯救“那些为我国牺牲生命、浴血奋战，却因为日本战败而背上战犯恶名的人”。<sup class="footnote-ref" id="note-ref-ch1-21"><a href="./chapter-011#note-ch1-21" aria-label="查看原书注释 21">[21]</a></sup>

1954年12月鸠山一郎出任首相后，保守派对东京审判的攻击愈演愈烈。鸠山认为战后宪法是盟国强加的，不仅想修改它，还任命了若干前战犯和曾遭公职追放的人担任大臣，例如重光葵出任外务大臣兼副首相，正力松太郎出任原子能委员会委员长。这些政治人物在亚太战争期间确实曾批评军方领导人，但他们仍然否定东京审判。<sup class="footnote-ref" id="note-ref-ch1-22"><a href="./chapter-011#note-ch1-22" aria-label="查看原书注释 22">[22]</a></sup> 重光尤其反复公开批评东京审判，因为他“坚定地相信，那些被称为‘战犯’的人，其实是战争的受害者”。<sup class="footnote-ref" id="note-ref-ch1-23"><a href="./chapter-011#note-ch1-23" aria-label="查看原书注释 23">[23]</a></sup> “战犯”是“胜利者单方面捏造的东西”，而“大东亚战争是否确实构成国际法意义上的侵略战争”，仍有待确定。<sup class="footnote-ref" id="note-ref-ch1-24"><a href="./chapter-011#note-ch1-24" aria-label="查看原书注释 24">[24]</a></sup> 此外，重光认为这场战争可以辩护，不仅因为它是自卫行为，也因为它使亚洲国家受益：“亚洲国家在第二次世界大战后获得了自决权并取得独立，我对此感到十分欣喜。对于自己参加的这场战争所产生的这一结果，日本应该感到满意。”<sup class="footnote-ref" id="note-ref-ch1-25"><a href="./chapter-011#note-ch1-25" aria-label="查看原书注释 25">[25]</a></sup> 因此，虽然日本政府为恢复独立而接受了东京判决，最公开地谴责这一判决的却正是政府中的政治人物。历史学家吉田裕把这种面向国际和国内受众采用不同说辞的矛盾称为“双重标准”；在此后数十年中，它将界定政府的纪念立场。<sup class="footnote-ref" id="note-ref-ch1-26"><a href="./chapter-011#note-ch1-26" aria-label="查看原书注释 26">[26]</a></sup>

与此相反，日本共产党成员积极纪念外国受害者。共产党人在亚太战争之前就反对日本的帝国主义扩张，因此许多人遭到酷刑折磨致死或被监禁。

<span class="original-page-marker" id="page-26" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 26 页</span>

所以，日本共产党成员认为，为了防止战后日本退回战前状态，大力批判日本的战争罪行至关重要。他们也是当时日本政治人物中最具国际取向的一群，因为他们与其他共产主义国家保持团结，其中包括曾深受日本侵略之害的中华人民共和国。例如，在1952年4月的国会会议上，日本共产党议员加藤充援引东京审判所揭示的日本战争罪行的具体细节，表示反对释放战犯：

> 1937年12月在南京，即使战斗已经结束，日本军队仍在松井石根的指挥下，以一切可以想象的暴行杀害了大约95,000名中国市民、妇女和儿童：枪决、斩首、割舌、烧死、挖眼、殴打和踢打致死、个别强奸和集体强奸、奸尸，等等……日本帝国主义者杀害了1,000万中国人、100多万菲律宾人，并在越南、马来亚、印度尼西亚、缅甸、新几内亚及其他地方实施了各种暴行。<sup class="footnote-ref" id="note-ref-ch1-27"><a href="./chapter-011#note-ch1-27" aria-label="查看原书注释 27">[27]</a></sup>

在日本共产党看来，释放战犯等于遗忘日本的战争罪行、逃避战争责任。

日本共产党还反对签署《旧金山和约》，因为和约将中华人民共和国排除在签署国之外。日本共产党议员林百郎认为，没有中国参加的“和约”不会带来真正意义上的和平：“如果我们希望将日本重建为亚洲一个热爱和平、民主的国家，就应当向中国——这个遭我们伤害最为严重的国家——赎罪和道歉，并与中国人民建立友好关系。我相信，这是政府处理亚太战争遗产时最迫切的任务。”<sup class="footnote-ref" id="note-ref-ch1-28"><a href="./chapter-011#note-ch1-28" aria-label="查看原书注释 28">[28]</a></sup> 因而，完全接受东京判决的日本共产党成员强烈抗议保守派政府。

日本社会党是战后最大的反对党，它对释放战犯和东京审判的立场与日本共产党略有不同。代表日本社会党的 Taman Hirofumi 支持释放战犯，“考虑到战犯家属的困境……尤其是许多乙级和丙级战犯<span class="original-page-marker" id="page-27" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 27 页" title="原书第 27 页">原书第 27 页</span>已被证明是误判的”。<sup class="footnote-ref" id="note-ref-ch1-29"><a href="./chapter-011#note-ch1-29" aria-label="查看原书注释 29">[29]</a></sup> Taman 支持释放他们，并不是像保守派同僚那样否定东京审判，而是因为他同情那些遭到误判的日本士兵及其家属。在日本社会党看来，对遭误判者予以赦免、减刑或假释，并不意味着免除日本的战争罪行。正如另一位日本社会党议员大野幸一所说：“我们必须对自己犯下的错误，对亚洲人民实施的暴行，表达悔悟与悔恨”，这样的悔悟与悔恨是释放战犯的前提。<sup class="footnote-ref" id="note-ref-ch1-30"><a href="./chapter-011#note-ch1-30" aria-label="查看原书注释 30">[30]</a></sup>

与此同时，日本社会党对东京审判持批判立场。该党议员古屋贞雄认为，他绝不能接受仅仅起诉日本战争罪行的做法，尤其考虑到广岛和长崎的原子弹轰炸，那是“人类历史上最残暴的行为。既然这些暴行尚未受到起诉，我们日本人民就不能接受这样一个事实：因远没有那么残暴的行为而被起诉的乙级和丙级战犯仍遭囚禁”。<sup class="footnote-ref" id="note-ref-ch1-31"><a href="./chapter-011#note-ch1-31" aria-label="查看原书注释 31">[31]</a></sup> 另一位日本社会党议员青野武一甚至提出，应该由国际战争法庭起诉美国将军、军官和飞行员的“原子弹轰炸这一不人道行为”。<sup class="footnote-ref" id="note-ref-ch1-32"><a href="./chapter-011#note-ch1-32" aria-label="查看原书注释 32">[32]</a></sup> 在这方面，日本社会党不同于不加批判地接受东京判决的日本共产党。日本社会党接受判决，却明确认为这场审判存在严重缺陷，其中包括未对盟国适用同一套刑事司法标准。

但日本社会党成员的立场也与保守派政治人物不同。虽然他们批评东京审判不公正，却不像保守派那样否认日本的战争罪行。日本社会党成员没有因为审判未起诉盟国犯下的战争罪而彻底否定它，而是呼吁建立更加公正的国际法庭，对双方的战争罪行都进行起诉。因而，日本社会党处于保守派政治人物与日本共产党之间的中间地带。<sup class="footnote-ref" id="note-ref-ch1-33"><a href="./chapter-011#note-ch1-33" aria-label="查看原书注释 33">[33]</a></sup>

总的来说，1952年日本恢复独立后，围绕东京审判的辩论大致形成了对亚太战争的两种不同纪念立场。第一种居于支配地位的立场由保守派政治人物采取：他们接受民族主义纪念逻辑，拒绝记住遭日本侵略的外国受害者的苦难。相比之下，日本共产党和日本社会党等反对党采用世界主义逻辑，纪念遭受日本过去错误行为的外国受害者，尽管它们对东京审判采取了不同立场。

<span class="original-page-marker" id="page-28" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 28 页</span>

然而，这些世界主义纪念的倡导者人数少于保守派。后者抓住盟军最高司令部逆转路线之后的政治机会，获得了进入政府的渠道，并通过否定东京审判的有效性、将日本过去的侵略辩护为自卫行为，推动民族主义纪念。

## 对战争死者的民族主义纪念

除东京审判外，日本政治人物还辩论应如何救济那些在亚太战争期间服役于日本军队的士兵。战前日本的军队享有特权地位。明治政府早在1875年就设立了军人养老金，比为文官设立待遇较低的养老金早了9年。军人养老金也深深植根于民族主义逻辑，因为它在日语中被称作“恩给”，意为“赐予的恩惠”。为国家作出的牺牲——其最终中心是作为现人神和主权者的天皇——被界定为有价值，并且值得获得政府恩惠的行为。盟军最高司令部认为，军人养老金是助长战前日本军国主义的机制，因此把暂停这一制度作为推动日本社会非军事化的措施之一。<sup class="footnote-ref" id="note-ref-ch1-34"><a href="./chapter-011#note-ch1-34" aria-label="查看原书注释 34">[34]</a></sup>

军人养老金的停发，使伤残退伍军人和遗族陷入经济困境。遗族人数尤其庞大，因为战争期间约有230万名军人和军队文职人员死亡。为缓解日益恶化的经济处境，遗族先在各都道府县成立团体，继而于1947年11月在全国层面成立遗族厚生联盟。起初，盟军最高司令部因担心这一团体阻碍非军事化而迟疑是否批准其成立。但在规定三项条件后，它批准了该团体：会员应包括为公共利益牺牲生命的平民遗族；以互助为主要宗旨；并将政府官员、遭公职追放者和前军人排除在理事会之外。<sup class="footnote-ref" id="note-ref-ch1-35"><a href="./chapter-011#note-ch1-35" aria-label="查看原书注释 35">[35]</a></sup>

获得盟军最高司令部批准后，联盟开始游说政治人物和厚生省。国会两院于1949年5月作出回应，<span class="original-page-marker" id="page-29" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 29 页" title="原书第 29 页">原书第 29 页</span>通过决议，要求政府向遗族提供养老金、慰问金及社会福利救济。联盟还成功地使其会长长岛银藏于1950年6月当选参议院议员。<sup class="footnote-ref" id="note-ref-ch1-36"><a href="./chapter-011#note-ch1-36" aria-label="查看原书注释 36">[36]</a></sup> 1951年2月，联盟在东京举行首次全国大会，并通过决议宣布：“我们遗族是受苦最深的战争受害者。我们的亲人为国家执行任务而死。政府理应补偿遗族。”<sup class="footnote-ref" id="note-ref-ch1-37"><a href="./chapter-011#note-ch1-37" aria-label="查看原书注释 37">[37]</a></sup> 大会之后，联盟成员向吉田茂首相及两院议长递交请愿书，要求发放养老金和其他形式的救济。

作为回应，吉田政府于1952年3月提出《战伤病者战殁者遗族援护法案》。法案拟向退伍军人和遗族提供养老金及慰问金，但仅限于正式受雇于政府的人。执政的自由党议员大石武一解释了法案的精神：“无论战争胜负如何，政府向那些表现出最高程度爱国精神、为我国献出生命的人的遗族，以及伤残退伍军人提供保障，都是理所当然的。”<sup class="footnote-ref" id="note-ref-ch1-38"><a href="./chapter-011#note-ch1-38" aria-label="查看原书注释 38">[38]</a></sup> 换言之，法案旨在“向那些在战争期间为日本牺牲生命的人表达感谢与慰问”。<sup class="footnote-ref" id="note-ref-ch1-39"><a href="./chapter-011#note-ch1-39" aria-label="查看原书注释 39">[39]</a></sup> 这种以表彰为日本民族作出的牺牲来论证法案的方式，偏离了1949年的国会决议；那些决议曾批判性地探究政府对伤残退伍军人的责任，并强调遗族的反战情绪。<sup class="footnote-ref" id="note-ref-ch1-40"><a href="./chapter-011#note-ch1-40" aria-label="查看原书注释 40">[40]</a></sup>

日本社会党基于两点理由反对该法案。第一，它认为“援护”一词暗含政府的家长式作风，应以“补偿”取代；日语“补偿”中的“偿”字包含赎罪之意，从而明确把阵亡士兵、遗族和伤残退伍军人界定为日本政府发动战争的受害者。<sup class="footnote-ref" id="note-ref-ch1-41"><a href="./chapter-011#note-ch1-41" aria-label="查看原书注释 41">[41]</a></sup> 第二，日本社会党批评拟议养老金计划的范围。它认为，分配给伤残退伍军人和遗族福利的资金太少，仅占1952年预算的约2.6%。日本社会党议员冈良一援引西德的例子：该国1951年预算的24%用于补偿包括平民在内的战争受害者；他敦促吉田政府投入类似比例的经费。<sup class="footnote-ref" id="note-ref-ch1-42"><a href="./chapter-011#note-ch1-42" aria-label="查看原书注释 42">[42]</a></sup> 此外，日本社会党提议，养老金不应仅向阵亡士兵的遗族发放，还应包括在动员参加军事相关勤务时死亡的技术人员和学生的遗族。<sup class="footnote-ref" id="note-ref-ch1-43"><a href="./chapter-011#note-ch1-43" aria-label="查看原书注释 43">[43]</a></sup>

<span class="original-page-marker" id="page-30" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 30 页</span>

日本共产党提出了类似批评，而且比日本社会党更进一步，把法案与日本正在进行的重新武装联系起来。正如日本共产党议员神田浅野所说：“这项法案将范围限定为曾直接领取政府薪酬的军队人员，目的在于促进日本的重新武装。范围应扩大到所有战争受害者，至少应包括从前殖民地归国的人、船员、技术人员、被动员的学生、女子挺身队，以及在原子弹轰炸中失去家庭经济支柱的人。”<sup class="footnote-ref" id="note-ref-ch1-44"><a href="./chapter-011#note-ch1-44" aria-label="查看原书注释 44">[44]</a></sup> 她还质疑，为何朝鲜人等曾以日本国民身份被动员参加战争的前殖民地臣民，只因战后失去日本国籍，就被排除在法案范围之外。<sup class="footnote-ref" id="note-ref-ch1-45"><a href="./chapter-011#note-ch1-45" aria-label="查看原书注释 45">[45]</a></sup> 因而，反对党认为，军人和平民在内的所有战争受害者，都应获得补偿，因为他们都遭受了政府发动的错误战争之害。

吉田政府向反对党作出一项让步：即使不以“国家补偿”本身为依据，也要以“国家补偿的精神”为拟议法案的基础。反对党仍然反对，但吉田政府于1952年4月成功通过法案，随后又提交另一项法案，建议为职业军人——包括前甲级战犯——建立额外的养老金计划。具体而言，新法案拟恢复盟军最高司令部在占领期间暂停的军人养老金，并为职业军人和征召军人这两类军事相关人员建立两级养老金制度。日本社会党和日本共产党再次反对政府提案。日本社会党议员成濑幡治说：“政府应该以公平、合理的方式补偿所有战争受害者。事实上，普通市民遭受的苦难最深……职业军人并不是唯一的受害者……那些对战争负有责任的甲级战犯将领取养老金，而许多其他战争受害者却一无所得，我对此极难理解。”<sup class="footnote-ref" id="note-ref-ch1-46"><a href="./chapter-011#note-ch1-46" aria-label="查看原书注释 46">[46]</a></sup> 日本共产党议员岩间正男也批评拟议法案背后潜伏着“军国主义”的回归，他认为该法案“是由那些企图让日本人民忘记战争悲剧、再发动一场战争的人撰写的”。<sup class="footnote-ref" id="note-ref-ch1-47"><a href="./chapter-011#note-ch1-47" aria-label="查看原书注释 47">[47]</a></sup> 尽管遭到强烈反对，吉田政府仍于1953年8月通过了法案，并把领取养老金的资格扩大到被处决或在服刑期间死亡的战犯的遗族。<sup class="footnote-ref" id="note-ref-ch1-48"><a href="./chapter-011#note-ch1-48" aria-label="查看原书注释 48">[48]</a></sup>

在围绕战争相关救济的政治斗争中，遗族厚生联盟于1953年3月改组为日本遗族会，并开始比以前更明确地推动民族主义议程。

<span class="original-page-marker" id="page-31" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 31 页</span>

遗族会此前曾把宗旨表述为“努力建设和平的日本、防止战争、确立永久世界和平，从而为人类福祉作出贡献”，却从新的宗旨声明中删去了这些话。<sup class="footnote-ref" id="note-ref-ch1-49"><a href="./chapter-011#note-ch1-49" aria-label="查看原书注释 49">[49]</a></sup> 取而代之，遗族会将“显彰英灵”和“慰灵相关事业”界定为主要目标之一。<sup class="footnote-ref" id="note-ref-ch1-50"><a href="./chapter-011#note-ch1-50" aria-label="查看原书注释 50">[50]</a></sup> 因而，在成功为替国家献身的军事相关人员恢复养老金这一物质特权后，遗族会如今又寻求恢复军队战争死者的象征特权。为此，它开始努力恢复靖国神社的地位；靖国神社曾是战前日本民族主义纪念的中心。

在战前日本，国家所有的靖国神社依据神道教把阵亡士兵作为“英灵”供奉：神社是日本民族主义最为神圣的场所，为献身国家的牺牲赋予最终的宗教意义。它不仅具有民族主义性质，也具有军国主义性质，因为它表彰的是军人而非平民。神社的军国主义性质也体现在战前日本的管理结构中：陆海军将领作为神道教现人神裕仁天皇的代理人，掌管着神社。正因为靖国神社曾是战前日本民族主义和军国主义的宗教中心，盟军最高司令部于1945年12月取消了政府对靖国神社及其他神道教神社的支持。1947年5月生效的新宪法确认了这一政教分离原则。占领期间，首相和皇室成员也暂停参拜靖国神社。<sup class="footnote-ref" id="note-ref-ch1-51"><a href="./chapter-011#note-ch1-51" aria-label="查看原书注释 51">[51]</a></sup> 靖国神社因此被剥夺了战前日本赋予它的特殊地位。

然而，《旧金山和约》刚一签署，吉田茂就以首相身份参拜了神社。和约生效、日本正式恢复独立后，裕仁天皇也于1952年10月进行战后首次参拜，得到约3,000名遗族的欢呼。<sup class="footnote-ref" id="note-ref-ch1-52"><a href="./chapter-011#note-ch1-52" aria-label="查看原书注释 52">[52]</a></sup> 由于宪法规定政教分离，吉田政府没有试图恢复国家对靖国神社的支持，却为神社提供了特殊待遇。每年春秋两季神社举行祭祀英灵的例大祭时，政府会增开列车，并提供优惠票价，帮助遗族前往东京。

<span class="original-page-marker" id="page-32" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 32 页</span>

政府——尤其是厚生省——还提供阵亡士兵的姓名及死亡时间、地点，秘密协助靖国神社神职人员合祀战争死者。特别是新成立的自民党于1955年11月掌控政府之后，神社开始在更大程度上享有非正式的政府支持。例如，1956年4月，厚生省发布指令，保证向神社提供财政和事务上的支持，以查明阵亡士兵身份，并将其作为英灵合祀。<sup class="footnote-ref" id="note-ref-ch1-53"><a href="./chapter-011#note-ch1-53" aria-label="查看原书注释 53">[53]</a></sup>

厚生省积极支持靖国神社，是因为它主管引扬援护局，该局处理海外归国者、战犯、遗族和伤残退伍军人的相关问题。事实上，援护局的工作人员来自原陆军省和海军省。这些官僚中许多人曾在战前参与神社管理，他们迫切希望为神社提供支持，尽管只能以非正式方式进行。他们甚至主动敦促靖国神社神职人员合祀那些被控犯有乙级、丙级战争罪的人。此外，1959年3月，巢鸭监狱所有战犯服刑完毕后，厚生省向神社送交了已故乙级和丙级战犯的“祭神名票”。随后，靖国神社神职人员于1959年4月秘密合祀了346名乙级和丙级战犯。<sup class="footnote-ref" id="note-ref-ch1-54"><a href="./chapter-011#note-ch1-54" aria-label="查看原书注释 54">[54]</a></sup>

遗族也加大了恢复国家支持神社的努力。1956年3月，日本遗族会成立靖国神社国家护持小委员会。1959年至1960年间，遗族会收集了约300万份支持国家护持神社的签名，并游说6个都道府县议会和345个市町村议会，通过支持将神社重新国有化的决议。<sup class="footnote-ref" id="note-ref-ch1-55"><a href="./chapter-011#note-ch1-55" aria-label="查看原书注释 55">[55]</a></sup> 接着，1961年9月，遗族会向国会两院议长提交请愿书，要求他们立即设立政府委员会，研究恢复国家对神社的支持。<sup class="footnote-ref" id="note-ref-ch1-56"><a href="./chapter-011#note-ch1-56" aria-label="查看原书注释 56">[56]</a></sup>

通过这些游说活动，遗族会加强了与政府的联系。首先，吉田政府的前大臣高桥龙太郎成为遗族会首任会长，任期为1953年至1961年。其次，遗族会于1953年3月取得了使用政府财产的权利，即靖国神社附近那座战前专供职业军人使用的建筑。第二任会长安井诚一郎，任期为1961年至1962年，是自民党成员；第三任会长<span class="original-page-marker" id="page-33" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 33 页" title="原书第 33 页">原书第 33 页</span>贺屋兴宣，任期为1962年至1977年，同样是自民党成员，曾作为甲级战犯受到起诉，后来却在池田勇人政府担任法务大臣。此外，池田出任首相期间，政府于1964年4月恢复了向退伍军人授勋，以“向那些为国家牺牲宝贵生命的人表达由衷的感谢，并表彰他们的功绩”。<sup class="footnote-ref" id="note-ref-ch1-57"><a href="./chapter-011#note-ch1-57" aria-label="查看原书注释 57">[57]</a></sup> 接着，池田政府于1964年8月在靖国神社境内举行全国战殁者追悼仪式。同年，遗家族议员协会也通过决议，要求将神社重新国有化。<sup class="footnote-ref" id="note-ref-ch1-58"><a href="./chapter-011#note-ch1-58" aria-label="查看原书注释 58">[58]</a></sup>

日本遗族会在开展又一轮游说政治人物的签名运动——该运动于1964年累计获得600多万份签名——的同时，于1964年1月与靖国神社举行了首次联络会议，协调恢复国家护持神社的努力。<sup class="footnote-ref" id="note-ref-ch1-59"><a href="./chapter-011#note-ch1-59" aria-label="查看原书注释 59">[59]</a></sup> 会后，靖国神社神职人员向首相和两院议长递交了要求重新国有化的请愿书。因此，从20世纪50年代初到60年代中期，自民党与日本遗族会结合各自的动员结构，巩固自民党对政府的垄断，并通过表彰日本士兵、无视外国受害者的苦难，在日本的官方纪念中推动民族主义。

## 将民族主义逻辑重新置入教育

占领结束后，保守派政府还试图重振日本教育中的民族主义。吉田茂首相批评战后教育制度，因为他觉得这一制度没有做到“培养爱国心”，没有培养愿意为国家战斗的年轻爱国者。<sup class="footnote-ref" id="note-ref-ch1-60"><a href="./chapter-011#note-ch1-60" aria-label="查看原书注释 60">[60]</a></sup> 吉田政府的文部大臣天野贞祐也多次主张在教育中更加重视爱国主义。<sup class="footnote-ref" id="note-ref-ch1-61"><a href="./chapter-011#note-ch1-61" aria-label="查看原书注释 61">[61]</a></sup> 实质上，这些保守派政治人物不喜欢1947年的《教育基本法》，因为它主要以世界主义用语界定日本教育的目的：“我们制定了《日本国宪法》，宣示了建设民主而有文化的国家、为世界和平与人类福祉作贡献的决心。实现这一理想，从根本上取决于教育的力量。我们要培养尊重个人尊严、热切追求真理与和平的人，并通过<span class="original-page-marker" id="page-34" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 34 页" title="原书第 34 页">原书第 34 页</span>教育，大力推动具有普遍性和独创性的文化创造。”<sup class="footnote-ref" id="note-ref-ch1-62"><a href="./chapter-011#note-ch1-62" aria-label="查看原书注释 62">[62]</a></sup> 在这里，《教育基本法》意味着对战前教育制度的重大突破；后者建立在《教育敕语》之上，旨在培养“在危急之时勇敢而忠诚地承担神圣皇运的皇国臣民”。<sup class="footnote-ref" id="note-ref-ch1-63"><a href="./chapter-011#note-ch1-63" aria-label="查看原书注释 63">[63]</a></sup>

1954年12月鸠山一郎出任首相后，保守派对《教育基本法》的攻击日益增多。他任命的文部大臣清濑一郎曾任东条英机的辩护律师，公开批评这部法律，认为它“直接将个人与世界联系起来，却完全缺乏居于两者之间的国家概念”。<sup class="footnote-ref" id="note-ref-ch1-64"><a href="./chapter-011#note-ch1-64" aria-label="查看原书注释 64">[64]</a></sup> 随后，1956年2月，鸠山政府向国会提交法案，拟设立临时教育审议会，审查以该法为依据的战后教育制度，理由是这一制度“在占领这一特殊情境下改革得过于迅速，因此，在不少方面与〔日本社会的〕现实不相适应”。<sup class="footnote-ref" id="note-ref-ch1-65"><a href="./chapter-011#note-ch1-65" aria-label="查看原书注释 65">[65]</a></sup> 清濑在解释法案的动机时表示，他并不反对《教育基本法》所倡导的道德原则，只是“读到这部法律时，我总忍不住想：‘它究竟在哪里提到了对我们日本国家的忠诚？’”<sup class="footnote-ref" id="note-ref-ch1-66"><a href="./chapter-011#note-ch1-66" aria-label="查看原书注释 66">[66]</a></sup>

然而，日本社会党严厉批评这一法案“试图将教育置于政府控制之下”。<sup class="footnote-ref" id="note-ref-ch1-67"><a href="./chapter-011#note-ch1-67" aria-label="查看原书注释 67">[67]</a></sup> 法案于1956年3月在众议院通过，却在参议院被搁置，因为鸠山政府在1956年的国会会期中把重点放在另外两项教育相关法案上：《地方教育行政法案》和《教科书法案》。<sup class="footnote-ref" id="note-ref-ch1-68"><a href="./chapter-011#note-ch1-68" aria-label="查看原书注释 68">[68]</a></sup> 《地方教育行政法案》旨在取代占领期间为分散教育政策制定权力、推动其民主化而制定的《教育委员会法》。具体而言，法案建议将地方选举教育委员会委员改为由市町村长任命，因为自民党希望阻止日本社会党和日本教职员工会的支持者掌控地方教育委员会。1956年4月和5月，日本教职员工会及其他教育相关非政府组织发表联合声明，反对该法案。<sup class="footnote-ref" id="note-ref-ch1-69"><a href="./chapter-011#note-ch1-69" aria-label="查看原书注释 69">[69]</a></sup> 此外，日本全国约50万名教师停课抗议，他们认为这是倒退到战前日本政府控制教育的状态。<sup class="footnote-ref" id="note-ref-ch1-70"><a href="./chapter-011#note-ch1-70" aria-label="查看原书注释 70">[70]</a></sup> 最终，1956年6月，自民党凭借在国会的多数席位，在与日本社会党及其他反对党的愤怒叫喊和肢体冲突中强行通过了法案。<sup class="footnote-ref" id="note-ref-ch1-71"><a href="./chapter-011#note-ch1-71" aria-label="查看原书注释 71">[71]</a></sup>

<span class="original-page-marker" id="page-35" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 35 页</span>

与此同时，自民党试图通过《教科书法案》修改教科书审定程序。战前日本由政府垄断学校教科书的编写和出版，但这种政府垄断于1949年被废除，取而代之的是政府管理的教科书审定制度。这鼓励了教师与大学教授、教科书出版社合作，编写自己的教科书。<sup class="footnote-ref" id="note-ref-ch1-72"><a href="./chapter-011#note-ch1-72" aria-label="查看原书注释 72">[72]</a></sup> 在改革后的制度下，教科书选择也由各学校进行，教师得以参与选择过程。然而，1955年初，鸠山的日本民主党开始出版一系列题为《令人忧虑的教科书问题》的小册子，批评日本教职员工会成员编写的教科书。<sup class="footnote-ref" id="note-ref-ch1-73"><a href="./chapter-011#note-ch1-73" aria-label="查看原书注释 73">[73]</a></sup> 1955年11月自民党成立后，对“偏向教科书”的攻击最终形成了《教科书法案》；它建议增加政府在教科书审定中的特权，并授权教育委员会为其辖区内学校统一选用教科书。<sup class="footnote-ref" id="note-ref-ch1-74"><a href="./chapter-011#note-ch1-74" aria-label="查看原书注释 74">[74]</a></sup> 因而，法案旨在减少日本教职员工会成员对学校教科书编写和选择的影响。

面对日本社会党和日本教职员工会的强烈反对，鸠山政府放弃了《教科书法案》，因为它认为通过《地方教育行政法案》更为重要。但文部省仍在1956年末运用其预算和自由裁量权，在初等中等教育局教科书课内扩充进行教科书审定的人员。<sup class="footnote-ref" id="note-ref-ch1-75"><a href="./chapter-011#note-ch1-75" aria-label="查看原书注释 75">[75]</a></sup> 随后，文部省于1957年7月发布行政指令，宣布教育委员会应有权为辖区内学校选择教科书。<sup class="footnote-ref" id="note-ref-ch1-76"><a href="./chapter-011#note-ch1-76" aria-label="查看原书注释 76">[76]</a></sup> 此外，1958年修订小学和初中《学习指导要领》时，文部省赋予其法律约束力，要求教科书作者和教师更加严格地遵循文部省的课程指导方针。1963年12月，自民党成功制定《义务教育学校教科书法》，教育委员会也由此获得为辖区内学校选择教科书的法定权力。<sup class="footnote-ref" id="note-ref-ch1-77"><a href="./chapter-011#note-ch1-77" aria-label="查看原书注释 77">[77]</a></sup>

政府对教育日益增强的控制，影响了那些批判日本在亚太战争期间所作所为的教科书作者。东京教育大学历史学教授家永三郎就是其中一位。1955年，他提交高中教科书《新日本史》的草稿进行审定，从此开始了与教科书审定制度的斗争。<sup class="footnote-ref" id="note-ref-ch1-78"><a href="./chapter-011#note-ch1-78" aria-label="查看原书注释 78">[78]</a></sup> 虽然他的教科书草稿获准通过，<span class="original-page-marker" id="page-36" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 36 页" title="原书第 36 页">原书第 36 页</span>审定官却要求家永对总共216项修改意见作出回应。例如：“将‘日本军队先后占领北京、南京和汉口，将战线扩大到中国各地’改为‘战线扩大到中国各地’”；“删除图注为‘在原子弹轰炸中受伤后惊慌奔跑的广岛妇女和儿童’的插图”；“删除图注为‘反对日本重新武装的工人’的插图”。<sup class="footnote-ref" id="note-ref-ch1-79"><a href="./chapter-011#note-ch1-79" aria-label="查看原书注释 79">[79]</a></sup> 采纳大部分修改意见后，家永的教科书草稿获准在高中使用。但由于1955年高中《学习指导要领》进行了修订，家永马上又必须接受新一轮教科书审定。这一次，他的教科书草稿没有通过。文部省这样解释驳回的理由：“由于作者〔家永〕过于热衷于依据历史事实进行批判性反思，这本教科书偏离了日本历史教育的目标，即使学生认识祖先的努力，增强作为日本人的自觉，并培养丰厚的爱国心。”<sup class="footnote-ref" id="note-ref-ch1-80"><a href="./chapter-011#note-ch1-80" aria-label="查看原书注释 80">[80]</a></sup> 得知被驳回的理由后，家永修改并重新提交教科书，于1959年获得批准。

然而，《学习指导要领》于1960年再次修订后，家永的教科书草稿又遭驳回。他修改并重新提交教科书之后，文部省有条件地批准了它，要求家永回应近300项修改意见。例如，文部省要求家永“从‘无谋的战争’中删除‘无谋’一词，因为考虑到当时的世界形势，似乎不应将亚太战争的责任完全归咎于日本”，并要求他“对‘战争罪犯’一词加以限定，解释东京审判是如何由战胜国单方面进行的”。<sup class="footnote-ref" id="note-ref-ch1-81"><a href="./chapter-011#note-ch1-81" aria-label="查看原书注释 81">[81]</a></sup> 这促使家永于1965年6月提起诉讼。家永和律师们所质疑的并非这些修改要求本身，而是教科书审定制度本身的合宪性。他们认为，教科书审定违反了《日本国宪法》第13条、第23条和第26条所保障的学术研究与教育自由，以及《教育基本法》第10条禁止政府对教育进行“不当支配”的规定。<sup class="footnote-ref" id="note-ref-ch1-82"><a href="./chapter-011#note-ch1-82" aria-label="查看原书注释 82">[82]</a></sup> 换言之，后来被称为“家永教科书诉讼”的案件，在根本层面上质疑了民族主义逻辑，即那套授权政府控制国民教育、<span class="original-page-marker" id="page-37" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 37 页" title="原书第 37 页">原书第 37 页</span>在历史教育中推动民族主义的制度安排本身。家永起诉政府后不久，教育和历史学领域的大学教授、学校教师及律师于1965年8月在东京集会，讨论支持其诉讼的策略，随后成立了支援教科书审定诉讼全国联络会。<sup class="footnote-ref" id="note-ref-ch1-83"><a href="./chapter-011#note-ch1-83" aria-label="查看原书注释 83">[83]</a></sup> 这标志着家永及其支持者将在随后数十年进行的长期斗争的开始。

因此，在这一时期，保守派政治人物试图利用自己垄断政府的政治机会，将民族主义逻辑重新置入战后教育制度；但他们未能完全成功，因为日本社会党、日本教职员工会以及其他反对党和非政府组织拥有足以抵抗保守派政府提出的教育法案的动员结构。反对力量以和平主义的语言强调战争的罪恶，批评政府的教育政策是向战前军国主义的倒退。尽管反对力量未能阻止政府加强对教育的控制，却仍成功保住了将世界主义制度化的《教育基本法》。

## 广岛与长崎不完善的世界主义纪念

在战后日本，世界主义最清楚地体现在对原子弹轰炸的纪念中。广岛和长崎民众分别于1947年和1948年开始举行和平纪念仪式时，把原子弹轰炸作为划时代的事件来纪念，并鉴于潜在核战争对全球构成的威胁，呼吁全人类为世界和平而努力。广岛市1947年的《和平宣言》号召：“让我们消除地球上的恐惧和罪恶，以确立真正的和平。让我们通过永远放弃战争，实现世界和平的理想。”<sup class="footnote-ref" id="note-ref-ch1-84"><a href="./chapter-011#note-ch1-84" aria-label="查看原书注释 84">[84]</a></sup> 同样，长崎市1948年的《和平宣言》承诺，“通过向整个世界呼吁‘不要再有长崎’，在地球上建立永久和平”。<sup class="footnote-ref" id="note-ref-ch1-85"><a href="./chapter-011#note-ch1-85" aria-label="查看原书注释 85">[85]</a></sup> 这种世界主义取向部分源于占领期间的审查。由于盟军最高司令部不允许日本民众因原子弹轰炸而批评美国，原爆受害者不得不采用超越国籍的普遍主义语言。<sup class="footnote-ref" id="note-ref-ch1-86"><a href="./chapter-011#note-ch1-86" aria-label="查看原书注释 86">[86]</a></sup> 新兴的全球反核运动与和平运动也推动了这一世界主义框架。例如，世界和平理事会于1950年3月发表《斯德哥尔摩呼吁书》，在世界各地收集了<span class="original-page-marker" id="page-38" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 38 页" title="原书第 38 页">原书第 38 页</span>5亿多份签名，要求彻底禁止核武器。日本贡献了约740万份签名，原爆诗人峠三吉写下《呼吁》一诗，支持《斯德哥尔摩呼吁书》。<sup class="footnote-ref" id="note-ref-ch1-87"><a href="./chapter-011#note-ch1-87" aria-label="查看原书注释 87">[87]</a></sup>

原爆受害者及其支持者不仅纪念原子弹轰炸，还游说地方和国家政府。1952年8月，广岛市约250名原爆受害者成立原爆受害者会，要求免费体检、福利支持以及对原爆相关疾病治疗提供补贴等救济。<sup class="footnote-ref" id="note-ref-ch1-88"><a href="./chapter-011#note-ch1-88" aria-label="查看原书注释 88">[88]</a></sup> 1952年国会审议《战伤病者战殁者遗族援护法案》时，广岛市议会前议长兼广岛与长崎复兴委员会委员长 Nitoguri Ikkō 在众议院厚生委员会作证。他在那里要求委员们考虑扩大法案范围，把在动员参加军事相关勤务期间死于原子弹轰炸的平民纳入其中。<sup class="footnote-ref" id="note-ref-ch1-89"><a href="./chapter-011#note-ch1-89" aria-label="查看原书注释 89">[89]</a></sup>

日本社会党最积极地支持原爆受害者。1952年2月，日本社会党议员冈良一将广岛的请愿转交国会，敦促政府保护“原爆孤儿”——即在原子弹轰炸中失去父母的儿童——“作为将日本重建为和平国家的努力的一部分，因为日本是地球上第一个也是唯一的原子弹受害国”。<sup class="footnote-ref" id="note-ref-ch1-90"><a href="./chapter-011#note-ch1-90" aria-label="查看原书注释 90">[90]</a></sup> 4月，另一位日本社会党议员 Aono Buichi 主张，《战伤病者战殁者遗族援护法案》应包含无差别空袭的平民受害者，尤其是广岛和长崎原子弹轰炸的受害者。<sup class="footnote-ref" id="note-ref-ch1-91"><a href="./chapter-011#note-ch1-91" aria-label="查看原书注释 91">[91]</a></sup> 日本社会党成员经常主持国会厚生委员会，并邀请广岛民众前来就其经济与健康状况作证。

随后，1954年3月1日，比基尼环礁附近发生了第五福龙丸事件：一艘日本渔船的船员暴露于氢弹的放射性尘埃中。船员患上急性放射病，他们带回日本的金枪鱼也显示出高水平放射性。第五福龙丸事件在日本全国引起震惊，以至于全国46个都道府县议会都在1954年3月至10月间通过了反核决议。1954年8月开始的全国反核武器签名运动，一年之内便积累了3,000多万份签名。<sup class="footnote-ref" id="note-ref-ch1-92"><a href="./chapter-011#note-ch1-92" aria-label="查看原书注释 92">[92]</a></sup> 为响应这一全国性的反核运动，<span class="original-page-marker" id="page-39" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 39 页" title="原书第 39 页">原书第 39 页</span>众议院于1954年4月一致通过了一项禁止使用核武器的决议。在充满热烈演说和响亮掌声的国会会议上，日本社会党议员木下郁热情支持这一决议：“我们日本人民出于对过去错误行为的深刻反省，制定了所谓的‘和平宪法’……既然我们也是唯一经历过原子弹轰炸的人民，我认为通过这样一项有关核武器的决议是我们的责任。”<sup class="footnote-ref" id="note-ref-ch1-93"><a href="./chapter-011#note-ch1-93" aria-label="查看原书注释 93">[93]</a></sup>

全国反核运动于1955年8月举行反对原子弹氢弹世界大会时达到高潮。14个国家及日本46个都道府县的代表参加了在广岛举行的大会，开幕时听取了广岛和长崎原爆受害者的证言。世界大会的核心参与者随后成立禁止原子弹氢弹日本协议会，以继续反核运动，并开始征集要求政府补偿原爆受害者的签名。<sup class="footnote-ref" id="note-ref-ch1-94"><a href="./chapter-011#note-ch1-94" aria-label="查看原书注释 94">[94]</a></sup> 1956年8月在长崎举行的第二届世界大会通过决议，要求政府补偿原爆受害者。会后，原爆受害者成立了自己的全国性组织——日本原水爆被害者团体协议会，组织日本各地的受害者，更有效地游说日本政府。<sup class="footnote-ref" id="note-ref-ch1-95"><a href="./chapter-011#note-ch1-95" aria-label="查看原书注释 95">[95]</a></sup>

为支持原爆受害者，日本社会党发表了《原爆症患者援护法案要纲》，建议由政府承担原爆受害者的医疗费用。同样，广岛和长崎两市于11月共同提出了有关政府救济原爆受害者的法案草案。随后，12月初，禁止原子弹氢弹日本协议会与国会议员会面，并向鸠山一郎首相和两院议长递交请愿书，要求政府救济原爆受害者。<sup class="footnote-ref" id="note-ref-ch1-96"><a href="./chapter-011#note-ch1-96" aria-label="查看原书注释 96">[96]</a></sup> 这些游说活动促使日本社会党和自民党共同提出一项决议，要求政府“从人道主义的立场”向原爆受害者提供医疗。<sup class="footnote-ref" id="note-ref-ch1-97"><a href="./chapter-011#note-ch1-97" aria-label="查看原书注释 97">[97]</a></sup> 众议院一致通过决议后，石桥湛山政府于1957年2月提出《关于原子弹被爆者医疗等的法律案》。由于该法案获得广泛支持，<span class="original-page-marker" id="page-40" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 40 页" title="原书第 40 页">原书第 40 页</span>它很快在两院通过，并于4月1日生效。新制定的法律规定向原爆受害者发放“被爆者健康手帐”。持有这些健康记录册的人被认定为“正式原爆受害者”，有权每年接受两次免费健康检查。如果其症状符合“认定患者”的标准，他们还有资格接受由政府全额负担的免费医疗。虽然法律使政府承担为原爆受害者提供医疗的责任，但这种责任被界定为自愿责任。

这种对政府责任的界定在1955年4月受到挑战：日本律师联合会的一个律师团队帮助三名原爆受害者起诉日本政府，所谓的“原爆诉讼”由此开始。律师们起初试图要求美国政府赔偿，理由是美国违反了禁止使用不人道武器的《海牙公约》；然而，美国律师协会否认这种赔偿具有任何法律依据。<sup class="footnote-ref" id="note-ref-ch1-98"><a href="./chapter-011#note-ch1-98" aria-label="查看原书注释 98">[98]</a></sup> 律师们意识到起诉美国政府太过困难后，决定把日本政府作为诉讼对象，并提出如下论证：美国使用不人道的原子弹违反了国际法；然而，日本政府于1951年签署《旧金山和约》，放弃了包括原爆受害者请求权在内的全部对美赔偿请求权；因此，日本政府应该代替美国政府补偿原爆受害者。<sup class="footnote-ref" id="note-ref-ch1-99"><a href="./chapter-011#note-ch1-99" aria-label="查看原书注释 99">[99]</a></sup>

在原爆诉讼进行的同时，日本社会党要求自民党政府扩大对原爆受害者的救济。1959年11月，日本社会党提交法案，拟将《原爆受害者医疗法》扩展为与《战伤病者战殁者遗族援护法》相当的《原爆受害者援护法》。岸信介政府虽然拒绝向原爆受害者提供补偿，却同意于1960年7月扩大现有原爆受害者法律的覆盖范围，补贴并非直接与原子弹轰炸有关的疾病治疗，并在原爆受害者接受医疗期间向他们发放每月津贴。<sup class="footnote-ref" id="note-ref-ch1-100"><a href="./chapter-011#note-ch1-100" aria-label="查看原书注释 100">[100]</a></sup> 20世纪50年代，反对党与左倾非政府组织抓住日本国内外反核运动不断发展的政治机会，要求自民党政府承认战争责任，并<span class="original-page-marker" id="page-41" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 41 页" title="原书第 41 页">原书第 41 页</span>向原爆受害者提供补偿。他们挑战了日本补偿政策中的民族主义逻辑：这一政策只认可那些通过服役为国家牺牲生命的人。然而，反对力量的挑战最终失败了，因为自民党凭借其稳固的动员结构和对政府的控制，捍卫了现有补偿政策。

在政治人物与非政府组织辩论政府对原爆受害者的补偿时，广岛和长崎民众逐步巩固了世界主义纪念逻辑。1963年2月，四名日本佛教僧人开始了“广岛—奥斯维辛和平行进”。他们从广岛步行到奥斯维辛，访问了24个国家，传递“不要再有广岛，不要再有奥斯维辛”的讯息。<sup class="footnote-ref" id="note-ref-ch1-101"><a href="./chapter-011#note-ch1-101" aria-label="查看原书注释 101">[101]</a></sup> 1964年4月，40名原爆受害者也开始了“广岛—长崎世界和平巡礼”。他们访问了包括美国和苏联在内的8个国家、共150座城市，呼吁世界和平。<sup class="footnote-ref" id="note-ref-ch1-102"><a href="./chapter-011#note-ch1-102" aria-label="查看原书注释 102">[102]</a></sup> 但这种普遍主义纪念框架有一个根本缺陷：它未能涵盖那些遭受日本过去错误行为的外国受害者。这是一种以自身利益为中心的世界主义，很大程度上源于一个事实：日本与韩国和中国这两个距离最近、曾深受日本侵略之害的邻国，尚无正式外交关系。

## 战后日本与韩国、中国的关系

日本与中国的关系首先面临冷战地缘政治的障碍。1951年，日本在旧金山与美国签署和约和双边安全条约后，美国要求日本承认台湾是合法的中国。美国参议院甚至认为，应当以日本承认台湾作为批准《旧金山和约》的条件。<sup class="footnote-ref" id="note-ref-ch1-103"><a href="./chapter-011#note-ch1-103" aria-label="查看原书注释 103">[103]</a></sup> 面对美国的强大压力，吉田茂政府决定与台湾实现关系正常化。作为回应，台湾同意放弃对日本的赔偿请求权，尽管蒋介石起初曾打算要求对战争造成的损失进行赔偿。<sup class="footnote-ref" id="note-ref-ch1-104"><a href="./chapter-011#note-ch1-104" aria-label="查看原书注释 104">[104]</a></sup> 1952年4月，日本与台湾签署和约，使双方关系正常化，也将日本锁定于美国在东亚的冷战战略之中。

作为回应，中国总理周恩来于1952年5月发表声明，批评《旧金山和约》《美日安全条约》和《日台和约》。然而，周将其批评主要指向美国，而非日本。

<span class="original-page-marker" id="page-42" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 42 页</span>

周确实批评了日本政府追随美国的做法：“在签订《旧金山和约》之后，吉田政府立即释放了88名双手沾满中国人民鲜血的穷凶极恶的日本战犯。这表明日本的反动统治者毫无悔悟和赎罪之心……并企图恢复对中国和亚洲人民的帝国主义统治。”<sup class="footnote-ref" id="note-ref-ch1-105"><a href="./chapter-011#note-ch1-105" aria-label="查看原书注释 105">[105]</a></sup> 尽管如此，周仍将美国批评为中国真正的敌人，抨击《旧金山和约》是美国政府企图重新武装日本、对亚洲人民发动侵略战争的手段。周还谨慎地把日本人民与日本政府区分开来，甚至赞扬“日本人民对非法的《旧金山和约》和美国帝国主义占领的抵抗”，并进一步表达“中国人民对日本人民斗争的无限团结和热情支持”。<sup class="footnote-ref" id="note-ref-ch1-106"><a href="./chapter-011#note-ch1-106" aria-label="查看原书注释 106">[106]</a></sup>

周的声明体现了中国政府对于日本过去侵略所采取的温和纪念立场。中国高级官员，尤其是毛泽东，在谴责战前日本军国主义政府的同时，把普通日本民众描述为军国主义的受害者。相反，中国政府把中国人民的苦难归咎于国民党。<sup class="footnote-ref" id="note-ref-ch1-107"><a href="./chapter-011#note-ch1-107" aria-label="查看原书注释 107">[107]</a></sup> 对中国政府而言，抵抗美国在东亚的支配地位，比纪念日本过去的错误行为更为重要。

对于日本政府而言，与中国的经济关系同样比战争纪念更为重要。从20世纪40年代后期到50年代中期，日本政治人物和商界人士成立了各种团体，以促进对华贸易，推动战后日本的经济发展。例如，1949年的日中贸易促进议员联盟、1950年的日中友好协会、1952年的日本国际贸易促进委员会，以及1955年的日中进出口组合。<sup class="footnote-ref" id="note-ref-ch1-108"><a href="./chapter-011#note-ch1-108" aria-label="查看原书注释 108">[108]</a></sup> 这些努力促成了20世纪50年代上半期一系列与中国签订的民间贸易协定，但日本与中国的经济关系仍然有限而脆弱。直到1960年，热衷于推动经济发展的池田勇人出任首相，两国经济关系才开始改善。中国政府也<span class="original-page-marker" id="page-43" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 43 页" title="原书第 43 页">原书第 43 页</span>急于加强与日本的经济合作，因为中国在20世纪50年代后期的大跃进运动中遭受了重大经济损失。与此同时，中苏关系也开始恶化，使中国政府更加希望与日本改善关系。<sup class="footnote-ref" id="note-ref-ch1-109"><a href="./chapter-011#note-ch1-109" aria-label="查看原书注释 109">[109]</a></sup>

虽然日中关系基本局限于经济层面，日本的一些非政府组织却尝试纪念日本过去对中国实施的错误行为。例如，日中友好协会纪念“中国人民因日本军国主义的侵略政策而遭受的苦难”，并力求“纠正日本人民对中国的错误看法”——这些看法曾推动日本过去的侵略。<sup class="footnote-ref" id="note-ref-ch1-110"><a href="./chapter-011#note-ch1-110" aria-label="查看原书注释 110">[110]</a></sup> 吉田茂政府签署《日台和约》时，该协会还发表声明，批评这一和约“否认日本对中国人民的战争责任”。<sup class="footnote-ref" id="note-ref-ch1-111"><a href="./chapter-011#note-ch1-111" aria-label="查看原书注释 111">[111]</a></sup> 不过，当时日本很少出现这种对中国受害者的世界主义纪念。

与此同时，即便日本与韩国之间没有正式外交关系，两国在战争纪念方面的问题也更多。1945年8月日本向盟国投降后不久，朝鲜人便成立团体，要求日本政府和企业补偿他们在战争期间提供的兵役和劳务；韩国过渡政府也于1947年8月设立委员会，处理对日本的赔偿请求。<sup class="footnote-ref" id="note-ref-ch1-112"><a href="./chapter-011#note-ch1-112" aria-label="查看原书注释 112">[112]</a></sup> 随后，1948年9月，一个由前军人和劳工组成的团体要求日本政府赔偿30亿日元，以支付未付报酬的兵役与劳务。<sup class="footnote-ref" id="note-ref-ch1-113"><a href="./chapter-011#note-ch1-113" aria-label="查看原书注释 113">[113]</a></sup> 由长期支持独立的民族主义者李承晚领导的韩国政府，也向盟军最高司令部提交了多份有关韩国对日赔偿请求的调查报告。李承晚政府要求的赔偿总额超过300亿日元，包括朝鲜人民在战争期间遭受的损失，以及在“违背朝鲜人民意愿、违反正义、公平和互利原则的强制行为——日本殖民统治”期间遭受的损失。<sup class="footnote-ref" id="note-ref-ch1-114"><a href="./chapter-011#note-ch1-114" aria-label="查看原书注释 114">[114]</a></sup> 此外，李承晚政府还寻求以盟国成员身份参加旧金山和会。

然而，1947年8月，盟国认定韩国不享有对日赔偿请求权，应当满足于日本遗留下来的各种设施和物资。

<span class="original-page-marker" id="page-44" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 44 页</span>

（日本政府和国民向盟国投降时，已失去对日本前殖民地财产的所有权。）这一决定与美国对日本赔偿战争损失责任采取日益宽松的立场发生于同一时期：美国政府判断，迅速重建日本、使其成为冷战盟友，比课以巨额赔偿、妨碍日本重建更符合战略利益。<sup class="footnote-ref" id="note-ref-ch1-115"><a href="./chapter-011#note-ch1-115" aria-label="查看原书注释 115">[115]</a></sup>

日本政府也拒绝韩国的赔偿请求。从朝鲜归国的日本人甚至认为，盟国应该赔偿他们被没收的私人财产，称这种没收违反了《海牙公约》。<sup class="footnote-ref" id="note-ref-ch1-116"><a href="./chapter-011#note-ch1-116" aria-label="查看原书注释 116">[116]</a></sup> 日本签署《旧金山和约》后，这些归国者转而要求日本政府赔偿。他们要求赔偿的逻辑与原爆受害者的请求类似：既然日本政府放弃了对盟国的赔偿请求权，就应当承担补偿从朝鲜及其他前殖民地归国的日本人的责任。

因此，1952年2月，日本和韩国政府在东京开始第一轮关系正常化会谈时，双方对赔偿问题持有根本不同的看法。韩国方面决心坚持赔偿要求，日本方面则主张，吞并朝鲜在当时是合法的，并要求赔偿遭没收的日本国民私人财产。<sup class="footnote-ref" id="note-ref-ch1-117"><a href="./chapter-011#note-ch1-117" aria-label="查看原书注释 117">[117]</a></sup> 在接下来的两轮关系正常化会谈中，日韩仍未能解决分歧。随后，在第三轮会谈中，日本代表之一、外务省的久保田贯一郎表示：“虽然我承认日本对朝鲜的殖民统治存在负面的一面，但不可否认，日本也为朝鲜做了好事。”<sup class="footnote-ref" id="note-ref-ch1-118"><a href="./chapter-011#note-ch1-118" aria-label="查看原书注释 118">[118]</a></sup> 这激怒了韩国方面，但日本政府拒绝撤回久保田的言论。于是，关系正常化会谈于1953年破裂。

然而，1960年，韩国与日本均出现某些重要政治变化，关系正常化会谈因此恢复。1960年8月，尹潽善出任韩国总统，并采取了新的对日政策。韩国政府不再要求日本为过去的错误行为赔偿，而开始考虑接受日本经济援助作为替代。这一政策转变源于1957年韩国经济形势的两个重大变化：

<span class="original-page-marker" id="page-45" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 45 页</span>

美国对韩国的经济援助开始减少，而朝鲜启动了使经济实现工业化的五年计划。在这些变化了的条件下，韩国政府开始将日本视为重要的经济伙伴。1961年5月，朴正熙通过军事政变夺取政权后，这一看法得到巩固。在日本，1960年7月出任首相的池田勇人也希望通过向韩国出口商品和服务，促进日本的经济增长。事实上，日本政府早在20世纪50年代与缅甸、印度尼西亚、南越和菲律宾等东南亚国家谈判和约时，就已经开始发展这种以经济方式补偿战争损失的做法。日本政府以日本企业生产的商品和服务的形式，向这些国家提供对日本过去错误行为的“赔偿”。<sup class="footnote-ref" id="note-ref-ch1-119"><a href="./chapter-011#note-ch1-119" aria-label="查看原书注释 119">[119]</a></sup>

此外，20世纪60年代初，亚洲的冷战进一步升级。朝鲜于1961年与苏联签署共同防御条约，并与中国签署友好互助条约。随着美国愈来愈深地卷入越南战争，它希望日本和韩国这两个东亚盟友的关系更加稳定。在美国看来，日本对韩国的经济援助不仅有助于减轻美国的财政负担，还能促使韩国向越南派遣军队。<sup class="footnote-ref" id="note-ref-ch1-120"><a href="./chapter-011#note-ch1-120" aria-label="查看原书注释 120">[120]</a></sup> 因而，朝鲜的威胁与美国的压力共同促使日本和韩国在赔偿问题上作出妥协。

在关系正常化会谈的最后阶段，日本和韩国政府同意由前者向后者提供赠款和优惠贷款，代替赔偿，并由关系正常化解决两国之间的全部赔偿问题。然而，韩国的反对党和大学生于1964年3月抗议关系正常化。反对力量批评正常化条款实际上放弃了要求日本道歉和赔偿的任何诉求。3月25日至27日，首尔的抗议活动每天吸引4万至6万人参与，大学生继续组织抗议，直至6月初朴正熙政府宣布紧急状态、镇压抗议为止。<sup class="footnote-ref" id="note-ref-ch1-121"><a href="./chapter-011#note-ch1-121" aria-label="查看原书注释 121">[121]</a></sup>

同样，日本的反对党要求自民党政府正视日本过去的错误行为。外务大臣椎名悦三郎确实在1965年2月访问韩国、结束谈判时，<span class="original-page-marker" id="page-46" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 46 页" title="原书第 46 页">原书第 46 页</span>对“两国漫长历史中的不幸时期”表达了“深切反省”。<sup class="footnote-ref" id="note-ref-ch1-122"><a href="./chapter-011#note-ch1-122" aria-label="查看原书注释 122">[122]</a></sup> 但日本社会党议员细迫兼光此前已经敦促池田本人以日本首相身份向韩国道歉：“如果你希望与韩国建立友好关系……首先就应该道歉……为日本犯下的错误道歉并不可耻。事实上，不道歉才是可耻的。”<sup class="footnote-ref" id="note-ref-ch1-123"><a href="./chapter-011#note-ch1-123" aria-label="查看原书注释 123">[123]</a></sup> 日本共产党议员河上贯一也要求日本政府向韩国人民道歉：“毋庸置疑，日本长期以来对朝鲜人民实施了各种暴行——侵略、压迫、掠夺和奴役。今天，日本政府应反省自己对这些行为所负的责任，向朝鲜人民道歉，并为日本人民树立正义的榜样。”<sup class="footnote-ref" id="note-ref-ch1-124"><a href="./chapter-011#note-ch1-124" aria-label="查看原书注释 124">[124]</a></sup> 然而，发出这些批评的只是少数日本政治人物。因此，日本与韩国政府于1964年12月在东京着手敲定关系正常化的条款，正式把经济利益置于过去的问题之上。

## 亚太战争之后，历史问题之前

在战后最初的时期，历史问题实际上并不存在。日本不仅缺乏与韩国、中国的外交关系，三国政府还基于各自的经济利益和政治盘算，有意压制有关日本过去错误行为的讨论。此外，美国在占领期间逆转了政策目标的方向，使日本得以逃避过去的错误行为。因而，各国之间纪念的分隔与逆转路线，为保守派政治人物提供了政治机会；他们通过成立自民党、动员日本遗族会及其他支持群体，巩固了自身的权力。保守派政治人物借助稳固的动员结构，抓住政治机会，支配政府，并在日本的官方纪念中推动民族主义。结果是，首相在言论和行动中否定东京判决，政府通过补偿表彰伤残退伍军人和遗族，而教科书审定程序试图尽量减少对日本过去错误行为的描述。

相比之下，日本社会党和日本共产党采用世界主义逻辑，纪念遭受日本过去错误行为的外国受害者。然而，<span class="original-page-marker" id="page-47" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 47 页" title="原书第 47 页">原书第 47 页</span>这些反对党的动员结构较弱，也很少有政治机会将世界主义注入政府言论和行动、补偿政策及教育之中；尽管如此，它们确实降低了保守派政治人物能够在日本官方纪念中制度化的民族主义程度。此外，日本社会党虽与原爆受害者合作，后者开始阐明世界主义逻辑，以不分国籍地纪念所有战争受害者，但这种世界主义纪念仍不完善，因为它未能涵盖日本过去侵略的外国受害者。尽管如此，早期原子弹轰炸纪念所体现的这种不完善的世界主义，在日本分别于1965年和1972年与韩国、中国实现关系正常化后，将在纪念韩国和中国受害者方面发挥重要作用。同时，关系正常化也将扩大日本与韩国、中国在政府和民间层面的互动，推动历史问题的发展。

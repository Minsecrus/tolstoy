# 第六章 历史学家在历史问题中的作用

<span class="original-page-marker" id="page-155" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 155 页</span>

乍看之下，历史学家似乎并不是推动解决历史问题的最佳人选。这是因为，历史学家传统上一直把民族国家作为主要分析单位，帮助人们将它视为一种原初存在的实体。他们还建立专业协会，按照国界划定会员资格，与民族主义的自决逻辑相一致；例如，日本历史学家撰写日本史时，常常只是彼此交谈，而不咨询研究日本的外国历史学家。这种受国界限定的内容重心和成员资格，强化了把世界划分为各个独立民族国家的民族主义逻辑。因此，历史学家虽然未必支持民族主义，却一直以民族历史权威叙述者的身份参与国家建构。<sup class="footnote-ref" id="note-ref-ch6-1"><a href="#note-ch6-1" aria-label="查看原书注释 1">[1]</a></sup>

但与此同时，历史学家也经常批评民族主义者，指出他们倾向于简化过去，以创造民族神话和民族认同。<sup class="footnote-ref" id="note-ref-ch6-2"><a href="#note-ch6-2" aria-label="查看原书注释 2">[2]</a></sup>历史学家深知，历史证据往往并不完整，因此历史事件的事实与解释必然会产生争议，并且本身就可能在未来受到修订。民族主义者常常借助充满情感的纪念，把这些尚无定论的历史争议转化为不可更改的历史真理，作为民族认同的基础；历史学家则依据现有研究，揭露事实错误和缺乏根据的解释，来挑战这种民族主义纪念。

事实上，过去几十年间，历史学家在方法论意义上愈发批判民族主义，开始摆脱受国界限定的内容重心和专业成员资格。例如，<span class="original-page-marker" id="page-156" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 156 页" title="原书第 156 页">原书第 156 页</span>近来全球史和跨国历史书写不断发展。<sup class="footnote-ref" id="note-ref-ch6-3"><a href="#note-ch6-3" aria-label="查看原书注释 3">[3]</a></sup>从事这一新领域研究的历史学家，着重考察跨越国界的经济、政治、社会和文化互动，挑战将民族国家视为独立的原初实体的观念。历史学家 Eric Hobsbawm 甚至提出，任何历史书写都应包含全球和跨国视角：“历史学家，无论研究多么微观，都必须赞成普遍主义，这并非出于对一种我们许多人仍然眷恋的理想的忠诚，而是因为它是理解人类历史，包括理解人类任何特定群体的历史的必要条件。因为所有人类集体都必然是、也一向是一个更大且更复杂的世界的一部分。”<sup class="footnote-ref" id="note-ref-ch6-4"><a href="#note-ch6-4" aria-label="查看原书注释 4">[4]</a></sup>此外，一种规范也已出现：历史学家和历史教师在撰写过去国际冲突的历史时，应当跨国合作。东亚及世界其他地区不断增多的联合历史研究和教育项目，就证明了这一点。<sup class="footnote-ref" id="note-ref-ch6-5"><a href="#note-ch6-5" aria-label="查看原书注释 5">[5]</a></sup>这些联合项目代表着世界主义在历史书写中的制度化：它们把分析单位从民族国家转移到跨国互动，同时将外国视角纳入历史叙述。

因此，在本章中，我将批判性地考察历史学家在战争纪念政治中质疑民族主义、推动世界主义的潜力。近年来，历史学家在历史问题中的存在感不断增强，因为未经历亚太战争的世代已经成为日本、韩国和中国的人口多数——他们主要通过学校的历史课程了解这场战争。因此，从理论上说，参与联合历史研究和教育项目的历史学家，有能力帮助这些世代把民族主义纪念与东京审判有问题的历史判决分离开来，迈向更具世界主义性质的纪念。但与此同时，他们对这一场域中相关政治行动者的实际影响，仍有待系统考察。历史学家在多大程度上成功地使政府和公众的纪念从民族主义转向世界主义？他们试图影响历史问题的动态及其发展轨迹时，遭遇了哪些障碍？

## 历史学家：具有认识取向的扎根型世界主义者

要回答这些问题，首先必须理解历史学家作为“具有认识取向的扎根型世界主义者”的独特潜力。<sup class="footnote-ref" id="note-ref-ch6-6"><a href="#note-ch6-6" aria-label="查看原书注释 6">[6]</a></sup>通常，扎根型世界主义者以一个国家为生活基础，<span class="original-page-marker" id="page-157" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 157 页" title="原书第 157 页">原书第 157 页</span>却对外国他者保持开放。<sup class="footnote-ref" id="note-ref-ch6-7"><a href="#note-ch6-7" aria-label="查看原书注释 7">[7]</a></sup>他们包括个人经历和社会联系跨越多个民族国家的移民，以及动员倡议网络、应对世界各地人权侵犯的活动人士。<sup class="footnote-ref" id="note-ref-ch6-8"><a href="#note-ch6-8" aria-label="查看原书注释 8">[8]</a></sup>这些扎根型世界主义者表明，对外国他者的开放不仅是一种个人属性，也是一种由跨国网络维系的集体特性。正如社会学家 Craig Calhoun 所说，世界主义并不“只是一种无所依附的文化品味、个人态度或伦理选择”，而始终嵌入特定的行动者网络之中。<sup class="footnote-ref" id="note-ref-ch6-9"><a href="#note-ch6-9" aria-label="查看原书注释 9">[9]</a></sup>按照这一定义，历史学家也属于扎根型世界主义者，因为他们通过组织会议和其他专业活动，建立跨国社会网络，交流方法、卓越标准和培训计划，而这些活动向所有国籍的人开放。<sup class="footnote-ref" id="note-ref-ch6-10"><a href="#note-ch6-10" aria-label="查看原书注释 10">[10]</a></sup>

更重要的是，历史学家是具有认识取向的扎根型世界主义者。他们以社会学家 John Meyer 所说的“他者”的身份参与战争纪念政治：这些人被定义为不抱私利的“真理”承载者，并获授权担任追求自身利益的其他政治行动者的顾问。<sup class="footnote-ref" id="note-ref-ch6-11"><a href="#note-ch6-11" aria-label="查看原书注释 11">[11]</a></sup>从这一方面说，历史学家围绕历史问题构成了“认识共同体”，即以知识为基础的网络，由“在特定领域拥有公认的专门知识和能力，并对该领域或议题中与政策相关的知识提出权威性主张的专业人士”组成。<sup class="footnote-ref" id="note-ref-ch6-12"><a href="#note-ch6-12" aria-label="查看原书注释 12">[12]</a></sup>换言之，历史学家被视为提供可靠资料和权威解释的专家，历史问题场域中的相关政治行动者可以借助这些资料和解释，为自己的纪念立场提供正当性。

这种认识取向，使历史学家区别于历史问题中其他类型的扎根型世界主义者。或许最为显眼的一类扎根型世界主义者具有倡议取向：那些支持韩国原爆受害者、前“慰安妇”，以及日本过去错误行为的其他受害者的日本非政府组织成员。他们将团结关系扩展到国界之外，在跨国层面分享信息与资源，协调行动，要求日本政府采纳世界主义的纪念逻辑。然而，这些具有倡议取向的扎根型世界主义者，无意中加剧了历史问题，因为他们为政治上的权宜之计牺牲了历史准确性。例如，日本和韩国许多非政府组织追随联合国特别报告员，把慰安所一概界定为强奸中心，把军队“慰安妇”制度界定为性奴隶制。正如人类学家 C. Sarah Soh 批判性地指出的，这种一概而论的界定是“支持寻求补偿运动的政治行为”，也是一种“党派偏见”，<span class="original-page-marker" id="page-158" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 158 页" title="原书第 158 页">原书第 158 页</span>抹去了该制度的复杂性：它运行着不同类型的慰安所，并且依赖朝鲜人的协作。<sup class="footnote-ref" id="note-ref-ch6-13"><a href="#note-ch6-13" aria-label="查看原书注释 13">[13]</a></sup>因此，日本具有倡议取向的扎根型世界主义者，最终延续了韩国的民族主义纪念，同时激励日本民族主义者把前“慰安妇”的诉求斥为捏造。

相比之下，作为具有认识取向的扎根型世界主义者开展活动的历史学家，有可能对历史问题产生不同的影响。正如历史学家小菅信子所指出的：“历史学的方法，即审查历史资料（史料批判），最适合纠正对过去的误解和歪曲……通过审查历史资料并开展实证研究，历史学家不能不变得谦逊，接受学术上的自我节制［避免放纵地操纵资料、歪曲描述］。”<sup class="footnote-ref" id="note-ref-ch6-14"><a href="#note-ch6-14" aria-label="查看原书注释 14">[14]</a></sup>因此，历史学家能够批判性地反思民族主义纪念，防止历史上的不准确表述和有问题的解释助长历史问题。事实上，日本、韩国和中国历史学家的联合历史研究与教育项目，已经显示出它们促成对民族主义纪念的相互批评、推动历史研究世界主义逻辑的潜力。

不过，并非所有联合项目在批判民族主义纪念方面都同样有效。政府和非政府联合项目的过程与结果显示，后者往往更能成功推动世界主义逻辑。<sup class="footnote-ref" id="note-ref-ch6-15"><a href="#note-ch6-15" aria-label="查看原书注释 15">[15]</a></sup>非政府联合项目，尤其是“面向未来的历史”项目，使日本、韩国和中国的历史学家能够批评彼此的民族主义偏见。它们不仅更有效地把与外国历史学家的对话纳入历史研究过程，还把内容重心从民族国家转向民族国家之间的互动。

相比之下，政府联合项目似乎难以促成对民族主义纪念的相互批评。事实上，日韩联合项目受到日本外务省的严重限制，外务省长期以来一直抵制重新审视日韩两国于1965年签订的《基本条约》。外务省担心，对条约提及的历史事件，例如日本1910年吞并朝鲜，作出任何新的解释，都将为新的赔偿请求铺平道路。据报道，一名外务省官员曾说：“联合历史研究项目没有重新解释1965年《基本条约》的余地。

<span class="original-page-marker" id="page-159" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 159 页</span>

由于重新解释1965年《基本条约》可能重燃赔偿问题，日韩双方达成学术共识的可能性极小。”<sup class="footnote-ref" id="note-ref-ch6-16"><a href="#note-ch6-16" aria-label="查看原书注释 16">[16]</a></sup>日中联合项目也存在类似限制：中国历史学家在发表联合项目成果时，受到本国政府的约束。

我认为，非政府项目与政府项目之间的差异，源于它们支持的不同认同框架。一般而言，联合项目参与者可以采用两种不同的认同框架。第一种是受国界限定的框架，例如“日本人”“韩国人”和“中国人”。第二种是不受国界限定的框架，即“历史学家”。<sup class="footnote-ref" id="note-ref-ch6-17"><a href="#note-ch6-17" aria-label="查看原书注释 17">[17]</a></sup>非政府项目突出了不受国界限定的认同框架——关注历史问题升级的历史学家——而这种框定方式，使参与者在相当程度上能够暂时搁置自己的国家认同。然而，政府项目突出了受国界限定的框架，把参与者定位为本国代表。例如，日韩和日中联合项目的日本参与者，都由日本政府遴选，遴选过程未咨询历史学家的专业协会；这些联合项目也全部由各国政府的外交部管理。<sup class="footnote-ref" id="note-ref-ch6-18"><a href="#note-ch6-18" aria-label="查看原书注释 18">[18]</a></sup>这种结构性约束，使参与者难以对外国视角保持开放，也难以通过对话改变自己原有的立场。

非政府项目与政府项目在过程和结果上的差异，似乎也取决于参与者的倾向——取决于他们原本对外国他者开放到何种程度。例如，“面向未来的历史”项目的日本参与者包括许多左倾历史学家，如笠原十九司，他们曾积极参与反对保守派政治家与非政府组织的社会运动。在某些方面，“面向未来的历史”项目，是现有跨国倡议型非政府组织网络的延伸；这个网络曾要求日本政府向日本过去错误行为的外国受害者道歉并赔偿。参与者的倾向，也可以部分解释日韩联合项目为何进展艰难。日本政府任命筑波大学历史学教授古田博司参与该项目，他以相信日本人优于<span class="original-page-marker" id="page-160" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 160 页" title="原书第 160 页">原书第 160 页</span>朝鲜人而闻名。<sup class="footnote-ref" id="note-ref-ch6-19"><a href="#note-ch6-19" aria-label="查看原书注释 19">[19]</a></sup>韩国方面则包括国史编纂委员会委员长李万烈，他坚持认为：“任何关于韩国的研究，都必须以热爱韩国为前提……只有对韩国怀有十分强烈的爱，日本历史学家才能开始正确理解韩国历史。”<sup class="footnote-ref" id="note-ref-ch6-20"><a href="#note-ch6-20" aria-label="查看原书注释 20">[20]</a></sup>这两位具有强烈民族主义倾向的历史学家，被安排在同一个分委员会中，促使不信任在其他参与者之间蔓延。因此，参与者的倾向构成了另一种机制，既可能促进，也可能阻碍对民族主义纪念的相互批评，因为这些倾向会因具体情境而影响历史学家之间的互动动态。简言之，由于参与者的倾向更为开放，非政府项目往往比政府项目更能按照世界主义逻辑，成功地纳入外国视角。

不过，考虑到非政府项目与倡议型活动的重叠，它们也有局限。以“面向未来的历史”项目为例。总体而言，参与这一三边项目的日本历史学家，不愿回避对韩国和中国历史版本中民族主义偏见的批评，而韩国和中国参与者也愿意纳入有关日本受害经历的描述，并质疑本国政府推广的官方历史版本。但日本参与者在同意《开启未来的历史》第三章第二节第一小节关于第二次中日战争的第一句话时，还是为了倡议而牺牲了学术严谨性：“1937年7月7日，日本军队在北京附近发动了卢沟桥事变。”这句话受到日本历史学界的严厉批评；日本历史学家依据现有证据，已经得出结论：日本军队并未策划这一事件。<sup class="footnote-ref" id="note-ref-ch6-21"><a href="#note-ch6-21" aria-label="查看原书注释 21">[21]</a></sup>一些日本历史学家还认为，《开启未来的历史》整体而言在学术上令人失望；另一些人则对其抱有疑虑，因为许多日本参与者属于左倾人士，先前曾参加支持日本过去错误行为的外国受害者的倡议活动。<sup class="footnote-ref" id="note-ref-ch6-22"><a href="#note-ch6-22" aria-label="查看原书注释 22">[22]</a></sup>

事实上，日本参与者之一齐藤一晴十分清楚，“轻率的跨界（安易な越境）”存在危险：“未能批判性地考察对话和团结的性质，［就］可能使共同历史教科书传播错误的理解。”<sup class="footnote-ref" id="note-ref-ch6-23"><a href="#note-ch6-23" aria-label="查看原书注释 23">[23]</a></sup>换言之，危险在于，如果日本方面只是向韩国和中国方面表达“轻率的”团结，并允许有问题的历史事实与解释存在，那么共同历史教科书项目“最终的使命……在各方克服狭隘的民族主义”，<span class="original-page-marker" id="page-161" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 161 页" title="原书第 161 页">原书第 161 页</span>就会受到损害。<sup class="footnote-ref" id="note-ref-ch6-24"><a href="#note-ch6-24" aria-label="查看原书注释 24">[24]</a></sup>反过来说，也不能过于急切地否定政府联合项目促成对民族主义纪念相互批评的潜力，因为最终解决卢沟桥事变描述争议的，正是日中联合项目：在最终报告中，日中双方的历史学家一致认为，日本与中国军队在卢沟桥发生的战斗，是偶然开始的。这使齐藤承认：“在这一点［关于卢沟桥事变］上，政府联合项目克服了非政府联合项目未能克服的障碍。”<sup class="footnote-ref" id="note-ref-ch6-25"><a href="#note-ch6-25" aria-label="查看原书注释 25">[25]</a></sup>

## 对民族主义纪念的相互批评

在观察了东亚这些联合项目后，德国 Georg Eckert 国际教科书研究所成员 Falk Pingel 提出了如下反思：“在东亚，只有日本教科书受到指责，韩国和中国教科书则免于批判性讨论。改革的要求单方面地指向日本，似乎不可能建立起开放的关系，进行相互批评，并批判性地反思本国历史。”<sup class="footnote-ref" id="note-ref-ch6-26"><a href="#note-ch6-26" aria-label="查看原书注释 26">[26]</a></sup>Pingel 的观察提供了一个重要提醒：日本方面轻率的团结，可能使任何联合项目质疑所有相关民族主义纪念的根本目的落空；但他的观察也低估了日本、韩国和中国历史学家已经在多大程度上开展了对民族主义偏见的相互批评。例如，“面向未来的历史”项目的日本参与者之一笠原十九司，一直公开批评中国历史教科书中的事实错误和民族主义纪念。笠原承认，日本公民未能充分纪念南京大屠杀，但他也敦促中国方面“从人类历史的更高视角，重建‘他们的情感记忆和身体记忆’”，追求更高的学术严谨性，摆脱出于政治和意识形态动机的历史解释。<sup class="footnote-ref" id="note-ref-ch6-27"><a href="#note-ch6-27" aria-label="查看原书注释 27">[27]</a></sup>

中国历史学家也开始与中国政府对亚太战争的官方纪念保持批判性距离。例如，2005年《开启未来的历史》第一版出版后，中国参与者受到许多国内批评，因为他们没有把南京大屠杀的遇难人数明确规定为三十万。但他们仍然坚持认为，<span class="original-page-marker" id="page-162" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 162 页" title="原书第 162 页">原书第 162 页</span>依据不同资料，遇难人数的估计各不相同。<sup class="footnote-ref" id="note-ref-ch6-28"><a href="#note-ch6-28" aria-label="查看原书注释 28">[28]</a></sup>正如都曾参加这一三边项目的程兆奇和张连红所解释的，近年来有关大屠杀的历史研究，情绪化程度已经降低，中国历史学家也日益认识到，要准确估计遇难人数，还需要更多证据。<sup class="footnote-ref" id="note-ref-ch6-29"><a href="#note-ch6-29" aria-label="查看原书注释 29">[29]</a></sup>

中国社会科学院近代史研究所所长步平证实了中国历史学家态度上的这些变化。他曾参加“面向未来的历史”项目及其他双边历史研究项目。在2008年4月于东京举行的一次国际研讨会上，步平指出：“此前，中国历史学家开展以中国为中心的研究，对中国之外可利用的历史资料和研究了解不足。但这一情况正在改变……虽然许多中国人认为，共享历史认识与和解是不可能的，但我们必须努力［实现它们］。”<sup class="footnote-ref" id="note-ref-ch6-30"><a href="#note-ch6-30" aria-label="查看原书注释 30">[30]</a></sup>此外，日中联合项目2010年的最终报告，因为没有把“三十万以上”规定为南京大屠杀受害者的确切人数而遭到批评后，步平为报告辩护，认为它体现了“严格依据历史资料［进行解释］的态度”；他强调，中日双方“汇集档案资料和信息”十分重要，并重申他相信“历史观可以、也应该超越国界”。<sup class="footnote-ref" id="note-ref-ch6-31"><a href="#note-ch6-31" aria-label="查看原书注释 31">[31]</a></sup>

同样，在2009年11月于东京举行的第八届东亚历史认识与和平论坛上，中国人民抗日战争纪念馆研究人员 Cao Yi 指出，鉴于近来系统搜集日本战时暴行资料的努力，中国对亚太战争的纪念已经开始超越“愤怒以及与受害者身份相连的其他情感”。<sup class="footnote-ref" id="note-ref-ch6-32"><a href="#note-ch6-32" aria-label="查看原书注释 32">[32]</a></sup>他进而提出：“中国应超越由对侵略者的愤怒和中国人民的利益驱动的轻率战争纪念。采用地理范围更广、时间跨度更长的视角，重新审视历史、中日关系的现实，以及战争和战争纪念，虽然痛苦，却会更加理性。但这正是我们应当追求的目标。”<sup class="footnote-ref" id="note-ref-ch6-33"><a href="#note-ch6-33" aria-label="查看原书注释 33">[33]</a></sup>Cao Yi 以及步平、程兆奇和张连红的这些表述显示，尽管存在中国政府的爱国主义教育和审查，中国历史学家近年来还是获得了更大的研究自由。

<span class="original-page-marker" id="page-163" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 163 页</span>

在韩国，参与“面向未来的历史”项目的非政府组织，也于2005年11月组织了一次论坛，批判性地反思他们刚刚编写完成的教科书。在论坛上，各方参与者指出，这本教科书可能过分强调了日本的帝国主义侵略，使韩国学生相信日本是一个邪恶国家；它也本可以更多地描述日本民众在战争中的苦难，以及日本历史的积极方面。<sup class="footnote-ref" id="note-ref-ch6-34"><a href="#note-ch6-34" aria-label="查看原书注释 34">[34]</a></sup>

事实上，少数但不断增多的韩国历史学家，已经开始用自己的批判性反思来对抗本国的民族主义纪念。2002年4月，韩国月刊《当代批评》发表了三篇文章，批判性地考察围绕日本历史教科书的韩国民族主义。Ji Su Geol 批评韩国近现代史研究中的族裔民族主义偏见，尹海东则主张，用允许编写多种历史教科书的新制度，取代国定历史教科书。该刊主编、汉阳大学历史学教授林志弦的批评或许最为尖锐：“韩国政府的国定历史教科书与新历史教科书编纂会的历史教科书相互冲突，是因为它们分别强调韩国和日本的族裔认同。从认识论层面看，它们扎根于同一片土壤——即族裔民族主义。”<sup class="footnote-ref" id="note-ref-ch6-35"><a href="#note-ch6-35" aria-label="查看原书注释 35">[35]</a></sup>

作为日韩历史学家会议（日韓歴史家会議）的成员，林志弦也对按国界划分受害者与加害者的倾向感到不安。在他看来，历史学家的任务是提出“一种挑战‘我们的民族是受害者，另一个民族是加害者’这一二分思维的方法”。<sup class="footnote-ref" id="note-ref-ch6-36"><a href="#note-ch6-36" aria-label="查看原书注释 36">[36]</a></sup>因此，林志弦坚持认为：“帝国主义和殖民主义历史经验的不对称，不应被简单地用来批评日本的民族主义历史书写，同时帮助韩国的民族主义历史书写取得正当性……解构民族主义历史书写，不能局限于一个国家，而必须在整个东亚同时进行。”<sup class="footnote-ref" id="note-ref-ch6-37"><a href="#note-ch6-37" aria-label="查看原书注释 37">[37]</a></sup>另一位会议成员、首尔大学历史学教授 Ahn Byung Jik 也担心，“韩国对日本殖民统治的记忆，过于僵化和封闭。［韩国与日本］和解的前提，是让这种记忆开放起来。

<span class="original-page-marker" id="page-164" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 164 页</span>

……为了和解，强行施加某一种特定历史观并无帮助。”<sup class="footnote-ref" id="note-ref-ch6-38"><a href="#note-ch6-38" aria-label="查看原书注释 38">[38]</a></sup>

一些韩国历史学家甚至尝试对“慰安妇”问题进行批判性反思；它也许是韩国民族主义纪念中最容易引爆争议的因素。其中一人是首尔大学经济史教授李荣薰。他长期批评韩国政府的历史教科书，其中包含许多言过其实的句子，例如：“日本帝国以一种在世界历史上找不到类似例子的、彻底残暴的方式，压迫和剥削我们的人民。”<sup class="footnote-ref" id="note-ref-ch6-39"><a href="#note-ch6-39" aria-label="查看原书注释 39">[39]</a></sup>在2004年9月的一次电视辩论中，李荣薰表示，尚未发现任何历史证据，能够支持这一广为流传的观点：日本军队征召朝鲜女性加入“挺身队”，让她们在慰安所服务。他还认为，韩国人不仅应批评日本，也应批评那些帮助日本军队招募“慰安妇”的朝鲜人，以及使用慰安所的朝鲜士兵。<sup class="footnote-ref" id="note-ref-ch6-40"><a href="#note-ch6-40" aria-label="查看原书注释 40">[40]</a></sup>电视辩论结束后，韩国挺身队问题对策协议会谴责李荣薰“发表只有日本最极端的右翼人士才会发表的言论”，要求他向前“慰安妇”公开道歉，并主动辞去大学教职。2006年12月，Ahn Byung Jik 也在电视上表示，没有历史证据证明朝鲜女性遭到强征，而朝鲜人在招募“慰安妇”的过程中发挥了重要作用，由此引发了类似争议。他还透露，自己已经退出韩国挺身队问题对策协议会搜集前“慰安妇”证言的出版项目，因为他觉得项目的其他成员“更感兴趣的是与日本斗争，而不是了解历史事实”。<sup class="footnote-ref" id="note-ref-ch6-41"><a href="#note-ch6-41" aria-label="查看原书注释 41">[41]</a></sup>与李荣薰一样，Ahn Byung Jik 受到韩国非政府组织和公民的严厉批评。

这些事件表明，在韩国，“慰安妇”问题仍然充满民族主义情绪；但它们也表明，对韩国民族主义纪念提出批判性问题，已经成为可能。这种纪念把日本描绘为使朝鲜人民蒙受苦难的唯一且完全有罪者，同时把朝鲜受害者的证言视为客观的历史真理。事实上，韩国挺身队问题对策协议会出版项目于2004年推出的第六卷，放弃了“被强行拖走的朝鲜军队慰安妇”这一标题。出版团队决定，不再沿用把<span class="original-page-marker" id="page-165" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 165 页" title="原书第 165 页">原书第 165 页</span>朝鲜“慰安妇”单一地表现为遭强行征召者的主流呈现方式，转而采用历史描述，突出“慰安妇”制度的复杂性、多种招募方式，以及不同类型的慰安所。<sup class="footnote-ref" id="note-ref-ch6-42"><a href="#note-ch6-42" aria-label="查看原书注释 42">[42]</a></sup>

## 历史学家对政府和公民的影响有限

由此，日本、韩国和中国历史学家，已经开始相互批评民族主义纪念。但历史学家实际上能在多大程度上影响三国政府和公民，则是另一回事。在这一方面，步平为中国方面不公开日中联合项目产生的部分论文和备忘录的决定辩护时，提出了一项敏锐的观察。他认为：“中日之间的历史问题具有三个层面：政治判断、民众情感和学术研究……这三个层面部分重叠，却从不完全重叠。如果某一个层面出现问题，就会影响另外两个层面。也就是说，如果我们想克服历史问题的一个层面，就必须考虑另外两个层面。”<sup class="footnote-ref" id="note-ref-ch6-43"><a href="#note-ch6-43" aria-label="查看原书注释 43">[43]</a></sup>换言之，即使历史学家——具有认识取向的扎根型世界主义者——开展了对民族主义纪念的相互批评，这些批评也不会直接转化为政府和公众纪念的改变，因为后两者各有自己的动态。因此，东亚历史学家虽然已经编写出各种联合研究报告和共同教材，对各自国家亚太战争纪念的影响却十分有限。

我认为，“历史学家的辩论”对历史问题影响有限，至少源于四个制度因素。第一个因素是，缺乏赋予历史学家批判性反思以权威、使其能够影响政府纪念的制度机制。参与日中联合项目的国际关系史学家波多野澄雄指出：“从日本政府的角度看，这个项目的首要目标，是把历史问题交给专家处理，使它‘去政治化’，以免干扰日本与中国在贸易、投资、自然资源和粮食安全等重要问题上的关系。”<sup class="footnote-ref" id="note-ref-ch6-44"><a href="#note-ch6-44" aria-label="查看原书注释 44">[44]</a></sup>同样，另一位参与者、中国近现代史学家川岛真认为，历史学家的联合项目“对解决历史问题的贡献非常有限，因为其目标主要在于防止这个问题政治化”。<sup class="footnote-ref" id="note-ref-ch6-45"><a href="#note-ch6-45" aria-label="查看原书注释 45">[45]</a></sup>由于政府联合项目<span class="original-page-marker" id="page-166" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 166 页" title="原书第 166 页">原书第 166 页</span>被“去政治化”——被仪式性地当作历史问题的“泄压机制”——它们不大可能改变现有的官方纪念。

与此同时，尽管存在去政治化的修辞，历史学家的角色仍可能被政治化。首相安倍晋三试图为自己2013年12月参拜靖国神社的行为辩护时，坚持认为，日本在亚太战争中行为的解释，应由历史学家而非政治家决定：“政治家在历史观问题上必须谦逊。政府不能把某一种特定历史观规定为正确的历史观。这个问题应交给历史学家。”<sup class="footnote-ref" id="note-ref-ch6-46"><a href="#note-ch6-46" aria-label="查看原书注释 46">[46]</a></sup>同样，在重新审视就军队“慰安妇”制度道歉的1993年《河野谈话》时，安倍的内阁官房长官菅义伟表示：“我们的内阁成员一致认为，这个［‘慰安妇’］问题不应成为政治和外交问题……我希望有更多学术研究不断积累。”<sup class="footnote-ref" id="note-ref-ch6-47"><a href="#note-ch6-47" aria-label="查看原书注释 47">[47]</a></sup>然而，安倍、菅义伟和其他保守派政治家，最可能欢迎的，只是淡化日本过去错误行为的历史研究。因此，当内阁府设立一个五人委员会，考察《河野谈话》的形成过程时，以保守倾向著称的秦郁彦，被任命为其中唯一的历史学家。<sup class="footnote-ref" id="note-ref-ch6-48"><a href="#note-ch6-48" aria-label="查看原书注释 48">[48]</a></sup>秦的任命实际上是政治性的：他以“不抱私利的专家”的面目，支持安倍政府的立场。<sup class="footnote-ref" id="note-ref-ch6-49"><a href="#note-ch6-49" aria-label="查看原书注释 49">[49]</a></sup>在这里，历史学家并没有真正被“去政治化”，而是战争纪念政治不可分割的一部分；掌权的政治家利用他们，谋求把自己的纪念立场正当化为“理性”的立场。

第二个因素是大众媒体的存在；媒体充当一种机制，中介历史学家的辩论对公众纪念的影响。正如历史学家 Tessa Morris-Suzuki 所指出的：“如今，我们比以往任何时候都更多地通过多种媒体了解过去”，例如报纸、电视节目和电影。<sup class="footnote-ref" id="note-ref-ch6-50"><a href="#note-ch6-50" aria-label="查看原书注释 50">[50]</a></sup>事实上，日本、韩国和中国的大多数公民，很可能主要通过媒体，而非历史学家及其学术成果，了解有关亚太战争的“事实”。但媒体公司考虑到读者和观众的政治倾向，不断对历史学家的辩论作有倾向性的处理。例如，村山政府于1994年8月筹备亚洲妇女基金时，《朝日新闻》报道，政府计划向前“慰安妇”支付一笔向日本公民募集的一次性“慰问金”，并刊登了前“慰安妇”支持者批评政府试图逃避责任的反应。

<span class="original-page-marker" id="page-167" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 167 页</span>

据基金推动者之一和田春树称，这则新闻报道淡化了村山政府意图表达的“赎罪”程度，将其降为“慰问”，削弱了一些内阁成员正在推动政府赔偿的努力，并在政府与前“慰安妇”及其支持者之间制造了不信任。<sup class="footnote-ref" id="note-ref-ch6-51"><a href="#note-ch6-51" aria-label="查看原书注释 51">[51]</a></sup>韩国大众媒体也很少呈现那些会与“日本拒不道歉”这一刻板印象相矛盾的信息和解释。<sup class="footnote-ref" id="note-ref-ch6-52"><a href="#note-ch6-52" aria-label="查看原书注释 52">[52]</a></sup>同样，中国大众媒体在2001年猛烈抨击新历史教科书编纂会的历史教科书，却未报道只有0.039%的初中采用了这本教科书。<sup class="footnote-ref" id="note-ref-ch6-53"><a href="#note-ch6-53" aria-label="查看原书注释 53">[53]</a></sup>因此，东亚历史问题的升级，在相当程度上要归因于三国的大众媒体：它们传播有关日本过去错误行为和日本政府举措的信息，而这些信息耸人听闻，却带有误导性，甚至遭到歪曲。<sup class="footnote-ref" id="note-ref-ch6-54"><a href="#note-ch6-54" aria-label="查看原书注释 54">[54]</a></sup>

第三个因素是，历史学作为学术专业的制度边界薄弱。正如社会学家 Andrew Abbott 和 Thomas Gieryn 所揭示的，任何“专家”，从核物理学家到历史学家，都不断从事“边界工作”，以区分自己与“非专家”，捍卫自己的“管辖权”，即对某些活动的认知权威。<sup class="footnote-ref" id="note-ref-ch6-55"><a href="#note-ch6-55" aria-label="查看原书注释 55">[55]</a></sup>这种边界工作可能包括建立专业协会、将标准培训计划编成制度，以及使特定的资料搜集和分析方法获得正当性。然而，历史学是人文社会科学中专家与非专家的区分高度模糊的领域之一；例如，许多地方历史学会由业余历史学家组织，而回忆录也有悠久传统，人们在其中充当自身生活的历史学家。归根结底，正如历史学家 James Banner 所说：“所有人，在记录和理解自身经历，评估他们认为与自己生活相关的过去的意义时，［都］在以历史学家的身份行动。”<sup class="footnote-ref" id="note-ref-ch6-56"><a href="#note-ch6-56" aria-label="查看原书注释 56">[56]</a></sup>由于叙事是过去的再现的构成要素，专业历史学家和业余历史学家都使用叙事，两者之间的区别更多体现为连续的差异，而非截然分立。<sup class="footnote-ref" id="note-ref-ch6-57"><a href="#note-ch6-57" aria-label="查看原书注释 57">[57]</a></sup>这使历史学成为人文社会科学中最具民主性的学科之一，但也妨碍专业历史学家有效地介入历史问题，纠正官方和公众纪念中事实上的不准确之处和缺乏根据的解释。

日本历史学家权威的薄弱，最明显地体现在20世纪90年代围绕“慰安妇”和<span class="original-page-marker" id="page-168" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 168 页" title="原书第 168 页">原书第 168 页</span>南京大屠杀的民族主义纪念升级的方式上。例如，韩国挺身队问题对策协议会宣称，日本政府强行征召朝鲜“女子挺身队”进入军队“慰安妇”制度，共有二十万朝鲜女性被迫从事这种工作。然而，连最同情她们的日本历史学家，包括吉见义明，以及一些韩国历史学家，都不赞同韩国挺身队问题对策协议会的这一说法。这些历史学家指出，女子挺身队和“慰安妇”是分别招募的，招募者中也有朝鲜人，而且有关朝鲜“慰安妇”人数的估计过高。<sup class="footnote-ref" id="note-ref-ch6-58"><a href="#note-ch6-58" aria-label="查看原书注释 58">[58]</a></sup>这些日本历史学家还建议，应仔细评估证言，因为一些前“慰安妇”证言的细节随着时间发生了变化。但韩国挺身队问题对策协议会拒绝改变自己的主张，甚至谴责七名前“慰安妇”：她们接受了亚洲妇女基金提供的赎罪金、医疗和福利援助，以及日本首相的道歉信。该协议会会长尹贞玉甚至声称：“接受没有附带认罪的钱款，受害者［这七名前‘慰安妇’］就承认了自己曾自愿成为妓女。”<sup class="footnote-ref" id="note-ref-ch6-59"><a href="#note-ch6-59" aria-label="查看原书注释 59">[59]</a></sup>

在南京大屠杀的问题上，张纯如的《南京大屠杀》也激发了美国公众，尤其是华裔美国人的强烈反响。但专门研究中国近现代史的日本和美国历史学家批评张纯如的书，指出其中存在大量不准确之处，处理历史证据也不谨慎。斯坦福大学历史学教授 David Kennedy 怀疑张纯如这一主张的有效性：南京大屠杀是一个系统性的种族灭绝计划，可以与纳粹大屠杀相比。加利福尼亚大学圣巴巴拉分校历史学教授 Joshua Fogel 则批评该书未能仔细考量她作为“历史证据”呈现的访谈和文件的可信度，并错误地把这场大屠杀描述为已被日本公民彻底遗忘。<sup class="footnote-ref" id="note-ref-ch6-60"><a href="#note-ch6-60" aria-label="查看原书注释 60">[60]</a></sup>笠原十九司也曾当面请张纯如在解释现有档案资料时更加谨慎。<sup class="footnote-ref" id="note-ref-ch6-61"><a href="#note-ch6-61" aria-label="查看原书注释 61">[61]</a></sup>

尽管张纯如的书存在各种问题，左倾出版公司柏书房还是计划把它译成日文，因为该公司相信，南京大屠杀的细节应当在日本获得更广泛的了解。然而，当柏书房要求张纯如纠正书中各种错误和不准确之处时，她只同意<span class="original-page-marker" id="page-169" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 169 页" title="原书第 169 页">原书第 169 页</span>作出大约十几处小修改。此外，柏书房提议将该书日文版与一本评论文集配套出版，文集将批判性地评估书中的证据和论点；张纯如拒绝了这一提议。<sup class="footnote-ref" id="note-ref-ch6-62"><a href="#note-ch6-62" aria-label="查看原书注释 62">[62]</a></sup>最终，柏书房放弃了《南京大屠杀》的日文翻译，因为公司担心，该书的严重缺陷只会给日本民族主义者提供更多弹药，让他们把南京大屠杀污蔑为捏造。<sup class="footnote-ref" id="note-ref-ch6-63"><a href="#note-ch6-63" aria-label="查看原书注释 63">[63]</a></sup>柏书房转而出版了《南京大屠杀否认论的十三个谎言》（南京大虐殺否定論13のウソ）。该书由藤原彰、笠原十九司、吉田裕等一批著名历史学教授撰写，他们专门研究日本在中国的战时暴行；出版它是为了“反驳日本的南京大屠杀否认论，这种否认论因为张纯如书中大量事实错误而再度兴起”。但张纯如从未撤回她的主张：至少三十万中国人在南京城墙以内遭到屠杀，这是日本种族灭绝计划的一部分。

日本的保守派非政府组织，尤其是新历史教科书编纂会，抓住了韩国挺身队问题对策协议会、张纯如，以及其他支持韩国和中国受害者的倡议者提出的这些有问题的主张。它们援引自己同样存在问题的客观真理版本，把亚太战争正当化为英勇的自卫行为。事实上，它们甚至挑战那些维护“慰安妇”制度和南京大屠杀之历史真实性的专业历史学家。尤其是新历史教科书编纂会成员之一藤冈信胜，宣布“专家的时代已经结束”，并认为：“普通人一直误以为，只有历史学家，即历史专家，才能知道如何解释历史。但历史学所考察的事实，最接近普通人的常识，因此普通人可以依据自己的常识评判历史研究……即使是业余人士，只要运用自己健全的理性，也能反驳历史学家歪曲的论点。”<sup class="footnote-ref" id="note-ref-ch6-64"><a href="#note-ch6-64" aria-label="查看原书注释 64">[64]</a></sup>

因此，在“慰安妇”和南京大屠杀问题上，非历史学家对专业历史学家提出的问题置之不理。尹贞玉并非专业历史学家，而是英语教授。张纯如也并非专业历史学家，而是记者。新历史教科书编纂会的两位创始成员藤冈信胜和西尾干二，同样不是专业历史学家。他们都是大学教授，但分别专攻课程研究和德国文学。另一位编纂会成员东中野修道，也是大学教授，但他的专业是日本思想史。尤为突出的是，<span class="original-page-marker" id="page-170" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 170 页" title="原书第 170 页">原书第 170 页</span>小林善纪曾凭借其《战争论》漫画系列，一度成为新历史教科书编纂会最受欢迎的成员；他是一名漫画家，大学期间主修法国文学。然而，尹贞玉、张纯如及编纂会成员提出的有问题的事实主张，压过了那些终其学术生涯研究日本过去错误行为的日本历史学家谨慎而富于反思的声音。

归根结底，专业历史学家与业余历史学家之间区分的模糊，只是一个更大、更根本问题的一部分：历史书写与纪念作为两种相互重叠的过去再现方式，究竟是什么关系？这是限制历史学家影响的第四个制度因素。<sup class="footnote-ref" id="note-ref-ch6-65"><a href="#note-ch6-65" aria-label="查看原书注释 65">[65]</a></sup>长期以来，历史学家和集体记忆研究者，一直争论“历史”与“记忆”的关系。起初，许多历史学家和社会学家清楚地区分二者，将历史定义为“理性”和“客观”，与作为“非理性”和“主观”的记忆相对。然而，围绕纳粹大屠杀历史再现的争议、后现代主义对“客观历史事实”的挑战、人们对“底层历史”存在的认识不断增强，以及对口述史和其他新方法的接受，使越来越多历史学家开始认识到，他们的学术研究具有各种认识论上和政治上的局限。<sup class="footnote-ref" id="note-ref-ch6-66"><a href="#note-ch6-66" aria-label="查看原书注释 66">[66]</a></sup>因此，如今多数历史学家和集体记忆研究者，只把历史书写和纪念视为两种不同的过去叙述方式，其中一种并不在认识论上优于另一种。

从这一方面说，历史书写与纪念构成了 Paul Ricoeur 所说的真正“开放的辩证关系”，因为它们之间的对立，永远无法被超越并综合为关于过去的更高真理。<sup class="footnote-ref" id="note-ref-ch6-67"><a href="#note-ch6-67" aria-label="查看原书注释 67">[67]</a></sup>换言之，它们形成一种对话的、共生的关系，彼此相互构成，也相互改变。正如历史学家 Aleida Assmann 所解释的：“历史学术不仅在口头证言和经验方面依赖记忆，也在意义和相关性的判断标准方面依赖记忆；另一方面，记忆则依靠历史学术进行核实、证实和证伪。”<sup class="footnote-ref" id="note-ref-ch6-68"><a href="#note-ch6-68" aria-label="查看原书注释 68">[68]</a></sup>因此，专业历史学家难以援引自己的认知权威，为历史问题作出最终定论，因为政治家和公民拥有自己的记忆，而这些记忆的认识论有效性标准，不同于历史学家的标准。更糟的是，历史学家很可能被创伤性事件的记忆压倒，例如东亚历史问题中的战时暴行，因为创伤性事件的纪念往往如此充满情感，以至于人们<span class="original-page-marker" id="page-171" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 171 页" title="原书第 171 页">原书第 171 页</span>常常会过度认同受害者，变得无法察觉现有证据中的不一致、遗漏和矛盾。<sup class="footnote-ref" id="note-ref-ch6-69"><a href="#note-ch6-69" aria-label="查看原书注释 69">[69]</a></sup>

与纪念相比，历史书写的异质性，使历史学家面临的困难更加复杂。正如“历史学家的辩论”这一说法所表明的，争论，而不是共识，才是历史学家的常态。当不同历史学家对同一历史事件坚持相互竞争的解释时，相互竞争的政治行动者群体，就可以利用这些解释，为各自偏好的纪念立场提供正当性。在这种情况下，历史学家无法仲裁相互竞争的纪念。相反，他们为每一种纪念立场提供可信度，反而可能加剧竞争。

## 东亚的历史教育问题

此外，东亚历史教育的两个特点，使历史学家的辩论对政府和公众纪念影响有限的局面进一步恶化；这两个特点妨碍年轻世代发展批判性反思历史问题的能力。第一个特点是过分重视记诵。由于中等和高等教育的入学考试竞争极其激烈，且主要采用选择题，日本、韩国和中国学生从小学到高中，都被要求吸收大量知识。因此，中小学历史教育迫使学生记住重要历史事件的日期和著名历史人物的姓名，为考试做准备。这种以记诵为基础的历史教育，往往给人一种印象：历史是一个具有清楚明确答案、适合采用选择题的领域。这会误导学生，使他们把某一种过去的版本当作客观真理接受。由此，学生失去了发展必要认知技能的机会，无法学会权衡相互冲突的历史证据，并在相互竞争的解释之间作出判断——而这正是处理历史问题所需要的认知技能。<sup class="footnote-ref" id="note-ref-ch6-70"><a href="#note-ch6-70" aria-label="查看原书注释 70">[70]</a></sup>

尤其在日本，中小学教育对近现代史覆盖有限，使历史教育的这些缺陷进一步放大。日本历史教科书用相当大的篇幅讲述1868年明治维新之前的古代史，却只简略涉及日本对韩国和中国实施侵略与暴行的20世纪。关于20世纪的课程，通常也安排在学年末，<span class="original-page-marker" id="page-172" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 172 页" title="原书第 172 页">原书第 172 页</span>那时师生都忙于准备毕业典礼和入学考试，结果学生对这一历史时期只能获得匆忙而肤浅的了解。事实上，日本政府有意限制学校教授日本近现代史，恰恰是因为这一历史时期处于历史问题的核心。例如，2005年8月，时任外务大臣、曾任文部大臣的町村信孝承认，文部省建议学校尽量减少日本近现代史的教学，以防一些“马克思列宁主义教师”，尤其是日本教职员工组合成员，向学生灌输对日本的自我憎恶。<sup class="footnote-ref" id="note-ref-ch6-71"><a href="#note-ch6-71" aria-label="查看原书注释 71">[71]</a></sup>

然而，町村的立场不仅反映了自民党对日本教职员工组合长期以来的反感，也点出了日本历史教师教学倾向中的一个重要问题。对日本教职员工组合的教师而言，“决不再把我们的孩子送上战场！”是他们最重要的口号；这与东京审判史观相一致，不容许为日本过去的侵略提供任何辩护。<sup class="footnote-ref" id="note-ref-ch6-72"><a href="#note-ch6-72" aria-label="查看原书注释 72">[72]</a></sup>因此，日本教职员工组合的教师强烈批评保守派政府，反对它推动把日本过去的侵略呈现为英勇自卫行为的民族主义纪念。但与此同时，日本教职员工组合的教师，以及一般的日本教师，都在现有日本教育制度中接受训练，而在这一制度中，历史教育以记诵为基础。因此，他们并不总能向自己的学生提供鼓励批判性评估历史证据和解释的那种历史教育。虽然占领时期的教育改革，把历史教育的重点从以天皇为中心的民族主义转向和平主义，日本历史教育的基本结构——对记诵的强调——并未改变。

因此，日本战后的历史教育被两股截然相反的力量拉扯：保守派政府推动对亚太战争的民族主义纪念，而日本教职员工组合的教师则推动东京审判史观，认定日本对战争负有唯一且全部的罪责。为了预先避免有关如何教授日本近现代史的争议，文部省决定减少历史教科书对20世纪的覆盖，并在历史课程中强调按时间顺序展开的、经验主义的方法。<sup class="footnote-ref" id="note-ref-ch6-73"><a href="#note-ch6-73" aria-label="查看原书注释 73">[73]</a></sup>由于日本历史教育继续淡化近现代时期，并强调记诵，多数日本公民都没有充分准备好，就亚太战争与本国同胞，或与韩国和中国公民，开展建设性的辩论。

<span class="original-page-marker" id="page-173" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 173 页</span>

韩国和中国的历史教育情况也并没有很大不同。由于韩国学生必须积累大量知识，以竞争大学入学机会，该国历史教育也以记诵为重心。<sup class="footnote-ref" id="note-ref-ch6-74"><a href="#note-ch6-74" aria-label="查看原书注释 74">[74]</a></sup>同样，虽然中国各省的学校课程存在差异，而且近几十年来变化迅速，中国历史课堂仍然十分重视记诵历史事件，并强调这些事件在道德和意识形态上的含义。<sup class="footnote-ref" id="note-ref-ch6-75"><a href="#note-ch6-75" aria-label="查看原书注释 75">[75]</a></sup>因此，日本、韩国和中国的教育制度具有共同倾向：把某些过去的版本作为客观真理呈现给学生，而不是把它们作为暂时确立、允许未来修订的解释。正如教育研究者 Edward Vickers 所警告的，在东亚，“推行一种真正鼓励以批判态度看待过去的教学方法，前景很可能仍然不佳”。<sup class="footnote-ref" id="note-ref-ch6-76"><a href="#note-ch6-76" aria-label="查看原书注释 76">[76]</a></sup>如果三国年轻世代继续接受以记诵为基础的历史课程，历史问题就仍有风险，可能升级为围绕不可通约的过去版本而展开的难解冲突。

但归根结底，东亚历史教育的根本问题，并不在于重视记诵本身，而在于政府能够通过教科书审定控制历史课堂的内容。在日本、韩国和中国，教师只能使用本国教育部门批准的历史教科书。在这些教科书审定制度之下，教科书作者和出版商在形式上拥有决定历史教科书结构与内容的自由。但由于课程纲要具有法律约束力，许多作者和出版商被迫实行自我审查。<sup class="footnote-ref" id="note-ref-ch6-77"><a href="#note-ch6-77" aria-label="查看原书注释 77">[77]</a></sup>毕竟，政府有权要求按课程纲要修改教科书，由此对历史教科书施加重大控制——几乎等同于审查。<sup class="footnote-ref" id="note-ref-ch6-78"><a href="#note-ch6-78" aria-label="查看原书注释 78">[78]</a></sup>因此，历史教科书决定性地影响着公民的历史观，正如家永三郎所认识到的：“任何畅销书都比不过教科书。其他书如果你不喜欢，可以不读。但为了从学校毕业，教科书无论你喜欢与否都必须读。因此，我认为，对于政府影响公民的思想而言，教科书是一种比治安法律更加有效的手段。”<sup class="footnote-ref" id="note-ref-ch6-79"><a href="#note-ch6-79" aria-label="查看原书注释 79">[79]</a></sup>

具体而言，日本政府坚持认为，历史教科书只应包含“事实”，而不应包含解释或争论。<sup class="footnote-ref" id="note-ref-ch6-80"><a href="#note-ch6-80" aria-label="查看原书注释 80">[80]</a></sup>例如，政府对家永诉讼的反驳就是如此。1980年，在东京高等法院，政府指责家永“没有区分历史学与历史教育……在义务<span class="original-page-marker" id="page-174" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 174 页" title="原书第 174 页">原书第 174 页</span>教育阶段，历史教育不会达到专门学术研究的水平。它的目标，是向学生提供日本公民应当具备的基本历史知识……历史教科书应依据学界广泛接受的学说撰写……教科书作者应考虑学生的发展阶段。”<sup class="footnote-ref" id="note-ref-ch6-81"><a href="#note-ch6-81" aria-label="查看原书注释 81">[81]</a></sup>因此，政府认为，不应把历史学家的辩论引入历史教育，因为后者的最终目标是教育日本民族的成员，而不是训练历史学家。

然而，政府的反驳存在两个严重问题。首先，正如支持家永的历史学教授远山茂树所指出的：“基础性的历史问题，要求理解复杂交织的历史事实，必然会使历史学家作出自己的历史判断。在这些问题上，不同学说之间的分歧尤其强烈。”<sup class="footnote-ref" id="note-ref-ch6-82"><a href="#note-ch6-82" aria-label="查看原书注释 82">[82]</a></sup>换言之，如果历史教科书只能包含那些历史书写争论已经定论的过去描述，它们就必然会变得简短，因为它们无法提供重要历史事件的细节，其中许多仍然存在争议——事实上，日本历史教科书确实非常薄。政府要求只向学生教授已经确立的历史事实，使日本公民无法发展批判而独立地解释艰难过去的能力。

第二个、更严重的问题是，日本政府假定，学生还不够成熟，无法处理相互冲突的解释。远山再次为家永辩护道：

> 我们不应让儿童和青少年惧怕分歧。我们希望学生知道，通过与持不同想法的人对话，他们可以检验并完善自己的想法。如果公民都只会不加批判地服从政府的决定，民主就会遭到摧毁。文部省认为，小学、初中和高中学生没有形成自己判断的能力。但这一论点建立在错误认识之上。如果我们精心准备教学材料，学生就会展现出形成自己判断的惊人能力。<sup class="footnote-ref" id="note-ref-ch6-83"><a href="#note-ch6-83" aria-label="查看原书注释 83">[83]</a></sup>

因此，远山批评历史学与历史教育之间人为的分离，认为政府试图借助历史教育<span class="original-page-marker" id="page-175" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 175 页" title="原书第 175 页">原书第 175 页</span>培养顺从的公民。另一位历史学教授、家永的支持者永原庆二，对这种分离提出了更有力的批评，认为它令人想起战前的制度：该制度“把历史教育与历史学脱钩，推动爱国的、精神主义的历史教育”。<sup class="footnote-ref" id="note-ref-ch6-84"><a href="#note-ch6-84" aria-label="查看原书注释 84">[84]</a></sup>

家永的诉讼虽然帮助历史教科书增加了对日本过去错误行为的描述，但最终未能废除教科书审定制度本身。此外，通过诉诸诉讼，家永及其支持者制造了一种悖论局面：历史学家被迫放弃在同行内部裁断相互竞争的历史判断的专业权威，转而允许并非历史专家的法官，以司法判决的形式撰写官方历史。家永确实意识到了这种悖论局面，以及自己的诉讼带来的负面影响。因此，在1997年8月最高法院判决之后，家永表示：“我希望教科书诉讼运动继续发展，最终废除教科书审定制度本身。我真心希望下一代能够做到这一点。”<sup class="footnote-ref" id="note-ref-ch6-85"><a href="#note-ch6-85" aria-label="查看原书注释 85">[85]</a></sup>在这里，家永的长期斗争和持久希望，同样与韩国和中国的历史学家及教育工作者相关，因为在这两个国家，教科书的编写受到政府更加严格的管制。

因此，尽管近几十年来大众媒体的作用日益增强，东亚政府由于拥有界定并强加关于过去的正当版本的权力，仍然是推动历史问题动态和发展轨迹的最重要行动者。<sup class="footnote-ref" id="note-ref-ch6-86"><a href="#note-ch6-86" aria-label="查看原书注释 86">[86]</a></sup>只要日本、韩国和中国政府继续通过课程纲要和审定制度控制历史教科书，获得官方批准的历史教科书就会继续教授以民族国家为中心的历史：日本历史教科书仅以极少篇幅描述日本过去的错误行为，而韩国和中国的历史教科书则根据抗日抵抗的历史遗产，推动爱国主义。与此同时，由于非政府联合项目编写的教材，没有一种能够通过政府审定，它们在学校中只能作为非正式的补充材料使用，因此无法充分地把历史学家的批判性反思引入历史教育。简言之，正如小菅信子所指出的：“在解决历史问题、走向和解的过程中，最紧迫的任务之一，就是‘使历史历史化（歴史の歴史化）’。东亚的问题，是一种不容许历史的历史化、不容许历史解释多元性的政治，即支持并再生产有关昔日敌人之刻板印象的政治。”<sup class="footnote-ref" id="note-ref-ch6-87"><a href="#note-ch6-87" aria-label="查看原书注释 87">[87]</a></sup>

<span class="original-page-marker" id="page-176" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">原书第 176 页</span>

## 从历史学家的辩论到世界主义纪念

从理论上说，历史学家有潜力影响东亚历史问题的动态和发展轨迹，原因有二。其一是他们在历史问题场域中的独特地位。历史学家虽然能够参加倡议活动，像场域中的其他政治行动者一样行动，但他们主要作为“不抱私利的他者”活动，为其他政治行动者提供历史资料，帮助后者阐明自己的纪念立场。另一个原因，是该地区人口构成的变化。由于亚太战争结束后出生的人，如今已经成为日本、韩国和中国的人口多数，他们的纪念必然要依靠历史学家提出的证据和解释。在这一历史关口，越来越多的历史学家参与联合研究和教育项目，形成作为世界主义基础设施的跨国认识共同体：他们把外国视角纳入历史叙述，并以跨国互动为分析单位。这种在跨国层面不断发展的历史学家辩论，提供了一种潜力：它可以质疑日本、韩国和中国的民族主义纪念，并推动场域中的其他政治行动者采取更具世界主义性质的立场。

但在实践中，历史学家辩论的世界主义潜力受到各种约束。首先，不存在使历史学家的联合项目能够有效影响日本、韩国和中国官方纪念的制度化渠道。此外，另外两个因素也削弱了历史学家有效影响政府和公民的能力。其一是，历史学家的学术成果几乎总是经由大众媒体中介，而媒体愿意为了耸人听闻而牺牲准确性。其二是，历史书写与纪念作为两种相互重叠且同样正当的过去叙述方式并存，使历史学家对非历史学家只拥有薄弱的权威。尤其是在东亚历史问题中，涉及的历史事件极其复杂且充满情感，历史学家自身也卷入了证据与解释的争论，他们的历史书写很容易被民族主义纪念置之不理。历史学家作为扎根型世界主义者的潜力，还受到他们的辩论与历史教育脱节的进一步削弱；这种脱节由各国政府制造，因为政府急于把历史课程用作对公民的道德教育。

因此，在东亚，历史学家的辩论帮助公民批判性反思其民族主义纪念的世界主义潜力，尚未得到充分<span class="original-page-marker" id="page-177" style="display:inline;font-size:0;width:0;scroll-margin-top:96px;" aria-label="原书第 177 页" title="原书第 177 页">原书第 177 页</span>实现。结果，日本、韩国和中国依然困在历史问题之中。George Santayana 的格言“一个不记得历史的人，注定要再度经历它”，理所当然地广为人知，但按照民族主义逻辑记忆亚太战争，很可能会导致未来重演类似的悲剧。为确保三国公民不会“再度经历它”，有没有办法有效地运用历史学家的批判性反思，使相关政治行动者的纪念立场转向更具世界主义性质的方向？下一章将考察这一问题。

# 关于作者

<span class="original-page-marker" id="page-280" style="display:block;margin:1.5em 0 .5em;color:var(--vp-c-text-3);font-size:12px;scroll-margin-top:96px;">书后作者简介（PDF 第 293 页）</span>

Hiro Saito 是新加坡管理大学社会学助理教授。他在国际基督教大学取得学士学位，在密歇根大学取得博士学位。此前，他曾在夏威夷大学马诺阿分校教授社会学，并曾在东京大学社会科学研究所和哈佛大学美日关系研究项目担任博士后研究员。他关于集体记忆、民族主义和世界主义的研究，发表于其领域内的领先期刊，包括 *Sociological Theory*、*Global Networks* 和 *Cultural Sociology*。

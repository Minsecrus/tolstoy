# 第三部分导言：线性代数与表示

<span class="original-page-anchor" id="pdf-page-511" aria-hidden="true"></span>

我们将讨论模与向量空间，从各个角度深入考察它们的结构。这里的主要主题是研究由一个模及一个自同态（或一个自同态环）组成的对，并尝试把这个对分解为若干分量的直和，进而明确描述各个分量的结构。直和这一主题会在每一章中反复出现。有时，我们利用对偶性，针对一个配对得到直和分解；有时则直接得到分解。如果一个模无法分解为简单分量的直和，就只能应用格罗滕迪克构造，看看能够从中得到什么。

延拓这一主题只在维特定理中出现一次，与分解这一主题形成一段简短的对位。

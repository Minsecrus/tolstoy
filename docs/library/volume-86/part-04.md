# 第四部分导言：同调代数

<span class="original-page-anchor" id="pdf-page-767" aria-hidden="true"></span>

在二十世纪四十年代和五十年代，人们主要通过 Cartan、Eilenberg、MacLane 和 Steenrod 的工作（见 [CaE 57]），认识到线性代数中的某些关系可以用一种系统的方法来发展。这种方法只依赖于相当一般的构造，而这些构造大多着眼于箭头之间的关系，Steenrod 亲切地称之为**抽象的一般原理**（abstract nonsense）。（较新的教材可参见 [Ro 79]。）这些成果形成了一套代数，其中一部分涉及同调代数；它们起源于拓扑学、代数学、偏微分方程和代数几何。在拓扑学中，其中一些构造已被用于得到拓扑空间的同调群和上同调群，例如 Eilenberg-Steenrod [ES 52] 中的做法。在代数学中，因子集和 1-余循环出现在群扩张理论以及例如希尔伯特定理 90 中。近来，同调代数也进入了群的上同调以及群的表示论。可参见 Curtis-Reiner [CuR 81]，以及任何一本关于群上同调的书，例如 [La 96]、[Se 64] 和 [Sh 72]。注意，[La 96] 的写作是为了给 [ArT 68] 中的类域论提供背景。

从一个完全不同的方向出发，Leray 在偏微分方程的启发下发展了层和谱序列理论。层的基本理论在 Godement 关于这一主题的著作 [Go 58] 中有所论述。Grothendieck 在同调代数方面也提出了基本的见解 [Gro 57]，并在五十年代和六十年代将其应用于概形上的层理论。在第二十章中，我收录了 Hartshorne 在 [Ha 77] 中所需的同调代数内容。第二十章和第二十一章都为 Griffiths-Harris [GrH 78] 第 5 章（特别是 §3 和 §4）以及 Gunning [Gu 90] 所用的同调代数提供了适当的背景。第二十章发展导出函子的一般理论。习题和第二十一章则可以看作针对一些更为专门的具体情形提供实例与计算。

<span class="original-page-anchor" id="pdf-page-768" aria-hidden="true"></span>

第十章的交换代数，以及第四部分中关于同调代数的两章，也为代数几何中的某些主题提供了适当的背景，例如 Serre 对相交理论的研究 [Se 65]、Grothendieck 对偶性，以及代数几何中的 Grothendieck 黎曼—罗赫定理。可参见 [SGA 6]。

最后，我想提请读者注意同调代数在偏微分方程某些领域中的应用，例如 Atiyah-Bott-Patodi 和 Atiyah-Singer 关于椭圆算子复形的论文。读者可以通过 [ABP 73] 中给出的参考文献追溯一部分相关文献。

本部分内容的选择，在很大程度上受到上述各种应用的推动。

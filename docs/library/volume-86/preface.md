# 前言

<span class="original-page-anchor" id="pdf-page-6" aria-hidden="true"></span>

本书旨在作为研究生阶段一年制代数课程的基础教材。

### 对代数的看法

在我看来，研究生代数课程的首要任务，是使学生做好准备，能够处理他们在数学各个领域中将会遇到的代数：拓扑学、偏微分方程、微分几何、代数几何、分析以及表示论，更不用说代数本身，以及分支繁多的代数数论了。因此，我在全书各处加入了对近几十年来发表的论文和著作的引用，以说明本书所提供的代数基础应用于哪些方向；在这些引用之外，我还附上了一些说明动机的评述，解释本书的各个主题如何融入随后将在各领域中学到的数学；我也提及了代数和数论中若干尚未解决的数学问题。其中，$abc$ 猜想也许是最引人注目的一个。

当这些评述和例子偏离逻辑顺序时，尤其是当例子来自数学的其他分支时，有些术语不可避免地尚未定义，或者要到本书后面才定义。为了帮助读者，我不仅在书内给出了交叉引用，还明确引用了其他著作或论文。

我也增添了若干习题。总体而言，我努力使习题成为例子的补充，并使它们具有美感。我还希望借助习题，引导读者研究正文内容的变式和应用，求解特殊情形，并由此走向本书以外的应用。

### 结构安排

遗憾的是，一本书必须沿着页码这条轴，按照一个全序展开，但数学本身的“存在方式”并非如此。因此，读者必须自行作出选择，把某些主题重新安排成并行的学习内容，而不只是依次学习。

<span class="original-page-anchor" id="pdf-page-7" aria-hidden="true"></span>

我加入了交叉引用，以帮助读者这样做；但不同的人在不同的时间，会根据不同的情况作出不同的选择。

本书自然分为几个部分。第一部分介绍代数的基本概念。在这些基本概念之后，本书沿着两个主要方向展开：一是第二部分中代数方程的方向，其中包括伽罗瓦理论；二是第三、第四部分中线性代数与多重线性代数的方向。二者之间偶尔会相互反馈，但它们的统一是在下一层次的数学中实现的，例如第 VI 章第 15 节便对此有所提示。事实上，对有理数域的代数扩张的研究，可以从两个互补而又相互联系的观点来进行：将其代数闭包的伽罗瓦群表示到矩阵群中（线性的方法），以及明确确定生成代数扩张的无理量（方程的方法）。目前，取值于 $GL_2$ 的表示受到各方面的关注，读者也会在本书中多次见到 $GL_2$。例如，我认为有必要增添一节，描述当 $F$ 为有限域时 $GL_2(F)$ 的全部不可约特征标。最终，$GL_2$ 将作为李型群中最简单而又典型的情形出现；这类群既出现于微分的背景中，也出现于有限域或更一般的算术环上，以供算术方面的应用。

距离第二版出版已近十年，我发现代数的基本主题已经稳定下来，只有一个例外。我增添了关于消去理论的两节，作为原有结式一节的补充。代数几何在许多方面取得进展之后，如今有时又回到一些更古老、更困难的问题，例如寻找有效方法，构造在某些代数集上为零的多项式；上个世纪较早的消去过程，可以作为这些问题的入门。

除这一增补之外，本书的主要主题与第二版相比没有改变，但我尝试从几个方面改进本书。

首先，我重新安排了一些主题的次序。读者和审阅者使我意识到，两种目标之间存在一种张力：一方面要使教材适用于经验相对不足的学生，另一方面又要使它成为一本编排系统、能够方便查找结果的参考书。我尝试通过以下方式减轻这种张力：将所有同调代数的内容移到第四部分，并将交换代数与关于代数集和消去理论的那一章结合起来，从而介绍通向代数几何的不同观点。

### 本书作为教材和参考书

讲授这门课程时，可以沿着第二部分深入研究代数方程，也可以选择先进入第三、第四部分的线性代数。例如，可以为这两个方向各安排一个学期。在各章的写法上，我尽可能使这种安排具有最大的灵活性；我也常常犯下“冒犯布尔巴基”之罪，重复一些简短的论证或定义，以使某些节或章在逻辑上彼此独立。

<span class="original-page-anchor" id="pdf-page-8" aria-hidden="true"></span>

除了那些在基础课程中无论如何都不能省略的内容之外，还可以作出多种选择，使课程沿着不同的方向展开。要以同样的深入程度处理所有这些方向，是不可能的。在任何一个给定方向上，究竟愿意讲到哪里为止，取决于时间、地点和心境。然而，任何一本以本书目标为目标的书，都必须选取一些主题，继续向前，进入更深的水域，同时又在全面涉入之前止步。

在这些问题上，不可能有普遍一致的意见，甚至作者与他自己也不例外。因此，具体收入什么、略去什么，最终是根据整体的连贯性和美学上的平衡来决定的。任何讲授这门课程的人，都会希望在这些材料中体现自己的个性；他们可能比我更用力地推进某些主题，同时相应减少其他主题的篇幅。本书的任何内容都无意限制这种做法。

遗憾的是，为了呈现一个相当全面的代数视野，从第一版到第二版，本书的篇幅不得不大幅增加；到了这第三版，篇幅又有适度增加。篇幅的增加，要求我们就一门具体课程中应省略哪些内容作出决定。

在讲述这些主题时，可以采取许多捷径，也容许许多不同的安排。例如，在给出群、环、域、一元多项式和向量空间的基本定义后，就可以立即进入域论和伽罗瓦理论。由于伽罗瓦理论很快就能使人体会到深度，这种安排在许多方面都很令人满意。

这里也应提及我最初所受惠的 Artin，是他最先教我代数。我对伽罗瓦理论基础的处理，很大程度上受到他自己那部专著的叙述方式的影响。

### 读者与背景

正如我在前几版的前言中已经说明的，本书面向研究生层次；我期望大多数读者已经在本科课程中适当地接触过一些代数，或者具备相应的数学成熟程度。我期望修读研究生课程的学生已经接触过向量空间、线性映射和矩阵；而多项式，他们无疑至少在微积分课程中已经见过。

我的《本科代数》（*Undergraduate Algebra*）和《线性代数》（*Linear Algebra*）两本书，足以为研究生课程提供绰绰有余的背景。这类初等教材并行地展现代数的两个基本方面，其组织方式与本书不同；在本书中，这两个方面都得到了深化。当然，本书第三部分的线性代数中，有些内容比第二部分中的某些内容更“初等”；第二部分讨论的是伽罗瓦理论和多元多项式方程理论。由于第二部分对代数方程的研究更为深入，与之并行的线性代数在全书的全序安排中，就只能出现在较后的位置。读者应当把这两个部分看作同时展开的。

<span class="original-page-anchor" id="pdf-page-9" aria-hidden="true"></span>

遗憾的是，为了获得适当的背景，一个人在这第一年中理想情况下应当掌握的代数内容，无论最终专攻哪个领域，都超过了一位教师在一年制课程中实际上能够讲授的内容。因此，书中必须收入比课堂上实际能够处理的更多的材料。我认为，让研究生注意到这些材料是十分必要的。

我希望这些增补和修改，能使本书更便于用作教材。我试图通过这些增补，在代数与数学其他部分的联系方面，拓展读者的整体数学视野。

### 关于 2002 年及以后由 Springer 印行的版本

从现在起，《代数》将与我的其他著作一样，由 Springer-Verlag 出版。随着这一改变，我考虑过推出新版的可能性，但决定不这样做。我认为本书已经十分稳定。倘若从头开始，我唯一会增添的内容，是第 XIII 章中单纯性的证明之外，$SL_n$ 和 $GL_n$（在 $\mathbf{R}$ 或 $\mathbf{C}$ 上）的某些代数性质。在现有的安排下，我只是加入了几道习题，涉及一些人人都应知道的内容。事实上，这些材料现在已收入《本科代数》（*Undergraduate Algebra*）的一个新版本，那才是它们适合的位置。在这里，代数作为在李群上进行分析的辅助工具而出现；例如可参见 Jorgenson/Lang 的《$SL_n(\mathbf{R})$ 上的球面反演》（*Spherical Inversion on* $SL_n(\mathbf{R})$），Springer Verlag，2001 年。

我要特别感谢 Tom von Foerster、Ina Lindemann 和 Mark Spencer 在 Springer 所给予的编辑支持，也感谢负责制作工作的 Terry Kornak 和 Brian Howe。

Serge Lang

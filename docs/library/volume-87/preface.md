# arXiv 版前言

<span class="original-page-anchor" id="pdf-page-4" aria-hidden="true"></span>

本书于 2014 年由剑桥大学出版社首次出版，如今经双方同意，在 arXiv 上发布。剑桥大学出版社（CUP）一直允许作者在网上提供其著作的免费版本，以此支持数学界。作为回应，读者也可以购买纸质版本来支持 CUP，购买信息见 [http://www.cambridge.org/9781107044241](http://www.cambridge.org/9781107044241)。

这个电子版本不仅免费，而且还可以自由地*编辑*。例如，如果你希望使用本书讲授一门课程，但其中有些例子不适合你的学生，那么你可以删去这些例子，或者加入自己的例子。同样，如果你不喜欢某种记号，可以轻松地修改它；如果你想调整本书的排版，以便在某种特定设备上阅读，这也很容易。

从法律上说，本书依据知识共享“署名-非商业性使用-相同方式共享 4.0 国际”许可协议（CC BY-NC-SA 4.0）发布。许可条款可在知识共享网站 [https://creativecommons.org/licenses/by-nc-sa/4.0](https://creativecommons.org/licenses/by-nc-sa/4.0) 查阅。大体而言，只要你准确说明作者身份和版权归属，不将本书用于商业目的，并依据同一许可协议传播本书，该协议就允许你以任何喜欢的方式编辑和再传播本书。

从技术上说，编辑本书只需从 arXiv 下载源文件，然后按通常的方法使用 LaTeX（或 pdflatex）即可。

除了更正少量细微错误外，本版本与纸质版本完全相同。感谢所有指出这些错误的人，包括 Martin Brandenburg、Miguel Couto、Bradley Hicks、Thomas Moeller 和 Yaokun Wu。

*Tom Leinster，2016 年 12 月*

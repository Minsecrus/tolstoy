# 操作系统导论

〔美〕雷姆兹·H. 阿帕希-杜塞尔、安德莉亚·C. 阿帕希-杜塞尔著，王海鹏译，人民邮电出版社 2019 年出版。英文书名 *Operating Systems: Three Easy Pieces*，简称 OSTEP。

全书围绕虚拟化、并发和持久性三个主题展开，介绍现代操作系统的主要组件，包括调度、虚拟内存管理、磁盘和 I/O 子系统以及文件系统。大部分章节先提出一个关键问题，再通过书中介绍的技术、算法和思想解决它；各部分以师生对话引入。

本卷依据作者在[本书官方网站](https://pages.cs.wisc.edu/~remzi/OSTEP/)公开提供的中文版各章 PDF 整理。插图保留原书排版的图片，代码、公式和大部分表格转为可检索的文本；原书注释放在各章末尾，与正文双向链接。

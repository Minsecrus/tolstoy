# 白丝行<sup class="footnote-ref" id="note-ref-du-fu-0020-1"><a href="#note-du-fu-0020-1">〔一〕</a></sup>

<p class="du-fu-verse">缫丝须长不须白，越罗蜀锦金粟尺。<br />象<small class="du-fu-variant">一作牙</small>床玉手乱殷红，万草千花动凝碧。<br />已悲素质随时染<small class="du-fu-variant">一作改，</small>裂下鸣机色相射。<br />美人细意熨帖平，裁缝灭尽针线迹。<br />春天衣着为君舞，蛱蝶飞来黄鹂语。<br />落絮游丝亦有情，随风照日宜<small class="du-fu-variant">一作疑</small>轻举。<br />香汗轻尘污颜色<small class="du-fu-variant">一云香汗清尘似微污，又云香汗清尘污不着，陈浩然本一云香汗清尘似颜色，</small>开新合故置何<small class="du-fu-variant">一作相</small>许？<br />君不见才<small class="du-fu-variant">一作志</small>士汲引难，恐惧弃捐忍羁旅。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0020-1"><span class="footnote-number">〔一〕</span>白丝行：《傅咸集》曰：“河南郭泰机，寒素后门之士，不知余无能为益，以诗见。激切可施用之才，而况沉沦不能自拔于世。余虽心知之，而未如之何。此屈非复文辞可了，故直戏以答其诗云。”郭诗云：“皦皦白素丝，织为寒女衣。寒女虽妙巧，不得秉杼机。天寒知运速，况复雁南飞。衣工秉刀尺，弃我忽若遗。人不取诸身，世事焉所希。况复已朝餐，曷由知我饥。”此诗用泰机之言而反之。泰机以白丝、寒女自喻，而致憾于衣工之弃我，以冀咸之相荐。公此诗谓白丝素质，随时染裂，有香汗轻尘之污，有开新合故之置。所以深思汲引之难，“恐惧弃捐”而忍于羁旅也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0020-1" aria-label="返回正文">↩</a></span></p>

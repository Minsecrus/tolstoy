# 醉时歌

<small class="du-fu-variant">赠广文馆博士郑虔</small><sup class="footnote-ref" id="note-ref-du-fu-0023-1"><a href="#note-du-fu-0023-1">〔一〕</a></sup>

<p class="du-fu-verse">诸公衮衮登台<small class="du-fu-variant">一作华</small>省，广文先生官独冷。<br />甲第纷纷厌粱肉，广文先生饭不足。<br />先生有道出羲皇，先生有才<small class="du-fu-variant">一作所谈，一作所该，一作所抱</small>过屈宋<small class="du-fu-variant">一云有才或屈宋。</small>德尊一代常坎轲<small class="du-fu-variant">一作</small><img class="du-fu-glyph" src="/library/volume-94/images/glyph-70709e7415a070fd1ae0.jpg" alt="原书用字" style="width: 0.962em" />，名垂万古知何用。<br />杜陵野客人更<small class="du-fu-variant">一作见</small>嗤<sup class="footnote-ref" id="note-ref-du-fu-0023-2"><a href="#note-du-fu-0023-2">〔二〕</a></sup>，被褐短窄<small class="du-fu-variant">一作穴</small>鬓如丝。<br />日籴太<small class="du-fu-variant">一作泰</small>仓五升米，时赴郑老同襟期。<br />得钱即相觅，沽酒不复疑。<br />忘形到尔汝，痛饮真<small class="du-fu-variant">一作直</small>吾师。<br />清夜沉沉动春酌，灯前细雨檐花落<small class="du-fu-variant">一作檐前细雨灯花落。</small>但觉高歌有<small class="du-fu-variant">一作感</small>鬼神，焉知饿死填沟壑。<br />相如逸才亲涤器，子云识字终投阁。<br />先生早赋归去来，石田茅屋荒苍苔。<br />儒术于我何有哉，孔丘盗跖俱尘埃。<br />不须闻此意惨怆，生前相遇且衔杯。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0023-1"><span class="footnote-number">〔一〕</span>郑虔：《旧书》：“天宝九载，国子监置广文馆。”《唐语林》云：“天宝中，国学增置广文馆，以领词藻之士。郑虔久被贬谪，是岁始还京师参选，除广文馆博士。虔闻命，不知广文曹司何在，执政谓曰：广文馆新置，总领文词，故以公名贤处之。且令后代称广文博士自郑虔始，不亦美乎？遂就职。”按，广文馆于国子监增置，故云“不知曹司何在”。《新书》云：“久之，雨坏庑舍，有司不复修完，寓治国子馆，自是遂废。”非实录也。《长安志》：“韩庄在韦曲之东，退之与孟郊赋诗，又送其子读书之所也。郑庄又在其东南，郑十八虔之居也。”《通志》：“郑庄，即郑虔郊居，李商隐有《过郑虔旧隐》诗。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0023-1" aria-label="返回正文">↩</a></span></p>

# 骢马行

<small class="du-fu-variant">太常梁卿敕赐马也，李邓公爱而有之，命甫制诗。</small>

<p class="du-fu-verse">邓公马癖人共知，初得花骢大宛种。<br />夙昔传闻思一见，牵来左右神皆竦。<br />雄姿逸态何崷崪，顾影骄嘶自矜宠。<br />隅目青荧夹镜悬<sup class="footnote-ref" id="note-ref-du-fu-0042-1"><a href="#note-du-fu-0042-1">〔一〕</a></sup>，肉骏<small class="du-fu-variant">荆作鬃</small>碨礧连钱动<sup class="footnote-ref" id="note-ref-du-fu-0042-2"><a href="#note-du-fu-0042-2">〔二〕</a></sup>。<br />朝来久<small class="du-fu-variant">《草堂》作少</small>试华轩下，未觉千金满高价。<br />赤汗微生白雪毛，银鞍却覆香罗帕。<br />卿家旧赐公取之<small class="du-fu-variant">一云能取，一云有之，</small>天厩真龙此其亚。<br />昼洗须腾泾渭深<sup class="footnote-ref" id="note-ref-du-fu-0042-3"><a href="#note-du-fu-0042-3">〔三〕</a></sup>，朝<small class="du-fu-variant">荆作夕，一作晨</small>趋可刷幽并夜。<br />吾闻良骥老始成，此马数年人更惊。<br />岂有四蹄疾于鸟，不与八骏俱先鸣。<br />时俗造次那得致，云雾晦冥方降精。<br />近闻下诏喧都邑，肯使<small class="du-fu-variant">一作知有</small>骐<img class="du-fu-glyph" src="/library/volume-94/images/glyph-2d694cd8970751995883.jpg" alt="原书用字" style="width: 1.050em" />地上行？</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0042-1"><span class="footnote-number">〔一〕</span>隅目：《西京赋》：隅目高匡。薛综曰：隅目，角眼视也。《相马经》曰：眼欲得高匡。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0042-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0042-2"><span class="footnote-number">〔二〕</span>肉骏：东坡曰：余在岐下，见秦州进一马，鬃如牛，项下垂胡侧立，倒倾毛生肉端，蕃人曰“此肉鬃也”。乃知《骢马行》“肉骏碨礧”，当作“肉鬃”耳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0042-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0042-3"><span class="footnote-number">〔三〕</span>昼洗：《赭白马赋》：旦刷幽燕，昼秣荆越。张说《陇右监牧颂》：朝刷阆风，夕洗天泉。太白《天马歌》：鸡鸣刷燕暮秣越。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0042-3" aria-label="返回正文">↩</a></span></p>

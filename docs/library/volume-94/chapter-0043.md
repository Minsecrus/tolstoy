# 去矣行

<p class="du-fu-verse">君不见鞲上鹰，一饱则飞掣。<br />焉能作堂上燕，衔泥附炎热。<br />野人旷荡无䩄颜，岂可久在王侯间？<br />未试囊中餐玉法<sup class="footnote-ref" id="note-ref-du-fu-0043-1"><a href="#note-du-fu-0043-1">〔一〕</a></sup>，明朝且入蓝田山<sup class="footnote-ref" id="note-ref-du-fu-0043-2"><a href="#note-du-fu-0043-2">〔二〕</a></sup>。</p>

鲍钦止曰：天宝十四载，公在率府。数上赋颂，不蒙采录。欲辞职，遂作《去矣行》。

<p class="footnote-definition footnote-source" id="note-du-fu-0043-1"><span class="footnote-number">〔一〕</span>餐玉法：《后魏书》：李预每羡餐玉法，乃采访蓝田，躬往掘得若环璧杂器形者，大小百余。至而观之，皆光润可玩。预乃椎七十枚为屑，日服食之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0043-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0043-2"><span class="footnote-number">〔二〕</span>蓝田山：《汉·地理志》：蓝田县，本秦孝公置，山出美玉。《三秦记》曰：玉之美者曰“球”，其次曰“蓝”，盖以县出美玉，故名。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0043-2" aria-label="返回正文">↩</a></span></p>

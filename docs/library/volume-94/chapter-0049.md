# 悲青坂<sup class="footnote-ref" id="note-ref-du-fu-0049-1"><a href="#note-du-fu-0049-1">〔一〕</a></sup>

<p class="du-fu-verse">我军青坂在东门，天寒饮马太白窟<sup class="footnote-ref" id="note-ref-du-fu-0049-2"><a href="#note-du-fu-0049-2">〔二〕</a></sup>。<br />黄头奚儿日向西，数骑弯弓敢驰突。<br />山雪河冰野<small class="du-fu-variant">樊作晚，《乐府》作已</small>萧瑟<small class="du-fu-variant">一作扬，一作飒，</small>青是烽<small class="du-fu-variant">一作人</small>烟白人骨。<br />焉得附书与我军，忍待明年莫仓卒。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0049-1"><span class="footnote-number">〔一〕</span>青坂：癸卯，琯又率南军即战，复败。东坡曰：琯既败，犹欲持重有所伺，而中人邢延恩等促战。仓皇失据，遂及于败。故后篇云：“安得附书与我军，忍待明年莫仓卒。”青坂，地名，未详。陈涛斜在咸阳，房琯师次便桥。便桥在咸阳县西南十里，架渭水上。则青坂去陈涛便桥当不远。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0049-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0049-2"><span class="footnote-number">〔二〕</span>太白窟：太白山在武功县，去长安二百里。琯先分三军，刘悊将中军自武功入，故曰“饮马太白窟”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0049-2" aria-label="返回正文">↩</a></span></p>

茅元仪曰：肃宗已入贺兰进明之谤，而使房琯将兵。人主嫌疑于上，小人窥伺于下。持重有伺，焉知非胜机。而中人辄敢促战？败师之罪，琯不任受也。琯以宰相将师，若非主上见疑，何至使中人监制？若琯幸而胜，则肃宗之疑愈深，进明之谤滋甚，岂惟不敢望一州。他日欲如高力士、陈玄礼，亦不可得矣。琯既败，帝犹未敢即废，假琴工之事，发怒斥之。既废，而朝士多言琯谋包文武，可复用，帝益不能容。由此言之，唐世公议，犹足重也。

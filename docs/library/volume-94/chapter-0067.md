# 徒步归行

<small class="du-fu-variant">赠李特进，自凤翔赴鄜州，途经邠州作。</small>

<p class="du-fu-verse">明公壮年值时危，经济实藉英雄姿。<br />国之社稷今若是，武定祸乱非公谁。<br />凤翔千官且饱饭，衣马不复能轻肥<sup class="footnote-ref" id="note-ref-du-fu-0067-1"><a href="#note-du-fu-0067-1">〔一〕</a></sup>。<br />青袍朝士最困者，白头拾遗徒步归。<br />人生交契无老少，论交<small class="du-fu-variant">一作心</small>何必先同调。<br />妻子山中哭向天，须公枥上追风骠<sup class="footnote-ref" id="note-ref-du-fu-0067-2"><a href="#note-du-fu-0067-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0067-1"><span class="footnote-number">〔一〕</span>轻肥：时当肃宗括马之后，故曰“不复能轻肥”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0067-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0067-2"><span class="footnote-number">〔二〕</span>追风：《古今注》：始皇七马，一曰“追风”。 骠：《说文》：骠，黄马发白色。一曰“白鬣尾”。《广韵》：马黄白色曰“骠”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0067-2" aria-label="返回正文">↩</a></span></p>

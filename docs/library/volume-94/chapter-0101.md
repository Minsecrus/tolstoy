# 太平寺泉眼

<p class="du-fu-verse">招提凭高冈，疏散连草莽。<br />出泉枯柳根，汲引岁月古。<br />石间<small class="du-fu-variant">一作门</small>见海眼，天畔萦水府。<br />广深丈尺间，宴息敢轻侮。<br />青白二小蛇，幽姿可时睹。<br />如丝气或上，烂熳为云雨。<br />山头到山下，凿井不尽土。<br />取供十方僧，香美胜牛乳<sup class="footnote-ref" id="note-ref-du-fu-0101-1"><a href="#note-du-fu-0101-1">〔一〕</a></sup>。<br />北风起寒文，弱藻舒<small class="du-fu-variant">一作胜</small>翠缕。<br />明涵客衣净，细荡林影趣。<br />何当宅下流，余润通药圃。<br />三春湿黄精<sup class="footnote-ref" id="note-ref-du-fu-0101-2"><a href="#note-du-fu-0101-2">〔二〕</a></sup>，一食生毛羽。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0101-1"><span class="footnote-number">〔一〕</span>牛乳：《维摩经》：阿难白佛言：忆念昔时，世尊身有小疾，当用牛乳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0101-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0101-2"><span class="footnote-number">〔二〕</span>黄精：《博物志》：天老谓黄帝曰：太阳之草名黄精，饵之可以长生。世传华陀“漆叶青黏散”，云：青黏是黄精之正叶者。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0101-2" aria-label="返回正文">↩</a></span></p>

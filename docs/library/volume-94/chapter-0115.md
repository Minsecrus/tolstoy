# 盐井<sup class="footnote-ref" id="note-ref-du-fu-0115-1"><a href="#note-du-fu-0115-1">〔一〕</a></sup>

<p class="du-fu-verse">卤中草木白<sup class="footnote-ref" id="note-ref-du-fu-0115-2"><a href="#note-du-fu-0115-2">〔二〕</a></sup>，青者官盐烟。<br />官作既有程，煮盐烟在川。<br />汲井岁榾榾<small class="du-fu-variant">《草堂》本云当作搰搰，</small>出车日连连。<br />自公斗三百<sup class="footnote-ref" id="note-ref-du-fu-0115-3"><a href="#note-du-fu-0115-3">〔三〕</a></sup>，转致斛六千。<br />君子慎止足，小人苦喧阗。<br />我何良叹嗟，物理固自然<small class="du-fu-variant">一云亦固然。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0115-1"><span class="footnote-number">〔一〕</span>盐井：《水经注》：盐官水南入汉水，水有盐官，在幡冢西五十许里，相承营煮不辍，味与海盐同。故《地理志》云“西县有盐官”是也。《元和郡国志》：盐井，在成州长道县东三十里。水与岸齐，盐极甘美，食之破气。盐官故城，在县东三十里，在嶓冢西四十里。相承营煮，味与海盐同。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0115-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0115-2"><span class="footnote-number">〔二〕</span>卤中：《说文》：卤，盐池也。东方谓之斥，西方谓之卤。《宣帝纪》：常困于莲勺卤中，如淳曰“莲勺有盐池”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0115-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0115-3"><span class="footnote-number">〔三〕</span>三百：《食货志》：天宝、至德间，盐每斗十钱。乾元元年，第五琦为使。初变法，刘晏代之，法益密。贞元四年，江淮斗增二百，为钱三百一十。后复增六十，河中两池盐，斗三百七十。豪贾射利，官收不能半，以此例之，蜀井盐价，从可推矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0115-3" aria-label="返回正文">↩</a></span></p>

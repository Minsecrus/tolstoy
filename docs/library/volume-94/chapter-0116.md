# 寒硖

<p class="du-fu-verse">行迈日悄悄，山谷势多端。<br />云门转绝岸，积阻霾天寒。<br />寒硖不可度，我实<small class="du-fu-variant">一作贫</small>衣裳单。<br />况当仲冬交，溯㳂增波澜。<br />野人寻烟语，行子傍水餐。<br />此生免荷殳，未敢辞路难。</p>

鹤曰：秦至成之界，垂二百里，又七十里至成。今寒硖尚为秦地，而已交十一月，则去秦在十月之末，无疑也。

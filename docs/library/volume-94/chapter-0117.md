# 法镜寺

<p class="du-fu-verse">身危适他州，勉强终劳苦。<br />神伤山行深，愁破崖寺古。<br />婵娟碧鲜净<sup class="footnote-ref" id="note-ref-du-fu-0117-1"><a href="#note-du-fu-0117-1">〔一〕</a></sup>，萧摵寒箨聚。<br />回回<small class="du-fu-variant">一作洄洄</small>山<small class="du-fu-variant">一作石</small>根水，冉冉松上雨。<br />泄云蒙清晨，初日翳复吐。<br />朱甍半光炯，户牖粲可数。<br />拄<small class="du-fu-variant">一作枉</small>策忘前期，出萝已亭午。<br />冥冥子规叫，微径不复<small class="du-fu-variant">一作敢</small>取。</p>

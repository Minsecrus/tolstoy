# 杜鹃行<sup class="footnote-ref" id="note-ref-du-fu-0139-1"><a href="#note-du-fu-0139-1">〔一〕</a></sup>

<p class="du-fu-verse">君不见昔日蜀天子，化作杜鹃似老乌。<br />寄巢生子不自啄，群鸟至今与哺雏。<br />虽同君臣有旧礼，骨肉满眼身羁孤<sup class="footnote-ref" id="note-ref-du-fu-0139-2"><a href="#note-du-fu-0139-2">〔二〕</a></sup>。<br />业工窜伏深树里，四月五月偏号呼。<br />其声哀痛口流血，所诉何事常区区。<br />尔岂摧残始<small class="du-fu-variant">晋作如</small>发愤，羞带羽翮伤形愚。<br />苍天变化谁料得，万事反复何所无。<br />万事反复何所无，岂忆当殿群臣趋。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0139-1"><span class="footnote-number">〔一〕</span>杜鹃：《华阳国志》：鱼凫王后，有王曰杜宇。教民务农，一号杜主，七国称王。杜宇称帝，号曰望帝，更名蒲卑。自以为功德高诸王，乃以褒斜为前门，熊耳、灵关为后户，玉垒、峨眉为城郭，江、潜、绵、络为池泽。以汶山为畜牧，南中为园苑。会有水灾，其相开明，决玉垒山以除水患，帝遂委以政事。法尧、舜禅受之义，遂禅位于开明，帝升西山隐焉。时适二月，子鹃鸟鸣，故蜀人悲子鹃鸟鸣也。巴亦化其教而力农务，迄今巴蜀民，农时先祀杜主君。《蜀都赋》：鸟生杜宇之魄。刘注：《蜀记》曰：昔有人姓杜名宇，王蜀，号曰望帝。宇化，俗说云宇化为子规。子规，鸟名也。蜀人闻子规鸣，皆曰望帝也。《成都记》：望帝死，其魂化为鸟，名曰杜鹃，亦曰子规。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0139-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0139-2"><span class="footnote-number">〔二〕</span>羁孤：上元元年七月，上皇迁居西内，高力士流巫州，置如仙媛于归州，玉真公主出居玉真观。上皇不怿，因不茹荤，辟谷，浸以成疾。诗云“骨肉满眼身羁孤”，盖谓此也。移仗之日，上皇惊，欲坠马数四。高力士跃马厉声曰：“五十年太平天子，李辅国，汝旧臣，不宜无礼！”又令辅国拢马，护侍至西内。故曰“虽同君臣有旧礼”，盖谓此也。鲍照《行路难》曰：“愁思忽而至，跨马出北门。举头四顾望，但见松柏荆棘郁蹲蹲。中有一鸟名杜鹃，言是古时蜀帝魂。声音哀苦鸣不息，毛羽憔悴似人髠。飞走树间逐虫蚁，岂忆往日天子尊。念此死生变化非常理，心中恻怆不能言。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0139-2" aria-label="返回正文">↩</a></span></p>

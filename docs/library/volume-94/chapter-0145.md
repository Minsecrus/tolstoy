# 戏为双松图歌

<small class="du-fu-variant">韦偃</small>

<p class="du-fu-verse">天下几人画古松<small class="du-fu-variant">一作树，</small>毕宏已老韦偃少<sup class="footnote-ref" id="note-ref-du-fu-0145-1"><a href="#note-du-fu-0145-1">〔一〕</a></sup>。<br />绝笔长风起纤末，满堂动色嗟神妙。<br />两株惨裂苔藓皮，屈铁交错回高枝。<br />白摧朽骨龙虎死，黑入太阴雷雨垂。<br />松根胡僧憇寂寞，庞眉皓首无住著。<br />偏袒右肩露双脚，叶里松子僧前落。<br />韦侯韦侯数相见，我有一匹好东<small class="du-fu-variant">一云素</small>绢<sup class="footnote-ref" id="note-ref-du-fu-0145-2"><a href="#note-du-fu-0145-2">〔二〕</a></sup>，重之不减锦绣段。<br />已令拂拭光凌乱，请公放笔为直干。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0145-1"><span class="footnote-number">〔一〕</span>毕宏：张彦远《名画记》：毕宏，大历二年为给事中。画松石于左省厅壁，好事者皆诗咏之。改京兆少尹，为左庶子。树石擅名于代，树木改步变古，自宏始也。封演《闻见记》：毕宏，天宝中御史，善画古松。后见张璪，于是阁笔。 韦偃：《名画记》：韦鉴工龙马，妙得精气。鉴弟銮工山水松石，虽有其名，未免古拙。鉴子鶠，工山水、高僧奇士、老松异石。笔力劲健，风格高举。又善小马、牛、羊、山原，俗人空知鶠善马，不知松石更佳也。咫尺千寻，骈柯攒影，烟霞翳薄，风雨飕飗。轮囷尽偃盖之形，宛转极盘龙之状。《宣和画谱》：鶠虽家学，而烟霞风云之变，轮囷离奇之状，过其父远甚。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0145-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0145-2"><span class="footnote-number">〔二〕</span>东绢：吴曾《漫录》：东绢，关东绡也。梁庾肩吾《答武陵王赍绢启》曰：关东之妙，潜织陋其卷绡。坡诗注：鹅溪在梓州盐亭县，出绢甚良。杜诗“我有一匹好东绢”，盖谓此也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0145-2" aria-label="返回正文">↩</a></span></p>

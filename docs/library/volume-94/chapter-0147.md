# 徐卿二子歌

<p class="du-fu-verse">君不见徐卿二子生绝奇，感应吉梦相追随。<br />孔子释氏亲抱送，并是天上麒麟儿<sup class="footnote-ref" id="note-ref-du-fu-0147-1"><a href="#note-du-fu-0147-1">〔一〕</a></sup>。<br />大儿九龄色清澈，秋水为神玉为骨。<br />小儿五岁气食牛，满堂宾客皆回头。<br />吾知徐公百不忧，积善衮衮生公侯。<br />丈夫生儿有如此二雏者，名位岂肯卑微休<small class="du-fu-variant">一云异时名位岂肯卑微休。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0147-1"><span class="footnote-number">〔一〕</span>麒麟：《陈书》：徐陵母臧氏，尝梦五色云化而为凤，集左肩上，已而诞陵焉。宝志上人者，世称其有道。陵年数岁，家人携以候之。宝志手摩其顶曰：天上石麒麟也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0147-1" aria-label="返回正文">↩</a></span></p>

# 大雨

<p class="du-fu-verse">西蜀冬不雪，春农尚嗷嗷。<br />上天回哀眷，朱<small class="du-fu-variant">一作清</small>夏云郁陶。<br />执热乃沸鼎，纤<img class="du-fu-glyph" src="/library/volume-94/images/glyph-9b5f98548a34a12f7617.jpg" alt="原书用字" style="width: 0.950em" />成缊袍。<br />风雷飒万里，霈泽施蓬蒿。<br />敢辞茅苇漏，已喜黍豆高。<br />三日无行人，二<small class="du-fu-variant">一作大</small>江声怒号<sup class="footnote-ref" id="note-ref-du-fu-0158-1"><a href="#note-du-fu-0158-1">〔一〕</a></sup>。<br />流恶邑里清<sup class="footnote-ref" id="note-ref-du-fu-0158-2"><a href="#note-du-fu-0158-2">〔二〕</a></sup>，矧兹远江皋。<br />荒庭步鹳鹤，隐几望波涛。<br />沉痾聚药饵，顿忘所进劳。<br />则知润物功，可以贷不毛。<br />阴色静垄亩，劝耕自官曹。<br />四邻耒耜出<small class="du-fu-variant">一作出耒耜，</small>何必吾家操。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0158-1"><span class="footnote-number">〔一〕</span>二江：《水经注》：成都县有二江，双流郡下。故杨子云《蜀都赋》曰“两江珥其前”者也。《风俗通》曰：秦昭王使李冰为蜀守，开成都两江，溉田万顷。《寰宇记》：今谓内江、外江。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0158-1" aria-label="返回正文">↩</a></span></p>

# 渔阳

<p class="du-fu-verse">渔阳突骑犹精锐<sup class="footnote-ref" id="note-ref-du-fu-0163-1"><a href="#note-du-fu-0163-1">〔一〕</a></sup>，赫赫雍王都<small class="du-fu-variant">一作前</small>节制<sup class="footnote-ref" id="note-ref-du-fu-0163-2"><a href="#note-du-fu-0163-2">〔二〕</a></sup>。<br />猛将飘然恐后时，本朝不入非高计。<br />禄山北筑雄武城<sup class="footnote-ref" id="note-ref-du-fu-0163-3"><a href="#note-du-fu-0163-3">〔三〕</a></sup>，旧防败走归其营。<br />系书请问燕耆旧，今日何须十万兵。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0163-1"><span class="footnote-number">〔一〕</span>突骑：吴汉亡命在渔阳，说太守彭宠曰：“渔阳突骑，天下所闻也。”光武克邯郸，谓马武曰：“吾得渔阳、上谷突骑，欲令将军将之。”蔡邕幽州刺史议曰：“幽州突骑，冀州强弩，天下精兵，国家瞻仗。四方有事，未尝不取办于二州也。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0163-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0163-2"><span class="footnote-number">〔二〕</span>雍王：宝应元年九月，鲁王适改封雍王。十月，诏天下兵马元帅雍王，统河东、朔方及诸道行营、回纥等兵十余万讨史朝义，会军于陕州。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0163-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0163-3"><span class="footnote-number">〔三〕</span>雄武城：《安禄山事迹》：禄山归范阳，筑雄武城，外示御寇，内贮兵器，养同罗及降奚、契丹曳落河八千余为己子。又畜单于、护真战马数万匹，牛羊五万余头。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0163-3" aria-label="返回正文">↩</a></span></p>

赵傁曰：公在梓，闻雍王授钺，作此诗以讽河北诸将。谓“飘然”而来，犹“恐后时”，乃拥兵不入本朝，岂高计乎？末又举禄山往事以戒之。旧注以后事傅会，错乱殊甚。

# 黄河二首

## 其一

<p class="du-fu-verse">黄河北岸海西军，椎鼓鸣钟天下闻。<br />铁马长鸣不知<small class="du-fu-variant">一作如</small>数，胡人高鼻动成群。</p>

雍王至陕州，回纥可汗屯于河北，与僚属从数十骑往见之。诸军发陕州，仆固怀恩与回纥左杀为前锋，此所谓“河北”“海西”军也。旧注：指吐蕃入寇，谬甚。

## 其二

<p class="du-fu-verse">黄河西<small class="du-fu-variant">一云北，一云南，俱非</small>岸是吾<small class="du-fu-variant">一作故</small>蜀，欲须供给家无粟。<br />愿驱众庶戴君王，混一车书弃金玉。</p>

赵傁曰：此悯蜀人之困，而愿君王之无侈，如云不宝金玉之义。

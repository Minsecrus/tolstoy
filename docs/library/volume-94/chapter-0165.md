# 天边行

<p class="du-fu-verse">天边老人归未得，日暮东临大江哭。<br />陇右河源不种田，胡骑羌兵入巴蜀。<br />洪涛滔天风拔木，前飞秃鹙后鸿<small class="du-fu-variant">一作黄</small>鹄。<br />九度附书向洛阳，十年骨肉无消息。</p>

鹤曰：至德二载，吐蕃侵取廓、霸、岷等州，及河源莫门军。宝应元年，陷临洮，取秦、成、渭等州。此云“陇右河源不种田”，则河、陇尚未尽失。至广德元年，始尽取陇右之地也。

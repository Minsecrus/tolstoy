# 大麦行

<p class="du-fu-verse">大麦干枯小麦黄，妇女<small class="du-fu-variant">一作人</small>行泣夫走藏。<br />东至集壁西梁洋<sup class="footnote-ref" id="note-ref-du-fu-0166-1"><a href="#note-du-fu-0166-1">〔一〕</a></sup>，问谁腰镰胡与羌？<br />岂无蜀兵三千人<small class="du-fu-variant">一云千人去，</small>部<small class="du-fu-variant">一作簿</small>领辛苦江山长。<br />安得如鸟有羽翅，托身白云还故乡。</p>

吴若本注云：后汉桓帝时童谣：“小麦青青大麦枯，谁当获者妇与姑。”此诗源流出此。

<p class="footnote-definition footnote-source" id="note-du-fu-0166-1"><span class="footnote-number">〔一〕</span>集壁梁洋：四州皆属山南西道。宝应元年建卯月，羌浑奴刺寇梁州。建辰月，党项奴刺寇洋州。此诗当是宝应元年作。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0166-1" aria-label="返回正文">↩</a></span></p>

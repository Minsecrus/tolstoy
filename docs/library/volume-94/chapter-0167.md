# 苦战行

<p class="du-fu-verse">苦战身死马将军<sup class="footnote-ref" id="note-ref-du-fu-0167-1"><a href="#note-du-fu-0167-1">〔一〕</a></sup>，自云伏波之子孙。<br />干戈未定失壮士，使我叹恨伤精魂。<br />去年江南<small class="du-fu-variant">《英华》作南行</small>讨狂贼，临江把臂难再得。<br />别时孤云今不飞，时独看云泪横臆。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0167-1"><span class="footnote-number">〔一〕</span>马将军：马将军，旧注指马璘，大谬。璘以大历十二年卒也。遂州，在涪江少南，故曰“江南”，盖必死于段子璋之乱者。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0167-1" aria-label="返回正文">↩</a></span></p>

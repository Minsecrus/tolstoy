# 去秋行

<p class="du-fu-verse">去秋涪江木落时，臂枪<small class="du-fu-variant">一作苍</small>走马谁家儿。<br />到今不知白骨处，部曲有去皆无归。<br />遂州城中汉节在<sup class="footnote-ref" id="note-ref-du-fu-0168-1"><a href="#note-du-fu-0168-1">〔一〕</a></sup>，遂州城外巴人稀。<br />战场冤魂每夜哭，空令野营猛士悲。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0168-1"><span class="footnote-number">〔一〕</span>汉节：鲍钦止曰：上元二年，段子璋反。遂州刺史嗣虢王巨，修属郡礼出迎，子璋杀之。故云“遂州城中汉节在”，盖伤之也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0168-1" aria-label="返回正文">↩</a></span></p>

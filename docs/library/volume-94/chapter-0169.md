# 述古三首

## 其一

<p class="du-fu-verse">赤骥顿长缨，非无万里姿。<br />悲鸣泪至地，为问驭者谁？<br />凤凰从东<small class="du-fu-variant">一作天</small>来，何意复高飞。<br />竹花不结实，念子忍朝饥。<br />古时君臣合，可以物理推。<br />贤人识定分，进退<small class="du-fu-variant">一作用</small>固<small class="du-fu-variant">一作因</small>其宜。</p>

## 其二

<p class="du-fu-verse">市人日中集，于利竞锥刀。<br />置膏烈火上，哀哀自煎熬。<br />农人望岁稔，相率除蓬蒿。<br />所务谷<small class="du-fu-variant">一作农</small>为本，邪赢无乃劳。<br />舜举十六相，身尊道何高。<br />秦时任商鞅，法令如牛毛。</p>

## 其三

<p class="du-fu-verse">汉光得天下，祚永固有开。<br />岂惟高祖圣，功自萧曹来。<br />经纶中兴业，何代无长才。<br />吾慕寇邓勋，济时信良哉。<br />耿贾亦宗臣，羽翼共徘徊。<br />休运终四百<sup class="footnote-ref" id="note-ref-du-fu-0169-1"><a href="#note-du-fu-0169-1">〔一〕</a></sup>，图画在云台。</p>

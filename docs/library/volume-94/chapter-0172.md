# 越王楼歌<sup class="footnote-ref" id="note-ref-du-fu-0172-1"><a href="#note-du-fu-0172-1">〔一〕</a></sup>

<p class="du-fu-verse">绵州州府何磊落，显庆年中越王作。<br />孤城西北起高楼，碧瓦朱甍照城郭。<br />楼下长江百丈清，山头落日半轮明。<br />君王旧迹今人赏，转见千秋万古情。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0172-1"><span class="footnote-number">〔一〕</span>越王楼：《绵州图经》：在绵州城外，西北有台，高百尺。上有楼，下瞰州城。唐显庆中，太宗子越王贞为绵州刺史日建。李偓诗：“越王曾牧剑南州，因向城隅建此楼。横玉远开千峤雪，暗雷下听一江流。”贞刺绵州，本传不载，盖史阙也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0172-1" aria-label="返回正文">↩</a></span></p>

# 海棕行

<p class="du-fu-verse">左绵公馆清江<img class="du-fu-glyph" src="/library/volume-94/images/glyph-25bbb029d4626be94366.jpg" alt="原书用字" style="width: 1.000em" /><sup class="footnote-ref" id="note-ref-du-fu-0173-1"><a href="#note-du-fu-0173-1">〔一〕</a></sup>，海棕一株高入云<sup class="footnote-ref" id="note-ref-du-fu-0173-2"><a href="#note-du-fu-0173-2">〔二〕</a></sup>。<br />龙鳞犀甲相错落，苍棱白皮十抱文。<br />自<small class="du-fu-variant">一作但</small>是众木乱纷纷，海棕焉知身出群。<br />移栽北辰不可得，时有西域胡僧识。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0173-1"><span class="footnote-number">〔一〕</span>左绵：《蜀都赋》：于东则左绵巴中，百濮所充。旧注：绵州，涪水所经。涪居其右，绵居其左，故曰左绵。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0173-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0173-2"><span class="footnote-number">〔二〕</span>海棕：唐子西《将家游治平院》诗云：江边胜事略寻遍，不见海棕高入云。注云：即老杜所云东津者。盖馆与棕皆在涪江之东津也。陆放翁云：老杜在左绵所赋“海棕”，今已不存。宋子京《益都方物·海棕赞》：棕皆褫皮，此独自干。攒叶于颠，纛首披散。秋华而实，其值则四千。注云：大抵棕类，然不皮而干，叶丛于杪，至秋乃实，似楝子。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0173-2" aria-label="返回正文">↩</a></span></p>

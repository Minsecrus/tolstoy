# 相从歌赠严二别驾

<small class="du-fu-variant">一云严别驾相逢歌</small>

<p class="du-fu-verse">我行入东川<sup class="footnote-ref" id="note-ref-du-fu-0175-1"><a href="#note-du-fu-0175-1">〔一〕</a></sup>，十步一回首。<br />成都乱罢气萧飒<small class="du-fu-variant">一作瑟，一作索，</small>浣花草堂亦何有。<br />梓中<small class="du-fu-variant">一作州</small>豪俊<small class="du-fu-variant">一作贵</small>大者谁，本州从事知名久。<br />把臂开樽饮我酒，酒酣击剑蛟龙吼。<br />乌帽拂尘青螺<small class="du-fu-variant">一作骡</small>粟<sup class="footnote-ref" id="note-ref-du-fu-0175-2"><a href="#note-du-fu-0175-2">〔二〕</a></sup>，紫衣将炙绯衣走。<br />铜盘烧蜡光<small class="du-fu-variant">一作炎</small>吐日，夜如何其初促膝。<br />黄昏始扣主人门，谁谓俄顷<small class="du-fu-variant">晋作我倾</small>胶在漆。<br />万事尽付形骸外，百年未见<small class="du-fu-variant">一作及</small>欢娱毕。<br />神倾意豁真佳士，久客多忧今愈疾。<br />高视乾坤又可<small class="du-fu-variant">一作何</small>愁，一躯交态同<small class="du-fu-variant">一作真</small>悠悠。<br />垂老遇君未恨晚，似君须向古人求。</p>

陈浩然本及《草堂》诸本题下并注云：时方经崔旰之乱。吴若本无之。鹤曰：崔旰之乱，在永泰元年，公已次云安。此诗当是宝应元年避徐知道之乱往梓州作也。题下七字，乃注家妄添，而后人不察，以谓公自注也，今从吴若本削去。

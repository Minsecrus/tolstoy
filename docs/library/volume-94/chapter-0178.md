# 陈拾遗故宅

<p class="du-fu-verse">拾遗平昔居，大屋<small class="du-fu-variant">一作宅</small>尚修椽。<br />悠扬<small class="du-fu-variant">一作悠悠</small>荒山日，惨淡<small class="du-fu-variant">一作崔萃</small>故园<small class="du-fu-variant">一作国</small>烟。<br />位下曷足伤，所贵者圣贤。<br />有才继骚雅，哲匠不比肩。<br />公生杨马后，名与日月悬。<br />同游英俊人，多秉辅佐权。<br />彦昭超<small class="du-fu-variant">一作赵</small>玉价<sup class="footnote-ref" id="note-ref-du-fu-0178-1"><a href="#note-du-fu-0178-1">〔一〕</a></sup>，郭振<small class="du-fu-variant">晋作震</small>起通泉。<br />到今素壁滑，洒翰银钩连。<br />盛事会一时，此堂岂千年。<br />终古立<small class="du-fu-variant">一作占</small>忠义，感遇有遗编。</p>

《旧书》：陈子昂家世豪富，子昂独苦节读书，为《感遇诗》三十首。王适见而惊曰：此子必为天下文宗矣。高宗崩，诣阙上书，自称“梓州射洪县草莽愚臣子昂”。则天召见，拜麟台正字，再转右拾遗。

<p class="footnote-definition footnote-source" id="note-du-fu-0178-1"><span class="footnote-number">〔一〕</span>彦昭：赵彦昭，少以文词名中宗时，累迁中书侍郎，同中书门下三品。与郭元振、张说友善。《英华》注曰：中宗时，彦昭以权幸得相。《唐史·彦昭传》不载入蜀事。鹤曰：元振尉通泉，在梓州东南一百三十里。而彦昭与元振同业太学，故宜同游。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0178-1" aria-label="返回正文">↩</a></span></p>

# 奉赠射洪李四丈

<small class="du-fu-variant">明甫</small>

<p class="du-fu-verse">丈人屋上乌<sup class="footnote-ref" id="note-ref-du-fu-0180-1"><a href="#note-du-fu-0180-1">〔一〕</a></sup>，人好乌亦好。<br />人生意气豁，不在相逢早。<br />南京乱初定，所向邑<small class="du-fu-variant">一作色</small>枯槁。<br />游子无根株，茅斋付秋草。<br />东征下月峡，挂席穷海岛。<br />万里须十金，妻孥未相保。<br />苍茫风尘际，蹭蹬骐<img class="du-fu-glyph" src="/library/volume-94/images/glyph-0d08bd1c28737507629f.jpg" alt="原书用字" style="width: 1.050em" />老。<br />志士怀感伤，心胸已倾倒。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0180-1"><span class="footnote-number">〔一〕</span>屋上乌：《毛诗传》：富人之屋，乌所集也。《尚书大传》：武王登夏台以临殷民。周公曰：爱其人者，爱其屋上之乌；憎其人者，憎其储胥。《孔丛子》亦云：爱屋及乌。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0180-1" aria-label="返回正文">↩</a></span></p>

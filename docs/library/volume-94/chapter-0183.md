# 过郭代公故宅<sup class="footnote-ref" id="note-ref-du-fu-0183-1"><a href="#note-du-fu-0183-1">〔一〕</a></sup>

<p class="du-fu-verse">豪俊初未遇，其迹或脱略。<br />代公尉通泉，放意何自若。<br />及夫登衮冕，直气森喷薄<small class="du-fu-variant">一本此下有“精魄凛如在，所历终萧索”。</small>磊落见异人，岂伊常情度。<br />定策神龙后，宫中翕清廓。<br />俄顷辨尊亲，指挥存顾托。<br />群公有<small class="du-fu-variant">一作见</small>惭色，王室无削弱。<br />迥出名臣上，丹青照台阁。<br />我行得遗迹<small class="du-fu-variant">一作址，</small>池馆皆疏凿。<br />壮公临事断，顾步涕横落<small class="du-fu-variant">《草堂》本“精凛魄如在”一联在此下。</small>高咏宝剑篇，神交付冥漠。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0183-1"><span class="footnote-number">〔一〕</span>郭代公：张说撰《行状》云：公少倜傥，廓落有大志。十六入太学，与薛稷、赵彦昭同业。十八擢进士第，其年判入高等。请外官，授梓州通泉尉。落拓不拘小节，常铸钱，掠良人财以济四方，海内同声合气，有至千万者。则天闻其名，驿征引见，语至夜，甚奇之。问蜀川之迹，对而不隐。令录旧文，乃上《古剑歌》。则天览而佳之，令写数十本，遍赐学士。先天二年，知政事。太平公主、窦怀贞潜结凶党，谋废皇帝。睿宗犹豫不决，诸相皆阿谀顺旨，惟公廷争不受诏。及举兵诛怀贞等，宫城大乱，睿宗步肃章门观变，诸相皆窜外省，公独登奉天门楼躬侍。睿宗闻东宫兵至，将欲投于楼下。公亲扶圣躬，敦劝乃止。及上即位，宿中书十四日，独知政事，下诏封代国公。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0183-1" aria-label="返回正文">↩</a></span></p>

笺曰：按，代公定策在先天二年，而杜诗云“定策神龙后”，盖太平、安乐二公主及韦后用事，俱在神龙二年，故云“神龙后”也。吴若本注云：明皇与刘幽求平韦庶人之乱，正在神龙后。元振常有功其间，而史失之。微此诗，无以见。不知元振为宗楚客等所嫉，出之安西，几为所陷。楚客等被诛，始得征还。何从与平韦后之乱，此泥诗而不考古之过也。

# 春日戏题恼郝使君兄

<p class="du-fu-verse">使君意<small class="du-fu-variant">一作俊</small>气凌青霄，忆昨欢娱常见招。<br />细马时鸣金<img class="du-fu-glyph" src="/library/volume-94/images/glyph-5b3b147f61bb4cd5f029.jpg" alt="原书用字" style="width: 1.000em" />袅，佳人屡出董娇饶<sup class="footnote-ref" id="note-ref-du-fu-0187-1"><a href="#note-du-fu-0187-1">〔一〕</a></sup>。<br />东流江水西飞燕，可惜春光不相见。<br />愿携王赵两红颜，再骋肌肤如素练。<br />通泉百里近梓州，请<small class="du-fu-variant">一作诸</small>公一来开我愁。<br />舞处重看花满面，尊前还有锦缠头<sup class="footnote-ref" id="note-ref-du-fu-0187-2"><a href="#note-du-fu-0187-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0187-1"><span class="footnote-number">〔一〕</span>董娇饶：《玉台新咏》：宋子侯有《董娇饶》诗，毛晃韵新增“娆”字，误引此诗作“妖娆”，宜正之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0187-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0187-2"><span class="footnote-number">〔二〕</span>缠头：《太真外传》：上戏曰：“阿瞒乐籍，今日幸得供养夫人，请一缠头。”《唐书》：鱼朝恩出锦三匹，罗五十匹，绫一百匹，为子仪缠头之费。《御览》云：旧俗赏歌舞人锦彩，置之头上，谓之“缠头”。宴享加恩，借以为词。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0187-2" aria-label="返回正文">↩</a></span></p>

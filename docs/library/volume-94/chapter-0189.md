# 短歌行

<small class="du-fu-variant">送祁录事归合州，因寄苏使君。</small>

《草堂》本作邛州录事。

<p class="du-fu-verse">前者途中一相见，人事经年记君面。<br />后生相动<small class="du-fu-variant">一作劝</small>何寂寥，君有长才不贫贱。<br />君今起柁春江流，余亦沙边具小舟。<br />幸为达书贤府主，江花未尽会江楼<sup class="footnote-ref" id="note-ref-du-fu-0189-1"><a href="#note-du-fu-0189-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0189-1"><span class="footnote-number">〔一〕</span>江楼：《方舆纪胜》：在合州州治之前，钓鱼山、学士山、巫山横其前，下临汉水。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0189-1" aria-label="返回正文">↩</a></span></p>

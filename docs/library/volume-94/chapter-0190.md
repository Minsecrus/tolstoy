# 陪章留后惠义寺饯嘉州崔都督赴州

<p class="du-fu-verse">中军待上客，令肃事有恒。<br />前驱入宝地，祖帐飘金绳<sup class="footnote-ref" id="note-ref-du-fu-0190-1"><a href="#note-du-fu-0190-1">〔一〕</a></sup>。<br />南陌<small class="du-fu-variant">一作伯</small>既留欢，兹山亦深登。<br />清闻树杪磬，远谒云端僧。<br />回策匪新岸<small class="du-fu-variant">樊作崖，</small>所攀仍旧藤。<br />耳激洞门飙，目存寒谷冰。<br />出尘<img class="du-fu-glyph" src="/library/volume-94/images/glyph-45e6d25c506996b1b887.jpg" alt="原书用字" style="width: 0.850em" />轨躅，毕景遗炎蒸。<br />永愿坐长夏，将衰栖大乘。<br />羁旅惜宴会，艰难怀友朋。<br />劳生共几何，离恨兼相仍。</p>

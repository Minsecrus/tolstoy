# 棕拂子

<p class="du-fu-verse">棕拂且薄陋，岂知身效能。<br />不堪代白羽，有足除苍<small class="du-fu-variant">一作青</small>蝇。<br />荧荧金错刀<sup class="footnote-ref" id="note-ref-du-fu-0193-1"><a href="#note-du-fu-0193-1">〔一〕</a></sup>，擢擢朱丝绳。<br />非独颜色好，亦用<small class="du-fu-variant">晋作由</small>顾盻称。<br />吾老抱疾病，家贫卧炎蒸。<br />咂肤倦扑灭，赖尔甘服膺。<br />物微世竞弃，义在谁肯征。<br />三岁清秋至<sup class="footnote-ref" id="note-ref-du-fu-0193-2"><a href="#note-du-fu-0193-2">〔二〕</a></sup>，未敢阙缄縢。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0193-1"><span class="footnote-number">〔一〕</span>金错：《文选·四愁诗》：“美人赠我金错刀。”善注：“《续汉书》曰：佩刀，诸侯王黄金错环。”谢承《后汉书》：“诏赐应奉金错把刀。”《前汉志》：“新室更造契刀、错刀，错刀以黄金错其文，一刀直五千。”此云“荧荧金错刀”，谓佩刀也。《对雪》诗云：“金错囊徒罄。”谓钱刀也。《虎牙行》云：“金错旌竿满云直。”谓以黄金错镂旗竿也。盖古人以金错器，皆谓之金错。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0193-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0193-2"><span class="footnote-number">〔二〕</span>清秋：张九龄《白羽扇赋》：“纵秋气之移夺，终感恩于箧中。”此诗落句，亦九龄之意。而云“不堪代白羽”，其托喻深厚可讽。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0193-2" aria-label="返回正文">↩</a></span></p>

# 桃竹杖引

<small class="du-fu-variant">赠章留后</small>

<p class="du-fu-verse">江心<small class="du-fu-variant">一作上</small>蟠石生桃竹<sup class="footnote-ref" id="note-ref-du-fu-0194-1"><a href="#note-du-fu-0194-1">〔一〕</a></sup>，苍波喷浸尺度足。<br />斩根削皮如紫玉，江妃水仙惜不得<sup class="footnote-ref" id="note-ref-du-fu-0194-2"><a href="#note-du-fu-0194-2">〔二〕</a></sup>。<br />梓橦使君<small class="du-fu-variant">一作者</small>开一束，满堂宾客皆叹息。<br />怜我老病赠两茎，出入仄甲铿有声。<br />老夫复欲东南征，乘涛鼓枻<small class="du-fu-variant">一作棹</small>白帝城。<br />路幽必为鬼神夺，拔<small class="du-fu-variant">一作杖</small>剑或与蛟龙争。<br />重为告曰：杖兮杖兮，尔之生也甚正直，慎勿见水踊跃学变化为龙。<br />使我不得尔之扶持，灭迹于君山湖上之青峰。<br />噫！<br />风尘<img class="du-fu-glyph" src="/library/volume-94/images/glyph-ab38c7a12147f0f8ac5a.jpg" alt="原书用字" style="width: 1.050em" />洞兮豺虎咬人，忽失双杖兮吾将曷从。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0194-1"><span class="footnote-number">〔一〕</span>桃竹：《蜀都赋》：灵寿桃枝。注曰：桃枝，竹属也。出蛰江县，可以为杖。《元和郡国志》：合州铜梁山出桃枝竹。东坡《跋桃枝杖引后》：桃竹，叶如棕，身如竹。密节而实中，犀理瘦骨，盖天成拄杖也。岭外人多种此，而不知其为桃竹，流传四方，视其端有眼者，盖自东坡出也。又《书柳子厚诗》云：盛时一失贵反贱，桃笙葵扇安可常。偶阅《方言》：簟，宋、魏之间谓之笙。乃悟桃笙以桃竹为簟也。梁简文《答南平王饷舞簟书》云：五离九折，出桃枝之翠笋。乃谓桃枝竹簟也。郭璞有《桃杖赞》。桃竹出巴渝间。子美有《桃竹歌》。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0194-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0194-2"><span class="footnote-number">〔二〕</span>江妃水仙：《江赋》：冯夷倚浪以傲睨，江妃含嚬而绵眇。王逸《楚词注》：冯夷，水仙人。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0194-2" aria-label="返回正文">↩</a></span></p>

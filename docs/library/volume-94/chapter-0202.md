# 发阆中<sup class="footnote-ref" id="note-ref-du-fu-0202-1"><a href="#note-du-fu-0202-1">〔一〕</a></sup>

<p class="du-fu-verse">前有毒蛇后猛虎，溪行尽日无村坞。<br />江风萧萧云拂地，山木惨惨天欲雨。<br />女病妻忧归意速<small class="du-fu-variant">一作急，</small>秋花锦石谁复<small class="du-fu-variant">樊作能</small>数。<br />别家三月一得书<small class="du-fu-variant">一作书来，</small>避地何时免愁苦！</p>

《云溪友议》：李太白为《蜀道难》，乃为房、杜危之也。杜初作《阆中行》：豺狼当路，无地游从。太白初出蜀，即以《行路难》示贺知章。而野史记严武与房、杜相忤，皆在太白已卒之后。知《友议》非笃论也。

<p class="footnote-definition footnote-source" id="note-du-fu-0202-1"><span class="footnote-number">〔一〕</span>阆中：《水经注》：汉水又东南过巴郡。阆中县，巴西郡治也。刘璋之分三巴，此其一焉。《寰宇志》：阆中县，本汉旧县。阆水迂曲，经其三面。县居其中，盖取为县名。《阆地志》：阆江迂曲，三面环之，曰阆中。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0202-1" aria-label="返回正文">↩</a></span></p>

# 冬狩行

<small class="du-fu-variant">时梓州刺史章彝，兼侍御史，留后东川。</small>

<p class="du-fu-verse">君不见东川节度兵马雄，校猎亦似观成功。<br />夜发猛士三千人，清晨合围步骤同。<br />禽兽已毙十七八，杀声落日回苍穹。<br />幕前生致九青兕，馲驼<img class="du-fu-glyph" src="/library/volume-94/images/glyph-6080d69409bd0edbb36e.jpg" alt="原书用字" style="width: 0.900em" />峞垂玄熊。<br />东西南北百里间，仿佛蹴踏寒山空。<br />有鸟名鸲鹆，力不能高飞逐走蓬。<br />肉味不足登鼎俎，何为见羁虞罗中。<br />春搜冬狩侯<small class="du-fu-variant">一作候</small>得同，使君五马一马骢。<br />况今摄行大将权，号令颇有前贤风。<br />飘然时危一老翁，十年厌见旌旗红。<br />喜君士卒甚整肃，为我回辔擒西戎。<br />草中狐兔尽何益，天子不在咸阳宫。<br />朝廷虽无幽王祸，得不哀痛尘再蒙！<br />呜呼，得不哀痛尘再蒙！</p>

《旧书·严武传》：上皇诰：以剑两川合为一道。是时已废东川节度使，故章以刺史领留后事。诗云“东川节度”，则循其旧称也。时代宗幸陕，诏征天下兵，无一人应召者。故公感激言之。

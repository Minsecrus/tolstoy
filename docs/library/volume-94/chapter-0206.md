# 自平

<p class="du-fu-verse">自平宫中吕太一<small class="du-fu-variant">一作中宫，一作中官</small><sup class="footnote-ref" id="note-ref-du-fu-0206-1"><a href="#note-du-fu-0206-1">〔一〕</a></sup>，收珠南海千余日。<br />近供生犀翡翠稀，复恐征戎<small class="du-fu-variant">一作戍</small>干戈密。<br />蛮溪豪族小<small class="du-fu-variant">一作山</small>动摇，世封刺史非时<small class="du-fu-variant">一作常</small>朝<sup class="footnote-ref" id="note-ref-du-fu-0206-2"><a href="#note-du-fu-0206-2">〔二〕</a></sup>。<br />蓬莱殿前<small class="du-fu-variant">一作里</small>诸主将，才如伏波不得骄。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0206-1"><span class="footnote-number">〔一〕</span>吕太一：《旧书》：广德元年，宦官市舶使吕太一逐广南节度使张休，纵下大掠广州。《韦伦传》：代宗即位，中官吕太一于岭南矫诏募兵为乱。《通鉴》：张休弃城走端州，太一纵兵焚掠，官军讨平之。黄鹤曰：考《旧史》，当作中官吕太一。师古注云：《拾遗》有吕宁为太一宫使，唐未有此官号。太一，即人名也，亦初不云吕宁。按：鹤注良是。所谓《拾遗》者，即师古辈妄撰，如伪苏注之类。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0206-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0206-2"><span class="footnote-number">〔二〕</span>刺史：旧注：太宗时，溪洞蛮夷来归顺者，皆授以刺史，不以时朝，比于内诸侯，姑务羁糜而已。公《两川说》：八州素归心于其世袭刺史。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0206-2" aria-label="返回正文">↩</a></span></p>

笺曰：此诗言唐盛时处置蛮夷之法。“蛮溪豪族小动摇”，言其小小蠢动，朝廷置之不问也。“世封刺史非时朝”，不责以时朝之礼也。如此则蛮夷率俾，虽有伏波之将，不得生事于外夷也。“蓬莱殿前诸主将”，指中官掌禁军者而言。

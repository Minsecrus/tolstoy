# 释闷

<p class="du-fu-verse">四海十年不解兵，犬戎<small class="du-fu-variant">一作羊</small>也复临咸京。<br />失道非关出襄野，扬鞭忽是过胡<small class="du-fu-variant">晋作湖</small>城<sup class="footnote-ref" id="note-ref-du-fu-0207-1"><a href="#note-du-fu-0207-1">〔一〕</a></sup>。<br />豺狼塞路人断绝，烽火照夜尸纵横。<br />天子亦应厌奔走，群公固合思升平。<br />但恐诛求不改辙，闻道嬖孽能<small class="du-fu-variant">一作今</small>全生<sup class="footnote-ref" id="note-ref-du-fu-0207-2"><a href="#note-du-fu-0207-2">〔二〕</a></sup>。<br />江边老翁错料事，眼暗不见风尘清。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0207-1"><span class="footnote-number">〔一〕</span>扬鞭：《世说》：王大将军领军姑熟。晋明帝着戎服，骑巴賨马，赍一金马鞭，阴察军形势。按，《晋书》：敦屯兵于湖阴，故曰湖城。吴若本注曰：晋王敦举兵内向，元帝微行至于湖，阴察敦营垒事。自唐以来，皆破句读。故温庭筠乐府有《湖阴曲》，金陵地名有湖阴。张文潜云“微行至于湖”句断。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0207-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0207-2"><span class="footnote-number">〔二〕</span>嬖孽：谓代宗不能诛程元振也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0207-2" aria-label="返回正文">↩</a></span></p>

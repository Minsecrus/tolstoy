# 赠别贺兰铦

<p class="du-fu-verse">黄雀饱野粟，群飞动荆榛。<br />今君抱何恨，寂寞向时人。<br />老骥倦骧首，苍<small class="du-fu-variant">一作饥</small>鹰愁易驯。<br />高贤世未识，固合婴饥贫。<br />国步初返正<sup class="footnote-ref" id="note-ref-du-fu-0208-1"><a href="#note-du-fu-0208-1">〔一〕</a></sup>，乾坤尚风尘。<br />悲歌鬓发白，远赴湘吴春。<br />我恋岷下芋<sup class="footnote-ref" id="note-ref-du-fu-0208-2"><a href="#note-du-fu-0208-2">〔二〕</a></sup>，君思千里莼。<br />生离与死别，自古鼻酸辛。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0208-1"><span class="footnote-number">〔一〕</span>国步：谓代宗幸陕初还也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0208-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0208-2"><span class="footnote-number">〔二〕</span>芋：《水经注》：江都县滨文井江。江上有常氏堤，跨四十里。有朱亭，亭南有青城山，山上有嘉谷，山下有蹲鸱，即芋也。所谓“下有蹲鸱，至老不饥”，卓氏之所以乐远徙也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0208-2" aria-label="返回正文">↩</a></span></p>

# 阆山歌

<p class="du-fu-verse">阆州城东灵<small class="du-fu-variant">一作雪</small>山白<sup class="footnote-ref" id="note-ref-du-fu-0210-1"><a href="#note-du-fu-0210-1">〔一〕</a></sup>，阆州城北玉台<small class="du-fu-variant">一作壶</small>碧<sup class="footnote-ref" id="note-ref-du-fu-0210-2"><a href="#note-du-fu-0210-2">〔二〕</a></sup>。<br />松浮欲尽不尽云，江动将崩未崩石。<br />那知根无鬼神会，已觉气与嵩华敌。<br />中原格斗且未归，应结茅斋看<small class="du-fu-variant">一作着</small>青壁<small class="du-fu-variant">一作应著茅斋向青壁。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0210-1"><span class="footnote-number">〔一〕</span>灵山：《寰宇记》：仙穴山，在阆中县东北十里。《舆地图》云：灵山峰多杂树，昔蜀王鳖灵帝登此，因名灵山。山东南隅有玉女捣练石，山顶有池常清，有洞穴悬绝，微有一小径通。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0210-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0210-2"><span class="footnote-number">〔二〕</span>玉台：《舆地纪胜》：玉台观在城北七里。唐滕王尝游之，有滕王亭基。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0210-2" aria-label="返回正文">↩</a></span></p>

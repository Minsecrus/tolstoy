# 阆水歌

<p class="du-fu-verse">嘉陵江色<small class="du-fu-variant">一作山</small>何所似<sup class="footnote-ref" id="note-ref-du-fu-0211-1"><a href="#note-du-fu-0211-1">〔一〕</a></sup>，石黛碧玉相因依。<br />正怜日破浪花<small class="du-fu-variant">一云阆山</small>出，更复春从沙际归。<br />巴童荡桨欹侧过，水鸡衔鱼来去飞。<br />阆中胜事可肠断<sup class="footnote-ref" id="note-ref-du-fu-0211-2"><a href="#note-du-fu-0211-2">〔二〕</a></sup>，阆州城南天下稀。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0211-1"><span class="footnote-number">〔一〕</span>嘉陵：《水经注》：汉水又南径阆中县东，阆水出阆阳县而东，径其县南，又东注汉水。《寰宇记》：嘉陵水又名西汉水，又名阆中水。《周地图》云：水源出秦州嘉陵，因名嘉陵，经阆中，即阆中水，亦曰阆江，又曰渝水。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0211-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0211-2"><span class="footnote-number">〔二〕</span>阆中：阆中山，其山四合于郡，故曰阆中。《名山志》云：阆中山多仙圣游集焉。《方舆胜览》：亦名锦屏山，在城南三里。冯忠恕记云：阆之为郡，当梁、洋、梓、益之冲，有五城十二楼之胜概。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0211-2" aria-label="返回正文">↩</a></span></p>

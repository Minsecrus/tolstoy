# 草堂

<p class="du-fu-verse">昔我去草堂，蛮夷塞成都。<br />今我归草堂，成<small class="du-fu-variant">一作此</small>都适无虞。<br />请陈初乱时，反覆乃须臾<small class="du-fu-variant">一作斯须。</small>大将赴朝廷，群小起异图。<br />中宵斩白马，盟歃气已粗。<br />西取邛南兵，北断剑阁隅。<br />布衣数十人，亦拥专城居。<br />其势不两大，始闻蕃汉殊。<br />西卒却倒戈，贼臣互相诛。<br />焉知肘腋祸，自及枭镜徒。<br />义士皆痛愤，纪纲乱相逾。<br />一国实三公，万人欲为鱼。<br />唱和作威福，孰肯<small class="du-fu-variant">一作能</small>辨无辜。<br />眼前列杻械，背后吹笙竽。<br />谈笑行杀戮，溅<small class="du-fu-variant">一作流</small>血满长衢。<br />到今用钺地，风雨闻号呼。<br />鬼<small class="du-fu-variant">一作人</small>妾与鬼马<sup class="footnote-ref" id="note-ref-du-fu-0213-1"><a href="#note-du-fu-0213-1">〔一〕</a></sup>，色悲充尔娱。<br />国家法令在，此又足惊吁。<br />贱子且奔走，三年望东吴。<br />弧矢暗江海，难为游五湖。<br />不忍竟舍此，复来薙榛芜。<br />入门四松在，步屧<small class="du-fu-variant">一作堞</small>万竹疏。<br />旧犬喜我归，低徊入衣<small class="du-fu-variant">旧作我</small>裾。<br />邻舍喜我归，沽酒携胡芦<small class="du-fu-variant">一云提榼壶。</small>大官喜<small class="du-fu-variant">一作知</small>我来，遣骑问所须。<br />城郭喜<small class="du-fu-variant">一作知</small>我来，宾客隘<small class="du-fu-variant">一作溢</small>村墟。<br />天下尚未宁，健儿胜腐儒。<br />飘飖<small class="du-fu-variant">一作飘飘</small>风尘际，何地置一<small class="du-fu-variant">作致</small>老夫？<br />于时见<small class="du-fu-variant">一作是</small>疣赘，骨髓幸未枯。<br />饮啄愧残生，食薇不敢余。</p>

宝应元年四月，严武入朝。七月，剑南西川节度使徐知道反，八月伏诛。公携家避乱往梓州。广德二年，武镇剑南，公复还成都草堂。此诗云“大将赴朝廷，群小起异图”，谓武入朝而知道反也。“北断剑阁隅”，谓知道以兵守要害，武不得出也。“贼臣互相诛”，谓知道为其下李忠厚所杀也。王洙、梁权道辈，以为永泰元年避崔旰之乱。而吴若本于“布衣”“专城”之下注云：即杨子琳、柏贞节之徒。是时严武已没，公下峡适楚，何尝复归草堂哉？注家唯黄鹤能辨之。

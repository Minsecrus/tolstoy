# 水槛

<p class="du-fu-verse">苍江多风飙，云雨昼夜飞。<br />茅轩驾巨浪，焉得不低垂。<br />游子久在外，门户无人持。<br />高岸尚如<small class="du-fu-variant">一作为</small>谷，何伤浮柱欹<sup class="footnote-ref" id="note-ref-du-fu-0215-1"><a href="#note-du-fu-0215-1">〔一〕</a></sup>。<br />扶颠有劝诫，恐贻识者嗤。<br />既殊大厦倾，可以一木支。<br />临川视万里，何必栏槛为。<br />人生感故物，慷慨有余悲。</p>

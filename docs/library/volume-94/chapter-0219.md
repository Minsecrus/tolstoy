# 扬旗

<small class="du-fu-variant">二年夏六月，成都尹严公置酒公堂，观骑士试新旗帜。</small>

<p class="du-fu-verse">江<small class="du-fu-variant">一作风</small>雨飒长夏，府中有余清。<br />我公会宾客，肃肃有异声。<br />初筵阅军装，罗列照广庭。<br />庭空六<small class="du-fu-variant">一作四</small>马入，駊騀扬旗<small class="du-fu-variant">一作斾</small>旌。<br />回回偃飞盖，熠熠迸流星。<br />来缠<small class="du-fu-variant">一作冲</small>风飙急，去擘山岳倾。<br />材归俯身尽，妙取略地平。<br />虹霓就掌握，舒卷随人轻。<br />三州陷犬戎<sup class="footnote-ref" id="note-ref-du-fu-0219-1"><a href="#note-du-fu-0219-1">〔一〕</a></sup>，但见西岭青。<br />公来练猛士，欲夺天边城。<br />此堂不易升，庸蜀日已宁。<br />吾徒且加餐，休适蛮与荆。</p>

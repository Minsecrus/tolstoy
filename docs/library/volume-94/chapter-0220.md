# 太子张舍人遗织成褥段

<p class="du-fu-verse">客从西北来，遗我翠<small class="du-fu-variant">一作细</small>织成<sup class="footnote-ref" id="note-ref-du-fu-0220-1"><a href="#note-du-fu-0220-1">〔一〕</a></sup>。<br />开缄风涛涌，中有掉尾鲸。<br />逶迤罗水族，琐细不足名。<br />客云充君褥，承君终宴荣。<br />空堂魑魅<small class="du-fu-variant">一作魍魉</small>走，高枕形神清。<br />领客珍重意，顾我非公卿。<br />留之惧不祥，施之混柴荆。<br />服饰定尊卑，大哉万古程。<br />今我一贱老，裋<small class="du-fu-variant">一作短</small>褐更无营。<br />煌煌珠宫物，寝处祸所婴<small class="du-fu-variant">一作萦。</small>叹息当路子，干戈尚纵横。<br />掌握有权柄，衣马自<small class="du-fu-variant">一云已</small>肥轻。<br />李鼎死岐阳<sup class="footnote-ref" id="note-ref-du-fu-0220-2"><a href="#note-du-fu-0220-2">〔二〕</a></sup>，实以骄贵盈。<br />来瑱赐自尽<sup class="footnote-ref" id="note-ref-du-fu-0220-3"><a href="#note-du-fu-0220-3">〔三〕</a></sup>，气豪直<small class="du-fu-variant">晋作真</small>阻兵。<br />皆闻黄金多<small class="du-fu-variant">皆闻一作昔闻，</small>坐见悔吝生。<br />奈何田舍翁，受此厚贶情。<br />锦鲸卷还客，始觉心和平。<br />振我粗席尘，愧客茹<small class="du-fu-variant">一作饭</small>蔾羹。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0220-1"><span class="footnote-number">〔一〕</span>织成：《广雅》：天竺出细织成。《宋书·礼志》：诸织成衣帽、锦帐，纯金银器、云母，从广一寸以上者，皆为禁物。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0220-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0220-2"><span class="footnote-number">〔二〕</span>李鼎：上元元年，以羽林大将军李鼎为凤翔尹，兴、凤、陇等州节度使。二年二月，党项平羌寇宝鸡，入散关，陷凤州、凤翔，李鼎邀击之。六月，以鼎为鄯州刺史、陇右节度。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0220-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0220-3"><span class="footnote-number">〔三〕</span>来瑱：来瑱为襄阳节度使，代宗潜令裴茙图之，瑱擒茙于申江，入朝谢罪。广德元年正月，贬播州尉。翌日，赐死于鄠县。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0220-3" aria-label="返回正文">↩</a></span></p>

笺曰：史称严武累年在蜀，肆志逞欲，恣行猛政，穷极奢靡，赏赐无度。公在武幕下，此诗特借以讽谕，朋友责善之道也。不然辞一织成之遗，而侈谈杀身自尽之祸，不疾而呻，岂诗人之意乎？《草堂诗笺》次于广德二年，在严郑公幕中之作。当从之。

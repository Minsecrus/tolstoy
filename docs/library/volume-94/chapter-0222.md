# 别蔡十四著作

<p class="du-fu-verse">贾生恸哭后，寥落无其人。<br />安知蔡夫子，高义迈等伦。<br />献书谒皇帝，志已清风尘。<br />流涕洒丹极，万乘为酸辛。<br />天地则创痍，朝廷当<small class="du-fu-variant">一作多</small>正臣。<br />异才复间出，周道日惟新。<br />使蜀见知己，别颜始一伸。<br />主人薨城府<sup class="footnote-ref" id="note-ref-du-fu-0222-1"><a href="#note-du-fu-0222-1">〔一〕</a></sup>，扶榇归咸秦。<br />巴道此相逢，会我病江滨。<br />忆念凤翔都，聚散俄十春。<br />我衰不足道，但愿子意<small class="du-fu-variant">一作音</small>陈。<br />稍令社稷安，自契鱼水亲。<br />我虽消渴甚，敢忘帝力勤。<br />尚思未朽骨，复睹耕桑民。<br />积水驾三峡，浮龙倚长津<small class="du-fu-variant">一云轮囷。</small>扬舲洪涛间，仗子济物身。<br />鞍马下秦塞，王城通北辰。<br />玄甲聚不散，兵久食恐贫。<br />穷谷无粟帛，使者来相因。<br />若凭<small class="du-fu-variant">一云逢</small>南辕吏<small class="du-fu-variant">陈作使，</small>书札到天垠。</p>

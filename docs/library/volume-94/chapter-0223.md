# 杜鹃

<p class="du-fu-verse">西川有杜鹃，东川无杜鹃。<br />涪万无杜鹃，云安有杜鹃。<br />我昔游锦城，结庐锦水边。<br />有竹一顷余，乔木上参天。<br />杜鹃暮春至，哀哀叫其间。<br />我见常再拜，重是古帝魂。<br />生子百鸟巢<sup class="footnote-ref" id="note-ref-du-fu-0223-1"><a href="#note-du-fu-0223-1">〔一〕</a></sup>，百鸟不敢嗔<small class="du-fu-variant">一作喧。</small>仍为餧其子，礼若奉至尊。<br />鸿雁及羔羊<sup class="footnote-ref" id="note-ref-du-fu-0223-2"><a href="#note-du-fu-0223-2">〔二〕</a></sup>，有礼太古前。<br />行飞与跪乳，识序如<small class="du-fu-variant">一作又</small>知恩。<br />圣贤古<small class="du-fu-variant">一作吾</small>法则，付与<small class="du-fu-variant">一作之</small>后世传。<br />君看禽鸟情，犹解事杜鹃。<br />今忽暮春间，值我病经年。<br />身病不能拜，泪下如迸泉。</p>

题下旧注云：时明皇在蜀蒙尘。陈浩然本无此七字，当从陈本。此诗大历元年公在云安作，明皇晏驾久矣。

夏竦曰：诗前四句乃序耳，以叶韵，误以为诗，本题下甫自注耳。王直方曰：此与古谣语无异，岂复以韵为限耶？黄希曰：《白头吟》词云：“郭东亦有樵，郭西亦有樵。”此诗前四句或本此。吴曾《漫录》曰：乐府江南古词：“鱼戏莲叶间，鱼戏莲叶西。鱼戏莲叶南，鱼戏莲叶北。”子美正用此格。

<p class="footnote-definition footnote-source" id="note-du-fu-0223-1"><span class="footnote-number">〔一〕</span>寄巢：《博物志》：杜鹃生子，寄之他巢，百鸟为饲之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0223-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0223-2"><span class="footnote-number">〔二〕</span>鸿雁：羊祐《雁赋》：鸣则相和，行则接武，前不绝贯，后不越序。 羔羊：《春秋繁露》：羔饮其母必跪，类知礼者也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0223-2" aria-label="返回正文">↩</a></span></p>

笺曰：《东坡外集》载《辨王谊伯论杜鹃》云：子美盖讥当时之刺史，有不禽鸟若也。严武在蜀，虽横敛刻薄，而实资中原，是“西川有杜鹃”。其不虔王命，擅军旅，绝贡赋以自固，如杜克逊在梓州，是“东川无杜鹃”耳。涪、万、云安刺史，微不可考。其尊君者为有，怀贰者为无，不在夫杜鹃真有无也。按：杜克逊事，《新》《旧》两书俱无可考。严武在东川之后，节制东川者，李奂、张献诚也。其以梓州反者，段子璋也。梓州刺史见《杜集》者，有李梓州、杨梓州、章梓州，未闻有杜也。既曰讥当时之刺史，不应以严武并列也。逆节之臣，前有段子璋，后有崔旰、杨子琳，不当舍之而刺涪、万之刺史，微不可考者也。所谓杜克逊者，既不见史传，则亦子虚、无是之流，出后人伪撰耳。其文义舛错鄙倍，必非东坡之言。世所传《志林》诸书，多出妄庸人假托，如伪苏注之类，而无识者误编之集中也。黄鹤本载旧本题注云：“上皇幸蜀还，肃宗用李辅国谋，迁之西内，上皇悒悒而崩。此诗感是而作。”详味此诗，仍当以旧注为是。

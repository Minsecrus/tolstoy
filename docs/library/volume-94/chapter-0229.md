# 三韵三篇

<p class="du-fu-verse">高马勿唾<small class="du-fu-variant">一作捶</small>面，长鱼无损鳞。<br />辱马马毛焦，困鱼鱼有神。<br />君看磊落士，不肯易其身。</p>

<p class="du-fu-verse">荡荡万斛船，影若扬白虹扬，<small class="du-fu-variant">一作摇。</small>起樯必椎牛，挂席集众功。<br />自非风动天，莫置大水中。</p>

<p class="du-fu-verse">烈<small class="du-fu-variant">一作列</small>士恶多门，小人自同调。<br />名利苟可取，杀身傍权要。<br />何当官曹清，尔辈堪一笑。</p>

鹤曰：此诗刺广德、永泰间朝士之趋附元载、鱼朝恩者。

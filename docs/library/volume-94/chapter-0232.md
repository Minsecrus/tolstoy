# 蚕谷行

<p class="du-fu-verse">天下郡国向万城，无有一城无甲兵。<br />焉得铸甲作农器，一寸荒田牛得耕。<br />牛尽耕，<small class="du-fu-variant">一有田字</small>蚕亦成。<br />不劳烈士泪滂沱，男谷女丝行复歌。</p>

“无有一城无甲兵”言天下皆用兵也。鹤必欲举某年某事以实之，可谓固矣。

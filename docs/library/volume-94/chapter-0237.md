# 负薪行

<p class="du-fu-verse">夔州处女发半华，四十五十无夫家。<br />更遭丧乱嫁不售，一生抱恨堪<small class="du-fu-variant">一作长</small>咨嗟。<br />土风坐男使女立，应<small class="du-fu-variant">坡作男</small>当门户<small class="du-fu-variant">一作应门当户</small>女出入。<br />十犹<small class="du-fu-variant">一作有</small>八九负薪归，卖薪得钱应<small class="du-fu-variant">一作当</small>供给。<br />至老双鬟<small class="du-fu-variant">一作镮</small>只垂颈，野花山叶银钗并。<br />筋力登危集市门，死生射利兼盐井<sup class="footnote-ref" id="note-ref-du-fu-0237-1"><a href="#note-du-fu-0237-1">〔一〕</a></sup>。<br />面妆首饰杂啼痕，地褊衣寒困石根。<br />若道巫山女粗丑，何得此<small class="du-fu-variant">一作北</small>有昭君村<sup class="footnote-ref" id="note-ref-du-fu-0237-2"><a href="#note-du-fu-0237-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0237-1"><span class="footnote-number">〔一〕</span>盐井：《荆州图副》云：八阵图下，东西三里有一碛。碛上有盐泉井五口，以木为桶，昔常取<sup class="footnote-ref" id="note-ref-du-fu-0237-3"><a href="#note-du-fu-0237-3">[1]</a></sup>盐，即时沙壅，冬出夏没。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0237-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0237-2"><span class="footnote-number">〔二〕</span>昭君村：应劭曰：王嫱，王氏女，名嫱，字昭君。文颖曰：本南郡秭归人也。《寰宇记》：归州兴山县，有王昭君宅。王嫱即此邑人也，故曰昭君之县，村连巫峡，是此地。香溪在邑界，即昭君所游。《方舆胜览》：州东北四十里，有昭君村。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0237-2" aria-label="返回正文">↩</a></span></p>

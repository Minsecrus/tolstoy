# 驱竖子摘苍耳

<p class="du-fu-verse">江上秋已分，林<small class="du-fu-variant">一作村</small>中瘴犹剧。<br />畦丁告劳苦，无以供日夕。<br />蓬莠独不<small class="du-fu-variant">独一作犹</small>焦，野蔬暗泉石。<br />卷耳况疗风，童儿且时摘<small class="du-fu-variant">一云童仆先时摘。</small>侵星驱之去，烂熳任远适。<br />放筐亭<small class="du-fu-variant">一作当</small>午际，洗剥相蒙羃<sup class="footnote-ref" id="note-ref-du-fu-0261-1"><a href="#note-du-fu-0261-1">〔一〕</a></sup>。<br />登床半生熟，下箸还小益。<br />加点瓜薤间，依稀橘<small class="du-fu-variant">一作木</small>奴迹。<br />乱世诛求急，黎民糠籺窄。<br />饱食复何心，荒哉膏粱客。<br />富家厨肉臭，战地骸骨白。<br />寄语恶少年，黄金且休掷。</p>

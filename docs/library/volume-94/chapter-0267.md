# 又上后园山脚

<p class="du-fu-verse">昔我游山东，忆戏东岳阳。<br />穷秋立日观，矫首望八<small class="du-fu-variant">一云北</small>荒。<br />朱崖著毫发，碧海吹衣裳。<br />蓐收困用事，玄冥蔚强梁<sup class="footnote-ref" id="note-ref-du-fu-0267-1"><a href="#note-du-fu-0267-1">〔一〕</a></sup>。<br />逝水自朝宗，镇名各其方。<br />平原独憔悴，农力废耕桑。<br />非关<small class="du-fu-variant">一作北阙</small>风露凋，曾是戍役伤。<br />于时国用富，足以守边疆。<br />朝廷任猛将，远夺戎虏场。<br />到今事反覆，故老泪万行。<br />龟蒙不复见，况乃怀旧<small class="du-fu-variant">一作故</small>乡。<br />肺萎属久战，骨出热中肠。<br />忧来杖匣剑，更上林北冈。<br />瘴毒猿鸟落，峡干南日黄。<br />秋风亦已起，江汉始如汤。<br />登高欲有往，荡析川无梁。<br />哀彼远征人，去家死路旁。<br />不及祖父茔，累累冢相当。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0267-1"><span class="footnote-number">〔一〕</span>蓐收玄冥：蓐收，金神，西方也。玄冥，水神，北方也。穷秋之时，蓐收将退，而玄冥方来，喻长安渐凋敝，而禄山方强梁于范阳也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0267-1" aria-label="返回正文">↩</a></span></p>

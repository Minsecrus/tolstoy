<h1>暇日小园散病将种秋菜督勒耕牛兼书触目</h1>

<p class="du-fu-verse">不爱入州府，畏人嫌我真。<br />及乎归茅宇，旁舍未曾嗔。<br />老病忌拘束，应接丧精神。<br />江村意自放，林木心所欣。<br />秋耕属地湿，山雨近甚匀。<br />冬菁饭之半，牛力晚来新。<br />深耕种数亩，未甚后四邻。<br />嘉蔬既不一，名数颇具陈。<br />荆巫非苦寒，采撷接青春。<br />飞来两白鹤，暮啄泥中芹。<br />雄者左翮垂，损伤已露筋。<br />一步再流血，尚经一矰缴勤。<br />三步六号叫，志屈悲哀频。<br />鸾凰不相待，侧颈诉高旻。<br />杖藜俯沙渚，为汝鼻酸辛。</p>

# 暇日小园散病将种秋菜督勒耕牛兼书触目

<p class="du-fu-verse">不爱入州府，畏人嫌我真。<br />及乎归茅宇<small class="du-fu-variant">一云及归在茅屋，</small>旁舍未曾嗔。<br />老病忌<small class="du-fu-variant">一作恐</small>拘束，应接丧精神。<br />江村意自<small class="du-fu-variant">一作日</small>放，林木心所欣。<br />秋耕属地湿，山雨近甚匀。<br />冬菁饭之半，牛力晚<small class="du-fu-variant">一作晓</small>来新。<br />深耕种数亩，未甚后四邻。<br />嘉蔬既不一，名数颇具陈。<br />荆巫非苦寒，采撷接青春。<br />飞来两白鹤<sup class="footnote-ref" id="note-ref-du-fu-0272-1"><a href="#note-du-fu-0272-1">〔一〕</a></sup>，暮啄泥中芹。<br />雄者左翮垂，损伤已露<small class="du-fu-variant">一作及</small>筋。<br />一步再流血，尚经一<small class="du-fu-variant">作惊</small>矰缴勤。<br />三步六号叫，志屈悲哀频。<br />鸾凰不相待，侧颈诉高旻。<br />杖藜俯沙渚，为汝鼻酸辛。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0272-1"><span class="footnote-number">〔一〕</span>白鹄：古乐府《艳歌何尝行》，一曰《飞鹄行》：“飞来双白鹄，乃从西北来。十十五五，罗列成行。妻卒被病，行不能相随。五里一反顾，六里一徘徊。吾欲衔汝去，口噤不能开。吾欲负汝去，毛羽何推颓。乐哉新相知，忧来生别离。踌蹰顾群侣，泪下不自知。”梦弼曰：此诗全用古乐府《艳歌行》四解之意。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0272-1" aria-label="返回正文">↩</a></span></p>

# 狄明府

<small class="du-fu-variant">博济。一作寄狄明府。</small>

<p class="du-fu-verse">梁公曾孙我姨弟，不见十年官济济。<br />大贤之后竟陵迟，浩荡古今同一体。<br />比看叔伯四十人，有才无命百僚底。<br />今者兄弟一百人，几人卓绝秉周礼。<br />在汝更用文章为，长兄白眉复天启。<br />汝门请从曾翁<small class="du-fu-variant">一云公</small>说，太后当朝多巧诋<small class="du-fu-variant">一作计。</small>狄公执政在末年，浊河终<small class="du-fu-variant">陈浩然本作中</small>不污清济。<br />国嗣初将付诸武，公独廷诤守丹陛。<br />禁中决册<small class="du-fu-variant">陈作册决</small>请<small class="du-fu-variant">一作诏</small>房陵<sup class="footnote-ref" id="note-ref-du-fu-0289-1"><a href="#note-du-fu-0289-1">〔一〕</a></sup>，前<small class="du-fu-variant">一作满</small>朝长老皆流涕。<br />太宗社稷一朝正，汉官威仪重昭洗。<br />时危始识不世才，谁谓荼苦甘如荠。<br />汝曹又宜列土<small class="du-fu-variant">一作鼎</small>食，身使门户多旌棨。<br />胡为漂泊岷汉间，干谒王侯颇历抵<small class="du-fu-variant">一作诋。</small>况乃山高水有波，秋风萧萧露泥泥。<br />虎之饥，下巉岩，蛟之横，出清泚。<br />早归来，黄土泥衣<small class="du-fu-variant">浩然本作黄污人衣</small>眼易眯。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0289-1"><span class="footnote-number">〔一〕</span>决册：《旧书》：中宗自房陵还宫，则天匿之帐中，召仁杰以庐陵为言。仁杰慷慨敷奏，言发涕流，遽出中宗谓仁杰曰：“还卿储君。”仁杰降阶泣贺，既已，奏曰：“太子还宫，人无知者，物议安审是非？”则天以为然，乃复置中宗于龙门，具礼迎归，人情感悦。仁杰前后匡复奏对凡数万言，北海太守李邕撰为《梁公别传》，备载其辞。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0289-1" aria-label="返回正文">↩</a></span></p>

# 后苦寒行二首

## 其一

<p class="du-fu-verse">南纪巫庐瘴不绝<sup class="footnote-ref" id="note-ref-du-fu-0297-1"><a href="#note-du-fu-0297-1">〔一〕</a></sup>，太古以来无尺雪。<br />蛮夷长老怨苦寒，昆仑天关冻应<small class="du-fu-variant">《英华》作欲</small>折。<br />玄猿口噤不能啸，白鹄翅垂眼流<small class="du-fu-variant">一作出</small>血，安得春泥补地裂。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0297-1"><span class="footnote-number">〔一〕</span>南纪：旧注：巫、庐二山，南国之纲纪也。《唐·天文志》：李淳风撰《法象志》，以天下山河分为两戒，北戒自积石、终南，负地络之阴，东及太华，逾河并雷首、底柱、王屋、太行，北抵常山之右，乃东循塞垣，至濊貊朝鲜，是为北纪，所以限戎狄也。南戒自岷山、嶓冢，负地络之阳，东极太华，连商山、熊耳、外方、桐柏，自上洛南逾江汉，携武当、荆山，至于衡阳，乃东循岭徼，达东瓯，至闽中，是为南纪，所以限蛮夷也。故《星传》谓北戒为胡门，南戒为越门。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0297-1" aria-label="返回正文">↩</a></span></p>

## 其二

<p class="du-fu-verse">晚<small class="du-fu-variant">一作晓</small>来江门<small class="du-fu-variant">一作边</small>失大木，猛风中夜吹<small class="du-fu-variant">《英华》作飞</small>白屋。<br />天兵斩断<small class="du-fu-variant">《英华》作新斩</small>青海戎，杀气南行动地轴。<br />不尔苦寒何太<small class="du-fu-variant">一作其</small>酷，巴东之峡生凌凘，彼苍回轩<small class="du-fu-variant">旧作轲，刊作斡</small>人得知。</p>

# 寄从孙崇简

<p class="du-fu-verse">嵯峨白帝城东西，南有龙湫北虎溪。<br />吾孙骑曹不骑<small class="du-fu-variant">一作记</small>马，业学尸乡多养鸡。<br />庞公隐时尽室去，武陵春树他人迷。<br />与汝林居未相失，近身药里酒长携。<br />牧竖樵童亦无赖，莫令斩断青云梯<sup class="footnote-ref" id="note-ref-du-fu-0302-1"><a href="#note-du-fu-0302-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0302-1"><span class="footnote-number">〔一〕</span>青云梯：谢灵运诗：惜无同怀客，共登青云梯。张湛《列子注》曰：云梯可以陵虚。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0302-1" aria-label="返回正文">↩</a></span></p>

# 客从

<p class="du-fu-verse">客从南溟来，遗我泉客珠<sup class="footnote-ref" id="note-ref-du-fu-0316-1"><a href="#note-du-fu-0316-1">〔一〕</a></sup>。<br />珠中有隐字，欲辨不成书。<br />缄之箧笥久，以俟公家须。<br />开视化为血，哀今征敛无。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0316-1"><span class="footnote-number">〔一〕</span>泉客：《吴都赋》：泉室潜织而卷绡，渊客慷慨而泣珠。刘渊林注：鲛人从水中出，曾寄寓人家，积日卖绡。临去，从主人家索器，泣而出珠满盘，以与主人。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0316-1" aria-label="返回正文">↩</a></span></p>

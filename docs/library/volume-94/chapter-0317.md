# 白马

<p class="du-fu-verse">白马东北来，空鞍贯双箭。<br />可怜马上郎，意气今谁见。<br />近时主将戮，中夜商<small class="du-fu-variant">一作伤</small>於<sup class="footnote-ref" id="note-ref-du-fu-0317-1"><a href="#note-du-fu-0317-1">〔一〕</a></sup>战。<br />丧乱死多门，呜呼泪如霰。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0317-1"><span class="footnote-number">〔一〕</span>商於：《水经注》：丹水经流南乡两县之间，历於中之北，所谓商於者也，故张仪说楚绝齐，许以商於之地六百里。谓以此也。鹤曰：大历三年二月，商州兵马使刘洽杀防御使殷仲卿，寻讨平之。梦弼曰：谓臧玠杀崔瓘也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0317-1" aria-label="返回正文">↩</a></span></p>

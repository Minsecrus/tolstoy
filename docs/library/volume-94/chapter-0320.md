# 惜别行送向卿进奉端午御衣之上都

<p class="du-fu-verse">肃宗昔在灵武城，指挥猛将收咸京。<br />向公<small class="du-fu-variant">一云向公亦卫伯玉，盖芮字传写之误</small>泣血洒行殿，佐佑卿相乾坤平。<br />逆胡冥寞随烟烬，卿家兄弟功名震。<br />麒麟图<small class="du-fu-variant">一作阁</small>画鸿雁行，紫极出入黄金印。<br />尚书勋业超千古，雄镇荆州继吾祖<sup class="footnote-ref" id="note-ref-du-fu-0320-1"><a href="#note-du-fu-0320-1">〔一〕</a></sup>。<br />裁缝云雾成御衣，拜跪题封向<small class="du-fu-variant">吴本作贺</small>端午。<br />向卿将命寸心赤，青山落日江潮白。<br />卿到朝廷说老翁，漂零已是沧浪客。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0320-1"><span class="footnote-number">〔一〕</span>尚书：广德元年，卫伯玉拜江陵尹，兼御史大夫、荆南节度使，寻加检校工部尚书，封阳城郡王。此云镇荆州，知为伯玉也。“继吾祖”者，杜预以镇南大将军都督荆州诸军事也。向卿者，尚书将命之人也。旧注：尚书指向卿之父珣。又云：向秀继杜预镇荆州。唐人无所谓向珣者。向秀在晋朝，史称其在朝不任职，容迹而已。安得有继杜预镇荆之事？旧注无稽伪撰，皆此类也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0320-1" aria-label="返回正文">↩</a></span></p>

# 发刘郎浦<sup class="footnote-ref" id="note-ref-du-fu-0323-1"><a href="#note-du-fu-0323-1">〔一〕</a></sup>

<p class="du-fu-verse">挂帆早发刘郎浦，疾风飒飒昏亭午。<br />舟中无日不沙尘，岸上空村尽豺虎。<br />十日北风风未回，客行岁晚晚<small class="du-fu-variant">一作兀</small>相催。<br />白头厌伴渔人宿，黄帽青鞋归去来。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0323-1"><span class="footnote-number">〔一〕</span>刘郎浦：吴若本注：蜀先主纳吴女处也。吕温诗云：吴蜀成婚此水浔，明珠步障幄黄金。谁将一女轻天下，欲换刘郎鼎峙心。《十道志》：刘郎浦在荆州。《江陵图经》：在石首县。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0323-1" aria-label="返回正文">↩</a></span></p>

# 别董颋

<p class="du-fu-verse">穷冬急风水，逆浪开帆难。<br />士子甘旨阙，不知道里寒。<br />有求彼乐土，南适小长安<sup class="footnote-ref" id="note-ref-du-fu-0324-1"><a href="#note-du-fu-0324-1">〔一〕</a></sup>。<br />到<small class="du-fu-variant">刊作别</small>我舟楫去，觉君衣裳单。<br />素闻赵公节，兼尽宾主欢。<br />已结门庐<small class="du-fu-variant">一作闾</small>望，无令霜雪残。<br />老夫缆亦解，脱粟朝未餐。<br />飘荡兵甲际，几时怀抱宽。<br />汉阳颇宁静，岘首试考盘。<br />当念着白帽<small class="du-fu-variant">一作褐，</small>采薇青云端。</p>

鹤曰：诗云“急风”“逆浪”，盖董自岳阳溯汉水而之邓也。又云：“老夫缆亦解”，公是时亦有适潭之期矣。

<p class="footnote-definition footnote-source" id="note-du-fu-0324-1"><span class="footnote-number">〔一〕</span>小长安：《光武纪》：战于小长安。注：《续汉书》：淯阳县有小长安聚，故城在今邓州南阳县南。张叔卿《流桂州》诗：胡尘不到处，即是小长安。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0324-1" aria-label="返回正文">↩</a></span></p>

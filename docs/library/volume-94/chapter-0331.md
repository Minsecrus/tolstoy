# 宿凿石浦

<p class="du-fu-verse">早宿宾从劳，仲春江山丽。<br />飘风过无时，舟楫敢不<small class="du-fu-variant">一作不敢</small>系。<br />回塘澹暮色，日没众星嘒。<br />缺月殊未生，青灯死分翳。<br />穷途多俊异，乱世少恩惠。<br />鄙夫亦放荡，草草频卒<small class="du-fu-variant">樊作年</small>岁。<br />斯文忧患余，圣哲垂彖系。</p>

# 次空灵岸

<p class="du-fu-verse">沄沄逆素浪，落落展清眺。<br />幸有舟楫迟，得尽所历妙。<br />空灵霞石峻，枫栝<small class="du-fu-variant">一作枯</small>隐奔峭。<br />青春犹无<small class="du-fu-variant">一作有</small>私，白日亦<small class="du-fu-variant">一作已</small>偏照。<br />可使营吾居<small class="du-fu-variant">一作屋，</small>终焉托长啸。<br />毒瘴未足忧，兵戈满边徼。<br />向者留遗恨，耻为达人诮。<br />回帆觊赏延，佳处领其要。</p>

梦弼曰：空灵当作“空舲”，刀笔误耳。《水经注》：湘水县北有空舲峡，惊浪雷奔，浚同三峡。《十道四番志》：湘水空舲滩。《水经注》又云：江水自建平至东界峡，盛弘之谓空舲峡，峡甚高峻，即宜都、建平二郡界也。

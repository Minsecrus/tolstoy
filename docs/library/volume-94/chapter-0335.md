# 宿花石戍

<p class="du-fu-verse">午辞空灵岑，夕得花石戍。<br />岸疏开辟水<small class="du-fu-variant">一作山，</small>木杂今古树。<br />地蒸南风盛，春热西日暮。<br />四序本平分，气候何回互。<br />茫茫天造间，理乱岂恒数。<br />系舟盘藤轮，策杖古樵路。<br />罢人不在村，野圃泉自注。<br />柴扉虽芜没，农器尚牢固。<br />山东残逆气，吴楚守王度。<br />谁能扣君门，下令减征赋。</p>

《水经注》：湘水又北经三石山，东山枕侧湘川，此即三石水口也。水北有三石戍，戍城为二水之会也。《地理志》：潭州长沙，有渌口、花石二戍。

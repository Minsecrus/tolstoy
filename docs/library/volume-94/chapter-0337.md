# 次晚洲

<p class="du-fu-verse">参错云石稠，坡陁风涛壮。<br />晚洲适知名，秀色固异状。<br />棹经垂猿把，身在度鸟上。<br />摆浪散帙妨，危沙折花当<sup class="footnote-ref" id="note-ref-du-fu-0337-1"><a href="#note-du-fu-0337-1">〔一〕</a></sup>。<br />羁离暂愉悦，羸老反惆怅。<br />中原未解兵，吾得终疏放。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0337-1"><span class="footnote-number">〔一〕</span>花当：俞舜卿云：危沙既险，无他标识，插花以当之，非“玉巵无当”之“当”字也。《广韵》：当，底也。今体诗云：“常苦沙崩损药阑。”危沙易崩，故折花以为之当，此亦偶写近江之景色也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0337-1" aria-label="返回正文">↩</a></span></p>

# 湘江宴饯裴二端公赴道州

<p class="du-fu-verse">白日照舟师，朱旗散广川。<br />群公饯南伯，肃肃秩初筵。<br />鄙人奉末眷，佩服自早年。<br />义均骨肉地，怀抱罄所宣。<br />盛名富事业，无取愧高贤。<br />不以丧乱婴，保爱金石坚。<br />计拙百僚下，气苏君子前。<br />会合苦不久，哀乐本相缠。<br />交游飒向尽，宿昔浩茫然。<br />促觞激百虑，掩抑泪潺湲。<br />热云集曛黑<small class="du-fu-variant">一作初集黑，</small>缺月未生天。<br />白团为我破，华烛蟠长烟。<br />鸹鹖<small class="du-fu-variant">一作鹖</small><img class="du-fu-glyph" src="/library/volume-94/images/glyph-3e6bbbe9c17e3dd7991b.jpg" alt="原书用字" style="width: 0.950em" /><small class="du-fu-variant">，一作鸹鸧</small>催明星<sup class="footnote-ref" id="note-ref-du-fu-0339-1"><a href="#note-du-fu-0339-1">〔一〕</a></sup>，解袂从此旋。<br />上请减兵甲，下请安井田。<br />永念病渴老，附书远山巅。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0339-1"><span class="footnote-number">〔一〕</span>鸹鹖：师古注：《子虚赋》曰鸧鸹也。今关西呼为鸹鹿，山东谓之鸧，鄙俗名为错落。错落者，亦言鸧声之急耳。又谓鸹捋。鸹鹿、鸹捋，皆象其鸣声也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0339-1" aria-label="返回正文">↩</a></span></p>

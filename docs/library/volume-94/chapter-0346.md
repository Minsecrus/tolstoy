# 奉赠李八丈判官

<small class="du-fu-variant">曛</small>

<p class="du-fu-verse">我丈时英特，宗枝神尧后。<br />珊瑚市则无，<img class="du-fu-glyph" src="/library/volume-94/images/glyph-ea73e6601be7ab812bd3.jpg" alt="原书用字" style="width: 1.000em" />骥人得有。<br />早年见标格，秀气冲星斗。<br />事业富清机，官曹正独守。<br />顷来树嘉政，皆已传众口。<br />艰难体贵安，冗长吾敢取。<br />区区犹历试，炯炯更持久。<br />讨论实解颐，操割纷应手。<br />箧书积讽谏，宫阙限奔走。<br />入幕未展材<small class="du-fu-variant">一作怀，</small>秉钧孰为偶。<br />所亲问淹泊，泛爱惜衰朽。<br />垂白乱<small class="du-fu-variant">一作辞</small>南翁<sup class="footnote-ref" id="note-ref-du-fu-0346-1"><a href="#note-du-fu-0346-1">〔一〕</a></sup>，委身希北叟<sup class="footnote-ref" id="note-ref-du-fu-0346-2"><a href="#note-du-fu-0346-2">〔二〕</a></sup>。<br />真成穷辙鲋，或似丧家狗。<br />秋枯洞庭石，风飒长沙柳。<br />高兴激荆衡，知音为回首。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0346-1"><span class="footnote-number">〔一〕</span>南翁：虞般佑《高士传》：南公者，楚人，埋名藏用，世莫能识，居国南鄙，因以为号，著书言阴阳事。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0346-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0346-2"><span class="footnote-number">〔二〕</span>北叟：《幽通赋》：北叟颇识其倚伏。高允《塞上公亭诗序》曰：延和三年，余赴京师，发石门，北行失道，夜寓宿代之快马亭。其俗云：古塞上公所遗之邑也。公有良马，因以命之。代人云：塞上公姓李，代之李氏，并其后也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0346-2" aria-label="返回正文">↩</a></span></p>

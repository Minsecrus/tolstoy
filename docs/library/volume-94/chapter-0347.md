# 岁晏行

<p class="du-fu-verse">岁云暮矣多北风，潇湘洞庭白雪<small class="du-fu-variant">一作云</small>中。<br />渔父天寒网罟冻，莫徭射雁鸣桑弓<sup class="footnote-ref" id="note-ref-du-fu-0347-1"><a href="#note-du-fu-0347-1">〔一〕</a></sup>。<br />去年米贵阙军食，今年米贱大伤农。<br />高马达官厌酒肉，此辈杼轴茅茨空。<br />楚人重鱼不重鸟<small class="du-fu-variant">一作肉，</small>汝休枉杀南飞鸿。<br />况闻处处鬻男女，割慈忍爱还租庸。<br />往日用钱捉私铸<sup class="footnote-ref" id="note-ref-du-fu-0347-2"><a href="#note-du-fu-0347-2">〔二〕</a></sup>，今许<small class="du-fu-variant">一云来</small>铅锡和青铜。<br />刻泥为之最易得，好恶不合长相蒙。<br />万国城头吹画角，此曲哀怨何时终。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0347-1"><span class="footnote-number">〔一〕</span>莫徭：《隋·地理志》：长沙郡杂有夷蜑，名曰莫徭。自言其先祖有功，常免征役，故以为名。常衮《草江南西道观察魏少游制》曰：都团练观察处置莫徭，使莫徭，江湖猎手不他徭。刘长卿《连州腊日观莫徭猎诗》云：莫徭自生长，名字无符籍。市易杂蛟人，婚姻通木客。《广异记》：阑州莫徭，以樵采为事。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0347-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0347-2"><span class="footnote-number">〔二〕</span>私铸：《旧书》：张九龄初知政事，奏请不禁铸钱，令百官详议，以为不便。天宝数载之后，富商奸人，渐收好钱。潜将往江淮之南，每钱货得私铸恶者五文，假托官钱，将入京私用。鹅眼铁锡，古文<img class="du-fu-glyph" src="/library/volume-94/images/glyph-026a579ed6359d86ea74.jpg" alt="原书用字" style="width: 0.950em" />环之类，每贯重不过三四斤。按高宗尝谓侍臣，私铸过多，如闻荆、潭、宣、衡犯法尤甚，遂有将船筏宿于江中，所部官人不能觉察。公时居荆、衡间。故作此诗。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0347-2" aria-label="返回正文">↩</a></span></p>

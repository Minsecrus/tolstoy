# 李监宅<sup class="footnote-ref" id="note-ref-du-fu-0364-1"><a href="#note-du-fu-0364-1">〔一〕</a></sup>

<p class="du-fu-verse">尚觉王孙贵，豪家意颇浓。<br />屏开金孔雀<sup class="footnote-ref" id="note-ref-du-fu-0364-2"><a href="#note-du-fu-0364-2">〔二〕</a></sup>，褥隐绣芙蓉。<br />且食双鱼美，谁看异味重。<br />门阑多喜色，女婿近乘龙<sup class="footnote-ref" id="note-ref-du-fu-0364-3"><a href="#note-du-fu-0364-3">〔三〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0364-1"><span class="footnote-number">〔一〕</span>李监：《灵怪录》：李令问开元中为秘书监，颇事饮馔，其炙驴罂鹅之属，取味惨毒，病毒。朱衣鬼自内挟令问出，掷火车中，载之而去。诗云“谁看异味重”，或其人也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0364-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0364-2"><span class="footnote-number">〔二〕</span>金孔雀：《旧书》：高祖皇后窦氏父毅，于门屏画二孔雀，有求婚，辄与两箭射之，潜约中目者许之。高祖后至，两发各中一目，遂归于帝。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0364-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0364-3"><span class="footnote-number">〔三〕</span>乘龙：《初学记》：《魏志》：黄尚为司徒，与李元礼俱娶太尉桓焉女。时人谓桓叔元两女俱乘龙，言得婿如龙。又《御览》载《楚国先贤传》：孙隽字文英，与李元礼俱娶太尉桓焉女。吴曾《漫录》云：盖用《神仙传》弄玉乘凤、萧史乘龙语也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0364-3" aria-label="返回正文">↩</a></span></p>

# 龙门

<p class="du-fu-verse">龙门横野断，驿树出城来。<br />气色皇居近<sup class="footnote-ref" id="note-ref-du-fu-0368-1"><a href="#note-du-fu-0368-1">〔一〕</a></sup>，金银佛寺开<sup class="footnote-ref" id="note-ref-du-fu-0368-2"><a href="#note-du-fu-0368-2">〔二〕</a></sup>。<br />往还时屡改，川水<small class="du-fu-variant">一作陆</small>日悠哉。<br />相阅征途上，生涯尽几回。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0368-1"><span class="footnote-number">〔一〕</span>皇居：《元和郡国志》：炀帝登邙山，望伊阙曰：“此非龙门耶？自古何不建都于此？”仁寿四年，诏杨素营东京，今洛阳宫是也。北据邙山，南直伊阙之口，洛水贯都，有河汉之象。韦应物诗：都门逼相望，佳气生朝夕。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0368-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0368-2"><span class="footnote-number">〔二〕</span>佛寺：韦诗：精舍绕层阿，千龛邻峭壁。元人《龙门记》：旧有八寺，无一存者。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0368-2" aria-label="返回正文">↩</a></span></p>

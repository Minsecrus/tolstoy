# 赠李白

<p class="du-fu-verse">秋来相顾尚飘蓬，未就丹砂愧葛洪。<br />痛饮狂歌空度日，飞扬跋扈为谁雄<sup class="footnote-ref" id="note-ref-du-fu-0370-1"><a href="#note-du-fu-0370-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0370-1"><span class="footnote-number">〔一〕</span>飞扬跋扈：吴若本注：贺六浑论侯景专制河南十四年，有飞扬跋扈之意。按太白性倜傥，好纵横术。魏颢称其“眸子炯然，哆如饿虎”。少任侠，手刃数人。故公以“飞扬跋扈”目之，犹云“平生飞动意”也。旧注俱大谬。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0370-1" aria-label="返回正文">↩</a></span></p>

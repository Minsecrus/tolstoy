# 登兖州城楼

<p class="du-fu-verse">东郡趋庭日<sup class="footnote-ref" id="note-ref-du-fu-0372-1"><a href="#note-du-fu-0372-1">〔一〕</a></sup>，南楼纵目初。<br />浮云连海岳<small class="du-fu-variant">一作岱，</small>平野入青徐。<br />孤嶂秦碑在<sup class="footnote-ref" id="note-ref-du-fu-0372-2"><a href="#note-du-fu-0372-2">〔二〕</a></sup>，荒城鲁殿余<sup class="footnote-ref" id="note-ref-du-fu-0372-3"><a href="#note-du-fu-0372-3">〔三〕</a></sup>。<br />从来多古意，临眺独踌蹰。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0372-1"><span class="footnote-number">〔一〕</span>东郡：《前汉·志》：东郡，秦置，属兖州。 趋庭：甫父闲，尝为兖州司马。鹤曰：天宝九载，改兖州为鲁郡。乾元元年，复为兖州。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0372-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0372-2"><span class="footnote-number">〔二〕</span>秦碑：《水经注》：峄山北有绝岩，秦始皇观礼于鲁，登于峄山之上，命李斯以大篆勒铭山岭，名曰书门。《邹山记》：邹山盖古之峄山，始皇刻碑处，文字分明。始皇乘羊车以上，其路犹存。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0372-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0372-3"><span class="footnote-number">〔三〕</span>荒城：《寰宇记》：古鲁城，春秋之时鲁国都也，其城凡十有二门。 鲁殿：《水经注》：孔庙东南五百步，有双石阙，即灵光之南。阙北百余步，即灵光殿基，中间方七百余步。《寰宇记》：灵光殿高一丈，在鲁城内曲阜县西南二里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0372-3" aria-label="返回正文">↩</a></span></p>

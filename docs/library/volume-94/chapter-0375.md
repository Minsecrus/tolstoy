# 对雨书怀走邀许十一簿公

<p class="du-fu-verse">东岳云峰起，溶溶满太虚。<br />震雷翻幕燕，骤雨落河<small class="du-fu-variant">一作溪</small>鱼。<br />座对贤人酒<sup class="footnote-ref" id="note-ref-du-fu-0375-1"><a href="#note-du-fu-0375-1">〔一〕</a></sup>，门听长者车。<br />相邀愧泥泞，骑马到阶除。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0375-1"><span class="footnote-number">〔一〕</span>贤人酒：《魏略》：太祖时禁酒，而人窃饮之，故难言酒，以浊酒为贤人，清酒为圣人。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0375-1" aria-label="返回正文">↩</a></span></p>

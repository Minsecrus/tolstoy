# 巳上人茅斋

<p class="du-fu-verse">巳公茅屋下<sup class="footnote-ref" id="note-ref-du-fu-0376-1"><a href="#note-du-fu-0376-1">〔一〕</a></sup>，可以赋新诗。<br />枕簟入林僻，茶瓜留客迟。<br />江莲摇白羽<sup class="footnote-ref" id="note-ref-du-fu-0376-2"><a href="#note-du-fu-0376-2">〔二〕</a></sup>，天棘梦<small class="du-fu-variant">一作蔓</small>青丝<sup class="footnote-ref" id="note-ref-du-fu-0376-3"><a href="#note-du-fu-0376-3">〔三〕</a></sup>。<br />空忝许询辈，难酬支遁词。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0376-1"><span class="footnote-number">〔一〕</span>巳公：伪欧注云：齐己。谬甚。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0376-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0376-2"><span class="footnote-number">〔二〕</span>江莲：宋《乐府》：种莲长江边。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0376-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0376-3"><span class="footnote-number">〔三〕</span>天棘：《本草图经》曰：天门冬，春生，藤蔓高至丈余，其叶如丝杉而细散。《尔雅》：髦颠蕀。注曰：白华，有刺，蔓生，蕀音棘。《抱朴子》及《神仙服食方》云：天门冬，一名颠棘。梦弼云：颠、天，声相近也。许彦周云：江南徐铉家本云：“天棘蔓青丝。”蔓生如青丝，尤见是天门冬也。《通志》：柳，一名天棘。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0376-3" aria-label="返回正文">↩</a></span></p>

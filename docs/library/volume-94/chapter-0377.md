# 房兵曹胡马诗

<p class="du-fu-verse">胡马大宛名，锋棱瘦骨成。<br />竹批双耳峻<sup class="footnote-ref" id="note-ref-du-fu-0377-1"><a href="#note-du-fu-0377-1">〔一〕</a></sup>，风入四蹄轻<sup class="footnote-ref" id="note-ref-du-fu-0377-2"><a href="#note-du-fu-0377-2">〔二〕</a></sup>。<br />所向无空阔，真堪托死生。<br />骁腾有如此<sup class="footnote-ref" id="note-ref-du-fu-0377-3"><a href="#note-du-fu-0377-3">〔三〕</a></sup>，万里可横行。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0377-1"><span class="footnote-number">〔一〕</span>竹批：鲁国黄伯仁为《龙马颂》曰：“耳如削筒，目象明星。”《相马经》：耳欲得相近而前竖，小而厚。相马之法，先除三羸五驽。大头缓耳，一驽也。唐太宗叙《十骥》曰：耳根纤锐，杉竹难方，尾本高尻，掘搏非拟。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0377-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0377-2"><span class="footnote-number">〔二〕</span>风入：《拾遗记》：曹洪所乘马曰白鹄。此马走，唯觉耳中风声，脚似不践地，时人谓乘风行也。谚云：凭空虚跃，曹家白鹤。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0377-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0377-3"><span class="footnote-number">〔三〕</span>骁腾：颜延年《赭白马赋》：料武艺，品骁腾。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0377-3" aria-label="返回正文">↩</a></span></p>

# 画鹰

<p class="du-fu-verse">素练风<small class="du-fu-variant">一作如</small>霜起，苍鹰画作殊。<br /><img class="du-fu-glyph" src="/library/volume-94/images/unmapped-0f715b60655320b18756.png" alt="原书用字" style="width: 0.600em" />身思狡兔<sup class="footnote-ref" id="note-ref-du-fu-0378-1"><a href="#note-du-fu-0378-1">〔一〕</a></sup>，侧目似愁胡。<br />绦镟光堪擿<sup class="footnote-ref" id="note-ref-du-fu-0378-2"><a href="#note-du-fu-0378-2">〔二〕</a></sup>，轩楹势可呼。<br />何当击凡鸟，毛血洒平芜。</p>

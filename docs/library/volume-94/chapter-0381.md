# 过宋员外之问旧庄<sup class="footnote-ref" id="note-ref-du-fu-0381-1"><a href="#note-du-fu-0381-1">〔一〕</a></sup>

<small class="du-fu-variant">员外季弟执金吾，见知于代，故有下句。</small>

<p class="du-fu-verse">宋公旧池馆，零落守<small class="du-fu-variant">一云首</small>阳阿<sup class="footnote-ref" id="note-ref-du-fu-0381-2"><a href="#note-du-fu-0381-2">〔二〕</a></sup>。<br />枉道只从入，吟诗许更过。<br />淹留问耆老，寂寞向山河。<br />更识将军树，悲风日暮多。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0381-1"><span class="footnote-number">〔一〕</span>宋员外：之问景德中再转考功员外郎。弟之悌，有勇力，之逊善书。之悌开元中自右羽林将军出为益州长史、剑南节度兼采访使。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0381-1" aria-label="返回正文">↩</a></span></p>

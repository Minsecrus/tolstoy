# 夜宴左氏庄

<p class="du-fu-verse">风林<small class="du-fu-variant">晋作林风</small>纤月落，衣露净琴张。<br />暗水流花径，春星带草堂。<br />检书烧烛短，看<small class="du-fu-variant">一作说</small>剑<small class="du-fu-variant">一云煎茗</small>引杯长。<br />诗罢闻吴咏<sup class="footnote-ref" id="note-ref-du-fu-0382-1"><a href="#note-du-fu-0382-1">〔一〕</a></sup>，扁舟意不忘。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0382-1"><span class="footnote-number">〔一〕</span>吴咏：《壮游诗》：东下姑苏台，已具浮海航。此诗作于游吴之后，故闻“吴咏”而起“扁舟”之兴也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0382-1" aria-label="返回正文">↩</a></span></p>

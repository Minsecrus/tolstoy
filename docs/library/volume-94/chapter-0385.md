# 赠陈二补阙

<p class="du-fu-verse">世儒多汩没，夫子独声名。<br />献纳开东观<sup class="footnote-ref" id="note-ref-du-fu-0385-1"><a href="#note-du-fu-0385-1">〔一〕</a></sup>，君王问长卿。<br />皂雕寒始<small class="du-fu-variant">音试</small>急<sup class="footnote-ref" id="note-ref-du-fu-0385-2"><a href="#note-du-fu-0385-2">〔二〕</a></sup>，天马老能行。<br />自到青冥里，休看白发生。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0385-1"><span class="footnote-number">〔一〕</span>东观：和帝永元十三年，帝幸东观，览书林，阅篇籍，博选艺术之士，以充其官。注：陆机《洛阳记》曰：在南宫。高阙十二间，介于承风观。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0385-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0385-2"><span class="footnote-number">〔二〕</span>皂雕：《旧书》：王志愔除左台御史，百僚畏惮，时人呼为“皂雕”，言其顾瞻人吏，如皂雕之视燕雀也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0385-2" aria-label="返回正文">↩</a></span></p>

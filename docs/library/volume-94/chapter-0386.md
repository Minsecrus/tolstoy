# 寄高三十五书记

<small class="du-fu-variant">适</small>

<p class="du-fu-verse">叹惜高生老，新诗日又多<sup class="footnote-ref" id="note-ref-du-fu-0386-1"><a href="#note-du-fu-0386-1">〔一〕</a></sup>。<br />美名人不及，佳句法如何。<br />主将收才子，崆峒足凯歌<sup class="footnote-ref" id="note-ref-du-fu-0386-2"><a href="#note-du-fu-0386-2">〔二〕</a></sup>。<br />闻君已朱绂，且得慰蹉跎。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0386-1"><span class="footnote-number">〔一〕</span>新诗：《旧书》：天宝中，海内事干进者，注意文词。适年过五十，始留意篇什。数年之间，体格渐变，以气质自高。每吟一篇已，为好事者称诵。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0386-1" aria-label="返回正文">↩</a></span></p>

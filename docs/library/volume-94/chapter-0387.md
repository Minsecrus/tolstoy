# 送裴二虬作尉永嘉

<p class="du-fu-verse">孤屿亭何处<sup class="footnote-ref" id="note-ref-du-fu-0387-1"><a href="#note-du-fu-0387-1">〔一〕</a></sup>，天涯水气中。<br />故人官就此，绝境兴<small class="du-fu-variant">一作与</small>谁同。<br />隐吏逢梅福<sup class="footnote-ref" id="note-ref-du-fu-0387-2"><a href="#note-du-fu-0387-2">〔二〕</a></sup>，游山忆谢公<sup class="footnote-ref" id="note-ref-du-fu-0387-3"><a href="#note-du-fu-0387-3">〔三〕</a></sup>。<br />扁舟吾已就<small class="du-fu-variant">一作具，</small>把钓待秋风<small class="du-fu-variant">一云“扁舟吾已买，只是待秋风”。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0387-1"><span class="footnote-number">〔一〕</span>孤屿：谢灵运《登江中孤屿》诗：乱流趋正绝，孤屿媚中川。《寰宇记》：孤屿，在温州南四里永嘉江中，渚长三百丈，阔七十步，屿有二峰。李白诗：康乐上官去，永嘉游石门。江亭有孤屿，千载迹犹存。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0387-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0387-2"><span class="footnote-number">〔二〕</span>梅福：梅福补南昌尉，比裴之作尉也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0387-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0387-3"><span class="footnote-number">〔三〕</span>谢公：灵运出为永嘉太守，郡有名山水，肆意游遨。今积谷山南有谢公岩，其东有谢公池，又有东山。旧注引谢安，非是。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0387-3" aria-label="返回正文">↩</a></span></p>

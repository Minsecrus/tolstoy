# 赠田九判官<sup class="footnote-ref" id="note-ref-du-fu-0389-1"><a href="#note-du-fu-0389-1">〔一〕</a></sup>

<small class="du-fu-variant">梁丘</small>

<p class="du-fu-verse">崆峒使节上青霄，河陇降王款圣朝<sup class="footnote-ref" id="note-ref-du-fu-0389-2"><a href="#note-du-fu-0389-2">〔二〕</a></sup>。<br />宛马总肥春<small class="du-fu-variant">或作秦</small>苜蓿，将军只数汉<small class="du-fu-variant">一作霍</small>嫖姚。<br />陈留阮瑀谁争长，京兆田郎早见招。<br />麾下赖君才并入，独能无意向渔樵。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0389-1"><span class="footnote-number">〔一〕</span>田梁丘：颜真卿撰《颜允南神道碑》：潼关陷，朝官多出骆谷至兴道，中丞田梁丘为哥舒翰行军司马。既败，犹自振矜，因诵表云云。君独抗声叱之曰：“君何得尚为贼说征祥乎？”一坐皆壮之。《旧书》：哥舒翰讨禄山，以田梁丘为御史中丞，充行军司马。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0389-1" aria-label="返回正文">↩</a></span></p>

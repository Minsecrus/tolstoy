# 送韦书记赴安西

<p class="du-fu-verse">夫子歘通贵，云泥相望悬。<br />白头无籍在<sup class="footnote-ref" id="note-ref-du-fu-0391-1"><a href="#note-du-fu-0391-1">〔一〕</a></sup>，朱绂有哀怜。<br />书记赴三捷<small class="du-fu-variant">一作接，</small>公车留二年<sup class="footnote-ref" id="note-ref-du-fu-0391-2"><a href="#note-du-fu-0391-2">〔二〕</a></sup>。<br />欲浮江海去，此别意苍<small class="du-fu-variant">一作茫</small>然。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0391-1"><span class="footnote-number">〔一〕</span>无籍：籍在，谓无人慰籍如韦也。引通籍及尹赏传无市籍，俱非是。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0391-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0391-2"><span class="footnote-number">〔二〕</span>公车：“公车留二年”，公献赋隶有司参列选序之时也。《东方朔传》：朔待诏公车。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0391-2" aria-label="返回正文">↩</a></span></p>

# 九日杨奉先会白水崔明府

<p class="du-fu-verse">今日潘怀县，同时陆浚仪<sup class="footnote-ref" id="note-ref-du-fu-0398-1"><a href="#note-du-fu-0398-1">〔一〕</a></sup>。<br />坐开桑落酒<sup class="footnote-ref" id="note-ref-du-fu-0398-2"><a href="#note-du-fu-0398-2">〔二〕</a></sup>，来把菊花枝。<br />天宇清霜净，公堂宿雾披。<br />晚酣留客舞，凫舄共差池。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0398-1"><span class="footnote-number">〔一〕</span>潘、陆：《晋书》：潘岳栖迟十年，出为河阳令，转怀令。陆云以公府掾为太子舍人，出补浚仪令。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0398-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0398-2"><span class="footnote-number">〔二〕</span>桑落酒：《水经注》：河东郡民有姓刘名堕者，宿擅工酿，采挹河流，酝成芳酎，悬食同枯枝之年，排于桑落之辰，故酒得其名矣。然香醑之色，清白若<img class="du-fu-glyph" src="/library/volume-94/images/glyph-6b6f0b3b9a5e527e9358.jpg" alt="原书用字" style="width: 0.950em" />浆焉。《齐民要术》：酿桑落酒，亦以九月。索郎，桑落反语也。庾信诗：“蒲城桑叶落，灞岸菊花秋。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0398-2" aria-label="返回正文">↩</a></span></p>

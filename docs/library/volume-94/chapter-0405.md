# 赠比部萧郎中十兄

<small class="du-fu-variant">甫从姑子也</small>

<p class="du-fu-verse">有美生人杰，由来积德门。<br />汉朝丞相系，梁日帝王孙。<br />蕴藉为郎久，魁梧秉哲尊。<br />词华倾后辈，风雅蔼孤骞。<br />宅相荣姻戚<sup class="footnote-ref" id="note-ref-du-fu-0405-1"><a href="#note-du-fu-0405-1">〔一〕</a></sup>，儿童惠讨论。<br />见知真自幼，谋拙丑<small class="du-fu-variant">一作愧</small>诸昆。<br />漂荡云天阔，沉埋日月奔。<br />致君时已晚，怀古意空存。<br />中散山阳锻，愚公野谷村<sup class="footnote-ref" id="note-ref-du-fu-0405-2"><a href="#note-du-fu-0405-2">〔二〕</a></sup>。<br />宁纡长者辙，归老任乾坤。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0405-1"><span class="footnote-number">〔一〕</span>宅相：《魏舒传》：舒少孤，为外家宁氏所养。宁氏起宅，相宅者云：当出贵甥。舒曰：当为外氏成此宅相。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0405-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0405-2"><span class="footnote-number">〔二〕</span>愚公：《水经注》：时水又屈而经社山北，有愚公谷。齐桓公时，公隐于溪，邻有认其驹者，公以与之。山即社山之通阜，以其人状愚，故谓之愚公。《寰宇记》：愚公谷，在临淄县西二十五里。本社山，名愚公山、愚公谷。《郡国志》云：社山之西，愚公谷之东，有愚公冢存。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0405-2" aria-label="返回正文">↩</a></span></p>

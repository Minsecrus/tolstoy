# 官定后戏赠

<small class="du-fu-variant">时免河西尉，为右卫率府兵曹。</small>

<p class="du-fu-verse">不作河西尉，凄凉为折腰。<br />老夫怕趋走，率府且逍遥。<br />耽酒须微禄，狂歌托圣朝。<br />故山归兴尽，回首向风飙。</p>

天宝十四载，授河西尉，不拜，改右卫率府胄曹参军。是年禄山反，故曰“昔罢河西尉，初兴蓟北师”也。

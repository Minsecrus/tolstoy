# 九日蓝田崔氏庄<sup class="footnote-ref" id="note-ref-du-fu-0411-1"><a href="#note-du-fu-0411-1">〔一〕</a></sup>

<small class="du-fu-variant">自此已后诗十三首没贼时作。</small>

<p class="du-fu-verse">老去悲秋强自宽，兴来今<small class="du-fu-variant">一作终</small>日尽君欢。<br />羞将短发还吹帽，笑倩旁人为正冠。<br />蓝水远从千涧落<sup class="footnote-ref" id="note-ref-du-fu-0411-2"><a href="#note-du-fu-0411-2">〔二〕</a></sup>，玉山高并两峰寒<sup class="footnote-ref" id="note-ref-du-fu-0411-3"><a href="#note-du-fu-0411-3">〔三〕</a></sup>。<br />明年此会知谁健<small class="du-fu-variant">一云在，</small>醉<small class="du-fu-variant">一云再</small>把茱萸子细看。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0411-1"><span class="footnote-number">〔一〕</span>蓝田：《长安志》：蓝田，秦旧县也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0411-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0411-2"><span class="footnote-number">〔二〕</span>蓝水：《长安志》：霸谷，古滋水也，亦名蓝田谷水，即秦岭水之下流也。《汉书》：霸水出蓝田谷入渭，又蓝谷水自秦岭西流，经蓝关、蓝桥，过王顺山，水下出蓝谷，西北流入霸水。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0411-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0411-3"><span class="footnote-number">〔三〕</span>玉山：《太平寰宇记》：蓝田山在县西三十里，一名玉山，一名覆车山。郭缘生《述征记》曰：山形如覆车之象也，霸水之源出此。《三秦记》曰：有川方三十里，其水北流，出玉。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0411-3" aria-label="返回正文">↩</a></span></p>

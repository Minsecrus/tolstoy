# 崔氏东山草堂

<p class="du-fu-verse">爱汝玉山草堂静，高秋爽气相<small class="du-fu-variant">一作多</small>鲜新。<br />有时自发钟磬响，落日更见渔樵人。<br />盘剥白鸦谷口栗<sup class="footnote-ref" id="note-ref-du-fu-0412-1"><a href="#note-du-fu-0412-1">〔一〕</a></sup>，饭煮青泥坊底芹<sup class="footnote-ref" id="note-ref-du-fu-0412-2"><a href="#note-du-fu-0412-2">〔二〕</a></sup>。<br />何为西庄王给事<sup class="footnote-ref" id="note-ref-du-fu-0412-3"><a href="#note-du-fu-0412-3">〔三〕</a></sup>，柴门空闭锁<small class="du-fu-variant">一作好</small>松筠。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0412-1"><span class="footnote-number">〔一〕</span>白鸦谷：《通志》：白鸦谷，在蓝田东南二十里，谷中有翠微寺，其地宜栗。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0412-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0412-2"><span class="footnote-number">〔二〕</span>青泥坊：《水经注》：泥水历峣柳城南，魏置青泥军于城内，俗亦谓之青泥城。《长安志》：青泥驿在县郭下。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0412-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0412-3"><span class="footnote-number">〔三〕</span>西庄：《雍录》：辋川在蓝田县西南二十里，王维别墅在焉，本宋之问别圃也。《长安志》：辋谷水出南山辋谷，北流入霸水。吴若本注云：王维时被张通儒禁在京城东山北寺，有所叹息，故云。《安禄山事迹》：王维在贼中，拘于菩提佛寺。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0412-3" aria-label="返回正文">↩</a></span></p>

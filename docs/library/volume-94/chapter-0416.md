# 元日寄韦氏妹

<p class="du-fu-verse">近闻韦氏妹，迎在汉钟离。<br />郎伯殊方镇，京华旧国移。<br />春城回北斗<sup class="footnote-ref" id="note-ref-du-fu-0416-1"><a href="#note-du-fu-0416-1">〔一〕</a></sup>，郢树发南枝<sup class="footnote-ref" id="note-ref-du-fu-0416-2"><a href="#note-du-fu-0416-2">〔二〕</a></sup>。<br />不见朝正使<sup class="footnote-ref" id="note-ref-du-fu-0416-3"><a href="#note-du-fu-0416-3">〔三〕</a></sup>，啼痕满面垂。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0416-1"><span class="footnote-number">〔一〕</span>北斗：《三辅黄图》：初置长安城，本狭小，至惠帝，更筑之，高三丈五尺，上阔九尺，下阔一丈五尺，雉高三板，周回六十五里。城南为南斗形，北为北斗形，至今人呼汉旧京为斗城。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0416-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0416-2"><span class="footnote-number">〔二〕</span>郢树：柳诗：“长在荆门郢树烟。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0416-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0416-3"><span class="footnote-number">〔三〕</span>朝正：《唐会要》：天宝六载，敕中书门下奏，自今已后，诸道应贺正使，并取元日，随京官例，序立便见。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0416-3" aria-label="返回正文">↩</a></span></p>

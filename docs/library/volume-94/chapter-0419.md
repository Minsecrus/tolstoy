# 一百五日夜对月<sup class="footnote-ref" id="note-ref-du-fu-0419-1"><a href="#note-du-fu-0419-1">〔一〕</a></sup>

<p class="du-fu-verse">无家对寒食，有泪如金波。<br />斫却<small class="du-fu-variant">顾陶本作折尽</small>月中桂<sup class="footnote-ref" id="note-ref-du-fu-0419-2"><a href="#note-du-fu-0419-2">〔二〕</a></sup>，清光应更多。<br />仳离放红蕊，想像<img class="du-fu-glyph" src="/library/volume-94/images/glyph-0e1cb16fba1b58841795.jpg" alt="原书用字" style="width: 1.000em" />青蛾<small class="du-fu-variant">晋作娥</small><sup class="footnote-ref" id="note-ref-du-fu-0419-3"><a href="#note-du-fu-0419-3">〔三〕</a></sup>。<br />牛女漫愁思，秋期犹渡河。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0419-1"><span class="footnote-number">〔一〕</span>一百五日：《荆楚岁时记》：去冬至一百五日，即有疾风甚雨，谓之寒食。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0419-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0419-2"><span class="footnote-number">〔二〕</span>月中桂：《酉阳杂俎》：旧言月中有桂，有蟾蜍，故异书言月桂高五百丈，下有一人，常斫之，树创随合。人姓吴，名刚，西河人，学仙有过，谪令伐树。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0419-2" aria-label="返回正文">↩</a></span></p>

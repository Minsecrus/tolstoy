# 奉赠严八阁老<sup class="footnote-ref" id="note-ref-du-fu-0422-1"><a href="#note-du-fu-0422-1">〔一〕</a></sup>

<p class="du-fu-verse">扈圣<small class="du-fu-variant">《英华》作扈从，一作今日</small>登黄阁<sup class="footnote-ref" id="note-ref-du-fu-0422-2"><a href="#note-du-fu-0422-2">〔二〕</a></sup>，明公独妙年<sup class="footnote-ref" id="note-ref-du-fu-0422-3"><a href="#note-du-fu-0422-3">〔三〕</a></sup>。<br />蛟龙得云雨，雕鹗在秋天。<br />客礼容疏放，官曹可<small class="du-fu-variant">一作许</small>接联。<br />新诗句句好，应任老夫传。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0422-1"><span class="footnote-number">〔一〕</span>阁老：李肇《国史补》：宰相相呼为“堂老”，两省相呼为“阁老”。《通鉴》：王涯谓给事中郑肃、韩佽曰：二阁老不用封敕。此唐人称给事中为阁老也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0422-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0422-2"><span class="footnote-number">〔二〕</span>黄阁：《宋志》曰：“三公黄阁，前史无其义。”按：《礼记》曰：“士鞞与天子同，公侯大夫则异。”郑玄注云：“士贱，与君同，不嫌也。”夫朱门洞启，当阳之正色也。三公之与天子，礼秩相亚，故黄其阁以示嫌，不敢斥天子，疑是汉来制也。《缃素杂记》：“《汉旧仪》曰：丞相听事门曰黄阁。又《王莹传》云：既为公，须开黄阁。张敬儿谓其妻嫂‘我拜后府开黄阁’是也。”故杜诗云：“扈圣登黄阁。”《困学纪闻》：“给事中属门下省，开元曰黄门省，故曰黄阁。”左拾遗亦东省之属，故曰“官曹可接联”。近世用此诗为宰辅事，误矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0422-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0422-3"><span class="footnote-number">〔三〕</span>妙年：武弱冠，以门荫策名。至德初，仗节赴行在，房琯首荐才略可称。累迁给事中。既收长安，为京兆少尹兼御史中丞，时年三十二。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0422-3" aria-label="返回正文">↩</a></span></p>

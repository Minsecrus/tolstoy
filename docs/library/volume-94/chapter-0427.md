# 晚行口号

<p class="du-fu-verse">三川不可到，归路晚山稠。<br />落雁浮寒水，饥乌集戍楼。<br />市朝今日异，丧乱几时休。<br />远愧梁江总<sup class="footnote-ref" id="note-ref-du-fu-0427-1"><a href="#note-du-fu-0427-1">〔一〕</a></sup>，还家尚黑头。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0427-1"><span class="footnote-number">〔一〕</span>梁江总：江总，年十八解褐，年少有名。侯景之乱，避难崎岖累年，至会稽郡，憩于龙华寺。曰“梁江总”，以总在梁遇乱，尚少年也。刘会孟云：“总自梁入陈，自陈入隋，归尚黑头。”不知总入隋，年七十余矣。刘之不学可笑如此。总后有《自梁南还寻草宅》诗云：“红颜辞巩洛，白首入<img class="du-fu-glyph" src="/library/volume-94/images/glyph-f7d18b18471088d3aaf3.jpg" alt="原书用字" style="width: 1.000em" />辕。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0427-1" aria-label="返回正文">↩</a></span></p>

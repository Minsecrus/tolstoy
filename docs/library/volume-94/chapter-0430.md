# 重经昭陵

<p class="du-fu-verse">草昧英雄起，讴歌历数归。<br />风尘三尺剑，社稷一戎衣。<br />翼亮贞文德，丕承戢武威。<br />圣图天广大，宗祀日光辉。<br />陵寝盘空曲<sup class="footnote-ref" id="note-ref-du-fu-0430-1"><a href="#note-du-fu-0430-1">〔一〕</a></sup>，熊罴守翠微。<br />再窥松柏路，还见<small class="du-fu-variant">《草堂》作有</small>五云飞<sup class="footnote-ref" id="note-ref-du-fu-0430-2"><a href="#note-du-fu-0430-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0430-1"><span class="footnote-number">〔一〕</span>陵寝：《唐会要》：陵在醴泉县，因九嵕层峰，凿山南面深七十五丈为玄宫，傍岩架梁为栈道，悬绝百仞，绕回二百三十步，始达玄宫门，顶上亦起游殿。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0430-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0430-2"><span class="footnote-number">〔二〕</span>五云：《瑞应图》：景云，一曰庆云。非气非烟，氤氲五色，谓之庆云。《春秋运斗枢》：天子孝则景云出。《西京杂记》：董仲舒曰：“太平之时，云则五色而为庆，三色而为矞。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0430-2" aria-label="返回正文">↩</a></span></p>

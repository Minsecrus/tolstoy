# 紫宸殿退朝口号<sup class="footnote-ref" id="note-ref-du-fu-0434-1"><a href="#note-du-fu-0434-1">〔一〕</a></sup>

<p class="du-fu-verse">户外昭容紫袖垂<sup class="footnote-ref" id="note-ref-du-fu-0434-2"><a href="#note-du-fu-0434-2">〔二〕</a></sup>，双瞻御座引朝仪。<br />香飘合殿春风转，花覆千官淑景移。<br />昼漏希<small class="du-fu-variant">一作声</small>闻高阁报，天颜有喜近臣知。<br />宫中每出归东省<sup class="footnote-ref" id="note-ref-du-fu-0434-3"><a href="#note-du-fu-0434-3">〔三〕</a></sup>，会送夔龙集<small class="du-fu-variant">一作到</small>凤池。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0434-1"><span class="footnote-number">〔一〕</span>紫宸：《雍录》：含光之北为宣政，宣政之北为紫宸。《五代史·李琪传》：唐故事：天子日御前殿见群臣，曰常参。朔望荐食诸陵寝，御便殿见群臣曰入阁。宣政，前殿也，谓之衙，衙有仗。紫宸，便殿也，谓之阁。其不御前殿而御紫宸也，乃自正衙唤仗，由阁门而入，百官候朝于衙者，因随以入见，故谓之入阁。《春明退朝录》：唐日御宣政殿，殿列细仗、兵部旗旛等于廷，朝官退，皆赐食。自开元后，朔望宗庙上牙盘食。明皇意欲避正殿，遂御紫宸殿，唤仗入阁门。遂有入阁之名。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0434-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0434-2"><span class="footnote-number">〔二〕</span>昭容：《酉阳杂俎》：今阁门有宫人垂帛引百寮，或云自则天，或言因后魏。据《开元礼疏》曰：晋康献褚后临朝不坐，则宫人传百寮拜，周、隋相沿，国家因之不改。程大昌《演繁露》：《唐会要》：天祐二年，敕今后每遇延英坐朝日，只令小黄门祗候引从，宫人不得擅出内。杜诗“户外昭容紫袖垂”，郑谷《入阁》诗亦言“导引出宫钿”，盖至天祐始罢。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0434-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0434-3"><span class="footnote-number">〔三〕</span>东省：《雍录》：政事堂在东省，属门下。至中宗时，裴炎以中书令执政事笔，故徙政事于中书省，则堂在右省也。杜甫为左拾遗，其诗所谓“凤池”者，中书也。左省官方自宫中退朝而出，则归东省者，以本省言也。已又送夔龙于凤池，殆左省堂集政事堂白六押事耶！杜为拾遗时，政事堂已在中书。故出东省而集于西省者，就政事堂见宰相也。为其官于东省，而越至西省。故文昌录于此阙疑。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0434-3" aria-label="返回正文">↩</a></span></p>

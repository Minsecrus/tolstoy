# 曲江对酒

<p class="du-fu-verse">苑外江头坐不归，水精春<small class="du-fu-variant">一作宫</small>殿转霏微<sup class="footnote-ref" id="note-ref-du-fu-0436-1"><a href="#note-du-fu-0436-1">〔一〕</a></sup>。<br />桃花细逐杨花落<small class="du-fu-variant">一云欲共梨花语，</small>黄鸟时<small class="du-fu-variant">一作仍</small>兼白鸟飞。<br />纵饮久判人共弃，懒朝真与世相违。<br />吏<small class="du-fu-variant">一作含</small>情更觉沧洲远，老大悲伤未拂衣。</p>

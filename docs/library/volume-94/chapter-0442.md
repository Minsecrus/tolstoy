# 宣政殿退朝晚出左掖<sup class="footnote-ref" id="note-ref-du-fu-0442-1"><a href="#note-du-fu-0442-1">〔一〕</a></sup>

<p class="du-fu-verse">天门日射黄金榜，春殿晴曛<small class="du-fu-variant">一作熏</small>赤羽旗。<br />宫草微微<small class="du-fu-variant">一云霏霏</small>承委佩，炉烟细细驻游丝。<br />云近蓬莱常好<small class="du-fu-variant">一作五</small>色，雪残<img class="du-fu-glyph" src="/library/volume-94/images/glyph-47bb758d04a491a311a1.jpg" alt="原书用字" style="width: 1.000em" />鹊亦多时。<br />侍臣缓步归青琐，退食从容出每迟。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0442-1"><span class="footnote-number">〔一〕</span>宣政殿：《长安志》：龙朔二年，造蓬莱宫、含元殿，又造宣政、紫宸、蓬莱三殿。宣政殿在宣政门内，殿东有东上阁门，殿西有西上阁门，殿前东廊曰日华门，东有门下省。 左掖：《吕后纪》注：非正门而在两旁，若人之臂掖。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0442-1" aria-label="返回正文">↩</a></span></p>

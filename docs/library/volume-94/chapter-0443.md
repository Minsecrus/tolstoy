# 题省中院壁

<p class="du-fu-verse">掖垣竹埤梧十寻，洞门对霤 <small class="du-fu-variant">一作雪</small>常阴阴<sup class="footnote-ref" id="note-ref-du-fu-0443-1"><a href="#note-du-fu-0443-1">〔一〕</a></sup>。<br />落花游丝白日静，鸣鸠乳燕青春深。<br />腐儒衰晚谬通籍，退食迟回违寸心。<br />衮职曾无一字补，许身愧比双南金。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0443-1"><span class="footnote-number">〔一〕</span>洞门：《董贤传》：重殿洞门。师古曰：谓门门相当也。对霤：《吴都赋》：玉堂对霤，石室相距。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0443-1" aria-label="返回正文">↩</a></span></p>

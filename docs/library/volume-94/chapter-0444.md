# 春宿左省

<p class="du-fu-verse">花隐掖垣暮，啾啾栖鸟过。<br />星临万户动，月傍九霄多。<br />不寝听金钥<small class="du-fu-variant">《英华》作不寐听金锁，</small>因风想玉珂。<br />明朝有封事，数问夜如何<sup class="footnote-ref" id="note-ref-du-fu-0444-1"><a href="#note-du-fu-0444-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0444-1"><span class="footnote-number">〔一〕</span>问夜：《唐会要》：景云二年，敕南衙北门及诸门进状及封状意见及降墨敕，并于状上昼题时刻，夜题更筹。程嘉燧曰：味“明朝”句，似用傅玄欲入奏即朝衣待旦，时人谓台阁生风事。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0444-1" aria-label="返回正文">↩</a></span></p>

# 送郑十八虔贬台州司户伤其临老陷贼之故阙为面别情见于诗

<p class="du-fu-verse">郑公樗散鬓成<small class="du-fu-variant">一作如</small>丝，酒后常称老画师。<br />万里伤心严谴日，百年垂死中兴时。<br />苍惶<small class="du-fu-variant">一作伶俜</small>已就长途往，邂逅无端出饯迟。<br />便与先生应永诀，九重泉路<small class="du-fu-variant">一作下</small>尽交期。</p>

《新书》：虔迁著作郎。禄山反，遣张通儒劫百官置东都，伪授水部郎中。因称风缓，求摄市令，潜以密章达灵武。贼平，与王维并囚宣阳里。然皆善画，崔圆使绘斋壁。虔即祈解于圆，卒免死，贬台州司户参军。

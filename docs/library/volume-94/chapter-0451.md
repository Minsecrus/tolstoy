# 题郑十八著作虔

<p class="du-fu-verse">台州地阔<small class="du-fu-variant">一作僻</small>海冥冥，云水长和岛屿青。<br />乱后<small class="du-fu-variant">一作缱绻</small>故人双别泪，春深<small class="du-fu-variant">一作飘飖</small>逐客一浮萍。<br />酒酣懒舞谁相拽，诗罢能吟不复听。<br />第五桥东流恨水，皇陂岸北结愁亭。<br />贾生对<img class="du-fu-glyph" src="/library/volume-94/images/glyph-fc249282d9afd10084d4.jpg" alt="原书用字" style="width: 1.000em" />伤王傅，苏武看羊陷贼庭。<br />可念此翁怀<small class="du-fu-variant">一作常</small>直道，也沾新国用轻刑<sup class="footnote-ref" id="note-ref-du-fu-0451-1"><a href="#note-du-fu-0451-1">〔一〕</a></sup>。<br />祢衡实恐遭江夏，方朔虚传是岁星<sup class="footnote-ref" id="note-ref-du-fu-0451-2"><a href="#note-du-fu-0451-2">〔二〕</a></sup>。<br />穷巷悄然<small class="du-fu-variant">一作一朝</small>车马绝，案头干死读书萤。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0451-1"><span class="footnote-number">〔一〕</span>轻刑：是时陷贼官以六等定罪，虔在次三等之数，贬台州司户，故曰“用轻刑”也。虔称风缓，以密章达灵武，而议罚过重，故有惜之之语。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0451-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0451-2"><span class="footnote-number">〔二〕</span>岁星：吴曾《漫录》曰：《汉武故事》并《西京杂记》云：西王母使者曰：朔是水帝精，为岁星。下游人中，以观天下，非陛下臣也。故夏侯孝若《画赞》云：神变造化，灵为星辰。旧注曰：方朔为太白星。非也。《列仙传》云：东方朔，平原厌次人，智者疑其岁星精也。《西京杂记》《汉武故事》俱无吴氏云云。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0451-2" aria-label="返回正文">↩</a></span></p>

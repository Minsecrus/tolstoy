# 赠毕四

<small class="du-fu-variant">曜</small>

<p class="du-fu-verse">才大今诗伯，家贫苦宦卑。<br />饥寒奴仆贱，颜状老翁为。<br />同调嗟谁惜，论文笑自知。<br />流传江鲍体<sup class="footnote-ref" id="note-ref-du-fu-0453-1"><a href="#note-du-fu-0453-1">〔一〕</a></sup>，相顾免无儿<sup class="footnote-ref" id="note-ref-du-fu-0453-2"><a href="#note-du-fu-0453-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0453-1"><span class="footnote-number">〔一〕</span>江鲍：《诗品》：文通诗体总杂，善于摹拟，筋力于王微，成就于谢朓。鲍参军诗，其源出于二张，善制形状写物之词，贵尚巧似，不避危仄。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0453-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0453-2"><span class="footnote-number">〔二〕</span>无儿：中宗曰：“苏瓌有子，李峤无儿。”公与曜皆有子传其诗，庶免无儿之慨。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0453-2" aria-label="返回正文">↩</a></span></p>

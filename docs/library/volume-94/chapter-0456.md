# 奉陪郑驸马韦曲二首<sup class="footnote-ref" id="note-ref-du-fu-0456-1"><a href="#note-du-fu-0456-1">〔一〕</a></sup>

## 其一

<p class="du-fu-verse">韦曲花无赖，家家恼杀人。<br />绿樽虽<small class="du-fu-variant">一作须</small>尽日，白发好禁<small class="du-fu-variant">一作伤</small>春。<br />石角钩衣破，藤枝<small class="du-fu-variant">一作萝</small>刺眼新。<br />何时占丛竹，头戴小乌巾。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0456-1"><span class="footnote-number">〔一〕</span>韦曲：《雍录》：《吕图》，韦曲在明德门外，韦后家在此，盖皇子陂之西，所谓“城南韦杜”者也。《游城南记》<sup class="footnote-ref" id="note-ref-du-fu-0456-2"><a href="#note-du-fu-0456-2">[1]</a></sup>：览韩郑郊居，至韦曲。注云：韦曲在韩郑庄之北，逍遥公读书台犹在。《通志》：韦曲在樊川，唐韦安石之别业。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0456-1" aria-label="返回正文">↩</a></span></p>

## 其二

<p class="du-fu-verse">野寺垂杨里，春畦乱水间。<br />美花多映竹，好鸟不归山。<br />城郭终何事，风尘岂驻颜。<br />谁能共公子，薄暮欲俱还。</p>

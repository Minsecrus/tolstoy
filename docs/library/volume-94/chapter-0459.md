# 送许八拾遗归江宁觐省甫昔时常客游此县于许生处乞瓦棺寺维摩图样志诸篇末<sup class="footnote-ref" id="note-ref-du-fu-0459-1"><a href="#note-du-fu-0459-1">〔一〕</a></sup>

<p class="du-fu-verse">诏许辞中禁，慈颜赴<small class="du-fu-variant">樊作拜</small>北堂<small class="du-fu-variant">一云“天语辞中禁，家荣赴北堂”。</small>圣朝新孝理，祖席倍辉光<small class="du-fu-variant">一作行子倍恩光。</small>内<small class="du-fu-variant">一作赠</small>帛擎偏重，宫衣着更香。<br />淮阴清<small class="du-fu-variant">一云新</small>夜驿，京口渡江航。<br />春隔鸡人昼，秋期燕子凉。<br />赐书夸父老，寿酒乐城隍<small class="du-fu-variant">一云“竹引趋庭曙，山添扇枕凉。十年过父老，几日赛城隍”。</small>看画曾饥渴，追踪恨<small class="du-fu-variant">一作限</small>淼茫。<br />虎头金粟影，神妙独难忘。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0459-1"><span class="footnote-number">〔一〕</span>许拾遗：《岑参集》有《送许子擢第归江宁拜亲》诗，在天宝元年告赐灵符上加尊号之日。此云“许八拾遗”，盖擢第后十余年，官拾遗，又得觐省也。 维摩画：张彦远《名画记》：顾恺之，字长康，小字虎头。曾于瓦棺寺北小殿画维摩诘。画讫，光彩耀目数日。《京师寺记》云：兴宁中，瓦棺寺初置，僧众设会，请朝贤鸣剎注钱，其时士大夫莫有过十万者。既至长康，直打剎注钱百万。长康素贫，众以为大言。后寺众请勾疏，长康曰：宜备一壁。遂闭户。往来一月余日，所画维摩诘一躯。工毕，将欲点眸子，乃谓寺僧曰：第一日观者，请施十万，第二日可五万，第三日可任例责施。及开户，光照一寺，施者填咽。俄而得百万钱。吴曾《漫录》：《世说》顾恺之为虎头将军，非小字也。按晋无此官，《世说》亦无此语。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0459-1" aria-label="返回正文">↩</a></span></p>

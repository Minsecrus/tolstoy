# 至德二载甫自京金光门出问<small class="du-fu-variant">樊作间</small>道归凤翔乾元初从左拾遗移华州掾与亲故别因出此门有悲往事<sup class="footnote-ref" id="note-ref-du-fu-0461-1"><a href="#note-du-fu-0461-1">〔一〕</a></sup>

<p class="du-fu-verse">此道昔归顺，西郊胡正<small class="du-fu-variant">一作骑</small>繁。<br />至今残破胆，应<small class="du-fu-variant">一作犹</small>有未招魂<sup class="footnote-ref" id="note-ref-du-fu-0461-2"><a href="#note-du-fu-0461-2">〔二〕</a></sup>。<br />近得<small class="du-fu-variant">一作侍</small>归京邑，移官岂<small class="du-fu-variant">一作远</small>至尊<sup class="footnote-ref" id="note-ref-du-fu-0461-3"><a href="#note-du-fu-0461-3">〔三〕</a></sup>。<br />无才日衰老，驻马望千门。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0461-1"><span class="footnote-number">〔一〕</span>金光门：《长安志》：唐京师外郭城西面三门，北曰明远门，中曰金光门，西出趋昆明池，南曰延平门。 间道：《旧书》：肃宗征兵灵武，甫自京师宵遁，赴河西，谒肃宗于彭原郡，拜右拾遗。《新书》：禄山乱，天子入蜀，甫避走三川。肃宗立，自鄜州羸服欲奔行在，为贼所得。至德二年，亡走凤翔，上谒，拜左拾遗。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0461-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0461-2"><span class="footnote-number">〔二〕</span>招魂：《招魂》曰：魂兮归来，入修门些。经年之后，再出国都之门，痛定思痛，犹有未招之魂。比《招魂》之言，尤可伤矣。盖深叹肃宗之少恩也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0461-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0461-3"><span class="footnote-number">〔三〕</span>移官：公上疏救房琯，诏三司推问，以张镐力救，敕放就列。至次年，复与房琯、严武俱贬，坐琯党也。此公事君交友，平生出处之大节，《旧书》载之甚明。元稹《志》亦云：左拾遗岁余，以直言出华州司功。而《新书》则云：从还京师，出为华州司功参军。作年谱者，至以为不知为何事而出，则为《新书》所误耳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0461-3" aria-label="返回正文">↩</a></span></p>

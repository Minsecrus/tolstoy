# 寄高三十五詹事适

<p class="du-fu-verse">安稳高詹事，兵戈久索居。<br />时来如<small class="du-fu-variant">一作知</small>宦达，岁晚莫情疏。<br />天上多鸿雁，池<small class="du-fu-variant">一作河</small>中足鲤鱼。<br />相看过半百，不寄一行书。</p>

至德二载，适节度淮南。兵罢，李辅国恶于上前，左授太子少詹事。故曰“时来如宦达”，婉词以慰之也。适有《酬裴员外》<sup class="footnote-ref" id="note-ref-du-fu-0462-1"><a href="#note-du-fu-0462-1">[1]</a></sup>诗云：“小人胡不仁，谮我成死灰。赖得日月明，照耀无不该。留司洛阳官，詹府唯蒿莱。”

<p class="footnote-definition footnote-source" id="note-du-fu-0462-1"><span class="footnote-number">[1]</span> 裴员外：原作“崔员外”，据《高常侍集》卷四改。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0462-1" aria-label="返回正文">↩</a></span></p>

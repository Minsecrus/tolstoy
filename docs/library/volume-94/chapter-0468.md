# 忆弟二首

<small class="du-fu-variant">时归在南陆浑庄</small>

## 其一

<p class="du-fu-verse">丧乱闻吾弟，饥寒傍济州。<br />人稀吾<small class="du-fu-variant">一作书</small>不到，兵在见何由。<br />忆昨狂催走，无时病去忧。<br />即今千种恨，惟共水东流。</p>

## 其二

<p class="du-fu-verse">且喜河南定，不问邺城围。<br />百战今谁在，三年望汝归。<br />故园花自发，春日鸟还飞。<br />断绝人烟久，东西消息稀。</p>

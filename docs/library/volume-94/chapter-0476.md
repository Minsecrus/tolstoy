# 山寺

<p class="du-fu-verse">野寺残僧少，山园细路高。<br />麝香眠石竹<sup class="footnote-ref" id="note-ref-du-fu-0476-1"><a href="#note-du-fu-0476-1">〔一〕</a></sup>，鹦鹉啄金桃<sup class="footnote-ref" id="note-ref-du-fu-0476-2"><a href="#note-du-fu-0476-2">〔二〕</a></sup>。<br />乱石<small class="du-fu-variant">一作水</small>通人过，悬崖置屋牢<sup class="footnote-ref" id="note-ref-du-fu-0476-3"><a href="#note-du-fu-0476-3">〔三〕</a></sup>。<br />上方重阁晚，百里见秋<small class="du-fu-variant">一作纤</small>毫。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0476-1"><span class="footnote-number">〔一〕</span>麝香：《本草图经》：麝香出秦州、文州，诸蛮中尤多。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0476-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0476-2"><span class="footnote-number">〔二〕</span>鹦鹉：祢衡《赋》：命虞人于陇坻。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0476-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0476-3"><span class="footnote-number">〔三〕</span>悬崖：《玉堂闲话》：麦积山北跨清渭，南渐两当。五百里冈峦，麦积处其半。古记云：自平地积薪，至于岩巅，从上镌凿其龛室佛像。功毕，旋旋拆薪而下，然后梯空架险而上。其间千房万室，悬空蹑虚，登之者不敢四顾。《方舆胜览》：麦积山在秦州东南百里，状如积麦，为秦地林泉之冠。姚秦时建瑞应寺，在山之后。姚兴凿山而修，千崖万象，转崖为关，乃秦州胜境。又有隋时塔，杜甫有诗。《天水图经》：陇城邑南，唐杜工部故居侄佐草堂，在东柯谷南。积麦山瑞应寺上，山形如积麦，佛龛刳石，阁道萦旋，上下千余丈。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0476-3" aria-label="返回正文">↩</a></span></p>

# 即事

<p class="du-fu-verse">闻道花门破，和亲事却非。<br />人怜汉公主，生得渡河归<sup class="footnote-ref" id="note-ref-du-fu-0477-1"><a href="#note-du-fu-0477-1">〔一〕</a></sup>。<br />秋思抛云髻<small class="du-fu-variant">一作鬓，</small>腰支胜<small class="du-fu-variant">一作剩</small>宝衣。<br />群凶犹索战，回首意多违。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0477-1"><span class="footnote-number">〔一〕</span>渡河：乾元二年，回纥从郭子仪战于相州城下，不利，奔于西京。四月，可汗死，其牙官都督等欲以宁国公主殉葬，公主亦依回纥法剺面大哭，竟以无子得归。八月，诏百官于明凤门外迎之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0477-1" aria-label="返回正文">↩</a></span></p>

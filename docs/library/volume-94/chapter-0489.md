# 夕烽

<p class="du-fu-verse">夕峰来不近<small class="du-fu-variant">一作止，</small>每日报平安<small class="du-fu-variant">一云“夕烽明照灼，了了报平安”</small><sup class="footnote-ref" id="note-ref-du-fu-0489-1"><a href="#note-du-fu-0489-1">〔一〕</a></sup>。<br />塞上传光<small class="du-fu-variant">一云声</small>小，云边落<small class="du-fu-variant">一云数</small>点残。<br />照秦通警急，过陇自艰难<small class="du-fu-variant">一云“焰销仍再灭，烟迥不胜寒”。</small>闻道蓬莱殿，千门立马看<small class="du-fu-variant">一云“恐照蓬莱殿，城中几道看</small>”。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0489-1"><span class="footnote-number">〔一〕</span>平安：《唐六典》：凡烽候所置，大率相去三十里。其放烽有一炬、二炬、三炬、四炬者，随贼多少而为差焉。开元二十五年，敕以边隅无事，内地置烽，量停近畿烽二百六十所。唐镇戍每日初夜放烟一炬，谓之平安火。《安禄山事迹》：六月十四日辛卯，潼关失守。是夕平安火不至，玄宗惧焉。十五日壬辰，闻于朝廷。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0489-1" aria-label="返回正文">↩</a></span></p>

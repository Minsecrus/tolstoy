# 天末怀李白<sup class="footnote-ref" id="note-ref-du-fu-0494-1"><a href="#note-du-fu-0494-1">〔一〕</a></sup>

<p class="du-fu-verse">凉风起天末，君子意如何。<br />鸿雁几时到，江湖秋水多。<br />文章憎命达，魑魅喜人过<sup class="footnote-ref" id="note-ref-du-fu-0494-2"><a href="#note-du-fu-0494-2">〔二〕</a></sup>。<br />应共冤魂语，投诗赠汨罗。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0494-1"><span class="footnote-number">〔一〕</span>天末：陆士衡诗：借问叹何为，佳人眇天末。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0494-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0494-2"><span class="footnote-number">〔二〕</span>魑魅：“魑魅喜人过”，喜其来而择人以食也。《招魂》：得人肉以祀，以其骨为醢，吞人以益其心。正此意也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0494-2" aria-label="返回正文">↩</a></span></p>

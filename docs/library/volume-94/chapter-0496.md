# 日暮

<p class="du-fu-verse">日落风亦起，城头鸟<small class="du-fu-variant">晋作乌</small>尾讹<sup class="footnote-ref" id="note-ref-du-fu-0496-1"><a href="#note-du-fu-0496-1">〔一〕</a></sup>。<br />黄云高未动，白水已扬波。<br />羌妇语还哭，胡儿行且歌。<br />将军别换马<small class="du-fu-variant">一云换骏马，</small>夜出拥雕戈。</p>

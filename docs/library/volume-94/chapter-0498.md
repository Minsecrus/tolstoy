# 病马

<p class="du-fu-verse">乘尔亦已久，天寒关塞深。<br />尘中老尽力<sup class="footnote-ref" id="note-ref-du-fu-0498-1"><a href="#note-du-fu-0498-1">〔一〕</a></sup>，岁晚病伤心。<br />毛骨岂殊众，驯良犹至今。<br />物微意不浅，感动一沉吟。</p>

# 蕃剑

<p class="du-fu-verse">致<small class="du-fu-variant">一云至</small>此自僻远，又非珠玉装。<br />如何有奇怪，每夜吐光芒。<br />虎气必腾趠<small class="du-fu-variant">一作上</small><sup class="footnote-ref" id="note-ref-du-fu-0499-1"><a href="#note-du-fu-0499-1">〔一〕</a></sup>，龙身宁久藏<sup class="footnote-ref" id="note-ref-du-fu-0499-2"><a href="#note-du-fu-0499-2">〔二〕</a></sup>。<br />风尘苦未息，持汝奉明王。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0499-1"><span class="footnote-number">〔一〕</span>虎气：殷芸《小说》载《世说》云：王子乔墓在京茂陵。国乱时，有人盗发之，惟有一剑，悬在空中。欲取之，剑便作龙鸣虎吼，俄而飞上天。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0499-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0499-2"><span class="footnote-number">〔二〕</span>龙身：《水经注》：雷氏为建安从事，经践濑溪，所留之剑，忽于其怀跃出落水。初犹是剑，后变为龙。故吴均《剑骑》诗云：剑是两蛟龙。张华之言不孤为验矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0499-2" aria-label="返回正文">↩</a></span></p>

# 铜瓶

<p class="du-fu-verse">乱后碧井废，时清瑶殿深。<br />铜瓶未失水，百丈有哀音。<br />侧想美人意，应非<small class="du-fu-variant">一作悲</small>寒甃沉。<br />蛟龙半缺落，犹得折黄金。</p>

瞽者唐仲曰：张籍《楚妃怨》：“梧桐落叶黄金井，横架辘轳牵素绠。美人初起天未明，手拂银瓶秋水冷。”读籍诗，杜义自明。

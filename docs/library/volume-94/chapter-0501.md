# 观安西兵过赴关中待命二首<sup class="footnote-ref" id="note-ref-du-fu-0501-1"><a href="#note-du-fu-0501-1">〔一〕</a></sup>

## 其一

<p class="du-fu-verse">四<small class="du-fu-variant">一云西</small>镇富精锐，摧锋皆绝伦。<br />还闻献<small class="du-fu-variant">一作就</small>士卒，足以静风尘。<br />老马夜知道，苍鹰饥<small class="du-fu-variant">一作秋</small>着人。<br />临危经久战，用急<small class="du-fu-variant">一作意</small>始<small class="du-fu-variant">一作使</small>如神。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0501-1"><span class="footnote-number">〔一〕</span>安西：《旧书》：长寿二年，收复四镇，依前于龟兹国置安西都护府。至德后，河西陇右戍兵皆征集，收复两京。四镇都督府：龟兹、畋沙、疏勒、焉耆，皆安西都护所统。鹤曰：乾元元年，李嗣业以镇西北庭兵同讨安庆绪。二年正月，嗣业卒。安西节度使，至德元载改名镇西，而此犹循其旧名也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0501-1" aria-label="返回正文">↩</a></span></p>

## 其二

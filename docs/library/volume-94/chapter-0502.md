# 送人从军

<p class="du-fu-verse">弱水应无地<sup class="footnote-ref" id="note-ref-du-fu-0502-1"><a href="#note-du-fu-0502-1">〔一〕</a></sup>，阳关已近天<sup class="footnote-ref" id="note-ref-du-fu-0502-2"><a href="#note-du-fu-0502-2">〔二〕</a></sup>。<br />今君渡沙碛<sup class="footnote-ref" id="note-ref-du-fu-0502-3"><a href="#note-du-fu-0502-3">〔三〕</a></sup>，累月断人烟。<br />好武宁论命，封侯不计年。<br />马寒防失道，雪没锦鞍鞯。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0502-1"><span class="footnote-number">〔一〕</span>弱水：《寰宇记》：弱水，东自删丹县界流入，在甘州北二十三里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0502-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0502-2"><span class="footnote-number">〔二〕</span>阳关：《元和郡国志》：阳关，在沙州寿昌县西六里，以居玉门关之南，故曰阳关。本汉置也，谓之南道，西趋鄯善、莎车。玉门故关在县西北百一十八里，谓之北道，西趋车师、前庭及疏勒。此西域之门户也。《西域传》：东则接汉，阨以玉门、阳关。孟康曰：二关皆在敦煌西界。 近天：岑参诗：“走马西来欲到天。”西方地最高，故曰近天。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0502-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0502-3"><span class="footnote-number">〔三〕</span>沙碛：《北边备对》：赵信降匈奴，武帝必欲越漠征之，言沙积广漠，望之漠漠然也。汉以后史家变称为碛。碛者，沙积也，其义一也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0502-3" aria-label="返回正文">↩</a></span></p>

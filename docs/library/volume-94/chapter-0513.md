# 蜀相

<p class="du-fu-verse">丞相祠堂何处寻<sup class="footnote-ref" id="note-ref-du-fu-0513-1"><a href="#note-du-fu-0513-1">〔一〕</a></sup>，锦官城外柏森森<sup class="footnote-ref" id="note-ref-du-fu-0513-2"><a href="#note-du-fu-0513-2">〔二〕</a></sup>。<br />映阶碧草自春色，隔叶黄鹂空<small class="du-fu-variant">一作多</small>好音。<br />三顾频烦<small class="du-fu-variant">吴作繁</small>天下计，两朝开济老臣心。<br />出师未捷<small class="du-fu-variant">一作用</small>身先死，长使英雄泪满襟。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0513-1"><span class="footnote-number">〔一〕</span>祠堂：《寰宇记》：诸葛武侯祠，在先主庙西，府城西有故宅。《方舆胜览》：在府城西北二里。武侯初亡，百姓遇节朔，各私祭于道中。李雄称王，始为庙于少城内。桓温平蜀，平少城，独存孔明庙。《蜀志》：后主景耀六年春，诏为亮立庙于沔阳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0513-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0513-2"><span class="footnote-number">〔二〕</span>锦官城：《华阳国志》：成都西城，故锦官城也。锦江，织锦濯其中则鲜明，他江则不好，故命曰锦里也。《水经注》：成都夷里桥南岸道西有城，故锦官也。言锦工濯锦，则濯之江流，而锦至鲜明；濯以他江，则锦色弱矣，遂命之为锦里也。《元和郡国志》：锦城，在成都县南十里，故锦官城也。《益州记》：锦城在益州南笮桥东流江南岸，昔蜀时故锦官也，今号锦城，墉犹在。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0513-2" aria-label="返回正文">↩</a></span></p>

# 一室

<p class="du-fu-verse">一室他乡远<small class="du-fu-variant">一作老，</small>空林暮景悬。<br />正愁闻塞笛，独立见江船。<br />巴蜀来多病，荆蛮去几年<small class="du-fu-variant">一云千。</small>应同王粲宅<sup class="footnote-ref" id="note-ref-du-fu-0515-1"><a href="#note-du-fu-0515-1">〔一〕</a></sup>，留井岘山前。</p>

# 梅雨

<p class="du-fu-verse">南京西<small class="du-fu-variant">一作犀</small>浦道<sup class="footnote-ref" id="note-ref-du-fu-0516-1"><a href="#note-du-fu-0516-1">〔一〕</a></sup>，四月熟黄梅<sup class="footnote-ref" id="note-ref-du-fu-0516-2"><a href="#note-du-fu-0516-2">〔二〕</a></sup>。<br />湛湛<small class="du-fu-variant">一作黤黤</small>长江去，冥冥细雨来。<br />茅茨疏易湿，云雾密难开。<br />竟日蛟龙喜，盘涡与岸回<sup class="footnote-ref" id="note-ref-du-fu-0516-3"><a href="#note-du-fu-0516-3">〔三〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0516-1"><span class="footnote-number">〔一〕</span>南京：至德二载，以蜀郡为南京。《寰宇记》：犀浦县，周垂拱二年，割成都之西鄙置。杜甫宅，地属犀浦县。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0516-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0516-2"><span class="footnote-number">〔二〕</span>黄梅：《风土记》：夏至雨名黄梅雨，沾衣服，皆败黕。《埤雅》：江、湘二浙，四五月梅欲黄落，则水润土溽，其霏如雾，名梅雨。自江以南。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0516-2" aria-label="返回正文">↩</a></span></p>

三月雨谓之“迎梅”，五月雨谓之“送梅”。唐子西云：江南五月雨为黄梅雨。杜诗云云，蜀中梅雨在四月。柳诗：“梅实迎时雨，苍茫值晚春。”则岭外梅雨，又在春末也。陆放翁云：今成都未尝有梅雨，惟秋半积阴，气令蒸溽，与吴中四月时相类。岂古今地气有不同耶？

<p class="footnote-definition footnote-source" id="note-du-fu-0516-3"><span class="footnote-number">〔三〕</span>盘涡：《江赋》：盘涡谷转，凌涛山颓。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0516-3" aria-label="返回正文">↩</a></span></p>

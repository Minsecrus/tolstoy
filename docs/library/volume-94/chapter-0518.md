# 有客

<small class="du-fu-variant">《草堂》本作宾至。</small>

<p class="du-fu-verse">幽栖地僻经过少，老病人扶再拜难。<br />岂有文章惊海内，漫劳车马驻江干。<br />竟日淹留佳客坐，百年粗粝腐儒餐。<br />不嫌野外无供给，乘兴还来看药栏<sup class="footnote-ref" id="note-ref-du-fu-0518-1"><a href="#note-du-fu-0518-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0518-1"><span class="footnote-number">〔一〕</span>药栏：药栏，花药之栏也。李济翁《资暇集》：谓药即栏也。引《汉书》池籞为说，不知籞音御，与药音异。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0518-1" aria-label="返回正文">↩</a></span></p>

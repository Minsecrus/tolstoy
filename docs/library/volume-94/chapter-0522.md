# 堂成

<p class="du-fu-verse">背郭堂成荫白茅，缘江路熟俯青郊。<br />桤林碍日吟风叶<sup class="footnote-ref" id="note-ref-du-fu-0522-1"><a href="#note-du-fu-0522-1">〔一〕</a></sup>，笼竹和烟滴露梢<sup class="footnote-ref" id="note-ref-du-fu-0522-2"><a href="#note-du-fu-0522-2">〔二〕</a></sup>，暂止<small class="du-fu-variant">一作下</small>飞乌将数子，频来语燕定新巢。<br />旁人错比扬雄宅<sup class="footnote-ref" id="note-ref-du-fu-0522-3"><a href="#note-du-fu-0522-3">〔三〕</a></sup>，懒惰<small class="du-fu-variant">一作慢</small>无心作解嘲。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0522-1"><span class="footnote-number">〔一〕</span>桤林：旧注：诸韵无桤字，蜀人相传，以为音丘宜切。周公谨《齐东野语》：桤或读作岂。又郑氏注曰：五来反，若然，当作呆字。余尝见陈体仁端明云：见前辈读若欹韵，颇以为疑。后见《剑南》诗有“著书增木品，搜句觅桤栽”。又荆公云：“濯锦江边木有桤，小园封植伫华滋。”盖信欹音为然。桤惟蜀有之，不才木也，或谓即榕也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0522-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0522-2"><span class="footnote-number">〔二〕</span>笼竹：宋子京《益部方物记》：慈竹别有一种，节间容八九尺者，曰龙竹。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0522-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0522-3"><span class="footnote-number">〔三〕</span>扬雄宅：《成都记》：成都县百步有严君平、司马相如、扬雄宅，今草玄亭余迹尚存。《寰宇记》：子云宅在少城西南角，一名草玄堂。张孟阳诗：“郁郁少城内，峨峨百族居。借问扬子宅，想见长卿庐。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0522-3" aria-label="返回正文">↩</a></span></p>

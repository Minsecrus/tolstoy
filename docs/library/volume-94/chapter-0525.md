# 西郊

<p class="du-fu-verse">时出碧鸡坊<sup class="footnote-ref" id="note-ref-du-fu-0525-1"><a href="#note-du-fu-0525-1">〔一〕</a></sup>，西郊向草堂。<br />市桥官柳细<sup class="footnote-ref" id="note-ref-du-fu-0525-2"><a href="#note-du-fu-0525-2">〔二〕</a></sup>，江路<small class="du-fu-variant">晋作岸</small>野梅香。<br />傍架齐书帙，看题减<small class="du-fu-variant">晋作检</small>药囊，无人觉<small class="du-fu-variant">一云竞，一云与</small>来往，疏懒意何长。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0525-1"><span class="footnote-number">〔一〕</span>碧鸡坊：梁《益州记》：成都之坊，百有二十，第四曰碧鸡坊。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0525-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0525-2"><span class="footnote-number">〔二〕</span>市桥：《寰宇记》：市桥，在益州西四里。常璩云：石牛门曰市桥，石犀所潜渊中。李膺《益州记》云：冲星桥，旧市桥也，在今成都县西南四里，汉旧州市在桥南，因以名。《华阳国志》云“延岑渡市桥挑战”即此是也。《后汉书注》：市桥，即七星之一桥也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0525-2" aria-label="返回正文">↩</a></span></p>

# 所思

<p class="du-fu-verse">苦忆荆州醉司马<small class="du-fu-variant">崔吏部漪，</small>谪官<small class="du-fu-variant">一云居</small>樽俎<small class="du-fu-variant">一云酒</small>定常开。<br />九江日落醒何处<sup class="footnote-ref" id="note-ref-du-fu-0526-1"><a href="#note-du-fu-0526-1">〔一〕</a></sup>，一柱观头眠几回<sup class="footnote-ref" id="note-ref-du-fu-0526-2"><a href="#note-du-fu-0526-2">〔二〕</a></sup>。<br />可怜怀抱向人尽，欲问平安无使来。<br />故凭锦水将双泪，好过瞿塘滟滪堆。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0526-1"><span class="footnote-number">〔一〕</span>九江：《禹贡》：过九江，至于东陵。《传》曰：江分为九道，在荆州。东陵，地名。《水经》：江水又南过江陵县南。注云：县江有洲，号曰枝回洲，江水自此两分，而为南北江也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0526-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0526-2"><span class="footnote-number">〔二〕</span>一柱观：《渚宫故事》：宋临川王义庆在镇，于罗公洲立观甚大，而惟一柱。刘孝绰诗：经从一柱观，出入三休台。张说诗云：旧说江陵观。初疑神化来。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0526-2" aria-label="返回正文">↩</a></span></p>

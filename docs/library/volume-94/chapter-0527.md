# 江村

<p class="du-fu-verse">清江一曲抱村流，长夏江村事事幽。<br />自去自来<small class="du-fu-variant">一作归</small>堂上燕，相亲相近水中鸥。<br />老妻画纸为<small class="du-fu-variant">一作成</small>棋局<sup class="footnote-ref" id="note-ref-du-fu-0527-1"><a href="#note-du-fu-0527-1">〔一〕</a></sup>，稚子敲针作钓钩<sup class="footnote-ref" id="note-ref-du-fu-0527-2"><a href="#note-du-fu-0527-2">〔二〕</a></sup>。<br />多病所须唯药物<small class="du-fu-variant">一云但有故人供禄米；供，樊作分，</small>微躯此外更何<small class="du-fu-variant">一作无</small>求。</p>

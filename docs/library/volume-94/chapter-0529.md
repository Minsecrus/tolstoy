# 野老

<p class="du-fu-verse">野老篱前<small class="du-fu-variant">一作边</small>江岸回，柴门不正逐江开。<br />渔人网集澄潭下，贾客船随返照来。<br />长路关心悲剑阁，片云何意<small class="du-fu-variant">一作事，又云行云几处</small>傍琴台。<br />王师未报收东郡<sup class="footnote-ref" id="note-ref-du-fu-0529-1"><a href="#note-du-fu-0529-1">〔一〕</a></sup>，城阙秋生画角哀<small class="du-fu-variant">两京同南都，得云城阙也。</small></p>

# 云山

<p class="du-fu-verse">京洛云山外，音书静不来。<br />神交作赋客，力尽望乡台<sup class="footnote-ref" id="note-ref-du-fu-0530-1"><a href="#note-du-fu-0530-1">〔一〕</a></sup>。<br />衰疾江边卧，亲朋日暮回。<br />白鸥元水宿，何事有余哀。</p>

# 北邻

<p class="du-fu-verse">明府岂辞满<sup class="footnote-ref" id="note-ref-du-fu-0532-1"><a href="#note-du-fu-0532-1">〔一〕</a></sup>，藏身方告劳。<br />青钱买野竹，白帻岸江皋。<br />爱酒晋山简，能诗何水曹。<br />时来访老疾，步屧到蓬蒿。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0532-1"><span class="footnote-number">〔一〕</span>明府：《后汉·张湛传》“明府”注：郡守所居曰府，明府者，尊高之称。《前书》：韩延寿为东郡太守，门卒谓之明府，亦其义也。《宾退录》：明府，汉人以称太守，唐人以称县令。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0532-1" aria-label="返回正文">↩</a></span></p>

# 南邻

<p class="du-fu-verse">锦里先生乌角巾，园收芋粟<small class="du-fu-variant">一云栗</small>不全贫。<br />惯看宾客<small class="du-fu-variant">一云门户</small>儿童喜，得食阶除鸟雀驯。<br />秋水才深<small class="du-fu-variant">一云池虽</small>四五尺，野航<small class="du-fu-variant">鲁直作艇</small>恰受两三人<sup class="footnote-ref" id="note-ref-du-fu-0533-1"><a href="#note-du-fu-0533-1">〔一〕</a></sup>。<br />白沙翠竹江村<small class="du-fu-variant">一作山</small>暮<small class="du-fu-variant">一作路，</small>相对<small class="du-fu-variant">一作送</small>柴门<small class="du-fu-variant">一作篱南</small>月色新。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0533-1"><span class="footnote-number">〔一〕</span>航：山谷云：航，方舟也，当以艇为正，音平声。《方言》云：小舟也。近时杨慎曰：古乐府：“沿江引百丈，一濡多一艇。上水郎担蒿，何时至江陵。”杜诗正用此音也。按《方言》云：舟自关而西谓之船，自关而东或谓之舟，或谓之航。又云：小艒䑿谓之艇。《释名》云：二百斛以上谓之艇，鲁直之改，用修之证。皆臆说也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0533-1" aria-label="返回正文">↩</a></span></p>

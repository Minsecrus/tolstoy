# 逢唐兴刘主簿弟<sup class="footnote-ref" id="note-ref-du-fu-0539-1"><a href="#note-du-fu-0539-1">〔一〕</a></sup>

<p class="du-fu-verse">分手开元末，连年绝尺书。<br />江山且相见，戎马未安居。<br />剑外官人冷，关中驿骑疏。<br />轻舟下吴会，主簿意何如。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0539-1"><span class="footnote-number">〔一〕</span>唐兴：《寰宇记》：遂州蓬溪县，本汉广汉县地。唐永淳元年，置唐兴县。天宝元年，改为蓬溪。公此诗及《唐兴县客馆记》，俱循旧名。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0539-1" aria-label="返回正文">↩</a></span></p>

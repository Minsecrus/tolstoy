# 岁暮

<p class="du-fu-verse">岁暮远为客，边隅还用兵。<br />烟尘犯雪岭<sup class="footnote-ref" id="note-ref-du-fu-0544-1"><a href="#note-du-fu-0544-1">〔一〕</a></sup>，鼓角动江城。<br />天地日流血，朝廷谁请缨。<br />济时敢爱死，寂寞壮心惊。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0544-1"><span class="footnote-number">〔一〕</span>雪岭：《元和郡国志》：雪山在松州嘉城县东八十里，春夏常有积雪，故名。又云：傍便山与青城山连接，当吐蕃之界，溪谷深邃，夏积冰雪，此山所以隔中外也。《元和郡国志》：乾元元年，维州没于西戎。《九域志》：维州南至雪岭二百六十里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0544-1" aria-label="返回正文">↩</a></span></p>

# 散愁二首

## 其一

<p class="du-fu-verse">久客宜旋旆，兴王未息戈。<br />蜀星阴见少，江雨夜闻多。<br />百万传深入，寰区望匪它。<br />司徒<small class="du-fu-variant">光弼</small>下燕赵，收取旧山河。</p>

此诗亦作于上元元年光弼胜河阳之后，所谓“司徒下燕赵”，喜而望之之词也。

## 其二

<p class="du-fu-verse">闻道并州镇，尚书<small class="du-fu-variant">王思礼</small>训士齐。<br />几时通蓟北，当日报关西。<br />恋阙丹心破，沾衣皓首啼。<br />老魂招不得，归路恐长迷。</p>

乾元二年，以王思礼为太原尹、北京留守、河东节度使，时军粮百万，器械精锐。上元二年卒。

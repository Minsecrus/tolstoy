# 遣意二首

## 其一

<p class="du-fu-verse">啭枝黄鸟近，泛渚白鸥轻。<br />一径野花落，孤村春水生。<br />衰年催酿黍，细雨更<small class="du-fu-variant">一作夜</small>移橙。<br />渐喜交游绝，幽居不用名。</p>

## 其二

<p class="du-fu-verse">檐影微微落，津流脉脉斜。<br />野船<small class="du-fu-variant">一作松</small>明细火，宿雁聚圆<small class="du-fu-variant">一作寒</small>沙。<br />云掩初弦月，香传小树花。<br />邻人有美酒，稚子夜<small class="du-fu-variant">一作也</small>能赊。</p>

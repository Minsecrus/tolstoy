# 漫成二首

## 其一

<p class="du-fu-verse">野日荒荒<small class="du-fu-variant">一作野月茫茫</small>白，春<small class="du-fu-variant">一云江</small>流泯泯清<sup class="footnote-ref" id="note-ref-du-fu-0552-1"><a href="#note-du-fu-0552-1">〔一〕</a></sup>。<br />渚蒲随地有，村径逐门成。<br />只作披衣惯，常从漉酒生。<br />眼边无俗物，多病也身轻。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0552-1"><span class="footnote-number">〔一〕</span>泯泯：希曰：张有《复古编》：涽，古“活”字，泯泯，当是活活，如“北流活活”之义。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0552-1" aria-label="返回正文">↩</a></span></p>

## 其二

<p class="du-fu-verse">江皋已仲春，花下复清晨。<br />仰面贪看鸟，回头错应人。<br />读书难字过，对酒满壶频。<br />近识峨眉老<small class="du-fu-variant">东山隐者</small><sup class="footnote-ref" id="note-ref-du-fu-0552-2"><a href="#note-du-fu-0552-2">〔一〕</a></sup>，知予懒是真。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0552-2"><span class="footnote-number">〔一〕</span>峨眉：《水经注》：《益州记》曰：峨眉山在南安县界，去成都南千里，然秋日清澄，望见两山相峙，如峨眉焉。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0552-2" aria-label="返回正文">↩</a></span></p>

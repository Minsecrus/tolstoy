# 春水

<p class="du-fu-verse">三月桃花浪<small class="du-fu-variant">一云水</small><sup class="footnote-ref" id="note-ref-du-fu-0554-1"><a href="#note-du-fu-0554-1">〔一〕</a></sup>，江流复旧痕。<br />朝来没沙尾<small class="du-fu-variant">一云岸，</small>碧色动柴门。<br />接缕垂芳饵，连筒灌小园。<br />已添无数鸟，争浴故相喧<small class="du-fu-variant">《英华》云“不知无数鸟，何意更相喧”。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0554-1"><span class="footnote-number">〔一〕</span>桃花浪：《韩诗》：溱与洧，方涣涣兮。注云：谓三月桃花水下时也。《沟洫志》：来春桃花水盛。师古曰：月令，仲春之月，始雨水，桃始华。盖桃方华时，既有雨水，川谷冰泮，众流猥集，波澜盛长，故谓之桃花水。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0554-1" aria-label="返回正文">↩</a></span></p>

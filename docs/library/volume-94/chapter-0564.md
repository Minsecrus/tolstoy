# 高楠

<p class="du-fu-verse">楠树色冥冥，江边一盖青。<br />近根开药圃，接叶制茅亭。<br />落景阴犹合，微风韵可听。<br />寻常绝醉困，卧此片时醒。</p>

鹤曰：《楠树为风雨所拔叹》：“浦上童童一盖青。”故知即此树也。

# 闻斛斯六官未归

<p class="du-fu-verse">故人南郡去，去索作碑钱。<br />本卖文为活，翻令室倒悬。<br />荆扉深蔓草，土锉冷疏烟<sup class="footnote-ref" id="note-ref-du-fu-0568-1"><a href="#note-du-fu-0568-1">〔一〕</a></sup>。<br />老罢休无赖，归来省醉眠。</p>

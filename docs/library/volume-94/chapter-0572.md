# 江涨

<p class="du-fu-verse">江发蛮夷涨，山添雨雪流<sup class="footnote-ref" id="note-ref-du-fu-0572-1"><a href="#note-du-fu-0572-1">〔一〕</a></sup>。<br />大声吹地转，高浪蹴天浮。<br />鱼鳖为人得，蛟龙不自谋。<br />轻帆好去便，吾道付沧洲。</p>

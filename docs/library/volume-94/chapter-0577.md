# 赴青城县出成都寄陶王二少尹<sup class="footnote-ref" id="note-ref-du-fu-0577-1"><a href="#note-du-fu-0577-1">〔一〕</a></sup>

<p class="du-fu-verse">老耻妻孥笑<small class="du-fu-variant">一云老被樊笼役，</small>贫嗟出入劳。<br />客情投异县，诗态忆吾<small class="du-fu-variant">一作君</small>曹。<br />东郭沧江<small class="du-fu-variant">一云沧浪</small>合，西山白雪高。<br />文章差底病<sup class="footnote-ref" id="note-ref-du-fu-0577-2"><a href="#note-du-fu-0577-2">〔二〕</a></sup>，回首兴滔滔。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0577-1"><span class="footnote-number">〔一〕</span>青城：《元和郡国志》：青城县，因山为名，垂拱二年，改为蜀州，开元十八年，仍为青城。大江经县北，去县二里。《寰宇志》：傍便山在县西，与青城山连接，溪谷深邃，夏积冰雪。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0577-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0577-2"><span class="footnote-number">〔二〕</span>底：《匡谬正俗》：俗谓何物为底，此本言何等物，其后遂省何，但直云等物耳。底音丁儿反，等字本音都在反，转音丁儿反，今吴越之人呼齐等皆丁儿反。应璩诗云：“用等称才学，往往见叹誉。”此言讥其用何等才学，见叹誉而为官乎，以是知去何而言等，其言已旧，今人不详根本，乃作底字，非也。旧注云：“差底病”，犹云差得何病也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0577-2" aria-label="返回正文">↩</a></span></p>

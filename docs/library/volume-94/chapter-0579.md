# 野望因过常少仙<sup class="footnote-ref" id="note-ref-du-fu-0579-1"><a href="#note-du-fu-0579-1">〔一〕</a></sup>

<p class="du-fu-verse">野桥齐度马，秋望转悠哉。<br />竹覆青城合，江从灌口来<sup class="footnote-ref" id="note-ref-du-fu-0579-2"><a href="#note-du-fu-0579-2">〔二〕</a></sup>。<br />入村樵径引，尝果栗皱<small class="du-fu-variant">一作园</small>开<sup class="footnote-ref" id="note-ref-du-fu-0579-3"><a href="#note-du-fu-0579-3">〔三〕</a></sup>。<br />落尽高天日，幽人未遣回。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0579-1"><span class="footnote-number">〔一〕</span>少仙：《随笔》载：县尉为少公，予后得晏几道叔原一帖，与通叟少公者，正用此也。杜诗《过常少仙》蜀士注云：应是言县尉也。县尉谓之少府，而梅福为尉，有神仙之称，少仙二字，犹今俗呼“仙尉”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0579-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0579-2"><span class="footnote-number">〔二〕</span>灌口：《元和郡国志》：灌口山，在彭州导江县西北二十六里，蜀州东北至彭州一百二十里，汉文翁穿湔江灌溉，故以灌口名。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0579-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0579-3"><span class="footnote-number">〔三〕</span>栗皱：《西溪丛语》：或作“雏”字，殊不可解。《集韵》：皱，侧尤切，革文蹙也。《汉上题襟》：周繇诗云：“开栗戈之紫皱。”贯休云：“新蝉避栗皱。”又云：栗不和皱落，即栗蓬也。梦弼曰：皱当作皴，皮裂也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0579-3" aria-label="返回正文">↩</a></span></p>

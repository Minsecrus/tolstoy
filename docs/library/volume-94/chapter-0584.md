# 酬高使君相赠

<p class="du-fu-verse">古寺僧牢落<sup class="footnote-ref" id="note-ref-du-fu-0584-1"><a href="#note-du-fu-0584-1">〔一〕</a></sup>，空房客<small class="du-fu-variant">一作得</small>寓居。<br />故人供禄米，邻舍与园蔬。<br />双树容听法，三车肯载书<sup class="footnote-ref" id="note-ref-du-fu-0584-2"><a href="#note-du-fu-0584-2">〔二〕</a></sup>。<br />草《玄》吾岂敢，赋或似<small class="du-fu-variant">一云比</small>相如。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0584-1"><span class="footnote-number">〔一〕</span>古寺：公所居草堂寺，时寓寺中，故高诗云“传道招提客”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0584-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0584-2"><span class="footnote-number">〔二〕</span>三车：旧注：牛车、羊车、鹿车。《唐慈恩窥基传》云：基师，姓尉迟氏，鄂国公其诸父也。奘师因缘相扣，欲度为弟子，基曰：“听我三事，方誓出家。”奘许之，行至太原，以三车自随，前乘经论箱袠，中乘自御，后乘妓女食馔。道中，文殊菩萨化为老人，诃之而止。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0584-2" aria-label="返回正文">↩</a></span></p>

笺曰：此诗正用慈恩事也，言如容我双树听法，亦应许我如慈恩三车自随，但我只办用以载书耳。落句谓文字习气未尽，故下有草《玄》作赋之言，如旧注指《法华》三车，不知临门三车，乃《法华》三乘要义。泛滥引用，同外典之五车，戏论侮法，莫大于是，况文意粗鄙，公宁有是句法耶？

# 野人送朱樱

<p class="du-fu-verse">西蜀樱桃也自红，野人相赠满筠笼。<br />数回细写愁仍破<sup class="footnote-ref" id="note-ref-du-fu-0594-1"><a href="#note-du-fu-0594-1">〔一〕</a></sup>，万颗匀圆讶许同。<br />忆昨赐沾门下省，退朝擎出大明宫。<br />金盘玉筯无消息，此日尝新任转蓬。</p>

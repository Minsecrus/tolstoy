# 即事

<p class="du-fu-verse">百宝装腰带，真珠络臂鞲<sup class="footnote-ref" id="note-ref-du-fu-0595-1"><a href="#note-du-fu-0595-1">〔一〕</a></sup>。<br />笑时花近眼，舞罢锦缠头。</p>

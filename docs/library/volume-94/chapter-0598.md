# 观李固请司马弟山水图三首

## 其一

<p class="du-fu-verse">简易高人意<small class="du-fu-variant">一云体，</small>匡床竹火炉。<br />寒天留远客，碧海挂新图。<br />虽对连山好，贪看绝岛孤。<br />群仙不愁思，冉冉下蓬壶。</p>

## 其二

<p class="du-fu-verse">方丈浑连水，天台总映云。<br />人间长见画，老去<small class="du-fu-variant">一作身老</small>恨空闻。<br />范蠡舟偏小，王乔鹤不群。<br />此生随万物，何路出尘氛。</p>

## 其三

<p class="du-fu-verse">高浪垂翻屋，崩崖欲压床。<br />野桥<small class="du-fu-variant">一作楼</small>分子细，沙岸绕微茫。<br />红浸珊瑚短，青悬薜荔长。<br />浮查并坐得<small class="du-fu-variant">一云相并坐</small><sup class="footnote-ref" id="note-ref-du-fu-0598-1"><a href="#note-du-fu-0598-1">〔一〕</a></sup>，仙老暂相将。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0598-1"><span class="footnote-number">〔一〕</span>浮查：《拾遗记》：尧时有巨查，浮于四海，查上有光若星月，常绕四海，十二年一周，名贯月查，又名挂星查，羽仙栖息其上。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0598-1" aria-label="返回正文">↩</a></span></p>

# 赠别何邕

<p class="du-fu-verse">生死论交地，何由见一人。<br />悲君随燕雀，薄宦走风尘。<br />绵谷元通汉<sup class="footnote-ref" id="note-ref-du-fu-0606-1"><a href="#note-du-fu-0606-1">〔一〕</a></sup>，沱江不向秦<sup class="footnote-ref" id="note-ref-du-fu-0606-2"><a href="#note-du-fu-0606-2">〔二〕</a></sup>。<br />五陵花满眼，传语故乡春。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0606-1"><span class="footnote-number">〔一〕</span>绵谷：绵谷县属利州。《蜀志》：先主使陈戒绝马鸣阁，魏武闻之曰：此阁过汉中之阴平，乃咽喉之要路。《蜀梼杌》曰：利州四会五达之地。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0606-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0606-2"><span class="footnote-number">〔二〕</span>沱江：《寰宇记》：《禹贡》：岷山导江，东别为沱。《汉书·地理志》：《禹贡》：沱江在郫县，东入大江。郭璞云：沱水自蜀郡都水县湔山与江别而更流。据《汉书·沟洫志》郫江即李冰所凿，非《禹贡》之沱江矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0606-2" aria-label="返回正文">↩</a></span></p>

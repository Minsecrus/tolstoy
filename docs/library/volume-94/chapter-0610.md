# 严中丞枉驾见过

<small class="du-fu-variant">严自东川除西川，敕令两川都节制。</small>

<p class="du-fu-verse">元戎小队出郊坰，问柳寻花到野亭。<br />川合东西瞻使节<sup class="footnote-ref" id="note-ref-du-fu-0610-1"><a href="#note-du-fu-0610-1">〔一〕</a></sup>，地分南北任流<small class="du-fu-variant">一作孤</small>萍。<br />扁舟不独如张翰<sup class="footnote-ref" id="note-ref-du-fu-0610-2"><a href="#note-du-fu-0610-2">〔二〕</a></sup>，白<small class="du-fu-variant">一作皂</small>帽还应<small class="du-fu-variant">一作应兼</small>似管宁<sup class="footnote-ref" id="note-ref-du-fu-0610-3"><a href="#note-du-fu-0610-3">〔三〕</a></sup>。<br />寂寞<small class="du-fu-variant">一云今日</small>江天云雾里，何人道有少微星<sup class="footnote-ref" id="note-ref-du-fu-0610-4"><a href="#note-du-fu-0610-4">〔四〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0610-1"><span class="footnote-number">〔一〕</span>川合东西：上元二年十月，武代崔光远镇蜀，是时合剑，两川为一道，废东川节度。此诗系云“自东川除西川”，以武初镇东川故也。详见《八哀诗》注。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0610-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0610-2"><span class="footnote-number">〔二〕</span>张翰：《张翰传》：会稽贺循，赴命入洛，经吴阊门，于船中弹琴。翰初不相识，乃就循言谭，曰：“吾亦有事北京。”便同载即去。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0610-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0610-3"><span class="footnote-number">〔三〕</span>皂帽：《魏志》：管宁常着皂帽、布襦袴、布裙，随时单复。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0610-3" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0610-4"><span class="footnote-number">〔四〕</span>少微：《隋志》：少微四星在太微西，士大夫之位也。一名处士星，明黄则处士举矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0610-4" aria-label="返回正文">↩</a></span></p>

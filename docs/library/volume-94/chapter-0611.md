# 广州段功曹到得杨五长史谭书功曹却归聊寄此诗

<p class="du-fu-verse">卫青开幕府，杨仆将楼船<sup class="footnote-ref" id="note-ref-du-fu-0611-1"><a href="#note-du-fu-0611-1">〔一〕</a></sup>。<br />汉节梅花外，春城海水边。<br />铜梁书远及，珠浦使将旋<sup class="footnote-ref" id="note-ref-du-fu-0611-2"><a href="#note-du-fu-0611-2">〔二〕</a></sup>。<br />贫病他乡老，烦君万里传。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0611-1"><span class="footnote-number">〔一〕</span>杨仆：《南粤传》：杨仆为楼船将军，出豫章，下横浦。《元和郡国志》：桂江，一名漓水，经临桂县东，去县十步。杨仆平南粤，出零陵，下漓水，即谓此也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0611-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0611-2"><span class="footnote-number">〔二〕</span>珠浦：《后汉·循吏传》：孟尝为合浦太守，郡不产谷实，而海出珠。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0611-2" aria-label="返回正文">↩</a></span></p>

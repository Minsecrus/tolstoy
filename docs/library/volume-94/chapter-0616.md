# 三绝句

## 其一

<p class="du-fu-verse">楸树馨香倚钓矶，斩新花蕊未应飞。<br />不如醉里风吹<small class="du-fu-variant">一云春风</small>尽，可<small class="du-fu-variant">一作何</small>忍醒时雨打稀。</p>

## 其二

<p class="du-fu-verse">门外鸬鹚去<small class="du-fu-variant">一作久</small>不来，沙头忽见眼相猜。<br />自今已后知人意，一日须来一百回。</p>

## 其三

<p class="du-fu-verse">无数春笋满林生，柴门密掩断人行。<br />会须上番<small class="du-fu-variant">去声</small>看成竹，客至从嗔不出迎。</p>

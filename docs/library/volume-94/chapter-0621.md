# 野望

<p class="du-fu-verse">西山白雪三奇<small class="du-fu-variant">一作城，一作年</small>戍<sup class="footnote-ref" id="note-ref-du-fu-0621-1"><a href="#note-du-fu-0621-1">〔一〕</a></sup>，南浦清江万里桥。<br />海内风尘诸弟隔，天涯涕泪一身遥。<br />唯将迟暮供多病，未有涓埃答圣朝。<br />跨马出郊时极目，不堪人事日<small class="du-fu-variant">一作自</small>萧条。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0621-1"><span class="footnote-number">〔一〕</span>三奇：《困学纪闻》：《唐·地理志》：彭州导江县有三奇戍。《韦皋传》：遣大将陈垍等出三奇。《西南备边录》所谓“三奇营”也。当从旧本，作“三奇”为是。按，西山三城，界于吐蕃，为蜀边要害，屡见杜诗。正不必作“三奇”。此穿凿之过耳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0621-1" aria-label="返回正文">↩</a></span></p>

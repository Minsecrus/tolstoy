# 寄题杜二锦江野亭

严武

<p class="du-fu-verse">漫向江头把钓竿，懒眠沙草爱风湍。<br />莫倚善题鹦鹉赋，何须不着鵕䴊冠。<br />腹中书籍幽时晒，肘后医方静处看。<br />兴发会能驰骏一云五<small class="du-fu-variant">马，</small>终须晋作当<small class="du-fu-variant">重</small>一作直<small class="du-fu-variant">到使君滩</small><sup class="footnote-ref" id="note-ref-du-fu-0625-1"><a href="#note-du-fu-0625-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0625-1"><span class="footnote-number">〔一〕</span>使君滩：《水经注》：江水东经羊肠虎臂滩。杨亮为益州，至此舟覆，征其波澜，蜀人至今犹名之为“使君滩”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0625-1" aria-label="返回正文">↩</a></span></p>

# 奉酬严公寄题野亭之作

<p class="du-fu-verse">拾遗曾奏数行书，懒性从来水竹居。<br />奉引滥骑沙苑马，幽栖真钓锦江鱼。<br />谢安不倦登临费<small class="du-fu-variant">一作赏，</small>阮籍焉知礼法疏。<br />枉沐<small class="du-fu-variant">一云何日</small>旌麾出城府，草茅无<small class="du-fu-variant">一作荒</small>径欲教锄。</p>

孔毅夫《续世说》：严武为成都尹，甫与武世旧，待遇甚隆。于浣花里种竹植木，结庐枕江，纵酒吟咏，与田畯野老相荡狎。武过之，有时不冠，故武此诗云：“何须不着鵕䴊冠。”而公解其嘲曰“阮籍焉知礼法疏”也。

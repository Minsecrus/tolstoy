# 中丞严公雨中垂寄见忆一绝奉答二绝

<p class="du-fu-verse">雨映行宫<small class="du-fu-variant">一作官，一作云，非是</small>辱赠诗<sup class="footnote-ref" id="note-ref-du-fu-0627-1"><a href="#note-du-fu-0627-1">〔一〕</a></sup>，元戎肯赴野人期<small class="du-fu-variant">一云元戎欲动野人知。</small>江边老病虽无力，强拟晴天理钓丝。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0627-1"><span class="footnote-number">〔一〕</span>行宫：《国史补》：蜀郡有万里桥，玄宗至而喜曰：“吾自知行地万里则归。”公草堂在万里桥，当与行宫相近。张说《奉和早渡蒲关》诗：“楼映行宫日。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0627-1" aria-label="返回正文">↩</a></span></p>

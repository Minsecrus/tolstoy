# 严公仲夏枉驾草堂兼携酒馔

<small class="du-fu-variant">得寒字《草堂》本一作郑公枉驾携馔访水亭</small>

<p class="du-fu-verse">竹里行厨洗玉盘，花边立马簇金鞍。<br />非关使者征求急，自识将军礼数宽。<br />百年地辟<small class="du-fu-variant">今本作僻</small>柴门迥，五月江深草阁寒。<br />看弄渔舟移白日，老农何有罄交欢。</p>

《国史补》：严武少以强俊知名，蜀中坐衙，杜甫袒跣登其几案，武爱其才，终不加害，此所谓“将军礼数宽”也。“钩帘欲杀”之语，最为诬罔，不知宋子京《新书》何以载之本传。

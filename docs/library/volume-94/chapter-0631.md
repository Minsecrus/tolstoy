# 奉送严公入朝十韵

<p class="du-fu-verse">鼎湖瞻望远<sup class="footnote-ref" id="note-ref-du-fu-0631-1"><a href="#note-du-fu-0631-1">〔一〕</a></sup>，象阙宪章新。<br />四海犹多难，中原忆旧臣。<br />与时安反侧，自昔有经纶。<br />感激张天步，从容静塞尘。<br />南图回羽翮，北极捧星辰。<br />漏鼓还思昼，宫莺罢啭春。<br />空留玉帐术<sup class="footnote-ref" id="note-ref-du-fu-0631-2"><a href="#note-du-fu-0631-2">〔二〕</a></sup>，愁杀锦城人。<br />阁道通丹地<sup class="footnote-ref" id="note-ref-du-fu-0631-3"><a href="#note-du-fu-0631-3">〔三〕</a></sup>，江潭隐白<img class="du-fu-glyph" src="/library/volume-94/images/glyph-8c05c2c9f76e4b1540e0.jpg" alt="原书用字" style="width: 0.900em" />。<br />此生那老蜀，不死会归秦。<br />公若登台辅，临危莫爱身。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0631-1"><span class="footnote-number">〔一〕</span>鼎湖：二圣山陵，召武为桥道使，故云鼎湖。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0631-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0631-2"><span class="footnote-number">〔二〕</span>玉帐：《唐·艺文志》：李靖有《玉帐经》一卷。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0631-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0631-3"><span class="footnote-number">〔三〕</span>丹地：汉制，省中皆胡粉涂壁，画古贤列女，以丹漆地，谓之丹墀。张正见《艳歌》：“执戟移丹地。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0631-3" aria-label="返回正文">↩</a></span></p>

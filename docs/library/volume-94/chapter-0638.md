# 九日奉寄严大夫

<p class="du-fu-verse">九日应愁思，经时冒险艰。<br />不眠持汉节，何路出巴山。<br />小驿香醪嫩，重岩细菊<small class="du-fu-variant">《草堂》作雨</small>斑。<br />遥知簇鞍马，回首白云间。</p>

宝应元年四月，代宗即位，召武入朝。是年徐知道反，武阻兵，九月尚未出巴。《通鉴》载六月以武为西川节度使，徐知道守要害拒武，武不得进。误也，当以此诗正之。

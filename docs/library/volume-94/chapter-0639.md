# 黄草<sup class="footnote-ref" id="note-ref-du-fu-0639-1"><a href="#note-du-fu-0639-1">〔一〕</a></sup>

<p class="du-fu-verse">黄草峡西船不归，赤甲山下行人<small class="du-fu-variant">一云人行</small>稀。<br />秦中驿使无消息，蜀道兵<small class="du-fu-variant">一云干</small>戈有是非。<br />万里秋风吹锦水，谁家别泪湿罗衣。<br />莫愁剑阁终堪据，闻道松州已被围<sup class="footnote-ref" id="note-ref-du-fu-0639-2"><a href="#note-du-fu-0639-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0639-1"><span class="footnote-number">〔一〕</span>黄草：胡三省曰：《水经注》：涪州之西有黄葛峡，山高险绝，无人居，意即此峡也。杜诗“黄草峡西”，注云：在涪州之西。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0639-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0639-2"><span class="footnote-number">〔二〕</span>松州：《舆地纪胜》：《通鉴》于代宗广德元年书：吐蕃陷松、维、保三州。《茂州图经》云：广德二年，吐蕃取陇右，西川节度高适出兵西山，牵制无功，遂亡松、维。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0639-2" aria-label="返回正文">↩</a></span></p>

鹤曰：秦中驿使，谓李之芳奉使见留也。蜀道兵戈，谓徐知道据剑阁也。当时公在梓阆，非夔州诗也。按：鹤说良是，但又引来瑱、裴茂之战以解首二句，为曲说耳。

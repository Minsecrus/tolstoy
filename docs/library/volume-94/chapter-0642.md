# 不见

<small class="du-fu-variant">近无李白消息</small>

<p class="du-fu-verse">不见李生久，佯狂真可哀。<br />世人皆欲杀，吾意独怜才。<br />敏捷诗千首，飘零酒一杯。<br />匡山读书处<sup class="footnote-ref" id="note-ref-du-fu-0642-1"><a href="#note-du-fu-0642-1">〔一〕</a></sup>，头白好<small class="du-fu-variant">一云始</small>归来。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0642-1"><span class="footnote-number">〔一〕</span>匡山：《唐诗纪事》载东蜀杨天惠《彰明逸事》云：元符二年，补令于此，闻李白本邑人，微时募小吏，弃去，隐居大匡山，今犹有读书台。吴曾《能改斋漫录》、欧阳忞《舆地广记》皆本天惠之说。按，太白居庐山，见于诗文，不一而足。曾巩《诗序》云：永王璘节度东南，白时卧庐山，璘迫致之。公怜其因此得罪，故云“匡山读书处，头白好归来”。《彰明遗事》所载乃委巷传闻之语。近时杨慎辈力引为蜀中故事，殊不足信。《容斋三笔》亦云：太白乡郡，当以《范传正碑》为正。《范碑》云：国朝已来，编于属籍。神龙初，潜还广汉，因侨为郡人。杜田《杜诗补遗》引《范碑》云：白之先客居蜀之彰明，太白生焉云云。此好事者伪为之，以附会杜诗也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0642-1" aria-label="返回正文">↩</a></span></p>

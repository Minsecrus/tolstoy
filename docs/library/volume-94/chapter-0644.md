# 客夜

<p class="du-fu-verse">客睡何曾着，秋天不肯明。<br />卷帘残月影，高枕远江声。<br />计拙无衣食，途穷仗友生。<br />老妻书数纸，应悉未归情。</p>

吴曾《漫录》：张说有《深渡驿》诗云：洞房悬月影，高枕听江流。此诗用其意。

# 秋尽

<p class="du-fu-verse">秋尽东行且未回，茅斋寄在少城隈。<br />篱边老却陶潜菊，江上徒逢袁绍杯<sup class="footnote-ref" id="note-ref-du-fu-0646-1"><a href="#note-du-fu-0646-1">〔一〕</a></sup>。<br />雪岭独看西日落<small class="du-fu-variant">一云暮，</small>剑门犹阻北人来<sup class="footnote-ref" id="note-ref-du-fu-0646-2"><a href="#note-du-fu-0646-2">〔二〕</a></sup>。<br />不辞万里长为客，怀抱何时得好开<small class="du-fu-variant">一云好一开。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0646-1"><span class="footnote-number">〔一〕</span>袁绍杯：《郑玄传》：袁绍总兵冀州，遣使要玄，大会宾客，玄最后至，乃延升上坐。身长八尺，饮酒一斛，秀眉明目，容仪温伟。公以玄自况，为儒而遭世难也。旧注引河朔饮，非是。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0646-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0646-2"><span class="footnote-number">〔二〕</span>剑门：徐知道兵据剑阁，故曰“犹阻北人来”。邵宝曰：此时雪岭无人可到，但可望日落而已。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0646-2" aria-label="返回正文">↩</a></span></p>

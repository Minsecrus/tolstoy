# 野望

<p class="du-fu-verse">金华山北一云南涪水西<sup class="footnote-ref" id="note-ref-du-fu-0648-1"><a href="#note-du-fu-0648-1">〔一〕</a></sup>，仲冬风日始凄凄。<br />山连越嶲蟠三蜀<sup class="footnote-ref" id="note-ref-du-fu-0648-2"><a href="#note-du-fu-0648-2">〔二〕</a></sup>，水散巴渝下五溪<sup class="footnote-ref" id="note-ref-du-fu-0648-3"><a href="#note-du-fu-0648-3">〔三〕</a></sup>。<br />独鹤不知何事舞，饥乌似欲向人啼。<br />射洪春酒寒仍绿<sup class="footnote-ref" id="note-ref-du-fu-0648-4"><a href="#note-du-fu-0648-4">〔四〕</a></sup>，目极伤神谁为携。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0648-1"><span class="footnote-number">〔一〕</span>金华山：《方舆胜览》：在射洪县。 涪水：《寰宇记》：涪江，在郪县西二百里，自涪城县东南流入县界，合中江，东流入射洪县界，屈曲二十里，北通遂州。《水经》云：涪江水又东南合射江，今射洪县南有此水。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0648-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0648-2"><span class="footnote-number">〔二〕</span>越嶲：《寰宇记》：嶲州越嶲郡，本益州西南外夷地，汉武帝以邛都之地为越嶲郡，郡有越水、嶲水，皆出深羌界，南历本郡焉，故名越嶲郡。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0648-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0648-3"><span class="footnote-number">〔三〕</span>巴渝：《寰宇记》：巴州北水，一名巴岭水，一名渝州水，一名宕渠水，渝州今隶巴县。《三巴记》云：阆、白二水，东南流，曲折三回，如巴字，故谓三巴。 五溪：《寰宇记》：黔州涪陵水，一名内江水，在州西五十步，西北注涪州，入蜀江。五溪，谓酉、辰、巫、武、沅等五溪。《水经注》云：武陵有五溪，谓雄溪、樠溪、力溪、无溪、酉溪，辰溪其一焉。夹溪悉是蛮左右所居，故谓此蛮为五溪蛮也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0648-3" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0648-4"><span class="footnote-number">〔四〕</span>射洪：《元和郡国志》：梓潼水与涪江合流，急如箭，奔射涪江口，蜀人谓水口为洪，因名射洪。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0648-4" aria-label="返回正文">↩</a></span></p>

# 闻官军收河南河北

<small class="du-fu-variant">一云收两河</small>

<p class="du-fu-verse">剑外忽传收蓟北，初闻涕泪满衣裳。<br />却看妻子愁何在，漫卷诗书喜欲狂。<br />白日<small class="du-fu-variant">一云首</small>放歌须纵酒，青春作伴好还乡。<br />即从巴峡穿巫峡，便下襄阳向洛阳。<br /><small class="du-fu-variant">余田园在东京。</small></p>

宝应元年十一月，官军破贼于洛阳，进收东都。河南平，朝义走河北，李怀仙斩其首以献，河北平。此诗公在剑外闻捷书而作也。

# 春日梓州登楼二首

## 其一

<p class="du-fu-verse">行路难如此，登楼望欲迷。<br />身无却少壮，迹有但<small class="du-fu-variant">旧作但有</small>羁栖。<br />江水流城郭，春风入鼓鞞。<br />双双新燕子，依旧已衔泥。</p>

## 其二

<p class="du-fu-verse">天畔登楼眼，随春<small class="du-fu-variant">一云风</small>入故园。<br />战场今始定，移<small class="du-fu-variant">晋作栘</small>柳更能存。<br />厌蜀交游冷，思吴胜事繁。<br />应须理舟楫，长啸下荆门<sup class="footnote-ref" id="note-ref-du-fu-0651-1"><a href="#note-du-fu-0651-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0651-1"><span class="footnote-number">〔一〕</span>荆门：《寰宇记》：荆门本汉旧地，荆襄之要津。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0651-1" aria-label="返回正文">↩</a></span></p>

# 送路六侍御入朝

<p class="du-fu-verse">童稚情亲四<small class="du-fu-variant">一云三</small>十年，中间消息两茫然。<br />更为后会知何地，忽漫相逢是别筵。<br />不分<small class="du-fu-variant">《草堂》本作愤</small>桃花红胜锦<sup class="footnote-ref" id="note-ref-du-fu-0654-1"><a href="#note-du-fu-0654-1">〔一〕</a></sup>，生憎柳絮白于<small class="du-fu-variant">一作如</small>绵。<br />剑南春色还无赖，触忤愁人到酒边。</p>

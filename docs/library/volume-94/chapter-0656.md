# 上牛头寺<sup class="footnote-ref" id="note-ref-du-fu-0656-1"><a href="#note-du-fu-0656-1">〔一〕</a></sup>

<p class="du-fu-verse">青山意不尽，衮衮上牛头。<br />无复能拘碍，真成浪出游。<br />花浓春寺静，竹细野池幽。<br />何处莺啼切，移时独未休。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0656-1"><span class="footnote-number">〔一〕</span>牛头山：《寰宇记》：牛头山在郪县西南二里，高一里，形似牛头，四面孤绝，俯临州郭，下有长乐寺，楼阁烟花，为一方胜概。《图经》云：山上无禽鸟栖集。而杜诗有“莺啼”之句，则《图经》误也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0656-1" aria-label="返回正文">↩</a></span></p>

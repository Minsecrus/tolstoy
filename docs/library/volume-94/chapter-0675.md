# 王命

<p class="du-fu-verse">汉一云漠北豺狼满，巴西道路难。<br />血埋诸将甲，骨断使臣<small class="du-fu-variant">一云君</small>鞍<sup class="footnote-ref" id="note-ref-du-fu-0675-1"><a href="#note-du-fu-0675-1">〔一〕</a></sup>。<br />牢落新烧栈，苍茫旧筑坛<sup class="footnote-ref" id="note-ref-du-fu-0675-2"><a href="#note-du-fu-0675-2">〔二〕</a></sup>。<br />深怀喻蜀意，恸哭望王官<small class="du-fu-variant">一云京峦。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0675-1"><span class="footnote-number">〔一〕</span>使臣：广德元年，李之芳等使吐蕃被留，二年方得归。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0675-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0675-2"><span class="footnote-number">〔二〕</span>筑坛：旧注以为指郭子仪，余谓指严武也。武入朝而吐蕃陷河西、陇右，又围松州，蜀人思得武以代适也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0675-2" aria-label="返回正文">↩</a></span></p>

# 送元二适江左<sup class="footnote-ref" id="note-ref-du-fu-0678-1"><a href="#note-du-fu-0678-1">〔一〕</a></sup>

<p class="du-fu-verse">乱后今相见，秋深复远行。<br />风尘为客日，江海送君情。<br />晋室丹阳尹<sup class="footnote-ref" id="note-ref-du-fu-0678-2"><a href="#note-du-fu-0678-2">〔二〕</a></sup>，公孙白帝城<sup class="footnote-ref" id="note-ref-du-fu-0678-3"><a href="#note-du-fu-0678-3">〔三〕</a></sup>。<br />经过自爱惜，取次莫论兵。<br /><small class="du-fu-variant">元尝应孙吴科举。</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0678-1"><span class="footnote-number">〔一〕</span>元结：刘会孟本题下公自注：元结也。考《颜鲁公墓碑》及《次山集》，代宗时，以著作郎退居樊上，起家为道州刺史，未尝至蜀，亦未尝至江左。次山《舂陵行》及广德二年道州上《谢表》，时月皆可据，所谓元二者，必非结也。宋刻善本无此六字，明是后人妄益耳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0678-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0678-2"><span class="footnote-number">〔二〕</span>丹阳尹：梁元帝《丹阳尹传序》曰：自二京版荡，五马南渡，因乃上烛天文，下应地理。既变淮海为神州，亦即丹阳为京尹。虽得人之盛，颇愧前贤，而盻遇之深，多用宰辅。《晋中兴书》：大兴元年，改丹阳内史为丹阳尹。《晋书》：王敦以温峤为丹阳尹，欲使觇伺朝廷。峤至，具言敦逆谋。刘谦之《晋纪》曰：苏峻召祖约为逆，约遣许柳以众会，峻克京师，拜丹阳尹，后以罪诛。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0678-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0678-3"><span class="footnote-number">〔三〕</span>白帝城：《郡国志》：公孙述至鱼复，有白龙出井中，因号鱼复为白帝城。《寰宇记》：公孙述据蜀，自以承汉土运，故号曰“白帝城”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0678-3" aria-label="返回正文">↩</a></span></p>

# 玩月呈汉中王

<p class="du-fu-verse">夜深露气清，江月满江城。<br />浮<small class="du-fu-variant">一作游</small>客转危坐，归舟应独行。<br />关山同一照<small class="du-fu-variant">《海录》作点，</small>乌鹊自多惊。<br />欲得淮王术<sup class="footnote-ref" id="note-ref-du-fu-0680-1"><a href="#note-du-fu-0680-1">〔一〕</a></sup>，风吹晕已生。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0680-1"><span class="footnote-number">〔一〕</span>淮王：《淮南子》：画随灰而月晕阙。许慎注曰：有军士相围守则月晕，以芦灰环，阙其一面，则月晕亦阙于上。周王褒《关山月》诗：“天寒光转白，风多晕欲生。”庾肩吾《望月》诗：“圆随汉东蚌，晕逐淮南灰。”<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0680-1" aria-label="返回正文">↩</a></span></p>

# 遣愤

<p class="du-fu-verse">闻道花门将，论功未尽归。<br />自从收帝里，谁复总戎<small class="du-fu-variant">一云兵</small>机<small class="du-fu-variant">一云军麾。</small>蜂虿终怀毒，雷霆可振威。<br />莫令鞭血地，再湿汉臣衣。</p>

笺曰：回纥既助顺收河北，以贼平，恣行暴掠。代宗册命可汗，复论功封左右杀都督以下，寻为仆固怀恩所诱，与吐蕃合兵入寇。此诗盖深忧之也。初，雍王见回纥可汗于黄河北，责雍王不于帐前舞蹈，车鼻遂引药子昂、李进、章少华、魏琚各榜棰一百。少华、琚一宿而死。汉臣鞭血，正记此事也。

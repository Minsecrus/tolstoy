# 送李卿晔<sup class="footnote-ref" id="note-ref-du-fu-0692-1"><a href="#note-du-fu-0692-1">〔一〕</a></sup>

<p class="du-fu-verse">王子思归日，长安已乱兵。<br />沾衣问行在，走马向承明。<br />暮景巴蜀僻，春风江汉清。<br />晋山虽自弃<sup class="footnote-ref" id="note-ref-du-fu-0692-2"><a href="#note-du-fu-0692-2">〔二〕</a></sup>，魏阙尚含情。</p>

广德元年十月，吐蕃入寇，车驾幸陕。

<p class="footnote-definition footnote-source" id="note-du-fu-0692-1"><span class="footnote-number">〔一〕</span>李晔：《颜真卿集》：《颜允南神道碑》：潼关陷，舆驾幸蜀，朝官多出骆谷，至兴道，房琯、李晔、高适等数十人尽在。《世系表》：晔终刑部侍郎。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0692-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0692-2"><span class="footnote-number">〔二〕</span>晋山：《水经》：袁崧《郡国志》曰：界休县有介山，有绵上聚、子推庙，公自以不与灵武之赏，每以子推自喻也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0692-2" aria-label="返回正文">↩</a></span></p>

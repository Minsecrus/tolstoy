# 绝句

<p class="du-fu-verse">江边踏青罢<sup class="footnote-ref" id="note-ref-du-fu-0693-1"><a href="#note-du-fu-0693-1">〔一〕</a></sup>，回首见旌旗。<br />风起春城暮，高楼鼓角悲。</p>

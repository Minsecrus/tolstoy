# 奉待严大夫

<p class="du-fu-verse">殊方又喜故人来，重镇还须济世才。<br />常怪偏裨终日待，不知旌节隔年回。<br />欲辞巴徼啼莺合，远下荆门去鹢催。<br />身老时危思会面，一生襟<small class="du-fu-variant">一作怀</small>抱向谁开。</p>

广德二年正月，武以黄门侍郎拜成都尹，充剑南节度使。此云“大夫”，再镇时兼官也，以后称郑公。

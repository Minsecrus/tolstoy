# 奉寄高常侍

<small class="du-fu-variant">一云寄高三十五大夫</small>

<p class="du-fu-verse">汶上相逢年颇多，飞腾无那故人何。<br />总戎楚蜀应全未，方驾<small class="du-fu-variant">一云价</small>曹刘不啻过。<br />今日朝廷须汲黯，中原将帅忆廉颇。<br />天涯春色催迟暮，别泪遥添锦水波。</p>

代宗以严武代适，召还为刑部侍郎，转散骑常侍。适善言王霸大略，务功名，尚节义。逢时多难，以安危为己任，故以汲黯许之。

# 奉寄章十侍御

<small class="du-fu-variant">时初罢梓州刺史、东川留后，将赴朝廷。</small>

<p class="du-fu-verse">淮海维扬一俊人，金章紫绶照青春。<br />指麾能事回天地，训练强兵动鬼神。<br />湘西不得归关羽<sup class="footnote-ref" id="note-ref-du-fu-0702-1"><a href="#note-du-fu-0702-1">〔一〕</a></sup>，河内犹宜借寇恂。<br />朝觐从容问幽仄，勿云江汉有<small class="du-fu-variant">一作老</small>垂纶。</p>

《旧书》：梓州刺史章彝，初为武判官，及是小不副意，赴成都杖杀之。《国史补》：武与章彝素善，再入蜀，谈笑杀之。《云溪友议》：刺史章彝因小瑕，武遂棒杀，后为彝外家报怨，严氏遂微焉。按此诗，武再镇蜀，彝已入觐矣，岂及其未行而杀之耶！《新书》并载欲杀甫之事，尤为失实。

<p class="footnote-definition footnote-source" id="note-du-fu-0702-1"><span class="footnote-number">〔一〕</span>湘西：此暗指来瑱之事也。瑱镇襄阳，犹羽之专有荆土。以程元振构陷而死，故曰“不得归关羽”，婉词以伤之也。瑱徙淮西，讽将吏留己，若河内自请借寇，则当听之。故曰“犹宜借寇恂”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0702-1" aria-label="返回正文">↩</a></span></p>

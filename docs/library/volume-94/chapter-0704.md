# 奉寄别马巴州

<small class="du-fu-variant">时甫除京兆功曹在东川</small>

<p class="du-fu-verse">勋业终<small class="du-fu-variant">一作真</small>归马伏波，功曹非<small class="du-fu-variant">一云无</small>复汉萧何<sup class="footnote-ref" id="note-ref-du-fu-0704-1"><a href="#note-du-fu-0704-1">〔一〕</a></sup><small class="du-fu-variant">甫曾任华州司功。</small>扁舟系缆沙边久，南国浮云水上多。<br />独把鱼竿终远去，难随鸟<small class="du-fu-variant">樊作乌</small>翼一相过。<br />知君未爱春湖色，兴在骊驹白玉珂。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0704-1"><span class="footnote-number">〔一〕</span>功曹：《西溪丛语》：刘贡父据曹参未尝为功曹，以此诗为误。按《史记》：萧何为沛主吏掾。注曰：主吏，功曹也。杜未尝误。《吴志》：孙策谓虞翻曰：“孤有征讨事，未得还府，卿复以功曹为吾萧何，守会稽耳！”《旧书》：久之，召补京兆府功曹。严武镇成都，奏为节度参谋。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0704-1" aria-label="返回正文">↩</a></span></p>

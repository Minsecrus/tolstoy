# 陪王使君晦日泛江就黄家亭子二首

## 其一

<p class="du-fu-verse">山豁何时断，江平不肯流。<br />稍知花改岸，始验鸟随舟。<br />结束多红粉，欢娱恨白头。<br />非君爱人客，晦日更添<small class="du-fu-variant">一作禁</small>愁。</p>

## 其二

<p class="du-fu-verse">有径金沙软，无人碧草芳。<br />野畦连蛱蝶，江槛俯鸳鸯。<br />日晚烟花乱，风生锦绣香。<br />不须吹急管，衰老易悲伤。</p>

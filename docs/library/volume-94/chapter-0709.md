# 春远

<p class="du-fu-verse">肃肃花絮晚，菲菲红素轻。<br />日长唯鸟雀，春远独柴荆。<br />数有关中乱，何曾剑外清。<br />故乡<small class="du-fu-variant">一作园</small>归不得，地入亚夫营<sup class="footnote-ref" id="note-ref-du-fu-0709-1"><a href="#note-du-fu-0709-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0709-1"><span class="footnote-number">〔一〕</span>亚夫营：《后汉志》：长安有细柳聚，周亚夫所屯处。《长安志》：细柳仓，在咸阳县西南三十里。如淳曰：细柳仓在渭北，近石徼。张楫曰：在昆明池南，今有柳市是也。师古曰：《匈奴传》云：置三将军，军长安西细柳、渭北棘门、霸上。则此细柳不在渭北，楫说是也。《三辅故事》曰：今石徼是也。石徼西有细柳仓。《樊哙传》：柳中，即细柳地也，在长安西。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0709-1" aria-label="返回正文">↩</a></span></p>

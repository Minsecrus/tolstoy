# 百舌

<p class="du-fu-verse">百舌来何处，重重只报春。<br />知音兼众语，整翮岂多身。<br />花密藏难见<small class="du-fu-variant">一云难相见，</small>枝高听转新。<br />过时如发口<sup class="footnote-ref" id="note-ref-du-fu-0712-1"><a href="#note-du-fu-0712-1">〔一〕</a></sup>，君侧有谗人。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0712-1"><span class="footnote-number">〔一〕</span>过时：《汲冢周书·时训解》：芒种之日，螳螂生。又五日，鵙始鸣。又五日，反舌无声。螳螂不生，是谓阴息；鵙不始鸣，令奸壅逼；反舌有声，佞人在侧。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0712-1" aria-label="返回正文">↩</a></span></p>

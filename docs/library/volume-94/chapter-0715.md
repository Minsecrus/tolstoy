# 归梦

<p class="du-fu-verse">道路时通塞，江山日寂寥。<br />偷生唯一老，伐叛已三朝。<br />雨急青枫暮，云深黑水遥<sup class="footnote-ref" id="note-ref-du-fu-0715-1"><a href="#note-du-fu-0715-1">〔一〕</a></sup>。<br />梦归归未得<small class="du-fu-variant">一作梦魂归亦得，</small>不用楚辞招。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0715-1"><span class="footnote-number">〔一〕</span>黑水：《禹贡》：华阳黑水惟梁州。传曰：东据华山之南，西距黑水。又曰：黑水自北而南，经三危，过梁州，入南海。疏曰：滇池县有黑水祠。《水经注》：黑水出张掖鸡山，南流至燉煌，过三危山，南流入于南海。《寰宇记》：嶲州越嶲县有黑水。杜诗“云深黑水遥”是也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0715-1" aria-label="返回正文">↩</a></span></p>

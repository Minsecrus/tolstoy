# 别房太尉墓

<small class="du-fu-variant">阆州</small><sup class="footnote-ref" id="note-ref-du-fu-0726-1"><a href="#note-du-fu-0726-1">〔一〕</a></sup>

<p class="du-fu-verse">他乡复行役，驻马别孤坟。<br />近泪无干土，低空<small class="du-fu-variant">一云空山</small>有断云。<br />对棋陪谢傅<sup class="footnote-ref" id="note-ref-du-fu-0726-2"><a href="#note-du-fu-0726-2">〔二〕</a></sup>，把剑觅徐君<sup class="footnote-ref" id="note-ref-du-fu-0726-3"><a href="#note-du-fu-0726-3">〔三〕</a></sup>。<br />唯见林花落，莺啼送客闻。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0726-1"><span class="footnote-number">〔一〕</span>房太尉：琯以乾元元年贬邠州刺史，上元元年为汉州刺史，宝应三年拜刑部尚书，在路遇疾。广德元年八月，卒于阆州僧舍。《新书》载琯卒在宝应二年，与《旧书》异。按杜祭房公文，广德元年九月，而《酉阳杂俎》记琯舍阆州紫极宫，见治龟兹版，忆邢和璞言终身事，皆与《旧书》合，知《新书》误也。《国史补》：宰相自张曲江之后，称房太尉、李梁公为重德。又云：开元以后，不以姓而可称者：燕公、曲江、太尉、鲁公；不以名而可称者：宋开府、陆宣公、王右丞、房太尉。《困学纪闻》：司空图《房太尉》诗曰：“物望倾心久，匈渠破胆频。”注谓禄山初见分镇诏书，抚膺叹曰：“吾不得天下矣。”琯建议遣诸王为都统节度，而贺兰进明谗于肃宗。晋以琅琊立江左，宋以康王建中兴。以表圣之言观之，琯可谓善谋矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0726-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0726-2"><span class="footnote-number">〔二〕</span>对棋：琯为宰相，听董庭兰弹琴。李德裕《游房太尉西池诗》注：房公以好琴闻于海内。公此诗以谢傅围棋为比，盖为房公解嘲也。刘禹锡《和德裕房公旧竹亭闻琴》云：尚有竹间露，永无棋下尘。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0726-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0726-3"><span class="footnote-number">〔三〕</span>把剑：祭文云：抚坟日落，脱剑秋高。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0726-3" aria-label="返回正文">↩</a></span></p>

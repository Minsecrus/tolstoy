# 自阆州领妻子却赴蜀山行三首

## 其一

<p class="du-fu-verse">汩汩<small class="du-fu-variant">一作揖揖，又作浥浥，音蛰</small>避群盗，悠悠经十年。<br />不成向南国，复作游西川。<br />物役水虚照，魂伤山寂然。<br />我生无倚着，尽室畏途边。</p>

## 其二

<p class="du-fu-verse">长林偃风色，回复<small class="du-fu-variant">一云首</small>意犹迷。<br />衫裛翠微润，马衔青草嘶。<br />栈<small class="du-fu-variant">一云径</small>悬斜避石，桥断却寻溪。<br />何日干<small class="du-fu-variant">一作兵</small>戈尽，飘飘愧老妻。</p>

## 其三

<p class="du-fu-verse">行色递隐见，人烟时有无。<br />仆夫穿竹语，稚子入云呼。<br />转石惊魑魅，抨弓落狖鼯。<br />真供一笑乐<sup class="footnote-ref" id="note-ref-du-fu-0727-1"><a href="#note-du-fu-0727-1">〔一〕</a></sup>，似欲慰穷途。</p>

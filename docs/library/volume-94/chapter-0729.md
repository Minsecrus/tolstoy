# 行次盐亭县聊题四韵奉简严遂州蓬州两使君咨议诸昆季<sup class="footnote-ref" id="note-ref-du-fu-0729-1"><a href="#note-du-fu-0729-1">〔一〕</a></sup>

<p class="du-fu-verse">马首见盐亭，高山拥县青。<br />云溪花淡淡<small class="du-fu-variant">一云漠漠，</small>春郭水泠泠。<br />全蜀多名士，严家聚德星。<br />长歌意无极，好为老夫听。</p>

《寰宇记》：盐亭县因井为名。负戴山在县西一里，高二里，自剑门南来，过剑州，入当县，龙盘虎踞，起伏四百余里，至此却蹲。山有飞龙泉，喷下南流，入梓潼江，水色清泠，其味甘美，时以为琼浆水。

<p class="footnote-definition footnote-source" id="note-du-fu-0729-1"><span class="footnote-number">〔一〕</span>严君：《旧书》：严震，梓州盐亭人。屡出家财以助军，授州长史王府咨议参军。严武移西川，署为押衙。砺，震之宗人也。《寰宇记》：严震及弟砺二墓，在负戴山下，去县西一里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0729-1" aria-label="返回正文">↩</a></span></p>

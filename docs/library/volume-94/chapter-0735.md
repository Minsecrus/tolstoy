# 登楼

<p class="du-fu-verse">花近高楼伤客心，万方多难此登临。<br />锦江春色来<small class="du-fu-variant">一云水流</small>天地，玉垒浮云变古今<sup class="footnote-ref" id="note-ref-du-fu-0735-1"><a href="#note-du-fu-0735-1">〔一〕</a></sup>。<br />北极朝廷终不改，西山寇盗莫相侵。<br />可怜后主还祠庙，日暮聊为《梁甫吟》<sup class="footnote-ref" id="note-ref-du-fu-0735-2"><a href="#note-du-fu-0735-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0735-1"><span class="footnote-number">〔一〕</span>玉垒：《蜀都赋》：包玉垒而为宇。刘注：玉垒，山名也，湔水出焉，在成都西北。岷山界在后，故曰宇也。《寰宇记》：在茂州汶川县北三里。又有玉轮坂，其下汶水所经。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0735-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0735-2"><span class="footnote-number">〔二〕</span>梁甫吟：《水经注》：沔水又东经乐山北。昔诸葛亮好为《梁甫吟》，每取登游，故俗以乐山为名。《西溪丛语》：《艺文类聚》载诸葛亮《梁甫吟》，不知何义。张衡《四愁诗》：欲往从之梁甫艰。言人君有德则封泰山，泰山以喻人君，梁甫以喻小人也。诸葛好为《梁甫吟》，恐取此意。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0735-2" aria-label="返回正文">↩</a></span></p>

鹤曰：此广德二年避乱归成都之作。吐蕃陷京师，立广武郡王承宏为帝。郭子仪复京师，乘舆反正，故曰“北极朝廷终不改”。言吐蕃虽立君，终不能改命也。

笺曰：“西山寇盗”，指吐蕃言之，非谓“剑南西山”也。“可怜后主还祠庙”，其以代宗任用程元振、鱼朝恩，致蒙尘之祸，而托讽于后主之用黄皓乎？其兴寄微婉如此。

# 寄董卿嘉荣十韵

<p class="du-fu-verse">闻道君牙帐<sup class="footnote-ref" id="note-ref-du-fu-0739-1"><a href="#note-du-fu-0739-1">〔一〕</a></sup>，防秋近赤霄<sup class="footnote-ref" id="note-ref-du-fu-0739-2"><a href="#note-du-fu-0739-2">〔二〕</a></sup>。<br />下临千雪岭<small class="du-fu-variant">一作千仞雪，</small>却背五绳桥。<br />海内久戎服，京师今晏朝。<br />犬羊曾烂熳，宫阙尚萧条。<br />猛将宜尝胆，龙泉必在腰。<br />黄图遭污辱，月窟可焚烧。<br />会取干戈利，无令斥候骄。<br />居然双捕虏，自是一嫖姚。<br />落日思轻骑，高<small class="du-fu-variant">一作秋</small>天忆射雕。<br />云台画形像，皆为扫氛妖。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0739-1"><span class="footnote-number">〔一〕</span>君牙：吴若本注云：此邢君牙也。本传云：田神功为兖郓节度使，使君牙将屯兵好畤防秋。神功镇兖郓，在代宗初，故曰京师今晏朝。是时君牙尚微，在神功麾下，乃名斥之。按此诗言“君牙帐”者，谓君之牙帐也。雪岭、绳桥，皆防西之地。邢君牙领防秋兵入镇好畤，又扈从代宗幸陕，与此诗绝不相涉。若但以“君牙”二字，曲说附会耳。 牙帐：《唐志》：佛堂一百八十里至勃令驿，鸿胪馆至赞普牙帐。《南部新书》：近代通谓府庭为公衙，即古之公朝也。字本作“牙”。《诗》曰：“祈父，予王之爪牙。”祈父，司马，掌武备。象兽以爪牙为衙，故军前大旗谓之牙旗，出师则有建牙、禡牙之事。军中听号令，必至牙旗之下，与府朝无异。近俗尚武，是以通呼。公府门为牙门，字讹变转而为“衙”。《珩璜新论》：突厥畏李靖，徙牙于碛中。牙者，旗也。《东京赋》：竿上以象牙饰之。后人遂以牙为衙。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0739-1" aria-label="返回正文">↩</a></span></p>

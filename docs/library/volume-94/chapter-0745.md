# 过故斛斯校书庄二首

<small class="du-fu-variant">老儒艰难时，病于庸蜀。叹其没后，方授一官。《英华》注云：公名融。</small>

## 其一

<p class="du-fu-verse">此老已云殁，邻人嗟亦休<small class="du-fu-variant">一云叹未休。</small>竟无宣室召，徒有茂陵求。<br />妻子寄他食，园林非昔游。<br />空堂穗帷在，淅淅野风秋。</p>

## 其二

<p class="du-fu-verse">燕入非傍舍，鸥归只故池。<br />断桥无复板，卧柳自生枝。<br />遂有山阳作，多惭鲍叔知。<br />素交零落尽，白首泪双垂。</p>

公诗有“走觅南邻爱酒伴”。注云：斛斯融，吾酒徒。

# 奉和

<p class="du-fu-verse">秋风袅袅动高旌，玉帐分弓射虏营。<br />已收滴博云间戍<sup class="footnote-ref" id="note-ref-du-fu-0748-1"><a href="#note-du-fu-0748-1">〔一〕</a></sup>，更夺<small class="du-fu-variant">胡三省作次取</small>蓬婆雪外城<sup class="footnote-ref" id="note-ref-du-fu-0748-2"><a href="#note-du-fu-0748-2">〔二〕</a></sup>。</p>

《严武传》：广德二年，破吐蕃七万余众，拔当狗城。十月取盐川城。《崔旰传》：武遣旰统兵西山，拓地数百里。

<p class="footnote-definition footnote-source" id="note-du-fu-0748-1"><span class="footnote-number">〔一〕</span>滴博：《困学纪闻》：的博岭在维州。《韦皋传》：出西山灵关，破峨和通鹤，定廉城。逾的博岭，遂围维州。搏鸡栖，攻下羊溪等三城，取剑山屯焚之。李义山《献杜仆射》诗：南诏应闻命，西山莫敢惊。寄辞收的博，端坐扫欃枪。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0748-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0748-2"><span class="footnote-number">〔二〕</span>蓬婆：《元和郡国志》：柘州城西面险阻，易于固守。有安戎江、蓬婆水，在州南三十里。大雪山一名蓬婆山，在柘县西北一百里。《吐蕃传》：开元二十六年，王昱率剑南兵攻安戎，顿兵于蒲婆岭下，运剑南道资粮以守之。胡三省曰：《新书》作蓬婆岭，其地在雪山外。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0748-2" aria-label="返回正文">↩</a></span></p>

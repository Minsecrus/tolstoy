# 院中晚晴怀西郭茅舍

<p class="du-fu-verse">幕府秋风日夜清，澹云疏雨过高城。<br />叶心朱实看<small class="du-fu-variant">一作堪</small>时落，阶面青苔先自生。<br />复有楼台衔暮景，不劳钟鼓报新晴。<br />浣花溪里花饶笑，肯信吾兼<small class="du-fu-variant">一作今</small>吏隐名。</p>

张璁曰：此公有不乐于幕府者也。明年正月，遂行归草堂。

# 哭严仆射归榇

<p class="du-fu-verse">素幔随流水，归舟返旧京。<br />老亲如宿昔，部曲异平生。<br />风送<small class="du-fu-variant">一作逆</small>蛟龙雨<small class="du-fu-variant">一作匣</small><sup class="footnote-ref" id="note-ref-du-fu-0765-1"><a href="#note-du-fu-0765-1">〔一〕</a></sup>，天长骠骑营。<br />一哀三峡暮，遗后见君情。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0765-1"><span class="footnote-number">〔一〕</span>蛟龙匣：《西京杂记》：汉帝送死，皆珠襦玉匣。武帝匣上皆镂为蛟龙、鸾凤、龟麟之象，世谓为“蛟龙玉匣”。按《霍光传》：赐璧珠玑玉衣梓宫。则人臣亦可称“蛟龙匣”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0765-1" aria-label="返回正文">↩</a></span></p>

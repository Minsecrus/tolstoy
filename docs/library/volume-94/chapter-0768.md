# 拨闷

<small class="du-fu-variant">一云赠严二别驾</small>

<p class="du-fu-verse">闻道云安曲米春<sup class="footnote-ref" id="note-ref-du-fu-0768-1"><a href="#note-du-fu-0768-1">〔一〕</a></sup>，才倾一盏即醺人。<br />乘舟取醉非难事，下峡消愁定几巡。<br />长年三老遥怜汝，棙柂开头<small class="du-fu-variant">一作鸣铙</small>捷有神。<br />已办青钱防雇直，当令美味入吾唇。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0768-1"><span class="footnote-number">〔一〕</span>曲米春：东坡云：退之诗：“且可勤买抛青春。”杜诗有“曲米春”，裴硎《传奇》有松醪春。《国史补》云：郢之富水，乌程之若下，荥阳之土窟春，富平之石冻春，剑南之烧春。乃知唐人名酒多以“春”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0768-1" aria-label="返回正文">↩</a></span></p>

# 题忠州龙兴寺所居院壁

<p class="du-fu-verse">忠州三峡内，井邑聚云根。<br />小市常争米，孤城早闭门。<br />空<small class="du-fu-variant">一作岂</small>看过客泪，莫觅主人恩。<br />淹泊仍愁虎，深居赖独园。</p>

陆务观有《龙兴寺吊少陵先生寓居》诗：“扈跸老臣身万里，天寒来此听江声！”寺门听江声甚壮。

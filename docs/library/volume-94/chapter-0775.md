# 十二月一日三首

## 其一

<p class="du-fu-verse">今朝腊月春意动，云安县前江可怜。<br />一声何处送书雁，百丈谁家上水<small class="du-fu-variant">一作濑</small>船。<br />未将梅蕊惊愁眼，要<small class="du-fu-variant">一作更</small>取楸<small class="du-fu-variant">一作椒</small>花媚远天。<br />明光起草人所羡，肺病几时朝日边。</p>

云安冬蒸地暖，有烟雾。又家有盐井，其俗以女当门户，多贩盐自给。

## 其二

<p class="du-fu-verse">寒轻市上山烟碧，日满楼前江雾黄。<br />负盐出井此溪女，打鼓发船何郡郎。<br />新亭举目风景切<sup class="footnote-ref" id="note-ref-du-fu-0775-1"><a href="#note-du-fu-0775-1">〔一〕</a></sup>，茂陵著书消渴长。<br />春花不愁不烂熳，楚客唯听棹相将<sup class="footnote-ref" id="note-ref-du-fu-0775-2"><a href="#note-du-fu-0775-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0775-1"><span class="footnote-number">〔一〕</span>新亭：山谦之《丹阳记》：新亭，吴旧亭也。隆安中，丹阳尹司马恢移创今地。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0775-1" aria-label="返回正文">↩</a></span></p>

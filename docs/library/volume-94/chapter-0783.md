# 将晓二首

## 其一

<p class="du-fu-verse">石城除击柝，铁锁欲开关。<br />鼓角悲荒塞，星河落曙山。<br />巴人常小梗，蜀使动无还。<br />垂老孤帆色，飘飘犯百<small class="du-fu-variant">一作白</small>蛮。</p>

## 其二

<p class="du-fu-verse">军吏回官烛，舟人自楚歌。<br />寒沙蒙薄雾，落月去清波。<br />壮惜身名晚，衰惭应接多。<br />归朝日簪笏，筋力定如何？</p>

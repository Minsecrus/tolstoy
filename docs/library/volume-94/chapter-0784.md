# 怀锦水居止二首

## 其一

<p class="du-fu-verse">军旅西征僻，风尘战伐多。<br />犹<small class="du-fu-variant">一作独</small>闻蜀父老，不忘舜讴歌。<br />天险终难立，柴门岂重过？<br />朝朝巫峡水，远逗锦江波。</p>

## 其二

<p class="du-fu-verse">万里桥南<small class="du-fu-variant">当作西</small>宅，百花潭北庄。<br />层轩皆面水，老树饱经霜。<br />雪岭界天白，锦城曛日黄。<br />惜哉形胜地，回首一茫茫。</p>

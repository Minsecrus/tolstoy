# 子规

<p class="du-fu-verse">峡里云安县，江楼翼瓦齐。<br />两边山木合，终日子规啼。<br />眇眇春风见，萧萧夜色凄。<br />客愁那听此，故作傍人低<small class="du-fu-variant">一作故傍旅人低。</small></p>

吴曾《漫录》：鲍彪《诗谱》：柳子厚永州游山记云：多秭归之禽。秭归是蜀中地名，疑其地多此禽也。《史记·历书》：秭鴂先滜。注：秭音姊，鴂音规，子规鸟也。一名鷤塢。乃知子规作“秭归”，不为无本矣。按郦道元《水经注》，乃县之名，秭归以屈原姊得名。鲍说非也。

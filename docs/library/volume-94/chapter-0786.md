# 立春

<p class="du-fu-verse">春日春盘细生菜<sup class="footnote-ref" id="note-ref-du-fu-0786-1"><a href="#note-du-fu-0786-1">〔一〕</a></sup>，忽忆两京梅发时。<br />盘出高门行白玉<sup class="footnote-ref" id="note-ref-du-fu-0786-2"><a href="#note-du-fu-0786-2">〔二〕</a></sup>，菜传纤手送青丝。<br />巫峡寒江那对眼，杜陵远客不胜悲。<br />此身未知归定处，呼儿觅纸一题诗。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0786-1"><span class="footnote-number">〔一〕</span>春盘：《摭遗》：东晋李鄂，立春日命以芦菔芹芽为菜盘相馈贶。《四时宝镜》：立春日春饼生菜，号春盘。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0786-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0786-2"><span class="footnote-number">〔二〕</span>高门：《三辅旧事》：武帝于未央宫起高门武台殿。《鲍宣传》：高门去省户数十步，求见出入，二年未省。《水经注》：北出西头第二门，本名洛门，又曰朝门，一曰高门。苏林曰：高门，长安城北门也。一曰厨门，其内有长安厨官在东，故曰“厨门”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0786-2" aria-label="返回正文">↩</a></span></p>

# 漫成一绝

<p class="du-fu-verse">江月去人只数尺，风灯照夜欲三更。<br />沙头宿鹭联拳静<small class="du-fu-variant">一作起，</small>船尾跳鱼拨<small class="du-fu-variant">一作跋</small>剌鸣<sup class="footnote-ref" id="note-ref-du-fu-0787-1"><a href="#note-du-fu-0787-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0787-1"><span class="footnote-number">〔一〕</span>拨剌：吴曾《漫录》：《思玄赋》云：“弯威弧之拨剌。”注：拨剌，张弓声，而非鱼也。太白诗：“双鳃呀呷鳍鬣张，跋剌银盘欲飞去。”意与杜同，以“拨”为“跋”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0787-1" aria-label="返回正文">↩</a></span></p>

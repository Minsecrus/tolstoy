# 寄岑嘉州

<small class="du-fu-variant">州据蜀江外</small>

<p class="du-fu-verse">不见故人十年余，不道故人无素书。<br />愿逢颜色关塞远，岂意出守江城居。<br />外江三峡且相接，斗酒新诗终日<small class="du-fu-variant">一作自</small>疏。<br />谢朓每篇堪讽诵，冯唐已老听吹嘘。<br />泊船秋夜经春草，伏枕青枫限玉除。<br />眼前所寄选何物，赠子云安双鲤鱼。</p>

按杜确《岑嘉州诗集序》，参自库部正郎出为嘉州，杜鸿渐表为职方郎中兼侍御史，列于幕府。无几使罢，寓居于蜀。鸿渐使罢还朝，在大历二年六月。则公寄此诗当在元年。

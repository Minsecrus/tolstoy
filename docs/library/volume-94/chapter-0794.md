# 雨不绝

<p class="du-fu-verse">鸣雨既过渐细<small class="du-fu-variant">晋作细雨</small>微，映空摇扬如丝飞。<br />阶前短草泥不乱，院里长条风乍稀。<br />舞石旋应将乳子<sup class="footnote-ref" id="note-ref-du-fu-0794-1"><a href="#note-du-fu-0794-1">〔一〕</a></sup>，行云莫自湿仙衣。<br />眼边江舸何匆促，未待<small class="du-fu-variant">晋作得</small>安流逆浪归。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0794-1"><span class="footnote-number">〔一〕</span>舞石：《水经注》：石燕山。其山有石，绀而状燕，因以名山。其石或大或小，若母子焉。及雷风相薄，则石燕群飞颉颃如真燕矣。罗君章云：今燕不必复飞也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0794-1" aria-label="返回正文">↩</a></span></p>

# 夜宿西阁晓呈元二十一曹长

<p class="du-fu-verse">城暗更筹急，楼高雨雪微。<br />稍通绡幕霁，远带玉绳稀。<br />门鹊晨光起<small class="du-fu-variant">一作喜，</small>墙<small class="du-fu-variant">一作樯</small>乌宿处飞<sup class="footnote-ref" id="note-ref-du-fu-0797-1"><a href="#note-du-fu-0797-1">〔一〕</a></sup>。<br />寒江流甚细，有意待人归。</p>

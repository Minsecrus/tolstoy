# 不离西阁二首

## 其一

<p class="du-fu-verse">江柳非时发，江花冷色频。<br />地偏应有瘴，腊近已含春。<br />失学从愚子，无家住<small class="du-fu-variant">一作任</small>老身。<br />不知西阁意，肯别定留<small class="du-fu-variant">一作何</small>人。</p>

旧注：落句言“西阁”之意肯令我别乎？莫定要留人也。

## 其二

<p class="du-fu-verse">西阁从人别，人今亦故亭。<br />江云飘素练<small class="du-fu-variant">一作叶，</small>石壁断<small class="du-fu-variant">一作斩</small>空青。<br />沧海先迎日，银河倒列星。<br />平生耽胜事，吁骇始初经。</p>

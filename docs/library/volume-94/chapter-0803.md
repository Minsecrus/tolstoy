# 阁夜

<p class="du-fu-verse">岁暮阴阳催短景，天涯霜雪霁寒宵。<br />五更鼓角声悲壮，三峡星河影动摇<sup class="footnote-ref" id="note-ref-du-fu-0803-1"><a href="#note-du-fu-0803-1">〔一〕</a></sup>。<br />野哭几<small class="du-fu-variant">晋作千</small>家闻战伐，夷歌数<small class="du-fu-variant">晋作是</small>处起渔樵。<br />卧龙跃马终黄土<sup class="footnote-ref" id="note-ref-du-fu-0803-2"><a href="#note-du-fu-0803-2">〔二〕</a></sup>，人事依依漫<small class="du-fu-variant">一作音尘日，一作音书颇</small>寂寥。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0803-1"><span class="footnote-number">〔一〕</span>星河：《天官书》：天一、枪、棓、矛、盾动摇，角大，兵起。《汉书》：元光中，天星尽摇。上以问候星者。对曰：星摇者，民劳也。后伐四夷，百姓劳于兵革。《汉武故事》：元光元年，天星大动，光耀焕焕竟天，数夜乃止。上以问董仲舒，对曰：是谓星摇，民人劳之妖也。是岁谋伐匈奴，天下始不安。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0803-1" aria-label="返回正文">↩</a></span></p>

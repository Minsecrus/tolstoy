# 赤甲

<p class="du-fu-verse">卜居赤甲迁居新，两见巫山楚水春。<br />炙背可以献天子<sup class="footnote-ref" id="note-ref-du-fu-0807-1"><a href="#note-du-fu-0807-1">〔一〕</a></sup>，美芹由来知野人。<br />荆州郑薛寄书近，蜀客郗岑非我邻<sup class="footnote-ref" id="note-ref-du-fu-0807-2"><a href="#note-du-fu-0807-2">〔二〕</a></sup>。<br />笑接郎中评事饮，病从深酌道吾真。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0807-1"><span class="footnote-number">〔一〕</span>炙背：嵇康《绝交书》：野人有快炙背而美芹子者，欲献之至尊。虽有区区之意。亦已疏矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0807-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0807-2"><span class="footnote-number">〔二〕</span>郗岑：符载《杨鸥墓志》：永泰三载，相国杜公鸿渐奏授犀浦县令，僚友杜员外甫、岑郎中参、郗舍人昂，闻公摈落，失声咨嗟。郑、薛，即郑审、薛据也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0807-2" aria-label="返回正文">↩</a></span></p>

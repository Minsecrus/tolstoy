# 示獠奴阿段<sup class="footnote-ref" id="note-ref-du-fu-0812-1"><a href="#note-du-fu-0812-1">〔一〕</a></sup>

<p class="du-fu-verse">山木苍苍落日曛，竹竿袅袅细泉分。<br />郡人入夜争余沥，竖<small class="du-fu-variant">一作稚</small>子寻源独不闻。<br />病渴三更回白首，传声一注湿青云。<br />曾惊陶侃胡奴异<sup class="footnote-ref" id="note-ref-du-fu-0812-2"><a href="#note-du-fu-0812-2">〔二〕</a></sup>，怪尔常穿虎豹群。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0812-1"><span class="footnote-number">〔一〕</span>獠奴：《北史》：獠无名字，以长幼次第呼之。丈夫称阿谟、阿段，妇人称阿夷、阿等之类。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0812-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0812-2"><span class="footnote-number">〔二〕</span>胡奴：陶侃胡奴，未详所出，旧引伪坡注，今削之。有人云见刘敬叔《异苑》。考之，仍是伪苏注也。《异苑》是流俗刻本，或缮写人剿入耳，不足援据。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0812-2" aria-label="返回正文">↩</a></span></p>

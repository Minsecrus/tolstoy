# 茅堂检校收稻二首

## 其一

<p class="du-fu-verse">香稻三秋末，平田百顷间。<br />喜无多屋宇，幸不碍云山。<br />御夹侵寒气，尝新破旅颜。<br />红鲜终日有，玉粒未吾悭。</p>

## 其二

<p class="du-fu-verse">稻米炊能白，秋葵煮复新。<br />谁云滑易饱，老藉软俱匀。<br />种幸房州熟<sup class="footnote-ref" id="note-ref-du-fu-0821-1"><a href="#note-du-fu-0821-1">〔一〕</a></sup>，苗同伊阙春<sup class="footnote-ref" id="note-ref-du-fu-0821-2"><a href="#note-du-fu-0821-2">〔二〕</a></sup>。<br />无劳映渠碗，自有色如银。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0821-1"><span class="footnote-number">〔一〕</span>房州：房州，唐与夔州并属山南道。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0821-1" aria-label="返回正文">↩</a></span></p>

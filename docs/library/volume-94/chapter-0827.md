# 上白帝城

<p class="du-fu-verse">城峻随天壁<sup class="footnote-ref" id="note-ref-du-fu-0827-1"><a href="#note-du-fu-0827-1">〔一〕</a></sup>，楼高更<small class="du-fu-variant">一作望</small>女墙<sup class="footnote-ref" id="note-ref-du-fu-0827-2"><a href="#note-du-fu-0827-2">〔二〕</a></sup>。<br />江流思夏后，风至忆襄王。<br />老去闻悲角，人扶报夕阳。<br />公孙初恃险<sup class="footnote-ref" id="note-ref-du-fu-0827-3"><a href="#note-du-fu-0827-3">〔三〕</a></sup>，跃马意何长。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0827-1"><span class="footnote-number">〔一〕</span>城峻：《寰宇记》：《荆州记》云：巴东郡峡上北岸有一山，孤峙甚峭，巴东郡据以为城。《水经注》云：白帝山北缘马岭，接赤岬山。其间平处，南北相去八十五丈，东西七十丈。又东傍瀼溪，即以为隍。西南临大江，瞰之眩目。惟马岭小差逶迤，犹斩山为路，羊肠数转，然后得上。故《记》云：寒山九坂，最为险峻。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0827-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0827-2"><span class="footnote-number">〔二〕</span>女墙：《释名》：城上垣谓之女墙，言其卑小，比之于城，如女子之于丈夫也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0827-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0827-3"><span class="footnote-number">〔三〕</span>公孙：《蜀都赋》：公孙跃马而称帝。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0827-3" aria-label="返回正文">↩</a></span></p>

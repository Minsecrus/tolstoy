# 白盐山

<p class="du-fu-verse">卓立群峰外，蟠根积水边<sup class="footnote-ref" id="note-ref-du-fu-0832-1"><a href="#note-du-fu-0832-1">〔一〕</a></sup>。<br />他皆任厚地，尔<small class="du-fu-variant">一作我</small>独近高天。<br />白榜千家邑，清秋万估<small class="du-fu-variant">一作里</small>船。<br />词人取佳句，刻画竟谁传<small class="du-fu-variant">《英华》作刷练始堪传？</small></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0832-1"><span class="footnote-number">〔一〕</span>积水：《荆州记》曰：三峡之首，北岸有白盐峰，峰下有黄龙滩，水最急，沿溯所忌。故曰“积水边”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0832-1" aria-label="返回正文">↩</a></span></p>

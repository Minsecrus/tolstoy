# 晓望白帝城盐山<sup class="footnote-ref" id="note-ref-du-fu-0837-1"><a href="#note-du-fu-0837-1">〔一〕</a></sup>

<p class="du-fu-verse">徐步移班杖，看山仰白头。<br />翠深开断壁，红<small class="du-fu-variant">一作江</small>远结飞楼。<br />日出清<small class="du-fu-variant">一作寒</small>江望，暄和散旅愁。<br />春城见松雪，始拟进归舟。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0837-1"><span class="footnote-number">〔一〕</span>盐山：《水经注》：广溪峡，其间三十里，颓岩倚木，厥势殆交。北岸山上有神渊，渊北有白盐崖，高可千余丈。土人见其高白，因以名之。《方舆胜览》：在城东七十里，崖壁五十余里。其色炳耀，状若白盐。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0837-1" aria-label="返回正文">↩</a></span></p>

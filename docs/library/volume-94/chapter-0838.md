# 白帝城最高楼

<p class="du-fu-verse">城尖径昃<small class="du-fu-variant">一作翼</small>旌旆愁，独立缥缈之飞楼。<br />峡坼云霾龙虎卧<small class="du-fu-variant">吴作睡，</small>江清日抱鼋鼍游。<br />扶桑西枝对<small class="du-fu-variant">一作封</small>断石<sup class="footnote-ref" id="note-ref-du-fu-0838-1"><a href="#note-du-fu-0838-1">〔一〕</a></sup>，弱水东影随长流<sup class="footnote-ref" id="note-ref-du-fu-0838-2"><a href="#note-du-fu-0838-2">〔二〕</a></sup>。<br />杖藜叹世者谁子，泣血迸空回白头。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0838-1"><span class="footnote-number">〔一〕</span>扶桑：《山海经》：旸谷上有扶桑，十日所浴居。水中有大木，九日居下枝，一日居上枝。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0838-1" aria-label="返回正文">↩</a></span></p>

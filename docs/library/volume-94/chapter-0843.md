# 峡口二首

## 其一

<p class="du-fu-verse">峡口大江间，西南控百蛮。<br />城欹连粉堞，岸断更青山。<br />开辟多<small class="du-fu-variant">一作当</small>天险，防隅一水关。<br />乱离闻鼓角，秋气动衰颜。</p>

## 其二

<p class="du-fu-verse">时清关失险，世乱戟如林。<br />去矣英雄事，荒哉割据心。<br />芦花留客晚，枫树坐猿深。<br />疲苶烦亲故，诸侯数赐金。<br /><small class="du-fu-variant">主人柏中丞频分月俸。</small></p>

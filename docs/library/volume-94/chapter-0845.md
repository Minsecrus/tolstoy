# 瞿塘两崖

<p class="du-fu-verse">三峡传何处，双崖壮此门。<br />入天犹石色，穿水忽云根<sup class="footnote-ref" id="note-ref-du-fu-0845-1"><a href="#note-du-fu-0845-1">〔一〕</a></sup>。<br />猱玃须髯古，蛟龙窟宅尊。<br />羲和冬<small class="du-fu-variant">一作骖</small>驭近，愁畏日车翻。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0845-1"><span class="footnote-number">〔一〕</span>云根：诗人多以云根为石，以云触石而生也。宋孝武《登乐山诗》：屯烟扰风穴，积水溺云根。元魏宣武裴粲诏云：栖素云根，饵芝清壑。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0845-1" aria-label="返回正文">↩</a></span></p>

# 偶题

<p class="du-fu-verse">文章千古事，得失寸心知。<br />作者皆殊列，名声岂浪垂？<br />骚人嗟不见，汉道盛于斯。<br />前辈飞腾入，余波绮丽为。<br />后贤兼旧列<small class="du-fu-variant">一云制，一云利，别本作例，</small>历代各清规。<br />法自儒家有，心从弱岁疲。<br />永怀江左逸<sup class="footnote-ref" id="note-ref-du-fu-0848-1"><a href="#note-du-fu-0848-1">〔一〕</a></sup>，多病<small class="du-fu-variant">一作谢</small>邺中奇<sup class="footnote-ref" id="note-ref-du-fu-0848-2"><a href="#note-du-fu-0848-2">〔二〕</a></sup>。<br />騄骥皆良马，骐<img class="du-fu-glyph" src="/library/volume-94/images/glyph-a91c8dd1376d63f444c7.jpg" alt="原书用字" style="width: 1.050em" />带好儿。<br />车轮徒已斲，堂构惜<small class="du-fu-variant">一作肯</small>仍亏。<br />漫作潜夫论，虚传幼妇碑<small class="du-fu-variant">一作词。</small>缘情慰漂荡，抱疾屡迁移。<br />经济惭长策，飞栖假一枝。<br />尘沙傍蜂虿，江峡绕蛟螭。<br />萧瑟唐虞远，联翩楚汉危。<br />圣朝兼盗贼，异俗更喧卑。<br />郁郁星辰剑，苍苍云雨池。<br />两都开幕府，万宇插军麾。<br />南海残铜柱，东风避月支<sup class="footnote-ref" id="note-ref-du-fu-0848-3"><a href="#note-du-fu-0848-3">〔三〕</a></sup>。<br />音书恨乌鹊，号怒怪熊罴。<br />稼穑分诗兴，柴荆学土宜。<br />故山迷白阁，秋水隐<small class="du-fu-variant">一作忆</small>黄陂。<br />不敢要佳句，愁来赋别离。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0848-1"><span class="footnote-number">〔一〕</span>江左：沈约《谢灵运传论》：降及元康，潘、陆特秀。遗风余烈，事极江左。自建武暨于义熙，历载将百，遒丽之辞无闻焉耳。仲文始革孙、许之风，叔源大变太元之气。爰逮宋氏，颜、谢腾声。《文心雕龙》：江左篇制，溺乎玄风。《续晋阳秋》曰：正始中，王、何好庄老。至过江，佛理尤盛。郭璞五言，始会合道家之言而韵之。孙绰、许询，转相祖尚，而诗骚之体尽矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0848-1" aria-label="返回正文">↩</a></span></p>

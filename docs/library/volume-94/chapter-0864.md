# 鹦鹉<sup class="footnote-ref" id="note-ref-du-fu-0864-1"><a href="#note-du-fu-0864-1">〔一〕</a></sup>

<p class="du-fu-verse">鹦鹉含愁思，聪明忆别离。<br />翠衿浑短尽，红嘴漫多知。<br />未有开笼日，空残旧宿枝。<br />世人怜复损，何用羽毛奇？</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0864-1"><span class="footnote-number">〔一〕</span>鹦鹉：祢衡赋：性辩慧而能言兮，才聪明以识机。绀趾丹嘴，绿衣翠衿，闭以雕笼，剪其翅羽。想昆山之高岳，思邓林之扶疏。顾六翮之残毁，虽奋迅其焉如？《明皇杂录》：开元中，岭南献白鹦鹉，养之宫中。岁久颇纵聪慧，洞晓言词。上及贵妃，皆呼“雪衣娘”。戏于殿槛，有鹰搏之而毙，遂瘗于苑中为主冢，呼为“鹦鹉冢”。此诗亦咏开元旧事也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0864-1" aria-label="返回正文">↩</a></span></p>

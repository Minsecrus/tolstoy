# 洛阳

<p class="du-fu-verse">洛阳昔陷没，胡马犯潼关。<br />天子初愁思<sup class="footnote-ref" id="note-ref-du-fu-0866-1"><a href="#note-du-fu-0866-1">〔一〕</a></sup>，都人惨别颜。<br />清笳去宫阙，翠盖出关山。<br />故老仍流涕，龙髯幸再攀<sup class="footnote-ref" id="note-ref-du-fu-0866-2"><a href="#note-du-fu-0866-2">〔二〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0866-1"><span class="footnote-number">〔一〕</span>愁思：明皇十七年，羯胡犯阙。上欲迁幸，登兴庆宫花蕚楼。置酒，四顾凄怆，使美人善歌者一人歌《水调》。毕奏，上将去，复留眷眷，因使视楼下，有少年善《水调歌头》者，使之登楼且歌。上闻之，潸然出涕，顾侍者曰：“谁为此词？”曰：“李峤。”上曰：“李峤真才子也。”不待曲终而去。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0866-1" aria-label="返回正文">↩</a></span></p>

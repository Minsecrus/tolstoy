# 中夜

<p class="du-fu-verse">中夜江山静，危楼望北辰。<br />长为万里客，有愧百年身。<br />故国风云气，高堂战伐尘。<br />胡雏负恩泽，嗟尔太平人。</p>

梦弼曰：“故国”，谓长安也；“高堂”，谓杜陵屋庐也；“胡雏”指禄山也。

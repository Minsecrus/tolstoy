# 遣愁

<p class="du-fu-verse">养拙蓬为户，茫茫何所开？<br />江通神女馆<sup class="footnote-ref" id="note-ref-du-fu-0884-1"><a href="#note-du-fu-0884-1">〔一〕</a></sup>，地隔望乡台。<br />渐惜容颜老，无由弟妹来。<br />兵戈与人事，回首一悲哀。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0884-1"><span class="footnote-number">〔一〕</span>神女馆：《寰宇记》：巫山。盛弘之《荆州记》曰：沿峡二十里有新崩滩，至巫峡，因山为名也。神女庙在峡之岸。《方舆胜览》：在巫山县西北二百五十步，有阳云台。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0884-1" aria-label="返回正文">↩</a></span></p>

# 耳聋

<p class="du-fu-verse">生年鹖冠子<sup class="footnote-ref" id="note-ref-du-fu-0890-1"><a href="#note-du-fu-0890-1">〔一〕</a></sup>，叹世鹿皮翁。<br />眼复几时暗，耳从前月聋。<br />猿鸣秋泪垂，雀噪晚愁空。<br />黄落惊山树，呼儿问朔风。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0890-1"><span class="footnote-number">〔一〕</span>鹖冠：刘向《七略》：鹖冠子常居深山，以鹖为冠，故号鹖冠子。虞般佑《高士传》：鹖冠子，或曰楚人，隐居幽山，衣弊履穿，以鹖为冠，莫测其名，因服成号。著书言道家事，冯暖常师事之。暖后显于赵，鹖冠子惧其荐己也，乃与暖绝。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0890-1" aria-label="返回正文">↩</a></span></p>

# 独坐二首

## 其一

<p class="du-fu-verse">竟日雨冥冥，双崖洗更青<small class="du-fu-variant">一作清。</small>水花寒落岸，山鸟暮过庭。<br />暖老须燕玉<sup class="footnote-ref" id="note-ref-du-fu-0891-1"><a href="#note-du-fu-0891-1">〔一〕</a></sup>，充饥忆楚萍。<br />胡笳在楼上，哀怨不堪听。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0891-1"><span class="footnote-number">〔一〕</span>燕玉：赵傁曰：燕玉，妇人也。《古诗》：燕赵多佳人，美者颜如玉。宋人仍袭，多用燕玉，实不知其何出。顾大韶曰：燕玉，正用玉田种玉事也。按《搜神记》：雍伯葬父母于无终山，有人与石一斗，令种之，玉生其田。北平徐氏有女，雍伯求之，要以白璧一双。伯至玉田，求得五双，徐氏妻之。在北平城西北百三十里，有无终城，故燕地也，今为玉田县。燕玉事出此无疑。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0891-1" aria-label="返回正文">↩</a></span></p>

## 其二

<p class="du-fu-verse">白狗斜临北<sup class="footnote-ref" id="note-ref-du-fu-0891-2"><a href="#note-du-fu-0891-2">〔一〕</a></sup>，黄牛更在东。<br />峡云常照夜，江月会兼风。<br />晒药安垂老，应门试小童。<br />亦知行不逮，苦恨耳多聋。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0891-2"><span class="footnote-number">〔一〕</span>白狗：《水经注》：乡口溪，源出归乡县东南数百里。西北入县，经狗峡西。峡崖龛中，石隐起有狗形，形状具足，故以狗名峡。《舆地纪胜》：白狗峡，在秭归县东三十里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0891-2" aria-label="返回正文">↩</a></span></p>

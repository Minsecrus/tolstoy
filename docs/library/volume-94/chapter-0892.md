# 远游

<p class="du-fu-verse">江阔浮高栋<small class="du-fu-variant">晋作冻，</small>云长出断山。<br />尘沙连越嶲，风雨暗荆蛮。<br />雁矫衔芦内<sup class="footnote-ref" id="note-ref-du-fu-0892-1"><a href="#note-du-fu-0892-1">〔一〕</a></sup>，猿啼失木间<sup class="footnote-ref" id="note-ref-du-fu-0892-2"><a href="#note-du-fu-0892-2">〔二〕</a></sup>。<br />弊裘苏季子，历国未知还。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0892-1"><span class="footnote-number">〔一〕</span>衔芦：《淮南子》：雁从风飞，以爱气力。衔芦而翔，以避弋缴。盛弘之《荆州记》：雁塞东南，岭属无际，唯一处为下。朔雁达塞，矫翼裁度。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0892-1" aria-label="返回正文">↩</a></span></p>

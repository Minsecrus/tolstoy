# 八月十五夜月二首

## 其一

<p class="du-fu-verse">满目飞明镜，归心折大刀<sup class="footnote-ref" id="note-ref-du-fu-0906-1"><a href="#note-du-fu-0906-1">〔一〕</a></sup>。<br />转蓬行地远，攀桂仰天高。<br />水路疑霜雪，林栖见羽毛。<br />此时瞻白兔，直欲数秋毫。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0906-1"><span class="footnote-number">〔一〕</span>大刀：《乐府解题》：大刀头者，刀头有环也。“何当大刀头”者，何日当还也。破镜者，月半缺也。“破镜飞上天”者，言月半当还也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0906-1" aria-label="返回正文">↩</a></span></p>

## 其二

<p class="du-fu-verse">稍下巫山峡，犹衔白帝城。<br />气沉全浦暗，轮仄半楼明。<br />刁斗皆催晓，蟾蜍且自倾<small class="du-fu-variant">一作清。</small>张弓倚残魄，不独汉家营。</p>

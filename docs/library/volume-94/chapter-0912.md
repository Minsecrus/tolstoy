# 暝

<p class="du-fu-verse">日下四山阴，山庭岚气侵。<br />牛羊归径险，鸟雀聚枝深。<br />正枕当星剑<sup class="footnote-ref" id="note-ref-du-fu-0912-1"><a href="#note-du-fu-0912-1">〔一〕</a></sup>，收书动玉琴<sup class="footnote-ref" id="note-ref-du-fu-0912-2"><a href="#note-du-fu-0912-2">〔二〕</a></sup>。<br />半扉开烛影，欲掩见清砧。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0912-1"><span class="footnote-number">〔一〕</span>星剑：吴曾《漫录》：《越绝书》：观其文，如列星之行；观其光，如水溢于塘。故曰星剑。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0912-1" aria-label="返回正文">↩</a></span></p>

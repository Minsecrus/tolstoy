# 朝二首

## 其一

<p class="du-fu-verse">清旭楚宫南，霜空万岭含。<br />野人时独往，云木晓相参。<br />俊鹘无声过，饥乌下食贪。<br />病身终不动，摇落任江潭。</p>

## 其二

<p class="du-fu-verse">浦帆晨初发，郊扉冷未开。<br />村<small class="du-fu-variant">一作林</small>疏黄叶坠，野静白鸥来。<br />础润休全湿<sup class="footnote-ref" id="note-ref-du-fu-0923-1"><a href="#note-du-fu-0923-1">〔一〕</a></sup>，云晴欲半回。<br />巫山冬可怪，昨夜有奔雷。</p>

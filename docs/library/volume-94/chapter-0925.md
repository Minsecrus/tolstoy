# 夜二首

## 其一

<p class="du-fu-verse">白夜月休弦，灯花半委<small class="du-fu-variant">一作委半</small>眠。<br />号山无定鹿，落树有惊蝉。<br />暂忆江东鲙，兼怀雪下船。<br />蛮歌犯星起，空<small class="du-fu-variant">一作重</small>觉在天边。</p>

## 其二

<p class="du-fu-verse">城郭悲笳暮，村墟过翼稀。<br />甲兵年数久，赋敛夜深归。<br />暗树依岩落，明河绕塞微。<br />斗斜人更望，月细鹊休飞。</p>

# 又示宗武

<p class="du-fu-verse">觅句新知律，摊书解满床。<br />试吟青玉案，莫羡<small class="du-fu-variant">陈作带</small>紫罗囊<sup class="footnote-ref" id="note-ref-du-fu-0927-1"><a href="#note-du-fu-0927-1">〔一〕</a></sup>。<br />假<small class="du-fu-variant">古雅切</small>日从时饮<sup class="footnote-ref" id="note-ref-du-fu-0927-2"><a href="#note-du-fu-0927-2">〔二〕</a></sup>，明年共我长。<br />应须饱经术，已似爱文章。<br />十五男儿志，三千弟子行。<br />曾参与游夏，达者得升堂。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0927-1"><span class="footnote-number">〔一〕</span>紫囊：《晋志》：八坐尚书荷紫。以生紫为袷囊，缀之服外，加于左肩。昔周公负成王，制此服，至今以为朝服。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0927-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0927-2"><span class="footnote-number">〔二〕</span>假日：《登楼赋》：聊假日以销忧。贾逵《国语注》曰：暇，闲也。暇或作“假”。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0927-2" aria-label="返回正文">↩</a></span></p>

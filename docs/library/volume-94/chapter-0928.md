# 熟食日示宗文宗武

<p class="du-fu-verse">消渴游江汉，羁栖尚甲兵。<br />几年逢熟食，万里逼清明。<br />松柏邛<small class="du-fu-variant">一作邙</small>山路<sup class="footnote-ref" id="note-ref-du-fu-0928-1"><a href="#note-du-fu-0928-1">〔一〕</a></sup>，风花白帝城。<br />汝曹催我老，回首泪纵横。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0928-1"><span class="footnote-number">〔一〕</span>邛山：《元和郡国志》：邛州南接邛来山，因以为名。《十道志》：邙山，在偃师县北二里。子美先茔在洛，故有是句。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0928-1" aria-label="返回正文">↩</a></span></p>

# 十月一日

<p class="du-fu-verse">有瘴非全歇，为冬亦不<small class="du-fu-variant">吴作不亦</small>难。<br />夜郎溪日暖<sup class="footnote-ref" id="note-ref-du-fu-0934-1"><a href="#note-du-fu-0934-1">〔一〕</a></sup>，白帝峡风寒。<br />蒸裹如千室<sup class="footnote-ref" id="note-ref-du-fu-0934-2"><a href="#note-du-fu-0934-2">〔二〕</a></sup>，焦糟<small class="du-fu-variant">一作糖</small>幸一柈。<br />兹辰南国重，旧俗自相欢。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0934-1"><span class="footnote-number">〔一〕</span>夜郎：《水经注》：温水出牂牁夜郎县，县故夜郎侯国也。《前书》：夜郎县有遯水，东至广郁。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0934-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0934-2"><span class="footnote-number">〔二〕</span>蒸裹：《齐民要术》：裹蒸生鱼，方七寸准，又云五寸准，豉汁煮秫米如蒸熊。生姜、橘皮、胡芹、小蒜、盐细切熬糁，膏油涂箬，十字裹之。糁在上，复以糁屈牖纂之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0934-2" aria-label="返回正文">↩</a></span></p>

# 忆郑南玭<sup class="footnote-ref" id="note-ref-du-fu-0939-1"><a href="#note-du-fu-0939-1">〔一〕</a></sup>

<p class="du-fu-verse">郑南伏毒寺<small class="du-fu-variant">一作守，</small>潇洒到江心。<br />石影衔珠阁，泉声带玉琴。<br />风杉曾曙倚，云峤忆春临。<br />万里沧浪<small class="du-fu-variant">陈作苍茫</small>外，龙蛇只自深。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0939-1"><span class="footnote-number">〔一〕</span>郑南：寺名伏毒，在华州郑南县。刘禹锡《别集》云：舅氏牧华州，前后由华觐谒，陪登伏毒寺，曾题诗于梁。今典冯翊，南望三峰，浩然生思。寄诗云：“曾作关中客，频经伏毒岩。晴烟沙苑树，晚日渭川帆。”玭：吴若本注：玭疑作玼，音泚，玉色鲜洁也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0939-1" aria-label="返回正文">↩</a></span></p>

# 喜观即到复题短篇二首

## 其一

<p class="du-fu-verse">巫峡千山暗，终南万里春。<br />病中吾见弟，书到汝为人。<br />意<small class="du-fu-variant">一作竟</small>答儿童问，来经战伐新。<br />泊船悲喜后，款款话<small class="du-fu-variant">一作议</small>归秦。</p>

## 其二

<p class="du-fu-verse">待尔嗔乌鹊<sup class="footnote-ref" id="note-ref-du-fu-0949-1"><a href="#note-du-fu-0949-1">〔一〕</a></sup>，抛书示鹡鸰。<br />枝间喜不去，原上急曾经。<br />江阁嫌津柳，风帆数驿亭。<br />应论十年事，愁<small class="du-fu-variant">一作捻</small>绝始星星。</p>

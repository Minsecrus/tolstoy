# 第五弟丰独在江左近三四载寂无消息觅使寄此二首

## 其一

<p class="du-fu-verse">乱后嗟吾在，羁栖见汝难。<br />草黄骐骥病，沙晚<small class="du-fu-variant">一作暖</small>鹡鸰寒。<br />楚设关城险，吴吞水府宽。<br />十年朝夕泪，衣袖不曾干。</p>

## 其二

<p class="du-fu-verse">闻汝依山寺，杭州定越州。<br />风尘淹别日，江汉失<small class="du-fu-variant">一作共</small>清秋。<br />影著啼猿树<sup class="footnote-ref" id="note-ref-du-fu-0951-1"><a href="#note-du-fu-0951-1">〔一〕</a></sup>，魂飘结蜃楼<sup class="footnote-ref" id="note-ref-du-fu-0951-2"><a href="#note-du-fu-0951-2">〔二〕</a></sup>。<br />明年下春水，东尽白云求<small class="du-fu-variant">一作游。</small></p>

# 江雨有怀郑典设

<p class="du-fu-verse">春雨暗暗塞<small class="du-fu-variant">一作发</small>峡中，早晚来自楚王宫。<br />乱波分披已打岸，弱云狼藉不禁风。<br />宠光蕙叶与多碧，点注桃花舒小红。<br />谷口子真正忆汝，岸高瀼滑<small class="du-fu-variant">一作阔</small>限西东。</p>

张璁曰：夔有涧水，横通山谷间，谓之瀼。时公又自赤甲迁居瀼西，则郑居瀼东也。

# 陪柏中丞观宴将士二首

## 其一

<p class="du-fu-verse">极乐三军士，谁知百战场。<br />无私齐绮馔，久坐密金章。<br />醉客沾鹦鹉<sup class="footnote-ref" id="note-ref-du-fu-0956-1"><a href="#note-du-fu-0956-1">〔一〕</a></sup>，佳人指凤凰。<br />几时来翠节，特地引红妆。</p>

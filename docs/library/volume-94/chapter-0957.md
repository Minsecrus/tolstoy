# 七月一日题终明府水楼二首

## 其一

<p class="du-fu-verse">高栋曾轩已自凉，秋风此日洒衣裳。<br />翛然欲下阴山雪，不去非无汉署香。<br />绝壁过云开锦绣，疏松夹水奏笙簧。<br />看君宜着王乔履，真赐还疑出尚方。<br /><small class="du-fu-variant">终明府，功曹也，兼摄奉节令，故有此句。伫观奏，即真也。</small></p>

## 其二

<p class="du-fu-verse">宓子弹琴邑宰日，终军弃繻英妙时。<br />承家节操尚不泯，为政风流今在兹。<br />可怜宾客尽倾盖，何处老翁来赋诗。<br />楚江巫峡半云雨，清簟疏帘看奕棋。</p>

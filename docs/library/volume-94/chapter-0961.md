# 孟仓曹步趾领新酒酱二物满器见遗老夫

<p class="du-fu-verse">楚岸通秋屐，胡床面夕畦。<br />藉糟分汁滓<sup class="footnote-ref" id="note-ref-du-fu-0961-1"><a href="#note-du-fu-0961-1">〔一〕</a></sup>，瓮酱落提携。<br />饭粝添香味，朋来有醉泥。<br />理生那免俗，方法报山妻。</p>

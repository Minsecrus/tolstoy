# 柳司马至

<p class="du-fu-verse">有使归三峡，相过问两京。<br />函关犹出将，渭水更屯兵。<br />设备邯郸道，和亲逻些城<sup class="footnote-ref" id="note-ref-du-fu-0962-1"><a href="#note-du-fu-0962-1">〔一〕</a></sup>。<br />幽燕唯鸟去，商洛少人行。<br />衰谢身何补，萧条病转婴。<br />霜天到宫阙，恋主寸心明。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0962-1"><span class="footnote-number">〔一〕</span>逻些城：《旧书·吐蕃传》：其人或随畜牧而不常厥居，然颇有城郭。其国都城，号为逻些城。《新书》：吐蕃有逻娑川。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0962-1" aria-label="返回正文">↩</a></span></p>

鹤曰：大历二年九月十月，京师以吐蕃入寇两戒严。故作此诗。

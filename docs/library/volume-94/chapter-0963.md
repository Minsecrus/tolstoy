# 简吴郎司法

<p class="du-fu-verse">有客乘舸自忠州，遣骑安置瀼西头<sup class="footnote-ref" id="note-ref-du-fu-0963-1"><a href="#note-du-fu-0963-1">〔一〕</a></sup>。<br />古堂本买藉疏豁，借汝迁居停宴游。<br />云石荧荧高叶曙<small class="du-fu-variant">一作晓，</small>风江飒飒乱帆秋。<br />却为姻娅过逢地，许坐曾轩数散愁。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0963-1"><span class="footnote-number">〔一〕</span>瀼西：时公又移居东屯，故以瀼西草堂借吴郎也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0963-1" aria-label="返回正文">↩</a></span></p>

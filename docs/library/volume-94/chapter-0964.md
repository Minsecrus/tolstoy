# 又呈吴郎

<p class="du-fu-verse">堂前扑枣任西邻<sup class="footnote-ref" id="note-ref-du-fu-0964-1"><a href="#note-du-fu-0964-1">〔一〕</a></sup>，无食无儿一妇人。<br />不为困穷宁有此，只缘恐惧转须亲。<br />即防<small class="du-fu-variant">一作知</small>远客虽多事，使<small class="du-fu-variant">一作便</small>插疏篱却甚真。<br />已诉征求贫到骨，正思戎马泪盈巾。</p>

# 送李八秘书赴杜相公幕

<p class="du-fu-verse">青帘白舫益州来，巫峡秋涛天地回。<br />石出倒听枫叶下<small class="du-fu-variant">滟滪堆，</small>橹摇皆<small class="du-fu-variant">一作背</small>指菊花开。<br />贪趋相府今晨发，恐失佳期后命催。<br />南极一星朝北斗，五云多处是三台。</p>

张璁曰：公有《赠李秘书别》诗曰：幕府筹频问，山家药正锄。自注：秘书比卧青城山中。详此，则鸿渐平崔旰，必资其谋。至入朝，表用之也。

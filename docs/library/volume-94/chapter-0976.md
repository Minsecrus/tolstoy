# 季夏送乡弟韶陪黄门从叔朝谒

<p class="du-fu-verse">令弟尚为苍水使，名家莫出杜陵人。<br />比来相国兼安蜀，归赴朝廷已入秦。<br />舍舟策马论兵地，拖玉腰金报主身。<br />莫度清秋吟蟋蟀<sup class="footnote-ref" id="note-ref-du-fu-0976-1"><a href="#note-du-fu-0976-1">〔一〕</a></sup>，早闻黄阁画骐<img class="du-fu-glyph" src="/library/volume-94/images/glyph-6119d107ae79286a27e0.jpg" alt="原书用字" style="width: 1.000em" />。</p>

杜鸿渐以大历二年六月入朝。

<p class="footnote-definition footnote-source" id="note-du-fu-0976-1"><span class="footnote-number">〔一〕</span>蟋蟀：潘岳《秋兴赋》：蟋蟀鸣于轩屏。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0976-1" aria-label="返回正文">↩</a></span></p>

张璁曰：“舍舟策马”，言蜀地用兵，水陆不得并进也。自注：韶比兼开江使，通成都外江下峡舟船。

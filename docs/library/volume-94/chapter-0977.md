# 送十五弟侍御使蜀

<p class="du-fu-verse">喜弟文章进，添余别兴牵。<br />数杯巫峡酒，百丈内江船<sup class="footnote-ref" id="note-ref-du-fu-0977-1"><a href="#note-du-fu-0977-1">〔一〕</a></sup>。<br />未息豺狼斗，空催犬马年。<br />归朝多便道，搏击望秋天。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0977-1"><span class="footnote-number">〔一〕</span>内江：《舆地广记》：涪州内江，即黔江也。昔司马错溯此水南上击楚，夺黔中地。又李膺《益州记》云：内江至关头滩。滩长百步，悬崖倒水，舟楫莫通。《方舆纪胜》：《九域志》引《水经》云：即延江文津也。杜诗注云：水自渝上合州者，谓之内江。自渝由戎泸上蜀者，谓之外江。与此不同。按内江即黔江，地志甚明，杜注不足据。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0977-1" aria-label="返回正文">↩</a></span></p>

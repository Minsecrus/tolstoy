# 送田四弟将军将夔州柏中丞命起居江陵节度阳城郡王卫公幕

<small class="du-fu-variant">一云夔府送田将军赴江陵</small>

<p class="du-fu-verse">离筵罢多酒，起地发寒塘。<br />回首中丞座，驰笺异姓王。<br />燕辞枫树日，雁度麦城霜<sup class="footnote-ref" id="note-ref-du-fu-0978-1"><a href="#note-du-fu-0978-1">〔一〕</a></sup>。<br />空<small class="du-fu-variant">晋作定</small>醉山翁酒，遥怜似葛强。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0978-1"><span class="footnote-number">〔一〕</span>麦城：《水经注》：沮水又东经驴城西，磨城东，又南经麦城西。盛弘之《荆州记》：麦城东有驴城，沮水之西有磨城，犄角麦城。子胥造此二城，以攻麦城。俗谚云：东驴西磨麦自破。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0978-1" aria-label="返回正文">↩</a></span></p>

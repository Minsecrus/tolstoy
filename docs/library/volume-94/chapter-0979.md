# 送王十六判官

<p class="du-fu-verse">客下荆南尽，君今复入舟。<br />买薪犹白帝，鸣橹少<small class="du-fu-variant">一作已</small>沙头<sup class="footnote-ref" id="note-ref-du-fu-0979-1"><a href="#note-du-fu-0979-1">〔一〕</a></sup>。<br />衡霍生春早，潇湘共海浮。<br />荒林庾信宅<sup class="footnote-ref" id="note-ref-du-fu-0979-2"><a href="#note-du-fu-0979-2">〔二〕</a></sup>，为仗主人留。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0979-1"><span class="footnote-number">〔一〕</span>沙头：吴若本注：江陵吴船至，泊于郭外沙头。《入蜀记》：过白湖抛江，至升子铺，日入泊沙市。自公安至此六十里，自此至荆南，陆行十里，舟不复进矣。老杜云：“买薪犹白帝，鸣橹已沙头。”又刘梦得云：“沙头樯干上，始见春江阔。”皆谓此也。《方舆胜览》：沙头市至江陵城十五里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0979-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0979-2"><span class="footnote-number">〔二〕</span>庾信宅：《寰宇记》：罗含宅，在江陵城西三里。庾信亦尝居之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0979-2" aria-label="返回正文">↩</a></span></p>

# 送鲜于万州迁巴州

<p class="du-fu-verse">京兆先时杰，琳琅照一门<sup class="footnote-ref" id="note-ref-du-fu-0981-1"><a href="#note-du-fu-0981-1">〔一〕</a></sup>。<br />朝廷偏注意<small class="du-fu-variant">一作玺，</small>接近与名藩。<br />祖帐排<small class="du-fu-variant">陈作维</small>舟数，寒江触石喧。<br />看君妙为政，他日有殊恩。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0981-1"><span class="footnote-number">〔一〕</span>琳琅：颜鲁公《鲜于仲通神道碑》：仲通子六人，叔曰万州刺史，炅雅有父风，颇精吏道，作牧万州，政绩尤异。有诏迁秘书少监，寻又改牧巴州。仲通一门，并见《赠鲜于京兆》诗注。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0981-1" aria-label="返回正文">↩</a></span></p>

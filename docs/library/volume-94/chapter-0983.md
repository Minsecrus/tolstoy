# 奉寄李十五秘书二首

<small class="du-fu-variant">文嶷</small>

## 其一

<p class="du-fu-verse">避暑云安县，秋风早下来。<br />暂留<small class="du-fu-variant">刊作之</small>鱼复浦，同过楚王台。<br />猿鸟千崖窄，江湖万里开。<br />竹枝歌未好<sup class="footnote-ref" id="note-ref-du-fu-0983-1"><a href="#note-du-fu-0983-1">〔一〕</a></sup>，画舸莫<small class="du-fu-variant">陈作且</small>迟<small class="du-fu-variant">一作轻</small>回。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0983-1"><span class="footnote-number">〔一〕</span>竹枝：《竹枝》本出于巴渝，唐贞元中，刘禹锡在沅湘，以俚歌鄙陋，乃依骚人《九歌》，作《竹枝新歌》。禹锡曰：竹枝，巴渝也。巴儿联歌，吹短笛击鼓以赴节。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0983-1" aria-label="返回正文">↩</a></span></p>

## 其二

# 送李功曹之荆州充郑侍御判官重赠

<p class="du-fu-verse">曾闻宋玉宅<sup class="footnote-ref" id="note-ref-du-fu-0985-1"><a href="#note-du-fu-0985-1">〔一〕</a></sup>，每欲到荆州。<br />此地生涯晚，遥悲<small class="du-fu-variant">一作通</small>水国秋。<br />孤城一柱观，落日九江流。<br />使者虽光彩，青枫远自愁。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0985-1"><span class="footnote-number">〔一〕</span>宋玉宅：《水经注》：宜城城南有宋玉宅。玉，邑人，隽才辩给，善属文而识音也。《西溪丛语》：唐余知古《渚宫故事》曰：庾信因侯景之乱，自建康遁归江陵，居宋玉故宅。宅在城北三里。故其赋曰：“诛茅宋玉之宅，穿径临江之府。”老杜云：“曾闻宋玉宅。”李义山亦云“可怜留着临江宅，异代应教庾信居”是也。然子美《移居夔州入宅》诗云：“宋玉归州宅。”又有“江山故宅”之咏，盖归州亦有宋玉宅也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0985-1" aria-label="返回正文">↩</a></span></p>

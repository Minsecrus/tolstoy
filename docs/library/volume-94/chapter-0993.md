# 吹笛

<p class="du-fu-verse">吹笛秋山风<small class="du-fu-variant">一云风山</small>月清，谁家巧作断肠声。<br />风飘律吕相和切，月傍<small class="du-fu-variant">《草堂》作倚</small>关山几处明。<br />胡骑中宵堪北走<sup class="footnote-ref" id="note-ref-du-fu-0993-1"><a href="#note-du-fu-0993-1">〔一〕</a></sup>，武陵一曲想南征<sup class="footnote-ref" id="note-ref-du-fu-0993-2"><a href="#note-du-fu-0993-2">〔二〕</a></sup>。<br />故园杨柳今摇<small class="du-fu-variant">一作摧，一作花</small>落<sup class="footnote-ref" id="note-ref-du-fu-0993-3"><a href="#note-du-fu-0993-3">〔三〕</a></sup>，何得愁中曲<small class="du-fu-variant">王原叔得甫诗稿，曲作却</small>尽生。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0993-1"><span class="footnote-number">〔一〕</span>胡骑：《世说》：刘越石为胡骑所围数重，城中窘迫无计。越石始夕乘月登楼清啸，胡贼闻之，皆凄然长叹。中夜奏胡笳，贼皆流涕，人有怀土之苦。向晓又吹之，贼并弃围奔走。陈宏让《长笛吐清气》诗：胡骑争北归，偏知别乡苦。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0993-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0993-2"><span class="footnote-number">〔二〕</span>武陵：《古今注》：《武溪深》，乃马援南征之所作也。援门生爰寄生善吹笛，援作歌以和之，名曰《武溪深》。陈贺衡《长笛吐清气》诗：方知出塞胡，不惮武陵深。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0993-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0993-3"><span class="footnote-number">〔三〕</span>杨柳：《唐书·乐志》：梁乐府有《胡吹歌》云：“上马不捉鞭，反抝杨柳枝。下马吹横笛，愁杀行客儿。”此歌词元出北国，即鼓角横吹笛《折杨柳》是也。《演繁露》：笛亦有《落梅》《折柳》二曲，今其词亡，不可考矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0993-3" aria-label="返回正文">↩</a></span></p>

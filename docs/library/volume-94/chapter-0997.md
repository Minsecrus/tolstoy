# 黄鱼

<p class="du-fu-verse">日见巴东峡，黄鱼出浪新。<br />脂膏兼饲犬<sup class="footnote-ref" id="note-ref-du-fu-0997-1"><a href="#note-du-fu-0997-1">〔一〕</a></sup>，长大不容身<sup class="footnote-ref" id="note-ref-du-fu-0997-2"><a href="#note-du-fu-0997-2">〔二〕</a></sup>。<br />筒桶<small class="du-fu-variant">一作䇶</small>相沿久，风雷肯为神<small class="du-fu-variant">一作伸。</small>泥沙卷涎沫，回首怪龙鳞。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0997-1"><span class="footnote-number">〔一〕</span>饲犬：《论衡》：彭蠡之滨，以鱼食犬。《盐铁论》：江陵之人，以鱼饲犬。韩诗：饲犬验今朝。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0997-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-0997-2"><span class="footnote-number">〔二〕</span>长大：《尔雅》注：鳣大者，长二三丈，今江东呼为黄鱼。陆机云：大者千余斤，可蒸为臛，又可为鲊，鱼子可为酱。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0997-2" aria-label="返回正文">↩</a></span></p>

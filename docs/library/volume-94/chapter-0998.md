# 白小

<p class="du-fu-verse">白小群分命，天然二寸鱼。<br />细微沾水族，风俗当园蔬<sup class="footnote-ref" id="note-ref-du-fu-0998-1"><a href="#note-du-fu-0998-1">〔一〕</a></sup>。<br />入肆银花乱，倾箱雪片虚。<br />生成犹拾<small class="du-fu-variant">一作舍</small>卵<sup class="footnote-ref" id="note-ref-du-fu-0998-2"><a href="#note-du-fu-0998-2">〔二〕</a></sup>，尽取义何如。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-0998-1"><span class="footnote-number">〔一〕</span>园蔬：《宾退录》：《靖州图经》载其俗，居丧，不食酒肉盐酪，而以鱼为蔬。今湖北多然，谓之鱼菜。老杜尝往来荆楚，而夔亦与湖北为邻。“风俗当园蔬”，正指此也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-0998-1" aria-label="返回正文">↩</a></span></p>

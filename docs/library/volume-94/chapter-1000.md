# 鸡

<p class="du-fu-verse">纪德名标五<sup class="footnote-ref" id="note-ref-du-fu-1000-1"><a href="#note-du-fu-1000-1">〔一〕</a></sup>，初鸣度必三。<br />殊方听有异，失次晓无惭。<br />问俗人情似，充庖尔辈堪。<br />气交亭育际<sup class="footnote-ref" id="note-ref-du-fu-1000-2"><a href="#note-du-fu-1000-2">〔二〕</a></sup>，巫峡漏司南。</p>

# 奉送蜀州柏二别驾将中丞命赴江陵起居卫尚书太夫人因示从弟行军司马佐

<p class="du-fu-verse">中丞问俗画熊频<sup class="footnote-ref" id="note-ref-du-fu-1024-1"><a href="#note-du-fu-1024-1">〔一〕</a></sup>，爱弟传书彩鹢新。<br />迁转五州防御使<sup class="footnote-ref" id="note-ref-du-fu-1024-2"><a href="#note-du-fu-1024-2">〔二〕</a></sup>，起居八座太夫人<sup class="footnote-ref" id="note-ref-du-fu-1024-3"><a href="#note-du-fu-1024-3">〔三〕</a></sup>。<br />楚宫腊送荆门水，白帝云偷碧海春。<br />报与惠连诗不惜，知吾斑鬓总如银。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1024-1"><span class="footnote-number">〔一〕</span>画熊：《后汉·舆服志》：公列侯车，倚鹿，伏熊，黑轓。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1024-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1024-2"><span class="footnote-number">〔二〕</span>五州：鹤曰：贞观十四年，夔州为都督府。督归、夔、忠、万、涪、渝、南七州。至德元载，于云安置七州防御使。诗云“五州”，误也。按《方镇表》，广德二年，置涪忠夔都防御使，治夔州。原领夔、峡、忠、归、万五州。故曰“五州”也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1024-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1024-3"><span class="footnote-number">〔三〕</span>八座：唐以六尚书、左右仆射合为八座。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1024-3" aria-label="返回正文">↩</a></span></p>

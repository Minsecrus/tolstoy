# 多病执热奉怀李尚书

<small class="du-fu-variant">之芳</small>

<p class="du-fu-verse">衰年正苦病侵凌，首夏何须气郁蒸。<br />大水淼茫炎海接，奇峰硉兀火云升。<br />思沾道暍黄梅雨，敢望宫恩玉井冰<sup class="footnote-ref" id="note-ref-du-fu-1029-1"><a href="#note-du-fu-1029-1">〔一〕</a></sup>。<br />不是尚书期不顾，山阴野雪兴难乘。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1029-1"><span class="footnote-number">〔一〕</span>玉井：鱼豢《魏略》：明帝九龙殿前为玉井绮栏。《水经注》：华林园疏圃中，有古玉井，井悉以珉玉为之，以锱石为口，工作精密，犹不变古，璨焉如新。《东京赋》：于南则有<img class="du-fu-glyph" src="/library/volume-94/images/glyph-fbbae16bed1c85795ec2.jpg" alt="原书用字" style="width: 1.000em" />门曲榭。注：<img class="du-fu-glyph" src="/library/volume-94/images/glyph-06cace00e83f78fc1bee.jpg" alt="原书用字" style="width: 1.000em" />门冰室门也，门内有宣阳冰室。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1029-1" aria-label="返回正文">↩</a></span></p>

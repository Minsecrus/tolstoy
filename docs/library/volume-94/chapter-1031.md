# 奉贺阳城郡王太夫人恩命加邓国太夫人

<small class="du-fu-variant">阳城郡王，卫伯玉也。</small>

<p class="du-fu-verse">卫幕衔恩重，潘舆送喜频。<br />济时瞻上将，锡号戴慈亲。<br />富贵当如此，尊荣迈等伦。<br />郡依封土旧，国与大名新。<br />紫诰鸾回纸，清朝燕贺人。<br />远传冬笋味，更觉彩衣春。<br />奕叶班姑史，芬芳孟母邻。<br />义方兼有训，词翰两如神。<br />委曲承颜体，骞飞报主身。<br />可怜忠与孝，双美画骐<img class="du-fu-glyph" src="/library/volume-94/images/glyph-8e1c5a2c206d05debc85.jpg" alt="原书用字" style="width: 1.100em" />。</p>

鹤曰：《旧书》：大历初，伯玉丁母忧，朝廷以王昴代其任。讽将士请留，遂起复再任。则此诗当作于伯玉封王，母同受封之时。大约是大历元年前作。按《通鉴》：伯玉丁母忧，是大历五年。

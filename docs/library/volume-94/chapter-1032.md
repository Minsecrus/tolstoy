# 江陵望幸

<p class="du-fu-verse">雄都元壮丽，望幸歘威神。<br />地利西通蜀，天文北照秦。<br />风烟含越鸟，舟楫控吴人。<br />未枉周王驾，终期汉武巡。<br />甲兵分圣旨，居守付宗臣。<br />早发云台杖<small class="du-fu-variant">刊作路，</small>恩波起涸鳞。</p>

肃宗上元元年九月，置南都于荆州，以为江陵府。改吕<img class="du-fu-glyph" src="/library/volume-94/images/glyph-b3efaf2ae03783752e08.jpg" alt="原书用字" style="width: 1.100em" />为尹，二年罢都，是年建卯月，又诏为南都，寻罢。《吕<img class="du-fu-glyph" src="/library/volume-94/images/glyph-5a127c2c5b9bdb59b0df.jpg" alt="原书用字" style="width: 1.000em" />传》：建请荆州置南都，于是更号江陵府。以<img class="du-fu-glyph" src="/library/volume-94/images/glyph-0b3af6b3631e9c84c0d3.jpg" alt="原书用字" style="width: 1.100em" />为尹，置永平军万人，以遏吴蜀之冲。广德元年冬，乘舆幸陕。以伯玉有干略，可当重寄，乃拜江陵尹兼御史大夫，充荆南节度观察等使。

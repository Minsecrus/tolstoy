# 舟中

<p class="du-fu-verse">风餐江柳下，雨卧驿楼边。<br />结缆排鱼网，连樯并米船。<br />今朝云细薄，昨夜月清圆。<br />飘泊南庭老，只应学水仙<sup class="footnote-ref" id="note-ref-du-fu-1035-1"><a href="#note-du-fu-1035-1">〔一〕</a></sup>。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1035-1"><span class="footnote-number">〔一〕</span>水仙：《侯鲭录·清泠传》曰：冯夷，华阴潼乡堤畔人也。服八石得水仙，是为河伯。一云以八月庚子浴于南河溺死，出《庄子·大宗师》第六卷义注中。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1035-1" aria-label="返回正文">↩</a></span></p>

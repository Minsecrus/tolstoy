# 公安送韦二少府匡赞

<p class="du-fu-verse">逍遥公后世多贤<sup class="footnote-ref" id="note-ref-du-fu-1049-1"><a href="#note-du-fu-1049-1">〔一〕</a></sup>，送尔维舟惜此筵。<br />念我能书<small class="du-fu-variant">一作常能</small>数字至，将诗不必万人传。<br />时危兵甲黄尘里，日短江湖白发前。<br />古往今来皆涕泪，断肠分手各风烟。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1049-1"><span class="footnote-number">〔一〕</span>逍遥公：《宰相世系表》：韦夐，字敬远，后周逍遥公，号逍遥公房。至嗣立，更号小逍遥公房。张说《东山记》：皇帝幸韦公东山之别业，是日即席拜公逍遥公。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1049-1" aria-label="返回正文">↩</a></span></p>

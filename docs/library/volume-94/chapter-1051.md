# 公安县怀古

<p class="du-fu-verse">野旷吕蒙营<sup class="footnote-ref" id="note-ref-du-fu-1051-1"><a href="#note-du-fu-1051-1">〔一〕</a></sup>，江深刘备城<sup class="footnote-ref" id="note-ref-du-fu-1051-2"><a href="#note-du-fu-1051-2">〔二〕</a></sup>。<br />寒天催日短，风浪与云平。<br />洒落君臣契，飞腾战伐名。<br />维舟倚前浦，长啸一含情。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1051-1"><span class="footnote-number">〔一〕</span>吕蒙营：《寰宇记》：公安县有孱陵城。《十三州志》曰：吴大帝封吕蒙为孱陵侯，此地也。《入蜀记》：光孝寺后有废城，仿佛尚存。《图经》谓之吕蒙城。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1051-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1051-2"><span class="footnote-number">〔二〕</span>刘备城：《荆州记》云：刘备败于襄阳，南奔荆州，吴大帝推为左将军、荆州牧，镇油口，即居此城。时人号备为左公，故名其城公安也。《水经注》：刘备之奔江陵，使筑而镇之。曹公闻孙权以荆州借备，临书落笔。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1051-2" aria-label="返回正文">↩</a></span></p>

# 宴王使君宅题二首

## 其一

<p class="du-fu-verse">汉主追韩信，苍生起谢安。<br />吾徒自漂泊，世事各艰难。<br />逆旅招邀近，他乡思<small class="du-fu-variant">《英华》作意</small>绪宽。<br />不才甘朽质，高卧岂泥蟠。</p>

## 其二

<p class="du-fu-verse">泛爱容霜发<small class="du-fu-variant">一作髩，</small>留欢卜夜闲<small class="du-fu-variant">一云上夜关</small><sup class="footnote-ref" id="note-ref-du-fu-1053-1"><a href="#note-du-fu-1053-1">〔一〕</a></sup>。<br />自吟诗送老，相劝酒开颜。<br />戎马今何地，乡园独旧山<small class="du-fu-variant">旧山一作在山。</small>江湖堕清月，酩酊任扶还。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1053-1"><span class="footnote-number">〔一〕</span>夜关：《英华辩证》：世传杜子美不避家讳，两押“闲”字，其实非也。或改作“夜阑”，又不在韵。按《卞圜集》：杜诗自是“留欢上夜关”，盖有投辖之意。上字讹为“卜”，关字讹为“闲”耳。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1053-1" aria-label="返回正文">↩</a></span></p>

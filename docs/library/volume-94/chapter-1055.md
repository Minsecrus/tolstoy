# 晓发公安

<small class="du-fu-variant">数月憩息此县</small>

<p class="du-fu-verse">北城击柝复欲罢，东方明星亦不迟。<br />邻鸡野哭如昨日，物色生态<small class="du-fu-variant">一云生生</small>能几时。<br />舟楫眇然自此去，江湖远适无前期。<br />出门转眄已陈迹，药饵扶吾随所之。</p>

《入蜀记》：公《移居公安》诗云：“水烟通径草，秋露接园葵。”而《留别太易沙门》云：“沙村白雪仍含冻，江县红梅已放春。”则以是秋至此县，暮冬始去。其曰“数月憩息”，盖谓此也。

# 登岳阳楼<sup class="footnote-ref" id="note-ref-du-fu-1058-1"><a href="#note-du-fu-1058-1">〔一〕</a></sup>

<p class="du-fu-verse">昔闻洞庭水，今上岳阳楼。<br />吴楚东南坼，乾坤日夜浮。<br />亲朋无一字，老病有孤舟。<br />戎马关山北，凭轩涕泗流。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1058-1"><span class="footnote-number">〔一〕</span>岳阳楼：《岳阳风土记》：岳阳楼，城西门楼也。《方舆胜览》：岳阳楼，在郡治西南。西面洞庭，左顾君山，不知创始。开元四年，张说出守是邦，与才士登临赋咏，自尔名著。方回曰：予登岳阳楼，左序球门壁间，大书孟诗，右书杜诗，后人不敢复题也。刘长卿云：“叠浪浮元气，中流没太阳。”世不甚传，他可知也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1058-1" aria-label="返回正文">↩</a></span></p>

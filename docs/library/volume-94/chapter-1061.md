# 宿青草湖

<p class="du-fu-verse">洞庭犹在目，青草续为名<sup class="footnote-ref" id="note-ref-du-fu-1061-1"><a href="#note-du-fu-1061-1">〔一〕</a></sup>。<br />宿桨依农事，邮签报水程。<br />寒冰争倚薄，云月递微明。<br />湖雁双双起，人来故北征。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1061-1"><span class="footnote-number">〔一〕</span>青草：《荆州记》：巴陵南有青草湖，周回百里，日月出没其中。湖南有青草山，故因以为名。青草湖，一名洞庭湖，洞庭亦谓之太湖。《南迁录》：洞庭西岸有沙洲，堆阜隆起。即青草庙下，一湖之中有此洲。南名青草，北名洞庭，所谓重湖也。《水经注》：湘水自汨口西北径垒石山西，而北对青草湖，亦或谓之青草山也。《元和郡国志》：巴丘湖，又名青草湖。在巴陵县南七十九里，周回二百六十五里，俗云即古云梦泽也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1061-1" aria-label="返回正文">↩</a></span></p>

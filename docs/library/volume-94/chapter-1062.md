# 宿白沙驿

<small class="du-fu-variant">初过湖南五里</small>

<p class="du-fu-verse">水宿仍余照，人烟复此亭。<br />驿边沙旧白<sup class="footnote-ref" id="note-ref-du-fu-1062-1"><a href="#note-du-fu-1062-1">〔一〕</a></sup>，湖外草新青。<br />万象皆春气，孤槎自客星。<br />随波无限月<small class="du-fu-variant">一作景，</small>的的近南溟。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1062-1"><span class="footnote-number">〔一〕</span>白沙：《水经注》：潇者，水清深也。《湘中记》曰：湘川清照五六丈，下见底石如樗蒱矣。五色鲜明，白沙如霜雪，赤崖如朝霞，是纳潇湘之名矣。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1062-1" aria-label="返回正文">↩</a></span></p>

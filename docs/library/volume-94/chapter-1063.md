# 湘夫人祠

<p class="du-fu-verse">肃肃湘妃庙，空墙碧水春。<br />虫书玉佩藓，燕舞翠帷尘。<br />晚泊登汀树，微馨借<small class="du-fu-variant">一作香惜</small>渚<img class="du-fu-glyph" src="/library/volume-94/images/glyph-6871a3ab56b7baa8630b.jpg" alt="原书用字" style="width: 1.000em" />。<br />苍梧恨不尽，染泪在丛筠。</p>

《方舆胜览》：黄陵庙，在湘阴北八十里。玉逸注《楚辞》以湘君为水神，湘夫人乃二妃也。郭璞曰：天帝之二女，而处江为神。江湘之有夫人，犹河洛之有虙妃也。礼：五岳比三公，四渎比诸侯，今湘川不及四渎，无秩于命祀。而二女帝者之后，配灵神祗，无缘当复下降小水而为夫人也。韩退之《黄陵庙碑》则以娥皇为湘君，女英为湘夫人，后世宗之。公此诗题曰《湘夫人祠》，盖本王逸之说也。

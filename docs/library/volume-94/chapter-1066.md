# 归雁

<p class="du-fu-verse">闻道今春雁，南归自广州<sup class="footnote-ref" id="note-ref-du-fu-1066-1"><a href="#note-du-fu-1066-1">〔一〕</a></sup>。<br />见花辞涨海<sup class="footnote-ref" id="note-ref-du-fu-1066-2"><a href="#note-du-fu-1066-2">〔二〕</a></sup>，避雪到罗浮。<br />是物关兵气，何时免客愁。<br />年年霜露隔，不过五湖秋。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1066-1"><span class="footnote-number">〔一〕</span>广州：《唐会要》：大历二年，岭南节度使徐浩奏：十一月二十五日，当管怀集县阳雁来，乞编入史。从之。先是五岭之外，翔雁不到，浩以为阳为君德，雁随阳者，臣归君之象也。史称浩贪而妄，公诗盖深讥之。谢灵运《山居赋》：“海鸟违风，朔禽避凉。”注：朔禽，雁也，寒月转往衡阳。卢思道《孤鸿赋序》：《淮南子》曰：东归碣石，违溽暑也。平子《赋》云：南翔衡阳，避祁寒也。《地志》：衡山一阳峰极高，雁不能过。遇春北归，故名回雁。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1066-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1066-2"><span class="footnote-number">〔二〕</span>涨海：谢承《书》：交趾七郡贡献，皆从涨海出入。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1066-2" aria-label="返回正文">↩</a></span></p>

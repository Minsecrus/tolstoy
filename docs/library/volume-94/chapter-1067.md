# 野望

<p class="du-fu-verse">纳纳乾坤大，行行郡国遥。<br />云山兼五岭<sup class="footnote-ref" id="note-ref-du-fu-1067-1"><a href="#note-du-fu-1067-1">〔一〕</a></sup>，风壤带三苗<sup class="footnote-ref" id="note-ref-du-fu-1067-2"><a href="#note-du-fu-1067-2">〔二〕</a></sup>。<br />野树侵江阔，春蒲长雪消。<br />扁舟空老去，无补圣明朝。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1067-1"><span class="footnote-number">〔一〕</span>五岭：《元和郡国志》：晋怀帝分荆州、湘中诸郡，置湘州，南以五岭为限，北以洞庭为界。隋平陈，改潭州，取昭潭为名也。裴渊《广州记》：五岭云大庾、始安、临贺、桂阳、揭阳。师古曰：岭者，西自衡山之南，东穷于海，一山之限耳，而别标名则有五焉。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1067-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1067-2"><span class="footnote-number">〔二〕</span>三苗：《书疏》传曰：三苗之国，左洞庭，右彭蠡，其国在南方。《水经注》：洞庭湖右岸有山，世谓之苗乌头石。石北右会翁湖口水，上承翁湖，左合洞浦，所谓三苗之国，左洞庭者也。《潭州图经》云：三苗国之南境。《元和郡国志》：岳州，古三苗之国也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1067-2" aria-label="返回正文">↩</a></span></p>

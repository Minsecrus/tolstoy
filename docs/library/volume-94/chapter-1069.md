# 铜官渚守风<sup class="footnote-ref" id="note-ref-du-fu-1069-1"><a href="#note-du-fu-1069-1">〔一〕</a></sup>

<p class="du-fu-verse">不<small class="du-fu-variant">樊作亦</small>夜楚帆落，避风湘渚间。<br />水耕先浸草<sup class="footnote-ref" id="note-ref-du-fu-1069-2"><a href="#note-du-fu-1069-2">〔二〕</a></sup>，春火更烧山。<br />早泊云物晦，逆行波浪悭。<br />飞来双白鹤，过去杳难攀。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1069-1"><span class="footnote-number">〔一〕</span>铜官：《水经注》：湘水右岸，铜官浦出焉。湘水又北经铜官山，西临湘水，山土紫色，内含云母，故亦谓之云母山也。湘水又左合决湖口水，出西陂，东通湘渚。《方舆胜览》：铜官渚，在宁乡县界三十里。《旧志》：楚铸钱处。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1069-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1069-2"><span class="footnote-number">〔二〕</span>水耕：《汉武诏》：江南之地，火耕水耨。应劭曰：烧草下水种稻，草与稻俱生，高七八寸，因悉芟去，复下水灌之，草死稻独长，所谓火耕水耨也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1069-2" aria-label="返回正文">↩</a></span></p>

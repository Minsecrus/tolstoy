# 潭州送韦员外牧韶州迢

<p class="du-fu-verse">炎海韶州牧，风流汉署郎。<br />分符先令望，同舍有辉光。<br />白首多年疾，秋天昨夜凉。<br />洞庭无过雁，书疏莫相忘。</p>

韩文《韦氏夫人墓志铭》：其大王父迢，以都官郎为岭南军司马，卒赠同州刺史。

# 重送刘十弟判官

<p class="du-fu-verse">分源豕韦派<sup class="footnote-ref" id="note-ref-du-fu-1083-1"><a href="#note-du-fu-1083-1">〔一〕</a></sup>，别浦雁宾秋。<br />年事推兄忝，人才觉弟优。<br />经过辨酆剑，意气逐吴钩。<br />垂翅徒衰老，先鞭不滞留。<br />本枝凌岁晚，高义豁穷愁。<br />他日临江待，长沙旧驿楼。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1083-1"><span class="footnote-number">〔一〕</span>豕韦：赵曰：言刘、杜同出也。《左传》：范宣子曰：在夏为御龙氏，在商为豕韦氏，在周为唐杜氏。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1083-1" aria-label="返回正文">↩</a></span></p>

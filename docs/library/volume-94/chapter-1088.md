# 哭李常侍峄二首

## 其一

<p class="du-fu-verse">一代风流尽，修文地下深。<br />斯人不重见，将老失知音。<br />短日行梅岭，寒山<small class="du-fu-variant">一作江</small>落桂林。<br />长安若个畔，犹想映貂金。</p>

## 其二

<p class="du-fu-verse">青琐陪双入，铜梁阻一辞。<br />风尘逢我地，江汉哭君时。<br />次第寻书札，呼儿检赠诗。<br />发挥王子表，不愧史臣词。</p>

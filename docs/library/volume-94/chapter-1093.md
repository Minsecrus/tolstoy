# 冬晚送长孙渐舍人归州

<p class="du-fu-verse">参卿休坐幄，荡子不还乡。<br />南容潇湘外，西戎鄠杜旁。<br />衰年倾盖晚，费日系舟长。<br />会面思来札，销魂逐去樯。<br />云晴鸥更舞，风逆雁无行。<br />匣里雌雄剑，吹毛任选将。</p>

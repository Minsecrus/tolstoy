# 奉赠萧二十使君

<p class="du-fu-verse">昔在严公幕，俱为蜀使臣。<br />艰危参大府，前后间清尘。<br /><small class="du-fu-variant">严再领成都，余复参幕府。</small>起草鸣先路，乘槎动要津。<br />王凫聊暂出，萧雉只相驯<sup class="footnote-ref" id="note-ref-du-fu-1096-1"><a href="#note-du-fu-1096-1">〔一〕</a></sup>。<br />终始任安义，荒芜孟母邻。<br />联翩匍匐礼，意气死生亲。<br /><small class="du-fu-variant">严公没后，老母在堂，使君温凊之问，甘脆之礼，名数若己之庭闱焉。太夫人顷逝，丧事又首诸孙主典，抚孤之情，不减骨肉，则胶漆之契可知矣。</small>张老存家事<sup class="footnote-ref" id="note-ref-du-fu-1096-2"><a href="#note-du-fu-1096-2">〔二〕</a></sup>，嵇康有故人。<br />食恩惭卤莽，镂骨抱酸辛。<br />巢许山林志，夔龙廊庙珍。<br />鹏图仍矫翼，熊轼且移轮。<br />磊落衣冠地，苍茫土木身。<br />埙篪鸣自合，金石莹逾新。<br />重忆罗江外，同游锦水滨。<br />结欢随过隙，怀旧益沾巾。<br />旷绝含香舍，稽留伏枕辰。<br />停骖双阙早，回雁五湖春。<br />不达长卿病，从来原宪贫。<br />监河受贷粟，一起辙中鳞。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1096-1"><span class="footnote-number">〔一〕</span>萧雉：萧广济《孝子传》：萧芝至孝，除尚书郎。有雉数十头，饮啄宿止，当上直，送至岐路，下直入门，飞鸣车侧。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1096-1" aria-label="返回正文">↩</a></span></p>

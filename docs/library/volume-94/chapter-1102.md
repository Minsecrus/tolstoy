# 归雁二首

## 其一

<p class="du-fu-verse">万里衡阳雁，今年又北归。<br />双双瞻客上，一一背人飞。<br />云里相呼疾，沙边自宿稀。<br />系书元<small class="du-fu-variant">一作无</small>浪语，愁寂故山薇。</p>

## 其二

<p class="du-fu-verse">欲雪违胡地，先花别楚云。<br />却过清渭影，高起洞庭群。<br />塞北春阴暮，江南日色曛。<br />伤弓流落羽，行断不堪闻。</p>

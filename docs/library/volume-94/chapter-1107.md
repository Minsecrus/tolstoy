# 赠韦七赞善

<p class="du-fu-verse">乡里衣冠不乏贤，杜陵韦曲未央前。<br />尔家最近魁三象，<small class="du-fu-variant">斗魁下两两相比为三台。</small>时论同归<small class="du-fu-variant">一云因侵</small>尺五天。<br /><small class="du-fu-variant">俚语云：城南韦杜，去天尺五。</small>北走关山<small class="du-fu-variant">一作河</small>开雨雪，南游花柳塞云<small class="du-fu-variant">一作风</small>烟。<br />洞庭春色悲公子<sup class="footnote-ref" id="note-ref-du-fu-1107-1"><a href="#note-du-fu-1107-1">〔一〕</a></sup>，虾菜忘归范蠡船。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1107-1"><span class="footnote-number">〔一〕</span>洞庭：此谓楚之洞庭也。陶朱中男杀人，囚于楚。张华曰：陶朱公冢在南郡华容县西，故知非吴之洞庭也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1107-1" aria-label="返回正文">↩</a></span></p>

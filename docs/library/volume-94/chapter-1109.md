# 杜员外兄垂示诗因作此寄上

郭受

<p class="du-fu-verse">新诗海内流传遍，旧德朝中属望劳。<br />郡邑地卑饶雾雨，江湖天阔足风涛。<br />松醪酒熟旁看醉<sup class="footnote-ref" id="note-ref-du-fu-1109-1"><a href="#note-du-fu-1109-1">〔一〕</a></sup>，莲叶舟轻自学操。<br />春兴不知凡几首，衡阳纸价顿能高<sup class="footnote-ref" id="note-ref-du-fu-1109-2"><a href="#note-du-fu-1109-2">〔二〕</a></sup>。</p>

《唐诗纪事》：受大历间为衡阳判官。

<p class="footnote-definition footnote-source" id="note-du-fu-1109-1"><span class="footnote-number">〔一〕</span>松醪：裴硎《传奇》：酒名松醪春。《原化记》：有松花酒。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1109-1" aria-label="返回正文">↩</a></span></p>

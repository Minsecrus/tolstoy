# 酬郭十五判官

<p class="du-fu-verse">才微岁老尚虚名，卧病江湖春复生。<br />药里关心诗总废，花枝照眼句还成<sup class="footnote-ref" id="note-ref-du-fu-1110-1"><a href="#note-du-fu-1110-1">〔一〕</a></sup>。<br />只同燕石能星陨，自得隋珠觉夜明。<br />乔口橘洲风浪促，系帆何惜片时程。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1110-1"><span class="footnote-number">〔一〕</span>花枝：吴曾《漫录》：梁武帝《春歌》曰：“阶上香入怀，庭中花照眼。春心一如此，情来不自限。”乃悟子美“花枝照眼”之句。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1110-1" aria-label="返回正文">↩</a></span></p>

# 哭长孙侍御

<p class="du-fu-verse">道为谋<small class="du-fu-variant">一作谏，一作诗</small>书重，名因赋颂雄。<br />礼闱曾擢桂，宪府旧<small class="du-fu-variant">一作近</small>乘骢。<br />流水生涯尽，浮云世事空。<br />唯余旧台柏，萧瑟九原中。</p>

《文苑辩证》云：杜诵《哭长孙侍御》诗，今载《杜甫集》中。按《中兴间气集》《又玄集》《唐宋类诗》，皆云杜诵。高仲武当唐中兴肃宗时编《间气集》，载诵诗止此一首。又云：杜君诗平调不失，如“流水生涯尽，浮云世事空”，得生人始终之理，故编之。必不误。近卞圜注杜诗，亦载此篇，虽云或以为杜诵作，然不明辩也。

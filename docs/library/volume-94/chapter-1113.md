# 虢国夫人

<p class="du-fu-verse">虢国夫人承主恩，平明上马入宫<small class="du-fu-variant">祜集作金</small>门。<br />却嫌脂粉涴颜色，淡扫蛾眉朝至尊。</p>

见《张祜集》，作《集灵台》二首。《万首唐人绝句》亦作张祜。《杨妃外传》：有姊三人，皆丰硕修整，工于谑浪。每入宫中，移晷方出。虢国不施妆粉，自衒美艳，常素面朝天。当时杜甫有诗云云。

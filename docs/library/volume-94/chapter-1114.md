# 军中醉饮寄沈八刘叟

<p class="du-fu-verse">酒渴爱江清，余甘<small class="du-fu-variant">一作酣</small>漱晚汀。<br />软沙欹坐稳，冷石醉眠醒。<br />野膳随行帐，华音发从伶。<br />数杯君不见，醉<small class="du-fu-variant">一作都</small>已遣沉冥。</p>

《英华辩证》：其有可疑及当两存者，如畅当此诗，及司空曙《杜鹃行》，今并载《杜甫集》。潘淳《诗话补遗》：唐顾陶集《诗选》二十卷，载畅当《军中醉歌寄沈八刘叟》诗。山谷顷在蜀道，见古石刻，有唐人请以老杜“酒渴爱江清”为韵，人各赋一诗。

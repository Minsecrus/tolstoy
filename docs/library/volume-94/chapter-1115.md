# 杜鹃行

<small class="du-fu-variant">见陈浩然本，亦见黄鹤本。</small>

<p class="du-fu-verse">古时杜宇称望帝，魂作杜鹃何微细。<br />跳枝窜叶树木中，抢佯<small class="du-fu-variant">《英华》作翔</small>瞥捩雌随雄。<br />毛衣惨黑貌<small class="du-fu-variant">一作自</small>憔悴。<br />众鸟安肯相尊崇。<br />隳<small class="du-fu-variant">《英华》作陋</small>形不敢栖华屋，短翮唯愿巢深丛。<br />穿皮啄朽觜欲秃，苦饥始得食一虫。<br />谁言养雏不自哺，此语亦足为愚蒙。<br />声音咽咽如有谓<small class="du-fu-variant">《英华》作咽哕若有谓，注云咽平声，</small>号啼略与婴儿同。<br />口干垂血转迫促，似欲<small class="du-fu-variant">《英华》作欲以</small>上诉于苍穹。<br />蜀人闻之皆起立，至今<img class="du-fu-glyph" src="/library/volume-94/images/glyph-f2fdc6ffdbdc417ec957.jpg" alt="原书用字" style="width: 1.000em" />学传遗风<small class="du-fu-variant">《英华》作相效传遗风。</small>乃知变化不可穷，岂知昔日居深宫，嫔嫱<small class="du-fu-variant">一作妃</small>左右如花红。</p>

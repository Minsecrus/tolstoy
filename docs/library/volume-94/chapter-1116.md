# 闻惠二过东溪特一送

<p class="du-fu-verse">惠子白驹<small class="du-fu-variant">一作鱼，坡作驴</small>瘦，归溪惟病身。<br />皇天无老眼，空谷滞<small class="du-fu-variant">一作值</small>斯人。<br />崖蜜松花熟<small class="du-fu-variant">一作白，一作古，</small>山杯<small class="du-fu-variant">一作村醪</small>竹叶新。<br />柴门了无<small class="du-fu-variant">一作生</small>事，黄<small class="du-fu-variant">一作园</small>绮未称臣。</p>

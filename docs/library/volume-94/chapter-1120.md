# 绝句九首

<small class="du-fu-variant">前六首在十三卷中</small>

<p class="du-fu-verse">闻道巴山里，春船正好行。<br />都将百年兴，一望九江城。<br /><small class="du-fu-variant">《草堂》本云：行，赵作还；城，赵作山。</small></p>

<p class="du-fu-verse">水槛温江口，茅堂石笋西。<br />移船先主庙，洗药浣沙<small class="du-fu-variant">《草堂》作花</small>溪。</p>

<p class="du-fu-verse">设<small class="du-fu-variant">一作谩</small>道春来好，狂风大放颠。<br />吹<small class="du-fu-variant">一作飞</small>花随水去，翻却钓鱼船。</p>

右谢克家任伯题云：右五诗，得盛文肃家故书中，犹是吴越钱氏时人所传，格律高妙，其为少陵不疑。<small class="du-fu-variant">《诗说隽永》：晁氏尝于中壶缄线纩夹中，得吴越人写本杜诗。讳“流</small>”<small class="du-fu-variant">字之类，乃盛文肃故书也。如“日出篱东水</small>”<small class="du-fu-variant">等绝句六首，乃九首。其一云“漫道春来好</small>”<small class="du-fu-variant">云云。</small>

# 惜别行送刘仆射判官

<small class="du-fu-variant">见陈浩然本，又见《英华》。</small>

<p class="du-fu-verse">闻道南行市骏马，不限匹数军<small class="du-fu-variant">一作官</small>中须。<br />襄阳幕府天下异，主将俭省忧艰虞。<br />只收壮健胜铁甲，岂因格斗求龙驹。<br />而今西北自反胡，骐<img class="du-fu-glyph" src="/library/volume-94/images/glyph-6880e16924e6b2393927.jpg" alt="原书用字" style="width: 1.050em" />荡尽一匹无。<br />龙媒真种在帝都，子孙永落西南隅。<br />向非戎事备征伐，君肯辛苦越江湖。<br />江湖凡马多憔悴，衣冠往往乘蹇驴。<br />梁公富贵于身疏，号令明白人安居。<br />俸钱时散士子尽，府库不为骄豪虚。<br />以兹报主寸心赤，气却西戎回北狄。<br />罗网群马籍<small class="du-fu-variant">一作鸟藉</small>马多，气在<small class="du-fu-variant">一作用</small>驱驰出金帛。<br />刘侯奉使光推择，滔滔才略沧溟窄。<br />杜陵老翁秋系船，扶病相识长沙驿。<br />强梳白发提胡卢，手把<small class="du-fu-variant">一作兼</small>菊花路旁摘。<br />九州兵革浩茫茫，三叹聚散临重阳。<br />当杯对客忍流涕<small class="du-fu-variant">一作涕泪，</small>君<small class="du-fu-variant">一无此字</small>不觉老夫神内伤。</p>

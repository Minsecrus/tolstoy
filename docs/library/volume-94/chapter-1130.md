# 巴西驿亭观江涨呈窦使君二首

## 其一

<p class="du-fu-verse">转惊波作怒，即恐岸随流。<br />赖有杯中物，还同海上鸥。<br />关心小剡县，傍眼见扬州。<br />为接情人饮，朝来减半<small class="du-fu-variant">一作片</small>愁。</p>

## 其二

<p class="du-fu-verse">向晚波微<small class="du-fu-variant">一作犹</small>绿，连空岸脚青。<br />日兼春有暮，愁与醉无醒。<br />漂泊犹杯酒，踌躇此驿亭。<br />相看万里外，同是一浮萍。</p>

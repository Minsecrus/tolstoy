# 遣忧

<p class="du-fu-verse">乱离知又甚，消息苦难真。<br />受谏无今日<sup class="footnote-ref" id="note-ref-du-fu-1131-1"><a href="#note-du-fu-1131-1">〔一〕</a></sup>，临危忆古人<small class="du-fu-variant">顾作伤故臣</small><sup class="footnote-ref" id="note-ref-du-fu-1131-2"><a href="#note-du-fu-1131-2">〔二〕</a></sup>。<br />纷纷乘白马，攘攘着黄巾。<br />隋氏留<small class="du-fu-variant">顾作营</small>宫室，焚烧何太频。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1131-1"><span class="footnote-number">〔一〕</span>受谏：谓代宗还京，太常博士柳伉上疏切谏也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1131-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1131-2"><span class="footnote-number">〔二〕</span>临危：至德初，上皇在蜀，思九龄之先觉，下诏褒赠，遣使就韶州致祭。《剧谈录》：明皇幸蜀，妃子既死。一日登高山，望秦川，谓高力士曰：“吾取张九龄言，不至于此！”遣使祭之，吹笛为曲，号《谪仙怨》。公不斥言而曰古人，其词婉矣。吴曾《漫录》：唐顾陶大中丙子岁编《唐诗类选》，载此诗，世所传杜集皆无之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1131-2" aria-label="返回正文">↩</a></span></p>

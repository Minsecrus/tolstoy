# 愁坐

<p class="du-fu-verse">高斋常见野，愁坐更临门。<br />十月山寒重，孤城月水昏。<br />葭萌氐种迥<sup class="footnote-ref" id="note-ref-du-fu-1147-1"><a href="#note-du-fu-1147-1">〔一〕</a></sup>，左担犬戎存<sup class="footnote-ref" id="note-ref-du-fu-1147-2"><a href="#note-du-fu-1147-2">〔二〕</a></sup><small class="du-fu-variant">一作屯。</small>终日忧奔走，归期未敢论。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1147-1"><span class="footnote-number">〔一〕</span>葭萌：《十道志》曰：利州益昌郡，土地所属，与文州同。春秋战国时并属蜀汉葭萌县地。《华阳国志》曰：昔蜀王封其弟于汉中，号曰苴侯，因命其地曰葭萌。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1147-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1147-2"><span class="footnote-number">〔二〕</span>左担：任豫《益州记》：江由左担道，按图在阴平县北，于成都为西。其道至险，自北来者，担在左肩，不得度担也。邓艾束马悬车之处。《华阳国志》：<img class="du-fu-glyph" src="/library/volume-94/images/glyph-eb236ee154279205eaab.jpg" alt="原书用字" style="width: 1.000em" />降贾子，左担七里。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1147-2" aria-label="返回正文">↩</a></span></p>

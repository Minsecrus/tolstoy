# 为补遗荐岑参状

宣议郎试大理评事摄监察御史赐绯鱼袋岑参。右臣等，窃见岑参，识度清远，议论雅正，佳名早立，时辈所仰。今谏诤之路大开，献替之官未备。恭惟近侍，实藉茂材。臣等谨诣阁门，奉状陈荐以闻。伏听进止。

至德二载六月十二日，左拾遗内供奉臣裴荐等状。

右拾遗内供奉臣孟昌浩。

右拾遗内供奉臣魏齐聃。

左拾遗内供奉臣杜甫。

左补阙臣韦少游。

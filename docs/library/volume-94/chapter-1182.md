# 祭远祖当阳君文

维开元二十九年，岁次辛巳，月日。十三叶孙甫，谨以寒食之奠，敢昭告于先祖晋驸马都尉镇南大将军当阳成侯之灵。初陶唐出自伊祁，圣人之后，世食旧德。降及武库<sup class="footnote-ref" id="note-ref-du-fu-1182-1"><a href="#note-du-fu-1182-1">〔一〕</a></sup>，应乎虬精<sup class="footnote-ref" id="note-ref-du-fu-1182-2"><a href="#note-du-fu-1182-2">〔二〕</a></sup>。恭闻渊深，罕得窥测。勇功是立，智名克彰。缮甲江陵，祲清东吴。建侯于荆，邦于南土。河水活活，造舟为梁<sup class="footnote-ref" id="note-ref-du-fu-1182-3"><a href="#note-du-fu-1182-3">〔三〕</a></sup>。洪涛莽汜，未始腾毒。《春秋》主解<sup class="footnote-ref" id="note-ref-du-fu-1182-4"><a href="#note-du-fu-1182-4">〔四〕</a></sup>，稿隶躬亲。呜呼笔迹，流宕何人。苍苍孤坟<sup class="footnote-ref" id="note-ref-du-fu-1182-5"><a href="#note-du-fu-1182-5">〔五〕</a></sup>，独出高顶。静思骨肉，悲愤心胸。峻极于天，神有所降。不毛之地，俭乃孔昭。取象邢山，全模祭仲。多藏之诫，焯序前文。小子筑室，首阳之下。不敢忘本，不敢违仁。庶刻丰石，树此大道。论次昭穆，载扬显号。于以采蘩，于彼中园。谁其尸之，有齐列孙。呜呼！敢告兹辰，以永薄祭。尚飨。

<p class="footnote-definition footnote-source" id="note-du-fu-1182-1"><span class="footnote-number">〔一〕</span>武库：《晋书》：预在内七年，损益万机，朝野称美，号杜武库。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1182-1" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1182-2"><span class="footnote-number">〔二〕</span>虬精：《晋书》：预在荆州，因宴集，醉卧斋中。外人闻呕吐声，窃窥于户，正见一大蛇垂头而吐，闻者异之。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1182-2" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1182-3"><span class="footnote-number">〔三〕</span>造舟：《水经注》：孟津亦曰盟津，又曰富平津。晋阳秋，杜预造桥于富平津，所谓造舟为梁也，又谓之曰陶河。《晋书》：预以孟津渡时有覆没之患，请建河桥于富平津。桥成，帝从百僚临会，举觞属预曰：非君，此桥不立也。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1182-3" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1182-4"><span class="footnote-number">〔四〕</span>春秋：《晋书》：预耽思牍籍，为《春秋左氏经传集解》，又参考众家谱第，谓之《释例》。挚虞赞之曰：左丘明本为《春秋》作传，而《左传》遂自孤行；《释例》本为《传》设，而所发明何但《左传》，故亦孤行。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1182-4" aria-label="返回正文">↩</a></span></p>

<p class="footnote-definition footnote-source" id="note-du-fu-1182-5"><span class="footnote-number">〔五〕</span>孤坟：《水经注》：密县陉山上有郑祭仲墓，冢西有子产墓，累石为方坟，坟东有庙，并东北向郑城。杜元凯言不忘本。《晋书》：预先为遗令曰：“吾去春入朝，自表营洛阳城东首阳之南为将来兆域，开隧道南向，仪制取法于郑大夫，欲以俭自完耳。棺器小敛之事，皆当称此。”子孙一以遵之。陉山，《晋书》作邢山。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1182-5" aria-label="返回正文">↩</a></span></p>

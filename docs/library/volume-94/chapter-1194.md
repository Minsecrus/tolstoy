# 诸家诗话引言

宋人方惟道兄弟，纂录唐宋以来评杜诗者，号曰“诸家老杜诗评”。蔡梦弼《草堂诗话》一卷，悉摭《韵语阳秋》之类，尤为猥杂，今删补而存之。

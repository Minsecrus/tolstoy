# 《唐本事诗》二事

李白才逸气高，与陈拾遗齐名，先后合德，其论诗云：“梁、陈已来，艳薄斯极，沈休文又尚以声律，将复古道，非我而谁欤？”故陈、李二集律诗殊少，尝言：“寄兴深微，五言不如四言，七言又其靡也，况使束于声调俳优哉？”故戏杜曰：“饭颗山头逢杜甫，<small class="du-fu-variant">《唐摭言》作“长乐坡前逢杜甫”。</small>头戴笠子日卓午。借问别来<small class="du-fu-variant">别一作“新”</small>太瘦生，总为从前作诗苦。”盖讥其拘束也。<small class="du-fu-variant">“太瘦生”，唐人语也，至今犹以生为语助，如“作么生”“何似生”之类。</small>

白常出入宫中，恩礼殊厚，竟以疏纵乞归，上亦以非廊庙器，优诏罢遣之。后以不羁，流落江外，又以永王招礼，累谪于夜郎，及放还，卒于宣城。杜所赠《二十韵》，备叙其事，读其文，尽得其故迹。杜逢禄山之难，流离陇、蜀，毕陈于诗，推见至隐，殆无遗事，故当时号为“诗史”。

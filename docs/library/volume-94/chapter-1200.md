# 司马温公《迂叟诗话》一事

“牂羊坟首，三星在罶”，言不可久。古人为诗，贵于意在言外，使人思而得之。近世诗人，惟杜子美最得诗人之体，如“国破山河在”，明无余物矣；“城春草木深”，明无人矣。花鸟平时可娱之物，见之而泣，闻之而恐，则时可知矣。他皆类此，不可遍举。

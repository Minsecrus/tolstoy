# 蔡约之《西清诗话》一事

诗之声律，至唐始成，然亦多原六朝旨意。而造语工夫，各有微妙。何逊《入西塞诗》：“薄云岩际出，初月波中上。”至少陵《江边小阁》则云：“薄云岩际宿，孤月浪中翻。”虽因旧而益妍，类獭髓补痕也。

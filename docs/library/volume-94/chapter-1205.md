# 王彦辅《麈史》一事

杜审言诗有“绾雾青条弱，牵风紫蔓长”，又有“寄语洛城风月道，明年春色倍还人”之句。若子美“林花着雨胭脂落，水荇牵风翠带长”，又云“传语风光共流转，暂时相赏莫相违”，虽不袭取其意，而语脉益有家法矣。

# 使南海道长沙

侍御史唐扶

<p class="du-fu-verse">道林岳麓仲与昆，卓荦请从先后论。<br />松根踏雪二千步，始见大屋开三门。<br />泉清或戏蛟龙窟，殿豁数尽高帆掀。<br />即今异鸟声不断，闻道看花春更繁。<br />从容一衲分若有，萧瑟两鬓吾能髡。<br />逢迎侯伯转觉贵，膜拜佛像心加尊。<br />稍揖英皇颒浓泪，试与屈贾招清魂。<br />荒唐大树悉楠桂，细碎小草多兰荪，沙弥去学五印字，静女来悬千尺幡。<br />主人念我尘眼昏，半夜号令期至暾。<br />迟回虽得上白舫，羁绁不敢言绿尊。<br />两祠物色采拾尽，壁间杜甫原少恩。<br />晚来光彩更腾射，笔锋正健如可吞。</p>

《侯鲭录》云：长沙道林岳麓寺，老杜所赋诗者，沈传师有诗碑见于世。其序云“奉酬唐侍御、姚员外道林寺题示”。姚员外诗不复见之，今得唐侍御诗，题云“儒林郎监察御史唐扶”。

# 和

湖南观察使沈传师

<p class="du-fu-verse">承明年老辄自论，乞得湘守东南奔<sup class="footnote-ref" id="note-ref-du-fu-1214-1"><a href="#note-du-fu-1214-1">〔一〕</a></sup>。<br />为闻楚国富山水，青嶂逦迤僧家园。<br />含香珥笔皆耆旧，谦抑自忘台省尊。<br />不令执简候亭馆，直许携手游山樊。<br />忽惊列岫晚来碧，积雪洗尽烟岚昏。<br />碧波回屿三山转，丹槛绕郭千艘屯。<br />华镳蹀躞绚沙步，大旆粲错辉松门。<br />樛枝竞骛龙蛇执，折干不没风霆痕。<br />相重古殿倚岩腹，别引新径萦云根。<br />目伤平楚虞帝魂，情多思远聊开尊。<br />危弦细管逐歌飏，画鼓绣靴随节翻。<br />锵金七言凌老杜，入木八法蟠高轩。<br />嗟予绝倒久不和，忍复感激论元元。</p>

<p class="footnote-definition footnote-source" id="note-du-fu-1214-1"><span class="footnote-number">〔一〕</span>《唐书·沈传师传》：穆宗时召入翰林为学士，改中书舍人。翰林缺承旨，穆宗欲面命，辞曰：“学士、院长参天子密议，次为宰相，臣自知必不能，愿治人一方，为陛下长养之。”因称疾出，为湖南观察使。<span class="footnote-backrefs"><a class="footnote-backref" href="#note-ref-du-fu-1214-1" aria-label="返回正文">↩</a></span></p>

# 第九章

莱妮娜觉得在经过这一天的古怪和恐怖之后，自己应该度一个彻彻底底的假期。他们一回到招待所，她就吃下六片半克的苏摩，躺在自己的床上，十分钟后就来到了永恒的月球世界，至少要过上十八个小时她才会回到现实。

与此同时，伯纳德躺在床上思考着，在漆黑中睁大着眼睛，直到午夜过了很久才睡着，但他的失眠并非没有成果，他制订好了计划。

第二天早上十点钟，那个穿着绿色制服的混血儿准时从直升飞机里走了出来。伯纳德在龙舌兰丛中等候着他。

“克劳恩小姐吃了苏摩正在度假。”他解释说，“五点前不会醒来。我们有七个小时的时间。”

他可以飞去圣达菲，做完所有应该做的事情，然后再回到熔岩区，那时候离她醒来还早着呢。

“留下她一个人在这里安全吗？”

“就像在直升飞机里一样安全。”那个混血儿向他保证。

他们登上飞机，然后立刻起飞。十点三十四分他们在圣达菲邮政大楼的天台着陆。十点三十七分，伯纳德接通了白厅的世界主宰者办公室的电话，与主宰者的第四个人秘书通话。十点四十四分，他将故事向第一秘书复述了一遍，十点四十七分半，他听到主宰者穆斯塔法·蒙德本人深沉而富有磁性的声音在他的耳朵里回荡。

“小的斗胆认为，”伯纳德结结巴巴地说道，“大人或许会觉得这件事情很有科学价值……”

“是的，我确实觉得它很有科学价值。”那个深沉的声音说道。

“你把这两个人带回伦敦吧。”

“启禀主宰大人，您知道，我需要一份特别许可令……”

“有关文件，”穆斯塔法·蒙德说道，“正被送到保留区区长那里去。你可以立刻前往区长的办公室。早安，马克斯先生。”

没有声音了。伯纳德挂上话筒，立刻上了天台。

“去区长的办公室。”他对那个优等伽玛混血儿说道。

十点五十四分，伯纳德与区长握手。

“幸会，马克斯先生，幸会。”他毕恭毕敬地忙不迭说道，“我们刚刚收到特别命令……”

“我知道。”伯纳德打断了他，“刚才我和主宰者阁下通过电话。”他倦怠的语气暗示着他与主宰者通话是家常便饭。他在一张椅子上坐了下来，“请您尽快完成必要的手续，越快越好。”他断然强调，完全自得其乐。

十一点三分，他的口袋里就装进了所有必需的文件。

他盛气凌人地对区长说道：“再会。”区长一直把他送到电梯口。“再会。”

他走到酒店，洗了个澡，做了一个真空振荡按摩和电解质剃须，听了早上的新闻报道，看了半小时的电视，好整以暇地吃了一顿午饭，两点半的时候和那个混血儿飞回了熔岩区。

那个年轻人站在招待所的外面。

“伯纳德。”他喊道，“伯纳德！”没有人应话。

他穿着鹿皮软靴，悄无声息地，跑上台阶敲了敲门。门是锁着的。

他们走了！走了！这是发生在他身上最可怕的事情。他让他来和他们见面，而现在他们却走了。他坐在台阶上，哭了起来。

半个小时后，他才想到隔着窗户看个究竟。他看到的第一件东西是一个绿色的行李箱，盖子上面写着L.C.两个缩写字母。他的心中燃起了快乐的熊熊烈火。他拾起一块石头。碎玻璃叮叮当当掉了一地。没过一会儿他就已经进了房间。他打开那个绿色的行李箱，立刻闻到了莱妮娜的香水的味道，她的存在感填满了他的肺部。他的心怦怦乱跳，差点没晕过去。然后，他弯着腰在这个宝贝箱子里翻寻着，然后拿到光亮处审视。莱妮娜那条备用的粘胶纤维仿天鹅绒短裤上的拉链一开始让他觉得很困惑，然后琢磨出来它是干吗用的，觉得很开心。撕开，然后扣上；然后再撕开，然后再扣上。他玩得着了迷。她的绿色拖鞋是他见过的最美丽的东西。他展开那件两片式拉链内衣，顿时面红耳赤，急忙把它们放到一边。但他亲了亲那条喷了香水的醋酸丝手帕，将一条围巾系在脖子上。打开一个匣子时，他洒出了一大团香粉，手上沾满了粉末。他把粉末抹在胸膛上、肩膀上和赤裸的胳膊上。多么宜人的香味！他闭上眼睛，用沾着香粉的胳膊摩挲着脸颊。光滑的肌肤轻抚着他的脸，鼻孔里充斥着麝香粉的味道——她的存在是那么真实。“莱妮娜，”他低声说道，“莱妮娜！”

一个声音吓了他一跳，他怀着内疚感转过身，把偷出来的东西塞进行李箱里，合上盖子，然后又倾听着动静，张望了一下，没有人的迹象，也没有声音。但刚才他确实听到了声音——像是叹气的声音，又像一块木板发出的咯吱声。他踮着脚尖来到门边，小心翼翼地打开门，发现自己面前是一个宽阔的平台。在平台的对面是另一道门，门是打开着的。他走了出去，推开房门，朝里面窥视。

在一张矮床上，被子被掀了起来，莱妮娜穿着粉红色的一件式拉链睡衣，睡得正香，在如云的卷发映衬下显得如此美丽，粉红色的脚趾甲和她沉睡中的脸庞是如此稚嫩和动人，软绵绵的双手和四肢看上去是那么信任和无助，泪水不禁涌入他的眼眶。

他小心翼翼，但其实根本没有这个必要——因为只有枪声才能在时间到来之前把她从苏摩假期中拉回来——他走进房间，跪在床边的地板上，端详着他，嘴唇翕张着，喃喃说道：

她的眼睛、她的头发、她的面庞、她的步态、她的语调，

你口口声声对我说，一切洁白的东西，

和她的玉手一比，都会变成墨水一样黝黑，

都会自惭形秽；比起她柔荑的一握来，

天鹅的绒毛都会显得粗硬……

一只苍蝇在她身边嗡嗡嗡地飞舞着，他挥手把它赶跑了。“苍蝇，”他想起了这些篇章：

都可以接触亲爱的朱丽叶的皎洁的玉手，

从她的嘴唇上偷取天堂中的幸福，

那两片嘴唇是这样的纯洁贞淑，永远含着娇羞，

好像觉得它们自身的相吻也是一种罪恶。

他伸出手，以非常缓慢的犹豫迟疑的姿势，就像一个人要去抚摸一只害羞而且可能很危险的鸟儿，在几乎就要碰到她那软绵绵的手指，距离只有一英寸的地方停住了，颤抖着。他敢吗？他敢用自己那卑贱的手去亵渎……不，他不敢。这只小鸟太危险了。他的手缩了回去。她太漂亮了！太美丽了！

突然间，他发现自己意识到，只要他将她脖颈处的拉链往下用力一拉……他闭上眼睛，像刚从水里出来的小狗甩耳朵那样用力地甩着自己的头。多么下流可耻的想法！他为自己感到羞愧。她是这样的纯洁贞淑……

空中传来了嗡嗡嗡的声音。又有一只苍蝇想要偷取天堂中的幸福！是一只黄蜂！他看着周围，什么也没有看见。嗡嗡嗡的声音越来越响，听位置是在被打破的玻璃窗外。是飞机！他慌慌张张地站起身跑进另一个房间，从开着的窗口跳了出去，匆忙顺着两边是高大的龙舌兰的小径逃跑时，正好看到了从直升飞机里出来的伯纳德·马克斯。

# 第十四章

公园街临终医院是一座有六十层楼高的黄砖高楼。野人刚下的士直升飞机，一架颜色鲜艳的空中灵车就从天台呼啸起飞，朝西飞过公园，目的地是斯洛火葬场。在电梯的门口，操作员告诉了他需要了解的信息，然后他下到十七楼的第八十一号病房（按照电梯操作员的解释，是一间急症高龄病房）。

房间很宽敞明亮，涂了黄色的油漆，里面有二十张病床，都安置了病人。临终的琳达有人陪伴——不仅有伴，而且还有一切便利的现代设施。房间里一直播放着欢快的合成旋律。在每张病床的脚边，正对着垂死的病人，是一台电视机，从早到晚一直开着。每过一刻钟，房间里的香水味道就会自动变换。在门口接待野人的那位护士解释道：“我们努力在这里创造一个完全愉快的气氛——既是一流的酒店，又是一座感官体验的宫殿，希望你能明白我的意思。”

“她在哪儿？”野人问道，不去理会这些客套的解释。

那位护士很生气。“你着急得很嘛。”她说道。

“还有希望吗？”他问道。

“你是说，她不会死掉？”（他点了点头。）

“不，当然没希望。被送到这儿的人，没有……”看到他苍白的脸上流露出难过的表情，她吓了一跳，脱口而出：“怎么了，到底怎么了？”她问道。探访者出现这种反应令她觉得很不习惯。（反正也不会有很多探访者，有什么理由会有很多探访者呢？）“你不是觉得难受吧？”

他摇了摇头。“她是我的母亲。”他以几乎微不可闻的声音说道。

那位护士用惊恐的眼神瞥了他一眼，然后立刻转移了视线，从喉咙到太阳穴，一下子涨得通红。

“带我去见她。”野人说道，努力想恢复语气的平静。

她仍然面红耳赤，在病房里引路。一路走过，他们看到那些病人的脸仍然很年轻，没有皱纹（因为这里的人老得很慢，没有时间让面部老化——只是心脏和大脑衰竭了）。那些空洞呆板、婴儿一般混混沌沌的目光追随着他们。看着这些人，野人觉得不寒而栗。

琳达躺在那列长长的病床的最后一张上面，旁边靠着墙壁。她靠在枕头上，正在观看床脚的电视机里播放的在南美举行的黎曼曲面网球锦标赛的半决赛，电视调成了静音，里面的小人在方形发光的玻璃里悄无声息地满场飞奔，就像水族箱里的鱼——是另一个世界里的沉默而活跃的居民。

琳达看着电视，露出迷茫的淡淡的微笑，那张苍白浮肿的脸洋溢着白痴般的快乐。时不时地，她合上眼睑，有那么几秒钟的时间，她似乎在打盹，然后又猛地醒过来——醒过来观看水族箱里那些网球冠军滑稽的动作，倾听超级女声伍利策利娅纳唱着“亲爱的，紧紧地抱着我，让我醉去”。闻着从她头顶的通风口散发出来的温暖的马鞭草的香味——醒来时闻到的就是这些气息，或沉浸在血液里的苏摩营造的由美妙的事物构成的梦境中，再一次展现出她那婴儿般满足的支离破碎的没有血色的微笑。

“好了，我必须走了。”护士说道，“我那群小孩子快来了。而且，三号现在随时可能就会去世。”她指着病床。“请自便。”她快步走开了。

野人坐在床边。

“琳达。”他握着她的手，轻声说道。

听到她的名字，琳达转过头。她模糊的眼睛认出了他，闪烁着光芒。她抓住他的手，微笑着，嘴唇翕张着，然后她的头突然往前倾。她睡着了。他坐在床边看着她——透过疲惫的肉体找寻着辨认着那张年轻明艳的脸庞，伴随他度过那在熔岩区的童年，回忆（他闭上了眼睛）着她的声音、她的动作和他们共同生活所发生过的一切。《斯特雷托科克的G到班布里的T》，她的歌声曾经是那么美妙！还有那些幼稚的儿歌，多么陌生和神秘！

A、B、C，维他命D：

肝脏里有脂肪，海里有鳕鱼。

回忆起那些歌词和琳达念叨着这些歌词时的声音，他不禁热泪盈眶。还有阅读课：“猫咪在毯子上，小孩在瓶子里”。还有那本《胚胎仓库贝塔工作者实用指南》。还有夏天在那座小房子的屋顶围着火堆度过的漫长的夜晚，那时候她向他讲述了关于野人保留区外面的异域的故事，那个美丽的奇妙的异域，关于它的回忆，那是神奇的天堂乐土，他仍然是一个完整的个体，没有因为与这座真实的伦敦和这些真实的文明人的接触而被玷污。

突然间，刺耳的声音让他睁开双眼。他立刻抹去眼泪，回头望去。一群似乎无穷无尽的长得一模一样的八岁大的男性多胞胎正拥入房间。多胞胎跟着多胞胎，多胞胎跟着多胞胎，他们来了——就像噩梦一样。他们的面孔，他们那一张张一模一样的面孔——因为这么多张面孔真的只有一个模样——翘着鼻孔，无神的眼睛骨碌碌地盯着他看。他们穿着卡其布的制服，大张着嘴巴，叽叽喳喳地尖叫着交谈着走了进来。没过一会儿，病房里就挤满了蛆虫一样的他们，簇拥在病床之间，爬上爬下，看看电视机，朝病人扮鬼脸。

琳达被他们吓得不轻。有一群孩子簇拥在她的床边，就像突然间遇到未知事物的动物那样惊恐又傻乎乎地好奇地盯着她看。

“噢，看啊，看啊！”他们害怕地低声说道，“她到底怎么了？为什么她那么胖？”

他们从来没有见过像她那样的脸庞——从未见过一张不是年轻紧绷的脸庞或一具不再苗条挺拔的身躯。这些垂死的耄耋老人仍然长得像妙龄少女，相比之下，四十四岁的琳达就像是一头虚弱变形的老态龙钟的怪物。

“她好可怕，不是吗？”他们窃窃私语地评论着，“看看她的牙齿！”

一个长着狮子鼻的多胞胎的脸突然从床底下探了出来，就在约翰的椅子和墙壁之间，开始端详着琳达沉睡中的脸庞。

“我说……”他刚一开口，话还没说完就尖叫起来。野人抓住他的领口，把他举了起来，将一个盒子扣在他的耳朵上，把他给轰走了。

他的尖叫声引得护士长匆忙赶过来救他。

“你对他做了什么？”她厉声嚷道，“我不允许你打孩子。”

“那好，让他们不要靠近这张床。”野人的声音因为愤慨而发着颤。“这些脏兮兮的小混蛋到底在这里干什么？太不要脸了！”

“不要脸？你什么意思？他们正在接受死亡教育。”她凶巴巴地警告他，“我告诉你，如果我再发现你干涉他们的教育，我会叫门卫把你给扔出去。”

野人站起身，朝她走近了几步。他的动作和他脸上的表情是那么凶恶，护士惊慌地后退。他好不容易克制住自己，什么也没说，转身又坐在床边。

护士的心放了下来，摆出一副尊贵的模样，但仍然有点惊慌失措。“我警告过你了。”护士说道，“我警告过你了。记住了。”但她还是把那几个好奇心太重的孩子带走，让他们去玩她的一位同事在房间的另一端组织的找拉链的游戏。

“现在你可以离开去喝点咖啡因饮料，亲爱的。”她对另一位护士说道。行使权威让她恢复了自信，心情也好一些了。“好了，孩子们！”她召集起孩子们。

琳达被吓了一跳，睁开眼睛，呆滞地看了看周围，然后又昏昏睡去。野人坐在她的身边，努力想重现几分钟前的心情。“A、B、C，维他命D，”他对着自己重复着这些歌词，似乎它们是一个咒语，能让死寂的过去恢复生机。但这个咒语并没有奏效。美妙的回忆顽固地拒绝出现，记起的只有可恶的嫉妒、丑陋和悲惨。肩膀上的伤口流血不止的波普、睡相丑陋的琳达、在滴落在地板上的龙舌兰酒上嗡嗡飞舞的苍蝇，还有那些在她经过时叫嚷着那些难听的骂人的话的男孩子们……啊，不要，不要！他闭上眼睛，摇晃着脑袋拼命想摆脱这些回忆。“A、B、C，维他命D，”他试着记起往事，他坐在她的膝盖上，她搂着他，唱歌给他听，唱了一遍又一遍，摇晃着他，哄他睡觉。“A、B、C，维他命D，维他命D，维他命D……”

超级女声伍利策利娅纳升到了呜咽般的音调，突然间，马鞭草的味道消失了，取而代之的是强烈的天竺薄荷的香味。琳达动了一下，醒了过来，迷糊地盯着那两个半决赛运动员看了几分钟，然后抬起她的脸，闻了闻换了新香水的空气，突然露出微笑——孩子般开心的微笑。

“是波普吗？”她喃喃自语着，然后合上眼睛。“哦，我好喜欢这个味道，我真的好喜欢。”她长叹一声，躺倒在枕头上。

“琳达！”野人哀声说道，“你不认识我了吗？”他那么辛苦，尽了自己最大的努力，为什么她就由得自己遗忘了他呢？他稍稍用力地抓住她那只软绵绵的手，几乎硬要把她从这个可耻的快乐之梦中拉回来，从这些卑贱的可恨的回忆中拉回来——回到此刻，回到现实： 可怕的此刻，糟糕的现实——但那是庄严的意义重大的现实，正因为它让他们如此恐惧，所以才有着如此重要的意义。“你不认识我了吗，琳达？”

他感觉到她的手作出了轻微的回应。眼泪涌入他的眼睛。他弯下身亲吻她。

她的嘴唇动了一下。“是波普吗？”她又低声问道，他顿时感觉像是被一桶粪便浇到脸上。

突然间怒火在他的心中燃烧。他遭到了第二回打击，他的悲痛找到了另一个发泄，化为愤怒而痛苦的激情。

“但我是约翰啊！”他吼叫着，“我是约翰啊！”他悲愤地抓住她的肩膀，摇晃着她。

琳达费劲地张开眼睛，看到了他，认出了他——“约翰！”——但看到那张真实的面孔，触摸到那双真实的有力的手，在一个虚幻的弥漫着天竺薄荷的香气和超级女声伍利策利娅纳的歌声的世界里，在变幻的记忆和光怪陆离的感官梦幻天地里，她认出他是约翰，是她的儿子，却以为他是闯入天堂般的熔岩区的不速之客，而她正在和波普共度苏摩假期。他生气是因为她喜欢波普，他摇晃着她是因为波普就躺在床上——似乎这有什么不对，似乎文明人是不会这么做的。“人人为我，我为人人。”她的声音突然间变成了微弱到几乎听不见的喘不过气的嘶叫。她大张着嘴，拼命想让空气进入她的肺部。但似乎她忘记了如何呼吸，她试着叫嚷——却发不出声音，只有她那双睁得大大的眼睛里的恐惧透露出她所承受的痛苦。她的双手卡着自己的喉咙，然后抓着空气——她再也无法呼吸的空气，对于她来说已经不复存在的空气。

野人站了起来，弯腰看着她，“怎么了，琳达！你怎么了？”他哀声恳求着，似乎他在乞求得到保证。

她看着他的眼神里蕴含着无法用言语形容的恐惧——在他的眼里看来，就像是在责备。

她尝试着起身，但倒回枕头上。她的脸可怕地扭曲着，嘴唇发紫。

野人转身往病房的那头跑去。

“快点，快点！”他高喊道，“快点！”

护士长站在围成一圈玩找拉链的多胞胎的中心，观察着周围。刚开始的惊讶立刻化为不满。“不许高声喧哗！要为这些小孩子着想。”她皱着眉头，“你会影响教育效果的……你在干什么？”他闯进圆圈里。“当心！”一个孩子叫嚷着。

“快点，快点！”他抓住她的衣袖，把她拉在身后。

“快来！出事了。我害了她。”

等到他们回到病房的尽头时，琳达已经死了。

野人全身冰冷，静静地站了一会儿，然后跪在床边，双手捂着脸，无法自制地哭泣着。

护士不安地站在那儿看着床边这个跪在地上的人（多么可耻的一幕！），又看了看那些多胞胎（可怜的孩子们！）。他们停止了找拉链的游戏，从病房的另一头盯着这边，眼睛睁得大大的，鼻孔抬得高高的，看着第二十号病床那里正在上演的惊人一幕。她应该和他说话吗？尝试着让他回到体面庄重的模样？提醒他这里是什么场合？还是告诉他这么胡闹会对这些可怜的无辜的人造成多么致命的破坏，这一令人觉得恶心的哭泣会将健康的死亡教育统统抹杀——似乎死亡是一件可怕的事情，似乎有哪个人很重要一样！这会让他们对这个问题产生最可怕的想法，或许会刺激他们走向完全错误的彻底反社会的道路。

她走上前，拍了拍他的肩膀。“你就不能规矩点吗？”

她生气地低声说道。但她望着周围，看到有六七个多胞胎已经正朝病房的这边走来。圆圈正在解体。再过一会儿……不行，这太危险了。整群人六七个月的教育将会毁于一旦。她立刻朝这群受到威胁的孩子走去。

“好了，谁要巧克力手指饼干？”她以轻快的语气高声问道。

“我要！”这群波卡诺夫斯基多胞胎异口同声地喊道。二十号病床被彻底忘记了。

“噢，上帝啊，上帝啊，上帝啊……”野人不断地对自己重复着。他的脑海里充斥着悲哀与悔恨，这是唯一能够说出口的词语。“上帝啊！”他高声喊叫着，“上帝啊！”

“他到底在说什么？”一个声音说道，凑得很近，在超级女声伍利策利娅纳的颤抖的歌声中显得特别清晰刺耳。

野人吓了一跳，将双手从他的脸上放了下来，看着周围。五个穿着卡其布制服的多胞胎，每个人的右手都拿着一根长长的饼干，一模一样的面孔都糊着液状的巧克力，正站成一排，迷茫地盯着他看。

他们看着他的眼睛，同时咧嘴笑起来。其中一个拿着手指饼干的一头指指点点。

“她死了吗？”他问道。

野人沉默地瞪着他，过了一会儿，站起身，默不作声地慢慢地朝门口走去。

“她死了吗？”那个好管闲事的多胞胎快步走在他身边追问着。

野人低头看着他，依然没有说话，把他推开了。那个男孩摔倒在地上，嚎啕大哭着。野人却连头都不回。

# 第十五章

公园街的临终医院的下等工作人员由一百六十二个德尔塔构成，分为两个波卡诺夫斯基群体，分别是八十四个红头发的女性多胞胎和七十八个深色皮肤的长颅型男性多胞胎。六点钟下班的时候，这两组人在医院的前庭集中，由助理司库为他们分发苏摩。

野人从电梯里走出来，走到他们中间。但他的心灵却在别处——怀着悲痛和悔恨思考着死亡，他就像一具人偶，不知道自己在做什么，开始用肩膀顶着人群想穿过去。

“你在推谁呢？你以为你要到哪里去？”

从许许多多不同的喉咙里发出的只有或高或低两个声音在吱吱作响或咆哮不休。两张面孔就像一面面镜子不停地重复着，一个是长着雀斑的橙黄色的月亮般的光头，另一个是瘦削的长着鹰钩鼻两天没刮脸胡子拉碴的脸，都愤怒地转过来对着他。他们的话语，以及他们的肘部凶狠地顶着他的肋骨，打破了他昏昏沉沉的状态。他再一次醒来，回到现实中。他看着周围，察觉到自己眼前所看到的是什么之后，不仅心里一沉，感到恐惧与恶心，日日夜夜困扰着他的谵妄又开始发作了，噩梦般的蜂拥而至的无法分辨的长得一模一样的多胞胎。多胞胎，多胞胎，他们就像蛆虫，簇拥在临终的琳达身边。蛆虫又来了，但他们的个头更矮，而且发育完全，现在他们正在他的悲伤与悔恨上乱爬。他停下脚步，睁着困惑惊恐的眼睛，盯着身边这群穿着卡其布制服的乌合之众。站在他们中间，他足足比他们高出一个头。“这里有多少好看的人！”这些像歌曲般美妙的话语在嘲讽着他，“人类是多么美丽！啊，美丽的新世界！”

“分发苏摩！”一个声音高声说道，“请保持秩序。赶快到这边来。”

一扇门打开了，一张桌子和一张椅子被抬到前庭。那是一个年轻活泼的阿尔法的声音，捧着一个黑色的铁匣子进来了。这群翘首企盼的多胞胎满足地嘀咕着。他们全然忘记了野人，注意力现在都集中在那个年轻人摆放在桌子上的黑匣子上。他正在开锁，然后把盖子打开了。

“喔——噢！”那一百六十二个多胞胎异口同声地赞叹着，似乎他们正在观看烟花表演。

那个年轻人拿出几个小药匣。“好了，”他颐指气使地说道，“上来吧。每次一个人，不许推推搡搡。”

那群多胞胎每次一个人，没有推推搡搡地走上前。先是两个男的，然后是一个女的，然后又是一个男的，然后是三个女的，然后……

野人站在那儿看着这一幕。“啊，美丽的新世界，啊，美丽的新世界！”在他的脑海中，这些有如歌声般的语句似乎换了个调子。它们嘲讽着他的不幸与悔恨，以愤世嫉俗的可恶的调子调侃他！他们狞笑着，一直就像噩梦那样卑劣、丑陋、令人作呕。现在，突然间，它们就像嘹亮的军号在召集武装，“啊，美丽的新世界！”米兰达在宣告美好的可能性，要将噩梦变成美好而高贵的事物。“啊，美丽的新世界！”它是一个挑战，更是一个命令。

“那边不许推推搡搡！”助理司库怒气冲冲地高喊着，把匣子的盖子给盖上了，“如果行为不规规矩矩的，我就不派发苏摩了。”

德尔塔们嘟囔着，互相推搡了一会儿，然后安静了下来。这个威胁起作用了。领不到苏摩——多么可怕的想法！

“这还差不多。”那个年轻人说道，然后再次打开匣子。

琳达一直是一个奴隶，琳达已经死了，其他人应该生活在自由中，世界应该变得更美好。那是一次补偿，一种义务。突然间野人知道自己必须做什么，就像一扇百叶窗被打开了，一袭窗帘被拉开了。

“好了。”助理司库说道。

另一个穿着卡其布制服的女人走上前。

“停下来！”野人以洪亮铿锵的声音高喊着，“停下来！”

他朝那张桌子一路挤过去。那群德尔塔惊讶地看着他。

“吾主福特啊！”助理司库倒吸一口凉气，“是那个野人。”

他觉得很害怕。

“听着，我求求你们，”野人热烈地高喊着，“请借给我你们的耳朵……”他从未在大庭广众下发言，发现要表达自己的意思非常困难。“不要拿那个可怕的东西。那是毒药，是毒药。”

“听我说，野人先生。”助理司库微笑着想安抚他。

“您介不介意让我……”

“那是戕害灵魂和肉体的毒药。”

“是的，但请让我继续分发工作，好吗？帮帮忙。”他小心翼翼地拍了拍野人的胳膊，就好像在拍一头猛兽一样，“请让我……”

“不行！”野人喊道。

“听我说好吗？老伙计。”

“把它统统扔掉，那是可怕的毒药。”

“把它统统扔掉”这几个字穿透了层层叠叠的鲁钝，直插那些德尔塔的心头，他们发出了愤怒的抱怨。

“我是来赐予你们自由的。”野人说道，转身面对那些多胞胎，“我来了。”

那个助理司库听不见他在说些什么。他已经溜出了前庭，正在电话本里查找着号码。

“不在他自己的房间里。”伯纳德的结论就是，“也不在我的房间里，不在你的房间里。不在阿佛洛狄宫，也不在中心或学院。他能去哪儿呢？”

赫姆霍兹耸了耸肩膀。他们刚下班，以为野人会在平时经常见面的地方等候他们，但这个家伙不见踪影，真是讨厌，他们已经计划好了乘坐赫姆霍兹的四座运动型直升飞机去比亚里茨。如果他再不来的话，他们的晚餐就迟了。

“我们再给他五分钟吧。”赫姆霍兹说道，“如果他还不来的话，我们就……”

电话的铃声打断了他。他拿起话筒。

“你好，请讲。”然后，听了好一会儿，“吾主福特登临御车！”他骂了一句，“我马上来。”

“出什么事了？”伯纳德问道。

“一个在公园街医院的人，我认识他。”赫姆霍兹说道，“野人在那儿。似乎发疯了。不管怎样，事情很紧急。你和我一起去吗？”

他们一起匆匆沿着走廊来到电梯里。

“你们愿意做奴隶吗？”他们刚走进医院就听到野人说道。他的脸涨得通红，他的眼睛闪耀着热烈而愤慨的光芒。“你们愿意当婴儿吗？是的，婴儿。呜呜呜地哭泣和呕奶。”他被他们野兽般的愚昧激怒了，开始羞辱这些原本想要拯救的人。但这些侮辱根本无法穿透他们厚厚的愚昧的硬壳。他们一脸茫然地盯着他，眼睛里带着迟钝而阴郁的怨恨。

“是的，在呕奶呢！”他高喊着。悲伤与悔恨、同情与责任现在都被忘得一干二净，被一股强烈的压倒一切的对这些称不上是人的怪物的仇恨吞没。“难道你们不想成为自由的人吗？难道你们就不明白人性和自由为何物吗？”愤怒使他变得口齿清晰，这些话滔滔不绝地脱口而出。“难道你们就不知道吗？”他重复着，但没有人回答这个问题。“很好。”他冷冰冰地说道，“我会教导你们。我会让你们获得自由，无论你们想不想要。”他推开一扇朝向医院内庭的窗户，开始将那些盛着苏摩的小药盒一把把地扔出窗外。

那群穿着卡其布制服的乌合之众惊呆了，惊恐地看着这一肆意妄为离经叛道的做法。

“他疯了。”伯纳德喃喃说道，睁大着眼睛看着这一幕。“他们会杀了他的。他们会……”那群人突然爆发出一声呐喊，一波浪潮恶狠狠地朝野人涌去。“愿吾主福特保佑他！”伯纳德嚷道，移开了眼睛。

“自助者，吾主福特亦助之！”赫姆霍兹·华生得意地大笑着，推开人群冲了上去。

“自由吧，自由吧！”野人叫嚷着，一只手继续将苏摩扔出去，而另一只手痛殴着攻击者无法辨认的脸庞。

“自由吧！”赫姆霍兹突然出现在他身边——“赫姆霍兹，你好啊！”——又揍出一拳——“终于是男子汉了！”——与此同时一把又一把地将那些毒药扔出窗外。“是的，男子汉！男子汉！”再也没有毒药剩下了。他将那个空荡荡黑漆漆的匣子拎给那群人看。“你们自由了！”

那群德尔塔愈发愤怒地咆哮着冲了过来。

伯纳德在战斗的圈子外面徘徊着。“他们死定了。”伯纳德说道，冲动之下，他突然跑上前想去救他们，然后好好想了一想，停下脚步，然后觉得很羞愧，又往前跑了几步，然后又好好想了一想，站在那里为自己的优柔寡断感到羞愧和苦恼——心想要是他不上去帮他们的话他们或许会被杀死，又觉得如果上去帮助他们的话自己也可能搭上性命——这时，戴着鼓眼睛和猪鼻子一样的毒气面具的警察跑了过来。

伯纳德冲上去迎接他们。他挥舞着双臂，这就是行动，他总算做点什么事情了。他叫嚷着：“救命啊！”叫了好几次，而且越叫越大声，让自己觉得正在帮忙。“救命啊！救命啊！救命啊！”

警察将他推到一边，开始采取行动。三个肩膀上绑着喷射器的警察朝空中喷射浓烈的苏摩蒸汽。还有两个警察忙着摆弄那部移动式合成音乐盒。另外四个警察端着装满了强力麻醉剂的水枪，已经挤进人群中，干净利落地分头朝那些比较凶狠的打架斗殴者开枪。

“快点，快点！”伯纳德喊道，“你们如果不快点的话，他们会被杀死的。他们会……噢！”一个警察被他的喋喋不休烦透了，用水枪射了他一下。伯纳德摇摇晃晃地站了一两秒钟，双腿似乎没有了骨头、筋腱和肌肉，只是两根果冻凝胶，最后就连凝胶也不是了，瘫倒在地上。

突然间，从合成音乐盒里传出一个声音，开始说话。那是理性的声音，美好感觉之声。音轨纸卷正在播放的是合成反暴动演讲二号（中等强度），来自一个子虚乌有的人物的肺腑之声。“我的朋友，我的朋友！”那个声音是如此动情，深情款款地柔声责备，就连戴着毒气面具的警察一时间眼里也噙着泪花。“这是怎么回事？为什么你们不能快乐地好好相处呢？做一个快乐的好人。”那个声音重复着，“平静，平静。”它颤抖着，减弱为呓语，时不时低到根本听不见。“噢，我真的希望你能快乐。”它开始满怀真挚地说道，“我真的希望你能当一个好人！请当一个好人，请……”

两分钟后，那个声音和苏摩气体发挥了作用。那群德尔塔含泪互相亲吻和拥抱着——每六七个多胞胎互相紧紧地拥抱，就连赫姆霍兹和野人也几乎哭出来。从库房那里运来了新的药片匣子，新的分发行动立刻执行，在柔和热情的男中音的劝慰下，那些多胞胎哭哭啼啼地离开了，似乎心都碎了。“再见，我最最亲爱的朋友们，愿吾主福特保佑你们！再见，我最最亲爱的朋友们，愿主保佑你们。再见，我最最亲爱的……”

当最后一个德尔塔走后，警察切断了电流。那个天使般的声音顿时哑了。

“你们愿意安静地走吗？”小队长问道，“还是说我们必须使用麻醉剂？”

他指着自己的水枪以示威胁。

“噢，我们愿意安静地走。”野人回答，轮番轻抚着被割伤的嘴唇、被抓伤的脖子和被咬了好几口的左手。

赫姆霍兹仍然用手帕捂着自己流血的鼻子，点了点头表示同意。

伯纳德醒了过来，而且双腿也能走路了，正准备偷偷朝门口溜去。

“嘿，那边那位。”小队长喊道，一个戴着猪鼻式毒气面具的警察匆匆穿过房间，把手搭在伯纳德的肩膀上。

伯纳德以愤慨而无辜的表情转过头来。逃跑？他根本没有想过这种事情。

“你到底想要我怎么样？”他问小队长，“我真的无法想象。”

“你是这两个犯人的朋友吧？”

“嗯？”伯纳德犹豫着。他没办法否认。

“难道我不是吗？”他反口问道。

“那就走吧。”小队长说道，然后领着他们朝门口那辆等候着的警车走去。

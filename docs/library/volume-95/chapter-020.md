# 第二章　数量、质量、道德

在《美丽新世界》里，我所幻想的优生学和劣生学得以系统实现。在一组瓶子里装着生理质量优秀的卵子，由生理质量优秀的精子进行受精，得到最好的产前处理，最后通过试管培育出贝塔、阿尔法甚至优等阿尔法。在另一组数量多得多的瓶子里，生理质量低劣的卵子由生理质量低劣的精子受精，然后接受波卡诺夫斯基流程处理（由一个卵子培养出九十六个一模一样的多胞胎），并在产前再用酒精和其他蛋白质毒素加以处理。这些通过试管培育出来的生物几乎算不上是人，但他们能够进行非技术性的工作，经过适当的培育，自由频繁地与异性交往以放松身心，沉溺于免费的娱乐消遣，并通过每日服用苏摩对良好的行为模式加以强化，不会为他们的上司领导制造麻烦。

在二十世纪的后半阶段，我们并没有对生育进行系统性的处理，但由于我们的生育没有节制，我们不仅使得地球人口过剩，而且似乎这个数目庞大的人口的生理素质还变差了。在糟糕的旧时代，有明显遗传性缺陷的孩子或只是略有遗传性缺陷的孩子很难活下来。而如今，由于卫生、现代医学和社会良知的进步，大部分有遗传缺陷的孩子都能长大成人，而且繁衍自己的后代。在如今的普遍条件下，医学上的每一次进步都会被某些有基因缺陷的个体的生存率的提高抵消掉。尽管有了新的灵丹妙药和更合理的措施（事实上，从某种意义上说，正是因为这些），人口的整体健康状况将不会得到改善，甚至可能恶化。而伴随这一情况，人口的平均智力水平或许也会下降。事实上，某些权威人士相信这种情况已经出现，而且正在继续。“在软弱而无序的情况下，”威廉·赫伯特·谢尔顿博士写道，“我们最好的人种将会被方方面面都不如他们的劣等的人种所淹没……在一些学术圈子里，向学生们保证对于出生率差异的担心毫无根据成为一种风尚，说这些问题只是经济上的问题，或只是教育上的问题，或只是宗教上的问题，或只是文化上的问题，或某个方面的问题。这是盲目的乐观主义。生育不良是最基本的生物问题。”他还补充说：“没有人知道这个国家（美国）的平均智力水平自从一九一六年特曼尝试标准化IQ100的意义以来到底下降了多少。”

在一个人口过多的不发达的国家，当五分之四的人口每天的热量摄入不到两千卡路里，只有五分之一的人口能够吃得上饱饭时，能够自发实现民主吗？如果民主制度由外部确立或自上而下推行，它能够维持下去吗？

现在，让我们思考一下富裕的工业化的民主社会的情况，在劣生学随机而有效的作用下，智力水平和身体机能正在下降。这么一个社会能维持它的个体自由和民主政府的传统多久呢？再过五十年或一百年，我们的儿孙辈将会知道这个问题的答案。

与此同时，我们发现自己面临一个最令人不安的道德问题。我们知道对高尚目标的追求并不表示能动用卑劣的手段。但那些如今经常发生的由于好的手段而导致糟糕的结果的情况又如何呢？

比方说，我们来到一个热带岛屿，在滴滴涕的帮助下，我们消灭了疟疾，在两三年内，拯救了数十万人的生命。这显然是好事。但这数十万被救活的人，以及他们繁衍出的数以百万计的后代，没有衣服穿，没有房子住，无法接受教育，甚至将岛上可供利用的资源全部消耗殆尽。疟疾造成的早夭被消灭了，但营养不良和过度拥挤使得悲惨的生活成为常态，饥饿造成的早亡对更多的人口造成了威胁。

那些先天不足的人又怎么样呢？我们的医药和社会服务保全了他们的性命，让他们得以繁衍自己的后代。帮助不幸的人显然是好事。但不良变异的结果正成批量地遗传给我们的后代，一点一滴地污染我们这个物种赖以繁衍后代的基因库，显然也是很糟糕的事情。我们陷入了伦理上的两难境地，必须倾注所有的智慧和善意，才能找到一条中庸之道。

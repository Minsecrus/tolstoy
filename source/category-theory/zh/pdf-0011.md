条件”这样的说法，在范畴论中很常见。它的意思是，满足该条件的某某有且只有一个。要证明存在性部分，我们必须说明至少有一个；要证明唯一性部分，我们必须说明至多有一个，换句话说，满足该条件的任意两个某某都相等。

这样的性质称为“泛”性质，是因为它说明了所描述的对象（在这里是集合 $1$）与它所处的整个世界（在这里是集合的世界）之间的关系。这条性质以“*对所有*集合 $X$”开头，因此它说明了 $1$ 与*每一个*集合 $X$ 的关系：即存在唯一的从 $X$ 到 $1$ 的映射。

**例 0.2** 这个例子涉及环；本书中的环一律假定具有乘法单位元，记为 $1$。同样，环同态也一律理解为保持乘法单位元的同态。

环 $\mathbb{Z}$ 具有如下性质：对所有环 $R$，都存在唯一的同态 $\mathbb{Z} \to R$。

为证明存在性，设 $R$ 为一个环。定义函数 $\phi: \mathbb{Z} \to R$ 如下：

$$
\phi(n) = \begin{cases}
\underbrace{1 + \cdots + 1}_{n} & \text{若 } n > 0, \\
0 & \text{若 } n = 0, \\
-\phi(-n) & \text{若 } n < 0
\end{cases}
$$

（$n \in \mathbb{Z}$）。通过一系列初等的检验，可以确认 $\phi$ 是同态。

为证明唯一性，设 $R$ 为一个环，且 $\psi: \mathbb{Z} \to R$ 为一个同态。我们证明 $\psi$ 等于刚才定义的同态 $\phi$。由于同态保持乘法单位元，$\psi(1) = 1$。由于同态保持加法，

$$
\psi(n) = \psi\left(\underbrace{1 + \cdots + 1}_{n}\right) = \underbrace{\psi(1) + \cdots + \psi(1)}_{n} = \underbrace{1 + \cdots + 1}_{n} = \phi(n)
$$

对所有 $n > 0$ 都成立。由于同态保持零元，$\psi(0) = 0 = \phi(0)$。最后，由于同态保持加法逆元，当 $n < 0$ 时，$\psi(n) = -\psi(-n) = -\phi(-n) = \phi(n)$。

关键在于，满足给定泛性质的对象，本质上只能有*一个*。“本质上”的意思是，满足同一泛性质的两个对象未必在字面意义上相等，但它们总是同构的。例如：

**引理 0.3** *设 $A$ 为一个环，具有如下性质：对所有环 $R$，都存在唯一的同态 $A \to R$。那么 $A \cong \mathbb{Z}$。*
